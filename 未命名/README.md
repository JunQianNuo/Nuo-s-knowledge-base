# 收件箱

> [!tip]
> 这里是唯一的临时 Markdown 捕获区。先记录，后整理；不要在捕获时纠结最终归属。

## 放入这里

- 临时想法、网页摘录、待分类笔记；
- 需要后续处理的轻量任务；
- 尚未确定属于哪门课程或哪个项目的 Markdown。

## 不放入这里

- 课程原始 PDF、图片和 OCR 临时文件：进入对应课程的 `未处理/` 或 `未处理项/`；
- 闪卡：只放入 `闪卡/课程/章节/`，并遵守一文件一卡片；
- 已有明确归属的正式知识笔记。

## 每周清空

1. 标注归属、状态与下一步；
2. 归档到正式位置，或转为项目任务；
3. 无价值内容直接删除；
4. 收件箱只保留仍需判断的内容。

新条目请使用 [[模板/收件箱条目模板|收件箱条目模板]]。
