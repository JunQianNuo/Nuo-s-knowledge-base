# 可分性

## 一句话

可分性是"空间存在可数骨架"的拓扑性质——存在可数个元素使得空间中的每一点都可以用它们任意逼近，它是泛函分析中 Schauder 基、可分 Banach 空间理论的基础，也是 $L^p$（$1 \leq p < \infty$）区别于 $L^\infty$ 的关键性质。

## 严格定义

设 $(X, d)$ 为度量空间。称 $X$ 为**可分的**（separable），若存在可数子集 $\{x_n\}_{n=1}^{\infty} \subset X$ 使得

$$\overline{\{x_n\}} = X,$$

即该可数子集在 $X$ 中稠密。等价地：$X$ 中存在可数稠密子集。

### $L^p$ 空间的可分性

**定理**：设 $E \subset \mathbb{R}^n$ 为可测集。

- 对 $1 \leq p < \infty$，$L^p(E)$ 是**可分的**。
- $L^\infty(E)$（当 $m(E) > 0$ 时）是**不可分的**。

**$L^p$（$p < \infty$）可分性的证明思路**（逼近链）：

1. **简单函数稠密**：简单函数全体在 $L^p$ 中稠密（任意 $f \in L^p$ 可用简单函数列 $L^p$ 逼近）。
2. **紧支集连续函数逼近**：Lusin 定理保证紧支集连续函数在 $L^p$ 中稠密。
3. **阶梯函数逼近**：紧支集连续函数可用阶梯函数（以方体上的特征函数为基）一致逼近，从而 $L^p$ 逼近。
4. **有理系数化——构造可数集**：将阶梯函数的系数限制为有理数、方体端点限制为有理坐标，如此得到的阶梯函数全体 $\Gamma$ 是**可数集**，且 $\Gamma$ 在 $L^p(E)$ 中稠密。
5. 结论：$\Gamma$ 是 $L^p(E)$ 的可数稠密子集，故 $L^p(E)$ 可分。

**替代路径**：也可用 Weierstrass 逼近定理——有理系数多项式全体可数且在 $L^p[a,b]$ 中稠密。

**$L^\infty[0,1]$ 不可分性的经典证明**：

考虑 $\mathcal{A} = \{\chi_{[0,\alpha]} \mid 0 < \alpha < 1\}$。对 $\alpha \neq \beta$，

$$\|\chi_{[0,\alpha]} - \chi_{[0,\beta]}\|_\infty = 1.$$

$\mathcal{A}$ 是**不可数集**，且其中任意两个不同元素的 $L^\infty$ 距离均为 $1$。因此不存在可数集能同时逼近 $\mathcal{A}$ 中所有元素——任何可数集最多能逼近其中至多一个元素（在以 $1/2$ 为半径的球内）。

> [!important] 核心要点
> - **可分性是"小空间"性质**：度量空间的势（基数）决定可分性的可能——可分度量空间的势不超过 $\mathfrak{c}$（连续统）。
> - **$L^p$（$p<\infty$）可分 vs $L^\infty$ 不可分**：$p$ 越小，空间越"大"（有限测度集上 $L^{p_2} \subset L^{p_1}$ 当 $p_2 > p_1$），但可分性恰恰相反——$p<\infty$ 可分，$p=\infty$ 不可分。这是因为 $L^\infty$ 范数"太强"——它不会把不同的特征函数"拉近"。
> - **$L^\infty$ 不可分的根源**：存在不可数个相互距离为 $1$ 的元素（特征函数族 $\chi_{[0,\alpha]}$），而可分空间中两两距离 $\geq 1$ 的集合至多可数。
> - **可分性在逼近论中的意义**：可分空间保证存在可数基（Schauder 基等），使得每个元素可展开为可数级数——这是数值计算的基石。
> - **Sobolev 空间也可分**：$W^{k,p}(\Omega)$ 对 $1 \leq p < \infty$ 也可分（通过磨光算子 + $L^p$ 可分性得到）。

## 由来与作用

- **历史起源**：可分性的概念随度量空间的诞生而出现——法国数学家 **Maurice Fréchet**（1906）在引入度量空间的同时定义了可数稠密子集的概念。F. Riesz（1910）在系统研究 $L^p$ 空间时证明了 $L^p$（$p<\infty$）的可分性，Banach（1920s）将其纳入赋范空间的框架，证明了"可分 Banach 空间存在 Schauder 基"这一重要结论（Mazur 的早期工作围绕此问题展开）。

- **解决的问题**：可分性回答了"函数空间是否可以用可数个'基本构件'完全描述"的问题。在实际计算（有限元、谱方法、机器学习核方法）中，算法本质上是有限维逼近无限维空间——可分性保证了这种逼近在理论上是可能的：存在可数稠密子集意味着可以用可数个基函数展开空间中的任意元素。

- **在实变函数中的核心角色**：
  - **课程知识链的终点之一**：实变函数从集合论 → 测度 → 积分 → $L^p$ 空间，最终讨论 $L^p$ 的完备性和可分性——这两个性质确立了 $L^p$ 作为 Banach 空间的完整结构，是泛函分析的入口。
  - **$L^p$ 与 $L^\infty$ 的本质分界**：$L^p$（$p<\infty$）和 $L^\infty$ 都是 Banach 空间（完备），但**可分性把它们彻底分开**——$L^p$ 是"可操作的"（可用可数个基逼近），$L^\infty$ 是"不可操作的"（过于庞大）。这是 $L^\infty$ 在理论分析中被"边缘化"的核心原因。
  - **逼近论的根基**：可分性的证明引入了"有理系数 + 有理端点方体"的构造——这是将连续量离散化为可数集的经典技巧，在数值分析和逼近论中反复出现。

- **关键性质**：
  - 可分度量空间的任意子空间也可分（与完备性不同：完备空间的闭子空间完备，但任意子空间不一定完备）。
  - 可分度量空间的势（基数）$\leq \mathfrak{c}$（连续统）。
  - 紧度量空间必可分（紧集可由有限开覆盖中的有理端点球系构成可数稠密子集）。
  - 任意可分 Banach 空间等距同构于某个 $C[0,1]$ 的商空间（Banach-Mazur 定理）。
