# 度量空间

## 一句话

度量空间是将 $\mathbb{R}^n$ 中距离的三条基本性质（正定性、对称性、三角不等式）抽象到任意集合上，使得收敛、开闭、完备性等拓扑概念能在远不止欧氏空间的一般结构中讨论——它是泛函分析的起点。

## 严格定义

设 $X$ 是一个非空集合，映射 $d: X \times X \to [0, +\infty)$ 称为 $X$ 上的一个**度量**（距离函数），若对任意 $x, y, z \in X$ 满足：

1. **正定性**：$d(x, y) = 0 \iff x = y$
2. **对称性**：$d(x, y) = d(y, x)$
3. **三角不等式**：$d(x, z) \leq d(x, y) + d(y, z)$

此时称 $(X, d)$ 为一个**度量空间**。

> [!important] 核心要点
> - 度量是 $\mathbb{R}^n$ 中欧氏距离的公理化抽象——只要满足这三条，任何空间都可以谈论"远近"。
> - 度量诱导的拓扑：以开球 $B(x, r) = \{ y \in X \mid d(x, y) < r \}$ 为基生成拓扑，由此定义**开集、闭集、内点、聚点、闭包**等所有拓扑概念。
> - **同一集合上可定义不同的度量**：$(\mathbb{R}^n, d_{\ell^1})$、$(\mathbb{R}^n, d_{\ell^2})$、$(\mathbb{R}^n, d_{\ell^\infty})$ 诱导相同的拓扑（等价度量），但离散度量 $d_{\text{disc}}$ 诱导完全不同的拓扑（所有单点集都是开集）。
> - 序列收敛 $x_n \to x$ 在度量空间中等价于 $d(x_n, x) \to 0$。
> - **完备性**：度量空间 $(X, d)$ 完备 $\iff$ 每个 Cauchy 列（满足 $\lim_{k,\ell \to \infty} d(x_k, x_\ell) = 0$）都收敛于 $X$ 中某点。
> - **紧致性**：度量空间中，紧致 $\iff$ 列紧（每个序列有收敛子列）$\iff$ 每个开覆盖有有限子覆盖（Heine-Borel 性质）。

### 典型例子

| 度量空间 | 距离定义 | 完备性 |
|:--|:--|:--|
| $(\mathbb{R}^n, d_2)$（Euclid 空间） | $d_2(x, y) = \left(\sum_{i=1}^{n} \vert x_i - y_i \vert^2\right)^{1/2}$ | 完备 |
| $(\mathbb{R}^n, d_1)$（Manhattan） | $d_1(x, y) = \sum_{i=1}^{n} \vert x_i - y_i \vert$ | 完备 |
| $(\mathbb{R}^n, d_\infty)$（Chebyshev） | $d_\infty(x, y) = \max_i \vert x_i - y_i \vert$ | 完备 |
| $(X, d_{\text{disc}})$（离散度量） | $d(x, y) = 1$ 若 $x \neq y$，否则 $0$ | 完备 |
| $(C[0,1], d_\infty)$（连续函数空间） | $d_\infty(f, g) = \sup_{x \in [0,1]} \vert f(x) - g(x) \vert$ | 完备 |
| $(L^p, d_p)$ | $d_p(f, g) = \Vert f - g \Vert_p$ | 完备 |
| $(\mathbb{Q}, d_2)$（有理数 + 欧氏距离） | 同上 $d_2$ | **不完备**（Cauchy 列 $(1+\frac{1}{n})^n \to e \notin \mathbb{Q}$） |

## 由来与作用

- **历史渊源**：度量空间由法国数学家 **Maurice Frechet** 于 1906 年在其博士论文中正式引入，目的是将 Cantor、Volterra、Arzela 等人在函数空间中的收敛性讨论统一到一个抽象框架中。这是现代泛函分析的开端。
- **解决的问题**：在 $\mathbb{R}^n$ 上做分析，我们可以用 $\vert x - y \vert$ 谈论极限和连续性，但函数空间（如 $C[0,1]$、$L^p$）中的收敛需要新的"距离"。度量空间提供了统一语言——只要定义好 $d$，所有分析论证照搬。
- **在实变函数中的角色**：
  - 实变函数研究的是 Lebesgue 积分和测度，其理论建立在一系列拓扑和度量概念之上（开集 $\to$ Borel 集 $\to$ 可测集）。
  - $L^p$ 空间是实变函数的核心研究对象，而其完备性是整个理论的基石（Riesz-Fischer 定理）。
  - 完备度量空间上的 Baire 范畴定理是实分析中许多"存在性"论证的核心工具。
- **关键性质**：
  - 完备度量空间的闭子空间完备；不完备空间可完备化（类似于 $\mathbb{Q} \to \mathbb{R}$）。
  - 紧度量空间必完备且有界（但反之不真：$(\mathbb{R}, d_2)$ 完备有界不紧致）。
  - 度量空间中紧致等价于列紧（序列紧），但在一般拓扑空间中二者不等价——这是度量空间特有的优良性质。
