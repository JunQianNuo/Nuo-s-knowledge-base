# 量子化

## 一句话
量子化是微观世界最根本的特征——能量、角动量、自旋等物理量只能取一系列**分立值**，而非经典物理允许的连续值；普朗克常量 $h$ 是量子化尺度的标志。

## 严格定义

**普朗克能量子假设（1900）**：
谐振子的能量不连续，只能取最小能量单元 $h\nu$ 的整数倍：
$$\varepsilon_n = n h \nu, \quad n = 0, 1, 2, \ldots$$
其中 $h = 6.63 \times 10^{-34} \text{ J·s}$ 为普朗克常量。

**玻尔角动量量子化条件（1913）**：
氢原子中电子的轨道角动量只能取 $\hbar = h/2\pi$ 的整数倍：
$$L = mvr = n\hbar, \quad n = 1, 2, 3, \ldots$$

在此基础上导出氢原子能级 $E_n = -\dfrac{13.6}{n^2} \text{ eV}$。

**量子力学中的量子化（1926+）**：
薛定谔方程在束缚态边界条件下自然导出**量子化**，不再需要人为假设：
- 一维势阱能级：$E_n = n^2 \dfrac{\hbar^2 \pi^2}{2ma^2}$，$n=1,2,3,\ldots$
- 轨道角动量：$L = \sqrt{l(l+1)}\hbar$，$l = 0,1,\ldots,n-1$
- 角动量 $z$ 分量：$L_z = m_l \hbar$，$m_l = 0,\pm1,\ldots,\pm l$
- 自旋 $z$ 分量：$S_z = m_s \hbar$，$m_s = \pm\frac{1}{2}$

> [!important] 量子化的本质
> 量子化不是"假设"，而是**束缚态边界条件的必然结果**：薛定谔方程 $-\frac{\hbar^2}{2m}\nabla^2\psi + U\psi = E\psi$ 在束缚条件下只有某些 $E$ 值（本征值）有物理上可接受的波函数解（满足标准条件）。

## 由来与作用
- 1900年普朗克为解决黑体辐射"紫外灾难"引入能量子假设，标志着量子物理的诞生——这是人类第一次认识到自然界有不连续性
- 1913年玻尔将量子化条件引入原子模型，成功解释了氢原子光谱的线状结构（里德伯公式 $\bar{\nu} = R(1/k^2 - 1/n^2)$）
- 量子力学建立后，量子化成为薛定谔方程的自然推论——从"人为假设"变为"数学必然"，所有束缚系统（原子、分子、原子核、固体中的电子）都表现出量子化能谱
- 关键性质：量子化的"粒度"由 $h$ 决定——$h$ 极小（$10^{-34}$ 量级），因此宏观世界中量子化不可察觉
