# 条件概率与条件期望

## 一句话

条件概率和条件期望回答"在已知部分信息的条件下，概率和平均值如何更新"——它们把样本空间缩小到已发生的事件上重新计算，是从"先验"到"后验"的概率更新机制。

## 严格定义

**条件概率**（事件）：设 $P(B) > 0$，则 $P(A|B) = \dfrac{P(AB)}{P(B)}$。$P(\cdot|B)$ 是 $(\Omega, \mathscr{F})$ 上合法的概率测度。

**条件分布**（连续型）：$f_{\eta|\xi}(y|x) = \dfrac{f(x,y)}{f_\xi(x)}$（$f_\xi(x) > 0$）。本质是联合密度的"切片归一化"。

**条件数学期望**：$E(\eta|\xi = x) = \int y \, dF_{\eta|\xi}(y|x)$。它是 $x$ 的函数 $\mu(x)$；将 $x$ 替换回 $\xi$，得到随机变量 $E(\eta|\xi) \triangleq \mu(\xi)$。

**全数学期望公式**（必考）：
$$E(\xi) = E[E(\xi|\eta)]$$

> [!important] 核心要点
> - 条件概率 $P(\cdot|B)$ 满足概率的三条公理——所有无条件概率的公式（加法、多除少补、连续性）加 $|B$ 后全部照常成立。
> - 全概率公式 $P(A) = \sum P(B_i)P(A|B_i)$ 和贝叶斯公式 $P(B_i|A) = \frac{P(B_i)P(A|B_i)}{P(A)}$ 是事件层面的核心推理工具——前者从原因推结果，后者从结果反推原因。
> - **贝叶斯陷阱**：罕见病筛查阳性 $\neq$ 确诊——先验概率极小时，即使检测准确率很高，绝大多数阳性仍是假阳性。
> - 全期望公式是 Ch4 必考大题的核心工具：随机和 $S = \sum_{i=1}^N \xi_i$ 的期望 $E(S) = E(N)E(\xi)$。

## 由来与作用

- **概念演进**：Ch1 条件概率（事件层面）→ Ch3 条件分布（随机变量层面，联合/边缘/条件三者关系）→ Ch4 条件期望与全期望公式（数字特征层面）。
- **核心思维**："分情况讨论"。全概率公式和全期望公式的本质都是把复杂问题按划分拆成简单子问题，加权平均。
- **贝叶斯推理**：先验概率 $P(B_i)$ → 似然 $P(A|B_i)$ → 后验概率 $P(B_i|A)$。贝叶斯公式是概率更新（从先验到后验）的数学表述，是贝叶斯统计学派的基石。
- **最优预测**：在均方误差意义下，$E(\xi|\eta)$ 是 $\xi$ 基于 $\eta$ 的最优预测。
