# 分布函数

## 一句话

分布函数 $F(x) = P\{\xi \leq x\}$ 是把随机变量的全部概率信息编码为一条完整曲线的工具——它统一了离散型（阶梯函数）和连续型（光滑函数）的描述框架，概率计算由此"函数化"。

## 严格定义

设 $\xi$ 是概率空间 $(\Omega, \mathscr{F}, P)$ 上的随机变量，称

$$F(x) = P\{\xi \leq x\} = P\{\omega: \xi(\omega) \leq x\}, \quad x \in \mathbb{R}$$

为 $\xi$ 的**分布函数**（Cumulative Distribution Function, CDF）。

**三大充要性质**（定理 2.1.1 及其逆定理）：
1. **单调不减**：$x_1 < x_2 \Rightarrow F(x_1) \leq F(x_2)$
2. **右连续**：$F(x+0) = F(x)$，$\forall x \in \mathbb{R}$
3. **有界性**：$\lim_{x \to -\infty} F(x) = 0$，$\lim_{x \to +\infty} F(x) = 1$

对于二维随机变量 $(\xi, \eta)$，**联合分布函数**为 $F(x,y) = P\{\xi \leq x, \eta \leq y\}$，额外要求矩形概率非负（相容性）。

> [!important] 核心要点
> - 分布函数的增量才是区间概率：$P\{a < \xi \leq b\} = F(b) - F(a)$。在连续点处 $P\{\xi = x\} = 0$，概率"藏"在增量中。
> - 三大性质是分布函数的"身份证"——任何满足这三条的函数**一定**是某个随机变量的分布函数（逆定理）。
> - 由联合分布可唯一确定边缘分布（令其他变量 $\to +\infty$），但由边缘分布一般**不能**确定联合分布——丢失了变量间的依赖信息。

## 由来与作用

- **统一框架**：离散型下 $F(x) = \sum_{x_i \leq x} p_i$ 是阶梯函数（跳跃高度 = $p_i$）；连续型下 $F(x) = \int_{-\infty}^x f(t) dt$ 是连续函数，$F'(x) = f(x)$。
- **工具链**：分布函数 → R-S 积分给出数学期望 $E(\xi) = \int x dF(x)$；分布函数 → 傅里叶-斯蒂尔杰斯变换给出特征函数 $\varphi(t) = \int e^{jtx} dF(x)$。分布函数是数字特征和特征函数的"母体"。
- **与特征函数的一一对应**：唯一性定理保证分布函数和特征函数互相唯一确定——这是特征函数法的理论基础。
