# 温度

## 一句话
温度是分子平均平动动能的宏观量度——热力学第零定律给出了温度的宏观定义基础，统计物理则揭示了其微观本质 $\bar{E}_t = \frac{3}{2}kT$。

## 严格定义

**宏观定义（热力学第零定律）**：
> 如果系统 A 与 C 热平衡，系统 B 与 C 热平衡，则 A 与 B 也热平衡。处于热平衡的系统具有相同的**温度**。

第零定律确立了温度作为表征热平衡的态函数，使温度测量成为可能。

> [!important] 温度的统计本质
> 联立理想气体状态方程 $p = nkT$ 与压强公式 $p = \frac{2}{3}n\bar{E}_t$，消去 $p$ 得：
> $$\bar{E}_t = \frac{3}{2}kT$$
> 温度是大量分子**平均平动动能**的量度。温度只对大量分子有意义——单个分子没有温度概念。

其中 $k = R/N_A = 1.38 \times 10^{-23} \text{ J/K}$ 为玻尔兹曼常量。

## 由来与作用
- 温度概念源于人类对冷热的直觉感知，经历了从经验到科学的飞跃：热力学第零定律（1930年代被命名为"第零定律"）提供了温度的宏观操作定义——不需要知道热是什么，只需建立热平衡的传递性即可定义温度
- 统计物理进一步揭示了温度的微观本质：温度正比于分子的平均平动动能，是大量粒子无规则运动强度的统计表征
- 关键性质：温度是**强度量**（与系统大小无关），是**状态函数**（平衡态下才有确定意义）；温度决定热传递方向——热量总是自发地从高温传向低温（热力学第二定律）
