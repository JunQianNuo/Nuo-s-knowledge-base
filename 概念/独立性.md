# 独立性

## 一句话

独立性是概率论中最重要的"乘法结构"——当两个对象（事件或随机变量）独立时，联合概率/分布就等于各自概率/分布的乘积，这使得复杂问题的概率计算可以被拆解为简单部分的乘积。

## 严格定义

**事件独立**：$A$ 与 $B$ 相互独立 $\iff P(AB) = P(A)P(B)$。此定义不要求 $P(A) > 0$ 或 $P(B) > 0$，比 $P(A|B) = P(A)$ 更一般。

**随机变量独立**：$\xi$ 与 $\eta$ 相互独立 $\iff F(x,y) = F_\xi(x) \cdot F_\eta(y)$，$\forall (x,y) \in \mathbb{R}^2$。等价地：
- 离散型：$p_{ij} = p_{i\cdot} \cdot p_{\cdot j}$，对所有 $(x_i, y_j)$
- 连续型：$f(x,y) = f_\xi(x) \cdot f_\eta(y)$，在平面上除去零测集外成立

**$n$ 个事件相互独立**：对任意 $s$（$1 < s \leq n$）及任意 $s$ 个事件，乘积公式均成立——共需验证 $2^n - n - 1$ 个等式。

> [!important] 核心要点
> - **独立 $\neq$ 互不相容**：独立是"概率乘积关系"，互不相容是"事件不能共存"。概率非零时，独立的事件必有交集，互不相容的事件必不独立。
> - **两两独立 $\nRightarrow$ 相互独立**（四面体问题是经典反例）：相互独立要求所有子集组合的乘积公式都成立，远比两两独立严格。
> - **多维正态的特殊性**：对联合正态分布，独立 $\iff$ 不相关（$r = 0$）。这是一般分布不具备的特殊性质，因为正态特征函数的交叉项 $t_i t_j \sigma_{ij}$ 为 0 时自然因子分解。
> - 独立事件的"取反不变"：若 $A, B$ 独立，则 $\overline{A}$ 与 $B$、$A$ 与 $\overline{B}$、$\overline{A}$ 与 $\overline{B}$ 也分别独立。

## 由来与作用

- **从事件到随机变量**：独立性从 Ch1 的事件层面（$P(AB) = P(A)P(B)$）自然推广到 Ch3 的随机变量层面（$F(x,y) = F_\xi(x)F_\eta(y)$），并在 Ch5 多维正态中达到顶峰（独立 $\iff$ 不相关）。
- **核心简化**：一旦确认独立，联合分布 = 边缘分布的乘积——这使多维概率计算从二重积分退化为一维积分的乘积。
- **应用**：$n$ 重贝努里试验（独立重复试验）、可靠性系统（串并联）、小概率事件在大量独立重复中几乎必然发生（$1 - (1-p)^k \to 1$）。
