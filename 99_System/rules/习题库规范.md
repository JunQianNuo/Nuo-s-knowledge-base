# 习题库规范

## DeepTutor 题库同步导出（2026-11-14 用户指定）

此节为当前交付要求，覆盖下方旧目录示例中与本节冲突的内容。

### 存放与生成时机

- 每次完成一份作业解析，除原有作业笔记外，同步交付一份 JSON：`03_Sources/Courses/<课程>/作业/题库/<作业笔记同名>.json`。
- 保留原课程、作业、题面与附件的位置；题库目录仅存放对应作业的导入 JSON，不集中搬迁源资料，不为每次导出新建日期目录。
- 每份作业一份文件，不按题目拆成多个 JSON；含多个小问的原大题可作为一条记录。作业解析修订后同步更新同名 JSON，避免题库与笔记内容不一致。
- 不以跨课程合并包代替每份作业文件；用户另行要求合并时再额外生成。已有文件不因本规则自动迁移或删除。

### 官方 JSON 格式

文件采用 UTF-8，顶层必须是题目对象数组。使用官方字段：

| 字段 | 要求 |
|:--|:--|
| `question` | 必填，完整题干，包含独立解题所需的条件、数据与共享记号 |
| `question_type` | 必填；计算题、证明题、推导题使用 `short_answer`；其余按官方支持的题型填写 |
| `correct_answer` | 必填，真实参考答案；不得只写“见上文”“略”或以占位文字代替 |
| `explanation` | 保存提示、完整证明或推导、必要勘误与来源文件/题号；不得冒称教师原话 |
| `tags` | 可选字符串数组，保留有依据的课程、来源或知识标签 |
| `options` | 仅选择题需要；简答题可省略或使用空对象，不虚构选项 |
| `difficulty`、`user_answer` | 可选；缺乏依据时省略或留空，不推断用户已作答或已掌握 |

- 支持题型为 `single_choice`、`multi_choice`、`true_false`、`fill_blank`、`short_answer`。简答与证明按当前官方流程自评，不声称会自动可靠批改数学证明。
- 保留 LaTeX；用 JSON 序列化器正确转义反斜杠和换行，不手工拼接 JSON。将 Obsidian 专用 callout 与 Wiki-link 转为普通文本或可用链接；不得遗留只能在 Vault 内解析的题面依赖。
- 共享定义、教材记号、题面表格、边界条件及必要前题结论应补入对应题干；来源、条件冲突和补全性质按原记录如实说明，不把解析中的额外假设伪装成原题条件。
- 不可靠题面或未完成答案不得塞入正式导入数组；在作业笔记或交付说明中逐条报告缺项及未导出范围。此情况不等于整份作业已完成。

### 验证与交付

- 检查 JSON 可解析、题数与本次完成范围一致、每题有非空题干和参考答案、解析完整，以及必要条件与附件是否可用。
- 当前官方限制为每文件最多 500 题、5 MB，每个文本单元不超过 20,000 字符，标签最多 20 个且每个不超过 100 字符。超过限制时按官方限制分批导入并说明，不能截断题干或解析来凑限额。
- 优先使用匹配版本的官方 `deeptutor/services/practice/importing.py` 中 `preview` 校验；如未实际运行，不声称已通过官方解析器或已在用户实例导入。
- 写入前保留逐文件 diff、SHA-256 与 Vault 外备份；覆盖已有 JSON 前检查并发修改。导出不修改原作业的原子归档 `status`。
- 交付时提供对应 JSON 路径、题数及未导出项。只有用户要求时才写入其 DeepTutor 实例。
- 官方格式参考：[题库导入文档](https://github.com/HKUDS/DeepTutor/blob/main/docs-for-dev/PRACTICE.md)、[官方解析器](https://github.com/HKUDS/DeepTutor/blob/main/deeptutor/services/practice/importing.py)。若项目导入格式发生变化，先核对匹配版本再适配。

## 目录结构

```
课程/{课程名}/习题库/
└── XX-章节名/                  # 按章节分文件夹，命名对齐课件笔记
    ├── README.md               # 章节习题索引（MOC），含依赖关系图
    ├── 习题X.Y.md              # 单道习题，每题一个文件
    └── ...
```

沿用课程实际位置；归档课程使用 `课程/归档/{课程名}/习题库/`。习题保留课程归属，供学习、作业与考试使用。

## 习题文件 Frontmatter

每道习题使用以下 YAML frontmatter：

```yaml
---
title: 习题X.Y - 题目简述
subject: 最优化方法
chapter: 2
section: 章节名
source: 源文件名.jpg
status: OCR转换（已校对）
type: 习题
topics:
  - 知识点1
  - 知识点2
knowledge_tags:
  - 知识点1
  - 知识点2
method_tags:
  - 方法1
  - 方法2
tags:
  - 知识点1
  - 知识点2
  - 方法1
  - 方法2
---
```

`knowledge_tags` 和 `method_tags` 可保留知识与方法的角色区分。内置 `tag:` 搜索的统一入口是 `tags`：实际使用的核心概念和方法，也需按 [[99_System/knowledge/tags/标签库.base|标签数据库]] 中的标准名填入 `tags`；仅填写自定义字段不算完成标签检索入口。历史字段与 `topics` 无需删除或重写。命名规则详见 [[99_System/rules/Obsidian写作规范#Tag]]。

## 习题文件内容结构

每道习题按以下固定顺序组织，各区块间用 `---` 分隔：

1. **题目正文** — 原题陈述（LaTeX 数学公式）
2. **💡 提示** — 使用 `> [!hint]- 点击展开提示` 折叠 callout，引导思路但不直接给出答案
3. **📝 详细解析** — 使用 `> [!solution]- 点击展开详细解析` 折叠 callout，包含完整证明/推导 + 点评
4. **前置习题**（可选）— 若本题依赖其他习题的结论，引用并简述
5. **相关知识点** — Wiki-link 列表，链接回课件笔记对应章节

## Callout 规范

- 提示区块：`> [!hint]- 点击展开提示`（默认折叠）
- 解析区块：`> [!solution]- 点击展开详细解析`（默认折叠）
- 解析中需包含：
  - 完整证明/推导过程
  - 关键步骤的 LaTeX 公式
  - `\square` 结束标记
  - 一段「**答案**：」汇总行（格式：`**答案**：(1) $...$；(2) $...$`），在点评之前
  - 一段「点评」，关联前后章节或点明深层含义
- 反例/注意事项使用 `> [!warning]` 或文字说明
 
## 流程图规则

**判据**：解答涉及 ≥ 3 个计算步骤或含分支判断的习题 → 必须在解析 callout 开头添加 Mermaid 流程图。

**格式**：
```
> [!solution]- 点击展开详细解析
> **流程图**：
> ```mermaid
> flowchart TD
>   A[步骤1] --> B[步骤2]
>   B --> C{判断}
>   C -->|是| D[步骤3a]
>   C -->|否| E[步骤3b]
> ```
>
> **解**：...
```

**注意事项**：节点标签用中文简述，避免 `()` `{}` `[]` `|` 等 Mermaid 特殊字符（或用 `"..."` 包裹）。

## 章节 README（MOC）

每个章节习题文件夹必须包含 `README.md`，内容：

```yaml
---
title: 第X章 习题库 - 章节名
subject: 最优化方法
chapter: X
type: MOC
---
```

正文包含：
- 链接回课件笔记
- 作业范围说明
- 习题列表表格（题号 | 题目 | 知识点 | 状态）
- 依赖关系 Mermaid 流程图（标注已录入/未录入的依赖）

## 习题录入流程

```
习题图片/PDF → Tesseract OCR（chi_sim+eng, --psm 4）→ 文本清理校对 → 
按作业范围筛选 → 写入 .md 文件 → 添加提示与解析 → 更新 README → 回链课件笔记 →
删除未处理项中的原始文件
```

## 未处理项清理规则

- **处理完毕即删除**：`未处理项/` 中的文件在完成处理后必须删除，不保留原始图片/PDF
- 习题内容已固化到 `习题库/` 的 `.md` 文件中，无需保留 OCR 源文件
- OCR 临时产物（tessdata/、.txt）一并清理
- **`未处理项/` 目录本身保留**，不删除（即使为空）

## OCR 注意事项

- OCR 输出必须人工校对，修正公式识别错误
- 对分块矩阵、行列式等复杂排版，需结合原图确认
- 临时 tessdata 目录和 OCR 输出 txt 文件处理后应清理
- **原始图片/PDF 处理完毕后从 `未处理项/` 删除**，不留备份

## 回链约定

- 习题文件中通过 Wiki-link 链接到课件笔记：`[[02-向量空间与矩阵#2.5 矩阵的秩|矩阵的秩]]`
- 课件笔记的「作业」部分需添加反向链接指向习题库
- 习题间的依赖通过 `[[习题X.Y]]` 互链
- 实际用到的共享条目可链接为 `[[概念/名称]]`、`[[知识点/名称]]`、`[[方法/名称]]`；共享条目直接位于根目录，不按课程复制。
- 习题与共享条目的关联以实际应用为准，不反向要求每个共享条目都必须配习题。
