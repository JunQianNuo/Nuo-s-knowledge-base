# 闪卡规范

> 本规范适用于基于 Yanki 插件的闪卡制作与维护。Yanki 语法为纯 Markdown，不需任何特殊标记。

---

## 一、文件夹结构

```
闪卡/
└── 课程名/                    # 课程
    └── 章节名/                # 章节
        ├── 子章节/            # (可选) 可继续嵌套
        │   ├── 01-卡片名.md
        │   └── ...
        └── 01-卡片名.md
```

**规则：**

| 规则 | 说明 |
|------|------|
| **每门课一个文件夹** | 课程名作为一级子文件夹 |
| **每章一个子文件夹** | 章节名作为二级子文件夹 |
| **章节后可继续嵌套** | 根据内容需要可建更深子文件夹 |
| **一文件一卡片** | 每个 `.md` 文件对应一张 Anki 卡片 |

牌组自动映射: `闪卡/课程名/章节名/子章节/` → Anki 牌组 `课程名::章节名::子章节`

---

## 二、文件命名

```
NN-简明描述.md
```

| 规范 | 示例 |
|------|------|
| 数字前缀 | `01-` `02-` ... 确保有序 |
| 中文描述 | 简洁概括卡片内容 |
| 不含特殊字符 | 避免 `: / \ ? *` |

示例:
```
01-收敛阶-定义.md
05-梯度-锯齿现象.md
14-CG-Q共轭定义.md
35-实践决定认识.md
```

## 三、卡片语法

### 3.1 基础问答

```markdown
问题的正面内容

---

答案的背面内容。支持 Markdown 格式。
```

- `---` 必须**独占一行**，前后各一个空行
- 正面和背面都支持完整 Markdown（表格、列表、加粗等）
- LaTeX 公式用 `$...$` 或 `$$...$$` 包裹，Yanki 同步后 Anki 自动渲染

### 3.2 填空 (Cloze)

**Cloze 卡片是纯文本，没有 `---` 分隔符。** 同步脚本自动识别：不含 `---` 且含 `~~` 的卡片 → Cloze。

```markdown
最速下降法的精确步长是 ~~$\alpha_k = \frac{g_k^T g_k}{g_k^T Q g_k}$~~。
```

- `~~...~~` 内的内容被隐藏，复习时需回忆
- 支持多空：`~~空1~~` `~~空2~~`（同一张卡上的多个填空同时显示）
- **LaTeX 公式**：用 `~~$formula$~~`（cloze 包裹 `$...$`）。脚本自动转换 `$...$` → `\(...\)`（Anki cloze 内仅 `\(...\)` 可用），并插入零宽空格防止 `}}` 被误解析
- 同步时使用 Anki 内置 **填空题** 模型
- 文件内**不能有 `---`**，否则会被识别为基础问答卡

### 3.3 反向卡片

```markdown
正面

---

---

背面

---

额外内容（两张卡片都显示）
```

双 `---` → `---` 生成双向卡片。

### 3.4 禁止混用

> [!warning]
> 一个文件只能是一种卡片类型。不要把基础问答和填空混在一个文件里。

## 四、制作流程

```
源笔记（课程/xxx/复习/）→ 提取关键事实 → 写卡片 → Sync → 暂停占位卡
```

### 4.1 提取原则

1. **一卡一事** — 每张卡片只测试一个知识点
2. **10 秒可答** — 单张卡片阅读+回答不超过 10 秒
3. **脱离上下文** — 卡片本身包含足够信息，不需要翻看原文
4. **概念辨析优先** — 易混淆概念对用对比表格放在背面

### 4.2 卡片模板

**概念辨析类:**
```markdown
概念A 与 概念B 的核心区别？

---

| 维度 | 概念A | 概念B |
|------|-------|-------|
| 维度1 | ... | ... |

判断关键: ...
```

**定义类:**
```markdown
XXX 的定义 / 本质 / 特征？

---

核心回答 + 关键点列表
```

**原理类:**
```markdown
XXX 原理的内容 / 关系 / 意义？

---

简要概述 + 记忆口诀（如有）
```

## 五、同步与维护

### 5.1 同步流程

1. 打开 Anki 桌面端（AnkiConnect 运行中）
2. 终端运行：
```bash
cd "D:\知识库"
python scripts/sync_flashcards.py
```
3. 脚本自动：扫描 → MD转HTML → 创建/更新/删除 → 完成

### 5.2 修改卡片

直接编辑 `.md` 文件 → 运行脚本 → 自动检测变更并更新，**不丢失复习进度**。

### 5.3 删除卡片

删掉 `.md` 文件 → 运行脚本 → 自动删除 Anki 中对应卡片。

### 5.4 新增章节

```bash
mkdir -p 闪卡/课程名/新章节名
# 放入卡片文件
# → 运行 sync_flashcards.py
# → 自动创建新牌组
```
