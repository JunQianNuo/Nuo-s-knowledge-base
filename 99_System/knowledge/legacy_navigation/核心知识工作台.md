# 核心知识工作台

这里按知识职责和学习问题导航，目录位置保留历史存储方式。例如概念目录中的 KKT 条件可以是 proposition，知识点目录中的协方差可以是 concept。三类并列，不要求每个主题都有三类卡片。

## 从问题选择路线

- **积分与极限为什么能交换？** 从 [[01_Knowledge/可测集]]、[[01_Knowledge/可测函数]] 进入 [[01_Knowledge/Lebesgue积分]]，再沿 [[02_Maps/MOC-收敛性与积分理论]] 比较条件并选择方法。
- **概率如何成为分析中的积分？** [[01_Knowledge/概率空间]] → [[01_Knowledge/随机变量]] → [[01_Knowledge/数学期望]] → [[01_Knowledge/全数学期望公式]] → [[01_Knowledge/全期望公式法]]。结合 [[01_Knowledge/Lebesgue积分]] 看概率测度下的统一表达。
- **数值答案为什么可能不可靠？** [[01_Knowledge/误差]] → [[01_Knowledge/范数]] → [[01_Knowledge/条件数]] → [[01_Knowledge/数值稳定性]]，再进入 [[01_Knowledge/条件数误差分析流程]]；区分问题病态与算法不稳定。
- **迭代为什么会收敛？** [[01_Knowledge/不动点]] → [[01_Knowledge/收敛阶定理]]、[[01_Knowledge/迭代收敛定理(谱半径)]] → [[00_Inbox/待核实核心/方法/不动点迭代判敛流程]]、[[00_Inbox/待核实核心/方法/迭代法收敛性判断流程]]。非线性求根与矩阵迭代的假设分别检查。
- **优化中怎样选择一步？** [[01_Knowledge/下降方向]] → [[01_Knowledge/线搜索]] → [[01_Knowledge/Armijo准则]] → [[01_Knowledge/回溯线搜索]]；有约束时另外阅读 [[01_Knowledge/凸集]]、[[01_Knowledge/凸函数]]、[[01_Knowledge/KKT条件]]。
- **怎样跨主题比较同一种结构？** 继续阅读 [[总览/跨主题联系-MOC]] 中的加权平均、正交投影、变换及离散化路线。

这些箭头是阅读顺序，不自动声明数学蕴含或每一项都是严格先修。正式先修、讨论对象和调用关系见属性；性质与证明正确性仍以原文、来源和人工核查为准。
