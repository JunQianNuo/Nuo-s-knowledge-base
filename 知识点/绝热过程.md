# 绝热过程

## 一句话

绝热过程（$Q=0$）中，气体不需要外界热量也能改变温度和体积——做功完全靠消耗自身内能，过程方程 $pV^\gamma = C$ 要求整个过程是准静态的。

## 严格定义

绝热过程：$dQ = 0$。对理想气体**准静态**绝热过程：

**过程方程**（三种等价形式）：

$$
\boxed{pV^\gamma = \text{常数}} \qquad \boxed{TV^{\gamma-1} = \text{常数}} \qquad \boxed{p^{\gamma-1}T^{-\gamma} = \text{常数}}
$$

其中 $\gamma = C_p/C_V = (i+2)/i$。

**功**（两种等价计算方式）：

$$
\boxed{A = -\Delta E = -\nu C_V (T_2 - T_1) = \frac{p_1 V_1 - p_2 V_2}{\gamma - 1}}
$$

> [!important] 绝热自由膨胀（非准静态）$\neq$ 准静态绝热过程
> 气体向真空膨胀：$Q=0$，$A=0$（真空无阻力）$\Rightarrow \Delta E = 0 \Rightarrow T$ 不变（理想气体）。
> **不能用 $pV^\gamma = C$**，因为中间态不是平衡态！

## 推导：绝热过程方程

> [!proof]- 推导
> 由热力学第一定律 $dQ = dE + p\, dV$，绝热：$dQ = 0$：
> $$\nu C_V \, dT + p\, dV = 0 \quad\text{①}$$
>
> 状态方程 $pV = \nu RT$ 微分：$p\, dV + V\, dp = \nu R\, dT \quad\text{②}$
>
> 由①得 $\nu\, dT = -\frac{p}{C_V}\, dV$，代入②：
> $$p\, dV + V\, dp = -\frac{R}{C_V} p\, dV$$
> $$V\, dp = -\left(1 + \frac{R}{C_V}\right) p\, dV = -\frac{C_p}{C_V} p\, dV = -\gamma\, p\, dV$$
> $$\frac{dp}{p} + \gamma \frac{dV}{V} = 0$$
>
> 积分：$\ln p + \gamma \ln V = C \Rightarrow pV^\gamma = C$。
>
> 用 $pV = \nu RT$ 消去 $p$ 或 $V$ 可得另外两种等价形式。
>
> 核心洞察：$\gamma > 1$ 使绝热线比等温线更陡——绝热膨胀时压强下降来自"体积增大"+"温度降低"双重因素。

## 关键性质

| 对比项 | 等温线 | 绝热线 |
|--------|--------|--------|
| 过程方程 | $pV = C$ | $pV^\gamma = C$ |
| 斜率 $\frac{dp}{dV}$ | $-\dfrac{p}{V}$ | $-\gamma \dfrac{p}{V}$ |
| 陡峭程度 | 较平缓 | **更陡峭**（$\gamma > 1$） |
| 物理原因 | 体积 $\uparrow$ → $p \downarrow$ | 体积 $\uparrow$ + $T \downarrow$ → $p \downarrow\downarrow$ |

| 绝热线用法 | 判断方式 |
|-----------|---------|
| p-V 图上判断吸热/放热 | 比较过程曲线与过同一点的绝热线：在绝热线**上方**→吸热，**下方**→放热 |

## 典型例题

> **题目**（习题8-7）：一绝热容器，中间用隔板分开，一侧充有理想气体（$p_1, V_1, T_1$），另一侧为真空。抽去隔板，气体绝热自由膨胀至整个容器。求终态温度、压强。

> [!example]- 解答
> 绝热自由膨胀 $Q=0$，向真空膨胀 $A=0$（无外界阻力）→ $\Delta E = 0$。
>
> 理想气体 $\Delta E = \nu C_V \Delta T = 0 \Rightarrow T_2 = T_1$（温度不变）。
>
> 终态体积 $V_2$（容器总体积），由 $p_1V_1 = p_2V_2$（等温）：$p_2 = p_1 \cdot V_1/V_2$。
>
> 重要：**不能用 $pV^\gamma = C$**（非准静态过程）。
>
> 点评：绝热自由膨胀是最容易出错的过程——$Q=0$ 但 $T$ 不变，因为没做功。

> **题目**（习题8-9）：1 mol 氮气（$C_V = 20.8\text{ J/(mol·K)}$）从状态 $(p_1, V_1, T_1 = 300\text{ K})$ 分别经（a）等温、（b）等压、（c）绝热三种过程压缩到原体积的一半 $V_2 = V_1/2$。求各过程的终态温度、做功和吸热。

> [!example]- 解答
> 氮气 $M_{mol}=28\text{ g/mol}$，刚性双原子 $i=5$，$C_V \approx 20.8\text{ J/(mol·K)}$。
>
> （a）等温压缩 $V_2 = V_1/2$：$T_2 = T_1 = 300\text{ K}$，$A = RT\ln(V_2/V_1) = 8.31 \times 300 \times \ln\frac{1}{2} \approx -1729\text{ J}$，外界对气体做正功。$Q = A < 0$（放热）。
>
> （b）等压压缩 $V_2 = V_1/2$：$T_2 = T_1 \cdot V_2/V_1 = 150\text{ K}$。$A = p(V_2-V_1) = -p_1 V_1/2 = -RT_1/2 = -1247\text{ J}$。$\Delta E = C_V \Delta T \approx -3120\text{ J}$。$Q = \Delta E + A \approx -4367\text{ J}$（放热最多）。
>
> （c）绝热压缩 $V_2 = V_1/2$：$\gamma = 7/5 = 1.4$。$T_2 = T_1(V_1/V_2)^{\gamma-1} = 300 \times 2^{0.4} \approx 396\text{ K}$。$A = -\Delta E = -C_V(T_2-T_1) \approx -20.8 \times 96 \approx -1997\text{ J}$。$Q = 0$。
>
> 点评：相同压缩比下——等温压缩时压强最小（做功最少），绝热压缩温度升高（不做功但压强最大），等压压缩放热最多。p-V 图上看压力线高低来判断。

## 易错点

> [!warning] 易错点
> 1. **绝热自由膨胀 $\neq$ 准静态绝热过程**：绝热自由膨胀不能用 $pV^\gamma = C$，$\Delta E = 0$，$T$ 不变
> 2. **绝热线比等温线更陡**：膨胀时，压强下降有两个来源（$V\uparrow$ + $T\downarrow$）；压缩时压强上升也更快
> 3. **绝热过程 $dQ=0$ 但 $dT \neq 0$**：温度变化来自 $dE = -dA$，膨胀降温、压缩升温
> 4. **绝热过程的功有两种算法**：$A = -\nu C_V \Delta T$ 或 $A = (p_1V_1 - p_2V_2)/(\gamma-1)$，两者等价
