# 二维正态分布

## 一句话

二维正态分布 $N(m_1, \sigma_1^2; m_2, \sigma_2^2; r)$ 由五个参数完全刻画，其最独特的性质是**不相关 $\iff$ 独立**（$r = 0$ 等价于两个分量独立）——这是一般分布不具备的考试必考结论。

## 严格定义

**五个参数**：$m_1 = E(\xi)$，$m_2 = E(\eta)$，$\sigma_1^2 = D(\xi)$，$\sigma_2^2 = D(\eta)$，$r = \rho_{\xi\eta}$（相关系数，$|r| < 1$）。

**联合密度**：
$$f(x,y) = \frac{1}{2\pi\sigma_1\sigma_2\sqrt{1-r^2}} \exp\left\{-\frac{1}{2(1-r^2)}\left[\frac{(x-m_1)^2}{\sigma_1^2} - 2r\frac{(x-m_1)(y-m_2)}{\sigma_1\sigma_2} + \frac{(y-m_2)^2}{\sigma_2^2}\right]\right\}$$

**矩阵形式**：$M = \begin{bmatrix} m_1 \\ m_2 \end{bmatrix}$，$\Sigma = \begin{bmatrix} \sigma_1^2 & r\sigma_1\sigma_2 \\ r\sigma_1\sigma_2 & \sigma_2^2 \end{bmatrix}$，则 $(\xi, \eta) \sim N(M, \Sigma)$。

**特征函数**：
$$\boxed{\varphi(t_1, t_2) = e^{j(m_1 t_1 + m_2 t_2) - \frac{1}{2}(\sigma_1^2 t_1^2 + 2r\sigma_1\sigma_2 t_1 t_2 + \sigma_2^2 t_2^2)}}$$

> [!important] 核心判定：不相关 $\iff$ 独立
> $r = 0 \iff \Sigma \text{ 为对角阵} \iff \varphi(t_1, t_2) = \varphi_{\xi_1}(t_1) \cdot \varphi_{\xi_2}(t_2) \iff \xi \text{ 与 } \eta \text{ 相互独立}$。
>
> 原因：当 $r = 0$ 时，特征函数中交叉项 $2r\sigma_1\sigma_2 t_1 t_2$ 消失，自然分解为两个边缘特征函数的乘积。由唯一性定理，特征函数分解 $\iff$ 独立。
>
> **警告**：此等价性**仅对联合正态分布成立**。对于非正态分布，独立必不相关，但不相关不能推出独立。

## 推导：条件分布

> [!proof]- 推导
> 在 $\xi = x$ 的条件下，$\eta \sim N\left(m_2 + r\frac{\sigma_2}{\sigma_1}(x-m_1),\; \sigma_2^2(1-r^2)\right)$。特别地，条件期望是一条直线：$E(\eta|\xi=x) = m_2 + r\frac{\sigma_2}{\sigma_1}(x-m_1)$，条件方差与 $x$ 无关：$D(\eta|\xi=x) = \sigma_2^2(1-r^2)$。$|r|$ 越接近 1，条件方差越小，$\xi$ 对 $\eta$ 的预测越精确。

## 关键性质

| 性质 | 内容 |
|:--|:--|
| 边际分布 | $\xi \sim N(m_1, \sigma_1^2)$，$\eta \sim N(m_2, \sigma_2^2)$ |
| 数字特征 | $Cov(\xi, \eta) = r\sigma_1\sigma_2$，$\rho_{\xi\eta} = r$ |
| 独立等价条件 | $r = 0$（$r = 0 \iff$ 独立，这是正态独有的） |
| 线性变换 | 正态向量的线性变换仍是正态：$C\xi \sim N(CM, C\Sigma C^T)$ |
| 条件分布 | 给定一个分量，另一个分量也是正态 |
| 子向量正态性 | 任意 $m$ 维子向量 $(\xi_{k_1},\ldots,\xi_{k_m})$ 仍服从正态分布 |

**$n$ 维推广**：所有二维正态的结论均自然推广到 $n$ 维——联合正态由 $M$（均值向量）和 $\Sigma$（协方差矩阵）完全确定；特征函数 $\varphi(t) = \exp\{jM^T t - \frac{1}{2}t^T\Sigma t\}$；当 $|\Sigma|=0$ 时为退化（奇异）正态分布，无密度但特征函数仍有效。

## 从二次型反推参数（考试要诀）

给定密度 $f(x,y) = C \cdot \exp\{-Q(x,y)/2\}$，不需配方法，三步读出五参数：

**① 求 $\mu_1, \mu_2$**：解 $Q$ 的偏导 = 0 得驻点——这就是均值向量。

**② 取 $Q$ 的二次齐次部分**，写成矩阵形式——这就是 $\Sigma^{-1}$ 乘常数：

$$Q(x,y) = ax^2 + 2bxy + cy^2 - \cdots \quad\Rightarrow\quad \begin{bmatrix}a & b \\ b & c\end{bmatrix} = \Sigma^{-1}$$

**③ 求逆得 $\Sigma$**，直接读数：

$$\Sigma = \begin{bmatrix} \sigma_1^2 & \rho\sigma_1\sigma_2 \\ \rho\sigma_1\sigma_2 & \sigma_2^2 \end{bmatrix}$$

加上 $C = 1/(2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}) = 1/(2\pi\sqrt{\det\Sigma})$ 作为交叉验证。

> [!example]- 示例（习题3.13）
> $Q = 2x^2 + y^2 + 2xy - 22x - 14y + 65$。偏导 → $\mu_1=4, \mu_2=3$。二次项矩阵 $\begin{bmatrix}2&1\\1&1\end{bmatrix} = \Sigma^{-1}$ → $\Sigma = \begin{bmatrix}1&-1\\-1&2\end{bmatrix}$ → $\sigma_1=1,\sigma_2=\sqrt{2},\rho=-1/\sqrt{2}$。30 秒出完，不碰配方。

## 典型例题

> **题目**：若 $(\xi, \eta) \sim N(0, 1; 0, 1; \rho)$，求 $E(\eta|\xi=x)$，并说明 $\rho=0$ 时的特殊性质。

> [!example]- 解答
> 由条件分布性质：$E(\eta|\xi=x) = \rho x$。
>
> 当 $\rho = 0$ 时：$E(\eta|\xi=x) = 0 = E(\eta)$——条件期望退化为无条件期望，$\xi$ 不提供任何关于 $\eta$ 的信息。同时特征函数分解为 $\varphi(t_1,t_2) = e^{-t_1^2/2} \cdot e^{-t_2^2/2}$，故 $\xi$ 与 $\eta$ 独立。
>
> **点评**：条件期望 $E(\eta|\xi=x) = \rho x$ 是一条过原点的直线——$|\rho|$ 越大，$\xi$ 的取值对 $\eta$ 的预测越"陡峭"；$\rho = 0$ 时直线是平的，知道 $\xi$ 完全没用。

## 易错点

> [!warning] 易错点
> 1. **"不相关 $\iff$ 独立"仅对联合正态成立**：不能推广到一般分布。这是考试中最常考的区分点。
> 2. **边际正态 $\neq$ 联合正态**：两个边际都是正态，联合不一定正态。反例：$\xi \sim N(0,1)$，$\eta = \xi \cdot \text{sgn}(U)$ 可构造边际正态但联合非正态。
> 3. **$r$ 不独立时不等于 $\rho$**：在二维正态中，参数 $r$ **就是**相关系数 $\rho$——这是二维正态的特殊性。
