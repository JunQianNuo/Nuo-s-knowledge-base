# 概率密度函数

## 一句话

概率密度 $f(x)$ 与分布函数 $F(x)$ 互为微积分对偶——$F(x) = \int_{-\infty}^x f(t)dt$（累积面积），$f(x) = F'(x)$（概率增长率）；这一关系是连续型随机变量所有概率计算的基础。

## 严格定义

**定义**：若存在非负可积函数 $f(x) \geq 0$，使得对任意 $a < b$，有

$$P\{a < \xi \leq b\} = \int_a^b f(x) \, dx$$

则称 $\xi$ 为连续型随机变量，$f(x)$ 为概率密度函数。

**密度函数的两个充要条件**：

$$
\boxed{(1)\; f(x) \geq 0, \quad \forall x \in \mathbb{R}} \qquad \boxed{(2)\; \int_{-\infty}^{+\infty} f(x) \, dx = 1}
$$

**密度 ↔ 分布函数**：

$$
\boxed{F(x) = \int_{-\infty}^x f(t) \, dt} \qquad \boxed{f(x) = F'(x) \;(\text{在 } f \text{ 的连续点})}
$$

> [!important] 关键点
> - $f(x)$ 本身不是概率——它是概率的"密度"，只有乘以 $dx$（微小区间长度）后才得到概率 $\approx f(x)dx$。
> - 验证一个函数是否为合法密度：只需检查 (1) 非负 + (2) 全空间积分为 1。
> - 连续型下单点概率为零：$P\{\xi = x_0\} = 0$，所以端点是否包含在区间内不影响概率值。

## 推导：密度函数的极限含义

> [!proof]- 推导
> 在 $f$ 的连续点 $x$ 处：
> $$f(x) = \lim_{\Delta x \to 0^+} \frac{P\{x < \xi \leq x + \Delta x\}}{\Delta x} = \lim_{\Delta x \to 0^+} \frac{F(x+\Delta x) - F(x)}{\Delta x} = F'(x)$$
> 这个极限形式揭示了"密度"的字面含义——单位长度上的概率量，类比于物理中的线密度。

## 算法/关键性质

**常见操作**：

| 操作 | 方法 |
|:--|:--|
| 验证密度合法性 | 检查 $f(x) \geq 0$ + $\int_{-\infty}^{\infty} f(x)dx = 1$ |
| 已知 $f(x)$ 求 $F(x)$ | $F(x) = \int_{-\infty}^x f(t)dt$（分段积分） |
| 已知 $F(x)$ 求 $f(x)$ | $f(x) = F'(x)$（在 $F$ 可导点，分段点单独处理） |
| 求区间概率 | $P\{a < \xi < b\} = \int_a^b f(x)dx = F(b) - F(a)$ |
| 求 $P\{\xi > x\}$ | $1 - F(x)$ 或 $\int_x^\infty f(t)dt$ |
| 判断变量独立性 | $f(x,y) = f_\xi(x) \cdot f_\eta(y)$（在非零区域几乎处处成立） |

**离散 vs 连续关键对比**：

| | 离散型 | 连续型 |
|:--|:--|:--|
| 核心描述 | 分布律 $p_n = P\{\xi=x_n\}$ | 密度 $f(x)$ |
| 单点概率 | $P\{\xi=x_n\} = p_n > 0$ | $P\{\xi=x_0\} = 0$ |
| $F(x)$ 形态 | 阶梯函数（跳跃） | 连续函数（光滑/分段光滑） |
| 总概率 | $\sum p_n = 1$ | $\int f(x)dx = 1$ |

## 典型例题

> **题目**：设随机变量 $\xi$ 的密度为 $f(x) = \begin{cases} kx, & 0 < x < 2 \\ 0, & \text{其他} \end{cases}$，求 (1) 常数 $k$；(2) $F(x)$；(3) $P\{0.5 < \xi < 1.5\}$。

> [!example]- 解答
> **(1)** 由规范性：$\int_0^2 kx \, dx = k \cdot \frac{x^2}{2}\big|_0^2 = 2k = 1$，故 $k = \frac{1}{2}$。
>
> **(2)** 分段积分：
> - $x < 0$：$F(x) = 0$
> - $0 \leq x < 2$：$F(x) = \int_0^x \frac{1}{2}t \, dt = \frac{x^2}{4}$
> - $x \geq 2$：$F(x) = 1$
>
> **(3)** $P\{0.5 < \xi < 1.5\} = F(1.5) - F(0.5) = \frac{2.25}{4} - \frac{0.25}{4} = 0.5$。
>
> 或用密度积分：$\int_{0.5}^{1.5} \frac{1}{2}x \, dx = 0.5$。
>
> **点评**：$k$ 的确定用"总概率为 1"（规范性），这是最常见的求参数方法。验证 $F(0)=0$、$F(2)=1$、$F$ 连续且单调不减，确认结果正确。

## 易错点

> [!warning] 易错点
> 1. **$f(x)$ 可以大于 1**：如 $U(0, 0.5)$ 上 $f(x) = 2$。$f(x)$ 本身不是概率，乘以 $dx$ 后才是。
> 2. **密度函数不唯一**：改变 $f$ 在有限个点上的值不影响积分和概率——但通常约定在连续点取 $F'(x)$。
> 3. **$F(x)$ 连续但未必处处可导**：如均匀分布在 $x=a$ 和 $x=b$ 处 $F$ 不可导，$f$ 在这些分段点处的值可任意定义。
> 4. **开区间和闭区间概率相同**：因为端点概率是 0——这是连续型独有的便利。
> 5. **验证密度必须检查非负性**：有些函数积分为 1 但不恒非负（如 $f(x) = 2x$ 在 $[-1,1]$ 上有负值）——不是合法密度。
