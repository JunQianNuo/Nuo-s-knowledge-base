# 相关系数

## 一句话

相关系数 $\rho$ 是"标准化后的协方差"——消去量纲后落在 $[-1,1]$，$|\rho|$ 越近 1 线性关系越强，$\rho=0$ 表示不相关（无线性关系）；在二维正态下，$\rho=0 \iff$ 独立。

## 严格定义

设 $D(\xi)>0$，$D(\eta)>0$，称
$$\boxed{\rho_{\xi\eta} = \frac{Cov(\xi,\eta)}{\sqrt{D(\xi)}\sqrt{D(\eta)}} = E[\xi^*\eta^*]}$$
其中 $\xi^* = \frac{\xi-E(\xi)}{\sqrt{D(\xi)}}$ 是标准化随机变量。

**三条核心性质**：
1. **有界性**：$|\rho| \leq 1$
2. **极端值**：$|\rho| = 1 \iff \xi$ 与 $\eta$ 以概率 1 线性相关（$\exists \alpha \neq 0$ 使 $P\{\eta = \alpha\xi + \beta\} = 1$）
3. **线性变换不变性**：$|\rho_{a\xi+b,\, c\eta+d}| = |\rho_{\xi\eta}|$，符号取决于 $ac$ 的正负

**三种情形**：

| $\rho$ | 含义 |
|:--|:--|
| $\rho = 1$ | 完全正相关 |
| $\rho = -1$ | 完全负相关 |
| $\rho = 0$ | 不相关（无线性关系，但可能有非线性关系） |

> [!important] 关键点
> - **独立 $\Rightarrow$ 不相关（$\rho=0$），但逆一般不真。**
> - **二维正态特例（考试必考）**：若 $(\xi,\eta)$ 服从二维正态，则 $r = \rho$，且 $\rho = 0 \iff \xi$ 与 $\eta$ 相互独立。
> - 相关系数只度量**线性**关联——$\eta = \xi^2$ 且 $\xi \sim N(0,1)$ 时 $\rho=0$，但两者有严格的非线性函数关系。

## 推导：$|\rho| \leq 1$ 与极端值含义

> [!proof]- 推导
> 利用标准化变量 $\xi^*, \eta^*$（$E=0, D=1$）：
> $$0 \leq D(\xi^* \pm \eta^*) = D(\xi^*) + D(\eta^*) \pm 2Cov(\xi^*, \eta^*) = 2 \pm 2\rho = 2(1 \pm \rho)$$
> 故 $1 \pm \rho \geq 0$，即 $|\rho| \leq 1$。
>
> 当 $\rho = -1$：$D(\xi^* + \eta^*) = 0 \;\Rightarrow\; P\{\xi^* + \eta^* = 0\} = 1$，展开得线性关系。$\rho = 1$ 同理（$D(\xi^* - \eta^*) = 0$）。
>
> 关键技巧：方差的非负性 $+$ 方差零值 $\iff$ 几乎处处为常数。

## 关键性质

**独立与不相关的关系**：

| 命题 | 成立？ | 条件 |
|:--|:--|:--|
| 独立 $\Rightarrow \rho = 0$ | ✅ | 无条件 |
| $\rho = 0 \Rightarrow$ 独立 | ❌ | 一般分布（反例：圆内均匀） |
| $\rho = 0 \iff$ 独立 | ✅ | 二维正态分布 |
| $\rho = 0 \Rightarrow$ 无线性关系 | ✅ | 但可能有非线性关系 |

**线性变换下相关系数的行为**：
$$\rho_{a\xi+b,\, c\eta+d} = \text{sgn}(ac) \cdot \rho_{\xi\eta}$$
常数项 $b,d$ 不影响，$\pm$ 号取决于 $a$ 与 $c$ 是否同号。

## 典型例题

> **题目**（不相关但不独立）：$(\xi, \eta)$ 在单位圆 $x^2+y^2 \leq 1$ 内服从均匀分布。求 $\rho_{\xi\eta}$，并判断独立性。

> [!example]- 解答
> $f(x,y) = \frac{1}{\pi}$。由对称性 $E(\xi)=E(\eta)=0$。
> $$Cov(\xi,\eta) = E(\xi\eta) = \iint_D \frac{xy}{\pi} dxdy = 0 \;\Rightarrow\; \rho = 0$$
>
> 但 $\xi$ 与 $\eta$ **不独立**：$|\eta| \leq \sqrt{1-\xi^2}$，$\xi$ 的取值限制了 $\eta$ 的范围。
>
> **点评**：圆内均匀分布是"不相关但不独立"的经典反例。考试中常与二维正态（不相关即独立）配对考查。

---

> **题目**（线性变换下 $\rho$ 不变）：已知 $\rho_{\xi\eta} = 0.5$，求 $U = 2\xi + 1$ 与 $V = -3\eta + 2$ 的相关系数。

> [!example]- 解答
> $$\rho_{UV} = \frac{Cov(2\xi+1, -3\eta+2)}{\sqrt{D(2\xi+1)}\sqrt{D(-3\eta+2)}} = \frac{-6\,Cov(\xi,\eta)}{2\sqrt{D(\xi)} \cdot 3\sqrt{D(\eta)}} = -\rho_{\xi\eta} = -0.5$$
>
> **点评**：$|\rho|$ 不变（始终 0.5），符号取决于系数乘积 $ac$ 的正负——这里 $2 \times (-3) < 0$，故反号。常数项 $+1,+2$ 对相关系数无任何影响。

## 易错点

> [!warning] 易错点
> 1. **$\rho = 0 \nRightarrow$ 独立**：圆内均匀分布是标准反例。只有联合正态下两者等价。
> 2. **相关系数只度量线性关系**：$\eta = \xi^2$ 且 $\xi \sim N(0,1)$ 时 $\rho = 0$，但存在严格的非线性函数关系。
> 3. **$|\rho| = 1$ 是"以概率 1"线性相关**：允许零测集上偏离直线，不是确定性的函数关系。
> 4. **线性变换下 $|\rho|$ 不变，但符号可变**：$\rho_{a\xi+b, c\eta+d} = \text{sgn}(ac) \cdot \rho_{\xi\eta}$——系数同号则同号，异号则反号。
