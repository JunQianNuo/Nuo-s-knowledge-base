# 一维无限深势阱

## 一句话

粒子被关在"无限深"的盒子里，能量只能取离散值 $E_n \propto n^{2}$——最低能量 > 0（零点能），粒子永远不能"完全静止"。

## 严格定义

**模型**：质量为 $m$ 的粒子在 $0 < x < a$ 内自由（$U = 0$），阱外势能无穷大：

$$
U(x) = \begin{cases} 0 & 0 < x < a \\ \infty & x \leq 0,\ x \geq a \end{cases}
$$

**能级**（由定态薛定谔方程 + 边界条件解得）：

$$
\boxed{E_n = n^{2} \frac{\hbar^{2}\pi^{2}}{2ma^{2}}}, \quad n = 1, 2, 3, \ldots
$$

**波函数**（归一化的定态解）：

$$
\boxed{\psi_n(x) = \sqrt{\frac{2}{a}} \sin\left(\frac{n\pi}{a}x\right)}, \quad 0 < x < a
$$

**概率密度**：

$$
|\psi_n(x)|^{2} = \frac{2}{a} \sin^{2}\left(\frac{n\pi}{a}x\right)
$$

> [!important] 零点能
> 最低能级（$n=1$）：$\displaystyle E_1 = \frac{\hbar^{2}\pi^{2}}{2ma^{2}} > 0$。经典粒子被关在盒子里可以静止（$E_{\min} = 0$），量子粒子却**不能**——这与不确定关系一致（$\Delta x \sim a$ → $\Delta p > 0$ → $E > 0$）。

## 推导：从薛定谔方程到能级

> [!proof]- 推导
> 阱内 $U = 0$，定态薛定谔方程：
> $$-\frac{\hbar^{2}}{2m} \frac{d^{2}\psi}{dx^{2}} = E\psi$$
>
> 令 $k = \sqrt{2mE}/\hbar$，通解：$\psi(x) = A\sin(kx) + B\cos(kx)$
>
> **边界条件**（阱无限深 → 波函数在阱外为零，由连续性在边界处也为零）：
> - $\psi(0) = 0$ → $B = 0$
> - $\psi(a) = 0$ → $A\sin(ka) = 0$ → $ka = n\pi$，$n = 1, 2, \ldots$
>
> $$\Rightarrow k_n = \frac{n\pi}{a}, \quad E_n = \frac{\hbar^{2}k_n^{2}}{2m} = n^{2}\frac{\hbar^{2}\pi^{2}}{2ma^{2}}$$
>
> **归一化**：$A^{2}\int_{0}^{a} \sin^{2}(n\pi x/a) dx = A^{2} \cdot a/2 = 1$ → $A = \sqrt{2/a}$
> $$\psi_n(x) = \sqrt{\frac{2}{a}} \sin\left(\frac{n\pi}{a}x\right)$$
>
> 关键洞察：能量量子化来自**边界条件** $ka = n\pi$——只有满足整数个半波长的驻波才是允许的状态。

## 关键性质

| 性质 | 公式/结论 | 说明 |
|------|------|------|
| 能级 | $E_n = n^{2} \dfrac{\hbar^{2}\pi^{2}}{2ma^{2}}$ | $E_n \propto n^{2}$，间隔随 $n$ 增大而增大 |
| 零点能 | $E_1 = \dfrac{\hbar^{2}\pi^{2}}{2ma^{2}} > 0$ | 量子力学特有，经典最低能量为 0 |
| 波函数节点数 | $n-1$ 个节点（内部） | $n$ 越大，振荡越多 |
| 概率密度 | $|\psi_n|^{2} = \frac{2}{a}\sin^{2}(\frac{n\pi}{a}x)$ | 不均匀分布，与经典均匀分布完全不同 |
| $n \to \infty$ | 经典对应原理 | 概率密度的平均趋近均匀分布 |
| 能级间距 | $\Delta E_n = (2n-1)E_1$ | $n \gg 1$ 时 $\Delta E/E \to 0$（准连续） |

## 典型例题

> **题目**（习题17-6b）：电子处在宽度 $a = 1\text{ \AA}$ 的一维无限深势阱中。（1）求 $n=1, 2, 3$ 的能级；（2）$n=1$ 时概率密度最大的位置。

> [!example]- 解答
> （1）$m_e = 9.11 \times 10^{-31}\text{ kg}$，$a = 10^{-10}\text{ m}$，
> $$E_1 = \frac{\hbar^{2}\pi^{2}}{2m_e a^{2}} = \frac{(1.055 \times 10^{-34})^{2} \pi^{2}}{2 \times 9.11 \times 10^{-31} \times (10^{-10})^{2}} \approx 6.02 \times 10^{-19} \text{ J} \approx 3.76 \text{ eV}$$
> $$E_2 = 4E_1 \approx 15.0 \text{ eV}, \quad E_3 = 9E_1 \approx 33.8 \text{ eV}$$
>
> （2）$|\psi_1(x)|^{2} = \frac{2}{a}\sin^{2}(\frac{\pi}{a}x)$，正弦平方在 $x = a/2$ 处最大。
>
> 点评：阱宽越小，$E_1$ 越大（$\propto 1/a^{2}$）——粒子被关得越紧，零点能越高，与不确定关系一致。

> **题目**：一维无限深势阱中，粒子处于 $n=2$ 态，在 $[0, a]$ 中何处找到粒子的概率最大？最小？

> [!example]- 解答
> $|\psi_2(x)|^{2} = \frac{2}{a}\sin^{2}(\frac{2\pi}{a}x)$
>
> $\sin^{2}$ 取最大值 $1$ 时：$\frac{2\pi}{a}x = \frac{\pi}{2}, \frac{3\pi}{2}$ → $x = a/4, 3a/4$
>
> $\sin^{2}$ 取最小值 $0$ 时：$\frac{2\pi}{a}x = 0, \pi, 2\pi$ → $x = 0, a/2, a$
>
> 点评：$n=2$ 时粒子**不可能出现在 $x = a/2$ 处**（概率为零）——这在经典物理中是无法理解的。

## 易错点

> [!warning] 易错点 1
> 量子数 $n$ 从 **1** 开始，不是从 0 开始。$n = 0$ 会使波函数恒为零（$\psi \equiv 0$——粒子不存在）。
>
> [!warning] 易错点 2
> 零点能 $E_1 > 0$！经典粒子在势阱底可以静止（$E = 0$），但量子粒子由于不确定关系，不可能同时 $\Delta x \sim a$ 且 $\Delta p = 0$，故 $E_1 > 0$。
>
> [!warning] 易错点 3
> 概率密度 $|\psi_n(x)|^{2}$ 在阱内不均匀（与经典力学均匀分布不同），且 $n=2, 3, \ldots$ 存在概率为零的位置（节点）。这是量子力学的特有现象。
>
> [!warning] 易错点 4
> 波函数在边界 $x=0$ 和 $x=a$ 处为 0（束缚态），波函数的一阶导数在边界处**可以不连续**（因为势能无限大）。
