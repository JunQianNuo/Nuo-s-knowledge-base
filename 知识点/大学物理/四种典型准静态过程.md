# 四种典型准静态过程

## 一句话

四种过程由各自的约束条件定义——等体（$V$ 不变）、等温（$T$ 不变）、等压（$p$ 不变）、绝热（$Q=0$）——每种过程的 $\Delta E$、$A$、$Q$ 可直接套用公式，无需每次从头推导。

## 严格定义

对理想气体准静态过程，第一定律 $dQ = \nu C_V dT + p\, dV$，结合状态方程 $pV = \nu RT$ 和各过程约束条件：

$$
\boxed{
\begin{aligned}
\text{等体: } & dV = 0, \quad A = 0, \quad Q = \Delta E = \nu C_V \Delta T \\[4pt]
\text{等温: } & dT = 0, \quad \Delta E = 0, \quad Q = A = \nu RT \ln\frac{V_2}{V_1} \\[4pt]
\text{等压: } & dp = 0, \quad A = p(V_2-V_1), \quad Q = \nu C_p \Delta T \\[4pt]
\text{绝热: } & dQ = 0, \quad A = -\Delta E = -\nu C_V \Delta T, \quad pV^\gamma = C
\end{aligned}
}
$$

> [!important] 核心对比
> 所有过程中 $\Delta E = \nu C_V \Delta T$ 始终成立（对理想气体，$\Delta E$ 只看始末温度）。

## 推导：过程方程的来源

> [!proof]- 推导
> 四种过程方程来自状态方程 $pV = \nu RT$ + 各自约束条件：
>
> - **等体**（$V = C$）：$p/T = C$（查理定律）
> - **等温**（$T = C$）：$pV = C$（玻意耳定律）
> - **等压**（$p = C$）：$V/T = C$（盖-吕萨克定律）
> - **绝热**（$dQ = 0$）：由 $dQ = \nu C_V dT + p\,dV = 0$，结合 $pV = \nu RT$ 微分消去 $dT$，利用 $C_p = C_V + R$ 和 $\gamma = C_p/C_V$，积分得 $pV^\gamma = C$。
>
> 核心洞察：前三种来自气体实验定律的特例，绝热过程方程需要解微分方程。

## 关键性质：对比总表

| | 等体 | 等温 | 等压 | 绝热 |
|------|:--|:--|:--|:--|
| **特征** | $V = C$ | $T = C$ | $p = C$ | $Q = 0$ |
| **过程方程** | $p/T = C$ | $pV = C$ | $V/T = C$ | $pV^\gamma = C$ |
| **$\Delta E$** | $\nu C_V \Delta T$ | $0$ | $\nu C_V \Delta T$ | $\nu C_V \Delta T$ |
| **$A$** | $0$ | $\nu RT\ln\frac{V_2}{V_1}$ | $p(V_2-V_1)$ | $-\nu C_V \Delta T$ |
| **$Q$** | $\nu C_V \Delta T$ | $A$ | $\nu C_p \Delta T$ | $0$ |
| **热容** | $C_V$ | $\infty$ | $C_p$ | $0$ |

在 p-V 图上：
- 等温线：$p \propto 1/V$（双曲线），斜率 $-\frac{p}{V}$
- 绝热线：$p \propto V^{-\gamma}$，斜率 $-\gamma\frac{p}{V}$（比等温线**更陡**，因 $\gamma > 1$）

## 典型例题

> **题目**（习题8-3）：1 mol 刚性双原子理想气体，经历循环 a→b→c→a。过程：a→b 等压膨胀（$p_0, V_0 \to 2V_0$），b→c 等温压缩（回到 $V_0$），c→a 等体升压（回到 $p_0$）。求各过程的 $\Delta E$、$A$、$Q$。

> [!example]- 解答
> $i=5$，$C_V = \frac{5}{2}R$，$C_p = \frac{7}{2}R$。
>
> **a→b**（等压）：
> $A_{ab} = p_0 V_0$，$\Delta E_{ab} = \frac{5}{2}R(T_b-T_a) = \frac{5}{2}p_0V_0$，
> $Q_{ab} = \frac{7}{2}p_0V_0$
>
> **b→c**（等温）：
> $\Delta E_{bc} = 0$，$A_{bc} = RT_b \ln\frac{V_c}{V_b} = 2p_0V_0 \ln\frac{1}{2} = -2p_0V_0\ln 2$，
> $Q_{bc} = A_{bc}$
>
> **c→a**（等体）：
> $A_{ca} = 0$，$\Delta E_{ca} = \frac{5}{2}R(T_a-T_c) = \frac{5}{2}p_0V_0(1-2) = -\frac{5}{2}p_0V_0$，
> $Q_{ca} = -\frac{5}{2}p_0V_0$
>
> 循环净功：$A_{net} = A_{ab} + A_{bc} = p_0V_0(1 - 2\ln 2)$
>
> 点评：核心是牢记每种过程的 $\Delta E, A, Q$ 公式，逐一计算即可。

> **题目**（习题8-5）：1 mol 理想气体经等温膨胀和等体升压两过程回到原压强。求：（1）两过程中的吸热；（2）该气体的 $\gamma$。

> [!example]- 解答
> 由题给数据反推过程参数，利用各过程的 $\Delta E, A, Q$ 关系和第一定律列方程，解出 $\gamma$。
>
> 点评：此类题的关键是利用已知的 $Q$ 和 $A$ 通过第一定律反推温度变化，进而确定 $\gamma$。

## 易错点

> [!warning] 易错点
> 1. **$\Delta E = \nu C_V \Delta T$ 在所有过程中都成立**（对理想气体），不要以为只在等体过程中才能这样算——$\Delta E$ 是状态函数
> 2. **等温过程热容是 $\infty$ 不是 0**：$Q \neq 0$ 但 $\Delta T = 0$
> 3. **绝热过程 $dQ=0$ 但温度可以变化**：$dE = -dA$，气体膨胀降温、压缩升温
> 4. **绝热线比等温线更陡**的原因：绝热膨胀时体积增大+温度降低，双重效果使压强下降更快
