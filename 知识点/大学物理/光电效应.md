# 光电效应

## 一句话

光子将全部能量 $h\nu$ 交给金属中一个电子——一部分用于克服逸出功 $A$，剩余变为电子动能。

## 严格定义

光照射金属表面，电子从表面逸出的现象。爱因斯坦光子理论给出：

$$
\boxed{h\nu = \frac{1}{2}mv^{2} + A}
$$

其中 $A = h\nu_0$ 为逸出功，$\nu_0$ 为**红限频率**。

截止电压与最大初动能的关系：

$$
\boxed{eV_a = \frac{1}{2}mv^{2}}
$$

> [!important] 四条实验规律
> 1. **饱和电流 $\propto$ 光强**（光强越大，逸出电子越多）
> 2. **截止电压只与频率有关**（与光强无关）
> 3. **存在红限 $\nu_0 = A/h$**，$\nu < \nu_0$ 时无论光强多大都无光电子
> 4. **瞬时性**：延迟不超过 $10^{-8}\text{ s}$

**光子的性质**：

| 物理量 | 公式 | 说明 |
|--------|------|------|
| 能量 | $E = h\nu = hc/\lambda$ | $h = 6.63 \times 10^{-34} \text{ J·s}$ |
| 动质量 | $m = E/c^{2} = h\nu/c^{2}$ | 光子有动质量 |
| 静质量 | $m_0 = 0$ | 光子静质量为零 |
| 动量 | $p = mc = h/\lambda$ | $p = E/c$ |

## 推导：光电效应方程

> [!proof]- 推导
> 爱因斯坦假设：一个光子与一个电子发生完全非弹性碰撞，光子能量全部传递给电子。
>
> 能量守恒：
> $$h\nu = \frac{1}{2}mv^{2} + A$$
>
> 当 $\nu = \nu_0$ 时，电子刚好逸出（动能 = 0）：
> $$h\nu_0 = A \quad \Rightarrow \quad \nu_0 = \frac{A}{h}$$
>
> 代入得：$\displaystyle \frac{1}{2}mv^{2} = h(\nu - \nu_0)$
>
> 截止电压 $V_a$ 使光电流降为零，即 $eV_a = \frac{1}{2}mv^{2}$，故：
> $$eV_a = h(\nu - \nu_0)$$
>
> $V_a$-$\nu$ 图线为直线，斜率 $= h/e$（可通过实验测定普朗克常数）。

## 关键性质

| 性质 | 说明 |
|------|------|
| 截止电压与光强无关 | 光强只影响光电子数量（饱和电流），不影响最大动能 |
| 红限频率 $\nu_0 = A/h$ | 不同金属逸出功不同，红限不同 |
| 光子能量 $h\nu < A$ 时 | 无论光强多大，均无光电子逸出 |
| I-U 特性曲线 | 正向饱和电流随光强增大；反向截止电压与光强无关 |

## 典型例题

> **题目**（习题16-1）：用波长 $\lambda = 4000\text{ \AA}$ 的光照射铯（Cs，逸出功 $A = 1.9\text{ eV}$）。求：（1）逸出电子的最大动能；（2）截止电压。

> [!example]- 解答
> （1）光子能量：
> $$E = h\nu = \frac{hc}{\lambda} = \frac{6.63 \times 10^{-34} \times 3 \times 10^{8}}{4000 \times 10^{-10}} = 4.97 \times 10^{-19} \text{ J} = 3.11 \text{ eV}$$
>
> 最大动能：
> $$\frac{1}{2}mv^{2} = h\nu - A = 3.11 - 1.9 = 1.21 \text{ eV}$$
>
> （2）截止电压：
> $$V_a = \frac{\frac{1}{2}mv^{2}}{e} = 1.21 \text{ V}$$
>
> 点评：计算截止电压只需用 $h\nu - A$ 除以 $e$，与光强无关。

> **题目**（习题16-2）：光电管在磁场 $B$ 中，光电子最大轨迹半径 $R$，求逸出功 $A$。

> [!example]- 解答
> 电子在磁场中做圆周运动：$evB = mv^{2}/R$，得 $mv = eBR$。
>
> $\frac{1}{2}mv^{2} = \frac{(eBR)^{2}}{2m}$，代入 $h\nu = \frac{1}{2}mv^{2} + A$：
> $$A = h\nu - \frac{(eBR)^{2}}{2m}$$
>
> 点评：用磁场偏转法测量光电子动能——$R$ 越大，动能越大。

## 易错点

> [!warning] 易错点 1
> 截止电压由**光的频率**决定，与光强无关。光强只决定饱和电流的大小。
>
> [!warning] 易错点 2
> 光子静质量 $m_0 = 0$（**不是** $m = 0$），但有动质量 $m = h\nu/c^{2}$ 和动量 $p = h/\lambda$。
>
> [!warning] 易错点 3
> 红限是**频率**下限而非波长下限——$\nu < \nu_0$ 时无光电子，对应 $\lambda > \lambda_0 = c/\nu_0$。
