# 答疑规范

## 目录结构

```
答疑/
├── README.md                    ← 总索引（所有章节答疑一览）
├── XX-章节名/                   ← 按章节分文件夹，命名对齐课件笔记
│   ├── README.md                ← 章节答疑索引
│   ├── XX-答疑主题.md            ← 每个问题一个独立文件
│   └── ...
└── ...
```

## 文件命名

`{章节号}-{简短主题}.md`，如 `06-FONC详解.md`、`11-ShermanMorrison公式.md`。

## Frontmatter 规范

```yaml
---
title: 第X章 答疑 — 主题简述
subject: 最优化方法
chapter: X
type: 答疑
topics:
  - 关键词1
  - 关键词2
source_context:                          # 必填：答疑的触发位置
  - file: "XX-知识梳理.md"
    line: 64                             # 精确行号（优先）；跨章节对比问题可用 section 替代
    text: "若 H ≻ 0..."
related_notes:
  - "[[XX-知识梳理]]"
  - "[[YY-知识梳理]]"
---
```

- `source_context` 用列表，可有多条（若问题涉及多个位置）
- `line` 优先用精确行号；跨章节对比、概念辨析等无法定位到单行的问题，用 `section` 字段替代
- `related_notes` 列出与本答疑内容相关的笔记链接

## 内容结构

1. **问题重述** — 用 `> 问题：...` 引用块还原原始提问
2. **来源标注** — 紧接着用 `> 来源：` 标注触发位置
3. **回答正文** — 自由组织，但建议：
   - 先给核心结论（一两句话兜底）
   - 再展开推导 / 对比 / 图示
   - 公式用 LaTeX
   - 表格用于对比
   - 适当使用 `> [!warning]` callout 标注易错点
4. **相关链接** — 末尾列出 Wiki-link，回链课件笔记和习题

## 引用约定

- **每个答疑必须留链接指向引用处**——在 `source_context` frontmatter 和正文「来源」行中标注
- 链回课件笔记用 Wiki-link，格式：`[[XX-知识梳理#锚点|显示文本]]`
- 答疑之间的互引用同样用 Wiki-link

## 修改规则

- **用户引用答疑文件提问时，直接对该答疑文件做补充修改**——不新建文件
- 补充内容追加在原回答之后，用 `---` 分隔，标注「补充」或「追问」
- 同步更新 frontmatter 的 `topics` 和文末的「相关链接」

## 章节 README（索引）

每个章节文件夹必须包含 `README.md`，内容：

```yaml
---
title: 第X章 答疑索引
subject: 最优化方法
chapter: X
type: MOC
---
```

正文包含：
- 链接回课件笔记
- 答疑列表表格（序号 | 主题 | 来源行 | 状态）
