# Obsidian 写作规范

> [!important] 属性规则适用范围
> 新原子笔记与 MOC 的类型、主题、关系及标题规则以 [[docs/KNOWLEDGE_ARCHITECTURE]] 为准。下面课程元数据示例不是 v1 模板，其中描述性 topics 仅兼容历史笔记；新建笔记使用主题链接，课程专用字段继续按课程规范，历史字段不自动替换。
>
> v1 的 tags 仅辅助检索，不强制把每个核心概念补成标签，也不从 topics 链接、显示文本或关联目标推导标签。词表命名规则对实际填写的 tags 继续适用；旧标签脚本对新格式写入前须完成独立适配验收。

## Frontmatter

课程笔记尽量使用 YAML frontmatter 管理元数据：

```yaml
---
title: 标题
subject: 课程名
type: 知识梳理
topics:
  - 关键词
tags:
  - 概念名
---
```

内容类型用 `type` 字段，状态用 `status` 字段，不用 tag 表示。

## Wiki-link

- Vault 内部文件使用 `[[wikilink]]`。
- 文件名可能重复时使用带路径的链接，如 `[[课程/最优化方法/习题库/README]]`。
- 外部网页使用普通 Markdown 链接。

## Tag

Tag 是跨课程/跨章节的概念锚点，默认放在 frontmatter 的 `tags` 字段，不用正文内联 `#tag`。

原则：

- 用概念名，不带内容类型前缀。
- 中文为主，常用英文缩写可保留，如 `KKT条件`。
- 不用 `#知识点`、`#习题`、`#todo` 等类型/状态 tag。
- 新增 tag 前先搜索同义 tag。

标准名与同义名称统一维护在 [[总览/标签库.base|标签数据库]]，使用方法见 [[总览/标签库/README]]。新建笔记先查词表并复用 `canonical_tag`；确有新概念时先登记，再使用。标准名变更时将旧名保存在 `tag_aliases`，再审计和同步实际笔记中的 `tags`。

依据 [Obsidian 官方标签文档](https://obsidian.md/zh/help/tags)：标签不区分大小写，不能包含空格；允许字母、数字、下划线、连字符及表示层级的正斜杠，并且必须包含非数字字符。数字可以开头；数学写法如 `L^p空间` 保留在 `topics` 或同义名称中，标准标签使用词表中的合法写法。

- `tags` 是内置 `tag:标准名` 搜索入口，使用字符串列表，不带 `#`。
- `topics` 保留描述性主题，不要求逐项复制到标签。
- `knowledge_tags`、`method_tags` 用于区分角色；用于统一检索的对应概念也应写入 `tags`。
- 数据库中的同义词不会被内置搜索自动展开；维护脚本按记录精确归一实际标签。
- `/` 只表示真实的上下位关系；父标签搜索包含子标签，不将同义名称建成父子关系。
- 单次使用不是删除依据。仅登记保留的历史标签需核对后再启用自动补标，不把类型、状态、课程位置等结构词机械变成概念标签。

批量维护使用 `python scripts/tag_maintenance.py` 先只读审计，核对后加 `--apply`；须保存原始字节备份，并验证正文、其他元数据、实际搜索结果与二次运行幂等性。

## Markdown 表格

表格单元格禁止裸 `|`。在 LaTeX 中使用：

| 场景 | 表格内写法 |
|---|---|
| 绝对值 | `\vert x \vert` |
| 范数 | `\Vert x \Vert` |
| 条件概率/集合条件 | `\mid` |

验证表格：

- 表头、分隔行、数据行列数一致。
- 分隔行冒号紧贴横线，如 `|:--|`。
- 表格前后各空一行。

## Mermaid

- 节点标签含数学符号、括号、花括号、方括号、竖线、冒号时，用 `"..."` 包裹。
- 避免 `<br/>`，用短节点 + 图外解释。
- 避免在标签中使用未转义的 `|`、`{}`、`[]`。
- 可使用 Unicode 箭头 `→`，但复杂说明放图外。

## Callout

常用格式：

```markdown
> [!warning] 易错点
> 内容

> [!hint]- 点击展开提示
> 内容

> [!solution]- 点击展开详细解析
> 内容
```

折叠 callout 使用 `-`，展开 callout 使用 `+`。

## LaTeX

- 行内公式用 `$...$`。
- 块级公式用 `$$...$$`。
- 表格内避免裸 `|`，改用 `\vert`、`\Vert`、`\mid`。

## 验证清单

- Frontmatter 是否有必要字段？
- Wiki-link 是否可点击且无歧义？
- 表格是否无裸 `|` 且列数一致？
- Mermaid 是否避免 `<br/>` 和未加引号的特殊标签？
- Callout 是否每行都有 `>` 前缀？
