# tag 规范

## 目的

**Tag 是跨学科/跨课程的概念锚点**。文件夹提供"属于哪门课"的上下文，tag 提供"讨论什么概念"的跨文件连接。

点一个 tag，能看到知识库中**所有讨论该概念的文件**，无论它们在哪个课程、哪个章节。

## 核心原则

| 原则 | 说明 |
|:--|:--|
| **概念名，不带学科前缀** | `#剩余价值` 不是 `#马原/剩余价值`。除非同名概念在不同学科含义完全不同 |
| **中文为主** | 概念名用中文，除非中文名不常用（如 `#KKT条件` 比「Kuhn-Tucker 条件」更常见） |
| **扁平优先** | 默认不用层级。如 `#价值` 而非 `#马原/商品经济/价值` |
| **2 个文件以上才值得存在** | 只在一个文件中出现的 tag 本质是关键词，不是 tag。考虑删除或用 wikilink 替代 |

## 命名规则

```
#概念名
#概念名/子概念     ← 仅当需要消歧或精确引用的少数情况
```

**允许的格式**：
- `#剩余价值`、`#对偶`、`#收敛`、`#KKT条件`、`#单纯形法`
- `#实变/几乎处处`（跨学科有歧义时加学科前缀消歧）

**禁止的格式**：
- 单字母：~~`c`~~、~~`v`~~ → 展开全称 `不变资本`、`可变资本`（不是 tag 是缩写笔记）
- 公式符号：~~`G-W-G'`~~、~~`m'`~~ → 这类信息写进正文，不在 tag 中
- 内容类型标记：~~`#知识点`~~、~~`#习题`~~、~~`#闪卡`~~ → 文件夹已区分
- 状态标记：~~`#todo`~~、~~`#复习`~~ → 用 frontmatter `status` 字段而非 tag

## tag 的定位：和 wikilink 的区别

| | tag | wikilink |
|:--|:--|:--|
| **连接方式** | 一对多：一个 tag 下聚合所有相关文件 | 一对一：A 文件链接到 B 文件 |
| **适合场景** | "所有讨论 X 概念的文件" | "详见那篇笔记" |
| **前置条件** | 不需要目标文件存在 | 需要目标文件存在 |
| **典型用途** | 概念索引、跨课程主题聚合 | 知识点引用、相关笔记导航 |

**判断标准**：如果要连的是"一类东西"，用 tag；如果要连的是"一个具体的东西"，用 wikilink。

## 使用场景

### 适合用 tag 的

- **跨章节概念**：一门课内多次出现（如 `#剩余价值`、`#对偶`）
- **跨课程概念**：多门课都讨论（如 `#收敛`、`#正交`、`#不动点`）
- **方法/定理索引**：真题中反复考查的方法（如 `#单纯形法`、`#DCT控制收敛`）
- **考试要点**：标注真题考查过的概念（如 `#选择`、`#简答`、`#计算` 作为辅助 tag）

### 不适合用 tag 的

- 只在 1 个文件中出现的关键词 → 写到正文里即可
- 内容类型（知识点/习题/答疑）→ 文件夹已区分
- 文件状态（待校对/已复习）→ 用 frontmatter 字段
- 公式符号、缩写 → 写在正文里

## frontmatter 格式

```yaml
tags:
  - 剩余价值
  - 绝对剩余价值
  - 相对剩余价值
```

**不要**用内联 `#tag` 格式（除非在正文中自然引用）。tag 统一放在 frontmatter 的 `tags` 字段。

## 维护规则

1. **处理文件时顺带检查 tag**：每次编辑/创建笔记时，审视 tag 是否符合本规范
2. **孤儿清理**：如果一个 tag 只出现在 1 个文件中超过 1 个月，考虑删除或用 wikilink 替代
3. **新增 tag 前先搜索**：是否有同义 tag 已存在？是则复用，否则新建
4. **tag 数量控制在 3-8 个/文件**：过多说明粒度太细，考虑合并
