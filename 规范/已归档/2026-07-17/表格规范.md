# Markdown 表格书写规范

**本规范适用于 vault 内所有 Markdown 表格，尤其数学内容密集的课程笔记和答疑文件。**

## 铁律（优先级从高到低）

### 1. 表格单元格内禁止裸 `|`

`|` 是 Markdown 列分隔符。单元格内出现任何裸 `|` 都会被解析为新列，导致列数爆炸。

| ❌ 错误 | ✅ 正确 |
|:--|:--|
| `$\|x\|$` | `$\vert x \vert$` |
| `$\|\tilde{x} - x\|$` | `$\Vert\tilde{x} - x\Vert$` |
| `$P(A\|B)$` | `$P(A \mid B)$` |
| `$\{x \| x>0\}$` | `$\{x \mid x>0\}$` |

**LaTeX 对照表**：

| 符号 | 用途 | 表格内必须用 |
|:--|:--|:--|
| `\|` | 绝对值 | `\vert` 或 `\lvert` `\rvert` |
| `\|` | 范数 | `\Vert` 或 `\lVert` `\rVert` |
| `\|` | 条件概率 / 集合 | `\mid` |
| `\|` | 整除 | `\mid` |

### 2. 列数必须一致

表头、分隔行、每一数据行的 `|` 数量必须相等。

```
| A | B |      ← 2 列
|:--|:--|      ← 2 列
| 1 | 2 |      ← 2 列
```

### 3. 分隔行冒号紧贴横线

```
|:--|           ✅
|:-- |          ❌ 空格导致部分解析器失败
|---|           ✅ 默认左对齐
|:--:|          ✅ 居中
|---:|          ✅ 右对齐
```

### 4. 表格前后各空一行

```
段落文字。

| A | B |
|:--|:--|
| 1 | 2 |

后续段落。
```

### 5. Obsidian Live Preview 的自动补全

Obsidian 编辑模式下会对表格自动格式化（对齐列宽、补分隔符），常见副作用：

- 把 `$\vert x \vert$` 里的 `\vert` 两侧再补 `|`，生成 `|$\vert x \vert$|` 但不影响
- 把对齐行 `:--` 吞冒号

**预防**：
- 写完表格后切阅读模式确认
- 若反复被破坏，在数学列前后避免用 `|` 对齐——内容正确优先于列对齐美观

## 写作规则

### 结构

- 表格必须有三部分：**表头行 + 分隔行 + 数据行**，缺一不可
- 允许空表头（第一列为空），用于"行标签"风格：

```
| | 求根问题 | 线性方程组 |
|:--|:--|:--|
| 精确条件 | $f(r)=0$ | $Ax=b$ |
```

### 数学内容

- 单元格内 LaTeX 用 `$...$`（行内）或 `$$...$$`（不推荐在表格内用行间公式）
- 涉及 `|` 的符号**一律**使用 `\vert` / `\Vert` / `\mid` 替代（见铁律 1）
- 若单元格内 LaTeX 复杂，先在表格外写好确认无误，再填入

### 单元格换行

标准 Markdown 不支持表格单元格内换行。若有长内容：

- 用 `<br>` 强制换行（Obsidian 基本兼容）
- 或将内容拆到表格外用段落叙述

## 验证清单

写完表格后逐项检查：

- [ ] 单元格内无裸 `|`（尤其 LaTeX 内）
- [ ] 表头 / 分隔行 / 数据行的 `|` 数量一致
- [ ] 分隔行 `:--` 冒号紧贴横线
- [ ] 表格前后各有一个空行
- [ ] 阅读模式下表格正常渲染

## 快速修复

遇到表格异常时，按优先级排查：

1. **Grep 裸 `|`**：搜索表格区域内的 `$|` — 90% 的问题在此
2. **列数对齐**：数表头 `|` 数、分隔行 `|` 数、每行 `|` 数
3. **Obsidian 自动格式化**：切阅读模式确认是否是编辑器干扰

```bash
# 快速排查：搜索表格中 LaTeX 里的裸 |
rg '\$\|.*\|.*\$\|' --type md    # 查找疑似 | | 被拆分的位置
```
