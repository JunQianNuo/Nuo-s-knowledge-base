# 知识点解析梳理规范（初学导向）

## 目的

**面向初学**：第一次接触该章节时，能够**全面、难易分明、重轻分明、直观、有逻辑地**学懂。不是课件内容的搬运或缩写——是基于课件内容的重构和组织。

## 设计原则

| 原则       | 含义                                                                 |
| -------- | ------------------------------------------------------------------ |
| **全面**   | 课件中的定理、公式、例题**不能遗漏**，且要给出可折叠的详细解答和提示。梳理不是摘要，不能因为追求简洁而砍掉东西。         |
| **难易分明** | 标注哪些是重点（必须掌握）、哪些是难点（需要反复看）、哪些了解即可。在板块标题中体现——如「可行方向与切锥（**难点**）」     |
| **重轻分明** | 核心内容展开深入（配直观理解、证明思路、例题步骤）；非核心内容简略带过但不删除。篇幅可以长，但不能空洞。               |
| **直观**   | 每个核心概念配 `> 一句话来说：...`——用人类语言说清本质。定理配「直观理解」而非照抄定义。证明只保留核心洞察，不抄完整推导。 |
| **有逻辑**  | 脉络图体现**概念演进关系**（为什么先讲这个再讲那个），而非线性枚举。同一板块内的知识点之间说明衔接关系。             |

## 文件命名

`XX-章节名-知识梳理.md`

## Frontmatter

```yaml
---
title: 第X章 章节名 — 知识点梳理

  - 关键词1
  - 关键词2

```

## 内容结构

**固定部分**：开头（脉络）和收尾四个板块（公式速查 / 易错点 / 回链 / 作业）的位置和标题固定。

**灵活部分**：中间的内容板块**按该章知识体系自然切分**，标题体现具体内容，标注难度（如标注「难点」「核心」）。标题示例（来自第6章范本）：
- `二、优化问题的基本定义`
- `三、可行方向与切锥（难点）`
- `四、方向导数`
- `五、最优性条件（本章核心）`

| 板块 | 内容要求 | 标题固定？ |
|------|----------|:---:|
| **一、本章核心脉络** | 点明核心问题 + Mermaid 流程图展示**概念演进关系**（不要线性枚举）；图后一句话解释为什么是这个顺序 | ✅ |
| **内容板块（若干）** | 按知识逻辑分段；标题体现具体内容+难度标注；概念配表格；定理配「直观理解」+ 核心洞察证明；典型例题配步骤分解和点评；**课件中所有知识点必须覆盖** | ❌ 灵活命名 |
| **判定/决策流程** | Mermaid 流程图；节点文字简洁（不用 `<br/>` 和 `✅❌⬆↔⬇`） | ✅ 位置固定 |
| **核心公式速查表** | Markdown 表格 | ✅ |
| **易错点与注意事项** | `[!warning]` callout；区分必要条件 vs 充分条件 | ✅ |
| **相关知识点链接** | Wiki-link 前后章节；每处链接说明"为什么这章需要那个前置知识" | ✅ |
| **作业与练习** | 链接习题库 README + 做题建议 | ✅ |

## 格式规范

1. **Mermaid 图表**：节点文字避免 `<br/>` 和 `✅❌⬆↔⬇` 等特殊 Unicode 符号；换行用短文本节点 + 图外文字说明
2. **「一句话来说」**：用 `> 一句话来说：...` 引语块，放在每个核心概念/定理之后
3. **表格**：用于对比概念、条件、结论
4. **Callout**：`[!warning]` 易错点、`[!hint]` 记忆技巧、`[!solution]` 例题解析
5. **公式**：LaTeX，复杂公式用 `$$` 块级
6. **Wiki-links**：链接课件笔记和习题库

## 与知识点汇集的对比

|          | 知识点汇集       | 知识点解析梳理            |
| -------- | ----------- | ------------------ |
| **使用场景** | 复习、查缺补漏     | 初学、深入理解            |
| **结构**   | 固定9板块，标题不变  | 头尾固定，中间按知识逻辑灵活     |
| **覆盖**   | 全量（不遗漏知识点）  | 全量（不遗漏知识点）         |
| **篇幅**   | 简洁，清单式      | 可以长，核心展开、非核心简带     |
| **直观理解** | 需要          | 必须——每个核心概念配「一句话来说」 |
| **证明**   | 链接到对应md课件   | 核心定理保留核心洞察         |
| **轻重**   | 均匀（复习时自己判断） | 分明（标注难点/核心/了解即可）   |

## 生成流程

```
读取课件 MD → 提取所有概念/定理/例题（不能遗漏）→ 
分析知识逻辑，自然切分板块，标注难点/核心 → 
补充「一句话来说」、核心洞察证明、例题步骤 → 
添加公式速查/易错点/回链/作业 → 写入知识点解析梳理/XX-知识梳理.md
```
