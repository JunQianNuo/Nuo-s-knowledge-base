# 审查规范

## 目的

每次新增/修改习题或知识点后，启动双 agent 分工验证，确保格式无残留、内容无遗漏。

## 触发时机

- 新习题录入后
- 新知识点/方法文件生成后
- 批量修复后（如 OCR 清理）

## 双 Agent 分工

### Agent A：格式检查

**职责**：扫描指定目录下所有 .md 文件，逐项检查：

| 检查项 | 标准 |
|:--|:--|
| LaTeX OCR 残留 | 无 `\begin{array}`（应 `\begin{cases}`）、无 `\mathbf{0}`、无 `e l s e` 分裂、无 `\frac {x}` 空格、无 `\stackrel`、无 `\left\{...\right.` 冗余 |
| 公式包裹 | 所有数学符号/公式用 `$` 或 `$$` 包裹 |
| Callout 格式 | `[!solution]-` / `[!hint]-` 有 `-` 折叠符；callout 内行有 `>` 前缀 |
| Frontmatter 必填字段 | 参照对应规范（习题/知识点/方法/概念卡的 frontmatter 模板） |
| OCR 文本残留 | 无 `image_`、`Image_`、`Screenshot_`、`+N分`、`回答错误`、`AI答题辅导`、`答案解析`、`上传附件`、`暂无解析` |
| 答案汇总行 | 习题解答末尾有 `**答案**：` 汇总 |
| 流程图 | 复杂题（≥3 步或有分支）的 `[!solution]-` 开头有 Mermaid flowchart |
| Wiki-link 有效性 | 所有 `[[...]]` 指向的文件存在（Glob 验证） |

### Agent B：内容检查

**职责**：扫描指定目录，逐项检查：

| 检查项 | 标准 |
|:--|:--|
| 知识点板块完备性 | 一句话 / 严格定义 / 推导 / 关键性质 / 典型例题 / 易错点 / 相关概念 / 习题（8 板块齐全） |
| 方法板块完备性 | 适用场景 / 核心公式（`\boxed{}`）/ 流程图 / 例题 / 知识链接 / 习题链接（6 板块齐全） |
| 概念反向链接 | 概念文件 `## 相关概念` 包含知识点链接 |
| 知识点双向链接 | 知识点文件 `## 相关概念` 同时链概念层和方法层 |
| `\boxed{}` 存在 | 核心公式用 `\boxed{}` 框出 |
| 易错点数量 | ≤ 5 条 |
| 例题解答完整性 | 折叠 callout 内有解答内容，非空 |
| 内容冲突 | 不同文件中的相同结论表述一致 |
| 板块顺序 | 符合对应规范的固定顺序 |

## 执行流程

```
新内容录入
    │
    ├── Agent A (格式检查) ────┐
    │                          ├── 修复 → 重新验证 → 通过
    └── Agent B (内容检查) ────┘
```

两 agent 并行运行，各自输出问题清单。修复后重新验证，全部通过才算完成。

## 搜索广度

每次审查使用 `very thorough` 广度，确保覆盖所有子目录和文件。

## 输出格式

Agent 返回：

```
## 文件:行号 → 问题描述

| 级别 | 数量 | 文件 |
|:--|:--|:--|
| 严重 | N | ... |
| 警告 | N | ... |
| 通过 | N | ... |
```
