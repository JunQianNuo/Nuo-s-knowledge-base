# 知识点汇集规范（复习导向）

## 目的

**面向复习**：已学完课件后，用来快速翻看检查是否有遗漏。固定结构和全量覆盖是核心——复习时不需要重新理解，只需要确认每个知识点都记住了。

## 设计原则

| 原则 | 含义 |
|------|------|
| **固定结构** | 每个章节的板块标题完全一致，复习时知道"每一章都有这九块" |
| **全量覆盖** | 课件中的定理、公式、例题**不能遗漏**——复习时要查缺补漏 |
| **简洁** | 不展开长篇解释，不配直观理解——复习不需要重新学 |
| **模板化** | 类似清单（checklist），逐项过一遍即可 |

## 内容结构（固定9板块）

板块标题不允许变更，确保跨章节一致性：

| 板块 | 内容要求 |
|------|----------|
| **一、本章核心脉络** | 一句话点明核心问题 + Mermaid 流程图 |
| **二、基础定义** | 统一符号；表格整理术语/符号/含义 |
| **三、核心方法/定理** | 逐个列出定理（含公式）；不展开证明 |
| **四、计算/应用** | 典型例题精要；步骤分解；表格对比 |
| **五、判定/决策流程** | Mermaid 流程图 |
| **六、核心公式速查表** | 表格汇总所有核心公式 |
| **七、易错点与注意事项** | `[!warning]` callout |
| **八、相关知识点链接** | Wiki-link 前后章节 |
| **九、作业与练习** | 链接习题库 |

```

填入固定9板块模板 → 写入知识点汇集/XX-知识汇集.md
```
