# 质量审查规范

## 触发时机

- 新习题录入后。
- 新概念卡、知识点卡、方法卡生成后。
- 新知识梳理/知识汇集生成后。
- 学习笔记、课堂笔记生成或进行 CLT 分层适配后。
- 批量 OCR 清理后。
- 批量规范迁移或链接修复后。

## 格式检查

检查项：

- LaTeX OCR 残留：无 `\begin{array}` 误用、无 `e l s e` 分裂、无 `\frac {x}` 多余空格、无损坏 `\c\dots`。
- 公式包裹：数学符号和长公式有 `$` 或 `$$`。
- Callout：`[!solution]-`、`[!hint]-` 有折叠符，callout 内行有 `>` 前缀。
- Frontmatter：必填字段符合对应规范。
- OCR 文本残留：无 `image_`、`Screenshot_`、`AI答题辅导`、`暂无解析` 等无关文本。
- Mermaid：节点标签无未加引号的特殊符号。

## 内容检查

- 知识梳理：是否全量覆盖源 MD，核心概念是否有“一句话来说”。
- 知识汇集：是否固定9板块，是否清单式复习导向。
- 习题：是否有提示、详细解析、`**答案**：` 汇总、点评和相关知识点。
- 概念/知识点/方法卡：板块是否齐全，核心公式是否用 `\boxed{}`，推导/例题是否折叠。
- 答疑：是否有 `source_context`，是否回链来源。

## 学习适配检查

适用于学习笔记、课堂笔记与知识梳理，细则见 [[规范/课程笔记生成规范#CLT 建构主义与本地学习适配（通用要求）]]。

- 是否覆盖指定来源范围，而非为缩短篇幅删去必要条件、例题与推理？
- 是否提供必要先修提醒、直觉与严格表述，重要符号和关键推理依据是否清楚？
- 图表是否帮助理解一个明确关系，未以可视化代替数学论证？
- 核心内容是否可直接阅读，长展开与自测提示/答案是否合理折叠？
- 自测是否包含适合目标学科的独立应用，而非只有定义复述？静态笔记是否未误用对话等待协议？
- 课堂原内容与补充解释、新编题是否区分，原始资料是否保持来源性质？
- 是否未凭笔记“已完成”或未经作答的自测推断用户已掌握？
- 知识汇集是否仍为固定9板块速查，没有被强制改成初学长文？

## Wiki-link 检查

使用全文搜索或脚本检查：

- `[[...]]` 是否能解析到目标文件。
- 同名文件是否需要带路径。
- 旧规范链接是否指向跳转文件或新 active 规范。

## 课程资料转换检查

- Unicode 数学字母清零。
- 损坏 LaTeX 清零。
- 至少有章节标题。
- 文件大小与章节内容相称。
- 图片型习题已检查。

## 输出格式

审查报告建议使用：

```markdown
## 文件:行号 → 问题描述

| 级别 | 数量 | 文件 |
|---|---:|---|
| 严重 | 0 | - |
| 警告 | 0 | - |
| 通过 | N | ... |
```

## 修复闭环

```text
发现问题 → 修复 → 重新验证 → 通过
```

没有重新验证，不算完成。
