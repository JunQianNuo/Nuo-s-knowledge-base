# 每周回顾与任务

## 本周操作

1. 从 [[模板/每周回顾模板|每周回顾模板]] 新建一篇周回顾；
2. 处理 [[未命名/README|收件箱]] 与课程未处理资料；
3. 在 [[总览/待办与复习.base|待办与复习视图]] 中更新状态和复习日期；
4. 为高频、易错、可独立回忆的内容创建闪卡；
5. 更新每个进行中项目的 `next_action`；
6. 运行 `python scripts/audit_vault.py --root .`，仅处理人工确认的问题。
