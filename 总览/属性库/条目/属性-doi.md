# doi

## 用途与处理

文献 DOI。

仅在文献、资料或项目输入需要追溯时保留。

## 使用快照

统计日期：2026-10-27。

| 项目 | 数值 |
|:--|--:|
| 非管理、非模板笔记 | 20 |
| 标签库等管理记录 | 0 |
| 模板 | 0 |
| 扫描范围全部出现次数 | 20 |
| 空值出现次数（含管理与模板） | 0 |

观察到的值类型：文本 20。

当前 Obsidian 属性类型：`text`。

推荐值形式：按实际语义与现有协议填写，观察到的类型不等于强制规范。
