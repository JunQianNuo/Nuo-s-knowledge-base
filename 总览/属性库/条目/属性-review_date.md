# review_date

## 用途与处理

下一次计划复习日期。

只在有对应计划或时间语义时填写，不作为通用模板必填项。

## 使用快照

统计日期：2026-10-27。

| 项目 | 数值 |
|:--|--:|
| 非管理、非模板笔记 | 0 |
| 标签库等管理记录 | 0 |
| 模板 | 1 |
| 扫描范围全部出现次数 | 1 |
| 空值出现次数（含管理与模板） | 1 |

观察到的值类型：空值 1。

当前 Obsidian 属性类型：`text`。

推荐值形式：按实际语义与现有协议填写，观察到的类型不等于强制规范。

现有 Base 使用：

- `总览/待办与复习.base`
- `总览/课程笔记.base`

时间字段不能仅凭名字相似合并：创建、更新、记录发生、实际审查和下一次复习分别保留原有含义。
