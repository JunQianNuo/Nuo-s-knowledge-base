# 停课

## 用途与处理

课表中停课日期或规则。

课表与自动归档配置专用；仅出现一次也应保留。

## 使用快照

统计日期：2026-10-27。

| 项目 | 数值 |
|:--|--:|
| 非管理、非模板笔记 | 1 |
| 标签库等管理记录 | 0 |
| 模板 | 0 |
| 扫描范围全部出现次数 | 1 |
| 空值出现次数（含管理与模板） | 0 |

观察到的值类型：日期 1。

当前 Obsidian 属性类型：`date`。

推荐值形式：按实际语义与现有协议填写，观察到的类型不等于强制规范。
