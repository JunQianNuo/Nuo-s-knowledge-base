# reprocessed_on

## 用途与处理

课堂资料重新处理日期。

采集和质量核对专用；有值及有依赖时保留，不纳入普通笔记必填项。

## 使用快照

统计日期：2026-10-27。

| 项目 | 数值 |
|:--|--:|
| 非管理、非模板笔记 | 14 |
| 标签库等管理记录 | 0 |
| 模板 | 0 |
| 扫描范围全部出现次数 | 14 |
| 空值出现次数（含管理与模板） | 0 |

观察到的值类型：日期 14。

当前 Obsidian 属性类型：`date`。

推荐值形式：按实际语义与现有协议填写，观察到的类型不等于强制规范。
