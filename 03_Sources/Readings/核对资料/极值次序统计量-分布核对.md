# Order Statistics

## 本轮查阅范围

查阅极端次序统计量（sample minimum / sample maximum）的分布及指数样本例。对于独立同分布样本，最大值的分布函数为 $F^n$，最小值为 $1-(1-F)^n$。独立但不同分布情形由交事件独立性直接得到逐项乘积；同率指数样本最小值的率为 $n\lambda$。密度公式需分布绝对连续。
