# Numerical Methods for Engineers — Optimal relaxation parameter

## 本轮查阅范围

查阅 §6.4.2 与式6.59—6.61：矩形域 Poisson/Laplace 标准差分模型可由 Jacobi 的谱参数计算最优松弛因子；网格间隔数、内点数须区分。式 $2/(1+\sqrt{1-\rho^2})$ 依赖模型条件，不能只凭一般矩阵的 Jacobi 谱半径就普遍使用。本库的一维三对角模型另由其特征值及 SOR 谱关系核对。
