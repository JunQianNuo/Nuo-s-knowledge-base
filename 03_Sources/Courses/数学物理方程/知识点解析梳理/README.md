## 推荐学习顺序

```mermaid
flowchart LR
    A[第一章 数学与物理工具] --> B[第二章 建模、分类与定解条件]
    B --> C[第三章 分离变量与固有函数]
    C --> D[用典型题巩固完整解题流程]
```

1. 第一章重点掌握常微分方程、场论算子和基本物理定律，不必一次背完所有特殊函数性质。
2. 第二章重点掌握三类典型方程、三类边界条件、分类判据和适定性。
3. 第三章重点掌握“齐次化—分离—固有值—展开—叠加”的统一流程。
