会议主题：波动方程半无界问题与高维推广课程

发言人：电子科大王君豪

会议摘要：本次课程重点讲解了半无界波动方程的齐次与非齐次边界条件解法，通过奇延拓与偶延拓将问题转化为全空间问题，并引入球面平均法探讨三维高维波动方程。

------------------------------------------------------------------------

一、半无界波动方程齐次边界条件

1. 奇延拓法求解初值问题

-   达朗贝尔公式的局限性：直接套用达朗贝尔公式无法保证半无界问题在边界 x = 0 处满足 u(0,t) = 0 的条件。

-   构造奇函数延拓：通过在负半轴上定义新的函数，使得 f(x) 和 g(x) 均为奇函数，从而保证在 x = 0 处边界条件成立。

-   分情况得出最终解：根据 x 与 t 的大小关系分段计算，当 x > t 时解为 $\frac{1}{2}x + \frac{1}{2}(\sin(x+t) - \sin(x-t))$；当 x < t 时解为 $\frac{1}{2}x + \frac{1}{2}(\sin(x+t) + \sin(x-t))$。

2. 平方初值问题的验证

-   代入平方初值条件：将 u(x,0) = x² 及 u_(t)(x,0) = 0 代入奇延拓后的达朗贝尔公式中进行计算。

-   分段计算与连续性验证：当 x > 2t 时直接代入公式，当 x < 2t 时需对负半轴部分取负，最终验证在 x = 0 和 t = 0 时解均满足初始条件且连续。

二、半无界波动方程非齐次边界条件

1. 叠加原理拆分问题

-   分解为齐次与非齐次部分：利用叠加原理将非齐次边界问题拆分为 u = v + w，其中 v 满足齐次边界条件且初值非零，w 满足非齐次边界条件且初值为零。

2. 零初值非齐次边界的构造解法

-   基于波动方程通解构造：针对 w 部分，令其满足 w = f₁(x+at) + f₂(x−at)，通过强制 f₁ 和 f₂ 在 x > 0 时恒为零来保证初值条件成立。

-   利用边界条件反推函数：将边界条件 w(0,t) = h(t) 代入通解，推导出 f₂ 在负半轴的具体表达式，从而完成 w 的构造。

三、半无界波动方程非齐次方程

1. 三分量叠加分解

-   拆分为三个子问题：针对非齐次方程，将解拆分为 u = v + w + p 三个部分，分别处理齐次边界初值问题、非齐次边界初值问题以及非齐次方程齐次边界问题。

2. 非齐次方程部分的基岩法求解

-   利用基岩法处理源项：针对非齐次方程部分 p，采用基岩法将其转化为初值问题，在求得解后再还原处理。

四、半无界问题的其他边界条件

1. 偶延拓法求解 Neumann 边界条件

-   偶延拓保证导数边界条件：针对 u_(x)(0,t) = 0 的边界条件，不能采用奇延拓，而需对 f 和 g 进行偶延拓，使得求导后变为奇函数，从而在 x = 0 处导数为零。

2. 非齐次导数边界条件的构造

-   基于通解反推：同样从波动方程通解出发，令 f 恒为零，通过代入边界条件 u_(x)(0,t) = h(t) 反推出 g 在负半轴的表达式。

五、高维波动方程与球面平均法

1. 球对称情形的一维化降维

-   球坐标系下的方程化简：在球对称条件下，三维波动方程可化简为仅与半径 r 和时间 t 相关。

-   转化为一维波动方程：通过变量代换 v = ru，将高维问题转化为标准的一维波动方程进行求解。

2. 球面平均法的基本思路

-   定义球面平均值：引入以 M(x,y,z) 为中心、以 r 为半径的球面平均值函数 U_(m)(r,t)，用于求解一般高维波动方程。

-   极限收缩求中心值：当球面半径 r 无限趋于零时，该球面平均值将收敛于中心点 M 处的函数值。
