会议主题：傅里叶变换与偏微分方程求解讲座

发言人：电子科大王君豪

会议摘要：本次讲座讲解了傅里叶变换的局限性、余弦变换定义及多项核心性质，并重点演示了如何利用傅里叶变换求解波动方程、热方程及边界条件问题，最后布置了课后作业。

------------------------------------------------------------------------

一、傅里叶变换基础与局限性

1. 高斯函数的傅里叶变换推导

-   高斯函数变换结果：函数 e^(−a²ω²t) 的傅里叶变换结果为 $\frac{1}{\sqrt{4\pi a^2 t}} e^{-\frac{x^2}{4a^2 t}}$。

-   推导依赖正态分布积分：在推导过程中，利用了概率论中正态分布的积分公式 $\int e^{-\frac{(x-\mu)^2}{2\sigma^2}} dx = \sqrt{2\pi}\sigma$ 来完成配方与化简。

2. 直接积分法的局限性

-   要求绝对可积与指数级衰减：直接通过积分求傅里叶变换，要求原函数在实数域上绝对可积，且在正负无穷远处必须是快速的指数级衰减，不能是线性衰减或多项式衰减。

二、余弦变换与傅里叶变换核心性质

1. 余弦变换定义

-   偶函数降维处理：对于偶函数，其傅里叶变换中的正弦项为零，仅剩余弦项起作用，从而引出余弦变换 f̂_(c)(ω) = ∫₀^(∞)f(x)cos (ωx)dx 及其逆变换公式。

2. 傅里叶变换核心性质

-   线性性：函数线性组合的傅里叶变换等于各函数傅里叶变换的线性组合。

-   卷积定理：两个函数卷积的傅里叶变换等于它们各自傅里叶变换的乘积。

-   导数性质：原函数的一阶导数经过傅里叶变换后，对应像函数乘以 iω；高阶导数则对应乘以 (iω)^(n)。

-   位移与缩放性质：原函数的位移会导致像函数产生指数因子，而原函数的缩放会导致像函数产生对应的缩放与系数调整。

-   积分性质：函数积分的傅里叶变换等于其像函数除以 iω。

三、偏微分方程的傅里叶变换求解

1. 波动方程求解

-   转化为常微分方程：对空间变量 x 进行傅里叶变换，将波动方程 u_(tt) = a²u_(xx) 转化为关于时间 t 的二阶常微分方程 U_(tt) + a²ω²U = 0。

-   利用初值确定通解：结合初值条件 u(x,0) 和 u_(t)(x,0) 的傅里叶变换，解出常微分方程的通解系数，最后通过逆变换还原原函数。

2. 热传导方程求解

-   一阶常微分方程转化：对空间变量 x 进行傅里叶变换，将热方程 u_(t) = a²u_(xx) 转化为一阶常微分方程 U_(t) + a²ω²U = 0。

-   卷积形式还原原函数：解出像函数后，利用卷积定理，将其转化为初始条件与高斯核函数的卷积形式，从而求得原函数的形式解。

3. 半无界问题与边界条件处理

-   半无界问题处理：针对 x > 0 的半无界问题，通过引入偶函数延拓的方式，使得函数在负半轴也有定义，从而满足绝对可积条件以进行傅里叶变换。

-   非零常数边界条件处理：当边界条件为非零常数（如 u(0,t) = c）时，可通过变量代换 v = u − c 将其转化为齐次边界条件进行求解。

4. 梁方程求解

-   转化为四阶常微分方程：对空间变量进行傅里叶变换后，梁方程转化为关于 t 的四阶常微分方程，其像函数的解呈现指数形式。
