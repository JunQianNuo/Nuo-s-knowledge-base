# 单纯形表书写规范

**统一使用判别数（reduced cost）形式。** 方程形式（$w + \sum\gamma_j x_j = \text{RHS}$）不再使用，除非特别说明。

## 目标行格式

- 行标签：`r`（Phase I 和 Phase II 统一）
- 基变量列：$r_j = 0$
- 非基变量列：$r_j = c_j - c_B^\top B^{-1} a_j$（判别数 / reduced cost）
- RHS 列：$-f$（当前目标值的相反数；Phase I 为 $-w$）

## 入基规则（统一）

| | $\min$ 问题 | $\max$ 问题 |
|:--|:--|:--|
| 入基变量 | $r_j$ **最负** | $r_j$ **最大正数** |
| 最优性条件 | 所有非基 $r_j \geq 0$ | 所有非基 $r_j \leq 0$ |

## 行变换

目标行与约束行使用相同的行变换：$r \leftarrow r - r_{\text{pivot}} \times (\text{主元行归一化后})$。

## Phase I 判别数计算

Phase I 目标 $\min w = \sum a_i$，成本向量 $c$ 中人工变量系数为 $1$，其余为 $0$。初始判别数：

$$r_j = c_j - c_B^\top B^{-1} a_j$$

初始基为人工变量（$B = I$，$c_B = [1,\ldots,1]^\top$），直接代入计算。每次换基后通过行变换更新 $r$ 行。

## Phase II 过渡

删除人工变量列，用公式 $r_j = c_j - c_B^\top B^{-1} a_j$ 重算目标行（$c$ 为原问题成本，$c_B$ 为当前基对应的原问题成本）。继续单纯形迭代直至最优。
