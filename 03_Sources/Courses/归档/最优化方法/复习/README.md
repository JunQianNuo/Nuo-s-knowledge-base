## 使用建议

1. **先过一遍复习纲要**：[[../复习纲要-数学|复习纲要]] 列出了所有需要掌握的定义、理论和计算
2. **逐个板块复习**：每个子文件按"定义→理论→计算→典型题→易错点"组织
3. **重点关注证明**：[[复习/常考查的证明|常考查的证明]] 汇总了纲要列出的6个核心证明
4. **回顾知识点梳理**：需要深入理解时，点击文件中的 Wiki-link 回到[[../知识点解析梳理/|知识点解析梳理]]
