# 习题 7.10

**MATLAB 编程实现割线法求根。**

## a. 编写 MATLAB 程序

编写 MATLAB 程序，利用**割线法**求解方程 $g(x) = 0$，迭代的停止规则为：

$$|x^{(k+1)} - x^{(k)}| < \varepsilon\,|x^{(k)}|, \quad \varepsilon > 0 \text{ 为给定常数}$$

其中 $x^{(k)}$ 为第 $k$ 次迭代得到的近似解。

## b. 测试函数

函数 $g(x) = (2x - 1)^2 + 4(4 - 1024x)^4$，利用割线法求解方程 $g(x) = 0$ 的根，初始值为 $x^{(-1)} = 0$，$x^{(0)} = 1$，$\varepsilon = 10^{-5}$，并给出在所求出的根下，函数 $g(x)$ 的值。

---

## 💡 提示

> [!hint]- 点击展开提示
> **割线法迭代格式**（用于求方程 $g(x) = 0$ 的根）：
>
> $$x^{(k+1)} = x^{(k)} - \frac{g(x^{(k)})(x^{(k)} - x^{(k-1)})}{g(x^{(k)}) - g(x^{(k-1)})}$$
>
> 该公式是用**差商** $\frac{g(x^{(k)}) - g(x^{(k-1)})}{x^{(k)} - x^{(k-1)}}$ 替代牛顿法中导数 $g'(x^{(k)})$ 得到的。
>
> **注意**：函数 $g(x) = (2x-1)^2 + 4(4-1024x)^4$ 是两个非负项之和，$g(x) \geq 0$ 恒成立。由于 $(2x-1)^2 = 0$ 时 $x = 1/2$，而 $4(4-1024x)^4 = 0$ 时 $x = 4/1024 = 1/256$，两者零点不重合，故 $g(x) > 0$ 对所有 $x$ 成立，方程 $g(x) = 0$ **没有实根**。割线法会收敛到 $g(x)$ 的**极小点**附近（使两个惩罚项都尽可能小），在 MATLAB 程序中可观察到迭代序列的行为。

---

## 📝 详细解析

> [!solution]- 点击展开详细解析
>
> ### (a) 算法步骤
>
> 割线法求解 $g(x) = 0$ 的算法：
>
> 1. **输入**：初始点 $x^{(-1)}$, $x^{(0)}$，精度 $\varepsilon$，最大迭代次数 $N_{\max}$
> 2. 对 $k = 0, 1, 2, \dots, N_{\max}$：
>    - 计算 $x^{(k+1)} = x^{(k)} - \dfrac{g(x^{(k)})(x^{(k)} - x^{(k-1)})}{g(x^{(k)}) - g(x^{(k-1)})}$
>    - 若 $|x^{(k+1)} - x^{(k)}| < \varepsilon |x^{(k)}|$，**停止**，输出 $x^{(k+1)}$
> 3. 输出结果
>
> MATLAB 代码示例：
>
> ```matlab
> function [x, gx, k] = secant_method(x0, x1, eps, max_iter)
> % x0, x1: 初始值 x^(-1), x^(0)
> % eps: 停止精度
> % max_iter: 最大迭代次数
>
> for k = 0:max_iter
>     g0 = g_func(x0);
>     g1 = g_func(x1);
>     if abs(g1 - g0) < 1e-15
>         warning('分母接近零');
>         break;
>     end
>     x2 = x1 - g1 * (x1 - x0) / (g1 - g0);
>     if abs(x2 - x1) < eps * abs(x1)
>         x = x2;
>         gx = g_func(x);
>         return;
>     end
>     x0 = x1;
>     x1 = x2;
> end
> x = x2;
> gx = g_func(x);
> end
>
> function y = g_func(x)
>     y = (2*x - 1)^2 + 4*(4 - 1024*x)^4;
> end
> ```
>
> ### (b) 数值测试
>
> 调用：`[x, gx, k] = secant_method(0, 1, 1e-5, 100);`
>
> 函数 $g(x) = (2x-1)^2 + 4(4-1024x)^4$ 分析：
>
> - $g(x) \geq 0$ 恒成立
> - $(2x-1)^2 = 0 \iff x = 0.5$
> - $4(4-1024x)^4 = 0 \iff x = 1/256 \approx 0.00390625$
> - $g(x) = 0$ 需要两项同时为零，但零点不重合 → **无实根**
>
> 割线法会尝试平衡两个惩罚项，最终收敛到 $g(x)$ 的极小点附近（约在 $x \approx 0.004 \sim 0.5$ 之间的某个点）。$g(x)$ 在该点的值表示两个平方惩罚项的折中残差。
>
