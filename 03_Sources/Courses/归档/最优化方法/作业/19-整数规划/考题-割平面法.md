# 考题 01 — 割平面法（Gomory Cut）

考虑如下纯整数规划问题：

$$\begin{aligned}
\max \quad & 7x_1 + 9x_2 \\
\text{s.t.} \quad & -x_1 + 3x_2 \leq 6 \\
& 7x_1 + x_2 \leq 35 \\
& x_1, x_2 \geq 0, \; x_1, x_2 \in \mathbb{Z}
\end{aligned}$$

**a.** 将其化为标准形式，用单纯形法求解 LP 松弛，给出最优单纯形表。

**b.** 从最优表中找出一行其右端项非整数，构造 Gomory 割平面。

**c.** 加入割平面约束后重新求解，给出新单纯形表。

**d.** 新解是否为整数解？若否，构造第二个割平面并求解。

---

## 💡 提示

> [!hint]- 点击展开提示
> - 化标准形时加入松弛变量 $x_3, x_4 \geq 0$，目标函数系数保持极大化形式（即检验数 $c_j - z_j$ 形式）。
> - Gomory 割平面：设 LP 最优表中某基本变量的约束行右端为非整数 $b_i$，记 $\lfloor\cdot\rfloor$ 为向下取整，$f_{i0} = b_i - \lfloor b_i \rfloor$，$f_{ij} = a_{ij} - \lfloor a_{ij} \rfloor$。割平面为 $\sum_j f_{ij} x_j \geq f_{i0}$。
> - 割平面使当前 LP 最优解不满足，需用**对偶单纯形法**恢复可行性。
> - 若一次割平面后仍非整数，重复步骤 (b)–(c)。

---

## 📝 详细解析

> [!solution]- 点击展开详细解析
> ### (a) LP 松弛的单纯形求解
>
> 标准形式（极大化）：
>
> $$\begin{aligned}
> \max \quad & 7x_1 + 9x_2 \\
> \text{s.t.} \quad & -x_1 + 3x_2 + x_3 = 6 \\
> & 7x_1 + x_2 + x_4 = 35 \\
> & x_1, x_2, x_3, x_4 \geq 0
> \end{aligned}$$
>
> **初始单纯形表：**
>
> ```
>        x1   x2   x3   x4   RHS
>  x3    -1    3    1    0     6
>  x4     7    1    0    1    35
>  z     -7   -9    0    0     0
> ```
>
> **第一次迭代：** 入基 $x_2$（检验数 $-9$ 最小），比值 $6/3=2,\; 35/1=35$，出基 $x_3$。主元 $a_{12}=3$。
>
> 主行除以 $3$：$(-1/3,\; 1,\; 1/3,\; 0,\; 2)$。
>
> $x_4$ 行减去 $1 \times$ 新主行，$z$ 行减去 $(-9) \times$ 新主行，得：
>
> ```
>        x1      x2      x3      x4      RHS
>  x2   -1/3      1      1/3      0        2
>  x4   22/3      0     -1/3      1       33
>  z    -10       0       3       0       18
> ```
>
> **第二次迭代：** 入基 $x_1$（检验数 $-10$ 最小），仅有 $x_4$ 行系数正，比值 $33/(22/3) = 9/2$，出基 $x_4$。主元 $22/3$。
>
> 主行乘以 $3/22$：$(1,\; 0,\; -1/22,\; 3/22,\; 9/2)$。
>
> $x_2$ 行减去 $(-1/3) \times$ 新主行，$z$ 行减去 $(-10) \times$ 新主行，得 **LP 最优表**：
>
> ```
>        x1   x2     x3       x4      RHS
>  x2     0    1    7/22     1/22      7/2
>  x1     1    0   -1/22     3/22      9/2
>  z      0    0   28/11    15/11      63
> ```
>
> **LP 松弛最优解：** $x_1 = \frac{9}{2} = 4.5,\; x_2 = \frac{7}{2} = 3.5,\; z^* = 63$。
>
> ---
>
> ### (b) 构造 Gomory 割平面
>
> 取 $x_2$ 行：
>
> $$x_2 + \frac{7}{22}x_3 + \frac{1}{22}x_4 = \frac{7}{2} = 3 + \frac{1}{2}$$
>
> 分数部分：$f_{13} = \frac{7}{22},\; f_{14} = \frac{1}{22},\; f_{10} = \frac{1}{2}$。
>
> **Gomory 割：**
>
> $$\frac{7}{22}x_3 + \frac{1}{22}x_4 \geq \frac{1}{2}$$
>
> 引入剩余变量 $x_5 \geq 0$：
>
> $$\frac{7}{22}x_3 + \frac{1}{22}x_4 - x_5 = \frac{1}{2}$$
>
> 两边乘 $-1$ 写入单纯形表（$x_5$ 入基，右端为 $-1/2$）：
>
> ```
>        x1   x2     x3       x4      x5     RHS
>  x2     0    1    7/22     1/22      0      7/2
>  x1     1    0   -1/22     3/22      0      9/2
>  x5     0    0   -7/22    -1/22      1     -1/2
>  z      0    0   28/11    15/11      0       63
> ```
>
> ---
>
> ### (c) 对偶单纯形法求解（第一个割）
>
> $x_5$ 行右端为负，出基 $x_5$。入基：负系数列为 $x_3$（$-7/22$）和 $x_4$（$-1/22$）。
>
> 比值检验（$\frac{\bar{c}_j}{-\bar{a}_{rj}}$，$\bar{a}_{rj} < 0$）：
>
> $$x_3: \frac{28/11}{7/22} = 8, \qquad x_4: \frac{15/11}{1/22} = 30$$
>
> 最小比值为 $8$，$x_3$ 入基。主元 $-7/22$。
>
> 主行乘以 $-22/7$：$(0,\; 0,\; 1,\; 1/7,\; -22/7,\; 11/7)$。
>
> 消元后得：
>
> ```
>        x1   x2   x3     x4       x5      RHS
>  x2     0    1    0      0        1        3
>  x1     1    0    0     1/7     -1/7     32/7
>  x3     0    0    1     1/7    -22/7     11/7
>  z      0    0    0      1        8       59
> ```
>
> **当前解：** $x_1 = 32/7 \approx 4.57,\; x_2 = 3$。$z^* = 59$。
>
> ---
>
> ### (d) 第二个割平面
>
> $x_2 = 3$ 已为整数，但 $x_1 = 32/7 = 4 + 4/7$ 非整数。取 $x_1$ 行：
>
> $$x_1 + \frac{1}{7}x_4 - \frac{1}{7}x_5 = \frac{32}{7} = 4 + \frac{4}{7}$$
>
> 分数部分：
>
> $$f_{14} = \frac{1}{7},\quad f_{15} = \left(-\frac{1}{7}\right) - (-1) = \frac{6}{7},\quad f_{10} = \frac{4}{7}$$
>
> **第二个 Gomory 割：**
>
> $$\frac{1}{7}x_4 + \frac{6}{7}x_5 \geq \frac{4}{7} \quad\Longrightarrow\quad x_4 + 6x_5 \geq 4$$
>
> 加入剩余变量 $x_6 \geq 0$ 并乘以 $-1$：
>
> $$-x_4 - 6x_5 + x_6 = -4$$
>
> 扩表（基变量：$x_2, x_1, x_3, x_6$）：
>
> ```
>        x1   x2   x3   x4     x5     x6     RHS
>  x2     0    1    0    0      1      0       3
>  x1     1    0    0   1/7   -1/7     0     32/7
>  x3     0    0    1   1/7  -22/7     0     11/7
>  x6     0    0    0   -1     -6      1      -4
>  z      0    0    0    1      8      0      59
> ```
>
> **对偶单纯形法：** $x_6$ 出基。入基：$x_4$ 和 $x_5$ 列均负。比值：
>
> $$x_4: \frac{1}{1} = 1,\qquad x_5: \frac{8}{6} = \frac{4}{3}$$
>
> $x_4$ 入基。主元 $-1$。主行乘以 $-1$：$(0, 0, 0, 1, 6, -1, 4)$。
>
> 消元：
>
> - $x_1$ 行减去 $\frac{1}{7}\times$ 新主行：$x_1 - x_5 + \frac{1}{7}x_6 = 4$
> - $x_2$ 行不变（$x_4$ 系数为 0）
> - $x_3$ 行减去 $\frac{1}{7}\times$ 新主行：$x_3 - 4x_5 + \frac{1}{7}x_6 = 1$
> - $z$ 行减去 $1 \times$ 新主行：$z + 2x_5 + x_6 = 55$
>
> **最终表：**
>
> ```
>        x1   x2   x3   x4    x5     x6     RHS
>  x2     0    1    0    0     1      0       3
>  x1     1    0    0    0    -1    1/7       4
>  x3     0    0    1    0    -4    1/7       1
>  x4     0    0    0    1     6     -1       4
>  z      0    0    0    0     2      1      55
> ```
>
> 所有基本变量 $x_1=4, x_2=3, x_3=1, x_4=4$ 均为**非负整数**，且右端非负——已达到整数最优解。
>
> **整数最优解：** $x_1^* = 4,\; x_2^* = 3,\; z^* = 55$。
>
> **验证：**
> - 约束 1：$-4 + 3 \cdot 3 = 5 \leq 6$ $\checkmark$
> - 约束 2：$7 \cdot 4 + 3 = 31 \leq 35$ $\checkmark$
> - 目标值：$7 \cdot 4 + 9 \cdot 3 = 28 + 27 = 55$。
>
> LP 松弛最优值为 $63$，加入两个割平面后降至 $55$，体现了整数约束的代价。$\square$
>
> **点评：** 本题完整展示了 Gomory 分数割平面法的流程：LP 松弛求解 $\to$ 从分数行构造割平面 $\to$ 对偶单纯形恢复可行性 $\to$ 重复至整数解。关键细节：(1) 分数部分 $f_{ij}$ 取值为 $[0, 1)$，负系数如 $-\frac{1}{7}$ 的分数部分为 $1 - \frac{1}{7} = \frac{6}{7}$；(2) 割平面将当前 LP 最优解割去但不割去任何整数可行解；(3) 本题经历了两次割平面才达到整数解，实际应用中可能需要很多轮。
