## 题目

卡诺循环中，高温热源温度 $T_1 = 400\;\mathrm{K}$，低温热源温度 $T_2 = 300\;\mathrm{K}$，一个循环对外作功 $800\;\mathrm{J}$。现只把高温热源温度提高到 $T_1'$，其它条件不变（放热不变），要对外作功 $1000\;\mathrm{J}$，求 $T_1'$ 和此时的效率。

![[images/3299c863d13c1444aaae4b0adfc50345fc036aa5c1ef6a1994989e32492c2d05.jpg]]

![[images/1d8b26e15b59a9f261568b6b659a263c08af61d2f565e66685e7346057390904.jpg]]

> [!hint]- 点击展开提示
> 两过程的共同点：放热 $Q_2$ 不变。先用原始条件求 $Q_2$，再用新功值求新效率和新高温。

> [!solution]- 点击展开详细解析
> **原始条件：**
> $$\eta = 1 - \frac{T_2}{T_1} = 1 - \frac{300}{400} = 0.25 = \frac{A}{A + Q_2}$$
> $$0.25 = \frac{800}{800 + Q_2}, \quad \therefore Q_2 = 2400\;\mathrm{J}$$
>
> **提高高温热源后（放热 $Q_2 = 2400\;\mathrm{J}$ 不变）：**
> $$\eta' = \frac{A'}{A' + Q_2} = \frac{1000}{1000 + 2400} = 0.294 = 29.4\%$$
> $$\eta' = 1 - \frac{T_2}{T_1'} \quad \Rightarrow \quad T_1' = \frac{T_2}{1 - \eta'} = \frac{300}{1 - 0.294} = 425\;\mathrm{K}$$
>
> **答案：** $T_1' = 425\;\mathrm{K}$，$\eta' = 29.4\%$。
>
> **点评：** 提高高温热源温度 $25\;\mathrm{K}$ 就使作功从 $800\;\mathrm{J}$ 提升到 $1000\;\mathrm{J}$（增加 $25\%$），体现了"提高高温热源温度是提高热机效率的有效途径"。
>
