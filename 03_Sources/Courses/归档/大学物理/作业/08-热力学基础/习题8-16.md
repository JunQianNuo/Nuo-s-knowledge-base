## 题目

在图8-26所示的温熵图（T-S图）中，$B$ 点温度是 $C$ 点温度的 $n$ 倍，求此循环的效率。

![[images/1534ad15bbbc51b8a2c5fd244f0c7de027718ad23c87965cd3a76e907989f1bb.jpg]]

> [!hint]- 点击展开提示
> 在 T-S 图中，可逆过程的吸热量 = 过程曲线下的面积。$T\;\mathrm{d}S = \mathrm{d}Q$。

> [!solution]- 点击展开详细解析
> 由热力学基本关系：$T\;\mathrm{d}S = \mathrm{d}Q = \mathrm{d}E + p\;\mathrm{d}V$
>
> 在 T-S 图中，曲线下的面积 $= \int T\;\mathrm{d}S = \int \mathrm{d}Q$，即可逆过程的吸热量。
>
> **$AB$（等温过程）：**
> $$Q_1 = T_A (S_2 - S_1) > 0 \quad \text{(吸热)}$$
>
> **$BC$（绝热过程，等熵）：**
> $$\text{不吸热}$$
>
> **$CA$（放热过程，熵减少）：**
> $$Q_2 = \frac{1}{2}(T_C + T_A)(S_2 - S_1) \quad \text{(放热)}$$
>
> 已知 $T_A = T_B$（等温），$T_B = n T_C$，故 $T_A = n T_C$：
> $$\eta = 1 - \frac{Q_2}{Q_1} = 1 - \frac{\frac{1}{2}(T_C + nT_C)}{nT_C} = 1 - \frac{n+1}{2n} = \frac{n-1}{2n}$$
>
> **答案：** $\eta = \frac{n-1}{2n}$。
>
> **点评：** T-S 图（温熵图）的优点是吸放热量直接等于曲线下面积，无需分别计算功和内能变化。$CA$ 过程为直线，其下面积用梯形公式计算。这是"示热图"的应用。
>
