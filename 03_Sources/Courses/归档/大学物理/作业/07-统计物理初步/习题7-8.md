## 题目正文

如图，容器两边是同种气体，左边的压强、温度、体积分别是 $p_{1}$、$T_{1}$、$V$，右边的压强、温度、体积分别是 $p_{2}$、$T_{2}$、$V$；抽去中间的隔板，让两边的气体混合（设混合过程中气体与外界无能量交换），求平衡时的压强和温度。

---

> [!hint]- 点击展开提示
> 混合过程与外界无能量交换 → **内能守恒**：混合前总内能 = 混合后总内能。同种气体，$i$ 相同，可直接从 $E = \frac{i}{2}pV$ 入手。
>
> 混合后总体积为 $2V$，总物质的量为 $\nu_{1} + \nu_{2}$。用 $p(2V) = (\nu_{1} + \nu_{2})RT$ 求温度，或直接消元。

> [!solution]- 点击展开详细解析
> **解**：
>
> 因混合过程中气体与外界无能量交换，混合前后气体的内能不变。由内能公式 $E = \frac{i}{2}pV$，同种气体 $i$ 相同：
>
> $$\frac{i}{2}p_{1}V + \frac{i}{2}p_{2}V = \frac{i}{2}p(2V)$$
>
> 消去 $\frac{i}{2}$ 和 $V$，得平衡压强：
>
> $$p = \frac{1}{2}(p_{1} + p_{2})$$
>
> 又由理想气体状态方程：
>
> $$p_{1}V = \nu_{1}RT_{1},\quad p_{2}V = \nu_{2}RT_{2}$$
>
> 混合后总体积 $2V$，总物质的量 $\nu_{1} + \nu_{2}$：
>
> $$p(2V) = (\nu_{1} + \nu_{2})RT$$
>
> 将 $\nu_{1} = \dfrac{p_{1}V}{RT_{1}}$、$\nu_{2} = \dfrac{p_{2}V}{RT_{2}}$ 和 $p = \dfrac{p_{1}+p_{2}}{2}$ 代入：
>
> $$\frac{p_{1}+p_{2}}{2} \cdot 2V = \left(\frac{p_{1}V}{RT_{1}} + \frac{p_{2}V}{RT_{2}}\right)RT$$
>
> $$(p_{1}+p_{2})V = \left(\frac{p_{1}}{T_{1}} + \frac{p_{2}}{T_{2}}\right)VT$$
>
> $$T = \frac{p_{1} + p_{2}}{\dfrac{p_{1}}{T_{1}} + \dfrac{p_{2}}{T_{2}}}$$
>
> $\square$
>
> **答案**：平衡压强 $p = \dfrac{1}{2}(p_{1} + p_{2})$；平衡温度 $T = \dfrac{p_{1} + p_{2}}{\dfrac{p_{1}}{T_{1}} + \dfrac{p_{2}}{T_{2}}}$。
>
> **点评**：本题有两个关键：(1) 内能守恒（因绝热且无宏观位移功——隔板抽去不做功）；(2) 最终压强可直接从内能公式 $E = \frac{i}{2}pV$ 一步得到，非常简洁。注意 $T$ 的表达式不是 $T_{1}$ 和 $T_{2}$ 的简单平均，而是以 $p/T$ 为权的调和平均型。
>
