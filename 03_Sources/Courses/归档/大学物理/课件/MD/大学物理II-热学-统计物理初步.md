## 7-1 热力学系统与平衡态

## 7.1.1 热力学系统

热力学系统（简称系统）：在给定范围内，由大量微观粒子所组成的宏观客体。热力学中将研究对象称为系统。

系统的外界（简称外界）：能够与所研究的热力学系统发生相互作用的其它物体。系统周围的，与之相关联的部分称为外界（环境）。

系统与外界要根据实际情况进行分析。

## 7.1.2 平衡态

热力学系统所处的状态取决于初始状态和外界环境的影响。

系统处于恒定外界影响下，经过一定时间后系统将达到宏观性质不随时间变化而变化的状态，称为定态。

特别的，对于孤立系统而言，无论系统初始状态如何，经过一段时间后必将达到一种定态。这种定态中不仅系统宏观性质不变，而且系统内部不存在能量和质量的宏观流动，整个系统达到统一温度，这种定态称为热力学平衡态。

平衡态一定是定态，定态不一定是平衡态。

## 讨论-对平衡态的理解：

1. 平衡态不是孤立系统独有的性质，开放系统和封闭系统也可以达到平衡态（但此时可以视为孤立系统，因为没有物质和能量的流动与交换）；

2.平衡态的标志：系统与环境无能量和物质交换且内部无宏观过程。

3.系统宏观性质不随时间变化，微观热运动不停。动态平衡（热动平衡）

4.理想情况，可以近似；

5.受到外界影响状态发生改变

## 7.1.3 状态与状态参量

状态：系统在某一时刻的宏观或微观特性的完整描述。根据描述层次的不同，状态可以分为宏观状态和微观状态。

微观参量：描述单个粒子的物理量，包括质量、位置、速度、能量等；

宏观参量：描述系统性质的参量，包括压强、体积、温度等；

宏观参量只有在平衡态条件下才有实际意义（满足某些关系）。

对于非平衡过程，可以描述其某个状态（例如体积、压强等），但是没有实际意义（参量之间没有关系）。

过程：系统受到外界影响，从某一状态到另一状态所经历的一系列变化称为热力学过程。

## 统计物理初步

## 状态参量

描述平衡态下系统宏观属性的一组独立宏观量即为状态参量。

分为：广延量（整个系统的参量值等于系统中各部分相应参量值的和）和强度量（可在系统内逐点测量，不累加）。

气体处于平衡态的标志是状态参量p、V、T处处相同且不随时间变化。

当状态参量确定后，其他宏观量可以用状态量表示，这些宏观量称为态函数。

常用的状态参量有：

几何参量（如：气体体积）

力学参量（如：气体压强）

热学参量（如：温度）

化学参量 （如：混合气体各化学组分的质量和摩尔数等）

电磁参量 （如：电场和磁场强度，电极化和磁化强度等）

## 统计物理初步

如果在所研究的问题既不涉及电磁性质又无须考虑与化学成分有关的性质，系统中也不发生化学反应，则不必引入电磁参量和化学参量。此时只需体积和压强就可确定系统的平衡态，我们称这种系统为简单系统（或 $\mathbf { \dot { p } - V }$ 系统）。大学物理中热力学与统计物理章节处理的都是这类简单系统的问题。对于这类系统，我们最关心三个核心参量温度（T）、体积（V）、压强（p）及其他们之间的关系。

关于温度的讨论：

1. 温度是热学中特有的物理量，它决定一系统是否与其他系统处于热平衡。处于热平衡的各系统温度相同。

2. 温度是状态参量，在实质上反映了组成系统大量微观粒子无规则运动的激烈程度（温度的微观意义，后续将在温度的微观意义部分讨论）。

## §7-2 理想气体的微观模型、压强和温度的统计意义

## 7.2.1 理想气体模型：

早期对实际气体进行实验中发现一些近似规律，进而对实际气体进行理想化：

1. 气体分子本身尺度与分子间距相比可忽略，即忽略分子体积。

2. 除分子分子之间、分子器壁之间的碰撞外，其他相互作用忽略。

3. 分子分子之间、分子器壁之间为完全弹性碰撞，无能量损失。

概括：将气体分子理想化为极小的、无相互作用的弹性小球。气体越稀薄越接近。

## §7-4 麦克斯韦气体分子速率分布律

气体分子热运动的一个重要特征是分子间存在频繁的碰撞(每秒钟要碰撞约上百亿次！)。由于频繁的碰撞，分子的速率在不断地改变着。因此，在某一个特定的时刻去观察某个特定的分子，它的速度具有怎样的量值和方向，那完全是偶然的，也是毫无意义的。

然而在平衡态下，就大量分子而言，分子的速率分布却遵循确定的统计规律。这是1859年麦克斯韦首先应用统计概念导出的，称为麦克斯韦速率分布定律。

## 7.4.1 麦克斯韦速率分布定律

理想气体处于温度T的平衡态时，在速率区间υ—υ+dv内的分子数为

$$
\mathrm{d} \mathbf {N} = \mathbf {N f (v)} \mathrm{d} v\tag{7-9}
$$

这就是麦克斯韦速率分布定律。

式中N为分子总数，f()称为麦克斯韦速率分布函数，它为

$$
f (\nu) = 4 \pi (\frac {m}{2 \pi k T}) ^ {\frac {3}{2}} \nu^ {2} e ^ {- \frac {m v ^ {2}}{2 k T}}\tag{7-10}
$$

式中：m是气体分子的质量, k是玻耳兹曼常数。

## 2.平均速率

速率区间0—内分子(全体分子)的平均速率为

$$
\bar {\upsilon} = \frac {\int_ {0} ^ {\infty} \upsilon f (\upsilon) d \upsilon}{\int_ {0} ^ {\infty} f (\upsilon) d \upsilon} = \int_ {0} ^ {\infty} \upsilon f (\upsilon) d \upsilon \qquad \int_ {0} ^ {\infty} f (\upsilon) d \upsilon = 1
$$

完成积分，求得平均速率为

$$
v _ {\mathrm{p}} = \sqrt {\frac {8 R T}{\pi M _ {\mathrm{mol}}}}\tag{7-13}
$$

解 速率区间υ一υ+dv内的分子数： $\scriptstyle \mathbf { d N } = \mathbf { N f } ( \mathbf { \boldsymbol { v } } ) \mathbf { d \boldsymbol { v } }$

速率区间υ一υ+dv内的分子速率之和：

$\boldsymbol { \mathsf { \upsilon } } \mathbf { d N } = \boldsymbol { \mathsf { N } } \mathbf { \upsilon } \mathbf { f } ( \boldsymbol { \mathsf { \upsilon } } ) \mathbf { d } \boldsymbol { \mathsf { \upsilon } }$ 速率区间 $| \mathsf { v } _ { 1 } - \mathsf { v } _ { 2 }$ 内分子速率之和: $\int _ { \upsilon _ { 1 } } ^ { \upsilon _ { 2 } } N \upsilon f ( \upsilon ) d \upsilon$

$$
\bar {v} _ {v _ {1} \rightarrow v _ {2}} = \frac {\int_ {v _ {1}} ^ {v _ {2}} v f (v) d v}{\int_ {v _ {1}} ^ {v _ {2}} f (v) d v}
