定义3.1.7 设 若 和 中至少有一个是可积的，则称

$$
\int_ {E} f (x) d x = \int_ {E} f ^ {+} (x) d x - \int_ {E} f ^ {-} (x) d x
$$

为 在 上的积分。当上式右端两个积分值都有限时，称 在 上是Lebesgue可积的（简称可积的），或称 是 上的可积函数。

在 上的全体可积函数记为

$$
f ^ {+} = \max (0, f), f ^ {-} = \max (- f, 0), f = f ^ {+} - f ^ {-}, | f | = f ^ {+} + f ^ {-}.
$$

$$
f ^ {+} \in L (E), f ^ {-} \in L (E) \Longleftrightarrow f \in L (E). \qquad \int_ {E} | f | d x = \int_ {E} f ^ {+} d x + \int_ {E} f ^ {-} d x.
$$

$$
\therefore f ^ {+} \in L (E), f ^ {-} \in L (E) \Leftrightarrow f \in L (E) \Leftrightarrow | f | \in L (E).
$$

$$
\left| \int_ {E} f (x) d x \right| \leq \int_ {E} | f (x) | d x.
$$

可积即为绝对可积!

（与黎曼积分不同！）

定理3.1.9 （积分的线性性质） 设 $g \in L ( E ) , \alpha \in \mathbb { R }$ 则

$$
\alpha f \in L (E), f + g \in L (E),
$$

$$
\int_ {E} \alpha f d x = \alpha \int_ {E} f d x, \quad \int_ {E} f + g d x = \int_ {E} f d x + \int_ {E} g d x.
$$

证明 不妨设 $f ( x ) , g ( x )$ 处处有限。（避免处理 $\infty - \infty$ 。可以除去一个零测集）

(1) ${ \mathrm { I f ~ } } \alpha \geq 0 , { \mathrm { w e ~ s e e ~ t h a t ~ } } ( \alpha f ) ^ { + } = \alpha f ^ { + } , ( \alpha f ) ^ { - } = \alpha f ^ { - } { \mathrm { ~ a n d ~ } }$

$$
\begin{array}{l} \int_ {E} \alpha f d x = \int_ {E} \alpha f ^ {+} d x - \int_ {E} \alpha f ^ {+} d x \\ = \alpha \left(\int_ {E} f ^ {+} d x - \int_ {E} f ^ {-} d x\right) = \alpha \int_ {E} f d x. \\ \end{array}
$$

The case of $\alpha < 0$ is similar.

(2) From $| f + g | \leq | f | + | g |$ ， we know that $f + g \in L ( E )$

In view of $( f + g ) ^ { + } - ( f + g ) ^ { - } = f + g = f ^ { + } - f ^ { - } + g ^ { + } - g ^ { - }$ ， we have

$$
(f + g) ^ {+} + f ^ {-} + g ^ {-} = (f + g) ^ {-} + f ^ {+} - f ^ {-} + g ^ {+}.
$$

（利用非负可测函数的积分的线性性质）

$$
\int_ {E} (f + g) ^ {+} d x + \int_ {E} f ^ {-} d x + \int_ {E} g ^ {-} d x = \int_ {E} (f + g) ^ {-} d x + \int_ {E} f ^ {+} d x + \int_ {E} g ^ {+} d x,

$$
