## 题目正文

证明 $A = \{(x_1, x_2, \cdots) : x_i \in \mathbb{R},\ i = 1,2,\cdots\}$ 的基数是 $c$。

## 提示

> [!hint]- 点击展开提示
> $|A| = |\mathbb{R}^{\mathbb{N}}| = c^{\aleph_0} = (2^{\aleph_0})^{\aleph_0} = 2^{\aleph_0} = c$。

## 详细解析

> [!solution]- 点击展开详细解析
> $\mathbb{R}$ 的基数为 $c = 2^{\aleph_0}$。$A = \mathbb{R}^{\mathbb{N}}$ 是 $\mathbb{R}$ 的可数个拷贝的笛卡尔积。
>
> $$|A| = |\mathbb{R}|^{\aleph_0} = c^{\aleph_0} = (2^{\aleph_0})^{\aleph_0} = 2^{\aleph_0 \cdot \aleph_0} = 2^{\aleph_0} = c.$$
>
> 或者更直接：$\mathbb{R}^\mathbb{N}$ 与 $\mathbb{R}$ 之间存在一一对应（可由 $\mathbb{R} \cong (0,1)^\mathbb{N}$ 及十进制展开构造）。
>
> $\square$
