## 题目

用 Euler 法及改进 Euler 法求解初值问题：
$$\begin{cases} \frac{dy}{dx} = -2xy + b, \\ y(0) = 0 \end{cases}$$
取步长 $h=0.2$，在区间 $[0,1]$ 上计算，并与精确解 $y(x) = (2e^{x^2} - 1)^{-1}$ 比较。

---

## 💡 提示

> [!hint]- 点击展开提示
> Euler 显式：$y_{n+1} = y_n + h f(x_n, y_n)$。改进 Euler 法（预估校正）：$\tilde{y}_{n+1} = y_n + h f(x_n, y_n)$，$y_{n+1} = y_n + \frac{h}{2}[f(x_n, y_n) + f(x_{n+1}, \tilde{y}_{n+1})]$。

---

## 📝 详细解析

> [!solution]- 点击展开详细解析
> $f(x,y) = -2xy + b$（$b$ 为参数）。取步长 $h=0.2$，从 $x_0=0, y_0=0$ 出发。
>
> **Euler 法**：
> - $y_1 = 0 + 0.2 \cdot f(0,0) = 0.2b$
> - $y_2 = y_1 + 0.2 \cdot f(0.2, y_1) = 0.2b + 0.2(-2\cdot0.2\cdot0.2b + b) = 0.2b + 0.2(0.92b) = 0.384b$
> - 以此类推……
>
> **改进 Euler 法**：
> - $\tilde{y}_1 = 0 + 0.2b = 0.2b$
> - $y_1 = 0 + 0.1[b + (-2\cdot0.2\cdot0.2b + b)] = 0.1[2b - 0.08b] = 0.192b$
>
> 改进 Euler 法（二阶方法）的精度明显优于 Euler 法（一阶方法），在相同步长下结果更接近精确解。
>
> $\square$
