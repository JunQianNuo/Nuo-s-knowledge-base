## 单选题

下列陈述正确的命题是()

若 $P\{X \leqslant 1\} = P\{X \geqslant 1\}$ ，则 $P\{X \leqslant 1\} = \frac{1}{2}$ 若 $X \sim b(n, p)$ ，则 $P\{X = k\} = P\{X = n - k\}, k = 0, 1, 2, \ldots, n$ 若X服从正态分布，则 $F(x) = 1 - F(-x)$ $\lim_{x \to +\infty} [F(x) + F(-x)] = 1$

> [!hint]- 点击展开提示
> 逐一验证每个命题是否"无条件成立"。A需要注意单点概率的影响；B要求 $p=1/2$ 才成立；C要求正态分布的均值为0；D则对所有分布函数都成立。

> [!solution]- 点击展开详细解析
> **解**：逐一分析四个命题：
> 
> **A**："若 $P\{X \leqslant 1\} = P\{X \geqslant 1\}$，则 $P\{X \leqslant 1\} = \dfrac{1}{2}$。"
> 
> 记 $p_0 = P\{X = 1\}$。由 $P\{X \leqslant 1\} = P\{X < 1\} + p_0$，$P\{X \geqslant 1\} = p_0 + P\{X > 1\}$，且 $P\{X < 1\} + p_0 + P\{X > 1\} = 1$。
> 由条件 $P\{X \leqslant 1\} = P\{X \geqslant 1\}$ 得 $P\{X < 1\} = P\{X > 1\}$。
> 代入全概率：$2P\{X < 1\} + p_0 = 1$，故 $P\{X \leqslant 1\} = P\{X < 1\} + p_0 = \dfrac{1 + p_0}{2}$。
> 仅当 $p_0 = 0$ 时 $P\{X \leqslant 1\} = \frac{1}{2}$，若 $X$ 在1处有概率质量则不成立。（反例：$P\{X=1\}=1$，则 $P\{X \leqslant 1\} = P\{X \geqslant 1\} = 1 \neq \frac{1}{2}$。）✗
> 
> **B**："若 $X \sim B(n, p)$，则 $P\{X = k\} = P\{X = n-k\},\,k=0,1,\dots,n$。"
> 
> $P\{X=k\} = C_n^k p^k (1-p)^{n-k}$，$P\{X=n-k\} = C_n^{n-k} p^{n-k} (1-p)^k$。
> 由 $C_n^k = C_n^{n-k}$，相等要求 $p^k(1-p)^{n-k} = p^{n-k}(1-p)^k$，即 $p^{2k-n} = (1-p)^{2k-n}$，对任意 $k$ 成立仅当 $p = \frac{1}{2}$。一般情形不成立。✗
> 
> **C**："若 $X$ 服从正态分布，则 $F(x) = 1 - F(-x)$。"
> 
> 设 $X \sim N(\mu, \sigma^2)$，则 $F(x) = \Phi\!\left(\frac{x-\mu}{\sigma}\right)$。$1 - F(-x) = 1 - \Phi\!\left(\frac{-x-\mu}{\sigma}\right)$。
> 仅当 $\mu = 0$ 时，$\Phi\!\left(\frac{x}{\sigma}\right) = 1 - \Phi\!\left(-\frac{x}{\sigma}\right)$ 成立；若 $\mu \neq 0$（如 $X \sim N(1,1)$，$F(1) \approx 0.5$ 而 $1-F(-1) \approx 0.977$），等式不成立。✗
> 
> **D**："$\lim_{x \to +\infty} [F(x) + F(-x)] = 1$。"
> 
> 对任意分布函数，$\lim_{x \to +\infty} F(x) = 1$，$\lim_{x \to +\infty} F(-x) = \lim_{t \to -\infty} F(t) = 0$。
> 因此 $\lim_{x \to +\infty} [F(x) + F(-x)] = 1 + 0 = 1$。**无条件成立。** ✓
> 
> **答案**：D
> 
> **点评**：本题考察分布函数的基本性质与常见分布的特性。D实质上就是分布函数的两条基本极限性质之和，是唯一无需附加条件即成立的命题。$\square$
