## 9/9 证明/计算/分析题

在长为 L 的线段上随机选取一点，将其分为两段，求短的一段与长的一段之比小于 1/4 的概率.


> [!hint]- 点击展开提示
> 设分点距左端距离 $X \sim U(0, L)$。两段长度为 $X$ 和 $L-X$。利用对称性，只需考虑 $X \in [0, L/2]$ 的情况再乘以2，或用几何概型直接求满足条件的区间长度占总长的比例。

> [!solution]- 点击展开详细解析
> **解**：设分点距线段左端距离为 $X$，则 $X \sim U(0, L)$。两段长度分别为 $X$ 和 $L - X$。
> 
> 短段为 $\min(X, L-X)$，长段为 $\max(X, L-X)$。
> 
> 所需求概率为：
> $$P\left\{\frac{\min(X, L-X)}{\max(X, L-X)} < \frac{1}{4}\right\}$$
> 
> 分两种情况讨论：
> 
> **情况1**：$0 \leqslant X \leqslant \dfrac{L}{2}$（此时短段为 $X$，长段为 $L-X$）
> 
> $$\frac{X}{L-X} < \frac{1}{4} \;\Longrightarrow\; 4X < L - X \;\Longrightarrow\; 5X < L \;\Longrightarrow\; X < \frac{L}{5}$$
> 
> 故在该区间内，满足条件的 $X$ 范围为 $\big[0, \frac{L}{5}\big)$。
> 
> **情况2**：$\dfrac{L}{2} < X \leqslant L$（此时短段为 $L-X$，长段为 $X$）
> 
> $$\frac{L-X}{X} < \frac{1}{4} \;\Longrightarrow\; 4(L-X) < X \;\Longrightarrow\; 4L - 4X < X \;\Longrightarrow\; 4L < 5X \;\Longrightarrow\; X > \frac{4L}{5}$$
> 
> 故在该区间内，满足条件的 $X$ 范围为 $\big(\frac{4L}{5}, L\big]$。
> 
> 综上，满足条件的总区域为 $[0, \frac{L}{5}) \cup (\frac{4L}{5}, L]$，总长度为 $\frac{L}{5} + \frac{L}{5} = \frac{2L}{5}$。
> 
> 由几何概型：
> $$P = \frac{\text{有利区域长度}}{\text{总长度}} = \frac{2L/5}{L} = \frac{2}{5}$$
> 
> **答案**：$\dfrac{2}{5}$（即 $0.4$）
> 
> **点评**：本题是典型的几何概型问题。关键是正确表达"短段与长段之比小于1/4"的数学不等式，并在区间$[0,L]$上找出对应解集。左右对称性使得两段有利区间长度相等，简化了计算。$\square$
