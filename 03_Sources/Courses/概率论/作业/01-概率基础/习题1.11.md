若 $AB \subset C$ ，则必有：

> [!hint]- 点击展开提示
> $AB \subset C$ 的集合含义：若 $\omega$ 同时属于 $A$ 和 $B$，则 $\omega$ 必属于 $C$。由此可通过概率单调性得到 $P(AB) \le P(C)$；也可以导出 $P(A \cup B) \le 1 + P(C) - P(A \cap B)$ 等关系。

> [!solution]- 点击展开详细解析
> **条件分析**：$AB \subset C$ 意味着 $A \cap B \subseteq C$，即同时发生的事件 $A$ 和 $B$ 一定被事件 $C$ 覆盖。
>
> **由集合包含可推出的结论**：
>
> 1. **概率单调性**：$AB \subset C \;\Rightarrow\; P(AB) \le P(C)$。
>
> 2. **等价条件**：$AB \cap \overline{C} = \varnothing$，即 $A, B, \overline{C}$ 三者不可能同时发生。换言之 $P(AB\overline{C}) = 0$。
>
> 3. **关系 $P(A \cup B) \le P(C) + P(A \triangle B)$**（其中 $A \triangle B$ 为对称差）：不太常用，但从包含关系可推导。
>
> 4. **一个重要但易错的推论**：$AB \subset C$ **不**等价于 $A \subset C$ 或 $B \subset C$。例如：$A = \{1,2\}$，$B = \{2,3\}$，$C = \{2\}$，则 $A \cap B = \{2\} \subset C$，但 $A \not\subset C$。
>
> **常见选择题选项判断**（原题选项未完整转录，以下分析典型选项）：
> - $P(AB) \le P(C)$：**正确**，由 $AB \subset C$ 结合概率单调性即得。
> - $P(A \cup B) \le P(C)$：一般**不成立**，反例：$A = \Omega, B = \Omega, C = \Omega$ 满足 $AB = \Omega \subset \Omega = C$，此时 $P(A \cup B)=1 = P(C)$ 恰好成立；但取 $A = \Omega, B = \Omega, C = \{ \omega_0 \}$ 且 $P(\{\omega_0\}) < 1$，则 $AB=\Omega \not\subset C$，原条件不满足。若条件满足（$AB \subset C$），取概率空间使 $A, B$ 几乎占据整个空间而 $C$ 很小，条件要求 $A \cap B \subset C$，这强迫 $P(A \cap B) \le P(C)$，但不能约束 $P(A \cup B)$ 的上界。
> - $P(A) + P(B) \le 1 + P(C)$：由 $P(A)+P(B) = P(A\cup B) + P(AB) \le 1 + P(C)$，因 $P(A\cup B) \le 1$ 且 $P(AB) \le P(C)$。**正确**。
>
> 具体答案需对照原截图中的选项确定。
>
> **点评**：$AB \subset C$ 是最基础的集合包含关系之一，核心结论是 $P(AB) \le P(C)$。注意区分"集合包含"与"概率比较"——前者是确定性的集合论关系，后者是数值不等式。$\square$
