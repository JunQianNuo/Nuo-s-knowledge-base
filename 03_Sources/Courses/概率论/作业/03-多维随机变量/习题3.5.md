## 5/5 证明/计算/分析题

已知联合分布律，求联合分布函数

设随机变量 $X$ 和 $Y$ 的联合概率分布律如下： $P(X = 0, Y = 0) = 0.1, P(X = 0, Y = 1) = 0.3, P(X = 1, Y = 0) = 0.4, P(X = 1, Y = 1) = 0.2$ 。求联合分布函数 $F(x, y) = P(X \leq x, Y \leq y)$


> [!hint]- 点击展开提示
> 联合分布函数 $F(x,y)=P(X\le x, Y\le y)$ 等于满足 $X \le x$ 且 $Y \le y$ 的 $(X,Y)$ 取值点上的概率之和。对离散型随机变量，将 $(x,y)$ 平面按 $X=0,1$ 和 $Y=0,1$ 划分为若干区域，在每个区域内 $F(x,y)$ 为常数。注意分段条件和各区域对应的概率累积。

> [!solution]- 点击展开详细解析
> **求解**：$F(x,y) = P(X \le x, Y \le y) = \sum\limits_{x_i \le x} \sum\limits_{y_j \le y} P(X=x_i, Y=y_j)$。
>
> 已知联合分布律：
>
> | $(X,Y)$ | $(0,0)$ | $(0,1)$ | $(1,0)$ | $(1,1)$ |
> |:--|:--|:--|:--|:--|
> | 概率 | $0.1$ | $0.3$ | $0.4$ | $0.2$ |
>
> 分段讨论：
>
> (1) $x < 0$ 或 $y < 0$：$F(x,y)=0$
>
> (2) $0 \le x < 1$ 且 $0 \le y < 1$：只有 $(X,Y)=(0,0)$ 满足条件，$F(x,y)=0.1$
>
> (3) $0 \le x < 1$ 且 $y \ge 1$：满足 $X \le x < 1$（即 $X=0$）且 $Y \le y$（即 $Y=0$ 或 $Y=1$），$F(x,y)=P(X=0,Y=0)+P(X=0,Y=1)=0.1+0.3=0.4$
>
> (4) $x \ge 1$ 且 $0 \le y < 1$：满足 $X \le x$（即 $X=0$ 或 $X=1$）且 $Y \le y$（即 $Y=0$），$F(x,y)=P(X=0,Y=0)+P(X=1,Y=0)=0.1+0.4=0.5$
>
> (5) $x \ge 1$ 且 $y \ge 1$：所有点均满足，$F(x,y)=1$
>
> 综上：
> $$F(x,y) = \begin{cases}
> 0, & x<0 \text{ 或 } y<0 \\[4pt]
> 0.1, & 0 \le x < 1,\; 0 \le y < 1 \\[4pt]
> 0.4, & 0 \le x < 1,\; y \ge 1 \\[4pt]
> 0.5, & x \ge 1,\; 0 \le y < 1 \\[4pt]
> 1, & x \ge 1,\; y \ge 1
> \end{cases}$$
>
> **点评**：离散型联合分布函数是阶梯函数，由 $X$ 和 $Y$ 的取值点将平面划分为若干矩形区域，每个区域内函数值为常数。画出示意图有助于理解。
> $\square$
