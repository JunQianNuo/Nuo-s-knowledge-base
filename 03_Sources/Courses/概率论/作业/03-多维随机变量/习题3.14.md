## 2/3 证明/计算/分析题

设随机变量 $X \sim U(0, 1)$ , 当 $X = x (0 < x < 1)$ 时, Y 在 $(x, 1)$ 上服从均匀分布, 求 $(X, Y)$ 的联合概率密度以及关于Y的边缘概率密度。


> [!hint]- 点击展开提示
> 联合密度由 $f(x,y)=f_X(x)\cdot f_{Y|X}(y|x)$ 求得。$X\sim U(0,1)$ 故 $f_X(x)=1\,(0<x<1)$；给定 $X=x$ 时 $Y\sim U(x,1)$，故 $f_{Y|X}(y|x)=\frac{1}{1-x}\,(x<y<1)$。联合支撑集为 $0<x<y<1$。$f_Y(y)=\int_0^y f(x,y)\,dx$，注意积分上限受 $x<y$ 约束。

> [!solution]- 点击展开详细解析
> **(1) 联合概率密度**
>
> $X \sim U(0,1)$，边缘密度：
> $$f_X(x) = 1,\quad 0 < x < 1$$
>
> 给定 $X=x$ 时 $Y \sim U(x, 1)$，条件密度：
> $$f_{Y|X}(y|x) = \frac{1}{1-x},\quad x < y < 1$$
>
> 联合密度：
> $$f(x,y) = f_X(x) \cdot f_{Y|X}(y|x) = 1 \cdot \frac{1}{1-x} = \frac{1}{1-x}, \quad 0 < x < y < 1$$
> 其余区域 $f(x,y)=0$。
>
> **(2) $Y$ 的边缘密度**
>
> $$f_Y(y) = \int_{-\infty}^{\infty} f(x,y)\,dx = \int_{0}^{y} \frac{1}{1-x}\,dx, \quad 0 < y < 1$$
>
> 计算：
> $$\int_{0}^{y} \frac{1}{1-x}\,dx = \left[-\ln(1-x)\right]_{0}^{y} = -\ln(1-y)$$
>
> 故：
> $$f_Y(y) = \begin{cases} -\ln(1-y), & 0 < y < 1 \\ 0, & \text{其他} \end{cases}$$
>
> **(3) 验证**
>
> $$\int_{0}^{1} -\ln(1-y)\,dy = \left[(1-y)\ln(1-y) + y\right]_{0}^{1} = 1$$
> 归一化成立。$\checkmark$
>
> **点评**：注意联合支撑集 $0<x<y<1$（三角形），积分时 $x$ 的上限是 $y$ 而非 $1$，这是因为对固定的 $y$，$x$ 取值范围被条件 $x<y$ 限制。这是一个容易出错的地方。
> $\square$
