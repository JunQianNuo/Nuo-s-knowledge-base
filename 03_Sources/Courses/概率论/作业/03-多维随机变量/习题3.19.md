## 4/7 证明/计算/分析题

若 $\xi, \eta$ 为相互独立的分别服从 [0.1] 均匀分布的随机变量，试求 $\zeta = \xi + \eta$ 的分布密度函数。

> [!hint]- 点击展开提示
> 两个独立随机变量和的密度由卷积公式给出：$p_\zeta(z) = \int_{-\infty}^{\infty} p_\xi(x) p_\eta(z-x)\,dx$。由于 $\xi,\eta\in[0,1]$，$z-x$ 需满足 $0\le z-x\le 1$，即 $\max(0,z-1)\le x\le\min(1,z)$。分 $z\in[0,1]$ 和 $z\in[1,2]$ 两段积分，结果为三角形密度。

> [!solution]- 点击展开详细解析
> **流程图**：
> ```mermaid
> flowchart TD
>   A[卷积公式] --> B[确定被积函数非零区间]
>   B --> C{判断z的范围}
>   C -->|z在0到1| D[积分从0到z得z]
>   C -->|z在1到2| E[积分从z减1到1得2减z]
>   C -->|z小于0或大于2| F[密度为0]
>   D --> G[得三角形分布]
>   E --> G
>   F --> G
> ```
>
> $\xi,\eta$ 独立同分布于 $U[0,1]$，密度函数：
> $$p_\xi(x) = \begin{cases} 1, & 0 \le x \le 1 \\ 0, & \text{其他} \end{cases}, \quad p_\eta(y) = \begin{cases} 1, & 0 \le y \le 1 \\ 0, & \text{其他} \end{cases}$$
>
> $\zeta = \xi + \eta$ 的密度由卷积公式给出：
> $$p_\zeta(z) = \int_{-\infty}^{\infty} p_\xi(x)\,p_\eta(z-x)\,dx$$
>
> 被积函数非零需满足：
> $$0 \le x \le 1 \quad \text{且} \quad 0 \le z-x \le 1 \quad \Rightarrow \quad \max(0, z-1) \le x \le \min(1, z)$$
>
> 分段讨论：
>
> - **当 $z < 0$ 或 $z > 2$**：无解，$p_\zeta(z) = 0$。
>
> - **当 $0 \le z \le 1$**：积分限为 $0 \le x \le z$：
>   $$p_\zeta(z) = \int_{0}^{z} 1 \cdot 1\,dx = z$$
>
> - **当 $1 \le z \le 2$**：积分限为 $z-1 \le x \le 1$：
>   $$p_\zeta(z) = \int_{z-1}^{1} 1 \cdot 1\,dx = 2 - z$$
>
> 综上，$\zeta = \xi + \eta$ 的密度函数为：
> $$p_\zeta(z) = \begin{cases}
> z, & 0 \le z \le 1 \\[4pt]
> 2-z, & 1 \le z \le 2 \\[4pt]
> 0, & \text{其他}
> \end{cases}$$
>
> 这是一个**三角形分布**（又称 Simpson 分布），图形为底边 $[0,2]$ 上的等腰三角形，顶点在 $z=1$ 处，高度为 $1$。
>
> **点评**：两个独立均匀分布的和服从三角形分布，这是卷积的经典例子。更一般地，$n$ 个独立 $U[0,1]$ 的和服从 Irwin-Hall 分布，其密度为分段 $n-1$ 次多项式。卷积公式中积分限的确定是重点——需要正确刻画 $x$ 与 $z-x$ 同时属于 $[0,1]$ 的条件。
> $\square$
