# 深度学习期中上机练习

面向本课程第 1–6 章：先通过教学题掌握实现，再用空白代码区独立完成限时测试。题目依据现有课件、课堂笔记、演示代码与编程作业编写，**不是教师公布的考试原题，也不预测真实考题**。

共 **56 道教学练习、12 套限时测试**；按教学／测试 A／测试 B 分册，含独立答案，共 **36 个 `.ipynb`**。第 1–6 章教学题数依次为 7、9、10、10、10、10；每章两套测试各为一道完整编程题，内含多个小问。

## 考试规则如何落实

依据 [[03_Sources/Courses/深度学习/PPT/2026深度学习第一次上机考试规则与命令表v1.1 (1)/2026深度学习第一次上机考试规则与命令表v1.1 (1).md]]：

- 正式考试：闭卷，30 分钟、100 分，一道编程题含多个小问，**无代码补全**。
- 本套测试 A、B 均采用完整编程题，代码区不提供函数实现框架；题面规定的函数名只用于统一自检。
- 教学册允许接口骨架、分步提示与较长的作业扩展；它不是 30 分钟试卷。
- 正式考试的全屏行为限制、证件与可携物品要求，以规则原文及考场通知为准；本地 Notebook 不模拟监考或全屏检测。
- 正式命令表的图片保存路径为 `/output/Qxxx.png`。本地练习使用当前工作目录的 `output/`；**正式考试必须改为题目指定的完整路径和文件名**。
- 命令表是工具参考，不足以证明某个知识点必考或绝不会考。教学中的扩展 API 与长作业训练不等同于限时卷要求。

## 打开与运行

使用 JupyterLab、Jupyter Notebook 或支持 Notebook 的编辑器；选择装有 NumPy、PyTorch、Matplotlib 的 **Python 3 内核**。Obsidian 可用于浏览导航与资料，执行 `.ipynb` 需 Notebook 环境。

若已有课程 Python 环境，优先使用它，无需重装。缺少 Notebook 环境时，可在自行管理的环境中运行：

```bash
python -m pip install jupyterlab numpy torch matplotlib
python -m jupyter lab
```

练习默认 CPU、小数据、固定随机种子，不需要 CUDA，不联网下载数据。训练结果允许合理浮点差异；固定种子也不保证跨版本逐位一致。

1. **教学**：先读题与形状约定 → 自己实现 → 必要时展开提示 → 运行本题自检 → 最后核对答案。
2. **测试 A**：重启内核、计时 30 分钟，不查教学或答案；先写完整程序，再运行公开自检。
3. **订正**：按题面评分点人工评分，记录错误属于知识、维度、实现、数值稳定性还是时间分配。
4. **测试 B**：隔天重启内核，独立完成另一情境，检查是否真正掌握，而不是记住 A 卷代码。
5. **提交前**：重启内核并从头运行，核查输出名称、误差口径、图例、PNG 路径与程序完整性。

“尚未完成本题”不是通过；公开自检是代表性样例，**不能代替全部小问的人工评分**。评分细则见各测试题面与解答，不根据未作答的自测推断掌握程度。

自检里的比较函数、断言及文件检查属于练习配套工具，不要求当作命令表新增内容默写。先作答再查看自检，避免将其中的参考计算当成闭卷提示。

## 资料边界与作业衔接

- 第 1–6 章按本课程课件命名，不套用其他教材的章节顺序；第 7 章卷积网络不在本套范围。
- Homework02 的手动传播、有限差分与手动六种优化器，安排在第 3、4 章教学扩展中；保留“不能用深度学习库代替手动实现”的约束。
- Homework03 的回归与分类实验安排在第 5、6 章，提供深度、宽度、激活函数与优化器的单因素比较入口。
- **当前课程目录未找到 Homework03 所需的两个 `.data` 数据文件**。默认实验使用明确标注的合成替代数据，只验证编程流程，不能代表原作业未知函数、原始 MNIST1D 或其真实测试成绩。
- 缺逐字稿课次的补全笔记、笔记中的自测与整理建议，不冒称已恢复的教师原话；每题均标注其材料依据与新编／改编性质。

## 两处容易与通用教程混淆的课程口径

- 第 2 章课件将训练、测试 RMSE 之差的**绝对值**称为泛化差距。本套以题面显式命名为准：`gap_abs` 对应课件定义；若输出 `gap_signed`，它是测试 RMSE 减训练 RMSE 的有符号诊断量，不混为同一指标。MSE 与 RMSE 也不得混报。
- 第 4 章课件的 AdaGrad 使用完整矩阵历史量及矩阵平方根的伪逆；这不同于 PyTorch 常用的逐坐标 `Adagrad`。手动作业按课件版本实现，调用库优化器的比较另作说明，不能因为名字相同就认为公式相同。

## 接口核对依据
