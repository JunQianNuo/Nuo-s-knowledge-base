# 第5章 回归模型上机练习

> 一句说清：先从采样、输出形状和误差口径学起，再完成独立训练与受控比较。

本章10道教学题（Q501—Q510）+2道完整30分钟100分卷（Q5A/Q5B）。教学有提示和接口，测试从空白独立写；答案单独放置。建议基础题逐题完成，Q509/Q510为学习期作业扩展，不受30分钟限制。

## 覆盖与来源边界

- 课程：立方体/球内体积均匀采样；Module/Sequential、深度计Linear、参数量与batch=1；MSE/RMSE/课程泛化差距绝对值；全批/小批、线性lr端点、原最后一组越界诊断；手写L1/L2、早停、初始化与对称性。
- Homework03 Exercise 1：10维输入、深度3宽100 ReLU基准、SGD及全部指定单因素选项。12种唯一配置共享基准，默认256/96合成点、每配置30步。原100万点未知函数数据未找到，不以合成实验冒充原作业复现。
- pickle适配仅支持显式可信本地四键字典；默认完全离线合成，来源会打印，未知pickle不自动读取。真实数据键、维数与子集规模仍需到文件后核验。
- 补充API：初始化函数、快照clone、文件输出用于实现课程思想，不声称原演示已经采用。所有训练CPU单线程、固定seed，图表英文标签。自检阈值只为冒烟，不保证训练性能或平台逐位相同。
- 测试A为无噪声五维响应回归，测试B为带噪一维传感器校准+L2+验证早停，非只改随机种子。没有CNN。

课程主指标 `gap_abs=abs(RMSE_test-RMSE_train)`，可另报signed差作诊断。所有新增题为改编/新编，不是教师公布原题。
