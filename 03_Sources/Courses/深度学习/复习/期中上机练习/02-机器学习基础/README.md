# 第2章 机器学习基础上机练习

本章分为教学与两次独立限时测试。先理解数学对象，再写函数、自检，最后从空白单元复现完整实验。所有运算使用 CPU；无需网络、CUDA 或外部数据。

统一口径：MSE 为逐样本平方残差的均值，RMSE 为其平方根。**课件泛化差距采用 `gap_abs = abs(RMSE_test − RMSE_train)`**；本练习同时可输出 `gap_signed = RMSE_test − RMSE_train` 作为有符号诊断，两者不能混名，也不能将MSE与RMSE直接相减。

考试核心实现以命令表为主。教学扩展会明确标出：数组 `reshape`、`np.around`、正态噪声 `rng.normal`、Tensor 的 `dtype/device` 属性。绘图管理 `plt.figure/close`、本地 `Path('output').mkdir(exist_ok=True)` 是输出辅助，不是新增模型考点。公开自检使用 `np.allclose/isclose`、集合与文件检查等辅助 API，不要求闭卷背诵这些验证代码。测试从空白开始，不能把教学骨架当作正式题型。

绘图一律英文图例与轴标签，保存到运行目录的 `output/`；正式考试仍按正式题面的 `/output/Qxxx.png` 路径填写。每次作图都先创建本地目录。公开自检不代替图表与解释的人工评分。

重点覆盖C2-01—C2-11的编程部分。第1章已介绍的基本MSE不重复单列；这里重点是九点有理函数、演示中的正弦实验、容量、样本量、验证职责与正则化。教学扩展不表示原Chapter2.py已经包含正则化或验证流程。
