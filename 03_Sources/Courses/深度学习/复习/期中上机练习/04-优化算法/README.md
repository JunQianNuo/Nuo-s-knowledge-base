# 第4章 优化算法上机练习

本章10道教学题、A/B两道独立综合测试。先用Q401—Q406逐项校准更新公式，再复现Q407课堂代码、Q408真正小批量；Q409为原Rosenbrock六优化器长作业（60—90分钟），保留eta=.01和四初值，发散也如实输出；Q410与A/B为另行新编的可控优化实验。

关键口径：课件AdaGrad是全矩阵逆平方根伪逆，不是torch.optim.Adagrad的逐坐标形式；RMSProp/AdaMax原式未给eps，本练习0/0通道明确取零更新，Adam eps=.001按作业。每个算法都有首步数值检查，Adam/AdaMax另检第二步与状态。教学扩展API已逐题说明，不将其未加说明地放入限时测试。完成1000步仅称完成预算，不自动称收敛。
