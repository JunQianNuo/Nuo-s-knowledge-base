# 第6章 分类模型上机练习

> 一句说清：先对齐标签、概率与logits接口，再独立训练、测准确率并画出预测分区。

本章10道教学题（Q601—Q610）+2道完整30分钟100分卷（Q6A/Q6B）；答案独立。Q609/Q610是作业接口与单因素比较扩展，可分次学习，不挤进30分钟卷。

## 覆盖与来源边界

- 课程：四象限含坐标轴边界、1—4与0—3 long转换、one-hot、逐行稳定Softmax、概率手写CE、稳定logits CE与梯度核对、Module参数注册、独立训练/预测准确率、按预测类别绘图。
- 原Chapter6.py是显式Softmax+one-hot+手写log损失；本练习明确分开它与raw-logits+CrossEntropyLoss接口，**不对CE输入二次Softmax**。原默认CUDA及5000步配置不代表本地CPU练习配置。
- Homework03 Exercise 2：保留深度3宽100 ReLU基准与全部指定深度/宽度/激活/优化器单因素比较（12种唯一配置）。原MNIST1D 4000/1000数据未找到；合成40特征10类信号**不是MNIST1D**，未核验原.data实际维数，不声称完整复现。
- 默认合成320/120点、单因素每配置30步，CPU单线程、固定seed、无需网络/GPU。可信本地pickle仅显式opt-in；四键与维数检查不等于原文件已到手。
- 测试A为符号四区识别，测试B为同心三区及稳定手写CE，数据/目标/编码不同，非换seed重复。只涵盖第1—6章，10月19日后半CNN/池化不在本章。
- 分类准确率的宽松下限仅为冒烟检查，不是考试评分线；图表英文标签。本地output目录不冒充正式/output，正式考试以题面路径为准。
