会议主题：线性空间与拓扑结构课程

发言人：电子科大王君豪

会议摘要：本次课程讲解了线性空间的和与直和、哈默尔基的存在性证明，并引入了距离线性空间与拓扑开集概念，最后布置了基础性素质互评任务。

------------------------------------------------------------------------

一、线性空间的和与直和

1. 线性流行之和的定义

-   代数象征性加法：线性流行 M 与 N 的和（M+N）并非具体的数值计算，而是将 M 与 N 中的元素进行组合收集，构成一个代数上的目标集合。

2. 直和的定义与唯一分解定理

-   直和的判定条件：当 M 与 N 的交集仅为 {0} 时，X 可表示为 M 与 N 的直和。

-   元素分解的唯一性：若 X 能表示为 M 与 N 的直和，则 X 中的任意元素 x 都可以唯一地分解为 m 与 n 的和。

-   代数互补概念：当 X 可写为 M 与 N 的直和形式时，M 与 N 互为代数互补的线性流行。

二、哈默尔基及其存在性证明

1. 哈默尔基的定义与特性

-   线性无关与张成：哈默尔基 H 是线性空间 X 的一个线性无关子集，且能张成整个空间 X。

-   有限线性无关概念：哈默尔基概念中隐含的线性无关是指有限子集的线性无关，这与无限维空间中的基存在微弱差异。

2. 哈默尔基的存在性证明

-   极大线性无关集构造：利用佐恩引理，在包含给定线性无关集 S 的所有线性无关集中寻找极大元，该极大元即为哈默尔基 H。

-   极大性矛盾验证：若 H 不能张成 X，则存在元素 x 使得 H 并上 x 仍线性无关，这与 H 的极大性矛盾，从而证明 H 必能张成 X。

3. 代数补空间的存在性

-   非零线性空间必有代数补：对于任意非零线性空间 X 及其线性子空间 M，必然存在一个线性空间 N，使得 M 与 N 构成 X 的直和。

三、距离线性空间与拓扑结构

1. 拓扑开集的定义

-   开集的封闭性：开集是指对任意并集封闭，且对有限交集也封闭的拓扑结构。

2. 距离线性空间的相容性

-   运算连续性要求：线性空间配备距离后，其加法和数乘运算必须是连续的，否则该空间不能称为距离线性空间。

-   非相容距离反例：若定义距离 d 在两点相等时为 0，不等时为 1，则该距离无法满足数乘运算的连续性，不能作为距离线性空间的距离。

3. 距离线性空间实例

-   有界序列空间 L无穷：由有界序列构成的集合，配备按坐标的加法、数乘以及上确界距离，构成一个距离线性空间。

-   距离公理验证：L无穷 空间的上确界距离满足非负性、对称性及三角不等式。
