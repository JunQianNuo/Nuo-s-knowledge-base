## 二、不要一次读完一整章：分成可检验的小段

### 第一段：把“对象”认清

读00中的期望、方差、常见总体模型，再读06的第二、三部分。

**过关标准：** 能用自己的话区分总体参数、随机样本、观测值、统计量；能解释“统计量不含参数，但它的分布可以含参数”。

### 第二段：理解统计量的分布

读06的第四至七部分。先掌握构造结构，再看九条抽样结论。

**过关标准：** 看见一个比值会先核对标准化、自由度与独立性，而不是只凭形状认 $t$ 或 $F$。

### 第三段：会造点估计

读07的第二至四部分，重做Bernoulli、指数、均匀模型。

**过关标准：** 能独立写出矩方程或似然，并解释均匀模型为何要分析边界。

### 第四段：会评价与量化误差

读07的第五至十部分。

**过关标准：** 能区分无偏、MSE与相合；能从枢轴量完整反解一个均值区间、一个方差区间。不要只默写最终公式。

### 第五段：接上老师当前理论

先读07a第四至七、九、十部分，建立充分性、条件期望、完备性与最优估计的联系；再回看第三部分的信息下界、第八部分的指数族条件。

**过关标准：** 能回答“为什么充分性只能保证改进，完备性加进来后才锁定唯一最优”。

## 三、用两个贯穿例子理解上下文

### 1. 次品率：每一步都能看到样本频率

- 00：是否次品 $X_i$ 是Bernoulli变量，$EX_i=p$。
- 06：次品数 $T$ 服从二项分布，频率 $\bar X$ 的方差为 $p(1-p)/n$。
- 07：矩估计与MLE都得到 $\widehat p=\bar X$，无偏性与相合性检查其表现。
- 07：CLT允许在合适大样本条件下给出近似区间。
- 07a：总次品数充分完备；从 $X_1$ 取条件期望得到 $\bar X$；定理证明它在无偏类中最优。

同一个答案出现多次，是因为每次证明的事情不同，不是不同章节在重复废话。

### 2. 均匀上限：让不同方法真正显示差别

- 06：最大值也是统计量，顺序统计量能保留端点信息。
- 07：MM得到 $2\bar X$，MLE得到最大值 $M$。
- 07：$M$ 有向下偏差，修正为 $(n+1)M/n$；它比MM更有效。
- 07a：$M$ 充分完备，条件期望把MM改进成修正最大值。
- 07a：Lehmann–Scheffé最终证明修正最大值是UMVUE。

这个例子还说明：标准信息下界不适用，不意味着没有最优无偏估计。
