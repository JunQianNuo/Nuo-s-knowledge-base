## **并行计算机系统互连**

- 并行计算机组成要素
    - 结点（node）：包含一个或多个CPU，这些CPU通过HUB或全互联交叉开关相互联接，并共享内存，也可以直接与外部进行I/O操作
    - 互联网络（interconnetct network）：所有结点通过互联网络相互连接相互通信
    - 内存（memory）：内存由多个存储模块组成，这些模块可以与结点对称地分布在互联网络的两侧，或者位于各个结点的内部

## **并行计算机系统互连**

- 总线（Bus）是计算机各种功能部件之间传送信息的公共通信干线。如果说主板（Mother Board）是一座城市，那么总线就像是城市里的公共汽车，能按照固定行车路线，传输来回不停运作的比特（bit）。
    - 数据总线（Data Bus）：在CPU与RAM之间来回传送需要处理或是需要储存的数据。
    - 地址总线（Address Bus）：用来指定在RAM（Random Access Memory）之中储存的数据的地址。
    - 控制总线（Control Bus）：将微处理器控制单元（Control Unit）的信号，传送到周边设备。
- CPU 要从存储器读取数据时，三类总线的工作过程：
    1. CPU 通过地址总线发送要访问的存储单元的地址信息；
    2. CPU 通过控制总线发送读控制信号；
    3. 存储器通过数据总线发送指定存储单元上的数据。

- 系统域网络(System Area Network,SAN)：将短距离（3-35m）内的不同节点连接起来形成单一系统。

## **互连网络类型**

- **静态互联网络 (Static Interconnection Network)**
    - 处理单元间有着固定连接的一类网络，在程序执行期间，这种点到点的链接保持不变
    - 典型静态网络：一维线性阵列、二维网孔、树连接、超立方网络、立方环、洗牌交换网、蝶形网络等
- **动态互联网络 (Dynamic Interconnection Network)**
    - 用交换开关构成，可按应用程序的要求动态地改变连接组态
    - 典型动态网络：总线、交叉开关和多级互连网络等

## **网络性能指标**

- 节点度 (Node Degree)：一个节点直接连接的边（链路）数。
    - 节点度越高，单节点可同时通信的通道越多，路由选择更灵活，局部带宽更高。
    - 节点度越高，路由器端口、线缆、功耗和成本也越高，扩展难度增大。

- 网络直径 (Network Diameter)：网络中任意两个节点之间最短路径数的最大值。
    - 网络直径越大，最坏情况下的通信延迟越高，全局同步、广播等操作耗时越长。
- 对剖宽度 (Bisection Width)：对分网络各半所必须移去的最少边数。
- 对剖带宽（ Bisection Bandwidth）:每秒钟内，在最小的对剖平面上通过所有连线的最大信息位（或字节）数。
    - 决定网络最坏情况下的全局通信能力。
    - 对剖带宽太小会成为瓶颈，即使单链路很快，全局通信也上不去。
- 对称性 (Symmetry)
    - 如果从任一节点观看网络都一样，则称网络为对称的。

## **静态互连网络**

- **一维线性阵列 (1-D Linear Array)**
    - 并行机中最简单、最基本的互连方式
    - 每个节点只与其左、右近邻相连 (二近邻连接)
    - $N$ 个节点用 $N-1$ 条边串接，内节点度为2，直径为N-1，对剖宽度为1
    - 首尾相连可构成循环移位器，在拓扑结构上等同于环，环可以是单向的或双向的，其节点度恒为2，直径为 $\left⌊N/2\right⌋$ （双向环）或 $N-1$ （单向环），对剖宽度为2

## **静态互连网络**

- $\sqrt{N}\times \sqrt{N}$ 二维网孔（2-D Mesh）：
    - 每个节点只与其上、下、左、右的近邻相连（边界节点除外），节点度为4，网络直径为 $2\left(\sqrt{N}-1\right)$ ，对剖宽度为 $\sqrt{N}$
    - 在垂直方向上带环绕，水平方向呈蛇状，就变成Illiac网孔了，节点度恒为4，网络直径为 $\sqrt{N}-1$ ，对剖宽度为 $2\sqrt{N}$
    - 垂直和水平方向均带环绕，则变成了2-D环绕（2-D Torus），节点度恒为4，网络直径为 $2\left⌊\sqrt{N}/2\right⌋$ ，对剖宽度为 $2\sqrt{N}$

## **静态互连网络**

- 二叉树：
    - 除了根、叶节点，每个内节点只与其父节点和两个子节点相连。
    - 节点度为3，对剖宽度为1，而树的直径为 $2\left(\left⌈log_{2}N\right⌉-1\right)$
    - 如果尽量增大节点度为 $N-1$ ，直径缩小为2，此时就变成了星形网络，其对剖宽度为 $\left⌊N/2\right⌋$
    - 传统二叉树的主要问题是根易成为通信瓶颈，胖树节点间的通路自叶向根逐渐变宽。

## 嵌入

- 嵌入（Embedding）：将网络A（客网络）的各节点映射到网络B（宿主网络）中去。
- 单条边的膨胀（Dilation）系数：指客网络中某一条特定边在宿主网络中被映射成的路径长度。
- 整个嵌入的膨胀系数：指在一个嵌入映射中，所有边的膨胀系数中的最大值。
    - 如果该系数为1，则称为完美嵌入
    - 环网可完美嵌入到2-D环绕网中
    - 超立方网可完美嵌入到2－D环绕网中

- 交叉开关（Crossbar switcher）是一种高带宽网络，交叉点开关可由程序控制动态设置其处于“开”或“关”状态，提供所有“源-目的”对之间的动态连接。
    - 用于对称的多处理机（SMP）或多计算机机群中的处理器间的通信，每一行和每一列只能接通一个交叉点开关
    - 用于SMP服务器或向量超级计算机中处理器和存储器之间的存取，每一列中只能接通一个交叉点开关，但为了支持并行（或交叉）存储访问，每一行可同时接通多个交叉点开关。
    - 成本为 $O\left(n^{2}\right)$ ，就限制了它在大型系统中的应用。

## 计算机的Flynn分类

- 计算机在执行程序时，同时处理“指令流”和“数据流”的数量。根据这两个维度的组合，Michael J. Flynn将计算机分成四大类别：
    - SISD (Single Instruction stream Single Data stream)，如早期的单核CPU（如Intel 8086）
    - SIMD (Single Instruction stream Multiple Data stream)，如GPU（显卡）、向量处理器
    - MISD (Multiple Instruction stream Single Data stream)，极少见，仅存在于特定容错系统
    - MIMD (Multiple Instruction stream Multiple Data stream),现代多核CPU、超级计算机、分布式集群
- 现代处理器采用混合模式：比如多核 CPU 是 MIMD，而其中的 SIMD 指令扩展又能做 SIMD 运算；GPU 本质是"SIMD 风格控制 + MIMD 级并行"的混合体

## 并行计算机结构模型

- 对称多处理机SMP（Symmetric Multiprocessor）
    - 将各处理器经由高速总线（或交叉开关）与共享存储器相连
    - 每个处理器对共享存储器具有同等的访问权利
    - 每个处理器对I/O设备和其它系统资源享有同等的访问权利
    - 在SMP系统中一般要求每个处理机是相同的
    - 并行度高但是处理器不能太多（一般少于64个）
    - 代表机型：IBM公司的ES/9000系统和R50、Sun公司的SparcCenter 2000、我国的曙光1号

## 并行计算机结构模型

- 大规模并行处理机MPP（Massively Parallel Processor）：采用松耦合体系结构连接各种不同的处理器。
    - 处理节点采用商品微处理器；
    - 系统中有物理上的分布式存储器；

    - 能扩放至成百上千乃至上万个处理器；
    - 是一种异步的MIMD机器，程序系由多个进程组成，每个都有其私有地址空间，进程间采用传递消息相互作用；

## 并行计算机结构模型

- 分布共享存储DSM（Distributed Shared Memory)：
    - 存储器在物理上分布于各处理器附近，但在逻辑上可由多个处理器共享整个内存
    - DSM系统实际上是SMP和MPP结构的折中
    - 代表机型有Cray公司的Cray T3E、SGI/Cray公司的Origon 2000、BBN公司的TC 2000

- DSM的优点：
    - 避免了集中式存储结构中处理器和存储器的复杂连接
    - 有良好的可扩展性
    - 相对MPP来说，更容易编程
- DSM系统需着重考虑的问题：
    - 系统应具有维持存储器访问一致性的硬件支持
    - 相对SMP系统来说，其访问非物理局部存储器的时间要更长。

    - 大量的节点通过高速网络互连起来
    - 节点遵循Shell结构：用专门定制的Shell电路将商用微处理器和节点的其它部分（包括板级Cache、局存、NIC和DISK）连接起来。优点是CPU升级只需要更换Shell。

并行计算机访存模型

- 内存墙（memory wall）性能瓶颈：内存的访问速度要比处理器执行速度慢很多。
- 在内存和处理器之间增加一个高速缓冲区（cache）来克服内存墙
    - Cache 以 cache 线 (line) 为其基本组成单位，每条 cache 线包含L个字，每个字为8个字节。
    - 内存空间分割成块（block），每块大小与 cache 线长度一致（L个字）
    - 数据在内存和 cache 之间的移动，以 cache 线为基本单位
- Cache 数据的一致性策略
    - Write–through：cache 线中的数据一旦被修改，则立即写入内存块。
    - Write–back ：当且仅当要求进行 cache 线置换时，或者有外部请求访问内存块时，将cache线的数据写入内存。

多级存储结构示意图微处理器芯片和L2 cache通常可视为微处理器，多个微处理器和它们共享的局部内存模块构成一个完整的结点。

并行计算机访存模型

- 当程序中连续使用的数据存储在内存的连续位置时，高速缓存可以起到加速的作用。
- 一次内存访问操作，如果操作数存在于cache 中，则称该次访问是cache命中的，否则称该次操作是 cache 失效的。
- cache命中率：程序执行过程中，cache 命中的总次数和内存访问总次数之比值。
- 虽然程序员无需直接管理cache，但是程序如果考虑cache的访存模型可能会带来性能的显著提升。例如：在遍历矩阵的时候应该优先考虑行遍历行遍历

$\left[\begin{matrix}a_{11}&a_{12}&\ldots &a_{1n}\\a_{21}&a_{22}&\ldots &a_{2n}\\\vdots &\vdots &\vdots &\vdots \\a_{n1}&a_{n2}&\ldots &a_{nn}\end{matrix}\right]$

## 并行计算机访存模型

- 均匀存储访问模型（Uniform Memory Access， UMA ）：
    - 物理存储器被所有处理器均匀共享；
    - 所有处理器访问任何存储单元有相同的时间；
    - 每台处理器可带私有高速缓存(Cache)；
    - 外围设备也可以一定形式共享。
- 当所有的处理器都能等同地访问所有I/O设备、能同样地运行执行程序(操作系统内核和I/O服务程序等)时称为对称多处理机SMP。
- 如果只有一台或一组处理器（称为主处理器），它能执行操作系统并能操纵I/O，而其余的处理器无I/O能力（称为从处理器），只在主处理器的监控之下执行用户代码，这时称为非对称多处理机。

## 并行计算机访存模型

- 非均匀存储访问模型 (Nonuniform Memory Access, NUMA) ：
    - 被共享的存储器在物理上是分布在所有的处理器中的，其所有本地存储器的集合就组成了全局地址空间；
    - 处理器访问存储器的时间是不一样的；访问本地存储器LM或群内共享存储器CSM较快，而访问外地的存储器或全局共享存储器GSM较慢；
    - 每台处理器照例可带私有高速缓存，外设也可以某种形式共享。

## 并行计算机访存模型

- 全高速缓存存储访问 (Cache-Only Memory Access, COMA)模型：
    - 各处理器节点中没有存储层次结构，全部高速缓存组成了全局地址空间；
    - 利用分布的高速缓存目录D进行远程高速缓存的访问;
    - COMA中的高速缓存容量一般都大于2 级高速缓存容量；
    - 使用COMA时，数据开始时可任意分配，因为在运行时它最终会被迁移到要用到它们的地方。

## 并行计算机访存模型

- 高速缓存一致性非均匀存储访问模型（Coherent-Cache Nonuniform Memory Access, CC-NUMA ）：
    - 大多数使用基于目录的高速缓存一致性协议；
    - 保留SMP结构易于编程的优点，也改善常规SMP的可扩放性；
    - CC-NUMA实际上是一个分布共享存储的DSM多处理机系统；
    - 它最显著的优点是程序员无需明确地在节点上分配数据，系统的硬件和软件开始时自动在各节点分配数据，在运行期间，高速缓存一致性硬件会自动地将数据迁移至要用到它的地方。
