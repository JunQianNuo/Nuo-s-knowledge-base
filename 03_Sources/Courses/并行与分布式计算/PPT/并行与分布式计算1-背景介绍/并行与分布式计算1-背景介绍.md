1946年，我国著名数学家华罗庚在美国访学期间得知，世界第一台通用电子计算机“埃尼阿克”（ENIAC）在美国宾夕法尼亚大学宣告问世。当时，他心中就埋下了一个梦想：中国绝不能失去研究计算机的大好机会，要在中国研制出计算机，实现国家的“计算自由”。

1950年，华罗庚回到中国，1951年担任中国科学院原数学研究所（以下简称数学所）所长。开展电子计算机的研制工作一直是他念念不忘的事。为此，1952年，华罗庚从清华大学物色了闵乃大、夏培肃、王传英3位才华横溢的青年学者，组建了一支年轻的“开垦队”，开启了艰苦的计算机研究之旅。从设计基本电路到写出规划报告，每一步都是跨越未知的探索。1958年8月，中国第一台电子管计算机103机在中科院计算所研制成功， 运行速度每秒 1500次。

Cray-1，1976年发布，全球首款商业上成功的超级计算机。高2米，宽2.6米，重5吨，功耗115-150千瓦，售价500万到900万美元。采用单个向量处理器，内存8MB，巅峰性能达到160MFLOPS，1976-1982年保持世界最快的计算机记录。

Cray-2，1985年发布，重2.5吨，功耗150-200千瓦，售价1760万美元。采用4个向量处理器，内存2GB，巅峰性能达到1.9GFLOPS, 1985-1988年保持世界最快的计算机记录。Piotr Luszczek 2012年使用LINPACK benchmark测得Cray-2性能与iPad2相当。

![](../../../../../04_Assets/Images/Courses/%E5%B9%B6%E8%A1%8C%E4%B8%8E%E5%88%86%E5%B8%83%E5%BC%8F%E8%AE%A1%E7%AE%97/PPT/%E5%B9%B6%E8%A1%8C%E4%B8%8E%E5%88%86%E5%B8%83%E5%BC%8F%E8%AE%A1%E7%AE%971-%E8%83%8C%E6%99%AF%E4%BB%8B%E7%BB%8D/images/59380afca6e69283d36ba7c06970c462f50054dc4a61fa1b5040704d77456e78.jpg)

Illinois Automatic Computer （ILLIAC-IV），世界首台大规模并行计算机，设计处理器数量256（实际建造64），设计峰值性能1GFLOPS（实际达到50MFLOPS），预算800万美元（最终3100万-4000万美元）。1975年连接到ARPANET（互联网前身），成为首台可供网络使用的超级计算机，比Cray-I早一年。

## 科学计算的诞生与高性能计算的蓬勃发展

- 1947年Von Neumann和Goldstine在《美国数学会通报》发表了题为“高阶矩阵的数值求逆”的著名论文，开启了现代计算科学的研究。

- 1983年一个由美国著名数学家拉克斯(P. Lax)为首的不同学科的专家委员会向美国政府提出的报告之中，强调“**科学计算是关系到国家安全、经济发展和科技进步的关键性环节，是事关国家命脉的大事**。”1987年起美国NSF把“科学与工程计算”、“生物工程”“全局性科学”作为三大优先资助的领域。
- 1993年美国科学、工程、技术联邦协调理事会向国会提交了题为“重大挑战项目：高性能计算和通信（High Performance Computing and Communication）”的报告，简称为HPCC计划，目的是研制能够提供3T性能目标（1Tflops计算能力、1TB内存容量和1TB/s 的 I/O 带宽，1T=1012）的高性能并行机，解决科学与工程计算中的重大挑战性课题，保持其在高性能计算和计算机通信领域中的世界领先地位，利用高性能计算机与网络技术刺激生产，以提高国民经济、国家安全、教育和整体环境的竞争力。

## 高性能计算发挥作用的例子

- MANIAC(Mathematical Analyzer Numerical Integrator and Automatic Computer Model)：1948年在洛斯阿拉莫斯部署的一台计算机，用于模拟热核过程等复杂的计算。
- 1953年，在MANIAC 上利用蒙特卡洛模拟得到了第一个状态方程。
- 1956年，MANIAC 成为第一个在棋类游戏（ $6\times 6$ 的棋盘）打败人类的机器。

![](../../../../../04_Assets/Images/Courses/%E5%B9%B6%E8%A1%8C%E4%B8%8E%E5%88%86%E5%B8%83%E5%BC%8F%E8%AE%A1%E7%AE%97/PPT/%E5%B9%B6%E8%A1%8C%E4%B8%8E%E5%88%86%E5%B8%83%E5%BC%8F%E8%AE%A1%E7%AE%971-%E8%83%8C%E6%99%AF%E4%BB%8B%E7%BB%8D/images/9b5bc56799b3bee325b5a1184095fb14bac451fea312717277c0655f57fb7bcc.jpg)

- The FPUT lattice system：1953年夏天，物理学家费米(Enrico Fermi)、John Pasta、数学家Stanislaw Ulam、Mary Tsingou利用MANIAC取得了一项重要突破。研究团队建立了一个带有微弱非线性的、一维振子链模型，希望检验该系统是否会如假设那样演化，并最终达到一种平衡状态，使能量在各个模式之间均匀分配。然而，最后的结果表明，在微小扰动条件下，这种结果并非必然出现。这一发现既不平凡，也不直观，如果没有数值模拟，是无法预见的。这是物理学史上第一次，并非通过理论推导或实验手段，而是借助计算方法取得的科学发现。它后来引出了孤子和可积模型的发现，推动了混沌理论的发展，并加深了人们对遍历极限的理解。

![](../../../../../04_Assets/Images/Courses/%E5%B9%B6%E8%A1%8C%E4%B8%8E%E5%88%86%E5%B8%83%E5%BC%8F%E8%AE%A1%E7%AE%97/PPT/%E5%B9%B6%E8%A1%8C%E4%B8%8E%E5%88%86%E5%B8%83%E5%BC%8F%E8%AE%A1%E7%AE%971-%E8%83%8C%E6%99%AF%E4%BB%8B%E7%BB%8D/images/90ed607425a759575cf1825396e070679739bd7f26068fd380250393cf6c7bab.jpg)

If there is no nonlinearity (purple), all the amplitude in a mode will stay in that mode. If a quadratic nonlinearity is introduced in the elastic chain, energy can spread among all the mode, but if you wait long enough (two minutes, in this animation), you will see all the amplitude coming back in the original mode.

- 四色定理：任何一张（无外飞地的）地图都可以只用四种颜色给这些区域染色，并且不会使具有共同边界的国家着上相同的颜色。

1976年‌：阿佩尔（Kenneth Appel）与哈肯（Wolfgang Haken）借助计算机‌首次证明四色定理‌，这是计算机辅助证明的开端。他们将地图的无限种可能情况，简化为1936种需要检验的“构型”，并设计了一套放电算法和487条规则来生成这个集合。在伊利诺伊大学的IBM 360等计算机上，累计运行了约1200个小时，完成了超过100亿次的判断。

集成电路设计

- 电路功能仿真：通过求解大规模非线性微分代数方程组，精确仿真晶体管级的电学行为。这在模拟与混合信号电路设计中尤为重要，因为其高度依赖仿真。
- 工艺与器件仿真（TCAD）：从原子层面模拟半导体制造工艺和器件物理特性。如今，TCAD的应用已从单个器件扩展到全芯片级的良率与性能优化。
- 多物理场仿真：芯片是电、热、力等多物理场耦合的系统。科学计算能进行电磁场（求解麦克斯韦方程组）、热分析（从原子到芯片的多尺度仿真）和应力分析等多物理场耦合仿真，这对3D-IC芯片等先进封装设计至关重要.
- 成功案例（量子微芯片高精度模拟）：研究人员依托国家能源研究科学计算中心的“珀尔马特”超级计算机，动用超过7000块GPU的超级计算机，将一块量子微芯片离散化为110亿个网格单元进行模拟。这种“全波物理级精度”的模拟，在制造前就揭示了芯片内部的物理工作机制。

- 国家“十五五”重点建设方向：

1. 全国一体化算力网‌：将分散的数据中心、超算中心、智算中心用高速网络连接，实现跨区域、跨运营商的统一调度，解决“算力孤岛”问题，让算力像电力一样方便使用。
2. ‌算电协同‌：强调算力设施与电力系统的深度融合，特别是在西部新能源丰富地区建设绿色算力设施，通过“瓦特”与“比特”的双向奔赴，降低算力成本并实现绿色低碳发展。
3. ‌超大规模智算集群‌：论证并建设超大规模智算集群，支持有条件地区根据低时延场景需求适度发展算力，推进云边端协同发展，以满足大模型训练和推理的指数级需求。‌‌
