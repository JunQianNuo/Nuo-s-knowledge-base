# 复习VI — 整数规划（第19章）

> 对应复习纲要 Section VI。本章要求掌握基本概念和方法原理，不要求复杂数值计算。

---

## 一、核心定义速查

### 1.1 整数规划的定义

**整数规划 (Integer Programming, IP)**：在线性规划的基础上，要求部分或全部决策变量取整数值。

| 类型 | 定义 | 说明 |
|------|------|------|
| **纯整数规划** (Pure IP) | 所有变量必须取整数值 | $x_i \in \mathbb{Z}$ |
| **混合整数规划** (Mixed IP) | 部分变量取整数，部分连续 | $x_i \in \mathbb{Z}$（部分），$x_j \in \mathbb{R}$（部分） |
| **0-1 整数规划** | 变量只能取 0 或 1 | 常用于"是/否"决策问题 |

一般形式：

$$
\min \; c^T x, \quad \text{s.t.} \; Ax \leq b, \; x \geq 0, \; x_i \in \mathbb{Z} \;(i \in I)
$$

### 1.2 线性整数规划 vs 连续线性规划

| | 连续 LP | 整数 LP |
|---|---|---|
| 可行域 | 凸多面体（连续区域） | 凸多面体中的**离散格点** |
| 最优解位置 | 在极点（顶点）上 | 不一定在连续松弛的极点上 |
| 求解难度 | 多项式时间可解（单纯形/内点法） | **NP-hard**（一般情况下） |
| 最优值关系 | — | IP 最优值 $\geq$ LP 松弛最优值（对 $\min$ 问题） |

> 核心难点：整数约束破坏了可行域的凸性和连续性，不能直接应用单纯形法。

### 1.3 线性松弛 (LP Relaxation)

去掉整数约束 $x_i \in \mathbb{Z}$，得到与原 IP 对应的**线性松弛问题**：

$$
\min \; c^T x, \quad \text{s.t.} \; Ax \leq b, \; x \geq 0
$$

线性松弛的最优值是原 IP 最优值的**下界**（对 $\min$ 问题）。若松弛问题的最优解恰好是整数，则它也是 IP 的最优解。

## 二、核心定理

### 2.1 求解线性整数规划的两类方法

| 方法类别 | 代表算法 | 核心思想 |
|----------|----------|----------|
| **割平面法** (Cutting Plane) | Gomory 割平面 | 不断添加新的线性约束"切掉"不含整数解的可行域部分，逐步逼近整数解 |
| **分支定界法** (Branch and Bound) | B&B | 将可行域反复分割为子域（分支），用松弛问题计算上下界来剪枝 |

### 2.2 割平面法的原理

**核心思想**：
1. 先求解 IP 的线性松弛问题，得到最优解 $x^*$
2. 若 $x^*$ 的整数变量分量 $x_i^*$ 不是整数，则构造一个**割平面**（Gomory 割）：
   - 该割平面"切掉"当前的连续最优解 $x^*$
   - 但**不切掉**任何整数可行解
3. 将割平面作为新约束加入，重新求解松弛问题
4. 重复直到得到整数最优解

**Gomory 割的构造**（对纯整数规划）：

设单纯形表中基变量 $x_k$ 的方程为：

$$
x_k + \sum_{j \in N} \bar{a}_{kj} x_j = \bar{b}_k
$$

其中 $\bar{b}_k$ 不是整数。记 $f_{kj} = \bar{a}_{kj} - \lfloor \bar{a}_{kj} \rfloor$（小数部分），$f_k = \bar{b}_k - \lfloor \bar{b}_k \rfloor$。Gomory 割为：

$$
\sum_{j \in N} f_{kj} x_j \geq f_k
$$

等价地引入松弛变量化为等式约束。

### 2.3 分支定界法的原理

**核心思想**——分而治之：
1. **分支 (Branch)**：选择一个应取整数但当前为小数的变量 $x_i$，将问题分成两个子问题：
   - 左分支：$x_i \leq \lfloor x_i^* \rfloor$
   - 右分支：$x_i \geq \lceil x_i^* \rceil$
2. **定界 (Bound)**：对每个子问题求解线性松弛，得到目标值下界（$\min$ 问题）
3. **剪枝 (Prune)**：若子问题的下界 $\geq$ 当前已知最好整数可行解的目标值，则剪掉该分支（无需继续搜索）

**算法流程**：
```
1. 初始化：求解松弛问题，得最优值 LB。
   若解为整数，则已得最优解，停止。
2. 选一个非整数变量 x_i 进行分支。
3. 分别求解两个子问题的松弛，更新全局下界和上界。
4. 剪枝条件：
   a) 子问题不可行 → 剪枝
   b) 子问题最优值 ≥ 当前最好整数解目标值 → 剪枝
   c) 子问题最优解为整数 → 更新上界，剪枝
5. 若还有未处理的子问题，重复步骤 2。
6. 上界对应的整数解即为最优解。
```

> [!hint] 关键概念
> - **上界**：当前已知的最好整数可行解的目标值（$\min$ 问题中记录最小值）
> - **下界**：每个子问题线性松弛的最优值
> - 当上界 = 下界时，找到最优解

## 三、计算要点

### 3.1 割平面法的操作步骤

1. 求解初始 LP 松弛 → 得单纯形终表
2. 检查基变量是否全为整数：
   - 若是 → 得到整数最优解，停止
   - 若否 → 选择 $\bar{b}_k$ 小数部分最大的行
3. 构造 Gomory 割 $\sum_{j \in N} f_{kj} x_j \geq f_k$
4. 引入松弛变量，将割平面加入单纯形表
5. 用**对偶单纯形法**重新优化（因为添加约束后 $b$ 出现负分量）
6. 返回步骤 2

### 3.2 分支定界法的操作步骤

1. 求解根节点 LP 松弛 → 若非整数，创建搜索树
2. 选分支变量（通常选小数部分最大的）
3. 对每个活跃节点，求解其 LP 松弛
4. 根据规则剪枝，更新上界
5. 重复直到所有节点处理完毕

### 3.3 两种方法的对比

| | 割平面法 | 分支定界法 |
|---|---|---|
| 搜索方式 | 逐步压缩可行域 | 树状分割可行域 |
| 关键操作 | 添加 Gomory 割 | 分支、定界、剪枝 |
| 理论保证 | 有限步终止（纯 IP） | 有限步终止 |
| 实用效率 | 单独使用较慢 | 通常更快，可与割平面结合（Branch and Cut） |
| 对偶单纯形法 | 需要（添加约束后） | 各子节点独立求解 |

## 四、典型易错点

> [!warning] LP 松弛的最优解四舍五入不保证得到 IP 最优解
> LP 松弛解四舍五入后的点可能不可行，或虽可行但离 IP 最优解很远。必须用割平面或分支定界。

> [!warning] 整数规划的难度
> 不要认为"加个整数约束没什么大不了"——整数规划是 NP-hard 的。小规模问题可以用枚举法，大规模需用专业算法（Branch and Cut, Branch and Price）。

> [!warning] 割平面法保证不切整数解
> Gomory 割的构造利用了整数变量的小数部分，保证了割平面只切掉当前的非整数松弛解，不切任何整数可行解。割平面"切深了"会导致丢失最优解。

> [!warning] 分支定界的效率取决于分支顺序
> 选择哪个变量分支、选择哪个节点优先处理，对算法效率影响很大。好的启发式可以大幅减少搜索节点数。
