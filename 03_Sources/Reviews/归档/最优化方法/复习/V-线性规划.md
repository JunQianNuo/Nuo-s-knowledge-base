# 复习V — 线性规划（第15-17章）

> 对应复习纲要 Section V。涵盖：LP标准型与基本解、单纯形法、对偶理论、对偶单纯形法。

---

## 一、核心定义速查

### 1.1 线性规划的标准形式

$$
\min \; c^T x, \quad \text{s.t.} \; Ax = b, \; x \geq 0
$$

其中 $A \in \mathbb{R}^{m \times n}$，$\operatorname{rank}(A) = m < n$，$b \geq 0$。

| 要素 | 要求 | 说明 |
|------|------|------|
| 目标 | $\min$ | 最大化问题需取负 |
| 约束 | $Ax = b$ | 必须为等式 |
| 变量 | $x \geq 0$ | 不能有负分量 |
| 秩 | $\operatorname{rank}(A) = m$ | 行满秩，无冗余约束 |
| 右端 | $b \geq 0$ | 保证初始BFS非负 |

### 1.2 标准化四步法

| 步骤 | 原形式 | 处理方式 |
|------|--------|----------|
| 1. 目标 | $\max \; c^T x$ | 改为 $\min \; (-c)^T x$ |
| 2. $\leq$ 约束 | $a_i^T x \leq b_i$ | 引入松弛变量 $+s_i$，$s_i \geq 0$ |
| 2'. $\geq$ 约束 | $a_i^T x \geq b_i$ | 引入剩余变量 $-s_i$，$s_i \geq 0$ |
| 3. 自由变量 | $x_i$ 无限制 | $x_i = x_i^+ - x_i^-$，$x_i^+, x_i^- \geq 0$ |
| 4. $b_i < 0$ | 右端为负 | 方程两边乘 $-1$ |

### 1.3 基与基本解

将 $A = [a_1, \ldots, a_n]$ 按列分块，选 $m$ 个线性无关列构成**基矩阵** $B \in \mathbb{R}^{m \times m}$（可逆），其余列构成**非基矩阵** $N$。

| 术语 | 符号 | 定义 |
|------|------|------|
| 基矩阵 | $B$ | $m \times m$ 可逆子矩阵，由 $m$ 个线性无关列组成 |
| 非基矩阵 | $N$ | 剩余的 $n-m$ 列 |
| 基变量 | $x_B$ | 与 $B$ 的列对应的 $m$ 个变量 |
| 非基变量 | $x_N$ | 与 $N$ 的列对应的 $n-m$ 个变量 |
| 基本解 | $x = [B^{-1}b, \; 0]^T$ | 令 $x_N = 0$，解 $Bx_B = b$ |
| 基本可行解 (BFS) | 基本解 + $x_B \geq 0$ | 非负的基本解 |
| 退化 BFS | BFS 且某个基变量 = 0 | 正分量数 $< m$ |

### 1.4 三类解的关系

| 类型 | 满足 $Ax = b$ | 满足 $x \geq 0$ | 对应基 |
|------|:---:|:---:|:---:|
| 可行解 | yes | yes | 不一定 |
| 基本解 | yes | 不一定 | yes |
| 基本可行解 | yes | yes | yes |

> [!hint] 判断规则
> - 非零分量数 $> m$ 一定不是基本解
> - $B^{-1}b$ 含负分量 → 不是 BFS
> - $B^{-1}b$ 含零分量 → 退化 BFS
> - BFS 个数 $\leq \binom{n}{m}$

### 1.5 顶点（极点）与 BFS 的等价性

| 几何概念 | 代数概念 |
|----------|----------|
| 极点（顶点） | 基本可行解 (BFS) |
| 约束集 $M$ | $\{x \mid Ax = b, x \geq 0\}$ |
| 相邻极点 | BFS 仅一个基向量不同 |

> **定理**：$x$ 是 $M$ 的极点 $\iff$ $x$ 是 $M$ 的 BFS。

### 1.6 对偶问题定义

| | 原始问题 (P) | 对偶问题 (D) |
|---|---|---|
| 目标 | $\min \; c^T x$ | $\max \; b^T \lambda$ |
| 约束 | $Ax = b$ | $A^T \lambda \leq c$ |
| 变量 | $x \geq 0$ | $\lambda$ 无符号限制 |

### 1.7 一般形式的对偶转化

| 原问题特征 | 对偶问题对应特征 |
|-----------|-----------------|
| $\min$ 目标 | $\max$ 目标 |
| 约束 $a_i^T x \geq b_i$ | $\lambda_i \geq 0$ |
| 约束 $a_i^T x \leq b_i$ | $\lambda_i \leq 0$ |
| 约束 $a_i^T x = b_i$ | $\lambda_i$ 自由 |
| 变量 $x_j \geq 0$ | $A_j^T \lambda \leq c_j$ |
| 变量 $x_j \leq 0$ | $A_j^T \lambda \geq c_j$ |
| 变量 $x_j$ 自由 | $A_j^T \lambda = c_j$ |

## 二、核心定理

### 2.1 LP 基本定理

> **定理**：
> 1. 若可行域 $M \neq \varnothing$，则 $M$ 必有基本可行解。
> 2. 若 LP 有最优解，则存在一个最优解是基本可行解。

> 推论：求解 LP 等价于在有限个 BFS 中寻找最优目标值。

### 2.2 单纯形法的最优性条件

判别数（检验数）：

$$
r_N = c_N^T - c_B^T B^{-1} N
$$

目标函数表达式：$z = z_0 + r_N^T x_N$，其中 $z_0 = c_B^T B^{-1} b$。

| 条件（$\min$ 问题） | 结论 |
|------|------|
| $r_N \geq 0$（所有判别数非负） | **当前 BFS 是最优解** |
| 存在 $r_j < 0$ | 让 $x_j$ 进基可降低目标函数值 |
| 存在 $r_j < 0$ 且该列所有 $a_{ij} \leq 0$ | **LP 无下界（无最优解）** |

### 2.3 弱对偶定理

> **定理**：若 $x$ 是 (P) 的可行解，$\lambda$ 是 (D) 的可行解，则：
> $$c^T x \geq \lambda^T b$$

**推论**：
- (P) 无下界 $\Rightarrow$ (D) 不可行
- (D) 无上界 $\Rightarrow$ (P) 不可行
- 若 $c^T x = \lambda^T b$，则 $x$ 和 $\lambda$ 都是各自问题的最优解

### 2.4 强对偶定理

> **定理**：若 (P) 有最优解，则 (D) 必有最优解，且最优值相等。

对偶最优解：$\lambda^T = c_B^T B^{-1}$（从最优基直接获得）。

> 直观理解：$\lambda$ 是"影子价格"——$b_i$ 增加一个单位，最优值变化 $-\lambda_i$（对 $\min$ 问题）。

### 2.5 互补松弛条件

> **定理**：$x$ 和 $\lambda$ 分别是 (P) 和 (D) 的最优解 $\iff$
> $$(c_j - \lambda^T a_j) \cdot x_j = 0, \quad \forall j = 1, \ldots, n$$

分量含义：
- $x_j > 0 \Rightarrow c_j - \lambda^T a_j = 0$（正变量对应的对偶约束取等号）
- $c_j - \lambda^T a_j > 0 \Rightarrow x_j = 0$（非紧对偶约束对应的原始变量为零）

## 三、计算要点

### 3.1 求基本解与基本可行解

**步骤**：
1. 确定 $m = \operatorname{rank}(A)$
2. 从 $n$ 列中选 $m$ 个线性无关列构成 $B$
3. 计算 $B^{-1}b$，令非基变量为 0
4. 若 $B^{-1}b \geq 0$，则为 BFS

**常见题型**：约束集为
$$
\begin{cases} 2x_1 - x_2 = 1 \\ x_1 + x_2 = 1 \\ x \geq 0 \end{cases}
$$

$$
A = \begin{bmatrix} 2 & -1 \\ 1 & 1 \end{bmatrix}, \quad b = \begin{bmatrix} 1 \\ 1 \end{bmatrix}
$$

此处 $n = m = 2$，$B = A$（满秩方阵），$x = A^{-1}b$。计算 $A^{-1}b$ 即得唯一解，检验 $x \geq 0$ 是否成立。

### 3.2 原始单纯形法操作流程

```
1. 化为标准形，构造初始单纯形表
2. 若所有判别数 r_j ≥ 0：当前解最优，停止
3. 否则选最负的 r_q 对应的列 q 进基
4. 若第 q 列所有 a_iq ≤ 0：LP 无界，停止
5. 按 θ 规则选出基行 k：θ = min{b_i / a_iq | a_iq > 0}
6. 以 a_kq 为 pivot 做行变换，返回步骤 2
```

**θ 规则**：

$$
\frac{b_k}{a_{kl}} = \min\left\{\frac{b_i}{a_{il}} \;\middle|\; a_{il} > 0\right\}
$$

**单纯形表结构**：

| 位置 | 内容 | 含义 |
|------|------|------|
| 基列 | 单位矩阵 | 当前基变量 |
| 上半最右列 | $B^{-1}b$ | BFS 各分量值 |
| 下半非基列 | $r_N = c_N^T - c_B^T B^{-1}N$ | 判别数 |
| 右下角 | $-c_B^T B^{-1}b = -z_0$ | 目标值相反数 |

### 3.3 两阶段法（Phase I + Phase II）

**适用场景**：标准化后无自然基（系数矩阵不含完整单位矩阵）。

**Phase I**：构造人工 LP：

$$
\min \; e^T y, \quad \text{s.t.} \; [A, I_m]\begin{bmatrix} x \\ y \end{bmatrix} = b, \; x \geq 0, y \geq 0
$$

- 用单纯形法求解 $\min e^T y$
- 若最优值 $> 0$：原问题**不可行**
- 若最优值 $= 0$ 且基全是 $x$ 的分量：得到初始 BFS，进入 Phase II
- 若最优值 $= 0$ 但有人工变量仍在基中：退化情形，通过 pivot 换出或删去冗余行

**Phase II**：擦除人工变量列，替换目标函数行为原问题的 $c^T$，消去基变量对应的判别数，正常单纯形迭代。

### 3.4 大M法

**方法**：目标函数加惩罚项

$$
\min \; c^T x + M e^T y
$$

其中 $M > 0$ 充分大。优点是一阶段求解；缺点是 $M$ 太大导致数值病态。

**定理**：若 $(P_1)$ 有最优解 $[x^*, y^*]$：
- $y^* = 0 \Rightarrow x^*$ 是 $(P_0)$ 最优解
- $y^* \neq 0 \Rightarrow (P_0)$ 无最优解

### 3.5 从最终单纯形表获取对偶最优解

对偶最优解：$\lambda^T = c_B^T B^{-1}$

**操作方法**：初始单位矩阵（松弛变量/人工变量列）在最终单纯形表中对应的判别数**取负**即为对偶最优解。或者直接求解 $\lambda^T B = c_B^T$。

### 3.6 对偶单纯形法

**适用场景**：判别数已全部 $\geq 0$（对偶可行），但 $b$ 有负分量（原始不可行）。

**与原始单纯形的对称**：

|       | 原始单纯形法                                 | 对偶单纯形法                                    |
| ----- | -------------------------------------- | ----------------------------------------- |
| 顺序    | 先选列（进基），后选行（出基）                        | **先选行（出基）**，后选列（进基）                       |
| 行/列选择 | 最负 $r_j$ 决定进基列                         | 最负 $b_k$ 决定出基行                            |
| 对立选择  | $\min\{b_i / a_{il} \mid a_{il} > 0\}$ | $\min\{r_j / (-a_{kj}) \mid a_{kj} < 0\}$ |
|       |                                        |                                           |

**对偶单纯形法单步**：

```
1. 若所有 b_i ≥ 0：已最优，停止
2. 选最负的 b_k，对应的行 k 出基
3. 若第 k 行所有 a_kj ≥ 0：LP 不可行，停止
4. 在 a_kj < 0 的列中，选 r_j / (-a_kj) 最小的列进基
5. 以 a_kr 为 pivot 做行变换，返回步骤 1
```

### 3.7 方法选择决策

| 初始表状态 | 选用方法 |
|-----------|----------|
| $b \geq 0$，$r_N$ 不全 $\geq 0$ | **原始单纯形法** |
| $b \geq 0$，$r_N \geq 0$ | 已最优 |
| $b$ 有负，$r_N \geq 0$ | **对偶单纯形法** |
| $b$ 有负，$r_N$ 不全 $\geq 0$ | 两阶段法或大M法 |

### 3.8 写对偶问题的标准流程

**步骤**：
1. 将原问题写成标准形式：$\min c^T x$ s.t. $Ax = b, x \geq 0$
2. 若不是标准形式，先用转化规则（$\max \to \min$，$\leq \to$ 松弛变量等）标准化
3. 对偶问题：$\max b^T \lambda$ s.t. $A^T \lambda \leq c$，$\lambda$ 对应等式约束故无符号限制

**一般形式的直接对偶转化**（无须标准化，直接套用转化表）：

原始问题：
$$
\begin{aligned}
\min \quad & 8x_1 + 6x_2 + 3x_3 + 6x_4 \\
\text{s.t.} \quad & x_1 + 2x_2 + x_4 \geq 3 \\
& 3x_1 + x_2 + x_3 + x_4 \geq 6 \\
& x_3 + x_4 \geq 2 \\
& x_i \geq 0
\end{aligned}
$$

对偶问题：$\max 3\lambda_1 + 6\lambda_2 + 2\lambda_3$，约束：
$$
\begin{aligned}
\lambda_1 + 3\lambda_2 &\leq 8 \\
2\lambda_1 + \lambda_2 &\leq 6 \\
\lambda_2 + \lambda_3 &\leq 3 \\
\lambda_1 + \lambda_2 + \lambda_3 &\leq 6 \\
\lambda_j &\geq 0
\end{aligned}
$$

## 四、典型易错点

> [!warning] 单纯形法中判别数的符号方向
> 本章讨论 $\min$ 问题：$r_N \geq 0$ 最优。若原问题是 $\max$，需化为 $\min -c^T x$，或用等价规则：$\max$ 问题下 $r_N \leq 0$ 最优。

> [!warning] θ 规则只考虑 $a_{il} > 0$ 的行
> $b_i / a_{il}$ 只对 $a_{il} > 0$ 计算。忽略 $a_{il} \leq 0$ 的行。若所有 $a_{il} \leq 0$，LP 无下界。

> [!warning] 标准化时注意松弛变量 vs 剩余变量
> - $a_i^T x \leq b_i$：$a_i^T x + s_i = b_i$（松弛变量 $+$）
> - $a_i^T x \geq b_i$：$a_i^T x - s_i = b_i$（剩余变量 $-$）
> 搞错符号会导致 $b$ 变负。

> [!warning] 两阶段法中 Phase I 最后一张表 $\neq$ Phase II 第一张表
> Phase I 结束后需：(1) 删去人工变量列；(2) 替换判别数行为原目标 $c^T$；(3) 行变换消去基变量对应的判别数。

> [!warning] 对偶变元的符号由原约束方向决定
> $\geq$ 约束 $\to \lambda_i \geq 0$；$\leq$ 约束 $\to \lambda_i \leq 0$；$=$ 约束 $\to \lambda_i$ 自由。不要写反。

> [!warning] 弱对偶给出下界，强对偶才能保证最优值相等
> 弱对偶 $c^T x \geq \lambda^T b$ 总是成立。强对偶 $c^T x^* = \lambda^{*T} b$ 需要 LP 有最优解才成立。

> [!warning] 对偶单纯形法的 pivot 必须取负
> $a_{kr} < 0$ 是必要条件。若出基行所有元素 $\geq 0$，则原问题不可行。

> [!warning] 退化 BFS 的基可能不唯一
> 退化 BFS 中某基变量为 0，可以用另一列替换得到不同的基表示同一个极点。退化可能导致单纯形法理论上循环（实践中极少）。

## 六、典型考题速览

1. **基本解与 BFS 判断**：给定 $A$ 和 $b$，枚举基本解并判断是否为 BFS，识别退化 BFS
2. **标准化**：将一般 LP（含 $\max$/$\min$、$\leq$/$\geq$/$=$、自由变量、$b_i < 0$）化为标准形
3. **单纯形表迭代**：给定初始单纯形表，完成若干步到最优（含 θ 规则和 pivot 操作）
4. **对偶问题书写**：给定原 LP，写出对偶 LP
5. **从最终表获取对偶解**：给出最终单纯形表，提取对偶最优解 $\lambda^*$
6. **两阶段法 / 大M法**：对无自然基的 LP 进行完整求解
7. **互补松弛应用**：已知一方最优解，用互补松弛求另一方最优解
