# 卡诺循环与卡诺定理

## 一句话

卡诺循环是最理想的热机循环——由两条等温线和两条绝热线组成，其效率 $\eta = 1 - T_2/T_1$ 只取决于两个热源温度，是一切热机效率的上限。

## 严格定义

**卡诺循环**（四步均可逆）：温度为开尔文绝对温度，$T_1>T_2>0$；下文效率上界限定在这两个热源之间工作的循环热机。

```
a → b: 等温膨胀（T₁，从高温热源吸热 Q₁）
b → c: 绝热膨胀（T₁ → T₂，降温）
c → d: 等温压缩（T₂，向低温热源放热 Q₂）
d → a: 绝热压缩（T₂ → T₁，升温）
```

**卡诺热机效率**：

$$
\boxed{\eta = 1 - \frac{T_2}{T_1}}
$$

> [!important] 卡诺定理（核心结论）
> 1. 在 $T_1, T_2$ 间工作的**所有可逆热机**，效率相等：$\eta = 1 - T_2/T_1$（与工作物质无关）
> 2. 在 $T_1, T_2$ 间工作的**不可逆热机**，效率不可能高于可逆热机：$\eta < 1 - T_2/T_1$
>
> 合并：$\boxed{\eta \leq 1 - \dfrac{T_2}{T_1}}$

**卡诺制冷系数**：

$$
\boxed{\varepsilon = \frac{Q_2}{A} = \frac{T_2}{T_1 - T_2}}
$$

## 推导：卡诺效率的计算

> [!proof]- 推导
> 以下以常热容理想气体为工质推导；四过程均可逆。效率结论本身不限于理想气体。
>
> **等温膨胀（a→b, $T_1$）**：$Q_1 = A_{ab} = \nu RT_1 \ln\frac{V_b}{V_a} > 0$
>
> **绝热膨胀（b→c）**：$Q = 0$
>
> **等温压缩（c→d, $T_2$）**：$Q_2 = |A_{cd}| = \nu RT_2 \ln\frac{V_c}{V_d} > 0$（取绝对值，放热）
>
> **绝热压缩（d→a）**：$Q = 0$
>
> 由绝热关系 $T_1 V_b^{\gamma-1} = T_2 V_c^{\gamma-1}$ 和 $T_1 V_a^{\gamma-1} = T_2 V_d^{\gamma-1}$，相除得 $\frac{V_b}{V_a} = \frac{V_c}{V_d}$。
>
> 因此 $\frac{Q_2}{Q_1} = \frac{T_2}{T_1}$，代入 $\eta = 1 - Q_2/Q_1$ 得 $\eta = 1 - T_2/T_1$。
>
> 核心洞察：体积比恰好相等使 $Q_2/Q_1 = T_2/T_1$，效率与工作物质和具体体积无关。

## 关键性质

### 可逆过程 vs 不可逆过程

| | 可逆过程 | 不可逆过程 |
|------|----------|------------|
| 系统和外界能否复原 | 能完全复原 | 不能完全复原 |
| 与准静态的关系 | **可逆 ⇒ 准静态**（必要条件） | 非准静态一定不可逆 |
| 实例 | 无摩擦的准静态绝热压缩 | 热传导、摩擦生热、气体自由膨胀 |
| 热机效率 | $\eta = 1 - T_2/T_1$ | $\eta < 1 - T_2/T_1$ |

> [!warning] 准静态 $\neq$ 可逆：有摩擦的准静态过程仍是不可逆的

### 卡诺定理的证明思路（反证法）

假设存在效率更高的热机 → 将其与逆循环的卡诺制冷机联合 → 热量自动从低温传到高温 → 违反热力学第二定律。

## 典型例题

> **题目**（习题8-11）：一卡诺热机在 $T_1 = 400\text{ K}$ 和 $T_2 = 300\text{ K}$ 之间工作。求：（1）热机效率；（2）若保持 $T_2$ 不变并提高 $T_1$，使效率变为原来的 1.5 倍，求新的 $T_1$。

> [!example]- 解答
> （1）$\eta = 1 - 300/400 = 0.25 = 25\%$
>
> （2）新效率 $\eta' = 1.5 \times 0.25 = 0.375$。
> $\eta' = 1 - T_2/T_1' \Rightarrow T_1' = \frac{T_2}{1-\eta'} = \frac{300}{1-0.375} = 480\text{ K}$。
>
> 提高效率的策略：提高高温热源温度（$T_1 \uparrow$）或降低低温热源温度（$T_2 \downarrow$）。
>
> 点评：卡诺效率只取决于两个热源的温度——这是卡诺定理的核心结论。

> **题目**（习题8-13）：一卡诺制冷机在 $T_1 = 300\text{ K}$（室内）和 $T_2 = 260\text{ K}$（冷库）间工作。要从冷库抽走 $1.0 \times 10^4\text{ J}$ 的热量，需要消耗多少电能？

> [!example]- 解答
> 卡诺制冷系数：$\varepsilon = \frac{T_2}{T_1 - T_2} = \frac{260}{300 - 260} = 6.5$
>
> 消耗的电功：$|A| = \frac{Q_2}{\varepsilon} = \frac{1.0 \times 10^4}{6.5} \approx 1.54 \times 10^3\text{ J}$
>
> 点评：制冷系数 > 1 意味着消耗 1J 的电能从冷库抽走多于 1J 的热量——这并不违反能量守恒，因为向室内排放的总热量是 $Q_1 = Q_2 + |A|$。

## 易错点

> [!warning] 易错点
> 1. **卡诺效率公式只对可逆卡诺热机成立**：不可逆热机效率**小于** $1 - T_2/T_1$，不是等于
> 2. **可逆 ⇒ 准静态，但准静态 ⇏ 可逆**：有摩擦的准静态过程不可逆（产生了耗散）
> 3. **卡诺定理不单指卡诺循环**：任何在两个恒温热源之间工作的可逆循环，效率都等于卡诺效率——不一定要是卡诺循环的形状
> 4. **$T$ 必须是开尔文温度**：用摄氏温度代入 $\eta = 1-T_2/T_1$ 会得到荒谬结果
