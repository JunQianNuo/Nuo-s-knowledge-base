# II. 线性方程组的直接解法（第3章）

> 一句说清：通过行变换将 $A$ 化为上三角 $U$ → 回代得解。直接法 $O(n^3)$，误差由条件数控制——条件数大则再小的残差也不保证精度。

---

## 一、核心定义速查

### 1.1 Gauss 消元与 LU 分解

| 概念 | 定义 | 关键 |
|------|------|------|
| 行初等运算 | 交换、非零倍乘、倍加 | 同解变换（不改变解） |
| Gauss 消元 | 逐列消去对角线以下元素 → 上三角 $U$ | 消元 $O(\frac{2}{3}n^3)$，回代 $O(n^2)$ |
| LU 分解 | $A = LU$（$L$ 下三角，$U$ 上三角） | Doolittle：$L$ 对角元为 1；Crout：$U$ 对角元为 1 |
| 回代公式 | $x_i = (b_i - \sum_{j=i+1}^n a_{ij}x_j)/a_{ii}$ | 从 $x_n$ 向上求 |
| 列主元策略 | 每列选 $\max |a_{ji}|$（$j\geq i$）→ 交换到主元位 | $PA = LU$，总存在 |

### 1.2 范数

| 范数 | 公式 | 含义 |
|------|------|------|
| $\|x\|_1$ | $\sum \|x_i\|$ | 曼哈顿距离 |
| $\|x\|_2$ | $\sqrt{\sum x_i^2}$ | 欧氏距离 |
| $\|x\|_\infty$ | $\max_i \|x_i\|$ | 最大分量 |
| $\|A\|_1$ | $\max_j \sum_i \|a_{ij}\|$ | 最大绝对列和 |
| $\|A\|_\infty$ | $\max_i \sum_j \|a_{ij}\|$ | 最大绝对行和 |
| 算子范数 | $\|A\| = \max_{x\neq0} \frac{\|Ax\|}{\|x\|}$ | 矩阵的最大拉伸倍数 |

### 1.3 条件数与误差

| 概念 | 定义 |
|------|------|
| 条件数 | $\mathrm{cond}(A) = \|A\| \cdot \|A^{-1}\|$ |
| 前向误差 | $\|x_a - x\|$（答案差多少） |
| 后向误差/残差 | $\|r\| = \|b - Ax_a\|$（代入剩多少） |
| 严格行对角占优 | $\|a_{ii}\| > \sum_{j\neq i} \|a_{ij}\|$ |

---

## 二、核心定理

### 2.1 LU 分解存在性

$A$ 的所有前主子式非奇异 $\implies$ $A$ 有 LU 分解。不选主元下的 Gauss 消元等价于 $A = LU$。

### 2.2 Doolittle 递推公式

$$\begin{aligned} u_{kj} &= \left(a_{kj} - \sum_{s=1}^{k-1} l_{ks}u_{sj}\right) / l_{kk} \quad (k \leq j \leq n) \\ l_{ik} &= \left(a_{ik} - \sum_{s=1}^{k-1} l_{is}u_{sk}\right) / u_{kk} \quad (k < i \leq n) \end{aligned}$$

求解顺序：$u_{11} \to l_{i1},u_{1j} \to u_{22} \to l_{i2},u_{2j} \to \cdots \to u_{nn}$

### 2.3 条件数误差不等式

$$\frac{1}{\mathrm{cond}(A)}\frac{\|r\|_\infty}{\|b\|_\infty} \leq \frac{\|x_a-x\|_\infty}{\|x\|_\infty} \leq \mathrm{cond}(A)\frac{\|r\|_\infty}{\|b\|_\infty}$$

### 2.4 对角占优与不选主元

严格行对角占优矩阵 → 不选主元 Gauss 消元保持对角占优 → 可逆且有 LU 分解。

### 2.5 Gauss 消元与 LU 分解的矩阵联系

Gauss 消元的每一步行变换 = 左乘初等矩阵：$E_m \cdots E_1 A = U$ → $A = E_1^{-1}\cdots E_m^{-1} U = LU$。消元乘数 $\frac{a_{i1}}{a_{11}}$ 直接放入 $L$ 的对应位置。

---

## 三、计算要点

### 3.1 Gauss 消元求解

**步骤**：
1. 第1列消元：$a_{ij} \leftarrow a_{ij} - \frac{a_{i1}}{a_{11}}a_{1j}$，$b_i \leftarrow b_i - \frac{a_{i1}}{a_{11}}b_1$（$i=2,\ldots,n$）
2. 逐列重复，共 $n-1$ 轮
3. 回代：$x_n = b_n/a_{nn}$，逐层向上

### 3.2 Doolittle 分解

按递推公式逐层求 $u_{kj}$ 和 $l_{ik}$。得到 $L,U$ 后：$Ly=b$（前代）→ $Ux=y$（回代）。

**例**：$A = \begin{pmatrix}1&2&-1\\2&1&-2\\-3&1&1\end{pmatrix}$ → $L=\begin{pmatrix}1&0&0\\2&1&0\\-3&7/3&1\end{pmatrix}, U=\begin{pmatrix}1&2&-1\\0&-3&0\\0&0&2\end{pmatrix}$

### 3.3 范数与条件数计算

- $\|A\|_1$ = 逐列求和取最大；$\|A\|_\infty$ = 逐行求和取最大
- $\mathrm{cond}(A) = \|A\| \cdot \|A^{-1}\|$
- 条件数大 → 病态：残差小不保证前向误差小

**例**：$A = \begin{pmatrix}1&1\\1.0001&1\end{pmatrix}$，$\mathrm{cond}(A) \approx 40000$——系数仅变化万分之一，条件数已达四万。

### 3.4 综合例题（纲要指定）

用 Gauss 消元法、列主元消元法、LU 分解法求解：
$$A = \begin{pmatrix}3&1&2\\6&3&4\\3&2&5\end{pmatrix},\; b = \begin{pmatrix}11\\24\\22\end{pmatrix}$$

Gauss 消元：第1列 → 第2列 → 回代得 $x=(3,0,2)^T$。

### 3.5 小主元问题与列主元

每列消元前找该列绝对值最大元素所在行 → 交换到主元位置 → 再消元。等价于 $PA=LU$。

## 四、典型易错点

> [!warning] **求 $A^{-1}$ 求逆几乎永远不是正确答案**
> $x = A^{-1}b$ 比直接消元贵得多且数值更不稳定。实际中总是用 LU 分解。

> [!warning] **条件数大 ≠ 算不对，但残差小 ≠ 答案准**
> 条件数大意味着即使残差极小，前向误差仍可能很大。这就是"病态"的含义。

> [!warning] **Hilbert 矩阵是经典病态矩阵**
> $H_{ij} = 1/(i+j-1)$，$H_{20}$ 条件数 $\approx 10^{28}$，双精度全不够。

> [!warning] **范数选择影响条件数大小**
> $\mathrm{cond}_1, \mathrm{cond}_2, \mathrm{cond}_\infty$ 数值不同但都反映矩阵的病态程度。

> [!warning] **LU 分解可能不存在**
> 即使 $A$ 可逆也可能无 LU 分解（如 $\begin{pmatrix}0&1\\1&0\end{pmatrix}$）。列主元 $PA=LU$ 总存在。
