# III. 线性方程组的迭代法（第4章）

> 一句说清：分裂 $A = Q - (Q-A)$，迭代 $Qx_{k+1}=(Q-A)x_k+b$——$Q$ 越接近 $A$ 收敛越快，$Q$ 越对角/三角每步越便宜。收敛充要条件：$\rho(G) < 1$。

---

## 一、核心定义速查

### 1.1 统一框架

| 概念 | 定义 |
|------|------|
| 分裂矩阵形式 | $Qx_{k+1} = (Q-A)x_k + b$（$Q$ 可逆） |
| 不动点形式 | $x_{k+1} = Gx_k + c$，$G = I - Q^{-1}A$，$c = Q^{-1}b$ |
| 设计原则 | $Q$ 易求逆（每步便宜）+ $\rho(G) < 1$（收敛） |

### 1.2 四种迭代方法

| 方法 | $Q$ | 迭代矩阵 $G$ | 特点 |
|------|-----|-----|------|
| Richardson | $I$ | $I-A$ | 最简单，收敛苛刻 |
| Jacobi | $D$（对角） | $-D^{-1}(L+U)$ | 天然并行，全部用旧值 |
| Gauss-Seidel | $D+L$（下三角） | $-(L+D)^{-1}U$ | 用最新值，通常更快 |
| SOR | $\frac{1}{\omega}(D+\omega L)$ | $(D+\omega L)^{-1}[(1-\omega)D-\omega U]$ | $\omega=1$→GS；$\omega>1$→超松弛（加速）；$\omega<1$→欠松弛（求稳） |

其中 $A = D + L + U$（$D$=对角、$L$=严格下三角、$U$=严格上三角）。

### 1.3 谱半径

| 概念 | 定义 |
|------|------|
| 谱半径 | $\rho(A) = \max_i \|\lambda_i(A)\|$（仅方阵） |
| 与范数关系 | $\rho(A) \leq \|A\|$（任意算子范数）；存在算子范数 $\|\cdot\|^*$ 使 $\|A\|^* \leq \rho(A)+\epsilon$（$\epsilon>0$ 任意小） |

---

## 二、核心定理

### 2.1 Neumann 级数定理

若 $\|G\| < 1$，则 $I-G$ 可逆，$(I-G)^{-1} = \sum_{k=0}^\infty G^k$。

### 2.2 迭代收敛定理（范数充分条件）

$\|G\| = \delta < 1$ $\implies$ 迭代收敛，$\displaystyle \|x-x_k\| \leq \frac{\delta^k}{1-\delta}\|x_1-x_0\|$。

### 2.3 迭代收敛定理（谱半径充要条件）★

迭代 $x_{k+1}=Gx_k+c$ 对任意初值收敛 $\iff \rho(G) < 1$。$\rho(G)$ 越小收敛越快。

### 2.4 实用收敛判据

| 条件 | 结论 |
|------|------|
| $A$ 严格行对角占优 | Jacobi 收敛 |
| $A$ 严格行对角占优 | Gauss-Seidel 收敛 |
| $0 < \omega < 2$ | SOR 收敛的必要条件 |

---

## 三、计算要点

### 3.1 写出 Jacobi 迭代公式

$$x_i^{(k+1)} = \frac{b_i - \sum_{j\neq i} a_{ij}x_j^{(k)}}{a_{ii}}$$

**例**（$3u+v=5, u+2v=5$）：$\begin{cases} u_{k+1} = (5-v_k)/3 \\ v_{k+1} = (5-u_k)/2 \end{cases}$

### 3.2 写出 Gauss-Seidel 迭代公式

$$x_i^{(k+1)} = \frac{b_i - \sum_{j<i} a_{ij}x_j^{(k+1)} - \sum_{j>i} a_{ij}x_j^{(k)}}{a_{ii}}$$

**同一例**：$\begin{cases} u_{k+1} = (5-v_k)/3 \\ v_{k+1} = (5-u_{k+1})/2 \end{cases}$（$v_{k+1}$ 用刚算出的 $u_{k+1}$）

### 3.3 判断收敛性

1. 计算迭代矩阵 $G = I - Q^{-1}A$
2. 求 $\rho(G) = \max|\lambda_i(G)|$
3. $\rho(G) < 1$ → 收敛；$\rho(G) \geq 1$ → 不保证

**不收敛时的处理**：重排方程顺序使 $A$ 变为严格对角占优。

**例**：方程组 $\begin{cases} u - 8v - 2w = 1 \\ u + v + 5w = 4 \\ 3u - v + w = -2 \end{cases}$，重排为 $\begin{cases} 3u - v + w = -2 \\ u - 8v - 2w = 1 \\ u + v + 5w = 4 \end{cases}$ → 对角占优 → Jacobi/GS 收敛。

---

## 四、典型易错点

> [!warning] **$\|G\| < 1$ 是充分非必要条件**
> 可能 $\|G\| > 1$ 但 $\rho(G) < 1$，迭代仍收敛。谱半径才是终极判据。

> [!warning] **Jacobi vs Gauss-Seidel：不保证 GS 更快**
> 大多数情况 GS 更快，但存在 Jacobi 收敛而 GS 发散的特例。

> [!warning] **SOR 的 $\omega$ 需要调优**
> $\omega=1$ 即 Gauss-Seidel；$\omega \in (1,1.5)$ 常最优；$\omega \geq 2$ 必发散。

> [!warning] **谱半径 vs 谱范数**
> $\rho(A)$ 只对方阵有定义。非对称时 $\rho(A)$ 可能远小于 $\|A\|_2$。

> [!warning] **迭代法优势在大规模稀疏**
> 直接法 $O(n^3)$，迭代法 $O(k n^2)$（密集）或 $O(kn)$（稀疏）。$n=10^5$ 稀疏矩阵：Gauss 消元需 80GB 内存，迭代法只需几 MB。
