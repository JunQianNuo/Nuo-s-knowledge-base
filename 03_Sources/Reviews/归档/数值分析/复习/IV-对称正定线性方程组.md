# IV. 对称正定线性方程组（第5章）

> 一句说清：SPD 结构同时给了两条捷径——Cholesky 比 LU 快一倍存储省一半（直接法）；$Ax=b \iff \min q(x)$ 引出梯度下降和共轭梯度（迭代法），后者 $n$ 步精确。

---

## 一、核心定义速查

### 1.1 对称正定（SPD）矩阵

| 概念 | 定义 | 判据 |
|------|------|------|
| 对称 | $A^T = A$ | — |
| 正定 | $\forall x \neq 0, x^T A x > 0$ | 特征值全正 / 顺序主子式全正（Sylvester） |
| SPD 性质 | 可逆、主子式 SPD、特征值 $>0$、$P^TAP$ 亦 SPD（$P$ 满秩） | — |

### 1.2 Cholesky 分解

| 概念 | 公式 | 计算量 |
|------|------|:---:|
| Cholesky | $A = LL^T$，$L$ 下三角 | $\frac{1}{3}n^3$ |
| LU 分解 | $A = LU$ | $\frac{2}{3}n^3$ |

递推：$l_{kk} = \sqrt{a_{kk} - \sum_{s=1}^{k-1} l_{ks}^2}$，$l_{ik} = (a_{ik} - \sum_{s=1}^{k-1} l_{is}l_{ks})/l_{kk}$

### 1.3 二次型等价

$A$ SPD $\implies$ $Ax=b \iff \arg\min_x q(x) = \frac{1}{2}x^T A x - x^T b$

### 1.4 A-共轭

| 概念 | 定义 |
|------|------|
| A-内积 | $\langle v,w\rangle_A = v^T A w$ |
| A-共轭 | $\langle v,w\rangle_A = 0$ |

---

## 二、核心定理

### 2.1 Cholesky 分解存在定理

$A$ 实对称正定 $\implies$ 存在唯一的下三角 $L$（对角元 $>0$）使 $A = LL^T$。

### 2.2 梯度下降框架

$$x_{k+1} = x_k + t_k v_k, \quad t_k = \frac{\langle r_k, v_k\rangle}{\langle v_k, A v_k\rangle}, \quad r_k = b - Ax_k$$

性质：$\langle r_{k+1}, v_k\rangle = 0$。最速下降取 $v_k = r_k$（负梯度）。

### 2.3 共轭方向法有限步终止

沿 $n$ 个 A-共轭方向各做一次精确线搜索 → 精确解。三条不变性质：残差正交、方向 A-共轭、空间张成。

### 2.4 CG 算法

```
r₀ = b - Ax₀,  v₀ = r₀
for k = 0,1,...:
    t_k = ⟨r_k, r_k⟩ / ⟨v_k, Av_k⟩
    x_{k+1} = x_k + t_k v_k
    r_{k+1} = r_k - t_k Av_k
    s_k = ⟨r_{k+1}, r_{k+1}⟩ / ⟨r_k, r_k⟩
    v_{k+1} = r_{k+1} + s_k v_k
```

## 三、计算要点

### 3.1 判断正定性

① 检查对称性 ② 计算特征值（全正→正定）或用 Sylvester 准则（顺序主子式全正）。

### 3.2 Cholesky 分解

**例**：$A = \begin{pmatrix}4&-2&2\\-2&2&-4\\2&-4&11\end{pmatrix}$ →
$L = \begin{pmatrix}2&0&0\\-1&1&0\\1&-3&1\end{pmatrix}$，计算量 $\approx \frac{1}{3}n^3$。

**解方程**：$Ly=b$（前代）→ $L^T x = y$（回代）。

### 3.3 梯度下降一步

给定 $x_0$：① $r_0 = b - Ax_0$ ② $t_0 = \|r_0\|^2 / (r_0^T A r_0)$ ③ $x_1 = x_0 + t_0 r_0$

**例**：$A=\begin{pmatrix}2&2\\2&5\end{pmatrix}, b=\begin{pmatrix}6\\3\end{pmatrix}, x_0=(0,0)^T$：
$r_0 = (6,3)^T$，$t_0 = \frac{36+9}{6^2\cdot2+2\cdot6\cdot3\cdot2+3^2\cdot5} = \frac{45}{189}=0.238$，
$x_1 = (0,0)^T + 0.238(6,3)^T = (1.43,0.71)^T$（真解 $(2,-1)^T$）。

**zigzag 现象**：最速下降在扁长椭球等值线上路径来回振荡——条件数越大越严重。本例 $\mathrm{cond}(A)\approx10$，收敛慢。

### 3.4 共轭梯度 vs 梯度下降

CG 利用 $A$-共轭方向，理论 $n$ 步精确。上述同一例 $x_0=(0,0)^T$，CG 两步到精确解 $(2,-1)^T$——而梯度下降需数十步。

## 四、典型易错点

> [!warning] **Cholesky 只适用于 SPD 矩阵**
> 非 SPD 的对称矩阵会出现负数开方。此时用 $LDL^T$ 分解替代。

> [!warning] **梯度下降的 zigzag 现象**
> 最速下降"最速"仅限局部——扁长椭球等值线上路径来回振荡，收敛极慢。条件数越大越严重。

> [!warning] **共轭梯度 $n$ 步收敛是理论结果**
> 精确算术下必在 $n$ 步收敛；浮点运算中因舍入破坏正交性需更多步。实际常配合预处理。
