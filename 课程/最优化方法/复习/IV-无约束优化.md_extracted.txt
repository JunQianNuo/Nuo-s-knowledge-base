# IV. 无约束优化（第8-11章）

> 本章覆盖无约束优化的四大方法族：梯度法、牛顿法、共轭梯度法、拟牛顿法。核心线索是从"仅用一阶信息"到"利用二阶信息"再到"近似二阶信息"的演进——每一步都是为了在收敛速度与计算代价之间取得更好的平衡。

---

## 一、四大方法族总览

### 1.1 方法对比

| 维度 | 梯度法 | 牛顿法 | 共轭梯度法 | 拟牛顿法 (BFGS) |
|------|--------|--------|-----------|----------------|
| **使用信息** | 一阶（梯度） | 二阶（梯度 + Hessian） | 一阶（梯度 + 历史方向） | 一阶（梯度 + 历史更新） |
| **迭代格式** | $x_{k+1} = x_k - \alpha_k \nabla f(x_k)$ | $x_{k+1} = x_k - H_k^{-1} \nabla f(x_k)$ | $x_{k+1} = x_k + \alpha_k p_k$, $p_k = -\nabla f(x_k) + \beta_{k-1} p_{k-1}$ | $x_{k+1} = x_k - B_k^{-1} \nabla f(x_k)$，$B_k$ 由更新公式维护 |
| **每步计算量** | $O(n)$ | $O(n^3)$ | $O(n)$ | $O(n^2)$ |
| **存储量** | $O(n)$ | $O(n^2)$ | $O(n)$ | $O(n^2)$ |
| **二次函数收敛** | 线性收敛，需要多次迭代 | **一步终止** | 至多 $n$ 步终止 | 至多 $n$ 步终止（共轭特征定理） |
| **一般函数收敛** | 线性收敛 | **局部二次收敛** | 超线性（非线性 CG 需 restart） | **超线性收敛**（实践中接近牛顿法） |
| **收敛率常数** | $\left(\frac{\lambda_{\max}-\lambda_{\min}}{\lambda_{\max}+\lambda_{\min}}\right)^2$ | 局部误差平方缩小 | — | — |
| **全局收敛性** | 有（带线搜索） | 仅局部（需修正） | 有（带线搜索） | 有（带线搜索 + 曲率条件） |
| **Hessian 要求** | 不需要 | 需要，正定 | 不需要 | 不需要（通过更新近似） |
| **适用场景** | 大规模 + 低精度 | 中小规模 + 高精度 | 大规模 + 中等精度 | 中等规模 + 高精度 |

### 1.2 收敛阶定义

设 $\{x_k\}$ 收敛到 $x^*$：

$$\lim_{k \to \infty} \frac{\|x_{k+1} - x^*\|}{\|x_k - x^*\|^p} = L \in (0, \infty)$$

| 类型                    | $p$ |      $L$       | 典型序列             | 含义        |     |
| --------------------- | :-: | :------------: | ---------------- | --------- | --- |
| **次线性** (sublinear)   | $1$ |      $1$       | $x_k = 1/k$      | 收敛最慢      |     |
| **线性** (linear)       | $1$ |    $(0, 1)$    | $x_k = \gamma^k$ | 每步误差按比例缩小 |     |
| **超线性** (superlinear) | $1$ | $0$（或 $p > 1$） | 拟牛顿法             | 比线性快      |     |
| **二次** (quadratic)    | $2$ |       —        | $\gamma^{2^k}$   | 每步误差平方缩小  |     |

> [!hint] 数值表现差异
> - 线性收敛：误差 $10^{-1} \to 10^{-2} \to 10^{-3} \to 10^{-4}$（恒定比例）
> - 二次收敛：误差 $10^{-1} \to 10^{-2} \to 10^{-4} \to 10^{-8}$（有效数字翻倍）
> - 次线性收敛：误差 $1 \to 1/2 \to 1/3 \to 1/4$（越来越慢）

## 二、梯度下降法（第8章）

### 2.1 迭代格式

$$\boxed{x_{k+1} = x_k - \alpha_k \nabla f(x_k)}$$

| 方法变体      | 步长选取                                                                       |
| --------- | -------------------------------------------------------------------------- |
| 梯度下降法     | $\alpha_k$ 可固定、可衰减、可精确搜索                                                   |
| **最速下降法** | $\alpha_k = \arg\min_{\alpha \geq 0} f(x_k - \alpha \nabla f(x_k))$（精确线搜索） |

### 2.2 核心性质

**性质1（正交性/锯齿现象）**：最速下降法的相邻梯度正交：

$$\nabla f(x_{k+1}) \perp \nabla f(x_k)$$

**证明**：令 $\phi(\alpha) = f(x_k - \alpha \nabla f(x_k))$，$\alpha_k$ 是极小点，故 $\phi'(\alpha_k) = 0$。由链式法则：

$$\phi'(\alpha_k) = -\nabla f(x_{k+1})^T \nabla f(x_k) = 0$$

**性质2（严格下降）**：若 $\nabla f(x_k) \neq 0$，则 $f(x_{k+1}) < f(x_k)$。

### 2.3 二次函数的精确步长

若 $f(x) = \frac{1}{2} x^T Q x - b^T x$（$Q \succ 0$）：

$$\boxed{\alpha_k = \frac{(g_k)^T g_k}{(g_k)^T Q g_k}}$$

其中 $g_k = \nabla f(x_k) = Q x_k - b$。

### 2.4 收敛性分析

**分析框架**：定义 $V(x) = f(x) - f(x^*) = \frac{1}{2} \|x - x^*\|_Q^2$（到极小点的加权距离）。

**递推关系**：

$$V(x_{k+1}) = (1 - \gamma_k) V(x_k)$$

其中：

$$\gamma_k = \frac{((g_k)^T g_k)^2}{((g_k)^T Q g_k)((g_k)^T Q^{-1} g_k)} \in (0, 1]$$

**Kantorovich 不等式**给出 $\gamma_k$ 的与 $x$ 无关的正下界：

$$\gamma_k \geq \frac{4 \lambda_{\max} \lambda_{\min}}{(\lambda_{\max} + \lambda_{\min})^2}$$

**收敛率**：

$$\boxed{V(x_{k+1}) \leq \left( \frac{\lambda_{\max} - \lambda_{\min}}{\lambda_{\max} + \lambda_{\min}} \right)^2 V(x_k)}$$

记 $c = \left(\frac{\lambda_{\max} - \lambda_{\min}}{\lambda_{\max} + \lambda_{\min}}\right)^2 = \left(\frac{\kappa - 1}{\kappa + 1}\right)^2$，其中 $\kappa = \lambda_{\max}/\lambda_{\min}$ 是条件数。

| $\kappa$ | $c$ | 收敛行为 |
|:---:|:---:|------|
| $1$ | $0$ | 一步收敛（$Q$ 是单位阵的倍数） |
| $3$ | $0.25$ | 较快 |
| $100$ | $\approx 0.96$ | 极慢（病态问题） |

### 2.5 定步长梯度法

$$x_{k+1} = x_k - \alpha \nabla f(x_k), \quad \alpha \text{ 固定}$$

**收敛的充要条件**：$\boxed{\alpha \in \left(0, \frac{2}{\lambda_{\max}(Q)}\right)}$

取 $\alpha$ 在该区间外，即使对最简单的二次函数也可能发散。

### 2.6 停机准则

| 准则类型    | 表达式                                                           |     |     |     |     |
| ------- | ------------------------------------------------------------- | --- | --- | --- | --- |
| 一阶必要条件  | $\|\nabla f(x_k)\| < \varepsilon$                             |     |     |     |     |
| 函数值相对变化 | $\frac{f(x_{k+1})f - f(x_k)}{\max\{1,f(x_k)\}} < \varepsilon$ |     |     |     |     |
| 迭代点相对变化 | $\frac{\|x_{k+1} - x_k\|}{\max\{1, \|x_k\|\}} < \varepsilon$  |     |     |     |     |

## 三、牛顿法（第9章）

### 3.1 迭代格式

$$\boxed{x_{k+1} = x_k - [\nabla^2 f(x_k)]^{-1} \nabla f(x_k)}$$

记 $H_k = \nabla^2 f(x_k)$，$g_k = \nabla f(x_k)$。

实际实现中求解方程组 $H_k d_k = -g_k$ 获得牛顿方向 $d_k$（不显式求逆）。

### 3.2 推导

在 $x_k$ 处做二阶 Taylor 展开：

$$f(x) \approx f(x_k) + g_k^T (x - x_k) + \frac{1}{2}(x - x_k)^T H_k (x - x_k) =: m(x)$$

由 $\nabla m(x) = 0$ 得 $g_k + H_k(x - x_k) = 0$，解出 $x_{k+1} = x_k - H_k^{-1} g_k$。

> 一句话理解：牛顿法用二阶 Taylor 展开构造二次模型，直接跳到二次模型的极小点。如果 $f$ 本身是二次函数，一步到位。

### 3.3 收敛性分析（本章核心证明）

> **定理（局部二阶收敛）**：若 $f \in C^3$，$x^*$ 满足 $\nabla f(x^*) = 0$，$\nabla^2 f(x^*)$ 可逆。则对任意 $x_0$ 充分靠近 $x^*$，牛顿法有意义且迭代序列以**至少 2 阶**收敛率收敛到 $x^*$：

$$\|x_{k+1} - x^*\| \leq c_1 c_2 \|x_k - x^*\|^2$$

**证明思路**：
1. 对 $\nabla f$ 在 $x_k$ 处做 Taylor 展开，在 $x^*$ 处取值得出误差关系
2. 利用 $f \in C^3$ 和 $\nabla^2 f(x^*)$ 可逆，存在常数 $c_1, c_2 > 0$

> [!warning] "局部"是关键
> 该定理要求初始点在解附近。远离解时，牛顿法可能不收敛甚至发散。这是纯牛顿法最大的局限。

### 3.4 牛顿方向的下降性质

当 $H_k \succ 0$ 时，牛顿方向 $d_k = -H_k^{-1} g_k$ 是下降方向：

$$\phi'(0) = \nabla f(x_k)^T d_k = -g_k^T H_k^{-1} g_k < 0$$

当 $H_k$ 非正定时，牛顿方向**不是下降方向**——这是牛顿法需要修正的根本原因。

### 3.5 修正方法

**阻尼牛顿法**：引入线搜索

$$x_{k+1} = x_k - \alpha_k H_k^{-1} g_k$$

其中 $\alpha_k$ 由线搜索确定（如回溯 + Armijo），保证 $f(x_{k+1}) < f(x_k)$。

**Levenberg-Marquardt (L-M) 修正**：给 Hessian 加正则项

$$x_{k+1} = x_k - \alpha_k [H_k + \lambda I]^{-1} g_k, \quad \lambda \geq 0$$

| $\lambda$ 取值 | 行为 |
|:---:|------|
| $\lambda \to 0$ | 趋近牛顿法（二次收敛） |
| $\lambda \to \infty$ | 趋近梯度法（线性收敛，$d \approx -\frac{1}{\lambda}g$） |

### 3.6 牛顿法求解非线性方程组

解 $g(x) = 0$（$g: \mathbb{R}^n \to \mathbb{R}^n$）的牛顿法：

$$x_{k+1} = x_k - J(x_k)^{-1} g(x_k)$$

其中 $J(x)$ 是 $g$ 的 Jacobian 矩阵。一维时退化为经典 $x_{k+1} = x_k - \frac{g(x_k)}{g'(x_k)}$。

### 3.7 非线性最小二乘与高斯-牛顿法

**问题形式**：

$$\min_x \frac{1}{2} \sum_{i=1}^{m} [r_i(x)]^2 = \frac{1}{2} r(x)^T r(x)$$

**梯度与 Hessian 的特殊结构**：

$$\nabla f(x) = J(x)^T r(x)$$

$$\nabla^2 f(x) = J(x)^T J(x) + S(x)$$

其中 $J$ 是 $r$ 的 Jacobian，$S(x)$ 涉及 $r$ 的二阶导数。

**高斯-牛顿法**：省略 $S(x)$，用 $J^T J$ 近似 Hessian

$$\boxed{x_{k+1} = x_k - [J(x_k)^T J(x_k)]^{-1} J(x_k)^T r(x_k)}$$

**L-M 修正的高斯-牛顿法**：

$$x_{k+1} = x_k - [J(x_k)^T J(x_k) + \lambda I]^{-1} J(x_k)^T r(x_k)$$

**最优性条件**：$\nabla f(x) = J(x)^T r(x) = 0$——即残差向量 $r(x)$ 与 Jacobian 矩阵的各列正交。

## 四、共轭梯度法（第10章）

### 4.1 共轭方向的定义

> **定义（$Q$-共轭）**：设 $Q \in S_{++}^n$，非零向量组 $\{p_0, \dots, p_m\}$ 满足
> $$p_i^T Q p_j = 0, \quad \forall i \neq j$$
> 则称该组向量为 $Q$-共轭向量组。

**退化关系**：当 $Q = I$ 时，$Q$-共轭退化为普通正交。

**线性无关性**：$n$ 个 $n$ 维 $Q$-共轭非零向量构成 $\mathbb{R}^n$ 的一组基——保证沿着它们搜索能"到达"空间任意点。

### 4.2 共轭方向法

**算法**：给定初始点 $x_0$ 和 $Q$-共轭方向组 $\{p_0, \dots, p_{n-1}\}$：

$$\alpha_k = -\frac{g_k^T p_k}{p_k^T Q p_k}, \quad x_{k+1} = x_k + \alpha_k p_k$$

**核心定理（$n$ 步收敛）**：

$$\boxed{x_n = x^*}$$

> 对任意初始点 $x_0$，共轭方向法至多 $n$ 次迭代获得 $n$ 元二次函数的精确极小点。

**证明核心**：$\{p_i\}$ 是基，将 $x^* - x_0$ 在这组基下展开，利用共轭性证明 $\alpha_k$ 恰好等于展开系数。

### 4.3 扩展子空间定理

> **定理**：共轭方向法产生的 $x_{k+1}$ 是 $f$ 在 $k+1$ 维子空间上的全局最小点：
> $$x_{k+1} = \arg\min_{x \in V_k} f(x), \quad V_k = x_0 + \text{span}\{p_0, \dots, p_k\}$$

**含义**：每步迭代得到"逐渐扩大"的子空间上的最优解——步子不浪费。当 $k = n-1$ 时，$V_{n-1} = \mathbb{R}^n$，$x_n$ 就是全局极小点。

**推论**——梯度与历史方向正交：

$$g_{k+1}^T p_i = 0, \quad \forall 0 \leq i \leq k$$

即 $g_{k+1} \perp \text{span}\{p_0, \dots, p_k\}$。

### 4.4 共轭梯度法 — 在线生成方向

共轭梯度法不提前准备 $Q$-共轭方向，而是**边搜索边构造**：

$$\boxed{p_0 = -g_0}$$

$$\boxed{p_k = -g_k + \beta_{k-1} p_{k-1}, \quad \beta_{k-1} = \frac{g_k^T Q p_{k-1}}{p_{k-1}^T Q p_{k-1}}}$$

**有限步终止原因**：
1. $\{p_k\}$ 在线生成且保持 $Q$-共轭
2. $n$ 个 $n$ 维 $Q$-共轭向量线性无关，张成 $\mathbb{R}^n$
3. 由扩展子空间定理，到第 $n$ 步时已覆盖全空间

### 4.5 $\beta_k$ 的四种等价公式（二次函数）

| 名称 | 公式 | 特点 |
|------|------|------|
| **Hestenes-Stiefel (HS)** | $\beta_k^{\text{HS}} = \frac{g_{k+1}^T [g_{k+1} - g_k]}{p_k^T [g_{k+1} - g_k]}$ | 直接推导形式 |
| **Polak-Ribiere (PR)** | $\beta_k^{\text{PR}} = \frac{g_{k+1}^T [g_{k+1} - g_k]}{g_k^T g_k}$ | 分母为 $\|g_k\|^2$ |
| **Fletcher-Reeves (FR)** | $\beta_k^{\text{FR}} = \frac{g_{k+1}^T g_{k+1}}{g_k^T g_k}$ | **数值最稳定** |
| **Dai-Yuan (DY)** | $\beta_k^{\text{DY}} = \frac{g_{k+1}^T g_{k+1}}{p_k^T [g_{k+1} - g_k]}$ | 近年变体 |

> [!hint] 对二次函数四种公式等价；对非线性函数不等价，FR 被证明数值最稳定。

### 4.6 三种构造共轭方向的方法

| 方法 | 计算量 | 是否需要 $Q$ | 适用场景 |
|------|:---:|:---:|------|
| 待定系数法 | 手工 | 是 | 教学演示 |
| Gram-Schmidt 共轭化 | $O(n^3)$ | 是 | 理论可行但昂贵 |
| 特征值分解 | $O(n^3)$ | 是 | $Q$ 已知时 |
| **共轭梯度法** | 每步 $O(n)$ | **否** | **实际使用** |

### 4.7 非线性共轭梯度法

推广到一般函数的要点：
1. 使用不含 $Q$ 的 $\beta_k$ 公式（FR / PR / HS / DY）
2. 线搜索通常用非精确线搜索
3. **共轭性和正交性不再精确成立**，有限步终止不再成立
4. 需要 **restart**（每隔若干步重置方向为负梯度），通常每 $n$ 步或当连续梯度不够正交时

## 五、拟牛顿法（第11章）

### 5.1 动机与基本思想

牛顿法每次需 $O(n^3)$ 计算 Hessian 并求逆。拟牛顿法的目标是：用一阶（梯度）信息**迭代更新**一个矩阵，逐步逼近 Hessian（或其逆），实现超线性收敛。

**两种版本**：

| 版本 | 近似对象 | 迭代格式 |
|------|----------|----------|
| 版本1（近似 Hessian 逆） | $H_k \approx [\nabla^2 f(x_k)]^{-1}$ | $x_{k+1} = x_k - H_k g_k$ |
| 版本2（近似 Hessian） | $B_k \approx \nabla^2 f(x_k)$ | $B_k d_k = -g_k$，$x_{k+1} = x_k + d_k$ |

### 5.2 拟牛顿方程（割线方程）的来历

对 $\nabla f$ 在 $x_{k+1}$ 处做一阶 Taylor 展开（将 $x_k$ 代入）：

$$\nabla f(x_k) \approx \nabla f(x_{k+1}) + \nabla^2 f(x_{k+1}) (x_k - x_{k+1})$$

整理得：

$$\nabla^2 f(x_{k+1}) (x_k - x_{k+1}) \approx \nabla f(x_k) - \nabla f(x_{k+1})$$

引入记号：

$$\boxed{s_k = x_k - x_{k+1}, \qquad y_k = g_k - g_{k+1}}$$

将 Hessian 替换为近似矩阵并强制等号成立：

| 版本 | 拟牛顿方程 |
|------|-----------|
| 版本1（$H_k$ 近似 Hessian 逆） | $\boxed{H_{k+1} y_k = s_k}$ |
| 版本2（$B_k$ 近似 Hessian） | $\boxed{B_{k+1} s_k = y_k}$ |

> 拟牛顿方程是 $n$ 个方程、$\frac{n(n+1)}{2}$ 个未知数的欠定方程组——无数解。这正是"设计空间"所在：不同附加约束产生不同公式。

**曲率条件**：为保持 $H_{k+1} \succ 0$（正定性），需要：

$$s_k^T y_k > 0$$

该条件在采用**强 Wolfe 线搜索**时恒成立。 

### 5.3 秩1校正公式

**问题**：$H_{k+1} = H_k + \Delta H_k$，$\Delta H_k$ 为秩1矩阵。

**推导**：设 $H_{k+1} = H_k + a u u^T$，代入 $H_{k+1} y_k = s_k$：

$$a u (u^T y_k) = s_k - H_k y_k$$

这意味着 $u$ 必须与 $s_k - H_k y_k$ 平行。取 $u = s_k - H_k y_k$，反解 $a$：

$$\boxed{H_{k+1} = H_k + \frac{(s_k - H_k y_k)(s_k - H_k y_k)^T}{y_k^T (s_k - H_k y_k)}}$$

**缺陷**：不保证正定性，分母可能接近零——实践中已被秩2公式取代。

### 5.4 DFP 公式（秩2校正）

设 $H_{k+1} = H_k + a u u^T + b v v^T$（秩2修正），代入 $H_{k+1} y_k = s_k$：

$$(H_k + a u u^T + b v v^T) y_k = s_k$$

$$H_k y_k + a u (u^T y_k) + b v (v^T y_k) = s_k$$

$$a (u^T y_k) \, u + b (v^T y_k) \, v = s_k - H_k y_k$$

右侧有两项：$s_k$（正项）和 $-H_k y_k$（负项），自然地令 $u, v$ 分别对应：

$$u = s_k, \qquad v = H_k y_k$$

代回：

$$a (s_k^T y_k) \, s_k + b \big((H_k y_k)^T y_k\big) \, H_k y_k = s_k - H_k y_k$$

由于 $H_k$ 对称，$(H_k y_k)^T y_k = y_k^T H_k y_k$，比较 $s_k$ 和 $H_k y_k$ 的系数：

$$a (s_k^T y_k) = 1 \;\implies\; a = \frac{1}{s_k^T y_k},\qquad b (y_k^T H_k y_k) = -1 \;\implies\; b = -\frac{1}{y_k^T H_k y_k}$$

代回原设即得 DFP 公式：

$$\boxed{H_{k+1}^{\text{DFP}} = H_k + \frac{s_k s_k^T}{s_k^T y_k} - \frac{H_k y_k y_k^T H_k}{y_k^T H_k y_k}}$$

**公式结构**：
- 第一项 $H_k$：上一步的近似
- 第二项 $\frac{s s^T}{s^T y}$：正贡献项，保证拟牛顿方程
- 第三项 $-\frac{H_k y y^T H_k}{y^T H_k y}$：负修正项，消除旧信息矛盾

**正定性遗传**：若 $H_k \succ 0$，则 DFP 给出的 $H_{k+1} \succ 0$。

### 5.5 BFGS 公式（秩2校正，核心）

从版本2出发，设 $B_{k+1} = B_k + a u u^T + b v v^T$，代入 $B_{k+1} s_k = y_k$：

$$(B_k + a u u^T + b v v^T) s_k = y_k$$

$$B_k s_k + a u (u^T s_k) + b v (v^T s_k) = y_k$$

$$a (u^T s_k) \, u + b (v^T s_k) \, v = y_k - B_k s_k$$

自然地令 $u, v$ 分别对应 $y_k$ 和 $-B_k s_k$：

$$u = y_k, \qquad v = B_k s_k$$

代回，利用 $B_k$ 对称性 $(B_k s_k)^T s_k = s_k^T B_k s_k$，比较系数：

$$a (y_k^T s_k) = 1 \;\implies\; a = \frac{1}{y_k^T s_k},\qquad b (s_k^T B_k s_k) = -1 \;\implies\; b = -\frac{1}{s_k^T B_k s_k}$$

代回原设得 BFGS 公式（Hessian 近似版）：

$$\boxed{B_{k+1}^{\text{BFGS}} = B_k + \frac{y_k y_k^T}{y_k^T s_k} - \frac{B_k s_k s_k^T B_k}{s_k^T B_k s_k}}$$

**利用 Sherman-Morrison 公式得到的 $H_{k+1}$ 直接更新**：

$$\boxed{H_{k+1}^{\text{BFGS}} = (I - \rho_k s_k y_k^T) H_k (I - \rho_k y_k s_k^T) + \rho_k s_k s_k^T}$$

其中 $\rho_k = \frac{1}{y_k^T s_k}$。

> BFGS 是目前公认表现最好的拟牛顿公式——对 Rosenbrock 函数只需 34 步（vs 最速下降法的 5264 步），接近牛顿法的 21 步，但每步仅 $O(n^2)$。

### 5.6 Sherman-Morrison 公式

> **秩1逆公式**：设 $A \in \mathbb{R}^{n \times n}$ 可逆，$u, v \in \mathbb{R}^n$，则：

$$\boxed{(A + u v^T)^{-1} = A^{-1} - \frac{A^{-1} u v^T A^{-1}}{1 + v^T A^{-1} u}}$$

**一般形式**（$U \in \mathbb{R}^{n \times m}$, $V \in \mathbb{R}^{m \times n}$）：

$$(I_n + UV)^{-1} = I_n - U(I_m + VU)^{-1} V$$

**在 BFGS 中的应用**：$B_{k+1}$ 是 $B_k$ 的秩2修正，两次应用 S-M 公式即可从 $H_k$ 得到 $H_{k+1}$，避免每次求解 $B_{k+1} d = -g$。

### 5.7 DFP 与 BFGS 的对比

| 维度 | DFP | BFGS |
|------|-----|------|
| 近似对象 | $H_k \approx [F]^{-1}$（版本1） | $B_k \approx F$（版本2） |
| 公式 | $H_{k+1} = H_k + \frac{s s^T}{s^T y} - \frac{H_k y y^T H_k}{y^T H_k y}$ | $B_{k+1} = B_k + \frac{y y^T}{y^T s} - \frac{B_k s s^T B_k}{s^T B_k s}$ |
| 方向计算 | $d_k = -H_k g_k$ 直接 | 需解 $B_k d_k = -g_k$ |
| 数值表现 | 大规模可能停滞 | **更稳健，实践中首选** |
| 对偶关系 | 替换 $H \leftrightarrow B$，$s \leftrightarrow y$，DFP 变为 BFGS | 对称 |

### 5.8 共轭特征定理

> **定理**：用拟牛顿法极小化强凸二次函数时，若 $H_{k+1} y_k = s_k$ 对所有 $k$ 成立，且线搜索步长非零，则搜索方向 $\{d_k = -H_k g_k\}$ 是 $Q$-共轭向量组。

**推论**：拟牛顿法在二次函数上也具有至多 $n$ 步收敛的性质——不需要显式构造共轭方向，通过拟牛顿方程自动实现了共轭性。

> 这一结论是拟牛顿法理论最优美的结果之一：拟牛顿法本质上是"隐式"的共轭梯度法。

### 5.9 Barzilai-Borwein (BB) 方法

**思想**：进一步简化——用纯量矩阵 $\alpha_k I$ 近似 Hessian。代入拟牛顿方程后用最小二乘：

$$\boxed{\alpha_{k+1}^{BB} = \frac{s_k^T y_k}{s_k^T s_k} \quad \text{或} \quad \alpha_{k+1}^{BB} = \frac{y_k^T y_k}{s_k^T y_k}}$$

**特点**：$O(n)$ 计算量，无需存储矩阵，但非单调收敛（需配合非单调线搜索）。

**与最速下降法的关系**：对二次函数，BB 步长恰好等于上一步最速下降法（精确线搜索）的步长，但 BB 的收敛速度远超 SD。

## 六、Rosenbrock 函数 — 方法对比

$f(x_1, x_2) = 100(x_2 - x_1^2)^2 + (1 - x_1)^2$，$x^* = [1, 1]^T$，收敛到 $\|g\|_\infty < 10^{-5}$：

| 方法 | 迭代步数 | 每步计算量 |
|------|:---:|:---:|
| 最速下降法 | 5264 | $O(n)$ |
| 共轭梯度法（非线性 FR） | 约 50-100 | $O(n)$ |
| BFGS 拟牛顿法 | 34 | $O(n^2)$ |
| 牛顿法 | 21 | $O(n^3)$ |

> BFGS 以 $O(n^2)$ 的代价实现了接近牛顿法的收敛速度——这就是拟牛顿法在实践中的价值所在。

## 七、各方法的迭代格式速查表

| 方法           | 搜索方向                               | 步长                                          | 矩阵更新                                                                                    |
| ------------ | ---------------------------------- | ------------------------------------------- | --------------------------------------------------------------------------------------- |
| 最速下降法        | $d_k = -g_k$                       | 精确线搜索或非精确                                   | 无                                                                                       |
| 牛顿法          | $d_k = -H_k^{-1} g_k$              | $\alpha_k = 1$（基本），或有线搜索（阻尼）                | $H_k = \nabla^2 f(x_k)$                                                                 |
| 共轭梯度法（线性）    | $p_k = -g_k + \beta_{k-1} p_{k-1}$ | $\alpha_k = -\frac{g_k^T p_k}{p_k^T Q p_k}$ | 无矩阵，$\beta_k = \frac{g_{k+1}^T g_{k+1}}{g_k^T g_k}$ (FR)                                |

## 八、决策流程

```mermaid
flowchart TD
    Start(["无约束优化 min f(x)"]) --> Scale{"问题规模？"}
    Scale -->|"n 很大 (≥10^4)"| Large{"需要高精度？"}
    Scale -->|"n 中等"| Medium{"Hessian 可计算？"}
    Scale -->|"n 很小"| Small["牛顿法\nO(n³)但二次收敛"]
    
    Large -->|"是"| LCG["非线性共轭梯度法\n+ restart"]
    Large -->|"否"| SGD["随机梯度法\n或 BB 方法"]
    
    Medium -->|"是"| HessPD{"Hessian 正定？"}
    Medium -->|"否"| BFGS["BFGS 拟牛顿法\n超线性收敛首选"]
    
    HessPD -->|"是 + 近解"| NewtonPure["基本牛顿法"]
    HessPD -->|"非正定/远离解"| LM["L-M 修正\n牛顿/梯度之间"]
```

**选择策略**：
1. **$n$ 很大 + 低精度**：BB 方法（$O(n)$，无需矩阵）或随机梯度法
2. **$n$ 很大 + 需要精度**：非线性共轭梯度法（FR 公式 + restart）
3. **$n$ 中等**：BFGS（首选，超线性收敛，$O(n^2)$ 每步）
4. **$n$ 小 + Hessian 可计算 + 近解**：牛顿法（二次收敛）
5. **$n$ 小 + Hessian 不正定**：L-M 修正牛顿法
6. **非线性最小二乘**：高斯-牛顿法或 L-M 修正的高斯-牛顿法

## 九、典型易错点

> [!warning] 梯度下降法 ≠ 最速下降法
> 梯度下降法是一个方法族（步长可固定、可衰减）。最速下降法是采用**精确线搜索**的一种特定梯度下降法。两者迭代方向相同，区别仅在步长选取方式。

> [!warning] "最速"是局部概念
> 最速下降法中的"最速"仅指在当前点处负梯度方向的一阶下降速率最快。从全局收敛速度看，它是线性的，远不如牛顿法（二次收敛）。

> [!warning] 牛顿法二阶收敛是"局部"性质
> "至少二阶收敛"的前提是初始点充分靠近解。远离解时牛顿法可能发散。这是纯牛顿法最大的局限，也是阻尼牛顿法和 L-M 修正的设计动机。

> [!warning] 牛顿方向不一定是下降方向
> 仅当 Hessian 对称正定时，$d_k = -H_k^{-1} g_k$ 才是下降方向。若 Hessian 非正定，$d_k$ 可能指向函数值上升方向或鞍点方向。

> [!warning] 共轭 ≠ 正交
> $p_i^T Q p_j = 0$ 不意味着 $p_i^T p_j = 0$。$Q$-共轭方向在欧氏度量下一般不是正交的。只有在 $Q = I$ 时两者重合。

> [!warning] 共轭方向法的"$n$ 步收敛"仅对二次函数成立
> 该定理的前提是 $f(x) = \frac{1}{2} x^T Q x - b^T x$ 且使用精确线搜索。对一般非线性函数，共轭方向法不能保证 $n$ 步收敛。

> [!warning] 非线性 CG 中四种 $\beta$ 公式不等价
> 对二次函数等价，对非线性函数不等价。FR 被证明数值最稳定，推荐作为默认选择。

> [!warning] 曲率条件 $s_k^T y_k > 0$ 不可忽略
> 拟牛顿法必须保证此条件，否则 $H_{k+1}$ 或 $B_{k+1}$ 可能不正定。实践中用**强 Wolfe 线搜索**来保证。

> [!warning] DFP vs BFGS — 选哪个
> BFGS 在数值上普遍优于 DFP，实际应用中首选 BFGS 或 L-BFGS（有限内存版本）。DFP 在大规模问题中可能因 $H_k$ 渐近奇异而停滞。

> [!warning] 秩1校正不保证正定性
> 即使极小化二次函数，秩1校正也可能出现 $H_{k+1} \not\succ 0$。不要在生产代码中使用裸的秩1校正。

> [!warning] 收敛率分析针对二次函数
> 梯度法的收敛率公式（用 $c$ 表示）是针对二次函数的精确结果。对非二次函数，最速下降法通常也呈线性收敛，但收敛率常数的具体表达式没有闭式解。

> [!warning] 定步长的充要条件
> $\alpha \in (0, \frac{2}{\lambda_{\max}(Q)})$ 是**充要条件**——在这个范围内保证收敛，不在这个范围内则存在发散的反例。

## 十、核心公式速查表

| 概念 | 公式 |
|------|------|
| 梯度法迭代 | $x_{k+1} = x_k - \alpha_k \nabla f(x_k)$ |
| 二次函数精确步长 | $\alpha_k = \frac{g_k^T g_k}{g_k^T Q g_k}$ |
| 梯度法收敛率 | $V(x_{k+1}) \leq \left(\frac{\lambda_{\max} - \lambda_{\min}}{\lambda_{\max} + \lambda_{\min}}\right)^2 V(x_k)$ |
| 定步长收敛条件 | $\alpha \in \left(0, \frac{2}{\lambda_{\max}(Q)}\right)$ |
| 牛顿法迭代 | $x_{k+1} = x_k - [\nabla^2 f(x_k)]^{-1} \nabla f(x_k)$ |
| 牛顿法二阶收敛 | $\|x_{k+1} - x^*\| \leq c \|x_k - x^*\|^2$ |
| L-M 修正 | $x_{k+1} = x_k - [H_k + \lambda I]^{-1} g_k$ |
| 高斯-牛顿法 | $x_{k+1} = x_k - [J^T J]^{-1} J^T r$ |
| $Q$-共轭定义 | $p_i^T Q p_j = 0 \;(i \neq j)$ |
| CG 方向递推 | $p_k = -g_k + \beta_{k-1} p_{k-1}$, $p_0 = -g_0$ |
| FR 公式 | $\beta_k^{\text{FR}} = \frac{g_{k+1}^T g_{k+1}}{g_k^T g_k}$ |
| $n$ 步收敛 | $x_n = x^*$（二次函数） |
| 扩展子空间 | $x_{k+1} = \arg\min_{x \in V_k} f(x)$, $V_k = x_0 + \text{span}\{p_0, \dots, p_k\}$ |
| 拟牛顿方程（H版） | $H_{k+1} y_k = s_k$ |
| 拟牛顿方程（B版） | $B_{k+1} s_k = y_k$ |
| 秩1校正 | $H_{k+1} = H_k + \frac{(s_k - H_k y_k)(s_k - H_k y_k)^T}{y_k^T(s_k - H_k y_k)}$ |
| DFP 公式 | $H_{k+1} = H_k + \frac{s_k s_k^T}{s_k^T y_k} - \frac{H_k y_k y_k^T H_k}{y_k^T H_k y_k}$ |
| BFGS 公式 | $B_{k+1} = B_k + \frac{y_k y_k^T}{y_k^T s_k} - \frac{B_k s_k s_k^T B_k}{s_k^T B_k s_k}$ |
| BFGS 逆更新 | $H_{k+1} = (I - \rho s y^T) H_k (I - \rho y s^T) + \rho s s^T$, $\rho = 1/(y^T s)$ |
| Sherman-Morrison | $(A + u v^T)^{-1} = A^{-1} - \frac{A^{-1} u v^T A^{-1}}{1 + v^T A^{-1} u}$ |
| 曲率条件 | $s_k^T y_k > 0$（强 Wolfe 线搜索保证） |
| BB 步长 | $\alpha_{k+1}^{BB} = \frac{s_k^T y_k}{s_k^T s_k}$ 或 $\frac{y_k^T y_k}{s_k^T y_k}$ |
| 非线性最小二乘梯度 | $\nabla f(x) = J(x)^T r(x)$ |
| 收敛阶定义 | $\lim_{k \to \infty} \frac{\|x_{k+1} - x^*\|}{\|x_k - x^*\|^p} = L \in (0, \infty)$ |
| 锯齿现象 | $\nabla f(x_{k+1}) \perp \nabla f(x_k)$ |
