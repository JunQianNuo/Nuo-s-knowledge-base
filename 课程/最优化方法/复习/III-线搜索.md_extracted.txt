# III. 线搜索（第7章 + 第25章）

> 本章覆盖两个知识面：**一维搜索方法**（在单变量区间内找极小点）和**线搜索框架**（将多维优化分解为方向选取 + 一维搜索），外加**信赖域方法**（不同于线搜索的另一类优化范式）。

---

## 一、一维搜索方法速查

所有一维搜索方法的目标是求解：

$$\min f(x), \quad x \in [a_0, b_0] \subset \mathbb{R}$$

核心假设：$f$ 是**单峰函数**（区间内有唯一极小点，极小点左侧严格递减、右侧严格递增）。

### 1.1 方法对比总表

| 方法 | 所需信息 | 迭代格式 / 操作方式 | 收敛速度 | 使用条件 | 核心参数 |
|------|:---:|------|:---:|------|------|
| **黄金分割法** | $f(x)$ | 比较两个内点的 $f$ 值，删去不含极小点的一端 | 线性，压缩比 $\mu \approx 0.618$ | $f$ 连续，单峰 | $\lambda = \frac{3-\sqrt{5}}{2} \approx 0.382$，$\mu = \frac{\sqrt{5}-1}{2} \approx 0.618$ |
| **斐波那契法** | $f(x)$ | 同黄金分割，但内点比例逐轮变化 | 线性，前期比黄金分割略快 | $f$ 连续，单峰，需预计算 Fibonacci 数列 | $\mu_k = F_k / F_{k+1}$ |
| **二分法** | $f'(x)$ | 在区间中点计算 $f'$ 的符号决定删去哪一半 | 线性，压缩比 $0.5$ | $f \in C^1$，单峰 | 每步算 1 次导数 |
| **牛顿法（一元）** | $f'(x), f''(x)$ | $x_{k+1} = x_k - \frac{f'(x_k)}{f''(x_k)}$ | **二次**（局部） | $f \in C^2$，$f'' > 0$ | 用曲率校准步长 |
| **割线法（一元）** | $f'(x)$（两个点） | $x_{k+1} = x_k - \frac{f'(x_k)(x_k - x_{k-1})}{f'(x_k) - f'(x_{k-1})}$ | **超线性**（约 1.618 阶） | $f \in C^1$ | 用差商代替 $f''$ |
| **插值法** | $f$ 值 / $f'$ 值 | 用低次多项式插值 $f$，取插值多项式的极小点 | 取决于插值次数 | $f$ 足够光滑 | 常配合其他方法使用 |

### 1.2 黄金分割法 — 原理与操作

**设计思想**：通过自相似性设计，让每轮只需计算 **1 个新函数值**（旧的内点自动成为下一轮的新内点）。

**核心推导**：

设 $\lambda < \mu$ 是 $[0, 1]$ 中的两个内点。对称性要求 $\lambda = 1 - \mu$，自相似性要求 $\lambda = \mu^2$。代入得：

$$\lambda = (1 - \lambda)^2 \;\Longrightarrow\; \lambda^2 - 3\lambda + 1 = 0$$

解得 $\lambda = \frac{3 - \sqrt{5}}{2} \approx 0.382$，$\mu = \frac{\sqrt{5} - 1}{2} \approx 0.618$。

**算法步骤**：
1. 在 $[a_k, b_k]$ 中计算 $a_{k+1} = a_k + \lambda(b_k - a_k)$，$b_{k+1} = a_k + \mu(b_k - a_k)$
2. 比较 $f(a_{k+1})$ 和 $f(b_{k+1})$：
   - $f(a_{k+1}) < f(b_{k+1})$ $\Rightarrow$ 新区间 $[a_k, b_{k+1}]$
   - $f(a_{k+1}) > f(b_{k+1})$ $\Rightarrow$ 新区间 $[a_{k+1}, b_k]$
3. 旧的内点自动复用，只计算 1 个新内点
4. 停机准则：$L_0 \times \mu^N < \varepsilon$

**关键性质**：每次函数值计算 1 次（初始轮 2 次），区间压缩比 $\mu \approx 0.618$，$N$ 步后区间长度 $L_0 \cdot \mu^N$。

### 1.3 斐波那契数列法 — 与黄金分割的区别

| | 黄金分割法 | 斐波那契法 |
|---|---|---|
| 内点比例 | 固定 $\lambda = 0.382, \mu = 0.618$ | 动态 $\lambda_k, \mu_k$，逐轮变化 |
| 压缩比 | 每步 $\approx 0.618$ | 前期更小（更快），极限 $\to 0.618$ |
| 实现复杂度 | 简单 | 需预计算 Fibonacci 数列 $F_k$ |
| 使用建议 | 首选 | 对效率极致追求时考虑 |

其中 $F_k$ 满足 $F_0 = 1, F_1 = 1, F_{k+1} = F_k + F_{k-1}$，$\mu_k = F_k / F_{k+1}$。

### 1.4 二分法 — 原理与操作

**核心原理**：利用一阶必要条件 $f'(x^*) = 0$，将优化问题转化为求解 $f'(x) = 0$ 的根。

在区间中点 $x_{\text{mid}} = \frac{a_k + b_k}{2}$ 检查导数符号：

| $f'(x_{\text{mid}})$ 符号 | 结论 |
|:---:|------|
| $> 0$ | 极小点在左边，新区间 $[a_k, x_{\text{mid}}]$ |
| $< 0$ | 极小点在右边，新区间 $[x_{\text{mid}}, b_k]$ |
| $= 0$ | $x_{\text{mid}}$ 即为极小点 |

**与黄金分割法对比**：二分法压缩比 $0.5$（更快），但需要 $f \in C^1$ 并计算 $f'$。

### 1.5 牛顿法（一元）— 求极值 vs 求根

**求极值**：在 $x_k$ 处做二阶 Taylor 展开

$$g(x) = f(x_k) + f'(x_k)(x - x_k) + \frac{1}{2} f''(x_k)(x - x_k)^2$$

由 $g'(x) = 0$ 得迭代格式：

$$\boxed{x_{k+1} = x_k - \frac{f'(x_k)}{f''(x_k)}}$$

**求根**（解 $g(x) = 0$）：$x_{k+1} = x_k - \frac{g(x_k)}{g'(x_k)}$（用 Jacobian 代替了优化中的 Hessian）。

> **对二次函数 $f$，牛顿法一步收敛。** 若 $f''(x_k) \leq 0$，牛顿法可能失效（步长方向错误或除零）。

**两类牛顿法的对比**：

| 方法 | 迭代格式 | 所需信息 |
|------|---------|----------|
| 牛顿法（求极值） | $x_{k+1} = x_k - \frac{f'(x_k)}{f''(x_k)}$ | $f', f''$ |
| 牛顿法（求根） | $x_{k+1} = x_k - \frac{g(x_k)}{g'(x_k)}$ | $g, g'$ |

### 1.6 割线法 — 牛顿法的"平价替代"

**动机**：牛顿法需要 $f''$，用差商近似：

$$f''(x_k) \approx \frac{f'(x_k) - f'(x_{k-1})}{x_k - x_{k-1}}$$

代入牛顿公式得割线法迭代格式：

$$\boxed{x_{k+1} = x_k - \frac{f'(x_k) \cdot (x_k - x_{k-1})}{f'(x_k) - f'(x_{k-1})}}$$

**完整逻辑链**：
```
牛顿法求根 g(x)=0 → 割线法求根 g(x)=0 → 割线法求极值 (g = f')
```

| 方法 | 迭代格式 | 所需信息 |
|------|---------|----------|
| 牛顿法（求根） | $x_{k+1} = x_k - \frac{g(x_k)}{g'(x_k)}$ | $g$ 和 $g'$ |
| 割线法（求根） | $x_{k+1} = x_k - \frac{g(x_k)(x_k - x_{k-1})}{g(x_k) - g(x_{k-1})}$ | 仅 $g$（两个点） |
| 割线法（求极值） | $x_{k+1} = x_k - \frac{f'(x_k)(x_k - x_{k-1})}{f'(x_k) - f'(x_{k-1})}$ | 仅 $f'$（两个点） |

### 1.7 插值类方法

**思想**：在区间上取若干节点，用低次（$\leq 3$）插值多项式近似 $f$，将插值多项式的极小点作为近似极小点。

| 方法 | 所需信息 | 插值次数 |
|------|---------|:---:|
| 三点二次插值 | 三点 $x_1 < x_2 < x_3$ 的函数值，满足 $f(x_1) > f(x_2) < f(x_3)$ | 二次 |
| 两点二次插值 I | 两点函数值 + 一个导数值 | 二次 |
| 两点二次插值 II | 两点导数值（等价于割线法） | 二次 |
| 两点三次插值 | 两点函数值 + 两点导数值 | 三次 |

**推导思路**（以三点二次插值为例）：设 $q(x) = ax^2 + bx + c$ 通过三个插值点，则极小点 $x^* = -b/(2a)$ 由系数 $a, b$ 决定，而 $a, b$ 由三个插值条件解出。

> 插值法通常用作**初始阶段的加速**，之后配合迭代法精密搜索。一般不单独使用。

## 二、线搜索框架

### 2.1 多维优化的基本格式

对于 $\min_{x \in \mathbb{R}^n} f(x)$，线搜索将多维优化分解为：

$$\boxed{x_{k+1} = x_k + \alpha_k p_k}$$

| 符号 | 名称 | 含义 |
|------|------|------|
| $p_k \in \mathbb{R}^n$ | 搜索方向 | 从 $x_k$ 出发移动的方向 |
| $\alpha_k > 0$ | 步长 | 沿 $p_k$ 方向移动多远 |
| $\phi(\alpha) = f(x_k + \alpha p_k)$ | 一维函数 | 固定方向后的目标函数 |

### 2.2 下降方向条件

$p_k$ 必须满足：

$$\boxed{p_k^T \nabla f(x_k) < 0}$$

即搜索方向与负梯度方向的夹角小于 $90^\circ$。由 Taylor 展开：

$$f(x_k + \alpha p_k) = f(x_k) + \alpha \, p_k^T \nabla f(x_k) + o(\alpha) < f(x_k) \quad (\text{对充分小的 } \alpha)$$

### 2.3 精确步长公式

**定义**：$\alpha_k = \arg\min_{\alpha \geq 0} f(x_k + \alpha p_k)$

由一阶必要条件：

$$\phi'(\alpha) = \nabla f(x_k + \alpha p_k)^T p_k = 0$$

即最优步长处，新梯度与搜索方向正交。

**二次函数的闭式解**：若 $f(x) = \frac{1}{2} x^T A x + b^T x + c$（$A \succ 0$），则：

$$\boxed{\alpha_k = -\frac{p_k^T \nabla f(x_k)}{p_k^T A p_k}}$$

> 分子是方向导数，分母是沿方向的曲率——曲率越大，最优步长越小。

### 2.4 划界技术 — 进退法

所有一维搜索方法都需要初始区间 $[a, b]$（单峰区间）。进退法用于找到这个区间。

**目标**：找到三点 $a < c < b$ 满足 $f(c) < f(a)$ 且 $f(c) < f(b)$。

**基本思想**：沿着下降方向大步前进（步长逐次加倍），直到函数值开始回升——说明已越过极小点。

## 三、非精确步长准则对比

### 3.1 为什么需要非精确步长

精确步长需要在每一步解 $\min_{\alpha \geq 0} \phi(\alpha)$，代价高。实践中只需"足够好"的步长即可。

### 3.2 三种准则对比

| 准则 | 公式 | 参数 | 特点 |
| --- | --- | --- | --- |
| **Armijo** | $f(x_k + \alpha p_k) \leq f(x_k) + c \,\alpha\, p_k^T \nabla f(x_k)$ | $c \in (0, 1)$，典型 $10^{-4}$ | 仅保证充分下降，不能阻止步长过小 |
| **Goldstein** | $\begin{cases}f(x_k + \alpha p_k) \leq f(x_k) + c \,\alpha\, p_k^T \nabla f(x_k) \\ f(x_k + \alpha p_k) \geq f(x_k) + (1-c) \,\alpha\, p_k^T \nabla f(x_k)\end{cases}$ | $c \in (0, \frac{1}{2})$ | Armijo + 下界限制，防止步长过小 |
| **（强）Wolfe** | $\begin{cases}f(x_k + \alpha p_k) \leq f(x_k) + c_1 \,\alpha\, p_k^T \nabla f(x_k) \\ \lvert\nabla f(x_k + \alpha p_k)^T p_k\rvert \leq c_2 \,\lvert p_k^T \nabla f(x_k)\rvert\end{cases}$ | $0 < c_1 < c_2 < 1$，典型 $c_1 = 10^{-4}, c_2 = 0.9$ | Armijo + 曲率条件，**实践最常用** |

### 3.3 Armijo 条件的几何理解

不等号右边是过 $(0, f(x_k))$、斜率为 $c \cdot p_k^T \nabla f(x_k)$ 的直线。Armijo 要求 $\phi(\alpha)$ 落在这条直线下方。

- $c$ 越小 $\to$ 条件越宽松 $\to$ 可接受的步长范围更大
- $c$ 越大 $\to$ 条件越严格 $\to$ 要求更显著的下降

> [!warning] Armijo 不能单独使用
> Armijo 条件允许 $\alpha \to 0$，此时条件总是近似满足。必须配合回溯（从大 $\bar{\alpha}$ 开始）或加上 Wolfe 的曲率条件。

### 3.4 Wolfe 准则的曲率条件解读

$\nabla f(x_k + \alpha p_k)^T p_k$ 是 $\phi'(\alpha)$（沿方向的方向导数）。曲率条件要求：

$$|\phi'(\alpha)| \leq c_2 |\phi'(0)|$$

即在步长处，方向导数已**足够接近零**——说明在该方向上已接近极小点。

- 若 $c_2 = 0$：退化为精确步长（$\phi'(\alpha) = 0$）
- 若 $c_2 = 1$：任何不上升都接受
- 典型值 $c_2 = 0.9$：接近精确步长但计算代价低

## 四、回溯技术

### 4.1 算法

```
算法 (Backtracking Line Search):
  给定: ᾱ > 0 (初始步长), ρ ∈ (0,1) (收缩因子), c ∈ (0,1) (Armijo常数)
  
  1. α := ᾱ
  2. while f(x_k + α p_k) > f(x_k) + c·α·p_k^T ∇f(x_k):
  3.     α := ρ α
  4. α_k := α
```

### 4.2 参数选择

| 参数 | 典型值 | 含义 |
|------|--------|------|
| $\bar{\alpha}$ | $1$（牛顿法）/ 自适应 | 初始试探步长 |
| $\rho$ | $0.5$ 或 $0.8$ | 每次缩小的比例 |
| $c$ | $10^{-4}$ | Armijo 常数 |

### 4.3 优点

- 实现极其简单
- 自动避免步长过小（从大 $\bar{\alpha}$ 开始缩）
- 实践中效果很好
- 不需要 Wolfe 的曲率条件

> 一句话来说：回溯 = 先迈一大步试试，不行就缩一半再试，直到满足 Armijo。

## 五、Zoutendijk 收敛定理

### 5.1 定理陈述

> **定理 (Zoutendijk)**：设 $f: \mathbb{R}^n \to \mathbb{R}$ 连续可微且有下界，$\nabla f$ **Lipschitz 连续**。对于线搜索迭代 $x_{k+1} = x_k + \alpha_k p_k$，若 $p_k$ 是下降方向且 $\alpha_k$ 满足 Wolfe 准则，则：

$$\boxed{\sum_{k=0}^{\infty} \cos^2 \theta_k \; \|\nabla f(x_k)\|^2 < +\infty}$$

其中 $\theta_k$ 是 $p_k$ 与 $-\nabla f(x_k)$ 之间的夹角：

$$\cos\theta_k = \frac{-p_k^T \nabla f(x_k)}{\|p_k\| \|\nabla f(x_k)\|}$$

### 5.2 重要推论

由于级数收敛，必有：

$$\cos^2\theta_k \; \|\nabla f(x_k)\|^2 \to 0$$

因此：
- 若 $\cos\theta_k \geq \delta > 0$（方向始终不趋于与负梯度正交），则 $\|\nabla f(x_k)\| \to 0$——**梯度一定趋于零**
- 最速下降法中 $\cos\theta_k = 1$，Zoutendijk 直接给出 $\|\nabla f(x_k)\| \to 0$

### 5.3 定理意义

> Zoutendijk 定理是线搜索方法的**收敛性基石**——只要方向合理 + Wolfe 步长，算法一定收敛到稳定点。定理条件中的 Lipschitz 连续（比 $C^1$ 更强）保证梯度不能变化太快，从而 Taylor 展开的余项可控。

## 六、信赖域法（第25章）

### 6.1 基本思想

牛顿法在远离极小点或 Hessian 非正定时可能失效。**信赖域方法**的思路：在 $x_k$ 周围定义一个"信任区域"，只在这个区域内信任二次模型。

**与线搜索的关键区别**：

| | 线搜索方法 | 信赖域方法 |
|---|-------------|----------|
| 决策顺序 | 先选方向，再选步长 | 先选范围（半径），再在范围内选点 |
| 核心驱动 | 搜索方向驱动 | 信赖域约束驱动 |
| Hessian 非正定 | 需修正方向 | 约束自动处理 |
| 全局收敛性 | 需要 Wolfe 条件 | 通过半径调整自然获得 |

### 6.2 信赖域子问题

在 $\Omega_k = \{x \mid \|x - x_k\| \leq r_k\}$ 内求解：

$$\min_{s \in \mathbb{R}^n} \; q(s) = \frac{1}{2} s^T B_k s + g_k^T s \quad \text{s.t.} \quad \|s\| \leq r_k$$

其中 $B_k$ 是 Hessian 或其近似（可取 $B_k = \nabla^2 f(x_k)$, $B_k = I$, 或拟牛顿近似）。

### 6.3 子问题的最优性条件（$\ell^2$ 范数）

Lagrange 函数：$\mathcal{L}(s, \lambda) = \frac{1}{2} s^T B s + g^T s + \frac{\lambda}{2}(\|s\|^2 - r^2)$

**KKT 条件**：

$$\begin{aligned}
B s^* + g + \lambda s^* &= 0 \quad &\text{(梯度条件)} \\
\|s^*\| &\leq r \quad &\text{(约束)} \\
\lambda &\geq 0 \quad &\text{(乘子非负)} \\
\lambda(\|s^*\| - r) &= 0 \quad &\text{(互补松弛)}
\end{aligned}$$

> [!hint] 关键洞察
> 当 $B$ 非正定时，$\lambda > 0$ 使 $B + \lambda I$ 正定——约束的存在自动为 Hessian"加了正则项"，这是信赖域方法的核心优势。

### 6.4 子问题求解方法 — 折线法（Dogleg）与二维子空间法

**精确求解**（二分法）：
- 由 KKT 梯度条件，当 $B + \lambda I \succ 0$ 时：$s(\lambda) = -(B + \lambda I)^{-1} g$
- $\|s(\lambda)\|$ 关于 $\lambda$ 单调递减
- 在 $[\lambda_l, \lambda_u]$ 内二分搜索，其中 $\lambda_l = \max\{0, -\lambda_{\min}(B)\}$

**近似求解**（折线法 / Dogleg）：
- 构造一条从 $x_k$ 出发、先沿最速下降方向到柯西点、再转向牛顿方向的折线
- 信赖域解取为折线与球面 $\|s\| = r_k$ 的交点

### 6.5 柯西点

柯西点是沿负梯度方向在信赖域内精确极小化二次模型得到的点：

$$\boxed{x_k^c = x_k - \tau_k \frac{r_k}{\|g_k\|} g_k}$$

其中：

$$\tau_k = \begin{cases}
1, & g_k^T B_k g_k \leq 0 \\[8pt]
\min\!\left(1,\; \dfrac{\|g_k\|^3}{r_k \, g_k^T B_k g_k}\right), & g_k^T B_k g_k > 0
\end{cases}$$

**充分下降性**：柯西点保证：

$$m_k(x_k^c) - m_k(x_k) \leq -c_1 \|g_k\| \min\!\left(r_k,\; \frac{\|g_k\|}{\|B_k\|}\right)$$

这说明即使是非精确求解，每次迭代也有足够的下降量，足以驱动全局收敛。

### 6.6 信赖域半径的更新

通过比较**实际下降量**和**预估下降量**来判断模型质量：

| 量 | 定义 |
|----|------|
| 实际下降 | $\Delta_{\text{red}}^k = f(x_k) - f(x_{k+1})$ |
| 预估下降 | $\Delta_{\text{pred}}^k = m_k(0) - m_k(s_k)$ |
| 比值 | $\rho_k = \dfrac{\Delta_{\text{red}}^k}{\Delta_{\text{pred}}^k}$ |

**更新规则**：

| $\rho_k$ 范围 | 模型质量 | 半径调整 |
|:---:|:---:|------|
| $\rho_k < 0.25$ | 差 | $r_{k+1} = 0.5 \, r_k$（收缩） |
| $\rho_k \in [0.25, 0.75]$ | 可接受 | $r_{k+1} = r_k$（不变） |
| $\rho_k > 0.75$ | 好 | $r_{k+1} = \min\{2 r_k, \bar{r}\}$（扩张） |

仅当 $\rho_k > 0$ 时接受 $x_{k+1}$（即 $f$ 实际下降）；否则拒绝该步，缩小半径后重算。

### 6.7 收敛性

在 $\nabla^2 f$ 有界、下水平集有界的假设下，信赖域方法的梯度趋于零：

$$\nabla f(x_k) \to 0 \quad (k \to \infty)$$

**关键优势**：收敛性不要求 Hessian 正定——这是信赖域方法对比纯牛顿法的最重要优势。

## 七、典型易错点

> [!warning] 单峰假设是前提
> 黄金分割法和斐波那契法**依赖单峰假设**。如果函数在区间内有多个局部极小点，区间压缩法可能删掉全局极小点所在的区间。实际应用中需先用进退法框住一个单峰区间。

> [!warning] 牛顿法中 $f''(x) \leq 0$ 导致失效
> 牛顿法要求 $f''(x) > 0$（严格凸）。若某点处 $f'' \leq 0$，二次逼近的驻点是极大点或退化，牛顿方向可能指向错误的方向。

> [!warning] Armijo 条件不能单独保证收敛
> Armijo 允许步长任意小——当 $\alpha \to 0$ 时，Taylor 展开保证条件总是近似成立的。必须配合回溯（从大 $\bar{\alpha}$ 开始）或加上 Wolfe 的曲率条件。

> [!warning] Goldstein 与 Wolfe 的参数范围
> Goldstein 要求 $c \in (0, 0.5)$，而 Armijo 允许 $c \in (0, 1)$。Wolfe 要求 $0 < c_1 < c_2 < 1$。$c_2$ 越接近 1，曲率条件越严格。

> [!warning] Zoutendijk 定理需要 $\nabla f$ Lipschitz 连续
> 这是比 $C^1$ 更强的条件。它保证梯度不能变化太快，从而 Taylor 展开的余项可控。

> [!warning] 信赖域半径不等于线搜索步长
> 线搜索是"沿固定方向找步长"，信赖域是"在固定范围内找最佳点"。半径 $r_k$ 限制的是位移的范数，不是步长因子。两者不能直接等价。

> [!warning] KKT 条件中的 $\lambda$ 的特殊角色
> 信赖域子问题的 Lagrange 乘子 $\lambda$ 作用于 $\|s\|^2 - r^2 \leq 0$，它的角色是使 $B + \lambda I$ 正定——等价于在 Hessian 上加一个正则项。

> [!warning] 信赖域收敛不要求 Hessian 正定
> $B_k$ 可以不定甚至负定——因为子问题是有界约束下的优化，极小点总存在。纯牛顿法在 $G_k$ 非正定时产生的方向可能是上升方向。
