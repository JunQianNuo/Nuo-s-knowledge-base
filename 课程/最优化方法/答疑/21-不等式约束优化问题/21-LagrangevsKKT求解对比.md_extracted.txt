# 第21章 答疑 — Lagrange 乘子法 vs KKT 条件求解对比

> 问题：**Lagrange 乘子法和 KKT 条件的求解方式有什么不同？**

---

## 逐项对比

| | Lagrange 乘子法 | KKT 条件 |
|:--|:--|:--|
| 约束 | 只有 $h(x)=0$ | $h(x)=0$ **+** $g(x)\leq 0$ |
| 条件数 | 2 条 | 4 条（KKT 四件套） |
| 乘子符号 | 无限制 | $\mu \geq 0$ |
| 互补松弛 | 无 | $\mu_j g_j = 0$ |
| 求解 | **直接解方程组** | **分情形讨论** |

---

## Lagrange：直接解

$$\begin{cases} \nabla f + \lambda^T \nabla h = 0 \\ h(x) = 0 \end{cases}$$

$n+m$ 方程，$n+m$ 未知数，解就行。

---

## KKT：分情形枚举

互补松弛让你**不能直接解**——不知道哪些 $g_j$ 积极：

```
对每个约束 gⱼ：
  ├─ A：gⱼ < 0 → μⱼ = 0，约束从驻点条件消失
  └─ B：gⱼ = 0 → μⱼ可以 > 0，参与驻点，再用对偶可行筛
```

每种情形退化为一个 Lagrange 问题，加上符号条件筛选。

---

## 例题对比

同一目标：$\min x_1^2+x_2^2$

**等式约束** `x₁+x₂=2`：Lagrange 直接解 → $x_1=x_2=1$

**加不等式** `x₁≥0`：KKT 分 2 种情形：
- 不积极：$x_1>0$，$\mu_2=0$ → Lagrange → $x=(1,1)$，$\mu_2=0\geq 0$ ✅
- 积极：$x_1=0$ → $x=(0,2)$，$\mu_2=-4<0$ ❌
