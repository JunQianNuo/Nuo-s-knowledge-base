# 习题 6.16

考虑如下优化问题：

$$\begin{aligned} \underset{x \in \mathbb{R}^2}{\text{minimize}} \quad & f(x) = 4x_1^2 - x_2 \\ \text{subject to} \quad & x \in \Omega \end{aligned}$$

其中可行集为：

$$\Omega = \{x = [x_1, x_2]^\top : 4x_1^2 + x_2^2 \leq 2,\; x_1 \geq 0,\; x_2 \geq 0\}$$

**a.** $x^* = [0, 0]^\top$ 是否满足一阶必要条件？

**b.** $x^* = [0, 0]^\top$ 是否满足二阶必要条件？

**c.** $x^* = [0, 0]^\top$ 是不是局部极小点？

---

## 💡 提示

> [!hint]- 点击展开提示
> - 注意 $x^* = [0, 0]^\top$ 位于约束边界上（$x_1 = 0$ 且 $x_2 = 0$ 为边界），需用约束优化的 FONC/SONC。
> - 对于不等式约束 $g_i(x) \leq 0$，边界点处需验证可行方向锥上的条件。
> - 也可利用目标函数的结构：$f$ 在 $(0,0)$ 沿某些可行方向是下降的。

---

## 📝 详细解析

> [!solution]- 点击展开详细解析
> ### 约束分析
>
> 约束条件：
> - $g_1(x) = 4x_1^2 + x_2^2 - 2 \leq 0$（在 $x^* = [0,0]^\top$ 处，$g_1(0,0) = -2 < 0$，不起作用）
> - $g_2(x) = -x_1 \leq 0$（在 $x^*$ 处，$g_2(0,0) = 0$，起作用的约束）
> - $g_3(x) = -x_2 \leq 0$（在 $x^*$ 处，$g_3(0,0) = 0$，起作用的约束）
>
> 在 $x^*$ 处，$g_2$ 和 $g_3$ 是起作用约束。
>
> ### 梯度计算
>
> $$\nabla f(x) = \begin{bmatrix} 8x_1 \\ -1 \end{bmatrix}, \quad \nabla f(0,0) = \begin{bmatrix} 0 \\ -1 \end{bmatrix}$$
>
> ### (a) 一阶必要条件
>
> 对起作用约束，在 $x^*$ 处需存在 $\mu_2, \mu_3 \geq 0$ 使得：
>
> $$\nabla f(x^*) + \mu_2 \nabla g_2(x^*) + \mu_3 \nabla g_3(x^*) = 0$$
>
> 其中 $\nabla g_2 = [-1, 0]^\top$，$\nabla g_3 = [0, -1]^\top$（注意 $g_2 = -x_1$，$g_3 = -x_2$）。
>
> 代入：
>
> $$\begin{bmatrix} 0 \\ -1 \end{bmatrix} + \mu_2 \begin{bmatrix} -1 \\ 0 \end{bmatrix} + \mu_3 \begin{bmatrix} 0 \\ -1 \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix}$$
>
> 即：
> $$\begin{cases} -\mu_2 = 0 \\ -1 - \mu_3 = 0 \end{cases} \implies \mu_2 = 0,\; \mu_3 = -1$$
>
> $\mu_3 = -1 < 0$，不满足 KKT 条件中 $\mu_i \geq 0$ 的要求。故 $x^*$ **不满足**一阶必要条件。
>
> ### (b) 二阶必要条件
>
> 既然一阶条件不满足，$x^*$ 不可能满足二阶必要条件（二阶条件以一阶条件为前提）。
>
> ### (c) 局部极小点判断
>
> 考虑可行方向 $d = [0, 1]^\top$：在 $x^* = [0,0]^\top$ 附近，取 $x = [0, \varepsilon]^\top \in \Omega$（$\varepsilon > 0$ 充分小）：
>
> $$f(0, \varepsilon) - f(0, 0) = -\varepsilon < 0$$
>
> 故 $x^*$ 不是局部极小点。实际上，沿 $x_2$ 增大方向函数值严格下降。$\square$
>
> **点评：** 本题体现了约束问题中边界点检验的关键——不能简单套用无约束 FONC，必须考虑起作用约束的法向量能否线性组合出 $-\nabla f$。
