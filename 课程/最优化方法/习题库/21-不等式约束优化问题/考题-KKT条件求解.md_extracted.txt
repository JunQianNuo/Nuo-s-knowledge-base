# 考题 01 — KKT 条件求解不等式约束

用 KKT 条件求解：

$$\begin{aligned}
\min \quad & f(x_1, x_2) = (x_1 - 2)^2 + (x_2 - 1)^2 \\
\text{s.t.} \quad & g_1(x) = x_1 + x_2 - 2 \leq 0 \\
& g_2(x) = x_1^2 - x_2 \leq 0 \\
& x_1 \geq 0
\end{aligned}$$

**a.** 写出 KKT 条件（Lagrangian、驻点条件、互补松弛、对偶可行性）。

**b.** 枚举所有活动约束组合，逐一求解并检验 KKT 条件。

**c.** 指出真正的极小点及其目标值，说明理由。

**d.** 画出可行域示意图，标注 KKT 点和约束边界。

---

## 💡 提示

> [!hint]- 点击展开提示
> - 不等式约束 $g_i(x) \leq 0$ 对应乘子 $\mu_i \geq 0$；$x_1 \geq 0$ 可改写为 $g_3(x) = -x_1 \leq 0$。
> - 3 个不等式约束共有 $2^3 = 8$ 种活动/非活动组合，逐一尝试并检验。
> - 优先尝试「无活动约束」和「单活动约束」，往往能快速排除大部分组合。
> - 互补松弛：$\mu_i g_i(x^*) = 0$。
> - 最终 KKT 点的最优性：由于 $f$ 凸、约束函数 $g_1$ 线性（凸）、$g_2$ 凸（Hessian $\operatorname{diag}(2,0) \succeq 0$），可行域为凸集，KKT 点即全局极小。

---

## 📝 详细解析

> [!solution]- 点击展开详细解析
> ### (a) KKT 条件
>
> 将 $x_1 \geq 0$ 改写为 $g_3(x) = -x_1 \leq 0$。
>
> **Lagrangian：**
>
> $$\mathcal{L}(x, \mu) = (x_1 - 2)^2 + (x_2 - 1)^2 + \mu_1(x_1 + x_2 - 2) + \mu_2(x_1^2 - x_2) + \mu_3(-x_1)$$
>
> **驻点条件：**
>
> $$\begin{aligned}
> \frac{\partial \mathcal{L}}{\partial x_1} &= 2(x_1 - 2) + \mu_1 + 2\mu_2 x_1 - \mu_3 = 0 \\
> \frac{\partial \mathcal{L}}{\partial x_2} &= 2(x_2 - 1) + \mu_1 - \mu_2 = 0
> \end{aligned}$$
>
> **互补松弛：**
>
> $$\mu_1(x_1 + x_2 - 2) = 0,\quad \mu_2(x_1^2 - x_2) = 0,\quad \mu_3(-x_1) = 0$$
>
> **对偶可行性：**
>
> $$\mu_1 \geq 0,\quad \mu_2 \geq 0,\quad \mu_3 \geq 0$$
>
> ---
>
> ### (b) 枚举活动约束组合
>
> ---
>
> **Case 1：无活动约束（$\mu_1 = \mu_2 = \mu_3 = 0$）**
>
> 驻点：$2(x_1 - 2) = 0 \Rightarrow x_1 = 2$；$2(x_2 - 1) = 0 \Rightarrow x_2 = 1$。
>
> 检验可行性：$g_1(2,1) = 2 + 1 - 2 = 1 > 0$。**违反 $g_1 \leq 0$，排除。**
>
> ---
>
> **Case 2：仅 $g_1$ 活动（$\mu_1 > 0,\; \mu_2 = \mu_3 = 0$）**
>
> $x_1 + x_2 = 2$。
>
> 驻点：$2(x_1 - 2) + \mu_1 = 0$，$2(x_2 - 1) + \mu_1 = 0$。
>
> 得 $2x_1 - 4 = 2x_2 - 2 \Rightarrow 2x_1 - 2x_2 = 2 \Rightarrow x_1 - x_2 = 1$。
>
> 结合 $x_1 + x_2 = 2$：$x_1 = \frac{3}{2},\; x_2 = \frac{1}{2}$。$\mu_1 = 2(2 - \tfrac{3}{2}) = 1 > 0$ $\checkmark$
>
> 检验 $g_2$：$x_1^2 - x_2 = \frac{9}{4} - \frac{1}{2} = \frac{7}{4} > 0$。**违反 $g_2 \leq 0$，排除。**
>
> ---
>
> **Case 3：仅 $g_2$ 活动（$\mu_2 > 0,\; \mu_1 = \mu_3 = 0$）**
>
> $x_2 = x_1^2$。
>
> 驻点：$2(x_1 - 2) + 2\mu_2 x_1 = 0$，$2(x_2 - 1) - \mu_2 = 0 \Rightarrow \mu_2 = 2(x_1^2 - 1)$。
>
> 代入第一式：$2x_1 - 4 + 2 \cdot 2(x_1^2 - 1) \cdot x_1 = 0 \;\Longrightarrow\; 2x_1 - 4 + 4x_1(x_1^2 - 1) = 0$
>
> 化简：$4x_1^3 - 2x_1 - 4 = 0 \;\Longrightarrow\; 2x_1^3 - x_1 - 2 = 0$。
>
> 数值求解：$x_1 \approx 1.165$，$x_2 = x_1^2 \approx 1.357$。$\mu_2 = 2(1.357 - 1) \approx 0.714 > 0$ $\checkmark$
>
> 检验 $g_1$：$x_1 + x_2 - 2 \approx 1.165 + 1.357 - 2 = 0.522 > 0$。**违反 $g_1 \leq 0$，排除。**
>
> ---
>
> **Case 4：仅 $g_3$ 活动（$\mu_3 > 0,\; \mu_1 = \mu_2 = 0$）**
>
> $x_1 = 0$。驻点：$2(0 - 2) - \mu_3 = 0 \Rightarrow \mu_3 = -4 < 0$。**违反对偶可行性，排除。**
>
> ---
>
> **Case 5：$g_1$ 和 $g_2$ 同时活动（$\mu_1 > 0,\; \mu_2 > 0,\; \mu_3 = 0$）**
>
> $x_1 + x_2 = 2$，$x_2 = x_1^2$。
>
> $x_1^2 + x_1 - 2 = 0 \Rightarrow (x_1 + 2)(x_1 - 1) = 0$。
>
> $x_1 = 1$ 或 $x_1 = -2$。由 $x_1 \geq 0$，取 $x_1 = 1$，$x_2 = 1$。
>
> 驻点：$2(1 - 2) + \mu_1 + 2\mu_2 \cdot 1 = -2 + \mu_1 + 2\mu_2 = 0$
>
> $2(1 - 1) + \mu_1 - \mu_2 = \mu_1 - \mu_2 = 0 \Rightarrow \mu_1 = \mu_2$。
>
> 得 $3\mu_1 = 2 \Rightarrow \mu_1 = \mu_2 = \frac{2}{3} > 0$ $\checkmark$。
>
> 检验：$g_1(1,1) = 0 \leq 0$ $\checkmark$，$g_2(1,1) = 0 \leq 0$ $\checkmark$，$x_1 = 1 \geq 0$ $\checkmark$，$\mu_3 = 0$ $\checkmark$。
>
> **KKT 点：** $\boxed{x^* = (1, 1)^\top}$，$f(1, 1) = (1-2)^2 + (1-1)^2 = 1$。
>
> ---
>
> **Case 6：$g_1$ 和 $g_3$ 同时活动（$\mu_1 > 0,\; \mu_3 > 0,\; \mu_2 = 0$）**
>
> $x_1 = 0,\; x_1 + x_2 = 2 \Rightarrow x_2 = 2$。
>
> 驻点：$2(0-2) + \mu_1 - \mu_3 = -4 + \mu_1 - \mu_3 = 0$
>
> $2(2-1) + \mu_1 = 2 + \mu_1 = 0 \Rightarrow \mu_1 = -2 < 0$。**违反对偶可行性，排除。**
>
> ---
>
> **Case 7：$g_2$ 和 $g_3$ 同时活动（$\mu_2 > 0,\; \mu_3 > 0,\; \mu_1 = 0$）**
>
> $x_1 = 0,\; x_2 = x_1^2 = 0$。
>
> $2(0-2) + 0 - \mu_3 = -4 - \mu_3 = 0 \Rightarrow \mu_3 = -4 < 0$。**排除。**
>
> ---
>
> **Case 8：三个约束全部活动**
>
> $x_1 = 0,\; x_2 = 0,\; x_1 + x_2 = 0 \neq 2$。**不可能同时满足，排除。**
>
> ---
>
> ### (c) 真正的极小点
>
> 所有 KKT 点中仅 Case 5 满足全部条件，其余均被排除。
>
> **真解：** $x^* = (1, 1)^\top$，$f^* = 1$。
>
> **全局最优性论证：**
> - $f(x) = (x_1-2)^2 + (x_2-1)^2$ 是凸函数（Hessian $2I \succ 0$，严格凸）。
> - $g_1(x) = x_1 + x_2 - 2$ 是仿射函数（凸）。
> - $g_2(x) = x_1^2 - x_2$，Hessian $\operatorname{diag}(2, 0) \succeq 0$，故 $g_2$ 是凸函数。
> - $g_3(x) = -x_1$ 是线性函数（凸）。
> - 可行域 $\{x \mid g_i(x) \leq 0,\; i=1,2,3\}$ 是凸集（凸函数的下水平集之交）。
>
> 凸优化问题中，任何 KKT 点即为全局最优解，且此处 $f$ 严格凸，故解唯一。
>
> ---
>
> ### (d) 可行域示意图
>
> ```mermaid
> flowchart LR
>     subgraph "可行域分析（坐标示意）"
>         A["曲线 x2 = x1^2<br/>—— g2=0 边界"]
>         B["直线 x2 = 2 - x1<br/>—— g1=0 边界"]
>         C["x1=0 —— g3=0 边界"]
>         D["★ KKT点 (1, 1)<br/>g1=0且g2=0的交点"]
>     end
>     A --> D
>     B --> D
>     C --> D
> ```
>
> **可行域文字描述：**
> - $g_1 \leq 0$：直线 $x_1 + x_2 = 2$ 的下方（左下半平面）。
> - $g_2 \leq 0$：抛物线 $x_2 = x_1^2$ 的上方（$x_2 \geq x_1^2$）。
> - $g_3 \leq 0$：$x_1 \geq 0$（右半平面）。
>
> 可行域是三条边界围成的区域：$x_1 \in [0, 1]$ 时下界为 $x_2 = x_1^2$、上界为 $x_2 = 2 - x_1$；$x_1 \in [1, 2]$ 时下界为 $x_2 = x_1^2$、上界为 $x_2 = 2 - x_1$（此时 $x_1^2 > 2 - x_1$，交集为空）。故可行域为 $x_1 \in [0, 1]$ 且 $x_1^2 \leq x_2 \leq 2 - x_1$。
>
> KKT 点 $(1, 1)$ 恰好位于两条活动约束 $g_1$ 和 $g_2$ 交界处——这是典型的"边界解"。
>
> $\square$
>
> **点评：** 本题系统展示了 KKT 条件求解不等式约束问题的标准流程。核心经验：(1) KKT 是"嫌疑犯搜查令"——先枚举所有活动约束组合，再逐一验证；(2) 互补松弛是快速筛选工具——若 $\mu_i = 0$ 则对应的 $g_i(x)$ 可以严格小于 $0$；(3) 对于凸问题，KKT 也是充分条件，找到即最优。考试中常见陷阱：忘记检查某个活动约束组合导致漏解，或忘记检查对偶可行性（$\mu_i \geq 0$）导致接受非 KKT 点。
