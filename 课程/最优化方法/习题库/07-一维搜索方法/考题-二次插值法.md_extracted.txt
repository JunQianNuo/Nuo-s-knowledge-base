# 考题 06

**a.** 给定三个点 $(x_1, f_1), (x_2, f_2), (x_3, f_3)$，满足 $x_1 < x_2 < x_3$ 且 $f_1 > f_2 < f_3$（即三点形成包含极小点的"山谷"形状）。用二次多项式 $\varphi(x) = ax^2 + bx + c$ 拟合这三个点，推导二次插值极小点 $x^*$ 的计算公式。

**b.** 将公式应用于以下数据：$(0, 5),\ (1, 2),\ (3, 4)$，计算近似的极小点。

---

## 💡 提示

> [!hint]- 点击展开提示
> **a 部分的推导策略**：
>
> 方法一（Lagrange 插值）：写出过三点的 Lagrange 二次插值多项式，令其导数为零。
>
> 方法二（解线性方程组）：由 $\varphi(x_i) = f_i\ (i=1,2,3)$ 解出 $a, b$，然后 $x^* = -b/(2a)$。
>
> 方法三（利用 $x_2$ 为中心）：令 $\varphi(x) = a(x - x_2)^2 + b(x - x_2) + c$，可简化计算。
>
> 最终结果应对称于三个数据点。
>
> **验证条件**：三点需满足 $f_1 > f_2 < f_3$（确保拟合二次曲线的开口向上，即 $a > 0$）。

---

## 📝 详细解析

> [!solution]- 点击展开详细解析
>
> ### a. 推导二次插值极小点公式
>
> #### 方法一：解线性方程组
>
> 设 $\varphi(x) = ax^2 + bx + c$，代入三个数据点：
>
> $$\begin{cases} a x_1^2 + b x_1 + c = f_1 \\ a x_2^2 + b x_2 + c = f_2 \\ a x_3^2 + b x_3 + c = f_3 \end{cases}$$
>
> $(2) - (1)$：
> $$a(x_2^2 - x_1^2) + b(x_2 - x_1) = f_2 - f_1$$
> $$a(x_2 + x_1)(x_2 - x_1) + b(x_2 - x_1) = f_2 - f_1$$
>
> 消去 $x_2 - x_1 \neq 0$：
> $$a(x_2 + x_1) + b = \frac{f_2 - f_1}{x_2 - x_1} \quad\cdots\,(4)$$
>
> $(3) - (2)$ 同理：
> $$a(x_3 + x_2) + b = \frac{f_3 - f_2}{x_3 - x_2} \quad\cdots\,(5)$$
>
> $(5) - (4)$：
> $$a(x_3 - x_1) = \frac{f_3 - f_2}{x_3 - x_2} - \frac{f_2 - f_1}{x_2 - x_1}$$
>
> 解得：
> $$a = \frac{1}{x_3 - x_1}\left( \frac{f_3 - f_2}{x_3 - x_2} - \frac{f_2 - f_1}{x_2 - x_1} \right)$$
>
> 由 $(4)$ 得：
> $$b = \frac{f_2 - f_1}{x_2 - x_1} - a(x_1 + x_2)$$
>
> 极小点 $x^*$ 满足 $\varphi'(x^*) = 2ax^* + b = 0$，即：
> $$x^* = -\frac{b}{2a} = \frac{1}{2}\left(x_1 + x_2 - \frac{1}{a} \cdot \frac{f_2 - f_1}{x_2 - x_1}\right)$$
>
> #### 方法二：对称公式
>
> 利用 Lagrange 插值更为对称。过三点的二次多项式：
>
> $$\varphi(x) = f_1 \frac{(x-x_2)(x-x_3)}{(x_1-x_2)(x_1-x_3)} + f_2 \frac{(x-x_1)(x-x_3)}{(x_2-x_1)(x_2-x_3)} + f_3 \frac{(x-x_1)(x-x_2)}{(x_3-x_1)(x_3-x_2)}$$
>
> 求导并令 $\varphi'(x^*) = 0$，整理得：
>
> $$\boxed{x^* = \frac{1}{2}\;\frac{(x_2^2 - x_3^2)f_1 + (x_3^2 - x_1^2)f_2 + (x_1^2 - x_2^2)f_3}{(x_2 - x_3)f_1 + (x_3 - x_1)f_2 + (x_1 - x_2)f_3}}$$
>
> 这是二次插值极小点的**标准公式**，对称且便于记忆。
>
> ### b. 代入具体数据
>
> 数据：$(x_1, f_1) = (0, 5)$，$(x_2, f_2) = (1, 2)$，$(x_3, f_3) = (3, 4)$。
>
> 验证山谷条件：$f_1 = 5 > f_2 = 2 < f_3 = 4$ ✔
>
> 计算分子：
> $$(x_2^2 - x_3^2)f_1 = (1 - 9) \times 5 = (-8) \times 5 = -40$$
> $$(x_3^2 - x_1^2)f_2 = (9 - 0) \times 2 = 18$$
> $$(x_1^2 - x_2^2)f_3 = (0 - 1) \times 4 = -4$$
> $$\text{分子} = -40 + 18 - 4 = -26$$
>
> 计算分母：
> $$(x_2 - x_3)f_1 = (1 - 3) \times 5 = -10$$
> $$(x_3 - x_1)f_2 = (3 - 0) \times 2 = 6$$
> $$(x_1 - x_2)f_3 = (0 - 1) \times 4 = -4$$
> $$\text{分母} = -10 + 6 - 4 = -8$$
>
> $$x^* = \frac{1}{2} \times \frac{-26}{-8} = \frac{1}{2} \times \frac{26}{8} = \frac{13}{8} = 1.625$$
>
> 验证 $a > 0$（开口向上，确为极小）：
> $$a = \frac{1}{x_3 - x_1}\left( \frac{f_3 - f_2}{x_3 - x_2} - \frac{f_2 - f_1}{x_2 - x_1} \right) = \frac{1}{3}\left( \frac{2}{2} - \frac{-3}{1} \right) = \frac{1}{3}(1 + 3) = \frac{4}{3} > 0 \ \checkmark$$
>
> ### 结果总结
>
> 过三点 $(0, 5), (1, 2), (3, 4)$ 的二次插值多项式为：
> $$\varphi(x) = \frac{4}{3}(x - 1.625)^2 + \frac{31}{16}$$
>
> 其极小点为 $x^* = 1.625$，极小值为 $\varphi(1.625) = 31/16 \approx 1.9375$。
>
> **点评**：二次插值法用三个点拟合抛物线来逼近原函数的极小点，不需要计算导数。当函数在极小点附近近似为二次函数时，该方法收敛很快（超线性收敛，收敛阶约 $1.3$）。其缺点是需要三个初始点形成"山谷"结构，且每步用新点替换旧点中最远/最差的点以保持括号性质。
>
> $\square$
