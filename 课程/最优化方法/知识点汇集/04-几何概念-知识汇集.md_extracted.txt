## 2. 基础定义

### 2.1 基本几何对象

| 术语 | 符号/定义 | 参数条件 |
|------|----------|----------|
| 直线 | $\{a x + (1-a) y \mid a \in \mathbb{R}\}$ | $a$ 无限制 |
| 线段 | $[x, y] = \{a x + (1-a) y \mid a \in [0, 1]\}$ | $a \in [0,1]$ |
| 射线 | $\{a x + (1-a) y \mid a \geq 0\}$ | $a \geq 0$ |
| 超平面 | $H = \{x \mid v^{\top}(x - a) = 0\}$，$v \neq 0$ | $v$ 为法向量 |
| 正半空间 | $H^{+} = \{x \mid v^{\top}(x - a) \geq 0\}$ | 超平面一侧 |
| 负半空间 | $H^{-} = \{x \mid v^{\top}(x - a) \leq 0\}$ | 超平面另一侧 |
| 线性簇 | $L = \{x \mid Ax = b\}$ | $\dim L = \dim N(A)$ |

### 2.2 凸集

| 术语 | 定义 | 等价刻画 |
|------|------|----------|
| 凸集 | 任意两点的线段全在集合内 | $a x + (1-a)y \in S,\ \forall x,y \in S,\ \forall a \in (0,1)$ |

### 2.3 三种"包"

| 术语 | 离散形式（$C=\{x_i\}_{i=1}^m$） | 系数条件 |
|------|----------|----------|
| 凸包 $\operatorname{conv}(C)$ | $\{\sum a_i x_i\}$ | $a_i \geq 0,\ \sum a_i = 1$ |
| 锥包 $\operatorname{cone}(C)$ | $\{\sum a_i x_i\}$ | $a_i \geq 0$ |
| 仿射包 $\operatorname{aff}(C)$ | $\{\sum a_i x_i\}$ | $\sum a_i = 1$ |

### 2.4 球、椭球与凸锥

| 术语 | 定义 | 条件 |
|------|------|------|
| 球 | $B(x_0, r) = \{x \mid \|x - x_0\| \leq r\}$ | $r > 0$ |
| 椭球 | $E = \{x \mid \|x - x_0\|_{P^{-1}}^2 \leq r\}$ | $P \succ 0, P = P^{\top}$ |
| 椭球（变换形式） | $E = \{x_0 + A u \mid \|u\|_2 \leq r\}$ | $A$ 非奇异 |
| 二阶锥 | $K = \{(x, t) \in \mathbb{R}^n \times \mathbb{R} \mid \|x\|_2 \leq t\}$ | — |
| 正半定锥 | $\mathbb{S}_+^n = \{A \in \mathbb{R}^{n \times n} \mid A = A^{\top}, A \succeq 0\}$ | — |

### 2.5 点的分类

| 术语 | 定义 |
|------|------|
| 内点 | $\exists N(x) \subseteq S$ |
| 边界点 | $\forall N(x)$ 既含 $S$ 中点也含 $S$ 补集中点 |
| 相对内点 | $\exists N(x) \cap \operatorname{aff}(S) \subseteq S$ |

### 2.6 集合分类

| 术语 | 定义 |
|------|------|
| 开集 | 每个点都是内点 |
| 闭集 | 包含所有边界点（补集是开集） |
| 有界集 | 可用有限半径球覆盖 |
| 紧集 | 有界 + 闭（$\mathbb{R}^n$ 中） |

### 2.7 极点、多面体与支撑超平面

| 术语 | 定义 |
|------|------|
| 极点 | 不能表示为 $S$ 中其他两点的严格凸组合 |
| 极点等价刻画 | $x$ 是极点 $\Longleftrightarrow$ $S \setminus \{x\}$ 仍是凸集 |
| 多面体 | $\{x \mid a_i^{\top} x \leq b_i,\ i=1,\cdots,m\}$（有限半空间交） |
| 多胞体 | 非空且有界的多面体 |
| 支撑超平面 | 过凸集边界点 $x$ 的超平面，使凸集全在一侧 |
| 面（face） | $(k-1)$ 维多面体，形成 $k$ 维多面体边界 |
| 顶点 | 0 维面 |
| 边 | 1 维面 |

## 3. 核心方法/定理

### 3.1 凸集判定（用定义）

**三段式验证**：任取 $x, y \in S$ → 构造凸组合 $a x + (1-a) y$ → 检查是否属于 $S$。

**课件判定练习**：

| 集合 | 判定 | 理由 |
|------|:---:|------|
| $S = \{x \in \mathbb{R}^2 \mid x_1 x_2 \geq 1,\ x_1 \geq 0,\ x_2 \geq 0\}$ | 凸 | 双曲线上方区域 |
| $S = \{x \in \mathbb{R}^n \mid x^{\top} A x + b^{\top} x + c \leq 0,\ A \succ 0\}$ | 凸 | 凸函数水平下集 |
| 空集、单点集、直线、线段、子空间 | 凸 | 平凡情况 |
| 超平面、半空间、线性簇、多面体 | 凸 | 仿射集或半空间交 |
| 二阶锥、正半定锥 | 凸 | 见 3.4 |

### 3.2 保凸运算定理

集合 $\Theta, \Theta_1, \Theta_2$ 是凸集 $\Longrightarrow$ 以下运算结果也是凸集：

| 运算 | 定义 | 类型 |
|------|------|------|
| 数乘 | $r \Theta = \{r x \mid x \in \Theta\}$ | 一元 |
| 交集 | $\Theta_1 \cap \Theta_2$ | 二元 |
| Minkowski 和/差 | $\Theta_1 \pm \Theta_2 = \{x_1 \pm x_2 \mid x_1 \in \Theta_1, x_2 \in \Theta_2\}$ | 二元 |
| 线性变换 | $A \Theta = \{A x \mid x \in \Theta\}$ | 一元 |
| 内部 | $\operatorname{int}(\Theta)$ | 一元 |
| 闭包 | $\operatorname{cl}(\Theta)$ | 一元 |

### 3.3 三种"包"的性质

| 性质 | 凸包 | 锥包 | 仿射包 |
|------|:---:|:---:|:---:|
| 结果类型 | 凸集 | 凸锥 | 仿射集 |
| 最小性 | 包含 $C$ 的最小凸集 | 包含 $C$ 的最小凸锥 | 包含 $C$ 的最小仿射集 |
| 系数要求 | $a_i \geq 0,\ \sum a_i = 1$ | $a_i \geq 0$ | $\sum a_i = 1$ |

### 3.4 两类重要凸锥

| 凸锥 | 定义 | 应用领域 |
|------|------|----------|
| 二阶锥 | $K = \{(x, t) \mid \|x\|_2 \leq t\}$ | 二阶锥规划 (SOCP) |
| 正半定锥 | $\mathbb{S}_+^n = \{A = A^{\top} \succeq 0\}$ | 半定规划 (SDP) |

### 3.5 各类集合的极点

| 集合 | 极点 |
|------|------|
| 概率单纯形 $\{x \geq 0 \mid \sum x_i = 1\}$ | 自然基 $e_1, \ldots, e_n$ |
| 全维单纯形 $\{0 \leq x \leq 1 \mid \sum x_i \leq 1\}$ | $e_1, \ldots, e_n$ 和 $0$ |
| $\ell_1$ 范数单位球 $\{\|x\|_1 \leq 1\}$ | $\pm e_1, \ldots, \pm e_n$（$2n$ 个） |
| $\ell_{\infty}$ 范数单位球 $\{\|x\|_{\infty} \leq 1\}$ | 全部分量为 $\pm 1$（$2^n$ 个） |
| 圆盘 | 无极点 |
| 多面体 | 顶点 |
| 线段 | 端点 |

### 3.6 Birkhoff 定理

**双随机矩阵多面体**：
$$\mathcal{P}_n = \{X \in \mathbb{R}^{n \times n} \mid X \geq 0,\ X e = e,\ e^{\top} X = e^{\top}\}$$

**定理**：$\mathcal{P}_n$ 的极点是置换矩阵，共 $n!$ 个。

**推论**：任意双随机矩阵可写为置换矩阵的凸组合（Birkhoff-von Neumann 分解）。

### 3.7 Weierstrass 定理

**定理**：设 $\Omega \subset \mathbb{R}^n$ 紧，$f: \Omega \to \mathbb{R}$ 连续。则 $\min_{x \in \Omega} f(x)$ 存在（解的存在性）。

**条件缺一不可**：
- $\Omega$ 不闭：开区间上最小值可能取不到
- $\Omega$ 无界：函数可能趋于 $-\infty$ 或趋近但不到达下确界
- $f$ 不连续：可能跳跃越过最小值

**唯一性的额外条件**：严格凸性、下半连续性、强制性（$\|x\| \to \infty \Rightarrow f(x) \to \infty$）。

### 3.8 支撑超平面定理

设 $\Theta \subset \mathbb{R}^n$ 凸，$x \in \operatorname{bd}(\Theta)$。存在过 $x$ 的超平面使 $\Theta$ 完全在一侧（分离定理的前身，通向 Lagrange 对偶）。

## 4. 计算/应用

### 4.1 凸集判定实例

**例1**（习题4.3）：证明 $\{x \mid Ax = b\}$ 是凸集。
- 任取 $x_1, x_2$ 满足 $A x_1 = b$，$A x_2 = b$
- 构造 $x = a x_1 + (1-a) x_2$，$a \in (0,1)$
- $A x = a A x_1 + (1-a) A x_2 = a b + (1-a) b = b$
- $\therefore x$ 满足方程组 → 凸集

**例2**：判断 $S = \{x \mid x_1 x_2 \geq 1, x_1 \geq 0, x_2 \geq 0\}$ 是否凸集。
- 取 $(1,2)$ 和 $(2,1)$，中点 $(1.5, 1.5)$，$1.5 \times 1.5 = 2.25 \geq 1$ ✓
- 该集合是凸集（双曲线上方区域）

### 4.2 保凸运算应用

**技巧**：遇到复杂集合的凸性判定，优先尝试将其分解为已知凸集经保凸运算的组合，避免直接用定义验证。

**常见模式**：
- $Ax \leq b$ → 半空间（凸）的交 → 凸
- $\{x \mid f(x) \leq c\}$（$f$ 凸）→ 凸函数水平下集 → 凸
- $\{x \mid g(x) = 0\}$（$g$ 仿射）→ 超平面（凸）

### 4.3 极点的判定方法

取凸集 $S$ 中点 $x$：
1. 尝试将 $x$ 写成 $S$ 中不同两点 $u, v$ 的严格凸组合
2. 若存在 → $x$ 不是极点
3. 若不存在 → $x$ 是极点

**等价检验**：检查 $S \setminus \{x\}$ 是否仍是凸集。

### 4.4 Weierstrass 定理使用检查清单

- [ ] 可行域 $\Omega$ 是否闭？（检查边界点是否都在集合内）
- [ ] 可行域 $\Omega$ 是否有界？（检查 $\|x\| \to \infty$ 是否仍在集合内）
- [ ] 目标函数 $f$ 是否连续？
- [ ] 三项全部满足 → $\min f(x)$ 存在
- [ ] 如需唯一性 → 检查 $f$ 是否严格凸

## 7. 易错点与注意事项

> [!warning] 凸集判定：凸组合的 $a$ 范围是 $(0,1)$
> 用定义判定凸性时，注意 $a \in (0,1)$（开区间）。端点 $a=0$ 或 $a=1$ 给出 $x$ 或 $y$ 本身，属于平凡情况。

> [!warning] 凸包、锥包、仿射包的核心区别在系数条件
> 凸包 = 非负 + 和为 1；锥包 = 仅非负；仿射包 = 仅和为 1。考试高频考点——必须脱口而出。

> [!warning] 极点 $\neq$ 边界点
> 圆盘的边界上每个点都是边界点，但圆盘没有极点（圆盘内任意点可写成其他两点的凸组合）。只有带"尖角"的凸集才有极点。

> [!warning] 紧性对 Weierstrass 定理不可或缺
> 缺闭性（如开区间）或缺有界性（如无界可行域）都可能导致最小值不存在。连续性的缺失同样可能导致问题。

> [!warning] 凸集去掉一点未必仍是凸集
> 极点等价刻画的关键：$x$ 是凸集 $S$ 的极点当且仅当 $S \setminus \{x\}$ 仍是凸集。这意味着只有拿走极点才不破坏凸性；拿走非极点会产生"凹陷"。

> [!warning] 保凸运算只能用在凸集上
> 数乘、交、Minkowski 和、线性变换、取内部/闭包——这些操作保持凸性，但前提是原始集合本身就是凸集。不能用于验证未知集合的凸性。

> [!warning] 三种包的最小性
> $\operatorname{conv}(C)$ 是包含 $C$ 的**最小**凸集；若另有一凸集 $K \supset C$，则 $\operatorname{conv}(C) \subseteq K$。类似地，锥包和仿射包也满足最小性。

> [!warning] 超平面分类
> $v=0$ 时超平面过原点 → 子空间；$v \neq 0$ 时超平面不过原点 → 流形（仿射集）。这个区分影响后续对 Lagrange 乘子法的理解。
