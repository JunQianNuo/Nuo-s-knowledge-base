# 常考查的证明

> 一句说清：集中梳理跨章节核心证明，重点掌握多维正态"不相关 ⇔ 独立"的论证逻辑和 CLT 相关推导链。

---

## 1. 多维正态：不相关 ⇔ 独立（必考 ⭐）

### 命题

设 $X = (\xi_1, \ldots, \xi_n) \sim N(M, \Sigma)$，则
$$\xi_i \text{ 与 } \xi_j \text{ 不相关} \iff \operatorname{Cov}(\xi_i, \xi_j) = 0 \iff \xi_i \text{ 与 } \xi_j \text{ 相互独立}$$

### 证明思路

**关键**：利用多维正态的特征函数形式。

1. $X \sim N(M, \Sigma)$ 的特征函数：
   $$\varphi(t) = \exp\left\{jM^T t - \frac{1}{2} t^T \Sigma t\right\}$$

2. 若 $\operatorname{Cov}(\xi_i, \xi_j) = 0$（所有 $i \neq j$），则 $\Sigma$ 是对角阵：
   $$\Sigma = \operatorname{diag}(\sigma_1^2, \ldots, \sigma_n^2)$$

3. 代入特征函数：
   $$\varphi(t) = \exp\left\{j\sum m_k t_k - \frac{1}{2}\sum \sigma_k^2 t_k^2\right\} = \prod_{k=1}^n \exp\left\{j m_k t_k - \frac{1}{2}\sigma_k^2 t_k^2\right\}$$

4. 右边恰为各分量特征函数之积 → 由唯一性定理，联合分布 = 各边缘分布之积 → **各分量相互独立**。

**反向**（独立 ⇒ 不相关）：独立时 $\operatorname{Cov}(\xi_i, \xi_j) = E(\xi_i\xi_j) - E(\xi_i)E(\xi_j) = 0$，显然。

### 考试提醒

> 注意大前提：**多维正态**。若只说"两个正态变量不相关"，不能直接推独立——必须是联合正态！

## 2. CLT 推导链（理解即可，但要会叙述）

### 林德伯格-莱维 CLT 证明要点

**命题**：$\{\xi_k\}$ 独立同分布，$E(\xi_k)=\mu$，$D(\xi_k)=\sigma^2<\infty$，则

$$\frac{\sum_{k=1}^n \xi_k - n\mu}{\sqrt{n}\sigma} \xrightarrow{d} N(0,1)$$

**证明链**：

1. **标准化**：令 $Y_n = \frac{\sum (\xi_k - \mu)}{\sqrt{n}\sigma} = \sum \frac{\xi_k - \mu}{\sqrt{n}\sigma} = \sum X_{nk}$

2. **求特征函数**：$\varphi_{Y_n}(t) = \left[\varphi_X\left(\frac{t}{\sqrt{n}\sigma}\right)\right]^n$，其中 $X = \xi_1 - \mu$

3. **泰勒展开**（利用 $E(X)=0$，$E(X^2)=\sigma^2$）：
   $$\varphi_X(u) = 1 + jE(X)u - \frac{1}{2}E(X^2)u^2 + o(u^2) = 1 - \frac{\sigma^2}{2}u^2 + o(u^2)$$

4. **代入并取极限**：
   $$\varphi_{Y_n}(t) = \left[1 - \frac{t^2}{2n} + o\left(\frac{1}{n}\right)\right]^n \to e^{-t^2/2}$$

5. 由 **Lévy-Cramér 连续性定理**，$Y_n \xrightarrow{d} N(0,1)$。

## 3. 全期望公式证明

### 命题

$E(\xi) = E[E(\xi|\eta)]$

### 证明（连续型）

1. 由定义：$E[E(\xi|\eta)] = \int_{-\infty}^{+\infty} E(\xi|\eta=y) \cdot f_\eta(y) \, dy$

2. 代入 $E(\xi|\eta=y) = \int x \cdot f_{\xi|\eta}(x|y) \, dx$：
   $$= \int_{-\infty}^{+\infty} \left[\int_{-\infty}^{+\infty} x \cdot f_{\xi|\eta}(x|y) \, dx\right] f_\eta(y) \, dy$$

3. 交换积分次序 + 条件密度公式 $f_{\xi|\eta}(x|y) \cdot f_\eta(y) = f(x,y)$：
   $$= \int_{-\infty}^{+\infty} x \left[\int_{-\infty}^{+\infty} f(x,y) \, dy\right] dx = \int_{-\infty}^{+\infty} x f_\xi(x) \, dx = E(\xi)$$

## 4. 正态分布线性变换仍是正态

### 命题

若 $X \sim N(M, \Sigma)$（$n$ 维），则 $Y = AX + b \sim N(AM+b, A\Sigma A^T)$

### 证明（特征函数法）

1. $X$ 的特征函数：$\varphi_X(t) = \exp\{jM^T t - \frac{1}{2} t^T \Sigma t\}$

2. $Y = AX + b$ 的特征函数：
   $$\varphi_Y(s) = E[e^{js^T Y}] = E[e^{js^T(AX+b)}] = e^{js^T b} \cdot E[e^{j(A^T s)^T X}]$$

3. $= e^{js^T b} \cdot \varphi_X(A^T s) = \exp\{js^T b + jM^T A^T s - \frac{1}{2} s^T A\Sigma A^T s\}$

4. $= \exp\{j(AM+b)^T s - \frac{1}{2} s^T (A\Sigma A^T) s\}$

5. 这正是 $N(AM+b, A\Sigma A^T)$ 的特征函数，由唯一性定理得证。

## 5. 切比雪夫不等式 → 方差为零则几乎处处为常数

### 命题

$D(\xi) = 0 \implies P\{\xi = E(\xi)\} = 1$

### 证明

1. 由切比雪夫不等式：$\forall \varepsilon > 0$，$P\{|\xi - E\xi| \ge \varepsilon\} \le \frac{D(\xi)}{\varepsilon^2} = \frac{0}{\varepsilon^2} = 0$

2. 故 $P\{|\xi - E\xi| < \varepsilon\} = 1$ 对所有 $\varepsilon > 0$ 成立

3. 令 $\varepsilon \to 0^+$，由概率的连续性：$P\{\xi = E\xi\} = 1$
