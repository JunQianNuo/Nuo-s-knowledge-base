## 考试信息

- **形式**：全院统考，A/B 卷
- **难度**：非考研难度，覆盖重要知识点
- **题型分布**（根据串讲推断）：
  - 大题：林德伯格-莱维 CLT 应用题、全期望公式应用题
  - 小题（填空/选择）：棣莫弗-拉普拉斯 CLT、大数定律概念、特征函数识别、数字特征计算
  - 可能涉及证明：多维正态不相关⇔独立的论证

## 使用建议

1. **先读串讲原文** → [[../未处理/概率论复习串讲.txt|概率论复习串讲]] 了解考试重点分布
2. **按板块顺序复习**：I → II → III → IV → V，每块约 40-60 分钟
3. **对照知识梳理**：每块末尾有回链到 [[../知识点解析梳理/|知识点解析梳理]] 的详细笔记
4. **证明专项**：[[复习/常考查的证明|常考查的证明]] 集中攻克跨章节证明
5. **查漏补缺**：从 [[课程/概率论/概率论-学习导航|课程导航]] 定位知识梳理的完整讲解；需要核对定义、条件或步骤时，再查阅相关共享概念、知识点与方法条目。

## 不考大题的提醒

根据串讲明确说明：
- ❌ 大数定律（辛钦、伯努利）不考大题 — 但依概率收敛概念可能结合其他内容考小题
- ❌ 棣莫弗-拉普拉斯 CLT 不单独考大题 — 可能出现在填空/选择中
- ✅ 林德伯格-莱维 CLT（独立同分布情形）**必考一道应用大题**
- ✅ 全期望公式 **必考**
- ✅ 多维正态不相关⇔独立 **必考结论**
