# II · 特征函数与多维正态

> 一句说清：特征函数与分布函数一一对应（唯一性定理），6 个常见分布的特征函数必须记住；多维正态中"不相关 ⇔ 独立"是必考结论。

---

## 核心定义速查

### 特征函数定义

$$\varphi(t) = E(e^{jt\xi}) = \int_{-\infty}^{+\infty} e^{jtx} dF(x)$$

| 类型 | 形式 |
|:--|:--|
| 连续型 | $\varphi(t) = \int e^{jtx} f(x) dx$ |
| 离散型 | $\varphi(t) = \sum_k e^{jtx_k} p_k$ |

### 常见分布的特征函数（必记6个）

| 分布 | 特征函数 $\varphi(t)$ | 记忆要点 |
|:--|:--|:--|
| 二项 $B(n,p)$ | $(q + pe^{jt})^n$ | $n$ 个伯努利之积 |
| 泊松 $P(\lambda)$ | $e^{\lambda(e^{jt}-1)}$ | 指数上有指数 |
| 几何 $G(p)$ | $\frac{pe^{jt}}{1 - qe^{jt}}$ | — |
| 均匀 $U[-a,a]$ | $\frac{\sin at}{at}$ | 经典 $\operatorname{sinc}$ 函数 |
| 指数 $\operatorname{Exp}(\lambda)$ | $\frac{\lambda}{\lambda - jt}$ | 分母含 $jt$ |
| 正态 $N(\mu,\sigma^2)$ | $e^{j\mu t - \frac{1}{2}\sigma^2 t^2}$ | 特征函数也是"正态形式" |

**特例**：$N(0,1)$ 的特征函数 $\varphi(t) = e^{-t^2/2}$

---

## 关键定理

### 唯一性定理（串讲重点）

**定理**：分布函数 $F_1(x) = F_2(x) \iff \varphi_1(t) = \varphi_2(t)$

> 特征函数和分布函数**一一对应**——这是数学专业与非数学专业的本质区别之一。

**反演公式**（逆转公式）是实现唯一性的工具：

$$F(x_2) - F(x_1) = \lim_{T\to\infty} \frac{1}{2\pi} \int_{-T}^{T} \frac{e^{-jtx_1} - e^{-jtx_2}}{jt} \varphi(t) dt$$

**连续型特例**（$\varphi$ 绝对可积时）：$f(x) = \frac{1}{2\pi} \int e^{-jtx} \varphi(t) dt$

### 特征函数与矩的关系

$$E(\xi^k) = j^{-k} \varphi^{(k)}(0)$$

> 求矩不用积分，特征函数在 0 处求导即可。

### Lévy-Cramér 连续性定理

$$F_n \xrightarrow{W} F \iff \varphi_n(t) \to \varphi(t) \text{ 在任意有限区间一致收敛}$$

> 这是用特征函数证明 CLT 的桥梁：验证样本均值的特征函数 → 正态特征函数 → 依分布收敛到正态。

---

## 多维正态（必考板块）

### 定义（矩阵形式）

$X \sim N(M, \Sigma)$，密度：

$$\varphi(X) = \frac{1}{(2\pi)^{n/2} |\Sigma|^{1/2}} \exp\left\{-\frac{1}{2}(X-M)^T \Sigma^{-1} (X-M)\right\}$$

特征函数：

$$\varphi(t) = \exp\left\{jM^T t - \frac{1}{2} t^T \Sigma t\right\}$$

### 必考结论 ①：不相关 ⇔ 独立 ⭐

**在多维正态的大前提下**，以下三者等价：
$$\xi_i \text{ 与 } \xi_j \text{ 不相关} \iff \operatorname{Cov}(\xi_i, \xi_j) = 0 \iff \Sigma \text{ 为对角阵} \iff \xi_i \text{ 与 } \xi_j \text{ 相互独立}$$

> 这是我们学过的分布中，**唯一**不相关能推出独立的情形。

### 必考结论 ②：正态的线性性质

- **线性变换仍是正态**：若 $X \sim N(M, \Sigma)$，则 $Y = AX + b \sim N(AM+b, A\Sigma A^T)$
- **子向量也是正态**：$X$ 的任意分量子集仍服从多维正态
- **线性组合是一维正态**：任意非零线性组合 $a^T X$ 服从一维正态（这也是多维正态的**充要条件**）

### 二维正态速查

$(\xi, \eta) \sim N(m_1, \sigma_1^2; m_2, \sigma_2^2; r)$

- 边际分布：$\xi \sim N(m_1, \sigma_1^2)$，$\eta \sim N(m_2, \sigma_2^2)$
- 协方差：$\operatorname{Cov}(\xi, \eta) = r\sigma_1\sigma_2$
- 相关系数 $\rho = r$
- 独立 $\iff r = 0 \iff$ 不相关

## 典型题

### 特征函数识别题

> 已知 $\varphi(t) = e^{-t^2}$，识别分布 → $N(0, 2)$（因为 $e^{-\frac{1}{2} \cdot 2 \cdot t^2} = e^{-t^2}$）

### 多维正态判断题 ⭐

> 判断：若 $(\xi, \eta)$ 服从二维正态，且 $\operatorname{Cov}(\xi, \eta) = 0$，则 $\xi$ 和 $\eta$ 独立。

**答**：✅ 正确。多维正态下不相关 ⟺ 独立。

> 判断：若 $\xi \sim N(0,1)$，$\eta \sim N(0,1)$，且 $\operatorname{Cov}(\xi, \eta) = 0$，则 $\xi$ 和 $\eta$ 独立。

**答**：❌ 不一定。题目没说 $(\xi, \eta)$ 联合正态！仅知道边缘正态 + 不相关，不能推出独立。

---

## 易错点

1. **唯一性定理**只保证特征函数与分布函数一一对应，但**反演公式本身**也有绝对可积等条件限制
2. **不相关 ⇔ 独立只对多维正态成立**，其他分布不成立（如 $X \sim N(0,1)$，$Y = X^2$，$\operatorname{Cov}=0$ 但不独立）
3. 边缘正态 ≠ 联合正态（反例：边缘都是 $N(0,1)$ 但联合不是正态的分布存在）
4. 特征函数非负定性是判定"某个函数能否成为特征函数"的充要条件（波赫纳-辛钦定理）
