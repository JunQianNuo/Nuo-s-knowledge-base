# III · 数字特征与全期望公式

> 一句说清：全期望公式是必考内容（分解思想 + 信封匹配问题），期望/方差/协方差/相关系数的性质要熟稔于心，尤其注意"不相关 ≠ 独立"（除多维正态外）。

---

## 核心定义速查

### 数学期望

| 类型 | 定义 | 前提 |
|:--|:--|:--|
| 离散型 | $E(\xi) = \sum x_i p_i$ | $\sum \vert x_i\vert p_i < \infty$（绝对收敛） |
| 连续型 | $E(\xi) = \int x f(x) dx$ | $\int \vert x\vert f(x) dx < \infty$ |
| 一般 | $E(\xi) = \int x \, dF(x)$ | R-S 积分绝对可积 |

**关键性质**：
- **线性性**：$E(a\xi + b) = aE(\xi) + b$
- **独立/不相关时乘积的期望**：$E(\xi\eta) = E(\xi)E(\eta)$

### 方差

$$D(\xi) = E[(\xi - E\xi)^2]$$

**计算等价式**（最常用）：$D(\xi) = E(\xi^2) - [E(\xi)]^2$

**关键性质**：
- $D(c) = 0$（常数方差为零）
- $D(a\xi + b) = a^2 D(\xi)$
- $\xi, \eta$ 独立/不相关时：$D(\xi + \eta) = D(\xi) + D(\eta)$

**切比雪夫不等式**：$P\{|\xi - E\xi| \ge \varepsilon\} \le \frac{D(\xi)}{\varepsilon^2}$

### 协方差

$$\operatorname{Cov}(\xi, \eta) = E[(\xi - E\xi)(\eta - E\eta)]$$

**等价公式**：$\operatorname{Cov}(\xi, \eta) = E(\xi\eta) - E(\xi)E(\eta)$

**性质**：
- 双线性性（对每个变量线性）
- $\operatorname{Cov}(\xi, \xi) = D(\xi)$
- 若独立/不相关：$\operatorname{Cov}(\xi, \eta) = 0$

### 相关系数

$$\rho_{\xi\eta} = \frac{\operatorname{Cov}(\xi, \eta)}{\sqrt{D(\xi)}\sqrt{D(\eta)}}$$

**关键性质**：
- $|\rho| \le 1$
- $\rho = \pm 1 \iff \xi$ 与 $\eta$ 以概率 1 线性相关
- $\rho = 0$ 称为不相关（无线性关系，但**可能有非线性关系**）

## 全期望公式（必考 ⭐）

### 公式

$$E(\xi) = E[E(\xi|\eta)]$$

**离散型**：$E(\xi) = \sum_k E(\xi|\eta = y_k) \cdot P(\eta = y_k)$

**连续型**：$E(\xi) = \int E(\xi|\eta = y) \cdot f_\eta(y) \, dy$

### 分解思想（串讲核心）

> 当一个目标随机变量的数字特征难以直接求时，把它**分解成多个随机变量的和**（或借助条件期望）。

### 经典例题：信封匹配问题

> $n$ 封信随机放入 $n$ 个信封，求匹配数 $X$（信放对信封的数量）的期望。

**分解思路**：
1. 定义指示变量：$I_i = \begin{cases} 1, & \text{第 } i \text{ 封信放对} \\ 0, & \text{否则} \end{cases}$
2. 则 $X = \sum_{i=1}^n I_i$
3. $E(I_i) = P(\text{第 } i \text{ 封信放对}) = \frac{1}{n}$
4. $E(X) = \sum E(I_i) = n \cdot \frac{1}{n} = 1$

> 无论 $n$ 多大，平均只有 1 封信放对——这就是分解思想的威力。

### 全期望公式应用场景

- 随机和（随机个随机变量之和）
- 分层期望（按某个条件变量分层计算）
- 复合分布（如混合分布）的期望

## 典型题

### 题型1：数字特征计算

> 设 $(\xi, \eta)$ 在 $D = \{0 < x < 1, -x < y < x\}$ 上均匀分布，求 $E(2\xi+1)$、$D(\xi)$、$\operatorname{Cov}(\xi, \eta)$。

### 题型2：全期望应用题 ⭐

> 设 $N \sim P(\lambda)$，$\{\xi_i\}$ 独立同分布且与 $N$ 独立，$E(\xi_i) = \mu$，求随机和 $S_N = \sum_{i=1}^N \xi_i$ 的期望。

**解**：$E(S_N) = E[E(S_N|N)] = E[N \cdot \mu] = \mu E(N) = \mu\lambda$

---

## 易错点

1. **不相关 ≠ 独立**：只在多维正态下等价，一般分布下仅推出无线性关系（如 $X \sim N(0,1), Y = X^2$）
2. **$E(\xi\eta) = E(\xi)E(\eta)$ 需要独立或不相关**，不能无条件拆
3. **方差和公式** $D(\sum \xi_i) = \sum D(\xi_i)$ 要求**相互独立**（或不相关）
4. **相关系数为 0** 不意味没有关系——只意味没有**线性**关系
5. 计算 $\varphi^{(k)}(0)$ 时注意 $j^{-k}$ 因子转换
