## 1/9 单选题

f(x) = {4x³, 0 < x < 1 已知

0 , else

P{x > a} = P{x < a}, 则常数a =

A √2

B 1/√2

C √2

D 1/√2

> [!hint]- 点击展开提示
> 由 $P\{X > a\} = P\{X < a\}$ 结合连续性（$P\{X = a\} = 0$）可得 $P\{X < a\} = 1/2$，即 $a$ 是中位数。代入密度函数积分即可解出 $a$。

> [!solution]- 点击展开详细解析
> **解**：由 $P\{X > a\} = P\{X < a\}$ 且 $X$ 为连续型随机变量（有密度函数），故 $P\{X = a\} = 0$。
> 
> 由全概率公式：
> $$P\{X < a\} + P\{X = a\} + P\{X > a\} = 1$$
> 即 $2P\{X < a\} = 1$，得 $P\{X < a\} = \dfrac{1}{2}$。
> 
> 而 $P\{X < a\} = \displaystyle\int_0^a 4x^3\,dx = x^4\Big|_0^a = a^4 = \dfrac{1}{2}$。
> 
> 解得 $a = \sqrt[4]{\dfrac{1}{2}} = \dfrac{1}{\sqrt[4]{2}}$。
> 
> **答案**：$\dfrac{1}{\sqrt[4]{2}}$（对应选项 B 或 D，原题选项中 $1/\sqrt{2}$ 应为OCR识别误差，根号内指数应为4）
> 
> **点评**：本题本质上是在求中位数（median）。对于连续型对称分布，中位数与均值重合；但对于非对称分布（如此处的 $f(x)=4x^3$），需要积分求解。$\square$
