## 6/6 证明/计算/分析题

(1) 证明：
$$X_n \xrightarrow{P} X,\; Y_n \xrightarrow{P} Y \;\Rightarrow\; X_n + Y_n \xrightarrow{P} X + Y$$

(2) 证明：
$$X_n \xrightarrow{d} X,\; Y_n \xrightarrow{d} 0 \;\Rightarrow\; X_n + Y_n \xrightarrow{d} X$$

> [!hint]- 点击展开提示
> (1) 依概率收敛的线性性质：用三角不等式 $|(X_n+Y_n)-(X+Y)| \leq |X_n-X| + |Y_n-Y|$，然后对 $\varepsilon$ 用依概率收敛定义。(2) 用 Slutsky 定理：若 $X_n \xrightarrow{d} X$ 且 $Y_n \xrightarrow{d} c$（常数），则 $X_n + Y_n \xrightarrow{d} X + c$。这里 $c=0$。

> [!solution]- 点击展开详细解析
> **流程图**：
> ```mermaid
> flowchart TD
>   A[子题一：三角不等式放缩] --> B[用并集概率上界放缩]
>   B --> C[依概率收敛定义取极限]
>   C --> D[得证依概率收敛]
>   E[子题二：依分布收敛到常数] --> F[等价于依概率收敛到常数]
>   F --> G[构造集合包含关系]
>   G --> H[取概率得上下界不等式]
>   H --> I[令n趋于无穷取极限]
>   I --> J[令epsilon趋于零夹逼]
>   J --> K[得证依分布收敛]
> ```
>
> **证明**：
>
> ---
>
> **(1)** $X_n \xrightarrow{P} X,\; Y_n \xrightarrow{P} Y \;\Longrightarrow\; X_n + Y_n \xrightarrow{P} X + Y$
>
> 对任意 $\varepsilon > 0$：
> $$\begin{aligned}
> P\{|(X_n + Y_n) - (X + Y)| \geq \varepsilon\} &\leq P\{|X_n - X| + |Y_n - Y| \geq \varepsilon\} \\
> &\leq P\left\{|X_n - X| \geq \frac{\varepsilon}{2}\right\} + P\left\{|Y_n - Y| \geq \frac{\varepsilon}{2}\right\}
> \end{aligned}$$
>
> 其中用了 $\{|A+B|\geq\varepsilon\} \subseteq \{|A|\geq\varepsilon/2\} \cup \{|B|\geq\varepsilon/2\}$ 和并集的概率上界。
>
> 由假设 $X_n \xrightarrow{P} X$，$Y_n \xrightarrow{P} Y$：
> $$\lim_{n\to\infty} P\left\{|X_n - X| \geq \frac{\varepsilon}{2}\right\} = 0, \quad \lim_{n\to\infty} P\left\{|Y_n - Y| \geq \frac{\varepsilon}{2}\right\} = 0$$
>
> 因此 $\lim_{n\to\infty} P\{|(X_n+Y_n)-(X+Y)| \geq \varepsilon\} = 0$，即 $X_n + Y_n \xrightarrow{P} X + Y$。
>
> ---
>
> **(2)** $X_n \xrightarrow{d} X,\; Y_n \xrightarrow{d} 0 \;\Longrightarrow\; X_n + Y_n \xrightarrow{d} X$
>
> **第一步**：$Y_n \xrightarrow{d} 0$。收敛到常数时，依分布与依概率等价（C5.1 结论），故 $Y_n \xrightarrow{P} 0$。
>
> **第二步**：用夹逼法证 $X_n + Y_n \xrightarrow{d} X$。
>
> 对任意 $x \in \mathbb{R}$ 和 $\varepsilon > 0$，由集合包含关系：
> $$\{X_n \leq x - \varepsilon\} \;\subseteq\; \{X_n + Y_n \leq x\} \cup \{|Y_n| > \varepsilon\}$$
>
> 证第一个包含：若 $X_n + Y_n > x$ 且 $|Y_n| \leq \varepsilon$，则
> $$X_n = (X_n + Y_n) - Y_n > x - Y_n \geq x - \varepsilon$$
> 所以 $X_n \leq x - \varepsilon$ 时，不可能同时有 $X_n + Y_n > x$ 且 $|Y_n| \leq \varepsilon$——即要么 $X_n + Y_n \leq x$，要么 $|Y_n| > \varepsilon$。第一个包含得证。
>
> 第二个包含同理：若 $X_n > x + \varepsilon$ 且 $|Y_n| \leq \varepsilon$，则 $X_n + Y_n > (x + \varepsilon) - \varepsilon = x$。所以 $X_n + Y_n \leq x$ 时，要么 $X_n \leq x + \varepsilon$，要么 $|Y_n| > \varepsilon$。
>
> 取概率：
> $$P\{X_n \leq x - \varepsilon\} - P\{|Y_n| > \varepsilon\} \;\leq\; P\{X_n + Y_n \leq x\} \;\leq\; P\{X_n \leq x + \varepsilon\} + P\{|Y_n| > \varepsilon\}$$
>
> 令 $n \to \infty$：$P\{X_n \leq x \pm \varepsilon\} \to P\{X \leq x \pm \varepsilon\}$（$X_n \xrightarrow{d} X$，取 $x \pm \varepsilon$ 为 $F_X$ 的连续点），$P\{|Y_n| > \varepsilon\} \to 0$（$Y_n \xrightarrow{P} 0$）。得：
> $$P\{X \leq x - \varepsilon\} \;\leq\; \liminf P\{X_n + Y_n \leq x\} \;\leq\; \limsup P\{X_n + Y_n \leq x\} \;\leq\; P\{X \leq x + \varepsilon\}$$
>
> 令 $\varepsilon \to 0$（沿 $F_X$ 的连续点），对于 $F_X$ 的连续点 $x$，两边夹逼得：
> $$\lim_{n\to\infty} P\{X_n + Y_n \leq x\} = P\{X \leq x\}$$
>
> 即 $X_n + Y_n \xrightarrow{d} X$。
>
> **点评**：(1) 用三角不等式直接套定义，是依概率收敛的基本运算；(2) 用集合包含夹逼 + 收敛到常数的等价，全程不需要 Slutsky 定理（超出本课范围），只用到 C5.1 的知识。$\square$
