## 2/5 判断题

设袋中有4个乒乓球，其中1个涂有白色，1个涂有红色，1个涂有蓝色，1个涂有白、红、蓝三种颜色。今从袋中随机地取一个球，设事件A={取出的球涂有白色}，B={取出的球涂有红色}，C={取出的球涂有蓝色}。则事件A，B，C相互独立。（）

A 对

B 错


> [!hint]- 点击展开提示
> 先计算 $P(A), P(B), P(C)$ 以及两两交的概率。验证两两独立（$P(AB)=P(A)P(B)$ 等），再验证三者是否相互独立（需检查 $P(ABC)=P(A)P(B)P(C)$）。本题的陷阱在于：三色球共享一个三色球，导致两两独立但三联不独立。

> [!solution]- 点击展开详细解析
> **设定**：4 个球：
> - 球 1：仅白色（W）
> - 球 2：仅红色（R）
> - 球 3：仅蓝色（B）
> - 球 4：白、红、蓝三色（WRB）
>
> 等可能取一球，$P(\text{每个球}) = \frac{1}{4}$。
>
> **计算各事件概率**：
> - $A = \{\text{取出的球涂有白色}\} = \{\text{球1, 球4}\}$，$P(A) = \frac{2}{4} = \frac{1}{2}$
> - $B = \{\text{取出的球涂有红色}\} = \{\text{球2, 球4}\}$，$P(B) = \frac{2}{4} = \frac{1}{2}$
> - $C = \{\text{取出的球涂有蓝色}\} = \{\text{球3, 球4}\}$，$P(C) = \frac{2}{4} = \frac{1}{2}$
>
> **验证两两独立**：
> - $AB = \{\text{球4}\}$（同时有白和红），$P(AB) = \frac{1}{4}$
>   $P(A)P(B) = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$ → $P(AB) = P(A)P(B)$ ✓
> - $AC = \{\text{球4}\}$，$P(AC) = \frac{1}{4} = P(A)P(C)$ ✓
> - $BC = \{\text{球4}\}$，$P(BC) = \frac{1}{4} = P(B)P(C)$ ✓
>
> 所以 **A, B, C 两两独立**。
>
> **验证三者相互独立**：
> - $ABC = \{\text{球4}\}$（三色都有），$P(ABC) = \frac{1}{4}$
> - $P(A)P(B)P(C) = \frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}$
>
> $$P(ABC) = \frac{1}{4} \neq \frac{1}{8} = P(A)P(B)P(C)$$
>
> 所以 **A, B, C 不是相互独立的**。
>
> 题中说"事件 A, B, C 相互独立"，这是**错误**的。故选 **B（错）**。
>
> **点评**：这是概率论中经典的"两两独立但不相互独立"的例子（Bernstein 例）。核心在于三色球引入了三者间的正相关性：已知白和红同时出现时，蓝色必然也出现（都是球 4），而独立情况下只应有 $\frac{1}{2}$ 的概率。$\square$
