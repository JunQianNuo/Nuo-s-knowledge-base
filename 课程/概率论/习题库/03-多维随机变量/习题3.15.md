## 3/3 证明/计算/分析题

设二维随机变量 $(X, Y)$ 在 $(1, 0), (0, 1), (-1, 0), (0, -1)$ 四点构成的正方形上服从均匀分布，

（1）求条件概率密度 $f_{Y|X}(y|x)$ ；（2）计算概率 $P\{Y > \frac{1}{2} |X < \frac{1}{2}\}$ 。


> [!hint]- 点击展开提示
> 四点 $(1,0),(0,1),(-1,0),(0,-1)$ 构成以原点为中心、边长为 $\sqrt{2}$ 的正方形（旋转 45 度的菱形），其区域为 $|x|+|y| \le 1$。均匀分布意味着密度在此区域内为常数 $1/2$（面积 $=2$）。求条件密度 $f_{Y|X}(y|x)$ 时，对固定的 $x$，$y$ 的取值范围是 $-(1-|x|) \le y \le 1-|x|$。

> [!solution]- 点击展开详细解析
> 四点连成的正方形区域为：
> $$D = \{(x,y): |x| + |y| \le 1\}$$
>
> $D$ 的面积为 $2$（对角线长 $2$ 的菱形的面积 $= \frac{1}{2}\times 2\times 2 = 2$）。均匀分布意味着联合密度为：
> $$f(x,y) = \begin{cases} \frac{1}{2}, & |x|+|y| \le 1 \\ 0, & \text{其他} \end{cases}$$
>
> **(1) 条件密度 $f_{Y|X}(y|x)$**
>
> 先求 $X$ 的边缘密度。对固定的 $x \in (-1,1)$，$y$ 的范围为 $-(1-|x|) \le y \le 1-|x|$：
> $$f_X(x) = \int_{-(1-|x|)}^{1-|x|} \frac{1}{2}\,dy = \frac{1}{2} \cdot 2(1-|x|) = 1-|x|, \quad |x| \le 1$$
>
> 条件密度：
> $$f_{Y|X}(y|x) = \frac{f(x,y)}{f_X(x)} = \frac{1/2}{1-|x|} = \frac{1}{2(1-|x|)}, \quad |y| \le 1-|x|$$
>
> 即在给定 $X=x$ 条件下，$Y$ 在区间 $[-(1-|x|),\, 1-|x|]$ 上服从均匀分布。
>
> **(2) $P\{Y > \frac{1}{2} \mid X < \frac{1}{2}\}$**
>
> 由条件概率定义：
> $$P\left\{Y > \frac{1}{2} \;\middle|\; X < \frac{1}{2}\right\} = \frac{P\{Y > \frac{1}{2},\; X < \frac{1}{2}\}}{P\{X < \frac{1}{2}\}}$$
>
> 区域 $\{X < \frac{1}{2}\} \cap D$ 的面积：$D$ 的左半部分加上右半三角形中 $x < 1/2$ 的部分。
> 由于 $D$ 关于 $x=0$ 对称，且 $|x|+|y|\le1$，区域 $\{X<1/2\}\cap D$ 是 $D$ 去掉最右边的三角形（$x \ge 1/2$ 部分）。
>
> 更方便的做法：用条件概率公式 $P(A|B)=P(A\cap B)/P(B)$，其中概率等于面积除以总面积。
>
> 先求 $P\{X < \frac{1}{2}\}$：$X < 1/2$ 且 $|x|+|y| \le 1$。
> 对于 $x < 1/2$，需要分两段（$x \le 0$ 和 $0 < x < 1/2$）。
>
> 由于对称性，$P(X<0)=1/2$。在 $0 \le x < 1/2$ 区域，$y$ 范围为 $[-(1-x), 1-x]$，面积：
> $$\int_0^{1/2} 2(1-x)\,dx = 2\left[x - \frac{x^2}{2}\right]_0^{1/2} = 2\left(\frac{1}{2} - \frac{1}{8}\right) = 2 \cdot \frac{3}{8} = \frac{3}{4}$$
>
> 故 $\{X<1/2\}\cap D$ 面积 $= 1 + \frac{3}{4} = \frac{7}{4}$。$P\{X<\frac{1}{2}\} = \frac{7/4}{2} = \frac{7}{8}$。
>
> 再求 $\{Y>1/2, X<1/2\}\cap D$：满足 $y > 1/2$，$x < 1/2$，$|x|+|y| \le 1$。
> 由 $|x|+|y| \le 1$ 且 $y > 1/2$，得 $|x| \le 1-y$，即 $-(1-y) \le x \le 1-y$。
> 再加上 $x < 1/2$，只需在 $y \in (1/2, 1)$ 上对 $x$ 积分。
>
> 面积：
> $$\begin{aligned}
> \int_{1/2}^{1} \int_{\max(-(1-y),\, -1)}^{\min(1-y,\, 1/2)} 1\,dx\,dy
> \end{aligned}$$
>
> 由于 $y > 1/2$ 时 $1-y < 1/2$，故在 $x \le 1-y$ 条件下 $x<1/2$ 自然满足。下限 $-(1-y)$ 且 $(1-y) < 1/2 < 1$，$-(1-y) > -1/2$。被积区域为 $-(1-y) \le x \le 1-y$。
>
> $$\text{面积} = \int_{1/2}^{1} 2(1-y)\,dy = 2\left[y - \frac{y^2}{2}\right]_{1/2}^{1} = 2\left[(1-1/2) - (1/2 - 1/8)\right] = 2\left[\frac{1}{2} - \frac{3}{8}\right] = 2\cdot\frac{1}{8} = \frac{1}{4}$$
>
> 故 $P\{Y>1/2, X<1/2\} = \frac{1/4}{2} = \frac{1}{8}$。
>
> 因此：
> $$P\left\{Y > \frac{1}{2} \;\middle|\; X < \frac{1}{2}\right\} = \frac{1/8}{7/8} = \frac{1}{7}$$
>
> **点评**：在菱形（旋转正方形）上均匀分布的问题，关键是准确刻画区域。条件密度推导需注意对固定的 $x$，$y$ 的取值范围对称但长度依赖于 $|x|$。条件概率直接化为面积比计算更为直观。
> $\square$
