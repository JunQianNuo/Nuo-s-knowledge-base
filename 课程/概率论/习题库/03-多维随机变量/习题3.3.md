## 3/5 单选题

设二维随机变量 $(X,Y)$ 的联合分布函数为 $F(x,y)$ 。以下哪个说法是错误的？

A $F(x,y)$ 是关于 x 和 y 的非减函数

> [!hint]- 点击展开提示
> 联合分布函数 $F(x,y)=P(X\le x, Y\le y)$ 具有四条基本性质：对每个变量单调不减、右连续性、边界极限性质、区域概率非负性。选项 A 说的"非减函数"正是单调不减性质，该性质成立。逐一核查每条性质即可找出错误说法。

> [!solution]- 点击展开详细解析
> 二维联合分布函数 $F(x,y)=P(X\le x, Y\le y)$ 的基本性质：
>
> 1. **单调不减**：$F(x,y)$ 关于 $x$ 和 $y$ 分别是不减的。即对任意固定的 $y$，当 $x_1 < x_2$ 时 $F(x_1,y) \le F(x_2,y)$；对 $y$ 同理。**选项 A 正确。**
>
> 2. **有界性与极限**：$0 \le F(x,y) \le 1$，且 $F(-\infty, -\infty)=0$，$F(+\infty, +\infty)=1$。
>
> 3. **右连续性**：$F(x,y)$ 关于 $x$ 和 $y$ 分别右连续。
>
> 4. **矩形概率非负**：对任意 $x_1 < x_2, y_1 < y_2$，有 $P(x_1 < X \le x_2, y_1 < Y \le y_2) = F(x_2,y_2) - F(x_2,y_1) - F(x_1,y_2) + F(x_1,y_1) \ge 0$。
>
> 选项 A 所述 "$F(x,y)$ 是关于 $x$ 和 $y$ 的非减函数" 是联合分布函数的基本性质之一，表述正确。原题四个选项中真正的错误说法需对照完整选项判断（常见错误如"$F$ 是左连续的"、"$F$ 取值于 $[-1,1]$"、"矩形概率不要求非负"等）。
>
> **点评**：对比一维分布函数，二维分布函数多了一条关键性质——矩形概率非负性，这是保证概率测度定义自洽的必要条件。
> $\square$
