## 1/5 单选题

一射手进行射击, 击中目标的概率为 $p$ , 射击击中目标 2 次为止, 设 $X$ 表示首次击中目标所进行的射击次数, $Y$ 表示总共进行的射击次数, 则 $X$ 和 $Y$ 的联合分布率为 ( ).

A $P\{X = m, Y = n\} = p^2 q^{n-2}, n = 2, 3, \ldots; m = 1, 2, \ldots, n - 1$ B $P\{X = m, Y = n\} = C_n^m p^m q^{n-m}, n = 2, 3, \ldots; m = 1, 2, \ldots, n - 1$ C $P\{X = m, Y = n\} = C_n^2 p^2 q^{n-2}, n = 2, 3, \ldots m = 1, 2 \ldots$ D $P\{X = m, Y = n\} = C_m^2 p^2 q^{n-2}, n = 2, 3 \ldots m = 1, 2 \ldots n - 1$

> [!hint]- 点击展开提示
> 设每次射击命中概率为 $p$，未中概率 $q=1-p$。固定 $m,n$，事件 $\{X=m,Y=n\}$ 表示第 $m$ 次首中、第 $n$ 次第二次命中。除了第 $m$ 和第 $n$ 次必定命中外，其余 $n-2$ 次均为未中。写出概率表达式，注意取值范围。

> [!solution]- 点击展开详细解析
> **答案：A**
>
> **推导**：设 $q=1-p$。事件 $\{X=m,Y=n\}$ 表示在第 $m$ 次射击首次击中，在第 $n$ 次射击第二次击中（即射击停止）。这意味着：
> - 第 $m$ 次：命中
> - 第 $n$ 次：命中
> - 其余 $n-2$ 次：均未命中
>
> 各次射击相互独立，故概率为：
> $$P\{X=m,Y=n\}=p^2 q^{n-2},\quad n=2,3,\ldots;\; m=1,2,\ldots,n-1$$
>
> 注意 $m<n$，且 $n \ge 2$（至少需要两次射击才能两次命中）。故选 **A**。
>
> **点评**：本题关键是指定次序的 $n$ 次伯努利试验中有两个命中（位置固定为 $m$ 和 $n$），而非从 $n$ 次中任选 2 次，因此不含组合数。
> $\square$
