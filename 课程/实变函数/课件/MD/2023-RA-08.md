## 关于度量空间的一些话题

：空间（由某种特定类型的对象全体所构成的集合）

例如：由所有 维向量构成的线性空间 $\mathbb { R } ^ { n }$ ，

由所有 $n \times n$ 的矩阵构成的矩阵空间等

距离函数: $d ( x , y ) : X \times X \to \mathbb { R }$ .For all $x , y , z \in X$ ，we have

（1）正定性： $d ( x , y ) \geq 0 ; \quad d ( x , y ) = 0 \Leftrightarrow x = y$  
（2）对称性： $d ( x , y ) = d ( y , x )$  
（3）三角不等式： $d ( x , y ) \leq d ( x , z ) + d ( y , z )$

$( X , d )$ ：度量空间

## 是否为开集依赖于选取的度量

例. 5 $\{ 1 \} \subset \mathbb { R }$

在度量空间 $\left( \mathbb { R } , d _ { l ^ { 2 } } \right)$ 中不是开集，但在度量空间 $( \mathbb { R } , d _ { \mathrm { d i s c } } )$ 是开集。

$$
B _ {d _ {l ^ {2}}} (1, \epsilon) = \{x \mid | x - 1 | <   \epsilon \} \not \subseteq \{1 \}.
$$

$$
B _ {d _ {\mathrm{disc}}} (1, \frac {1}{2}) = \{x \mid \operatorname{disc} (1, x) <   \frac {1}{2} \} = \{1 \}.
$$

## 是否为开集也依赖于环绕空间

例. $6 X = \{ ( x , 0 ) \mid x \in \mathbb { R } \} \subset \mathbb { R } ^ { 2 }$

$$
E = \{(x, 0) \mid x \in (- 1, 1) \} \subset X.
$$

在(相对于)度量空间 $\left( \mathbb { R } ^ { 2 } , d _ { l ^ { 2 } } \right)$ 不是开集，

但在度量空间 $( X , d _ { l ^ { 2 } } )$ 是开集。

度量空间 是完备的，当且仅当 中的每一个柯西列在中都是收敛的。

是闭集。

例. 7 $( \mathbb { Q } ^ { n } , d _ { l ^ { 2 } } )$ 不是完备的

$( \mathbb { R } ^ { n } , d _ { l ^ { 2 } } )$ 是完备的

度量空间 是紧（致）的，当且仅当 中的每一个序列都有收敛子列。

是一个紧集。 。

在度量空间中这两个定义等价。在拓扑空间中则未必。
