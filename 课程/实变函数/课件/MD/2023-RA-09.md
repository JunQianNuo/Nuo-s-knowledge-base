## 关于自然数，整数，有理数和实数的一些话题

构造自然数集合集需要：增量运算++和皮亚诺公理

公理1 0是一个自然数。

公理2 如果n是一个自然数，那么n++也是一个自然数。

## 引入记号：

$$
1 := 0 + +, 2 := (0 + +) + +, 3 := ((0 + +) + +) + +, \dots
$$

$$
(I := 0 + +, I I := (0 + +) + +, I I I := ((0 + +) + +) + +, \dots)
$$

现在你可以证明3是一个自然数！

公理3 0不紧跟在任何自然数之后。（防止绕回0） 现在你可以证明4不等0！

公理4 m和n两个不同的自然数，则有 $m + + \neq n + +$

(1)防止绕回之前的某个自然数（2）防止有“天花板”

现在你可以证明6不等3！

但是你会发现集合 $N = \{ 0 , 0 . 5 , 1 , 1 . 5 , 2 , 2 . 5 , \cdot \cdot \cdot \}$ 也满足公理1-4.

公理5（数学归纳法原理）令 $\mathsf { P } ( \mathsf { n } )$ 表示自然数n的任意一个性质，如果 ${ \sf P } ( { \bf 0 } )$ 为真且 ${ \bf P } ( { \bf n } )$ 为真时必有 ${ \mathbb { P } } ( { \mathsf { n } } + 1 )$ 为真，那么对所有的n有 $\mathsf { P } ( \mathsf { n } )$ 为真。

## 由增量运算可定义（自然数的） 加法+

递归的定义方式

对 $m \in \mathbb { N }$ 定义 $0 + m : = m$

归纳的假设已定义 $n + m$ ，那么我们定义 $( n + + ) + m : = ( n + m ) + + .$

## 由加法可引入序的概念

$$
\begin{array}{l} n, m \in \mathbb {N}, n \geq m \quad (\text {or} m \leq n) \xleftrightarrow [ ] {d e f} \exists a \in \mathbb {N} \text {s.t.} n = m + a. \\ n, m \in \mathbb {N}, n > m \quad (\text {or} m <   n) \stackrel {{d e f}} {{\Longleftrightarrow}} n \geq m, n \neq m. \\ \end{array}
$$

## 由加法可定义乘法

对 $m \in \mathbb { N }$ 定义 $0 \times m : = 0 .$

归纳的假设已定义 $n \times m$ ，那么我们定义 $( n + + ) \times m = ( n \times m ) + m .$

## 由乘法可定义指数

对 $m \in \mathbb { N }$ 定义 $m ^ { 0 } = 1 . \quad ( 0 ^ { 0 } : = 1 )$

归纳的假设已定义 $m ^ { n }$ ，那么我们定义 $m ^ { n + + } : = m ^ { n } \times m .$

## 利用自然数集合定义整数集合

用两个自然数去定义一个整数

$$
m, n \in \mathbb {N}
$$

$$
m - n
$$

这样定义要满足：

$$
m - n = a - b \Leftrightarrow m + b = a + n.
$$

然后我们可以定义整数的加法，乘法，负数，绝对值，减法等。

## 利用整数集合定义有理数集合

用两个整数去定义一个有理数

$$
a, b \in \mathbb {Z}, (b \neq 0)
$$

$$
a / / b
$$

这样定义要满足：

$$
a / / b = c / / d \Leftrightarrow a d = c b
$$

然后我们可以定义有理数的加法，乘法，减法，除法，倒数等。

## 有理数集合是有 “间隙” 的

Ex. 1 $x ^ { 2 } = 2$ 的解不是有理数。

假设解 $x = { \sqrt { 2 } } .$ 是有理数。 $x = p / q p , q$ 互质。

$$
\begin{array}{l} x ^ {2} = 2 = p ^ {2} / q ^ {2} \Rightarrow p ^ {2} = 2 q ^ {2} \Rightarrow p = 2 k \\ \Rightarrow 4 k ^ {2} = 2 q ^ {2} \Rightarrow q ^ {2} = 2 k ^ {2} \Rightarrow q = 2 k ^ {\prime} \qquad p, q \text {都是偶数，矛盾。} \\ \end{array}
$$

怎么计算 $\sqrt { 2 }$

$$
x ^ {2} - 2 = 0
$$

## 利用有理数集合定义实数集合

用有理数柯西列去定义一个实数

$$
x \in \mathrm{R} \stackrel {d e f} {\Leftrightarrow} \exists \{a _ {n} \} \subset \mathbb {Q}: \text {柯西列}
$$

$$
x = \lim _ {n \to \infty} a _ {n}
$$

$$
\mathbb {R} = \mathbb {Q} ^ {\prime}
$$

实数的运算也用极限定义，例如：

$$
x = \lim a _ {n}, y = \lim b _ {n},
$$

$$
x + y := \lim (a _ {n} + b _ {n})
$$
