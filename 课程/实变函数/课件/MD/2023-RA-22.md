## Fubini定理的应用

卷积 设 和 是 上的可测函数，若积分

$$
\int_ {\mathbb {R} ^ {n}} f (x - y) g (y) d y
$$

存在，则称该积分为 和 的卷积，并记为 $f * g ( x )$ 。于是有

$$
f * g (x) = \int_ {\mathbb {R} ^ {n}} f (x - y) g (y) d y.
$$

卷积的交换性 （通过平移变换 可得）：

$$
f * g (x) = \int_ {\mathbb {R} ^ {n}} f (x - y) g (y) d y = \int_ {\mathbb {R} ^ {n}} f (z) g (x - z) d z = g * f (x).
$$

注： 是 $\mathbb { R } ^ { n } \times \mathbb { R } ^ { n }$ 上的可测函数。

定理3.3.7 设 $f , g \in L ( \mathbb { R } ^ { n } )$ 则卷积 $f * g ( x )$ 对几乎处处的 $x \in \mathbb { R } ^ { n }$ 存在 ,

$$
f * g \in L (\mathbb {R} ^ {n}) \text {且}
$$

可积函数的卷积也可积

$$
\int_ {\mathbb {R} ^ {n}} | f * g (x) | d x \leq \int_ {\mathbb {R} ^ {n}} | f (x) | d x \int_ {\mathbb {R} ^ {n}} | g (x) | d x.
$$

证明首先考虑 和 是非负可测函数的情形。因为 是 $\mathbb { R } ^ { n } \times \mathbb { R } ^ { n }$ 上的非负可测函数，由Tonelli定理得

$$
\int_ {\mathbb {R} ^ {n}} d x \int_ {\mathbb {R} ^ {n}} f (x - t) g (t) d t = \int_ {\mathbb {R} ^ {n}} d t \int_ {\mathbb {R} ^ {n}} f (x - t) g (t) d x
$$

$$
= \int_ {\mathbb {R} ^ {n}} g (t) d t \int_ {\mathbb {R} ^ {n}} f (x - t) d x = \int_ {\mathbb {R} ^ {n}} g (t) d t \int_ {\mathbb {R} ^ {n}} f (x) d x <   \infty .
$$

所以 $| f * g | < \infty \ \mathrm { a . e . }$ 且 $\int _ { \mathbb { R } ^ { n } } f \ast g ( x ) d x = \int _ { \mathbb { R } ^ { n } } g ( t ) d t \int _ { \mathbb { R } ^ { n } } f ( x ) d x .$

对于 和 是一般的可测函数的情形，注意到 $| f * g | \leq | f | * | g |$

从而有 $\int _ { \mathbb { R } ^ { n } } | f * g | d x \leq \int _ { \mathbb { R } ^ { n } } | f | * | g | d x = \int _ { \mathbb { R } ^ { n } } | g | d t \int _ { \mathbb { R } ^ { n } } | f | d x < \infty .$

定理3.3.7 给定 $E \in \mathfrak { M } _ { n } , f ( x )$ 是 上的非负实值函数。

（1）若 可测，则 $\Gamma _ { E } ( f ) , \underline { { G } } ( f ) \in \mathfrak { M } _ { n + 1 }$

$$
m (\Gamma_ {E} (f)) = 0, \quad m (\underline {{G}} (f)) = \int_ {E} f (x) d x.
$$

（2）若 $\underline { { G } } ( f ) \in \mathfrak { M } _ { n + 1 }$ 则 $f ( x )$ 可测，且 $m ( \underline { G } ( f ) ) = \int _ { E } f ( x ) d x$

证明 （1）首先证明 $m ( \Gamma _ { E } ( f ) ) = 0$ 不妨设 $m ( E ) < \infty$

对任意的 $\delta > 0$ 令 $E _ { k } = \{ x \in E \mid k \delta \leq f ( x ) < ( k + 1 ) \delta \} , \ k = 0 , 1 , 2 , \cdot \cdot \cdot$ 则有

$$
\Gamma_ {E} (f) = \bigcup_ {k = 0} ^ {\infty} \Gamma_ {E _ {k}} (f), \quad m ^ {*} (\Gamma_ {E} (f)) \leq \sum_ {k = 0} ^ {\infty} m ^ {*} (\Gamma_ {E _ {k}} (f)) \leq \delta m (E _ {k}) = \delta m (E).
$$

$\widehat { \vec { \mathrm { \scriptsize { v } } } } \delta \to 0$ 得 $m ( \Gamma _ { E } ( f ) ) = 0$

其次证明 $\underline { { G } } ( f ) \in \mathfrak { M } _ { n + 1 }$ 以及 $m ( { \underline { { G } } } ( f ) ) = \int _ { E } f ( x ) d x$

若 是一个可测集上的特征函数，结论显然成立。

从而对非负可测简单函数也成立。

对于一般的可测函数 存在非负可测简单函数的上升列 $\vert \phi _ { k } ( x ) \}$ 收敛于 。

易知 $\underline { { G } } ( \phi _ { k } ) \subset \underline { { G } } ( \phi _ { k + 1 } ) , \quad \Gamma _ { E } ( f ) \cup \bigcup _ { k \geq 1 } \underline { { G } } ( \phi _ { k } ) = \underline { { G } } ( f ) .$

由于 $m ( \Gamma _ { E } ( f ) ) = 0$ 所以 $\underline { { G } } ( f ) \in \mathfrak { M } _ { n + 1 }$ 且

$$
m (\underline {{G}} (f)) = \lim _ {k \to \infty} m (\underline {{G}} (\phi_ {k})) = \lim _ {k \to \infty} \int_ {E} \phi_ {k} (x) d x = \int_ {E} f (x) d x.
$$
