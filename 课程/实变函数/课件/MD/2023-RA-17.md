## 黎曼积分和Lebesgue积分的关系

黎曼可积的有界函数也是Lebesgue可积的，且积分值相同。

定理3.1.15 是闭区间 $I = [ a , b ]$ 上的有界函数。

若 在 上黎曼可积，则 在 上也是Lebesgue可积的，且

$$
\int_ {I} f (x) d x = \int_ {a} ^ {b} f (x) d x.
$$

此处 $\int _ { a } ^ { b } f ( x ) d x$ 表示黎曼积分， $\int _ { I } f ( x ) \ d x$ 表示Lebesgue积分。

证明 因为 $f$ 在区间 上有界，只要证明 $f$ 可测，就有 $f \in L ( E )$

考虑 上的一列划分 $\{ \Delta _ { n } \}$

$$
\Delta_ {n}: a = x _ {0} ^ {(n)} <   x _ {1} ^ {(n)} <   \dots x _ {i _ {n}} ^ {(n)} = b,
$$

$$
\Delta_ {n} \subset \Delta_ {n + 1}, \quad | \Delta_ {n} | = \max _ {1 \leq i \leq i _ {n}} \{x _ {i} ^ {(n)} - x _ {i - 1} ^ {(n)} \} \to 0,
$$

$$
M _ {i} ^ {(n)} = \sup \{f (x) \mid x _ {i - 1} ^ {(n)} \leq x \leq x _ {i} ^ {(n)} \}, m _ {i} ^ {(n)} = \inf \{f (x) \mid x _ {i - 1} ^ {(n)} \leq x \leq x _ {i} ^ {(n)} \}.
$$

由于 在 上黎曼可积，由黎曼积分的定义知

$$
\lim _ {n \to \infty} \sum_ {i = 1} ^ {i _ {n}} m _ {i} ^ {(n)} (x _ {i} ^ {(n)} - x _ {i - 1} ^ {(n)}) = \lim _ {n \to \infty} \sum_ {i = 1} ^ {i _ {n}} M _ {i} ^ {(n)} (x _ {i} ^ {(n)} - x _ {i - 1} ^ {(n)}) = \int_ {a} ^ {b} f d x.
$$

定义以下两个函数列：

$$
\phi_ {n} (x) = \left\{ \begin{array}{l l} m _ {i} ^ {(n)}, & x \in (x _ {i - 1} ^ {(n)}, x _ {i} ^ {(n)} ], \\ f (a), & x = a, \end{array} \right. \psi_ {n} (x) = \left\{ \begin{array}{l l} M _ {i} ^ {(n)}, & x \in (x _ {i - 1} ^ {(n)}, x _ {i} ^ {(n)} ], \\ f (a), & x = a, \end{array} \right.
$$

因为 $\Delta _ { n } \subset \Delta _ { n + 1 }$ 当区间缩小时，上确界不增，下确界不减，故有

$$
\psi_ {1} \geq \psi_ {2} \geq \dots \geq \psi_ {n} \geq \dots \geq f,
$$

$$
\phi_ {1} \leq \phi_ {2} \leq \dots \leq \phi_ {n} \leq \dots \leq f.
$$

于是

$$
\lim _ {n \to \infty} \psi_ {n} =: \overline {{f}} \geq f, \quad \lim _ {n \to \infty} \phi_ {n} =: \underline {{f}} \leq f.
$$

即得

$$
\overline {{f}} \geq f \geq \underline {{f}}.
$$

极限函数 ${ \overline { { f } } } , \underline { { f } }$ 都是有界可测的，故它们都是Lebesgue可积的，且 ${ \overline { { f } } } - f$ 是非负可测函数，故有

$$
\int_ {I} (\overline {{f}} - \underline {{f}}) d x \geq 0
$$

又由

$$
\int_ {I} \underline {{{{f}}}} d x \geq \int_ {I} \phi_ {n} d x = \int_ {a} ^ {b} \phi_ {n} d x = \sum_ {i = 1} ^ {i _ {n}} m _ {i} (x _ {i} ^ {(n)} - x _ {i - 1} ^ {(n)}) \rightarrow \int_ {a} ^ {b} f d x.
$$

$$
\int_ {I} \overline {{f}} d x \leq \int_ {I} \psi_ {n} d x = \int_ {a} ^ {b} \psi_ {n} d x = \sum_ {i = 1} ^ {i _ {n}} M _ {i} (x _ {i} ^ {(n)} - x _ {i - 1} ^ {(n)}) \to \int_ {a} ^ {b} f d x.
$$

可得

$$
\int_ {I} \overline {{f}} d x \leq \int_ {a} ^ {b} f d x \leq \int_ {I} \underline {{f}} d x.
$$

所以 $\int _ { I } { \overline { { f } } } d x = \int _ { I } { \underline { { f } } } d x$ 即 $\int _ { I } ( { \overline { { f } } } - \underline { { f } } ) \ d x = 0 .$

由定理3.1.6知 ${ \overline { { f } } } - \underline { { f } } = 0 { \mathrm { a . e . } }$ 从而 $\overline { { f } } = f = \underline { { f } } \mathrm { ~ a . e . ~ } [ I ]$

因此 $f$ 在 $I$ 可测，且 $f$ 的Lebesgue积分等于黎曼积分。

般情形下，黎曼可积的函数总是Lebesgue可积的，且积分值一样，但反之则不成立。

## 测度空间上的可测函数的积分

## 非负可测简单函数的积分

定义3.1.16 给定 $( X , { \mathcal { F } } , \mu )$ 上的非负 $\mu$ 可测简单函数

$$
h (x) = \sum_ {j = 1} ^ {m} a _ {j} \chi_ {A _ {j}} (x) \quad (\forall x \in X), \qquad 0 \leq a _ {1}, a _ {2}, \dots , a _ {m} \in \mathbb {R},
$$

$A _ { 1 } , A _ { 2 } , \cdots , A _ { m }$ 是互不相交的可测集。

定义 $h$ 在 $X$ 上的关于测度 $\mu$ 的积分为 $\int _ { X } h ( x ) \ \mu ( d x ) = \sum _ { j = 1 } ^ { m } a _ { j } \mu ( A _ { j } )$

记由非负 $\mu$ 可测简单函数全体组成的空间为 $S ^ { + } ( X )$

定义 $I : S ^ { + } ( X ) \to \mathbb { R } \cup \{ \infty \} , \quad I ( h ) = \int _ { X } h ( x ) \mu ( d x ) .$

易见映射 是 $S ^ { + } ( X )$ 上的可加泛函，即有

$$
I (h _ {1} + h _ {2}) = I (h _ {1}) + I (h _ {2}) \quad (\forall h _ {1}, h _ {2} \in S ^ {+} (X)),
$$

并且 $I ( a h ) = a I ( h ) \quad ( \forall a \in \mathbb { R } ^ { + } )$

## 非负可测函数的积分

定义3.1.17 设 $f ( x )$ 是 上的非负 $\mu$ 可测函数，定义 $f$ 在 上的积分为

$$
\int_ {X} f \mu (d x) = \sup \left\{\int_ {X} h (x) \mu (d x) \mid h \in S ^ {+} (X), h \leq f \right\}.
$$

这里的积分可以是 ；若 $\int _ { X } f ( x ) \mu ( d x ) < \infty ,$

则称 $f$ 在 上是 $\mu$ 可积的。全体非负 $\mu$ 可积函数的集合记作 $L ^ { + } ( X )$ ：

上一讲的非负Lebesgue可积函数的性质可以推广至非负 可积函数。

定义3.1.18 设 若 和 中至少有一个是 可积的，则称

$$
\int_ {X} f (x) \mu (d x) = \int_ {X} f ^ {+} (x) \mu (d x) - \int_ {X} f ^ {-} (x) \mu (d x)
$$

为 在 上的积分。若上式右端有限，则称 $f$ 在 上 可积。在 上可积的函数全体记作 $L ( X , { \mathcal { F } } , \mu )$ ,或L（X).

上一讲的Lebesgue可积函数的性质可以推广至 可积函数。
