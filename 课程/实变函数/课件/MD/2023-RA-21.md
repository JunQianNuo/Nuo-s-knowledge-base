## 定理3.3.5 (Tonelli定理) 记 $n = p + q$ ，设 $f ( x , y )$ 是 $\mathbb { R } ^ { p + q } = \mathbb { R } ^ { n }$

上的非负可测函数，则

（1）对于几乎处处的 $x \in \mathbb { R } ^ { p } , f ( x , \cdot )$ 是 $\mathbb { R } ^ { q }$ 上的非负可测函数；  
（2） $F _ { f } ( x ) = \int _ { \mathbb { R } ^ { q } } f ( x , y )$ 在 $\mathbb { R } ^ { p }$ 上几乎处处有定义，是 $\mathbb { R } ^ { p }$ 上的非负可测函数；  
（3）重积分与累次积分相等：

$$
\int_ {\mathbb {R} ^ {p + q}} f (x, y) d x d y = \int_ {\mathbb {R} ^ {p}} F _ {f} (x) d x = \int_ {\mathbb {R} ^ {p}} d x \int_ {\mathbb {R} ^ {q}} f (x, y) d y. \left(= \int_ {\mathbb {R} ^ {q}} d y \int_ {\mathbb {R} ^ {p}} f (x, y) d x\right)
$$

证明 由定理3.3.2知，对于任何可测集 $E \in \mathfrak { M } _ { n }$ ，特征函数 $\chi _ { E } ( x )$ 满足该定理的(1)(2)(3)，因此非负可测简单函数也满足该定理的(1)(2)(3)。对于某个非负可测函数，可视其为某个非负可测简单函数的上升列的极限，由Levi定理可知，该非负可测函数也满足定理的(1)(2)(3)。

取Tonelli定理中的非负可测函数为可测集的特征函数，易知Tonelli定理与定理3.3.2等价。

## 定理3.3.5 (Fubini定理) 若 $f \in L ( \mathbb { R } ^ { n } ) , \mathbb { R } ^ { n } = \mathbb { R } ^ { p } \times \mathbb { R } ^ { q }$ 则

（1）对于几乎处处的 $x \in \mathbb { R } ^ { p } , f ( x , \cdot )$ 是 $\mathbb { R } ^ { q }$ 上的非负可测函数；  
（2） $F _ { f } ( x ) = \int _ { \mathbb { R } ^ { q } } f ( x , y ) d y$ 在 $\mathbb { R } ^ { p }$ 上几乎处处有定义，是 $\mathbb { R } ^ { p }$ 上的非负可测函数；JRq  
（3）重积分与累次积分相等：

$$
\int_ {\mathbb {R} ^ {p + q}} f (x, y) d x d y = \int_ {\mathbb {R} ^ {p}} d x \int_ {\mathbb {R} ^ {q}} f (x, y) d y = \int_ {\mathbb {R} ^ {q}} d y \int_ {\mathbb {R} ^ {p}} f (x, y) d x.
$$

证明 令 $f ( x , y ) = f ^ { + } ( x , y ) - f ^ { - } ( x , y )$ 由Tonelli定理可知，非负可测函数$f ^ { + } ( x , y ) , f ^ { - } ( x , y )$ 满足该定理中的(1)(2)(3)，并且积分都是有限的，可相减。所以 $f ( x , y )$ 也满足该定理的(1)(2)(3)。
