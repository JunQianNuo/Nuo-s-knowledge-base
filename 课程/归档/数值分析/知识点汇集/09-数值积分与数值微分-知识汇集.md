# 第九章 数值积分与数值微分 — 知识点汇集

## 一、本章核心脉络

核心问题：当被积函数无解析原函数（如 $e^{-x^2}$、$\frac{\sin x}{x}$）或仅以表格形式给出时，如何近似计算定积分。从Newton-Cotes到复化求积、Romberg外推、Gauss求积，逐步提高精度和效率。

```mermaid
flowchart TD
    A[数值积分 ∫_a^b f(x)dx] --> B[求积公式: Σ A_k f(x_k)]
    B --> C{等距节点?}
    C -->|是| D[Newton-Cotes公式]
    D --> D1[梯形公式 n=1]
    D --> D2[辛普生公式 n=2]
    D --> D3[n≥3 Newton-Cotes]
    C -->|否| E[Gauss求积: 最高代数精度 2n+1]
    E --> E1[Gauss-Legendre: [-1,1], ρ=1]
    E --> E2[Gauss-Laguerre: [0,∞), ρ=e^{-x}]
    E --> E3[Gauss-Hermite: (-∞,∞), ρ=e^{-x²}]
    D1 & D2 & D3 --> F{精度不足?}
    F -->|小区间细分| G[复化求积]
    G --> G1[复化梯形: T_n]
    G --> G2[复化辛普生: S_{2m}]
    G2 --> H[Romberg外推: T→S→C→R]
```

## 二、基础定义

| 术语 | 符号/表述 | 含义 |
|:--|:--|:--|
| 求积公式 | $\int_a^b f(x) dx \approx \sum_{k=0}^n A_k f(x_k)$ | 用节点函数值的加权和近似积分 |
| 求积系数 | $A_k$ | 与 $f(x)$ 无关，取决于节点和公式 |
| 余项 | $R[f] = \int_a^b f(x) dx - \sum A_k f(x_k)$ | 求积公式的截断误差 |
| 代数精度 | $m$ | 对不超过 $m$ 次的多项式精确成立（$R \equiv 0$） |
| 内插求积公式 | $A_k = \int_a^b l_k(x) dx$ | 对 $f$ 做插值再积分的求积方法 |
| Newton-Cotes系数 | $C_k^{(n)}$ | 等距节点的内插求积系数，与 $f$ 和区间无关 |
| 复化求积 | — | 将区间分段，每段用低阶公式，提高精度 |
| Romberg外推 | $T \to S \to C \to R$ | 通过代数运算从慢收敛序列加速得到快收敛序列 |
| Gauss点 | — | 使求积公式代数精度达到 $2n+1$ 的节点 |
| 数值微分 | — | 用离散函数值近似导数 |

## 三、核心方法/定理

### 3.1 求积公式基础

**定义**（公式 (8.1)）：$\int_a^b f(x) dx \approx \sum_{k=0}^n A_k f(x_k)$

**余项**（公式 (8.2)）：$R[f] = \int_a^b f(x) dx - \sum_{k=1}^n A_k f(x_k)$

### 3.2 内插求积公式

由插值知 $f(x) = P_n(x) + R_n(x)$：

$$\int_a^b f(x)dx = \sum_{k=0}^n \left[\int_a^b l_k(x)dx\right] f(x_k) + R_n[f]$$

其中求积系数 $A_k = \int_a^b l_k(x) dx$。

### 3.3 矩形求积公式

**左矩形公式**：$\int_a^b f(x)dx = f(a)(b-a) + \frac{(b-a)^2}{2} f'(\eta)$（零次代数精度）

**右矩形公式**：$\int_a^b f(x)dx = f(b)(b-a) - \frac{(b-a)^2}{2} f'(\eta)$（零次代数精度）

**中矩形公式**：$\int_a^b f(x)dx = f(\frac{a+b}{2})(b-a) + \frac{(b-a)^3}{24} f''(\eta)$（一次代数精度）

### 3.4 Newton-Cotes公式

取等距节点：$h = (b-a)/n$，$x_k = x_0 + kh$（$k=0,1,\ldots,n$）。

求积系数：$A_k = \frac{(-1)^{n-k} h}{(n-k)! k!} \int_0^n t(t-1)\cdots(t-n) / (t-k)\, dt = (b-a) C_k^{(n)}$

其中 $C_k^{(n)}$ 为Newton-Cotes系数，与 $f(x)$ 和积分区间无关，可事先计算。

**余项**：$R_n[f] = \int_a^b \frac{f^{(n+1)}(\xi)}{(n+1)!} \omega(x) dx$

代数精度至少为 $n$；当 $n$ 为偶数时可达 $n+1$。

#### 梯形公式（$n=1$）

$$\int_a^b f(x) dx \approx \frac{b-a}{2}[f(a) + f(b)]$$

余项：$R_1 = -\frac{b-a}{12} h^2 f''(\xi) = -\frac{(b-a)^3}{12} f''(\xi),\; \xi \in (a,b)$

代数精度：1。

#### 辛普生（抛物形）公式（$n=2$）

$$\int_a^b f(x) dx \approx \frac{h}{3}\left[f(a) + 4f(\frac{a+b}{2}) + f(b)\right],\; h = \frac{b-a}{2}$$

也可写作：$\int_a^b f(x) dx \approx \frac{b-a}{6}\left[f(a) + 4f(\frac{a+b}{2}) + f(b)\right]$

余项：$R_2[f] = -\frac{b-a}{180} h^4 f^{(4)}(\xi),\; \xi \in (a,b)$

代数精度：3（对三次及以下多项式精确成立）。

### 3.5 复化求积公式

#### 复化梯形公式

将 $[a,b]$ $n$ 等分，$h = (b-a)/n$，$x_k = a + kh$：

$$T_n = \frac{h}{2}\left[f(a) + f(b) + 2\sum_{k=1}^{n-1} f(x_k)\right]$$

内节点系数为2（参与前后两小区间），端点系数为1。

**逐次对分**：$T_{2n} = \frac{1}{2} T_n + h' \sigma_n$，其中 $h' = h/2$，$\sigma_n$ 为新分点函数值之和。

截断误差：$R[T_n] = -\frac{b-a}{12} h^2 f''(\xi),\; \xi \in (a,b)$（$h = (b-a)/n$）

#### 复化抛物形（辛普生）公式

将区间 $2m$ 等分，$h = (b-a)/(2m)$：

$$S_{2m} = \frac{h}{3}\left[f(a) + f(b) + 2\sum_{k=1}^{m-1} f(x_{2k}) + 4\sum_{k=0}^{m-1} f(x_{2k+1})\right]$$

截断误差：$R[S_{2m}] = -\frac{b-a}{180} h^4 f^{(4)}(\xi)$

### 3.6 Romberg求积（外推加速）

复化梯形公式序列 $\{T_n\}$ 收敛慢。利用误差展开的外推关系：

$$I - T_n = -\frac{b-a}{12} h^2 f''(\xi)$$
$$I - T_{2n} = -\frac{b-a}{12} \cdot \frac{h^2}{4} f''(\eta)$$

设 $f''(\xi) \approx f''(\eta)$，得 $I \approx \frac{4 T_{2n} - T_n}{4 - 1}$。

记 $S_n = \frac{4 T_{2n} - T_n}{4 - 1}$（实际为逐次分半的复化抛物形序列）

同理：

- $C_n = \frac{16 S_{2n} - S_n}{16 - 1}$（逐次分半的复化柯特斯序列）
- $R_n = \frac{64 C_{2n} - C_n}{64 - 1}$（龙贝格序列）

**Romberg三角形数表**：

```
T₁
T₂  S₁
T₄  S₂  C₁
T₈  S₄  C₂  R₁
T₁₆ S₈  C₄  R₂
⋮   ⋮   ⋮   ⋮
```

四个序列都是收敛的，$\{R_n\}$ 收敛最快。

### 3.7 Gauss求积公式

**问题**：在节点数不变的情况下，代数精度最高能达 $2n+1$。

定义：若求积公式的代数精度达到 $2n+1$，则称为**Gauss求积公式**，节点称为**Gauss点**。

截断误差：$R[f] = \frac{f^{(2n+2)}(\xi)}{(2n+2)!} \int_a^b \omega^2(x) dx$

#### 高斯-勒让德（Gauss-Legendre）求积公式

区间 $[-1,1]$，权函数 $\rho(x) \equiv 1$。以Legendre多项式 $P_k(x) = \frac{1}{2^k k!} \frac{d^k}{dx^k}(x^2-1)^k$ 为正交多项式系。Gauss点为 $P_{n+1}(x) = 0$ 的根。

截断误差：$R[f] = \frac{2^{2n+3}}{(2n+3)[(2n+2)!]^2} f^{(2n+2)}(\xi),\; -1 < \xi < 1$

#### 高斯-拉盖尔（Gauss-Laguerre）求积公式

区间 $[0, +\infty)$，权函数 $\rho(x) = e^{-x}$。以Laguerre多项式 $L_k(x) = e^x \frac{d^k}{dx^k}(e^{-x} x^k)$ 为正交多项式系。

截断误差：$R[f, L_n] = \frac{[(n+1)!]^2}{(2n+2)!} f^{(2n+2)}(\xi)$

#### 高斯-埃尔米特（Gauss-Hermite）求积公式

区间 $(-\infty, +\infty)$，权函数 $\rho(x) = e^{-x^2}$。以Hermite多项式 $H_k(x) = (-1)^k e^{x^2} \frac{d^k}{dx^k}(e^{-x^2})$ 为正交多项式系。

截断误差：$R[f, H_n] = \frac{(n+1)! \sqrt{\pi}}{2^{n+1} (2n+2)!} f^{(2n+2)}(\xi)$

### 3.8 各种求积方法特点对比

| 方法 | 特点 | 适用场景 |
|:--|:--|:--|
| 梯形/抛物形 | 低精度，公式简单 | 光滑性较差的被积函数 |
| 复化梯形/抛物形 | 便于逐次对分，程序简单 | 一般定积分 |
| 龙贝格 | 节点加密时前面结果直接参与，减少计算量 | 需高精度、节点成倍增加可行 |
| 高斯型 | 最高代数精度，节点和系数无规则 | 无穷区间上的广义积分 |

### 3.9 数值微分

当函数由表格形式给出时，用插值多项式的导数近似原函数的导数。

#### 两点公式

已知 $y_0 = f(x_0)$，$y_1 = f(x_1)$，$h = x_1 - x_0$：

$$f'(x_0) \approx \frac{1}{h}(y_1 - y_0),\; R = -\frac{f''(\xi_1)}{2} h$$

$$f'(x_1) \approx \frac{1}{h}(y_1 - y_0),\; R = \frac{f''(\xi_2)}{2} h$$

#### 三点公式

已知 $y_0, y_1, y_2$（等距，步长 $h$）：

$$f'(x_0) \approx \frac{1}{2h}(-3y_0 + 4y_1 - y_2),\; R = \frac{f'''(\xi)}{3} h^2$$

$$f'(x_1) \approx \frac{1}{2h}(-y_0 + y_2),\; R = -\frac{f'''(\xi)}{6} h^2$$

$$f'(x_2) \approx \frac{1}{2h}(y_0 - 4y_1 + 3y_2),\; R = \frac{f'''(\xi)}{3} h^2$$

$f'(x_1)$ 的误差最小。

#### 差商近似微商

1. **向前差商**：$f'(x) = \frac{f(x+h) - f(x)}{h} - \frac{h}{2} f''(\xi)$
2. **向后差商**：$f'(x) = \frac{f(x) - f(x-h)}{h} + \frac{h}{2} f''(\xi)$
3. **中心差商**：$f'(x) = \frac{f(x+h) - f(x-h)}{2h} - \frac{h^2}{6} f'''(\xi)$
4. **二阶中心差商**：$f''(x) = \frac{f(x+h) - 2f(x) + f(x-h)}{h^2} - \frac{h^2}{12} f^{(4)}(\xi)$

**注意**：$h$ 不是越小越好——当 $h$ 过小时，相近数相减损失有效数位，舍入误差上升。

## 四、计算/应用

### 4.1 梯形公式计算例（slide 158）

$I = \int_0^1 \frac{4}{1+x^2} dx$：
$$I \approx \frac{1-0}{2}\left[\frac{4}{1+0^2} + \frac{4}{1+1^2}\right] = \frac{1}{2}(4+2) = 3$$

### 4.2 辛普生公式计算例（slide 160）

$$I \approx \frac{h}{3}[f(0) + 4f(0.5) + f(1)] = \frac{1}{6}\left[4 + 4 \cdot \frac{64}{5} + 2\right] = 3.1333$$

### 4.3 复化梯形误差估计例（slide 171）

$I = \int_0^1 \frac{\sin x}{x} dx$，误差限 $10^{-4}$。

由 $f^{(k)}(x) \le \frac{1}{k+1}$，$|R[T_n]| \le \frac{1}{36} h^2 \le 10^{-4}$，得 $n \ge 17$。

## 七、易错点与注意事项

> [!warning]
> - 代数精度是衡量求积公式质量的核心指标——对多项式精确成立就是好公式。
> - $n$ 为偶数时 Newton-Cotes 公式的代数精度可达到 $n+1$（如辛普生 $n=2$，精度为3），这是选择 $n$ 为偶数的原因。
> - 复化梯形公式的逐次对分中，$T_n$ 整体保留，只需计算新分点的函数值，不要重复计算。
> - Romberg外推的 $S_n$、$C_n$、$R_n$ 序列不是直接由积分得到的，而是通过四则运算从 $T_n$ 推算出来的。
> - $n \ge 8$ 的高阶 Newton-Cotes 公式出现负系数，数值不稳定，不推荐使用。
> - Gauss求积的节点和系数没有简单规则，节点增加时前面的计算结果不能被利用，只能重新计算。
> - 数值微分中 $h$ 过小反而导致精度下降（相近数相减丢失有效数字）——舍入误差与截断误差的权衡。
> - 中心差商的截断误差是 $O(h^2)$，比向前/向后差商的 $O(h)$ 精度高。
