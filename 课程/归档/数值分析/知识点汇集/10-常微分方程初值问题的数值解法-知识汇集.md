# 第十章 常微分方程初值问题的数值解法 — 知识点汇集

## 一、本章核心脉络

核心问题：给定一阶常微分方程初值问题 $y' = f(x, y),\; y(x_0) = y_0$，在离散节点 $\{x_i\}$ 上求近似解 $y_i \approx y(x_i)$。从最简单的Euler法到高阶Runge-Kutta法，核心是平衡精度与计算量。

```mermaid
flowchart TD
    A[ODE初值问题: y'=f(x,y), y(x₀)=y₀] --> B{方法分类}
    B --> C[单步法: 只用y_i算y_{i+1}]
    B --> D[多步法: 用y_{i-1},y_{i-2},...]
    C --> E{显式还是隐式?}
    E -->|显式| F[Euler显式: 一阶]
    E -->|显式| G[RK方法: 二阶及以上]
    E -->|隐式| H[Euler隐式: 一阶]
    E -->|隐式| I[梯形公式: 二阶]
    G --> J[二阶RK: 改进Euler / 中点公式]
    D --> K[Euler中点公式: 二步法]
    I --> L[预估校正: Euler预估+梯形校正]
```

## 二、基础定义

| 术语 | 符号/表述 | 含义 |
|:--|:--|:--|
| 单步法 | $y_{i+1}$ 只用 $y_i$ | 计算下一步只需前一点信息 |
| 多步法 | $y_{i+1}$ 用 $y_i, y_{i-1}, \ldots$ | 计算下一步需前面多个点 |
| 显式方法 | 右端不含 $y_{i+1}$ | 可直接计算，计算量小 |
| 隐式方法 | 右端含 $y_{i+1}$ | 需每步解方程，稳定性好 |
| 局部截断误差 | $y(x_{i+1}) - y_{i+1}$（假设 $y_i$ 精确） | 单步计算产生的误差 |
| 阶（r阶方法） | 局部截断误差 $O(h^{r+1})$ | 方法精度的度量 |
| 渐近误差常数 | $C$ | $y(x_{i+1}) - y_{i+1} \approx C h^{r+1}$ 中的常数 |
| 一阶ODEs | $y' = f(x, y),\; y(x_0) = y_0$ | 本章研究对象 |
| 高阶方程降阶 | 二阶ODE $\to$ 一阶ODEs组 | 引入新变量，化为向量形式 |

## 三、核心方法/定理

### 3.1 一阶常微分方程组和高阶方程

一阶常微分方程组常表述为向量形式。高阶常微分方程（如二阶定解问题）可通过引入新变量化作一阶常微分方程组的定解问题。

记 $y(x_{i+1})$ 为准确值，$y_{i+1}$ 为近似值。

**阶的定义**：若任意 $y(x)$ 属于不高于 $r$ 次多项式的集合，计算公式均能准确成立，但至少有一个 $r+1$ 次多项式不能准确成立，则称计算公式是 $r$ 阶的。

### 3.2 Euler方法的推导

将区间 $[a,b]$ 分为 $n$ 个小区间，步长 $h = (b-a)/n$，节点 $x_i = x_0 + ih$（$i = 0,1,\ldots,n$），$x_0 = a$。

**方法一**：积分推导。对 $y' = f(x, y)$ 两端在 $[x_i, x_{i+1}]$ 上积分：

$$\int_{x_i}^{x_{i+1}} y'(x) dx = \int_{x_i}^{x_{i+1}} f(x, y(x)) dx$$

对右端用**左矩形公式**，得Euler公式：

$$y_{i+1} = y_i + h f(x_i, y_i)$$

**方法二**：Taylor展开。设 $y(x)$ 二阶连续可导：

$$y(x_{i+1}) = y(x_i) + h y'(x_i) + \frac{h^2}{2} y''(\xi)$$

舍去 $h^2$ 项，并令 $y_i = y(x_i)$，注意到 $y'(x_i) = f(x_i, y_i)$，同样得Euler公式。

### 3.3 Euler隐式公式与Euler中点公式

**Euler隐式公式**：对积分右端用**右矩形公式**代替：

$$y_{i+1} = y_i + h f(x_{i+1}, y_{i+1})$$

因两端都含 $y_{i+1}$，需解方程，故称为隐式公式。属于单步法。

**Euler中点公式**：将积分区间改为 $[x_{i-1}, x_{i+1}]$，对右端用**中矩形公式**：

$$y_{i+1} = y_{i-1} + 2h f(x_i, y_i)$$

计算 $y_{i+1}$ 时需 $y_i$ 和 $y_{i-1}$ 的值，属**多步法（二步法）**。

### 3.4 方法分类总结

| 公式 | 显/隐 | 单/多步 |
|:--|:--|:--|
| Euler显式 $y_{i+1} = y_i + h f(x_i, y_i)$ | 显式 | 单步法 |
| Euler隐式 $y_{i+1} = y_i + h f(x_{i+1}, y_{i+1})$ | 隐式 | 单步法 |
| Euler中点 $y_{i+1} = y_{i-1} + 2h f(x_i, y_i)$ | 显式 | 多步法（二步法） |

### 3.5 局部截断误差与方法的阶

设 $y_i$、$y_{i-1}$ 的值没有误差，用公式计算 $y_{i+1}$ 时产生的误差称为**局部截断误差**。

- **Euler显式**：局部截断误差为 $O(h^2)$，是一阶方法。
- **Euler隐式**：局部截断误差为 $O(h^2)$，是一阶方法。
- **Euler中点公式**：局部截断误差为 $O(h^3)$，是二阶方法。

通常高阶方法比低阶方法精确。

### 3.6 梯形公式及其预估校正法

对积分右端用**梯形积分公式**近似代替：

$$y_{i+1} = y_i + \frac{h}{2}[f(x_i, y_i) + f(x_{i+1}, y_{i+1})]$$

是**单步隐式方法**，**二阶方法**。

一般求 $y_{i+1}$ 需解方程，常用迭代法。初值 $y_{i+1}^{(0)}$ 由Euler公式给出：

$$\begin{cases}
y_{i+1}^{(0)} = y_i + h f(x_i, y_i) & \text{（预估）} \\
y_{i+1}^{(k+1)} = y_i + \frac{h}{2}[f(x_i, y_i) + f(x_{i+1}, y_{i+1}^{(k)})] & \text{（校正）}
\end{cases}$$

这称为**梯形公式的预估校正法**。

### 3.7 二阶Runge-Kutta法

欧拉法是显式一步法，使用方便但精度低。R-K法的思路：用若干个点函数值的线性组合代替 $f(x_i, y_i)$。

$p$ 级R-K法的一般形式：

$$y_{i+1} = y_i + h \sum_{j=1}^p c_j K_j$$

其中 $K_j = f(x_i + a_j h, y_i + h \sum_{l=1}^{j-1} b_{jl} K_l)$，$c_j$、$a_j$、$b_{jl}$ 为待定参数，$a_j = \sum_{l=1}^{j-1} b_{jl}$。

显然Euler法就是一阶R-K法。

**二级R-K法**：$y_{i+1} = y_i + h(c_1 K_1 + c_2 K_2)$，其中 $K_1 = f(x_i, y_i)$，$K_2 = f(x_i + a_2 h, y_i + b_{21} h K_1)$。

由二阶条件 $c_1 + c_2 = 1$，$c_2 a_2 = \frac{1}{2}$，$b_{21} = a_2$，得：

**(1) 改进的欧拉法**（$c_1 = c_2 = \frac{1}{2}, a_2 = 1$）：
$$y_{i+1} = y_i + \frac{h}{2}[f(x_i, y_i) + f(x_{i+1}, y_i + h f(x_i, y_i))]$$

这实际上是梯形公式的预估-校正只迭代一次。

**(2) 中点公式**（$c_1 = 0, c_2 = 1, a_2 = \frac{1}{2}$）：
$$y_{i+1} = y_i + h f\!\left(x_i + \frac{h}{2},\; y_i + \frac{h}{2} f(x_i, y_i)\right)$$

### 3.8 单步法的收敛性和稳定性

（来源 slides 233-234）本章着重讨论一阶常微方程初值问题的各种数值解法。这些解法都可以写成向量形式而用于一阶常微分方程组的初值问题，也就解决了高阶方程的定解问题。

## 四、计算/应用

### 4.1 Euler公式计算步骤

1. 确定步长 $h = (b-a)/n$，计算节点 $x_i = x_0 + ih$
2. 已知 $y_0$，递推：$y_{i+1} = y_i + h f(x_i, y_i)$
3. 直到 $i = n-1$ 得到全部 $y_i$

## 五、判定/决策流程

```mermaid
flowchart TD
    A[ODE: y'=f(x,y), y(x₀)=y₀] --> B{精度要求?}
    B -->|低/简单分析| C[Euler显式: 一阶, O(h)]
    B -->|中等| D{一步法还是多步法?}
    D -->|单步法| E[二阶RK法]
    E --> F[改进Euler法]
    E --> G[中点公式]
    D -->|多步法| H[Euler中点公式: 二步, 二阶]
    B -->|高| I{显式 vs 隐式}
    I -->|显式| J[高阶RK法]
    I -->|稳定| K[梯形公式预估校正: 二阶]
    C & F & G & H & K --> L{稳定性检查}
    L -->|不满足| M[减小步长h]
    L -->|满足| N[得到数值解y_i]
```

## 七、易错点与注意事项

> [!warning]
> - Euler方法精度不高（一阶），在精度要求高时应选用二阶RK或更高阶方法。
> - 隐式方法需每步解方程，计算量大但稳定性好。预估校正法兼顾了两者。
> - Euler中点公式是二步法，启动时需要两个初始值，第一个步需要用单步法给出 $y_1$。
> - 局部截断误差与全局误差不同：局部假设前面值精确，全局误差随步数累积。
> - 高阶方法比低阶方法精确，但仅在光滑性条件满足的前提下——若 $f$ 不够光滑，高阶方法可能不如低阶方法。
> - 梯形预估校正只需迭代一次即可得到二阶精度，无需多次迭代。
> - 二阶RK法的不定方程有无穷多解，改进Euler和中点公式是两种特例。
