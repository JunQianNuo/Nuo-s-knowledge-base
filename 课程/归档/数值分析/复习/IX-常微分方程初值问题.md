# IX. 常微分方程初值问题的数值解法（第10章）

> 一句说清：离散化 $y'=f(x,y)$ → 节点上递推。Euler 一阶打底，预估校正融显隐，R-K 多点试探提阶数，多步法利用历史省计算。局部截断定阶，谱半径判稳。

---

## 一、核心定义速查

### 1.1 问题基础

| 概念 | 定义 |
|------|------|
| 初值问题 | $y' = f(x,y)$，$y(x_0) = y_0$ |
| Lipschitz 条件 | $\|f(x,y_1)-f(x,y_2)\| \leq L\|y_1-y_2\|$（保证解存在唯一） |
| 离散化 | $x_i = x_0+ih$，$y_i \approx y(x_i)$ |
| 高阶方程降阶 | $y''=f(x,y,y') \to \begin{cases} y'=u \\ u'=f(x,y,u) \end{cases}$（所有高阶均可化为一阶方程组） |

### 1.2 方法分类

| 维度 | 分类 | 含义 |
|------|------|------|
| 步数 | 单步法 | 只用 $y_i$ → $y_{i+1}$ |
| | 多步法 | 用 $y_i,y_{i-1},\ldots$ |
| 格式 | 显式 | 右端不含 $y_{i+1}$ |
| | 隐式 | 右端含 $y_{i+1}$，需解方程 |

### 1.3 局部截断误差与阶

| 概念 | 定义 |
|------|------|
| 局部截断误差 | $T_i = y(x_{i+1}) - y_{i+1}$（假设前面全对） |
| $r$ 阶方法 | $T_i = C h^{r+1} + O(h^{r+2})$ |
| 全局误差 | $\|y(x_i)-y_i\| = O(h^r)$（累积 $1/h$ 步） |

### 1.4 Euler 方法族

| 方法 | 公式 | 阶 | 步数 | 显/隐 |
|------|------|:---:|:---:|:---:|
| Euler 显式 | $y_{i+1}=y_i+hf_i$ | 1 | 单步 | 显 |
| Euler 隐式 | $y_{i+1}=y_i+hf_{i+1}$ | 1 | 单步 | 隐 |
| Euler 中点 | $y_{i+1}=y_{i-1}+2hf_i$ | 2 | 二步 | 显 |

### 1.5 梯形预估校正

$$\begin{cases} y_{i+1}^{(0)} = y_i + h f(x_i,y_i) & \text{（Euler预估）} \\ y_{i+1} = y_i + \frac{h}{2}[f(x_i,y_i) + f(x_{i+1},y_{i+1}^{(0)})] & \text{（梯形校正）} \end{cases}$$

### 1.6 Runge-Kutta 法

| 级别 | 典型公式 | 阶 |
|:---:|------|:---:|
| 一级 | $y_{i+1}=y_i+hf_i$（Euler） | 1 |
| 二级 | 改进 Euler / 中点公式 | 2 |
| 四级 | 经典四阶 R-K：$\frac{h}{6}(K_1+2K_2+2K_3+K_4)$ | **4** |

二阶 R-K 参数条件：$c_1+c_2=1, a_2c_2=1/2$（无穷多解）。

四阶经典 R-K 的 $K_j$：
$$\begin{aligned} K_1 &= f(x_i, y_i) \\ K_2 &= f(x_i+\frac{h}{2}, y_i+\frac{h}{2}K_1) \\ K_3 &= f(x_i+\frac{h}{2}, y_i+\frac{h}{2}K_2) \\ K_4 &= f(x_i+h, y_i+h K_3) \end{aligned}$$

### 1.7 线性多步法 `[课件补充]`

$$\sum_{j=0}^k \alpha_j y_{i+j} = h\sum_{j=0}^k \beta_j f_{i+j}$$

Adams 外推（4阶显式）：$y_{i+1}=y_i+\frac{h}{24}(55f_i-59f_{i-1}+37f_{i-2}-9f_{i-3})$

## 二、核心定理

### 2.1 Euler 公式推导

积分形式：$\int_{x_i}^{x_{i+1}} y' dx = \int f dx$，右端用左矩形 → $y_{i+1}=y_i+hf(x_i,y_i)$。

Taylor 展开：$y(x_{i+1}) = y(x_i) + h y'(x_i) + \frac{h^2}{2}y''(\xi)$，舍去 $h^2$ 项。

### 2.2 局部截断误差与阶

- Euler 显/隐：$T_i = O(h^2)$ → 1 阶
- 梯形公式：$T_i = -\frac{h^3}{12}y'''(\xi)$ → 2 阶
- 二阶 R-K：$T_i = O(h^3)$ → 2 阶
- 四阶 R-K：$T_i = O(h^5)$ → 4 阶

### 2.3 二阶 R-K 参数推导

由 $y_{i+1}=y_i+h(c_1K_1+c_2K_2)$ 与 Taylor 展开 $y(x_{i+1}) = y(x_i) + h y' + \frac{h^2}{2}y'' + O(h^3)$ 逐项匹配：
→ $c_1+c_2=1, a_2c_2=1/2$。无穷多解。

### 2.4 稳定性与绝对稳定域

对试验方程 $y'=\lambda y$（$\text{Re}(\lambda)<0$，真解衰减），分析数值方法的稳定性。

| 方法 | 稳定条件 | 特点 |
|------|------|------|
| Euler 显式 | $\|1+h\lambda\| < 1$ | 有限稳定域 |
| Euler 隐式 | $\|1-h\lambda\|^{-1} < 1$ | 无条件稳定 |
| 梯形公式 | A-稳定 | 无条件稳定 |
| 四阶 R-K | 实轴约 $[-2.78,0]$ | 有限稳定域 |

**稳定性分析推导**：Euler 显式对试验方程 $y'=\lambda y$（$\text{Re}\lambda<0$）：
$$y_{i+1} = y_i + h\lambda y_i = (1+h\lambda)y_i,\quad y_n = (1+h\lambda)^n y_0$$
稳定条件 $|1+h\lambda|<1$。若 $\lambda$ 为实数：$-2<h\lambda<0 \implies h<2/|\lambda|$。

**刚性方程实例**：$y'=-100y,\;y(0)=1$，真解 $e^{-100x}$ 急速衰减。Euler 显式若要稳定：$h<2/100=0.02$。取 $h=0.05$ 则 $|1+h\lambda|=|1-5|=4>1$ → 数值解振荡爆炸。真实系统中"快慢分量并存"（如 $\lambda_1\approx-1000,\;\lambda_2\approx-0.001$），显式步长被最快的分量锁死 $\to$ 必须用隐式方法。

## 三、计算要点

### 3.1 Euler 显式迭代

已知 $y_0$，步长 $h$ → $y_1 = y_0 + h f(x_0,y_0)$ → $y_2 = y_1 + h f(x_1,y_1)$ → ...

**例**：$y'=y,\;y(0)=1,\;h=0.1$：
$y_1 = 1 + 0.1\times 1 = 1.1$，$y_2 = 1.1 + 0.1\times 1.1 = 1.21$（真解 $e^{0.1}\approx1.1052$，$e^{0.2}\approx1.2214$，误差 $\sim0.01$）。

**例**：$y'=ax+b,\;y(0)=0$，求 $x_n=nh$ 处的近似式（解析递推）：
Euler 显式：$y_{i+1}=y_i+h(ax_i+b)$ → 累加 $n$ 步得
$$y_n = ah^2\frac{n(n-1)}2 + bnh, \quad \text{误差} = \frac a2 x_n h = O(h)$$
改进 Euler：$y_{i+1}=y_i+h(ax_i+b)+\frac{ah^2}2$ → 累加得
$$y_n = \frac a2 n^2 h^2 + bnh = y(x_n) \quad \text{（精确！）}$$
**洞察**：$f$ 不含 $y$ 时 Euler=左矩形（1阶），改进Euler=梯形（对线性精确→2阶）。ODE 方法阶 = 对应积分公式代数精度 + 1。

### 3.2 改进 Euler（预估校正一次）

① $y_{i+1}^{(0)} = y_i + h f(x_i,y_i)$ ② $y_{i+1} = y_i + \frac{h}{2}[f(x_i,y_i) + f(x_{i+1},y_{i+1}^{(0)})]$

### 3.3 四阶 R-K 迭代

依次算 $K_1 \to K_2 \to K_3 \to K_4$ → $y_{i+1} = y_i + \frac{h}{6}(K_1+2K_2+2K_3+K_4)$

**例**：$y' = -y - xy^2, y(0)=1, h=0.2$（四阶 R-K 一步详细计算）：
$$K_1 = f(0,1) = -1$$
$$K_2 = f(0.1, 1+0.1\cdot(-1)) = f(0.1,0.9) = -0.981$$
$$K_3 = f(0.1, 1+0.1\cdot(-0.981)) = f(0.1,0.9019) = -0.9833$$
$$K_4 = f(0.2, 1+0.2\cdot(-0.9833)) = f(0.2,0.8033) = -0.9324$$
$$y_1 = 1 + \frac{0.2}{6}[(-1)+2(-0.981)+2(-0.9833)+(-0.9324)] = 0.8046$$

精确解 $y(0.2) = (2e^{0.2}-0.2-1)^{-1} \approx 0.8046$——一步吻合到 4 位。5 步全程误差均 $\sim 10^{-5}$，体现四阶威力。

### 3.4 方法选择

| 场景 | 推荐方法 |
|------|----------|
| 精度要求低 | Euler 显式 |
| 精度要求中 | 改进 Euler（二阶） |
| 精度要求高 + $f$ 便宜 | 四阶 R-K |
| 精度要求高 + $f$ 贵 | 多步法（Adams）`[课件补充]` |
| 刚性问题 | 隐式方法（梯形/BDF） |

## 四、典型易错点

> [!warning] **局部截断误差 ≠ 全局误差**：局部 $O(h^{r+1})$，全局 $O(h^r)$（累积 $1/h$ 步）。

> [!warning] **隐式方法需解方程**：预估校正只用一次校正迭代是实用折中。

> [!warning] **多步法不能自启动**：前几步需用同阶 R-K 算出。`[课件补充]`

> [!warning] **显式方法对刚性方程不适用**：稳定域限制步长极小 → 必须用隐式。

> [!warning] **二阶 R-K 有无穷多种**：$c_1+c_2=1, a_2c_2=1/2$ 即可。改 Euler 和中点公式只是其中两种。
