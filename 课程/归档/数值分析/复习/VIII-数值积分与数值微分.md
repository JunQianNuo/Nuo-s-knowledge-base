# VIII. 数值积分与数值微分（第9章）

> 一句说清：绕开求原函数，用函数值的加权和近似积分。代数精度衡量公式好坏。等距节点→N-C→分段→复化→外推加速→Romberg。放弃等距用正交多项式零点→Gauss（$2n+1$ 精度上限）。

---

## 一、核心定义速查

### 1.1 求积公式基础

| 概念 | 定义/公式 |
|------|------|
| 求积公式 | $\int_a^b f(x)dx \approx \sum_{k=0}^n A_k f(x_k)$ |
| 余项 | $R[f] = \int f - \sum A_k f(x_k)$ |
| 代数精度 | 对 $f=1,x,\ldots,x^m$ 精确成立的最大 $m$ |
| 内插求积公式 | $A_k = \int_a^b l_k(x)dx$，$l_k$ 为 Lagrange 基函数 |

### 1.2 矩形与 Newton-Cotes 公式

| 公式 | 表达式 | 余项 | 精度 |
|------|------|------|:---:|
| 左矩形 | $(b-a)f(a)$ | $\frac{(b-a)^2}{2}f'(\eta)$ | 0 |
| 右矩形 | $(b-a)f(b)$ | $-\frac{(b-a)^2}{2}f'(\eta)$ | 0 |
| 中矩形 | $(b-a)f(\frac{a+b}{2})$ | $\frac{(b-a)^3}{24}f''(\eta)$ | 1 |
| 梯形 | $\frac{h}{2}[f(a)+f(b)]$ | $-\frac{h^3}{12}f''(\xi)$ | 1 |
| Simpson | $\frac{h}{3}[f(a)+4f_m+f(b)]$ | $-\frac{h^5}{90}f^{(4)}(\xi)$ | **3** |
| Cotes（$n=4$） | 5点加权 | — | 5 |

> 偶数阶 N-C 精度 +1：$n$ 为偶数时 $\int \omega = 0$（奇函数）→ 精度达 $n+1$。

### 1.3 复化求积

| 公式 | 表达式 | 余项 |
|------|------|------|
| 复化梯形 | $T_n = \frac{h}{2}[f(a)+f(b)+2\sum f_k]$ | $-\frac{b-a}{12}h^2 f''$ |
| 复化 Simpson | $S_{2m} = \frac{h}{3}[f(a)+f(b)+2\sum_{\text{偶}}+4\sum_{\text{奇}}]$ | $-\frac{b-a}{180}h^4 f^{(4)}$ |

逐次对分：$T_{2n} = \frac{1}{2}T_n + h'\sigma_n$（旧值保留，只算新分点）。

### 1.4 Romberg 外推序列

$$S_n = \frac{4T_{2n}-T_n}{3}, \quad C_n = \frac{16S_{2n}-S_n}{15}, \quad R_n = \frac{64C_{2n}-C_n}{63}$$

### 1.5 Gauss 求积

| 类型 | 区间 | 权函数 | 正交多项系 |
|------|------|------|------|
| Gauss-Legendre | $[-1,1]$ | $1$ | Legendre |
| Gauss-Laguerre | $[0,\infty)$ | $e^{-x}$ | Laguerre |
| Gauss-Hermite | $(-\infty,\infty)$ | $e^{-x^2}$ | Hermite |

Gauss 点条件：$\omega_{n+1}(x)$ 与任意 $\leq n$ 次多项式正交。精度：$2n+1$。

### 1.6 数值微分

**差商公式**：

| 公式 | 误差阶 | 误差主项 |
|------|:---:|------|
| 向前差商 $\frac{f(x+h)-f(x)}{h}$ | $O(h)$ | $-\frac{h}{2}f''(\xi)$ |
| 向后差商 $\frac{f(x)-f(x-h)}{h}$ | $O(h)$ | $\frac{h}{2}f''(\xi)$ |
| **中心差商** $\frac{f(x+h)-f(x-h)}{2h}$ | **$O(h^2)$** | $-\frac{h^2}{6}f'''(\xi)$ |
| 二阶中心 $\frac{f(x+h)-2f(x)+f(x-h)}{h^2}$ | $O(h^2)$ | $-\frac{h^2}{12}f^{(4)}(\xi)$ |

**基于插值的数值微分**（两点/三点公式）：

| 公式 | 表达式 | 误差 |
|------|------|------|
| 两点公式 | $f'(x_0)\approx\frac{y_1-y_0}{h}$ | $\|\frac{f''(\xi)}{2}h\|$ |
| 三点公式（中心） | $f'(x_1)\approx\frac{y_2-y_0}{2h}$ | $\|\frac{f'''(\xi)}{6}h^2\|$ |
| 三点公式（端点） | $f'(x_0)\approx\frac{-3y_0+4y_1-y_2}{2h}$ | $\|\frac{f'''(\xi)}{3}h^2\|$

## 二、核心定理

### 2.1 N-C 公式一般余项

$$R_n[f] = \int_a^b \frac{f^{(n+1)}(\xi)}{(n+1)!}\omega(x)dx, \quad \omega(x)=\prod_{i=0}^n(x-x_i)$$

特例：梯形 $R = -\frac{(b-a)^3}{12}f''(\xi)$。Simpson $R = -\frac{(b-a)^5}{2880}f^{(4)}(\xi)$（$=-\frac{b-a}{180}h^4 f^{(4)}$）。

### 2.2 复化余项

$R[T_n] = -\frac{b-a}{12}h^2 f''(\xi)$，$R[S_{2m}] = -\frac{b-a}{180}h^4 f^{(4)}(\xi)$。

### 2.3 Gauss 点充要条件

$$\int_a^b P(x)\omega_{n+1}(x)dx = 0 \quad \text{（}\forall P \text{ 次数} \leq n\text{）}$$

### 2.4 Gauss 截断误差

$$R[f] = \frac{f^{(2n+2)}(\xi)}{(2n+2)!}\int_a^b \omega^2(x)dx$$

## 三、计算要点

### 3.1 代数精度判断

依次代入 $f(x)=1,x,x^2,\ldots$ 到求积公式，找到 $R[x^m] \equiv 0$ 的最大 $m$。

**例**：验证 $\int_{-1}^1 f(x)dx = \frac{1}{3}f(-1)+\frac{4}{3}f(0)+\frac{1}{3}f(1)$：
$f=1$：左$=2$，右$=1/3+4/3+1/3=2$ ✅；$f=x$：左$=0$，右$=-1/3+0+1/3=0$ ✅；$f=x^2$：左$=2/3$，右$=1/3+0+1/3=2/3$ ✅；$f=x^3$：左$=0$，右$=-1/3+0+1/3=0$ ✅；$f=x^4$：左$=2/5$，右$=1/3+0+1/3=2/3\neq2/5$ ❌ → 代数精度为 3。

### 3.2 先验误差估计

已知 $|f^{(k)}| \leq M$，令余项绝对值 $\leq \varepsilon$ → 解出 $h$ 或 $n$。

**例**：$\int_0^1 \frac{\sin x}{x}dx$，$|f^{(k)}| \leq 1/(k+1)$，复化梯形误差 $10^{-4}$：
$|R| \leq \frac{h^2}{36} \leq 10^{-4} \implies h \leq 0.06 \implies n \geq 17$。复化 Simpson 只需 $n=2$。

### 3.3 Romberg 外推

从 $T_1,T_2,T_4,T_8$ 出发 → $T \to S \to C \to R$，层层外推加速。通式（Richardson 外推）：
$$A_{\text{new}} = \frac{2^p A(h/2) - A(h)}{2^p - 1}, \quad p=2,4,6,\ldots$$

**例**：$\int_0^1 \frac{4}{1+x^2}dx=\pi$。计算完整三角表：

$$\begin{aligned}
T_1 &= \frac{1}{2}[f(0)+f(1)] = 3.00000 \\
T_2 &= \frac{1}{2}T_1 + \frac{1}{2}f(0.5) = 1.5 + 1.6 = 3.10000 \\
T_4 &= \frac{1}{2}T_2 + \frac{1}{4}[f(0.25)+f(0.75)] = 3.13118 \\
T_8 &\approx 3.13899
\end{aligned}$$

外推：
$$S_1 = \frac{4T_2-T_1}{3} = 3.13333,\; S_2 = \frac{4T_4-T_2}{3} = 3.14157,\; S_4 = \frac{4T_8-T_4}{3} = 3.14159$$
$$C_1 = \frac{16S_2-S_1}{15} = 3.14212,\; C_2 = \frac{16S_4-S_2}{15} = 3.14159$$
$$R_1 = \frac{64C_2-C_1}{63} = 3.14159$$

| | $T$（$O(h^2)$） | $S$（$O(h^4)$） | $C$（$O(h^6)$） | $R$（$O(h^8)$） |
|:---:|:---:|:---:|:---:|:---:|
| $h$ | 3.00000 | | | |
| $h/2$ | 3.10000 | 3.13333 | | |
| $h/4$ | 3.13118 | 3.14157 | 3.14212 | |
| $h/8$ | 3.13899 | 3.14159 | 3.14159 | **3.14159** |

> 只用四则运算，从 $T_1=3.0$（误差 0.14）推到 $R_1=3.14159$（6 位精度）——没有增加任何函数计算。

### 3.4 Gauss 求积手算

**两点 Gauss-Legendre**：$x_{0,1} = \pm\frac{\sqrt{3}}{3}$，$A_0=A_1=1$。精度 $2n+1=3$。

对一般 $[a,b]$ 需变换：$x = \frac{b-a}{2}t + \frac{a+b}{2}$，$dx = \frac{b-a}{2}dt$。

**例**：$\int_0^1 (x^3+2x)dx$，两点 Gauss-Legendre：
$$t_{0,1}=\pm\frac{\sqrt{3}}{3},\; x_{0,1}=\frac{1\pm\sqrt{3}/3}{2},\; f(x)=x^3+2x$$
$$\int \approx \frac{1}{2}[f(0.2113)+f(0.7887)] = \frac{1}{2}[0.4320+2.0680] = 1.25$$
精确值 $\left[\frac{x^4}{4}+x^2\right]_0^1 = 1.25$ ——两点 Gauss **精确**（被积函数 3 次，不超精度）。

**三类 Gauss 公式选择**：
| 积分 | 选法 |
|------|------|
| $\int_a^b f(x)dx$ | 变换到 $[-1,1]$→Gauss-Legendre |
| $\int_0^\infty e^{-x}f(x)dx$ | Gauss-Laguerre |
| $\int_{-\infty}^\infty e^{-x^2}f(x)dx$ | Gauss-Hermite |

### 3.5 数值微分实例

**中心差商** $f'(x)\approx\frac{f(x+h)-f(x-h)}{2h}$，误差 $\approx\frac{h^2}{6}f'''$。

$f(x)=\sin x$，$x=0.5$，$h=0.1$：
- 向前差商：$\frac{\sin0.6-\sin0.5}{0.1} \approx 0.8521$，误差 0.0255
- 中心差商：$\frac{\sin0.6-\sin0.4}{0.2} \approx 0.8761$，误差 0.0015（准确值 $\cos0.5\approx0.87758$）
- 中心差商误差仅向前差商的 **1/17**——$O(h^2)$ vs $O(h)$

**最优步长问题**：$h$ 太小 → 相近数相减 → 舍入误差反超。中心差商最优 $h\approx(3\varepsilon_{\text{mach}})^{1/3}$。

## 四、典型易错点

> [!warning] **逐次对分复用**：$T_{2n} = \frac{1}{2}T_n + h'\sigma_n$——老节点保留！不要重算整个和。

> [!warning] **偶数阶 N-C 精度 +1**：Simpson（$n=2$）精度是 3 不是 2——考试最容易设陷阱。

> [!warning] **Gauss 节点无复用**：增加节点旧值全浪费——精度优势通常值得。

> [!warning] **数值微分有最优步长**：$h$ 太小→相近数相减→舍入误差反超截断误差。
