# 习题 8.16

考虑如下优化问题：

$$\min_{x \in \mathbb{R}^n} \|Ax - b\|^2$$

其中 $A \in \mathbb{R}^{m \times n}$，$m > n$，$b \in \mathbb{R}^m$。

**a.** 证明目标函数实际上是一个二次型函数，写出其**梯度**和**黑塞矩阵**（Hessian）。

**b.** 如果采用**步长固定梯度法**求解该问题，试写出其迭代公式。

**c.** 令 $A = \begin{bmatrix} 1 \\ 0 \end{bmatrix} \in \mathbb{R}^{2 \times 1}$，$b = [b_1, b_2]^\top$。试确定步长固定梯度法步长 $\alpha$ 的最大取值范围，保证算法全局收敛。

---

## 💡 提示

> [!hint]- 点击展开提示
>
> **(a)** 展开 $\|Ax - b\|^2$：
>
> $$f(x) = (Ax - b)^\top(Ax - b) = x^\top A^\top A x - 2b^\top A x + b^\top b$$
>
> 这是标准的二次型 $f(x) = \frac{1}{2}x^\top Q x - c^\top x + \text{const}$，其中：
>
> $$Q = 2A^\top A, \quad c = 2A^\top b$$
>
> 梯度：$\nabla f(x) = 2A^\top(Ax - b)$
> 黑塞矩阵：$F(x) = 2A^\top A$（常数矩阵，与 $x$ 无关）
>
> 由于 $m > n$ 且 $\text{rank}(A) = n$（列满秩），$A^\top A \succ 0$，故 $f$ 有唯一极小点 $x^* = (A^\top A)^{-1}A^\top b$（正规方程解）。
>
> **(b)** 定步长梯度法迭代：
>
> $$x^{(k+1)} = x^{(k)} - \alpha \cdot 2A^\top(Ax^{(k)} - b) = x^{(k)} - 2\alpha A^\top(Ax^{(k)} - b)$$
>
> 注意：有些教材将 $\alpha$ 吸收到系数中，写为 $x^{(k+1)} = x^{(k)} - \alpha_g \nabla f(x^{(k)})$。
>
> **(c)** 对于二次函数，定步长梯度法收敛的充要条件：
>
> $$0 < \alpha < \frac{2}{\lambda_{\max}(Q)} = \frac{2}{2\lambda_{\max}(A^\top A)} = \frac{1}{\lambda_{\max}(A^\top A)}$$
>
> 其中 $Q = 2A^\top A$ 是黑塞矩阵，$\lambda_{\max}(Q) = 2\lambda_{\max}(A^\top A)$。
>
> 对 $A = \begin{bmatrix} 1 \\ 0 \end{bmatrix}$：$A^\top A = [1]$，$\lambda_{\max}(A^\top A) = 1$，故 $\alpha \in (0, 1)$。

---

## 📝 详细解析

> [!solution]- 点击展开详细解析
>
> ### (a) 二次型形式
>
> 展开目标函数：
>
> $$\begin{aligned}
> f(x) &= \|Ax - b\|^2 = (Ax - b)^\top(Ax - b) \\
> &= x^\top A^\top A x - x^\top A^\top b - b^\top A x + b^\top b \\
> &= x^\top A^\top A x - 2b^\top A x + b^\top b
> \end{aligned}$$
>
> 写成标准二次型 $f(x) = \dfrac{1}{2}x^\top Q x - c^\top x + d$：
>
> $$Q = 2A^\top A, \quad c = 2A^\top b, \quad d = b^\top b$$
>
> **梯度**：
> $$\nabla f(x) = Qx - c = 2A^\top A x - 2A^\top b = 2A^\top(Ax - b)$$
>
> **黑塞矩阵**：
> $$F(x) = \nabla^2 f(x) = Q = 2A^\top A$$
>
> 当 $\text{rank}(A) = n$（列满秩）时，$A^\top A \succ 0$，存在唯一极小点：
>
> $$x^* = Q^{-1}c = (2A^\top A)^{-1} \cdot 2A^\top b = (A^\top A)^{-1}A^\top b$$
>
> ---
>
> ### (b) 定步长梯度法迭代公式
>
> $$x^{(k+1)} = x^{(k)} - \alpha \nabla f(x^{(k)}) = x^{(k)} - 2\alpha A^\top(Ax^{(k)} - b)$$
>
> 也可写为：
>
> $$x^{(k+1)} = (I - 2\alpha A^\top A) x^{(k)} + 2\alpha A^\top b$$
>
> ---
>
> ### (c) 收敛性分析
>
> 给定 $A = \begin{bmatrix} 1 \\ 0 \end{bmatrix} \in \mathbb{R}^{2 \times 1}$。
>
> $$A^\top A = \begin{bmatrix} 1 & 0 \end{bmatrix} \begin{bmatrix} 1 \\ 0 \end{bmatrix} = [1]$$
>
> 黑塞矩阵 $Q = 2A^\top A = [2]$。
>
> $\lambda_{\max}(Q) = 2$。
>
> 定步长梯度法全局收敛的充要条件：
>
> $$0 < \alpha < \frac{2}{\lambda_{\max}(Q)} = \frac{2}{2} = 1$$
>
> 因此：$\boxed{\alpha \in (0, 1)}$
>
> **验证**：迭代矩阵为 $I - \alpha Q = [1 - 2\alpha]$。收敛要求 $|1 - 2\alpha| < 1$，即 $-1 < 1-2\alpha < 1$，解得 $0 < \alpha < 1$，与特征值条件一致。
>
> **极小点**：$x^* = \dfrac{A^\top b}{A^\top A} = b_1$（第一个分量），即 $x^*$ 只依赖于 $b_1$。
>
> $\square$
