# 习题 21.1 — KKT 条件与二阶充分条件

求解以下不等式约束优化问题：

$$\begin{aligned}
\min \quad & f(x_1, x_2) = x_1^2 + 4x_2^2 \\
\text{s.t.} \quad & x_1^2 + 2x_2^2 \geq 4
\end{aligned}$$

**a.** 求出满足 KKT 条件的所有点（含对应乘子）。

**b.** 利用二阶充分条件（SOSC），判断问题 a 所求结果是不是极小点。若非极小点，说明理由。

---

## 💡 提示

> [!hint]- 点击展开提示
> - 先将约束改写为标准形式：$g(x) = 4 - x_1^2 - 2x_2^2 \leq 0$。
> - 驻点方程 $2x_1(1-\mu)=0$ 和 $4x_2(2-\mu)=0$ 提示按 $\mu$ 的取值分类——$\mu=0$、$\mu=1$、$\mu=2$ 三种情形。
> - 互补松弛 $\mu \cdot g(x^*) = 0$：若 $\mu > 0$，则约束边界必紧（$g(x^*) = 0$）。
> - 验证 SOSC 时，先写出 $\nabla_{xx}^2 \mathcal{L}$（对角矩阵），再对每个 KKT 点确定**临界锥** $\mathcal{C}$：对 $\mu>0$ 的积极约束，$d$ 需满足 $\nabla g^\top d = 0$。

---

## 📝 详细解析

> [!solution]- 点击展开详细解析
> ### (a) KKT 条件的求解
>
> **第一步：标准化**
>
> 将约束 $x_1^2 + 2x_2^2 \geq 4$ 改写为标准不等式形式：
>
> $$g(x) = 4 - x_1^2 - 2x_2^2 \leq 0$$
>
> **第二步：写出 Lagrangian**
>
> $$\mathcal{L}(x, \mu) = x_1^2 + 4x_2^2 + \mu(4 - x_1^2 - 2x_2^2), \quad \mu \geq 0$$
>
> **第三步：列出 KKT 四条件**
>
> 1. **原始可行性：** $4 - x_1^2 - 2x_2^2 \leq 0$
>
> 2. **对偶可行性：** $\mu \geq 0$
>
> 3. **驻点条件：**
>    $$\begin{aligned}
>    \frac{\partial \mathcal{L}}{\partial x_1} &= 2x_1 - 2\mu x_1 = 2x_1(1-\mu) = 0 \\
>    \frac{\partial \mathcal{L}}{\partial x_2} &= 8x_2 - 4\mu x_2 = 4x_2(2-\mu) = 0
>    \end{aligned}$$
>
> 4. **互补松弛：** $\mu(4 - x_1^2 - 2x_2^2) = 0$
>
> **第四步：分类讨论**
>
> 由驻点方程 $2x_1(1-\mu) = 0$ 和 $4x_2(2-\mu) = 0$，按 $\mu$ 的取值分三种情形：
>
> ---
>
> **情形 1：$\mu = 0$**
>
> 驻点方程退化为 $2x_1 = 0 \Rightarrow x_1 = 0$，$8x_2 = 0 \Rightarrow x_2 = 0$。
>
> 检验原始可行性：$g(0,0) = 4 - 0 - 0 = 4 > 0$，**违反 $g(x) \leq 0$，排除。**
>
> ---
>
> **情形 2：$\mu = 1$**
>
> 由驻点 $x_2$ 方程：$4x_2(2-1) = 4x_2 = 0 \Rightarrow x_2 = 0$。
>
> 由互补松弛（$\mu = 1 > 0$）：约束必紧，即 $g(x^*) = 0$：
>
> $$4 - x_1^2 - 2(0)^2 = 0 \;\Longrightarrow\; x_1^2 = 4 \;\Longrightarrow\; x_1 = \pm 2$$
>
> 检验原始可行性：$g(\pm 2, 0) = 4 - 4 - 0 = 0 \leq 0$ $\checkmark$
>
> **KKT 点 $A$：** $x^* = (2, 0)^\top$，$\mu^* = 1$
>
> **KKT 点 $B$：** $x^* = (-2, 0)^\top$，$\mu^* = 1$
>
> ---
>
> **情形 3：$\mu = 2$**
>
> 由驻点 $x_1$ 方程：$2x_1(1-2) = -2x_1 = 0 \Rightarrow x_1 = 0$。
>
> 由互补松弛（$\mu = 2 > 0$）：约束必紧：
>
> $$4 - 0 - 2x_2^2 = 0 \;\Longrightarrow\; x_2^2 = 2 \;\Longrightarrow\; x_2 = \pm\sqrt{2}$$
>
> 检验原始可行性：$g(0, \pm\sqrt{2}) = 4 - 0 - 4 = 0 \leq 0$ $\checkmark$
>
> **KKT 点 $C$：** $x^* = (0, \sqrt{2})^\top$，$\mu^* = 2$
>
> **KKT 点 $D$：** $x^* = (0, -\sqrt{2})^\top$，$\mu^* = 2$
>
> ---
>
> **汇总：** 共有 4 个 KKT 点：
>
> $$(2, 0),\quad (-2, 0),\quad (0, \sqrt{2}),\quad (0, -\sqrt{2})$$
>
> ---
>
> ### (b) 二阶充分条件（SOSC）验证
>
> **第一步：计算 Lagrangian 的 Hessian**
>
> $$\nabla_{xx}^2 \mathcal{L} = \begin{bmatrix} 2 - 2\mu & 0 \\ 0 & 8 - 4\mu \end{bmatrix}$$
>
> （因为 $\nabla^2 f = \operatorname{diag}(2, 8)$，$\nabla^2 g = \operatorname{diag}(-2, -4)$，故 $\nabla_{xx}^2 \mathcal{L} = \operatorname{diag}(2-2\mu, 8-4\mu)$。）
>
> **约束梯度：**
>
> $$\nabla g(x) = \begin{bmatrix} -2x_1 \\ -4x_2 \end{bmatrix}$$
>
> **第二步：逐一检验**
>
> ---
>
> **检验点 $A = (2, 0)$ 和 $B = (-2, 0)$（$\mu^* = 1$）**
>
> Hessian：$\nabla_{xx}^2 \mathcal{L} = \begin{bmatrix} 0 & 0 \\ 0 & 4 \end{bmatrix}$
>
> 约束梯度：在 $(2, 0)$ 处 $\nabla g = (-4, 0)^\top$，在 $(-2, 0)$ 处 $\nabla g = (4, 0)^\top$。
>
> 由于 $\mu^* = 1 > 0$（强积极约束），临界锥为：
>
> $$\mathcal{C} = \{d \in \mathbb{R}^2 \mid \nabla g(x^*)^\top d = 0\} = \{d \mid \mp 4 d_1 = 0\} = \{d \mid d_1 = 0\}$$
>
> 对任意 $d = (0, d_2)^\top \neq 0$：
>
> $$d^\top \nabla_{xx}^2 \mathcal{L}\, d = [0, d_2]\begin{bmatrix} 0 & 0 \\ 0 & 4 \end{bmatrix}\begin{bmatrix} 0 \\ d_2 \end{bmatrix} = 4d_2^2 > 0$$
>
> **SOSC 满足！** $x^* = (\pm 2, 0)^\top$ 是**严格局部极小点**，$f^* = (\pm 2)^2 + 0 = 4$。
>
> ---
>
> **检验点 $C = (0, \sqrt{2})$ 和 $D = (0, -\sqrt{2})$（$\mu^* = 2$）**
>
> Hessian：$\nabla_{xx}^2 \mathcal{L} = \begin{bmatrix} -2 & 0 \\ 0 & 0 \end{bmatrix}$
>
> 约束梯度：$\nabla g = (0, \mp 4\sqrt{2})^\top$。
>
> 由于 $\mu^* = 2 > 0$，临界锥为：
>
> $$\mathcal{C} = \{d \in \mathbb{R}^2 \mid \nabla g^\top d = 0\} = \{d \mid \mp 4\sqrt{2}\, d_2 = 0\} = \{d \mid d_2 = 0\}$$
>
> 对任意 $d = (d_1, 0)^\top \neq 0$：
>
> $$d^\top \nabla_{xx}^2 \mathcal{L}\, d = [d_1, 0]\begin{bmatrix} -2 & 0 \\ 0 & 0 \end{bmatrix}\begin{bmatrix} d_1 \\ 0 \end{bmatrix} = -2d_1^2 < 0$$
>
> **SOSC 不满足！** 在临界锥上二阶形式为**负定**，因此 $(0, \pm\sqrt{2})$ **不是极小点**（实际上沿临界方向 $f$ 的值会下降，结合约束来看这些点是局部极大点而非极小点）。
>
> ---
>
> **结论：** $\boxed{x^* = (2, 0)^\top \text{ 和 } (-2, 0)^\top}$ 是严格局部极小点，$f^* = 4$。
>
> $\square$
>
> **点评：** 本题是 KKT + SOSC 的经典入门练习，关键经验有三：(1) 驻点方程因式分解后按 $\mu$ 的取值分类讨论，比按"活动/非活动"枚举更高效——因为目标函数和约束函数都是分离变量形式；(2) 互补松弛对 $\mu>0$ 的情形直接将约束收紧为等式，联立求解非常直接；(3) SOSC 的临界锥只包含"沿紧约束边界的切线方向"——在本题中就是压低 Hessian 矩阵的"坏方向"，需要逐一检查 $(x_1, x_2)$ 哪个分量被 $\nabla g$ 锁定。
