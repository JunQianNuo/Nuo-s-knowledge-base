# 第16章 答疑 — 单纯形乘子 $\lambda^T = c_B^T B^{-1}$ 的推导

> 问题：**$\lambda^T = c_B^T B^{-1}$ 是怎么推导出来的？为什么最优基的乘子恰好是对偶最优解？**

> 来源：`复习/V-线性规划.md` 第 149 行

---

## 一句话兜底

> 最优基对应的 $\lambda^T = c_B^T B^{-1}$ 天然满足对偶可行（判别数非负 ↔ $A^T\lambda \leq c$），且原始-对偶目标值相等，弱对偶定理保证它就是最优。

---

## 推导（三步）

标准型 (P)：$\min \; c^T x,\; Ax = b,\; x \geq 0$。
对偶 (D)：$\max \; b^T \lambda,\; A^T \lambda \leq c$。

设 $B$ 是原始最优基，$x_B = B^{-1}b \geq 0$，$x_N = 0$。

### Step 1：验证对偶可行性

最优基的判别数全非负（$\min$ 问题）：$r_j = c_j - c_B^T B^{-1} a_j \geq 0$，$\forall j = 1,\dots,n$。

定义 $\lambda^T := c_B^T B^{-1}$，代入：

$$c_j - \lambda^T a_j \geq 0 \quad \Longrightarrow \quad a_j^T \lambda \leq c_j$$

对所有 $j$ 成立，即 $A^T \lambda \leq c$。$\lambda$ 是 (D) 的可行解。✅

### Step 2：验证目标值相等

$$c^T x^* = c_B^T x_B + c_N^T \underbrace{x_N}_{=0} = c_B^T B^{-1} b = \lambda^T b = b^T \lambda$$

原始最优值 = 对偶目标值。✅

### Step 3：弱对偶推出最优性

弱对偶定理：对任意 (P) 可行解 $x$ 和 (D) 可行解 $\lambda$：

$$c^T x \geq b^T \lambda$$

现在找到了一个 (P) 可行解 $x^*$ 和一个 (D) 可行解 $\lambda$，它们的目标值**相等**——达到了下界。所以两者都是各自问题的最优解。✅

> 三步只用到了：判别数非负 → 对偶可行，$x_N = 0$ → 目标相等，弱对偶 → 最优性。没有额外的假设。

---

## 直观理解

| 视角 | 含义 |
|:--|:--|
| **代数** | $\lambda^T = c_B^T B^{-1}$ 把基变量的成本"投影"到约束空间 |
| **经济** | $\lambda_i$ = 第 $i$ 个资源的**影子价格**：$b_i$ 增 1 单位，最优值改善 $\lambda_i$ |
| **几何** | $\lambda$ 是目标梯度 $c$ 在活动约束法向量上的线性组合系数 |
| **实用** | 单纯形表右下角的相反数 $-c_B^T B^{-1} b = -z_0$，而乘子本身藏在判别数行 |
