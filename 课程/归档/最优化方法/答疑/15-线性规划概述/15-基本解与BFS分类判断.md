# 第15章 答疑 — 基本解、可行解、BFS 的分类判断

> 问题：**笔记 6.4 的表里，每个解是怎么判断类型的？我没有清晰的理解。**

> 来源：`15-线性规划概述-知识梳理.md` 第 219 行

---

## 核心结论（一分钟版）

三个概念的递进关系：**可行解 ⊃ 基本解 ⊃ 基本可行解**。判断时按这个顺序筛：

```
x ≥ 0？ → 否 → 不是可行解（也不是 BFS）
   ↓是
非零分量数 > m？ → 是 → 不是基本解（也不是 BFS）
   ↓否
x ≥ 0 且 x 是基本解 → BFS
   └ B⁻¹b 有零分量 → 退化 BFS
```

---

## 前提设定

某 LP 的 $A$ 为 $2 \times 4$ 矩阵（$m = \operatorname{rank}(A) = 2$，$n = 4$）。以 $\{a_3, a_4\}$ 为基时 $B^{-1}b = [0, 2]^T$（即 $x_3 = 0, x_4 = 2$）。

**三个基本概念回顾：**

| 术语 | 定义 | 关键词 |
|------|------|--------|
| **可行解** | $Ax = b$ 且 $x \ge 0$ | 落在约束集 $M$ 内即可，不要求是"角点" |
| **基本解** | 存在某个基 $B$，$x_B = B^{-1}b$，$x_N = 0$ | 非基变量全为零；非零分量数 $\le m$ |
| **基本可行解 (BFS)** | 基本解 + $x \ge 0$ | 既是基本解又在 $M$ 内 |
| **退化 BFS** | BFS 且某个基变量 $= 0$ | $B^{-1}b$ 含零分量 |

---

## 逐行拆解

### 第1行：$x = [6, 2, 0, 0]^T$，基 $\{a_1, a_2\}$

| 判断 | 结论 | 理由 |
|---|---|---|
| 可行解？ | ✅ yes | 全部分量 $\ge 0$（6, 2, 0, 0），无负值 |
| 基本解？ | ✅ yes | 基是 $\{a_1, a_2\}$，非基变量 $x_3, x_4 = 0$。2 个非零分量 $= m = 2$，结构吻合 |
| BFS？ | ✅ yes（非退化） | 基本解 + 非负 → BFS。基变量 $x_1 = 6, x_2 = 2$ 均 $> 0$，无退化 |

---

### 第2行：$x = [0, 0, 0, 2]^T$，基 $\{a_3, a_4\}$

| 判断 | 结论 | 理由 |
|---|---|---|
| 可行解？ | ✅ yes | 全部分量 $\ge 0$（0, 0, 0, 2） |
| 基本解？ | ✅ yes | 基是 $\{a_3, a_4\}$，非基变量 $x_1, x_2 = 0$。**题干已给出**此基下 $B^{-1}b = [0, 2]^T$ |
| BFS？ | ✅ yes（**退化**） | 基本解 + 非负 → BFS。但 $x_3 = 0$（$B^{-1}b$ 的第一个分量）→ 基变量为零 → **退化** |

> 🔑 **退化的本质**：一个基变量"刚好踩在另一条边界上"（值为零），此时同一个 BFS 可能对应多个不同的基。这意味着单纯形法可能在某些退化顶点上"原地踏步"。

---

### 第3行：$x = [3, 1, 0, 1]^T$

| 判断 | 结论 | 理由 |
|---|---|---|
| 可行解？ | ✅ yes | 全部分量 $\ge 0$（3, 1, 0, 1） |
| 基本解？ | ❌ no | **非零分量有 3 个**（$x_1, x_2, x_4 \neq 0$），但 $m = 2$。基本解最多有 $m$ 个非零分量（只有基变量可以非零）。$3 > 2$ → 不可能是基本解 |
| BFS？ | ❌ no | 不是基本解 → 不是"角点" → 不可能是 BFS |

> ⚠️ **重要**：非零分量数 $\le m$ 是基本解的**必要条件**，不是充分条件。非零分量数少不保证是基本解（还需非零列线性无关），但非零分量数 $> m$ **一定**不是基本解。

这一行就是「可行但不基本」的最佳反例——这个点落在 $M$ 内部或边上，但不是由任何一个基产生的顶点。

---

### 第4行：$x = [0, 2, -6, 0]^T$，基 $\{a_2, a_3\}$

| 判断 | 结论 | 理由 |
|---|---|---|
| 可行解？ | ❌ no | $x_3 = -6 < 0$，违反非负约束 $x \ge 0$ |
| 基本解？ | ✅ yes | 基是 $\{a_2, a_3\}$，非基变量 $x_1, x_4 = 0$。$B^{-1}b = [2, -6]^T$ |
| BFS？ | ❌ no | 结构上是基本解，但不满足 $x \ge 0$——这个解落在约束集 $M$ **之外** |

> 几何上：这个点满足 $Ax = b$（在仿射子空间里），但不在第一象限（$x \ge 0$ 被违反），所以不在 $M$ 中。

---

## 三种分类的逻辑关系图

```
                所有解
                  │
        Ax=b, x≥0？  ────否───→  不可行解（第4行）
                  │是
                可行解
               ╱      ╲
       非零分量≤m    非零分量>m
      且可构成基？      ────→  非基本可行解（第3行）
          ╱    ╲
        x≥0?    否  ────→  基本但不可行（如 B⁻¹b 含负值）
         │是
       BFS
      ╱    ╲
  基变量    基变量
  全>0     有=0  ────→  退化BFS（第2行）
   │
 非退化BFS（第1行）
```
