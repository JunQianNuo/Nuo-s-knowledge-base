# 第21章 答疑 — 次梯度在非光滑 KKT 中的作用

> 问题：**KKT 中次梯度的作用是什么？为什么需要它？**

---

## 作用：在不可微点替身梯度

$$f(x) = |x_1| + x_2, \quad \text{s.t. } x_1 \leq 0,\; x_2 \geq 0$$

$|x_1|$ 在 $x_1 = 0$ 处不可微，$\partial|x_1| = [-1, 1]$。普通的 $\nabla f$ 不存在 → 次梯度顶上。

KKT 驻点条件变成存在性：

$$\exists\, g \in \partial f(x^*) \quad \text{s.t.} \quad g + \mu_1 \nabla g_1 + \mu_2 \nabla g_2 = 0$$

---

## 具体推演

$(g, 1) + \mu_1(1, 0) + \mu_2(0, -1) = (0, 0)$

- 第二分量：$1 - \mu_2 = 0 \Rightarrow \mu_2 = 1$
- 第一分量：$g + \mu_1 = 0 \Rightarrow \mu_1 = -g$

由于 $g \in [-1, 1]$ 且 $\mu_1 \geq 0$ → $\mu_1 \in [0, 1]$。

---

## 关键结论

$\mu_1$ **不唯一**（$\in [0, 1]$），反映 $|x_1|$ 在拐角处的不光滑性：

| $g$ | $\mu_1$ |
|:--|:--|
| 0 | 0 |
| -0.5 | 0.5 |
| -1 | 1 |

> 可微时次梯度退化为单点 $\{\nabla f\}$，$\mu$ 唯一。不可微时次梯度是集合，$\mu$ 是一段范围。
