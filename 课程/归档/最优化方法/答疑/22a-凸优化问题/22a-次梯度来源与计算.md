# 第22a章 答疑 — 次梯度的来源与计算方法

> 问题：**次梯度是怎么来的？怎么算？**

---

## 第一部分：次梯度的来源

### 1.1 可微凸函数的本质特征

对于可微凸函数，凸性等价于切平面永远在函数下方：

$$f(y) \ge f(x) + \nabla f(x)^T(y - x), \quad \forall x, y$$

这不是推论，而是**等价定义**。

### 1.2 但凸性不依赖可微性

$f(x) = |x|$ 在 $x = 0$ 处不可导，但它依然是凸函数（上图是 V 形凸集）。凸性是**几何性质**（上图是凸集），可微性是**分析性质**（梯度存在）。两者不绑定。

那么在不可微点处，"支撑"函数从下方的那个"东西"是什么？

### 1.3 几何推广：支撑超平面

凸函数 $\iff$ 上图 $\text{epi}(f)$ 是凸集。在边界点 $(x, f(x))$ 处，由凸集的支撑超平面定理，存在一个超平面将上图支撑在一侧：

$$\beta = f(x) + g^T(y - x)$$

因为上图在超平面上方，$f(y) \ge f(x) + g^T(y - x)$。**这个 $g$ 就是次梯度。**

### 1.4 $|x|$ 在 $x = 0$ 处的直观

什么样的直线 $y = gx$ 能始终在 $|x|$ 下方？

- $g = 1$：$y = x$，是右边切线，左边也满足 ✓
- $g = -1$：$y = -x$，是左边切线，右边也满足 ✓
- $g = 0$：$y = 0$，始终在下方 ✓
- $g = 0.5$：$y = 0.5x$，$x < 0$ 时跑上面了 ❌

**任何 $g \in [-1, 1]$ 都满足！** 这就是次微分：

$$\partial f(0) = [-1, 1]$$

### 1.5 总结

> 次梯度不是被"发明"的，而是凸函数**本来就有的几何性质**的代数表达——把"存在一个支撑超平面"翻译成了"存在一个向量 $g$ 满足全局下估计不等式"。可微时退化回梯度，不可微时揭示出梯度的"集合化"本质。

## 第二部分：次梯度的计算方法

### 2.1 可微点：直接退化

若 $f$ 在 $x$ 处可微，则 $\partial f(x) = \{\nabla f(x)\}$（单点集）。

### 2.2 基本计算规则

| 规则 | 公式 |
|:---|:---|
| 正数乘 | $\partial(\alpha f)(x) = \alpha \cdot \partial f(x)$，$\alpha > 0$ |
| 加法 | $\partial(f_1 + f_2)(x) = \partial f_1(x) + \partial f_2(x)$（集合 Minkowski 和） |
| 仿射复合 | $\partial f(Ax + b) = A^T \partial f(Ax + b)$ |
| **逐点极大** | $\partial(\max_i f_i)(x) = \text{conv}\{\nabla f_i(x) \mid i \in I(x)\}$，$I(x)$ 为达最大值的指标集 |

### 2.3 常见函数次梯度速查

| 函数 | 可微处 | 不可微处 |
|:---|:---|:---|
| $\vert x \vert$ | $\{\text{sign}(x)\}$ | $x=0$：$[-1, 1]$ |
| $\|x\|_2$ | $\{x/\|x\|_2\}$ | $x=0$：$\{g \mid \|g\|_2 \le 1\}$ |
| $\|x\|_1$ | $\{\text{sign}(x_i)\}$（分量） | $x_i=0$：$[-1,1]$（分量） |
| $\max\{0, x\}$ | $x>0: \{1\}$，$x<0: \{0\}$ | $x=0$：$[0, 1]$ |
| $\max_i f_i(x)$ | 唯一胜出者梯度 | 多个胜出者梯度的凸包 |

### 2.4 手算方法：直接解不等式

回到定义：$g \in \partial f(x) \iff f(y) \ge f(x) + g^T(y-x)$，$\forall y$。

分类讨论 $y$ 的符号，解出 $g$ 的范围。对一元分段线性凸函数，**区间端点 = 左导数和右导数**，次微分 = [左导数, 右导数]。

### 2.5 优化中的应用

无约束极小点条件 $\nabla f(x^*) = 0$ 推广为：

$$\mathbf{0} \in \partial f(x^*)$$

以 $|x|$ 为例，$0 \in [-1, 1] = \partial f(0)$，所以 $x^* = 0$ 是极小点。
