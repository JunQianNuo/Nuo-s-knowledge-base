# 第11章 答疑 — 为什么搜索方向是 $Q$-共轭向量组

> 问题：**为什么说拟牛顿法的搜索方向是 $Q$-共轭向量组？**

> 来源：`11-拟牛顿法-知识梳理.md` 第 161 行

---

## 核心回答

这是**共轭特征定理**——拟牛顿法理论最优美的结果。

### 前提条件

在二次函数 $f(x) = \frac{1}{2}x^T Q x - b^T x$（$Q \succ 0$）上，两个事实自动成立：

**事实 1**：$y^{(k)} = Q s^{(k)}$。代入拟牛顿方程 $H_{k+1} y^{(k)} = s^{(k)}$ 得：

$$H_{k+1} Q s^{(k)} = s^{(k)}$$

即 **$s^{(k)}$ 是 $H_{k+1}Q$ 的特征向量，特征值为 1**。

**事实 2**：精确线搜索 ⇒ $g^{(k+1)T} d^{(k)} = 0$。

### 核心推导（相邻方向）

$$\begin{aligned}
d^{(k+1)T} Q d^{(k)}
&= -g^{(k+1)T} H_{k+1} Q \, d^{(k)} \\
&= -g^{(k+1)T} H_{k+1} Q \left( -\frac{s^{(k)}}{\alpha_k} \right) \\
&= \frac{1}{\alpha_k} g^{(k+1)T} \underbrace{H_{k+1} Q s^{(k)}}_{\text{事实 1：}= s^{(k)}} \\
&= \frac{1}{\alpha_k} g^{(k+1)T} s^{(k)} \\
&= -g^{(k+1)T} d^{(k)} = 0 \quad \text{（事实 2）}
\end{aligned}$$

### 非相邻方向：继承性质

秩2更新（DFP/BFGS）有一个关键性质：如果 $H_k$ 满足了对 $j = 0, \dots, k-1$ 的所有拟牛顿方程，那么 $H_{k+1}$ 不仅满足新方程，也**自动保持所有旧方程**。因此对 $j < k$，同理有 $d^{(k+1)T} Q d^{(j)} = 0$。

### 推理链

```
拟牛顿方程 → H_{k+1}Q s^{(k)} = s^{(k)}
     ↓
 d^{(i)T} Q d^{(j)} ∝ g^{(i)T} d^{(j)}
     ↓                  精确线搜索下 = 0 (j < i)
 d^{(i)T} Q d^{(j)} = 0   ← Q-共轭！
```

### 这事为什么美？

**拟牛顿法从来没有被要求过"你给我造共轭方向"**。它唯一的约束是拟牛顿方程。但在二次函数 + 精确线搜索下，$Q$-共轭性**自己冒出来了**。

这就把拟牛顿法和共轭梯度法焊接到了一起：
- 共轭梯度法：显式用 $\beta_k$ 构造共轭方向
- 拟牛顿法：通过拟牛顿方程**自动地、不自觉地**产生了共轭方向

> **拟牛顿方程 $H_{k+1} Q s = s$ 这个代数关系，加上精确线搜索的正交性，自然推出所有搜索方向 $Q$-共轭。不需要显式构造——拟牛顿方程帮你做了。**
