# 第9章 答疑 — 牛顿法为什么用 Hessian 而不是梯度

> 问题：**牛顿法的方程是 $H_k d_k = -g_k$，为什么方向是由 Hessian 决定的而不是直接沿负梯度走？**

> 来源：`IV-无约束优化.md` 第 145 行

---

## 一句话兜底

> 梯度告诉你**往哪走**，Hessian 告诉你**走多远**。梯度下降只用了"脚下的坡度"，牛顿法还用了"地面的弯曲程度"——所以能直接算出谷底在哪。

---

## Taylor 展开的精度差异

| | 梯度下降 | 牛顿法 |
|------|------|------|
| 模型 | **一阶**：$f(x) \approx f_k + g_k^\top d$ | **二阶**：$f(x) \approx f_k + g_k^\top d + \frac{1}{2}d^\top H_k d$ |
| 模型形状 | 平面（无极小点） | 抛物面（有明确极小点） |
| 方向 | $d = -g_k$（沿最陡坡走） | $H_k d = -g_k$（直接跳到极小点） |
| 步长 | 需单独决定 | 方向和步长**同时**由 $H_k^{-1} g_k$ 决定 |

---

## 从推导看本质

梯度法：对一阶近似 $m_1(x) = f_k + g_k^\top (x - x_k)$ 而言，往负梯度方向走总能下降——但走多远不知道。

牛顿法：对二阶近似 $m_2(x) = f_k + g_k^\top (x - x_k) + \frac{1}{2}(x - x_k)^\top H_k (x - x_k)$，可以直接求驻点：

$$\nabla m_2(x) = g_k + H_k (x - x_k) = 0 \quad \Rightarrow \quad H_k d_k = -g_k$$

Hessian 出现在左边而不是右边——它**缩放和旋转**了梯度方向。$H_k^{-1}$ 在每个方向上分配的步长与该方向的曲率成反比（弯曲越大步越小，越平缓步越大）。

---

## 直观比喻

```
梯度下降：闭着眼睛站在山坡上，只知道脚下往哪边最陡 → 往那边走一步
牛顿法：  睁着眼睛，看到整个山坡的弯曲形状 → 直接看到谷底在哪，一步到位
```

对二次函数：牛顿法一步就到极小点。梯度法要无穷多步 zigzag。这就是二阶信息的威力。
