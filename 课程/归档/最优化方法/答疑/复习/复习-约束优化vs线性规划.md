# 答疑 — 约束优化与线性规划的区别

> 问题：**约束优化问题和线性规划问题有什么区别？为什么不直接用 KKT 解 LP？**

---

## 一、一句话回答

**线性规划是约束优化的一种特例**——就像正方形是矩形的特例。但因为是特例，它有自己一套完全不同的解法。

---

## 二、核心区别

| | 约束优化（一般） | 线性规划（LP） |
|:---|:---|:---|
| 目标函数 | 任意 $f(x)$（可非线、非凸、非光滑） | **必须是线性**：$c^T x$ |
| 约束 | 任意 $h(x)=0$，$g(x) \le 0$ | **必须是线性**：$Ax \le b$，$Ex = d$ |
| 解法 | KKT + 分类讨论 → 候选点 | **单纯形法** / 内点法 → 直接出答案 |
| 最优解位置 | 任何地方（内部、边界、鞍点…） | **一定在顶点**（可行多面体的角上） |
| KKT 的角色 | 必要条件（非凸时需正则性） | 充要条件，且等价于单纯形终止条件 |
| 求解难度 | 一般 NP-hard，凸时才"好解" | 多项式时间，永远可解 |

---

## 三、为什么不直接用 KKT 解 LP？

可以，但杀鸡用牛刀，而且**算不动**。

LP 的 KKT：
$$\nabla f + \sum \mu_i \nabla g_i = c + A^T\mu = 0, \quad \mu \ge 0, \quad \mu_i(A_i x - b_i) = 0$$

这导出的是 $2^p$ 种组合的枚举。$p$ 是约束个数，实际问题动辄成千上万——$2^{10000}$ 宇宙毁灭也算不完。

**单纯形法聪明在哪？** 利用了"最优解一定在顶点"这个几何性质，只在顶点之间跳，每次跳到更优的邻居顶点——不用枚举全体。

---

## 四、一张图理解关系

```
约束优化问题
    ├── 线性规划 (LP)        ← 全是线性的
    ├── 二次规划 (QP)        ← 目标二次，约束线性
    ├── QCQP                 ← 目标二次，约束二次
    ├── SOCP / SDP           ← 锥约束
    └── 一般非线性规划 (NLP)  ← 什么都可以是非线性的
```

LP 是最底层、最特殊、也最"好欺负"的那个——线性性太强，不需要 KKT 那套复杂理论，单纯形表一列就出答案。
