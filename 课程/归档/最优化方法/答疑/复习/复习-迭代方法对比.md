# 答疑 — 约束优化与无约束优化的迭代方法对比

> 问题：**约束优化和无约束优化的迭代方法有什么本质区别？各有哪些方法？**

---

## 一、一句话回答

**无约束方法只管"往哪走、走多远"；约束方法还要管"被拦住怎么办"。** 所有约束优化方法的本质都是——把约束问题**转化**成一系列无约束子问题来解。

---

## 二、核心思路对比

```
无约束迭代：
    当前点 → 算方向 → 定步长 → 走到新点 → 重复
                         ↑
                    全部在 ℝⁿ 里自由移动

约束迭代：
    当前点 → 转化约束 → 用无约束方法 → 走一步 → 处理约束 → 重复
                         ↑
                    四种策略之一（见下）
```

**无约束世界里的统一问题**：方向怎么取？步长怎么定？什么时候停？收敛多快？

**约束世界额外多出来的问题**：怎么不跑出可行域？

---

## 三、方法对照表

| 无约束方法 | 约束对应方法 | 核心思想 |
|:---|:---|:---|
| 梯度下降 $x \leftarrow x - \alpha \nabla f$ | **投影梯度法** $x \leftarrow \Pi_\Omega[x - \alpha \nabla f]$ | 走完拉回 |
| 牛顿法 $x \leftarrow x - H^{-1}\nabla f$ | 无直接推广 | 需解 KKT 系统 |
| — | **拉格朗日乘子法** | 交替追鞍点（$x$ 下降 + $\lambda$ 上升） |
| — | **罚函数法** | 把违规折成惩罚加入目标，$\gamma \to \infty$ |
| — | **增广拉格朗日法** | 拉格朗日 + 罚函数，$\gamma$ 固定 |

---

## 四、四种约束方法的"转化术"

| 方法 | 怎么做 | 优点 | 代价 |
|:---|:---|:---|:---|
| **投影梯度法** | 走完一步后硬拉回可行集 | 严格保证可行性 | 投影必须好算（闭式） |
| **拉格朗日乘子法** | 同时更新 $x$ 和乘子 | 不需投影 | 收敛慢，对初值敏感 |
| **罚函数法** | 加 $\gamma \cdot (\text{违规量})$ 到目标 | 灵活，适用广 | $\gamma \to \infty$ 数值病态 |
| **增广拉格朗日法** | $L_\gamma = f + \lambda^T h + \frac{\gamma}{2}\|h\|^2$ | $\gamma$ 固定 | 子问题需精确解 |

---

## 五、具体迭代格式

```
无约束梯度下降：
    xₖ₊₁ = xₖ - αₖ ∇f(xₖ)
    特点：走完就完，不检查约束

投影梯度法：
    xₖ₊₁ = Π_Ω [ xₖ - αₖ ∇f(xₖ) ]
    特点：走完拉回，永远在 Ω 内

拉格朗日乘子法（等式约束）：
    xₖ₊₁ = xₖ - αₖ [∇f(xₖ) + ∇h(xₖ)ᵀ λₖ]
    λₖ₊₁ = λₖ + βₖ h(xₖ)
    特点：x 下降，λ 上升，交替追鞍点

罚函数法：
    外层：γₖ → ∞（逐渐加大惩罚）
    内层：xₖ₊₁ ≈ argmin [ f(x) + γₖ·‖h(x)‖² ]
    特点：内层是纯无约束问题，外层调 γ
```

---

## 六、一句总结

```
无约束优化 → 自由落体，只管重力方向往下掉
约束优化   → 管道行进，每一步都要问：往这走会不会撞墙？
```
