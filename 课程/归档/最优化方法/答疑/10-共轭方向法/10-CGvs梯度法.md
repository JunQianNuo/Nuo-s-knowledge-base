# 第10章 答疑 — 共轭梯度法与梯度法的异同

> 问题：**共轭梯度法与梯度方法对比有什么同与不同？**

> 来源：`10-共轭方向法-知识梳理.md` §六；`08-梯度方法-知识梳理.md`

---

## 核心回答

### 相同之处

| 共同点 | 说明 |
|--------|------|
| **显式步长** | 都需精确线搜索，公式 $\alpha_k = -\dfrac{g^{(k)T} p^{(k)}}{p^{(k)T} Q p^{(k)}}$ 形式一样 |
| **第一步相同** | CG 第一步 $p^{(0)} = -g^{(0)}$，就是最速下降方向 |
| **一阶信息为主** | 都不需要存储和求逆完整 Hessian |
| **每步计算量** | 均为 $O(n)$ |

### 核心差异

| | 梯度法 | 共轭梯度法 |
|---|---|---|
| **搜索方向** | $d^{(k)} = -g^{(k)}$ | $p^{(k)} = -g^{(k)} + \beta_{k-1} p^{(k-1)}$ |
| **方向关系** | 相邻方向**欧氏正交** | 所有方向 **$Q$-共轭** |
| **"记忆"** | 无记忆 | 有记忆（融合旧方向） |
| **收敛速度** | 线性（可能极慢） | 对二次函数至多 $n$ 步精确收敛 |
| **zigzag** | 严重 | 无（共轭保证不"重复工作"） |
| **子空间** | 每步仅优化一维 | 每步在维数递增的 Krylov 子空间上最优 |

### zigzag 的根源

梯度法每步方向与上一步在**欧氏度量**下正交：$d^{(k+1)T} d^{(k)} = 0$。在狭长椭圆等高线中，正交反而意味着反复横跳。

CG 的方向在 **$Q$ 度量**下"正交"：$p^{(i)T} Q p^{(j)} = 0$。这相当于在 Hessian 定义的弯曲空间下正交——恰好顺着等高线的"主轴方向"走，绝不互相干扰。

### 为什么 CG 能 $n$ 步收敛？

**扩展子空间定理**：CG 每步在一个不断扩张的子空间上求了全局最优解：

$$\begin{aligned}
x^{(1)} &\text{ 在 } \text{span}\{g^{(0)}\} \text{ 上最优} \\
x^{(2)} &\text{ 在 } \text{span}\{g^{(0)}, Qg^{(0)}\} \text{ 上最优} \\
&\vdots \\
x^{(n)} &\text{ 在 } \text{span}\{g^{(0)}, \dots, Q^{n-1}g^{(0)}\} = \mathbb{R}^n \text{ 上最优}
\end{aligned}$$

梯度法没有这个性质——每步只沿一个一维方向往下走。

### 汇总

| | 梯度法 | 共轭梯度法 |
|---|---|---|
| 本质 | 每步沿"最陡方向"，方向间欧氏正交 | 每步沿"$Q$-共轭方向"，方向间 Hessian 度量下正交 |
| 比喻 | 蒙着眼，只靠脚下坡度——峡谷中反复横跳 | 记住了山体弯曲，每步选不重复的新角度下降 |
| 代价 | 每步 $O(n)$ | 每步 $O(n)$（只多了 $\beta$ 的几次内积） |
| 回报 | 线性收敛 | $n$ 步精确收敛（二次函数） |

> **CG = 梯度法 + 一点"记忆"。$\beta_{k-1} p^{(k-1)}$ 这一项值几个内积的计算量，把收敛性质从"无限步"拉到了"至多 $n$ 步"。**
