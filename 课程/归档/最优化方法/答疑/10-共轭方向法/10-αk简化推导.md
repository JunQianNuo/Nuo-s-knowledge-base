# 第10章 答疑 — CG 中 $\alpha_k$ 的简化推导

> 问题：**$\alpha_k = \dfrac{\|g^{(k)}\|^2}{{p^{(k)}}^\top Q p^{(k)}}$ 是怎么从通用精确步长公式简化来的？**

> 来源：`习题库/10-共轭方向法/习题10.10.md` 提示第 2 条

---

## 一句话兜底

> 通用公式 $\alpha_k = -g_k^T p_k / (p_k^T Q p_k)$，CG 中 $p_k = -g_k + \beta_{k-1}p_{k-1}$，而精确线搜索保证 $g_k \perp p_{k-1}$，代入后交叉项消失，分子退化为 $\|g_k\|^2$。

---

## 推导（两步）

### Step 1：通用精确步长公式

对 $f = \frac{1}{2}x^T Q x - b^T x$，沿 $p_k$ 精确线搜索 $\min_\alpha f(x_k + \alpha p_k)$，令导数为零：

$$\phi'(\alpha) = \nabla f(x_k + \alpha p_k)^T p_k = 0 \;\Longrightarrow\; (Q(x_k + \alpha p_k) - b)^T p_k = 0$$

$$(g_k + \alpha Q p_k)^T p_k = 0 \;\Longrightarrow\; \boxed{\alpha_k = -\frac{g_k^T p_k}{p_k^T Q p_k}}$$

### Step 2：利用 CG 结构消去 $g_k^T p_k$

CG 中 $p_k = -g_k + \beta_{k-1} p_{k-1}$。左乘 $g_k^T$：

$$g_k^T p_k = g_k^T(-g_k + \beta_{k-1} p_{k-1}) = -\|g_k\|^2 + \beta_{k-1} \underbrace{g_k^T p_{k-1}}_{=\,0}$$

**为什么 $g_k^T p_{k-1} = 0$？** 精确线搜索沿 $p_{k-1}$ 极小化，新梯度与搜索方向正交：

$$\phi'(\alpha_{k-1}) = \nabla f(x_{k-1} + \alpha_{k-1}p_{k-1})^T p_{k-1} = g_k^T p_{k-1} = 0$$

交叉项消失：

$$g_k^T p_k = -\|g_k\|^2$$

代入通用公式：

$$\boxed{\alpha_k = \frac{\|g_k\|^2}{p_k^T Q p_k}}$$

---

## $\alpha_k$ 与 $\beta_{k-1}$ 的对比

两个公式长得像，但来源完全不同：

| | $\alpha_k$（精确步长） | $\beta_{k-1}$（原始公式） |
|:--|:--|:--|
| 公式 | $\displaystyle -\frac{g_k^T p_k}{p_k^T Q p_k}$ | $\displaystyle \frac{g_k^T Q p_{k-1}}{p_{k-1}^T Q p_{k-1}}$ |
| **来源** | $\min_\alpha f(x_k + \alpha p_k)$ 的一阶条件 | $p_k^T Q p_{k-1} = 0$ 的 $Q$-共轭约束 |
| CG 简化 | $\dfrac{\|g_k\|^2}{p_k^T Q p_k}$ ✅ | 仍需 $Q$（见 FR 公式绕开） |
| 分子 | $g_k$ 与**当前**方向 | $g_k$ 与 $Q$ 乘**上一步**方向 |

分母都是 $p^T Q p$ 是巧合——因为两者都涉及"沿某方向的二次曲率"。
