## 题目

刚性双原子分子经图示过程 $abca$（P-V图），求各分过程的 $A$、$\Delta E$、$Q$ 及整个过程 $abca$ 气体对外作的净功。

![[课程/大学物理/课件/MD/images/4945b96843b004ba376fc624c0776c3229ee0a8366b7fd3478e934328bbbcca7.jpg]]

> [!hint]- 点击展开提示
> 刚性双原子分子 $i = 5$，$C_V = \frac{5}{2}R$。净功 = 三角形 $abc$ 的面积。

> [!solution]- 点击展开详细解析
> **过程 $ab$（等压膨胀）：**
> $$A_{ab} = \frac{1}{2}(p_b + p_a)(V_b - V_a) = 405.2\;\mathrm{J}$$
> $$\Delta E_{ab} = \frac{5}{2}(p_b V_b - p_a V_a) = -506.5\;\mathrm{J}$$
> $$Q_{ab} = \Delta E_{ab} + A_{ab} = -101.3\;\mathrm{J}$$
>
> **过程 $bc$（等压压缩）：**
> $$A_{bc} = p_b(V_c - V_b) = -202.6\;\mathrm{J}$$
> $$\Delta E_{bc} = \frac{5}{2}(p_c V_c - p_b V_b) = -506.5\;\mathrm{J}$$
> $$Q_{bc} = \Delta E_{bc} + A_{bc} = -709.1\;\mathrm{J}$$
>
> **过程 $ca$（等体升压）：**
> $$A_{ca} = 0$$
> $$\Delta E_{ca} = \frac{5}{2}(p_a V_a - p_c V_c) = 1013\;\mathrm{J}$$
> $$Q_{ca} = \Delta E_{ca} + A_{ca} = 1013\;\mathrm{J}$$
>
> **整个循环 $abca$ 的净功：**
> $$A = A_{ab} + A_{bc} + A_{ca} = 405.2 - 202.6 + 0 = 202.6\;\mathrm{J}$$
>
> 或：$A = \Delta abc$ 的面积 $= \frac{1}{2}(4-2)(3-1) \times 1.013 \times 10^2 = 202.6\;\mathrm{J}$
>
> **答案：** 净功 $A = 202.6\;\mathrm{J}$。
>
> **点评：** 熟记刚性双原子分子的 $C_V = \frac{5}{2}R$，以及各过程中 $\Delta E = \nu C_V \Delta T$ 的计算。
>
