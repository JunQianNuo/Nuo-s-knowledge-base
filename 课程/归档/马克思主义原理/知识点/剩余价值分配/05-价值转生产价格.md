# 价值转化为生产价格

## 定义

利润转化为平均利润后，**价值就转化为生产价格**。生产价格 = 生产成本 + 平均利润，是商品价值的**转化形式**。

## 核心要点

1. **生产成本** = 生产中实际耗费的 c + v（不变资本 + 可变资本）
2. **生产价格** = 生产成本 + 平均利润
3. **价值规律作用形式的变化**：商品不再以价值而是以**生产价格**为基础进行交换，市场价格以生产价格为中心波动。
4. 从价值到生产价格的转化，是随着资本主义大工业的出现和发展完成的，反映了从小商品生产到资本主义商品生产的历史发展过程。

## 常见考法

- **选择/判断**：生产价格 = 生产成本 + 平均利润；价值规律作用形式的变化（以生产价格为中心）
- **简答**：商品价值如何转化为生产价格？
