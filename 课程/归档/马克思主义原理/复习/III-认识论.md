# III. 认识论

> 一句说清：辩证唯物主义认识论回答"人能否认识世界、如何认识世界"——实践是认识的基础，认识是一个从感性到理性、从实践到认识再到实践的辩证过程，真理是客观的、绝对的又是相对的。

---

## 一、核心定义速查

### 1.1 认识的本质

| 派别 | 观点 |
|------|------|
| **辩证唯物主义认识论** | 认识是主体在实践基础上对客体的**能动反映** |
| **旧唯物主义认识论** | 认识是主体对客体的消极、被动、直观的反映 |
| **唯心主义认识论** | 认识是先于物质、先于经验的（先验论） |

> 关键区分：辩证唯物主义强调了实践的桥梁作用 + 认识的能动性和创造性，旧唯物主义忽视了这两点。

### 1.2 实践与认识的关系

| 方面 | 内容 |
|------|------|
| **实践决定认识** | 实践是认识的来源、动力、目的、检验标准 |
| **认识反作用于实践** | 正确的认识指导实践成功；错误的认识导致实践失败 |

> 四个"是"的记忆法："来动力标"——来源、动力、目的、标准。

### 1.3 感性认识与理性认识

| 对比 | 感性认识 | 理性认识 |
|------|----------|----------|
| **反映内容** | 事物的现象、外部联系 | 事物的本质、内部联系 |
| **形式** | 感觉、知觉、表象 | 概念、判断、推理 |
| **特点** | 直接性、具体性 | 间接性、抽象性 |
| **关系** | 理性认识依赖于感性认识 | 感性认识有待于发展到理性认识 |

> 辩证关系：感性认识是理性认识的基础，理性认识是感性认识的升华。二者在实践基础上统一。

### 1.4 认识运动的基本规律

**两次飞跃**：
1. **第一次飞跃**：从感性认识到理性认识（实践→认识）
2. **第二次飞跃**：从理性认识到实践（认识→实践，更有意义）

> 认识运动的总规律：实践→认识→再实践→再认识……循环往复以至无穷。

## 二、核心原理：实践与真理

### 2.1 实践的基本特征 ⭐⭐⭐（24年简答真题）

| 特征 | 含义 |
|------|------|
| **客观实在性** | 受客观条件制约，能把脑中的变成现实的（实践本质的特征） |
| **自觉能动性** | 实践受意识指导，有目的有计划 |
| **社会历史性** | 不同社会和历史下的实践不同 |

### 2.2 实践对认识的决定作用 ⭐⭐⭐（23年简答真题）

1. 实践是认识的**来源**
2. 实践是认识发展的**动力**
3. 实践是认识的**目的**
4. 实践是检验认识真理性的**唯一标准**

> 记忆口诀：来源、动力、目的、标准——"来动目标准"。

### 2.3 感性认识与理性认识的辩证统一 ⭐

1. 理性认识**依赖于**感性认识
2. 感性认识**有待于发展和深化为**理性认识
3. 二者**相互渗透、相互包含**

> 一句话：感性是"看到什么"，理性是"理解了什么"——不是对错关系，是深浅关系。

### 2.4 真理的属性 ⭐

| 属性 | 含义 | 关键点 |
|------|------|--------|
| **客观性**（本质属性） | 真理的内容客观，检验标准客观 | 反对主观真理论 |
| **绝对性** | 真理包含不依赖于主体的客观内容 | 承认客观真理 = 承认绝对真理 |
| **相对性** | 任何真理都在一定条件下、范围、程度上正确 | 真理有待深化和扩展 |

> 辩证关系：相互依存、相互包含、从相对走向绝对。片面夸大绝对性 → 教条主义；片面夸大相对性 → 相对主义（"过时论"）。

### 2.5 真理与谬误 ⭐

| 方面 | 内容 |
|------|------|
| **对立** | 真理与谬误有原则界限，不能混淆 |
| **统一** | 二者相比较而存在、相斗争而发展；在一定条件下相互转化 |

> 真理超越适用范围就转化为谬误；谬误被正确认识和纠正就可以通向真理。

### 2.3 实践是检验真理的唯一标准

| 原因 | 说明 |
|------|------|
| 真理的本性 | 主观与客观相符合——纯主观范畴或纯客观范畴都不能充当标准 |
| 实践的特点 | 实践是**主观见之于客观**的活动，能把主观认识与客观实际联系起来 |

> 实践标准既是确定的（只有实践才能最终检验），又是不确定的（实践是历史的、发展的，一定历史阶段的实践有其局限性）。

## 三、典型问答

> 对应复习纲要 Q15-20

**Q15：认识的本质**
- 辩证唯物主义：认识是主体在实践基础上对客体的能动反映
- 与旧唯物主义的区别：旧唯物主义缺乏实践观点和辩证观点

**Q16：实践和认识的关系**
- 实践是认识的基础（来源、动力、目的、标准）
- 认识对实践有指导作用

**Q17：认识运动的基本规律**
- 两次飞跃：感性→理性（第一次）；理性→实践（第二次）
- 感性认识和理性认识辩证统一

**Q18：真理的属性**
- 客观性：内容客观
- 绝对性：包含不依赖于主体的内容
- 相对性：受条件、范围、程度限制
- 三者统一

**Q19：真理与谬误**
- 有原则界限，不能混淆
- 相比较而存在，相斗争而发展
- 在一定条件下相互转化

**Q20：实践是检验真理的唯一标准**
- 由真理的本性决定（主观符合客观）
- 由实践的特点决定（连接主客观的桥梁）
- 实践标准是确定性和不确定性的统一

## 四、易错点

> [!warning] 感性认识和理性认识不可分割
> 没有纯粹的感性认识（已有理性渗透），也没有纯粹的理性认识（以感性为基础）。反对经验论（只重感性）和唯理论（只重理性）。

> [!warning] 真理有阶级性吗？
> 真理的内容是客观的，没有阶级性。但人们对真理的认识和运用可能受阶级立场影响。

> [!warning] 相对真理 ≠ 错误
> 相对真理是在一定条件下对事物的正确认识，只是不完全、不充分。错误是与客观实际不符合的认识。二者本质不同。

> [!warning] 实践标准的"不确定性"
> 这不是说实践不可靠，而是说实践是历史发展的，某一阶段的具体实践不能完全证实或驳倒一切认识。这是辩证的态度，不是怀疑论。

> [!warning] 旧唯物主义在认识论上的缺陷
> 抛弃了实践和辩证法，把认识看作是消极的、被动的反映。马克思把实践引入认识论，把辩证法应用于反映论。
