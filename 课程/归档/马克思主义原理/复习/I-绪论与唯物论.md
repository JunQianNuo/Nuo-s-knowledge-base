# I. 绪论与唯物论

> 一句说清：马克思主义是科学的世界观和方法论，唯物论回答"世界是什么"——世界是物质的，物质是运动的，意识是物质的产物且具有能动作用。

---

## 一、核心定义速查

### 1.1 马克思主义

| 概念 | 定义 | 关键点 |
|------|------|--------|
| **马克思主义** | 由马克思、恩格斯创立，后继者发展的科学理论体系 | 关于无产阶级和人类解放的科学 |
| **马克思主义基本原理** | 马克思主义立场、观点、方法的基本概括 | 科学性、革命性、实践性、人民性、发展性 |
| **三大组成部分** | 马克思主义哲学、政治经济学、科学社会主义 | 哲学是基础，政治经济学是主体，科学社会主义是归宿 |

> 一句话：马克思主义 = 科学的世界观（辩证唯物主义 + 历史唯物主义）+ 资本主义批判（政治经济学）+ 人类解放道路（科学社会主义）。

### 1.2 哲学基本问题

| 方面 | 内容 | 两大派别 |
|------|------|----------|
| **第一方面（本体论）** | 思维和存在何者为第一性？ | 唯物主义 vs 唯心主义 |
| **第二方面（认识论）** | 思维能否认识存在？（同一性问题） | 可知论 vs 不可知论 |

> 社会历史观的基本问题：社会存在与社会意识何者为第一性 → 历史唯物主义 vs 历史唯心主义。

### 1.3 物质

**列宁的物质定义**：物质是标志客观实在的哲学范畴，这种客观实在是人通过感觉感知的，它不依赖于我们的感觉而存在，为我们的感觉所复写、摄影、反映。

| 要点 | 说明 |
|------|------|
| 物质是**哲学范畴** | 不等于具体的物质形态或结构 |
| **客观实在性**是唯一特性 | 不依赖于人的意识 |
| 物质是**可认识的** | 反对不可知论 |

> 列宁定义的意义：① 坚持了唯物主义一元论，反对唯心主义和二元论；② 坚持了可知论，反对不可知论；③ 对物质世界的多样性做了最高哲学概括。

### 1.4 物质与运动

| 概念 | 含义 | 特性 |
|------|------|------|
| **运动** | 物质的根本属性和存在方式 | 绝对性、无条件性 |
| **静止** | 物质运动在一定条件下的稳定状态 | 相对性、有条件性（空间位置和性质未变） |
| **时间** | 物质运动的持续性、顺序性 | 一维性（一去不复返） |
| **空间** | 物质运动的广延性、伸张性 | 三维性 |

> [!important] 关键关系
> - **物质与运动不可分**：物质是运动的主体，运动是物质的属性。脱离运动的物质 = 形而上学；脱离物质的运动 = 唯心主义。
> - **运动与静止**：动中有静、静中有动。否认运动 = 形而上学；否认静止 = 相对主义诡辩论。
> - **时空与物质运动不可分**：时空是物质运动的存在形式。

### 1.5 意识

| 方面 | 内容 |
|------|------|
| **起源** | 自然界长期发展的产物 + 社会历史发展的产物（劳动） |
| **本质** | 人脑的机能；客观世界的主观映像 |
| **作用** | 意识具有能动作用（目的性、计划性、创造性、调控性） |

> 意识是物质世界长期发展的产物，是人脑的机能，是客观世界的主观映像。意识具有能动作用，但意识的能动作用受客观规律制约。

## 二、核心原理

### 2.1 世界的物质统一性原理 ⭐

世界是统一的物质世界，物质世界是多样的统一。这是**马克思主义哲学的基石**。

> 自然界是物质的，人类社会本质上也是生产实践基础上形成的物质体系。世界的物质统一性是多样性的统一。

### 2.2 马克思主义的物质范畴理论意义 ⭐

1. 坚持了**唯物主义一元论**，同唯心主义和二元论划清界限
2. 坚持了**能动的反映论和可知论**，批判了不可知论
3. 体现了**唯物论和辩证法的统一**，克服了形而上学唯物主义的缺陷
4. 体现了**唯物主义自然观与历史观的统一**，为彻底的唯物主义奠定理论基础

### 2.3 物质对意识的决定作用 ⭐

表现在意识的**起源**和**本质**上：
1. 从起源看：意识是自然界长期发展的产物
2. 从本质看：意识是人脑的机能和属性，是客观世界的主观映像

### 2.4 意识对物质的能动作用 ⭐⭐⭐（23年简答真题）

1. 意识具有**目的性和计划性**
2. 意识具有**创造性**
3. 意识具有**指导实践改造客观世界**的作用
4. 意识具有**调控人的行为和生理活动**的作用

### 2.5 主观能动性与客观规律性的辩证统一 ⭐

| 方面 | 内容 |
|------|------|
| **客观规律性** | 规律是客观的，不以人的意志为转移 |
| **主观能动性** | 人有意识、有目的地认识世界和改造世界的能力 |
| **辩证关系** | 尊重客观规律是发挥主观能动性的前提；发挥主观能动性是认识和利用客观规律的条件 |

> 正确发挥主观能动性的三个条件：从实际出发（前提）、实践（根本途径）、一定的物质条件和手段。

### 2.6 人工智能无法取代人类智能 ⭐

1. AI 只模拟理性智能，不具备情感、信念、意志
2. AI 不具备人类的社会属性
3. AI 难以完全理解自然语言的真实意义
4. AI 只能获得可化约为数字信号的内容

## 三、典型问答

> 对应复习纲要 Q1-7

**Q1：什么是马克思主义和马克思主义基本原理？**
- 马克思主义是由马克思、恩格斯创立并为后继者不断发展的科学理论体系
- 马克思主义基本原理是马克思主义立场、观点、方法的基本概括，是马克思主义科学理论体系的核心内容

**Q2：马克思主义的特征**
- 科学性：以事实为依据，以规律为对象
- 革命性：彻底的批判精神和鲜明的政治立场
- 实践性：从实践中来，到实践中去
- 人民性：植根于人民，服务于人民
- 发展性：与时俱进的理论品质

**Q3：哲学基本问题**
- 第一方面：思维和存在何者为第一性 → 唯物主义 vs 唯心主义
- 第二方面：思维能否正确认识存在 → 可知论 vs 不可知论
- 社会历史观基本问题：社会存在与社会意识的关系 → 历史唯物主义 vs 历史唯心主义

**Q4：列宁物质定义及意义**
- 定义核心：客观实在性
- 意义：坚持唯物主义；坚持可知论；做出最高哲学概括

**Q5：物质、运动、静止、时空**
- 物质是标志客观实在的哲学范畴
- 运动是物质的根本属性（绝对）
- 静止是运动的特殊状态（相对）
- 时空是物质运动的存在形式

**Q6：意识的涵义、本质和作用**
- 起源：自然界长期发展 + 社会劳动
- 本质：人脑的机能 + 客观世界的主观映像
- 作用：能动作用（目的、计划、创造、调控）

**Q7：意识能动作用与客观规律性**
- 尊重客观规律是前提
- 发挥主观能动性是条件
- 将二者统一于实践中

## 四、易错点

> [!warning] 物质 ≠ 具体物质形态
> 列宁的物质定义是哲学范畴，不能等同于物理学的"原子"、"粒子"等具体形态。

> [!warning] 静止是相对的不是绝对的
> 运动是绝对的无条件的，静止是相对的有条件的。割裂二者会导致形而上学（否认运动）或相对主义诡辩论（否认静止）。

> [!warning] 时空与物质运动不可分割
> 牛顿的"绝对时空观"认为时空可以脱离物质独立存在——这是形而上学观点。

> [!warning] 意识的能动作用受限
> 意识能反作用于物质，但不能决定物质。夸大意识能动作用 → 唯心主义；否认意识能动作用 → 机械唯物主义。

> [!warning] 物质决定意识 vs 社会存在决定社会意识
> 前者是唯物论层面，后者是历史唯物主义层面。二者一脉相承。
