# 导论

## 一、什么是马克思主义

- 三个基本组成部分：**马克思主义哲学、马克思主义政治经济学、科学社会主义**
- 马克思主义基本原理体现**科学性**和**革命性**的统一

## 二、马克思主义的创立与发展

- 三大直接理论来源：**德国古典哲学、英国古典政治经济学、英法空想社会主义**
- 三大自然科学前提：**细胞学说、能量守恒与转化定律、生物进化论**
- 马克思两大发现：**唯物史观**和**剩余价值学说**

## 三、马克思主义的基本特征

四大特征：**科学性、人民性、实践性、发展性**（后三者属革命性）
1. 科学的理论：正确反映自然、社会和人类思维发展的本质和规律
2. 人民的理论：人民性是**本质属性**，人民至上是**政治立场**
3. 实践的理论：从实践中来、到实践中去，在实践中检验和发展
4. 发展的理论：与时俱进的**理论品质**

## 四、马克思主义的当代价值 ⭐

1. 观察当代世界变化的**认识工具**
2. 指引当代中国发展的**行动指南**
3. 引领人类社会进步的**科学真理**

## 五、自觉学习和运用马克思主义

大学生学习马克思主义理论 ⭐：
1. 掌握**基本立场观点方法**
2. 掌握**中国化时代化的理论成果**
3. 坚持理论联系实际的**马克思主义学风**
4. 自觉**内化于心、外化于行**

# 世界的物质性及发展规律（辩证唯物主义）

> 辩证法回答的核心问题：世界的状况是怎样的问题

## 一、世界的多样性与物质统一性（唯物论）

### 哲学基本问题

- 哲学 = 系统化理论化的世界观
- **两大基本问题**：
  - 物质和意识谁为本原（第一性）→ 唯物主义 vs 唯心主义
  - 物质和意识是否具有同一性 → 可知论 vs 不可知论
- 世界怎样存在：形而上学（孤立静止）vs 辩证法（联系发展矛盾）

### 物质的范畴

- **列宁物质定义**：物质是标志客观实在的哲学范畴，不依赖于感觉而存在，为感觉所复写、摄影、反映
- **意识定义**：人脑的机能和属性，是物质世界的主观映像

### 物质的存在方式

- 运动是物质的**根本属性**和存在方式
- 物质和运动不可分割；运动是绝对的，静止是相对的
- 时间和空间是运动着的物质的基本存在形式

### 物质世界的二重化

- 自然界 ⇄ 人类社会（分化和统一的关键是**人的实践活动**）
- 客观世界 ⇄ 主观世界

### 马克思主义物质范畴的理论意义 ⭐（四条）

1. 坚持**唯物主义一元论**，同唯心主义一元论和二元论划清界限
2. 坚持**能动的反映论**和**可知论**，批判不可知论
3. 体现**唯物论和辩证法的统一**，克服形而上学唯物主义缺陷
4. 体现**唯物主义自然观与历史观的统一**，奠定彻底唯物主义基础

### 物质对意识决定作用的表现 ⭐

1. 从意识起源看：意识是自然界长期发展的产物
2. 从意识本质看：意识是人脑的机能和属性，是客观世界的主观映象

### 意识对物质能动作用的表现 ⭐⭐⭐（23 简答）

1. 意识具有**目的性和计划性**
2. 意识具有**创造性**
3. 意识具有**指导实践改造客观世界**的作用
4. 意识具有**调控人的行为和生理活动**的作用

### 主观能动性和客观规律性的辩证统一 ⭐

- 尊重客观规律是正确发挥主观能动性的**前提**
- 只有充分发挥主观能动性，才能正确**认识和利用**客观规律
- 正确发挥条件：从实际出发（前提）→ 实践（根本途径）→ 一定物质条件和手段

### 人工智能无法取代人类智能 ⭐

1. 人类意识是知情意的统一体，AI 只模拟理性智能
2. **社会性**是意识的本质属性，AI 不具备
3. AI 难以理解自然语言真实意义
4. 人脑中有许多无法被化约为数字信号的内容

### 世界的物质统一性 ⭐（马克思主义哲学基石）

1. 世界统一于**物质性**，意识统一于物质
2. 自然界是物质的，人类社会本质上是**实践**基础上的物质体系
3. 物质统一性是**多样性的统一**

## 二、事物的普遍联系和变化发展（唯物辩证法）

### 总体框架

- **两大总特征**：联系、发展
- **五对基本范畴**：内容与形式、本质与现象、原因与结果、必然与偶然、现实与可能
- **三大规律**：对立统一（根本规律/内在动力）、量变质变（渐进性飞跃性统一）、否定之否定（前进性曲折性统一）

### 联系的特点 ⭐

1. **客观性**——事物本身固有的，不以意志为转移
2. **普遍性**——事物内部、事物之间、整个世界相互联系
3. **多样性**——联系形式多样
4. **条件性**——条件支持或制约发展，可改变但须尊重客观规律

### 新事物与旧事物

- **新事物**：合乎历史前进方向、具有远大前途
- **旧事物**：丧失历史必然性、日趋灭亡
- 新事物必然战胜旧事物：新结构适应环境 + 对旧事物的扬弃

### 对立统一规律（根本规律）

实质和核心；提供根本方法——**矛盾分析法**

#### 矛盾的同一性和斗争性 ⭐（矛盾的基本属性）

| 属性 | 含义 | 特点 | 作用 |
|------|------|------|------|
| 同一性 | 相互依存、相互贯通 | 有条件的、相对的 | 存在发展前提、吸收有利因素、规定转化趋势 |
| 斗争性 | 相互排斥、相互分离 | 无条件的、绝对的 | 促进力量变化、推动矛盾体过渡 |

二者**相互联结、相辅相成**。

#### 矛盾的普遍性和特殊性（矛盾问题的精髓）

- **普遍性**（共性，无条件绝对）：矛盾存在于一切事物及其发展过程的始终
- **特殊性**（个性，有条件相对）：具体矛盾各有特点
- **关系**：共性寓于个性之中，无离开个性的共性，也无离开共性的个性

#### 矛盾的不平衡发展原理

- **主要矛盾**：支配地位、决定作用
- **次要矛盾**：服从地位
- 事物的性质由**主要矛盾的主要方面**决定
- 方法论：**"两点论"和"重点论"的统一**

### 量变质变规律

- **质**：事物区别于他物的内在规定性（认识质是起点）
- **量**：规模、程度、速度等数量规定性（认识量是深化和精确化）
- **度**：保持质的稳定性的数量界限，两端叫**关节点/临界点**

#### 量变和质变的辩证关系 ⭐

1. 量变是质变的**必要准备**
2. 质变是量变的**必然结果**
3. 量变和质变**相互渗透**（交替循环）
→ 事物发展的**渐进性和飞跃性的统一**

### 否定之否定规律

#### 唯物辩证法的否定观 ⭐（四条）

1. 否定是**事物的自我否定、自我发展**（内部矛盾运动）
2. 否定是**事物发展的环节**（旧质→新质飞跃）
3. 否定是**新旧事物联系的环节**（新孕育于旧）
4. 辩证否定的实质是**"扬弃"**（既批判又继承，既克服又保留）

#### 辩证否定过程：肯定 → 否定 → 否定之否定（两次否定、三个阶段）

→ 揭示事物发展的**前进性和曲折性的统一**

## 三、唯物辩证法是认识世界和改造世界的根本方法

### 本质特征和认识功能

- 唯物辩证法本质上是**批判的和革命的**
- 包括客观辩证法与主观辩证法，体现唯物主义、辩证法、认识论的统一
- 是科学的世界观 + 认识世界改造世界的**基本方法论**

### 增强思维能力（六种）

辩证思维、历史思维、系统思维、战略思维、底线思维、创新思维

### 如何提高辩证思维能力

1. 运用对立统一规律，掌握辩证逻辑思维方法
2. 客观地、联系地、发展地、全面地、系统地观察事物
3. 善于综合运用多种思想方法和工作方法

# 实践与认识及其发展规律（认识论）

> 实践性是马克思主义区别于其他理论的**根本特征**；实践的观点是马克思主义的基本观点

## 一、实践与认识

### 科学实践观的意义 ⭐

1. 克服旧唯物主义缺陷 → 为**辩证唯物主义**奠定基础
2. 揭示实践对认识的决定作用 → 为**能动的革命的反映论**奠定基础
3. 揭示社会生活的实践本质 → 为**唯物史观**奠定基础
4. 为认识世界改造世界提供基本**思想方法和工作方法**

### 实践的本质

实践是人类能动的改造世界的社会性的物质活动

### 实践的基本特征 ⭐⭐⭐（24 简答）

1. **客观实在性**（本质特征）——受客观条件制约，把观念变为现实
2. **自觉能动性**——受意识指导
3. **社会历史性**——不同社会历史阶段的实践不同

### 实践的基本结构 ⭐

- **实践主体**：具有主体能力、从事现实社会实践的人
- **实践客体**：实践活动所指向的对象
- **实践中介**：工具、手段及运用方法
- 主客体关系：实践关系（最根本）、认识关系、价值关系
- 双向运动：主体客体化 ⇄ 客体主体化

### 实践的形式

1. **物质生产实践**（最基本的实践活动 / 劳动）
2. **社会政治实践**
3. **科学文化实践**

### 实践对认识的决定作用 ⭐⭐⭐（23 简答）

1. 实践是认识的**来源**
2. 实践是认识发展的**动力**
3. 实践是认识的**目的**
4. 实践是检验认识真理性的**唯一标准**

### 认识的本质与过程

- 唯心主义：先验论（主观自生 or 客观精神产物）
- 旧唯物主义：直观反映论
- **辩证唯物主义：能动反映论**（引入实践 + 应用辩证法）
- 认识本质：主体在实践基础上对客体的能动反映
- 认识具有**反映特性**和**创造特性**（不可分割）

#### 感性认识与理性认识

| | 感性认识 | 理性认识 |
|--|---------|---------|
| 阶段 | 初级阶段 | 高级阶段 |
| 对象 | 现象、外部联系 | 本质、内部联系、规律 |
| 特点 | 直接性、具体性 | 间接性、抽象性 |
| 形式 | 感觉 → 知觉 → 表象 | 概念 → 判断 → 推理 |

- 二者是**深浅关系**，不是对错关系
- 片面夸大感性 → 经验主义；片面夸大理性 → 教条主义

#### 认识过程的两次飞跃

- **第一次飞跃**（实践→认识）：感性认识 → 理性认识
  - 条件：丰富感性材料 + 理性思考加工（去粗取精、去伪存真、由此及彼、由表及里）
- **第二次飞跃**（认识→实践）：理性认识 → 实践（**更为重要**）
  - 认识世界是为了改造世界；认识的真理性只有在实践中才能检验

### 感性认识和理性认识的辩证统一关系 ⭐

1. 理性认识**依赖于**感性认识
2. 感性认识**有待于发展和深化为**理性认识
3. 二者**相互渗透、相互包含**

### 认识过程中的影响因素

- **理性因素**（理性直观、理性思维）→ 指导、解释、预见作用
- **非理性因素**（情感、意志、联想、想象、灵感）→ 激活、驱动、控制作用

## 二、真理与价值

### 真理概念

真理是标志主观与客观相符合的哲学范畴，是对客观事物及其规律的**正确反映**。形式主观，内容和标准客观。真理内容一元、形式多元。

### 真理的三种属性 ⭐

1. **客观性**（本质属性）：内容包含不依赖于人的客观内容
2. **绝对性**：主客观统一的确定性和发展的无限性
3. **相对性**：一定条件下正确认识总是有限度的、不完善的
4. 二者辩证统一：相互依存、相互包含、从相对走向绝对
   - 片面夸大绝对性 → 绝对主义/教条主义
   - 片面夸大相对性 → 相对主义/"过时论"

### 真理与谬误的对立统一 ⭐

1. 相互对立
2. 对立是相对的，在一定条件下**相互转化**
3. 真理与谬误相比较而存在、相斗争而发展

### 实践是检验真理的唯一标准 ⭐

由真理的本性和实践的特点决定：
1. 真理本性要求标准须**连接主客观**→ 只有实践有此功能
2. 实践具有**直接现实性**（主要根据）
3. 逻辑证明是补充，但不能取代实践标准

### 实践标准的确定性与不确定性

- **确定性**（绝对性）：唯一性、归根到底性、最终性
- **不确定性**（相对性）：受主客观条件制约、受历史条件限制

### 价值

价值是反映主体和客体之间意义关系的哲学范畴

### 价值的基本特性 ⭐

1. **主体性**——以主体为中心
2. **客观性**——一定条件下不依赖于主观意识
3. **多维性**——同一客体对不同主体需要产生不同价值
4. **社会历史性**——主体和客体的不断变化决定

### 价值评价的特点 ⭐

1. 以主客体之间的**价值关系**为认识对象
2. 评价结果与评价主体直接相关
3. 正确与否依赖对客体状况和主体需要的认识
4. 有科学与非科学之别

### 实践的两种尺度

- **真理尺度**：必须遵循正确反映客观规律的真理（规律，该怎么做）
- **价值尺度**：按照自己的需要去认识改造世界（目的，想怎么做）
- 任何成功实践都是**真理尺度和价值尺度的统一** = **合规律性和合目的性的统一**

### 真理与价值在实践中的辩证统一 ⭐

1. 二者紧密联系、不可分割
2. 价值尺度必须以真理为前提
3. 人类内在需要（价值尺度）推动发现新真理

## 三、认识世界和改造世界

### 认识世界和改造世界的辩证关系 ⭐

1. 二者相互依赖、相互制约
2. 认识世界有助于改造世界（正确认识是有效改造的前提）
3. 只有在改造世界中才能深化对世界的认识

### 一切从实际出发，实事求是

- 一切从实际出发是马克思主义认识论的**根本要求**
- 实事求是是中国共产党思想路线的**核心**

### 理论创新与实践创新的关系 ⭐

1. 实践创新为理论创新提供不竭的**动力源泉**
2. 理论创新为实践创新提供科学的**行动指南**
3. 二者**相互促进、辩证统一**

# 人类社会及其发展规律（唯物史观）

## 社会基本矛盾

生产力与生产关系的矛盾 + 经济基础与上层建筑的矛盾

## 一、人类社会的存在与发展

### 社会历史观的基本问题

社会存在（物质）与社会意识（意识）的关系 → 区分唯物史观和唯心史观

### 生产方式是社会历史发展的决定力量 ⭐

1. 人类社会赖以存在和发展的**基础**和**首要前提**
2. 决定社会的**结构、性质和面貌**，制约全部社会生活
3. 决定社会**形态从低级向高级更替**

### 社会存在

= 自然地理环境 + 人口因素 + **物质生产方式**（决定力量）
- 生产方式 = 生产力 + 生产关系

### 社会意识

社会存在的反映，社会生活的精神方面
- 按主体：个体意识 / 群体意识
- 按层次：社会心理（低层） / 社会意识形式（高层）
  - **意识形态**（观念上层建筑）：与经济、阶级有关，政治法律思想为核心
  - **非意识形态**：与经济、阶级无关

### 社会存在与社会意识的辩证关系 ⭐

**社会存在决定社会意识**：
1. 社会意识是社会存在的反映
2. 社会意识是物质交往的产物
3. 社会意识是具体的、历史的

**社会意识反作用于社会存在**（相对独立性的突出表现）：
1. 不完全同步性和不平衡性
2. 内部各种形式相互影响且具历史继承性
3. **能动的反作用**（推动或阻碍）

### 生产力与生产关系的矛盾运动及规律

#### 构成

- **生产力** = 劳动资料（最重要的是生产工具）+ 劳动对象 + **劳动者**（最活跃因素）
- **生产关系** = 生产资料**所有制**（最基本决定性的）+ 经济关系 + 分配关系
- 生产力是人与自然的关系；生产关系是人与人的关系

#### 生产力和生产关系的关系 ⭐

1. 生产力**决定**生产关系
2. 生产关系对生产力有**能动的反作用**（适合→推动 / 不适合→阻碍）
3. 二者相互作用构成矛盾运动
4. **生产关系一定要适合生产力状况的规律** = 人类社会发展的基本规律

### 经济基础与上层建筑的矛盾运动及规律

- **经济基础** = 由生产力决定的生产关系的总和
- **上层建筑** = 政治上层建筑（主导地位，国家政权为核心）+ 观念上层建筑（意识形态）

#### 经济基础和上层建筑的辩证统一 ⭐

1. 经济基础**决定**上层建筑
2. 上层建筑对经济基础具有**反作用**
3. 二者相互作用构成矛盾运动
4. 上层建筑一定要适合经济基础状况的规律

### 交往及其作用 ⭐

1. 促进生产力发展
2. 促进社会关系进步
3. 促进文化发展与传播
4. 促进人的全面发展

# 资本主义的本质及规律（政治经济学）

## 一、商品经济和价值规律（劳动价值论）

### 商品经济的形成

- **自然经济**：自给自足，生产目的不是交换
- **商品经济**：以**交换为目的**的经济形式
  - 简单商品经济（私有制 + 个体劳动）
  - 发达商品经济（私有制 + 雇佣劳动）

#### 商品经济产生的历史条件

①存在**社会分工** ②**生产资料和劳动产品属于不同的所有者**

### 商品的二因素

| 因素 | 定义 | 属性 | 说明 |
|------|------|------|------|
| 使用价值 | 满足某种需要的**有用性** | 自然属性 | 交换价值的物质承担者；一切劳动产品共有 |
| 价值 | 凝结的**无差别一般人类劳动** | 社会属性 | 交换价值的基础；体现生产者之间的社会关系 |

> 使用价值与价值的**对立统一 ⭐**：对立——二者不可兼得；统一——须同时具备

### 生产商品的劳动的二重性

| | 具体劳动 | 抽象劳动 |
|--|---------|---------|
| 定义 | 生产一定使用价值的具体形式劳动 | 撇开具体形式的无差别人类劳动 |
| 形成 | **使用价值** | **价值** |
| 属性 | 自然属性（永恒范畴） | 社会属性（历史范畴） |

> 劳动的二重性**决定**商品的二因素

**具体劳动和抽象劳动的对立统一 ⭐**：
- 对立：反映不同属性（人与自然 vs 社会关系）
- 统一：同一劳动过程不可分割的两个方面，时间空间上统一

### 商品价值量的决定

- 决定因素：**社会必要劳动时间**（不是个别劳动时间）
- **价值量与劳动时间成正比，与劳动生产率成反比**
- 简单劳动 vs 复杂劳动：倍率由市场自发调控

### 货币

- 起源：价值形式发展的四个阶段（简单→总和→一般→货币）
- 本质：固定充当**一般等价物**的商品
- 五大职能：**价值尺度、流通手段**（最基本）、贮藏手段、支付手段、世界货币

### 价值规律

- **内容**：价值量由社会必要劳动时间决定，按等价交换原则进行
- **表现形式**：价格围绕价值自发波动

**积极作用 ⭐⭐⭐**：
1. 自发调节生产资料和劳动力分配
2. 自发刺激社会生产力发展
3. 自发调节社会收入分配

**消极后果**：资源浪费、阻碍技术、两极分化

### 以私有制为基础的商品经济的基本矛盾

**私人劳动与社会劳动的矛盾 ⭐**

- 私人劳动（私有制决定）vs 社会劳动（社会分工决定）
- **交换**是解决矛盾的唯一途径
- 这一矛盾：决定商品经济的本质和发展过程；是其他一切矛盾的基础；决定商品生产者的命运
- 在资本主义下发展为**资本主义基本矛盾**

### 马克思劳动价值论的意义 ⭐⭐⭐（24 简答）

1. 扬弃英国古典政治经济学 → 为**剩余价值论**奠定基础
2. 揭示私有制下商品经济基本矛盾 → 从物与物关系揭示人与人的关系
3. 揭示商品经济一般规律 → 指导社会主义市场经济

### 深化对劳动价值论的认识 ⭐

1. 深化对**创造价值的劳动**的界定
2. 深化对**脑力劳动**作用的认识
3. 深化对**价值创造与价值分配关系**的认识

## 二、资本主义经济制度（剩余价值理论）

### 资本的原始积累

以**暴力手段使生产者与生产资料相分离**，资本集中于少数人手中

### 劳动力成为商品

**两个基本条件**：①人身自由 ②一无所有（不得不卖劳动力）

### 劳动力商品的价值与使用价值

#### 劳动力价值（三部分）⭐

1. 维持劳动者**本人生存**的生活资料价值
2. 维持劳动者**家属生存**的生活资料价值
3. 劳动者**教育和训练**的费用

#### 劳动力使用价值

**是价值的源泉**，消费过程中创造的新价值**大于**劳动力本身的价值

### 货币转化为资本

- 简单商品流通：$W - G - W$（为买而卖）
- **资本总公式**：$G - W - G'$（为卖而买，$G' = G + \Delta G$）
- 劳动力成为商品是货币转化为资本的**条件**

### 资本主义生产过程的二重性

资本主义生产过程 = **劳动过程** + **价值增殖过程**的统一

- 劳动过程：工人在资本家监督下劳动，产品归资本家
- 价值增殖：超过劳动力价值补偿点而延长的价值形成过程

### 不变资本和可变资本

| | 不变资本（c） | 可变资本（v） |
|--|------------|------------|
| 形态 | 生产资料 | 购买劳动力的资本 |
| 特点 | 价值被转移，不增殖 | 由劳动再生产，能增殖 |

> 资本的本质不是物，而是**一定的社会历史形态下的生产关系**

### 商品价值构成与剩余价值率

$$W = c + v + m$$

$$m' = \frac{m}{v} = \frac{\text{剩余劳动}}{\text{必要劳动}} = \frac{\text{剩余劳动时间}}{\text{必要劳动时间}}$$

- 年剩余价值率：$M' = \frac{M}{v} = n \cdot m'$（$n$ = 年周转次数）

### 绝对剩余价值、相对剩余价值和超额剩余价值

| 类型 | 方式 | 条件 |
|------|------|------|
| 绝对剩余价值 | 延长工作日/提高劳动强度 | 必要劳动时间不变 |
| 相对剩余价值 | 缩短必要劳动时间 | 全社会劳动生产率提高 |
| 超额剩余价值 | 个别价值低于社会价值 | 个别企业提高劳动生产率 |

> 超额剩余价值是**原因**，相对剩余价值是**结果**。生产自动化下，**雇佣工人的剩余劳动仍是剩余价值的唯一源泉**。

### 资本积累

- **资本积累** = 剩余价值的资本化
- **简单再生产**：剩余价值全用于消费，原规模重复
- **扩大再生产**：部分剩余价值转化为资本，扩大规模
- 资本积累的本质：无偿占有剩余价值 → 扩大资本 → 加强剥削
- 源泉链：**剩余劳动 → 剩余价值 → 资本积累 → 扩大再生产**

### 资本有机构成

- **技术构成**：生产资料与劳动力的比例
- **价值构成**：不变资本与可变资本的比例（$c:v$）
- **有机构成**：由技术构成决定并反映技术构成变化的价值构成
- 趋势：资本有机构成不断提高 → 相对过剩人口（失业）

### 资本积聚与资本集中

- **资本积聚**：个别资本通过剩余价值资本化增大（资本积累的直接结果）
- **资本集中**：个别资本通过**结合**形成较大资本（竞争+信用是杠杆）

### 资本循环与周转

#### 产业资本的三个阶段

1. 购买阶段 → **货币资本**职能
2. 生产阶段 → **生产资本**职能
3. 售卖阶段 → **商品资本**职能

#### 正常进行的前提条件

1. 三种职能在**空间上并存**
2. 三种职能在**时间上继起**

#### 固定资本与流动资本

| | 固定资本 | 流动资本 |
|--|---------|---------|
| 形态 | 劳动资料（机器、设备、工具） | 劳动对象（原材料）+ 劳动力 |
| 周转 | 慢 | 快 |

> 与不变/可变资本不同：这是按**周转方式**划分

### 社会再生产

- **核心问题**：社会总产品的**实现问题**（价值补偿 + 实物补偿）
- **社会总产品**：一定时期生产的全部物质资料总和
- 两大部类：Ⅰ 生产资料 + Ⅱ 消费资料
- 价值构成：$c + v + m$
- 顺利实现条件：两大部类内部和之间保持**比例关系**

### 工资与剩余价值的分配

- **工资的本质**：劳动力的价值或价格（**不是**劳动的价格）
- 工资形式掩盖了必要劳动与剩余劳动的界限

#### 利润与平均利润

- 利润是剩余价值的**转化形式**
- $利润率 = \frac{m}{c+v}$（反映预付总资本增殖，掩盖剥削）
- **平均利润率** = 剩余价值总量 / 社会总资本（部门间竞争导致）
- **生产价格** = 生产成本 + 平均利润（价值的转化形式）

### 剩余价值理论的意义 ⭐

1. 揭露资本主义剥削本质 → 指出无产阶级革命历史必然性
2. 是马克思经济学说的**核心内容和基石**
3. 揭示商品经济和社会化生产的一般规律

### 资本主义的基本矛盾

**生产社会化**与**生产资料资本主义私人占有**之间的矛盾

具体表现：
1. 生产无限扩大 vs 有支付能力的需求相对缩小
2. 企业内部有组织 vs 整个社会生产无政府状态

### 资本主义经济危机

- 基本特征：**生产过剩**
- 根本原因：资本主义基本矛盾
- 周期性：危机 → 萧条 → 复苏 → 高涨

## 三、资本主义上层建筑

### 资本主义国家的本质

资产阶级进行阶级统治的**工具**

### 资本主义民主制度的本质

资产阶级实行政治统治和社会管理的**手段和方式**

### 资本主义政治制度的局限性 ⭐

1. 民主是金钱操纵下的民主，实质是资产阶级精英统治
2. 法律名义平等掩盖事实不平等
3. 政党制是维护资产阶级统治的工具
4. 政党恶斗相互掣肘，激化社会矛盾

### 资本主义意识形态的本质

1. 是资本主义社会的**观念上层建筑**，为经济基础和政治上层建筑服务
2. 是资产阶级**阶级意识的集中体现**

# 常考查的概念辨析

| 概念对 | 板块 | 关键区分 |
|--------|------|----------|
| 使用价值 vs 价值 | 商品经济 | 自然属性 vs 社会属性；物质承担者 vs 交换基础 |
| 具体劳动 vs 抽象劳动 | 商品经济 | 形成使用价值 vs 形成价值；永恒范畴 vs 历史范畴 |
| 不变资本 vs 可变资本 | 剩余价值 | 按作用划分；只转移 vs 能增殖 |
| 绝对剩余价值 vs 相对剩余价值 | 剩余价值 | 延长工作日 vs 缩短必要劳动 |
| 固定资本 vs 流动资本 | 资本周转 | 按周转方式；劳动资料 vs 劳动对象+劳动力 |
| 资本循环 vs 资本周转 | 资本流通 | 一次 vs 反复；静态 vs 动态 |
| 感性认识 vs 理性认识 | 认识论 | 现象 vs 本质；深浅关系非对错关系 |
| 社会存在 vs 社会意识 | 唯物史观 | 物质方面 vs 精神方面；决定 vs 反作用 |
| 量变 vs 质变 | 辩证法 | 渐进连续 vs 飞跃中断 |
| 矛盾的同一性 vs 斗争性 | 辩证法 | 依存贯通 vs 排斥分离；相对 vs 绝对 |
| 私人劳动 vs 社会劳动 | 商品经济 | 私有制 vs 社会分工；商品经济基本矛盾 |
| 真理绝对性 vs 相对性 | 认识论 | 无限性 vs 有限性；辩证统一 |
| 资本积聚 vs 资本集中 | 资本积累 | 剩余价值资本化增大 vs 结合形成较大资本 |
