## 题目正文

计算 Gauss 函数 $G(x) = e^{-x^2/2}$（$x \in \mathbb{R}$）的 Fourier 变换，并验证 $\hat{G} = G$。

## 详细解析

> [!solution]- 点击展开详细解析
> **方法（微分方程法）**：由 $G'(x) = -x G(x)$，两边取 Fourier 变换：
>
> $$\widehat{G'} = \widehat{-xG}.$$
>
> 利用性质：$\widehat{f'} = it\hat{f}$，$\widehat{xf} = i\hat{f}'$，得
>
> $$it\,\hat{G}(t) = -i\,\hat{G}'(t) \;\Rightarrow\; \hat{G}'(t) = -t\,\hat{G}(t).$$
>
> 这是一阶线性微分方程，解为 $\hat{G}(t) = C\,e^{-t^2/2}$。
>
> 确定常数 $C$：计算 $t=0$ 处的值：
>
> $$\hat{G}(0) = \frac{1}{\sqrt{2\pi}} \int_{\mathbb{R}} e^{-x^2/2}\,dx = 1 \;\Rightarrow\; C = 1.$$
>
> 因此 $\hat{G}(t) = e^{-t^2/2} = G(t)$。
>
> **点评**：Gauss 函数是 Fourier 变换的不动点。这是 Fourier 变换最重要的特征函数之一，也是证明 Fourier 反演公式和 Plancherel 定理的关键。
>
> $\square$
