## 第一块：集合论 → 只考基数

| 考 | 不考 |
|:--|:--|
| 可数集/不可数集的定义 | 开集、闭集及其结构 |
| 证明一个集合可数 | $\mathbb{R}^n$ 完备性 |
| 证明一个集合不可数（Cantor 对角线法） | 有理数集性质、Borel 集、$\sigma$ 代数 |
| | 选择公理、Zorn 引理 |
| | 闭集套、有限覆盖、紧集 |

### 必须掌握

**可数集**：能与 $\mathbb{N}$ 建立一一对应（双射）的集合。势 $\aleph_0$。

- 证明可数：直接构造双射 / 证明是已知可列集的子集 / 表为可数个可列集的并
- 必记：$\mathbb{Q}$ 可列（$f(p,q)=p/q$ 是满射），有理系数多项式全体可列

**不可数集**：不是可列集的无穷集。$(0,1)$ 不可列是核心例子。

**Cantor 对角线法**（证明 $(0,1)$ 不可列）：
1. 假定可列，枚举为 $f(1),f(2),\ldots$，写十进制展开
2. 构造 $x=0.b_1b_2\cdots$，$b_n=2$ 若 $a_{nn}=1$，否则 $b_n=1$
3. $x$ 与每个 $f(n)$ 第 $n$ 位不同 → 漏网 → 矛盾

**可列集的运算**：可数个可列集的并仍可列（对角线排列法）。有限个可列集的直积可列，但可数个可列集的直积不一定（$\{0,1\}^{\mathbb{N}}$ 势为 $\mathfrak{c}$）。

## 第二块：测度 → 只考收敛性

| 考 | 不考 |
|:--|:--|
| 四种收敛的定义 | 测度定义、可列可加性 |
| 收敛之间的关系 | 外测度构造 |
| Egorov 定理 | 可测集/不可测集的判定 |
| Riesz 定理 | Lebesgue 测度的具体计算 |

### 四种收敛

| 收敛 | 定义核心 | 记号 |
|:--|:--|:--|
| 一致收敛 | $\exists K,\forall k\geq K,\forall x:\lvert f_k-f\rvert<\varepsilon$ | $f_k\rightrightarrows f$ |
| 几乎一致收敛 | 去掉测度 $<\delta$ 的集后一致收敛 | $f_k\xrightarrow{a.u.}f$ |
| 几乎处处收敛 | 除零测集外逐点收敛 | $f_k\xrightarrow{a.e.}f$ |
| 依测度收敛 | $m(\{\lvert f_k-f\rvert>\varepsilon\})\to 0$ | $f_k\xrightarrow{m}f$ |

### 核心关系

```
一致 ⟹ 几乎一致 ⟹ 几乎处处（有限测度下 Egorov 可逆）
                  ⟹ 依测度（有限测度下）
依测度 ⟹ 存在子列几乎处处（Riesz 定理）
```

**Egorov 定理**：$m(E)<\infty$ 时，a.e. 收敛 $\Rightarrow$ 几乎一致收敛。
- 反例：$m(E)=\infty$ 时不成立（$\chi_{(0,k)}$ 在 $(0,\infty)$）

**Riesz 定理**：依测度收敛 $\Rightarrow$ 存在子列 a.e. 收敛。
- 经典反例：$[0,1)$ 上的"移动脉冲"列——依测度收敛于 $0$，但每点都不收敛

**Lusin 定理**（Littlewood 第二原理）：可测函数去掉小测度集后连续。

## 第三块：可积函数 → 主要考积分与极限交换

| 考 | 不考 |
|:--|:--|
| Levi 单调收敛定理 | 重积分与累次积分（仅了解） |
| Fatou 引理 | Fubini/Tonelli 定理（仅了解） |
| Lebesgue 控制收敛定理 (DCT) | |
| 有界收敛定理 | |
| 积分定义（vs. 黎曼积分，了解即可） | |

### Lebesgue 积分定义（了解）

- 非负简单函数 → 非负可测函数（取 sup）→ 一般函数（正部 $-$ 负部）
- **Lebesgue 可积 $\iff$ 绝对可积**（$\int|f|<\infty$），与黎曼积分根本不同
- Dirichlet 函数：黎曼不可积，但 Lebesgue 可积（= 0）

### 四个极限定理（核心）

| 定理          | 条件                                            | 结论                                                  |
| :---------- | :-------------------------------------------- | :-------------------------------------------------- |
| **Levi**    | $f_n\geq 0$，$f_n\uparrow f$                   | $\lim\int f_n=\int f$                               |
| **Fatou**   | $f_n\geq 0$                                   | $\int\varliminf f_n \leq \varliminf\int f_n$（注意方向！） |
| **DCT** ★★★ | $\lvert f_n\rvert\leq F\in L$，$f_n\to f$ a.e. | $\lim\int f_n=\int f$                               |
| **有界收敛**    | $m(E)<\infty$，$\lvert f_n\rvert\leq M$        | $\lim\int f_n=\int f$                               |

**解题核心**：构造控制函数 $F(x)$（DCT）。常见套路：
- 用 $\lvert\sin x\rvert,\lvert\cos x\rvert\leq 1$
- 用 $e^{-x}$ 衰减性
- 用幂函数 $x^{-\alpha}$ 可积条件
- 用 $\frac{\ln t}{t}\leq e^{-1}$

### 黎曼可积充要条件（了解）

$f$ 在 $[a,b]$ 上有界，黎曼可积 $\iff$ 不连续点集是零测集。

## 第四块：$L^p$ 空间

| 考 | 不考 |
|:--|:--|
| Hölder 不等式 + Minkowski 不等式 | |
| 完备性（Riesz-Fisher） | |
| 可分性（$p<\infty$ 可分，$L^\infty$ 不可分） | |
| 对偶性（$L^p\leftrightarrow L^q$） | |
| 强收敛 vs 弱收敛 | |
| 正交基 + Fourier 展开（$L^2$） | |
| $L^p$ 可积函数判断 | |

### 核心不等式

**Hölder**：$\int|fg|\leq(\int|f|^p)^{1/p}(\int|g|^q)^{1/q}$，$1/p+1/q=1$。
- $p=q=2$ → **Schwarz**：$|\int fg|\leq\|f\|_2\|g\|_2$

**Minkowski**（三角不等式）：$\|f+g\|_p\leq\|f\|_p+\|g\|_p$。

**Young（卷积版）**：$\|f*g\|_p\leq\|f\|_p\|g\|_1$。

### $L^p$ 空间结构

| 性质 | 结论 |
|:--|:--|
| 完备性 | 每个基本列收敛（Riesz-Fisher，证明链：基本列→测度基本列→依测度收敛→Riesz子列→Fatou） |
| 可分性 | $1\leq p<\infty$ 可分；$L^\infty$ 不可分 |
| 对偶性 | $\|f\|_p=\sup_{\|g\|_q=1}\int fg$（$1\leq p<\infty$） |
| 包含关系 | $m(E)<\infty$，$p_1<p_2$ → $L^{p_2}\subset L^{p_1}$；$\lim_{p\to\infty}\|f\|_p=\|f\|_\infty$ |

### 强弱收敛

- **强**（$L^p$ 收敛）：$\|f_n-f\|_p\to 0$。蕴含依测度收敛，但不蕴含 a.e. 收敛（只能抽出子列）
- **弱**：$\forall g\in L^q$，$\int f_ng\to\int fg$。强 ⇒ 弱，反之不成立。

### 正交基与 Fourier 展开

$L^2$ 中标准正交系 $\{\varphi_k\}$，四个等价条件（定理 4.2.14）：
1. 标准正交基 2. 线性组合稠密 3. 完全性 4. Parseval 等式

**必记例子**：
- $L^2[-\pi,\pi]$ 三角函数系 → Fourier 级数
- $L^2[-1,1]$ Legendre 多项式
- $L^2(\mathbb{R})$ Hermite 函数

### 判断 $L^p$ 可积

核心：$\int_E|f|^p<\infty$？关注奇点（如 $0$）和无穷远衰减。
- $f(x)=x^{-\alpha}$ 在 $(0,1)$ 上：需 $p\alpha<1$
- 在 $(0,\infty)$ 上需同时考虑 $0$ 和 $\infty$ 处

### 卷积与 Young 不等式

**卷积**：$f*g(x)=\int_{\mathbb{R}^n}f(x-y)g(y)dy$。交换性：$f*g=g*f$。

**Young 不等式**（定理 4.3.1）：$f\in L^p$，$g\in L^1$ → $f*g\in L^p$，$\|f*g\|_p\leq\|f\|_p\|g\|_1$。

**磨光算子（mollifier）**（定理 4.3.6）：取 $\varphi\in L^1$，$\varphi\geq 0$，$\|\varphi\|_1=1$，令 $\varphi_\varepsilon(x)=\varepsilon^{-n}\varphi(x/\varepsilon)$，则
$$\varphi_\varepsilon * f \xrightarrow{L^p} f \quad (\varepsilon\to 0)$$

> 推论：$C_c^\infty(\mathbb{R}^n)$ 在 $L^p(\mathbb{R}^n)$ 中稠密；$[a,b]$ 上全体多项式在 $L^p[a,b]$ 中稠密。

### Fourier 变换

**定义 4.3.7**：$f\in L^1(\mathbb{R}^n)$，$\hat{f}(t)=(2\pi)^{-n/2}\int_{\mathbb{R}^n}f(x)e^{-it\cdot x}dx$。

**基本性质**（引理 4.3.8）：$f,g\in L^1(\mathbb{R}^n)$
- $(T_x f)^\wedge = e_{-x}\hat{f}$（平移 ↔ 乘相位）
- $(e_x f)^\wedge = T_x\hat{f}$（乘相位 ↔ 平移）
- $(f*g)^\wedge = \hat{f}\hat{g}$（**卷积的 Fourier 变换 = Fourier 变换的乘积**）
- 伸缩：$f_\lambda(x)=f(x/\lambda)$ → $\hat{f}_\lambda(t)=\lambda^n\hat{f}(\lambda t)$

**速降函数空间** $S(\mathbb{R}^n)$（定义 4.3.9）：$C^\infty$ 且各阶导数比任意多项式衰减快。

**$S$ 上的 Fourier 变换**（命题 4.3.11 + 定理 4.3.13）：
- $F: S\to S$ 是双射，$F^4=I$
- $(P(D)f)^\wedge = P\cdot\hat{f}$，$(P\cdot f)^\wedge = P(-D)\hat{f}$
- **逆变换**：$f(x)=(2\pi)^{-n/2}\int\hat{f}(t)e^{ix\cdot t}dt$

**Plancherel 定理**（定理 4.3.15）：Fourier 变换可唯一延拓为 $L^2(\mathbb{R}^n)$ 上的酉算子，$\|\hat{f}\|_2=\|f\|_2$。

**经典例子**：Gauss 函数 $G(x)=e^{-|x|^2/2}$ 满足 $\hat{G}=G$，$G(0)=1$。

## 可能考察的证明（汇总）

### 集合论
1. **Cantor 对角线法**：$(0,1)$ 不可列
2. **可列并可列**：可数个可列集的并可列（对角线排列）

### 收敛性
3. **Egorov 定理**：有限测度上 a.e. ⇒ a.u.（证法：降列测度取极限）
4. **Riesz 定理**：依测度收敛 ⇒ 存在子列 a.e. 收敛

### 积分与极限
5. **Levi 定理**：非负单调列积分取极限（证法：$\alpha$ 技巧）
6. **Fatou 引理**：$\int\varliminf f_n\leq\varliminf\int f_n$（证法：令 $g_n=\inf_{j\geq n}f_j$）
7. **DCT**：控制函数下极限积分交换（证法：对 $2F-g_n$ 用 Fatou）
8. **黎曼可积充要条件**：不连续点零测（证法：振幅函数链）

### $L^p$ 空间
9. **Hölder 不等式**（证法：Young 不等式 $a^{1/p}b^{1/q}\leq a/p+b/q$）
10. **Minkowski 不等式**（证法：拆分 $\|f+g\|_p^p$ + Hölder）
11. **Riesz-Fisher**：$L^p$ 完备性（证法链：基本列→测度基本列→依测度收敛→Riesz子列→Fatou）

### 卷积与 Fourier 变换
12. **Young 不等式**（卷积版）：$\|f*g\|_p\leq\|f\|_p\|g\|_1$（证法：Hölder + Fubini）
13. **磨光算子逼近**：$\varphi_\varepsilon*f\xrightarrow{L^p}f$（证法：Hölder + 控制收敛）
14. **卷积的 Fourier 变换**：$(f*g)^\wedge=\hat{f}\hat{g}$（证法：Fubini）
