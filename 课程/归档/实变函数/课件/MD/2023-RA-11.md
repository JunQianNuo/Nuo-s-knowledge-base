定理2.1.8.若有递增可测集列 $E _ { 1 } \subset E _ { 2 } \subset \cdots \subset E _ { k } \subset \cdots$ 则

$$
\lim _ {k \to \infty} E _ {k} \in \mathfrak {M}, \text {且}
$$

$$
m (\lim _ {k \to \infty} E _ {k}) = \lim _ {k \to \infty} m (E _ {k}).
$$

证明： $\operatorname* { l i m } _ { k  \infty } E _ { k } = \bigcup _ { k = 1 } ^ { \infty } E _ { k } \in \mathfrak { M }$ 我们有 $\bigcup _ { k = 1 } ^ { \infty } E _ { k } = \bigcup _ { k = 1 } ^ { \infty } ( E _ { k } \backslash E _ { k - 1 } ) \qquad ( E _ { 0 } = \emptyset ) .$

$\{ E _ { k } \backslash E _ { k - 1 } \} _ { k = 1 } ^ { \infty }$ 由于 是不互相交的可测集列。 $E _ { k - 1 }$ 与 $E _ { k } \backslash E _ { k - 1 }$ 不互相交，

$$
m (E _ {k - 1}) + m (E _ {k} \backslash E _ {k - 1}) = m (E _ {k - 1} \cup (E _ {k} \backslash E _ {k - 1})) = m (E _ {k}),
$$

故 $m ( E _ { k } \backslash E _ { k - 1 } ) = m ( E _ { k } ) - m ( E _ { k - 1 } )$ 由测度的可列可加性，

$$
m (\lim _ {k \to \infty} E _ {k}) = m \left(\bigcup_ {k = 1} ^ {\infty} (E _ {k} \backslash E _ {k - 1})\right) = \sum_ {k = 1} ^ {\infty} m (E _ {k} \backslash E _ {k - 1})
$$

$$
= \sum_ {k = 1} ^ {\infty} (m (E _ {k}) - m (E _ {k - 1})) = \lim _ {k \rightarrow \infty} m (E _ {k}).
$$

定理2.1.10. 若 $E \in { \mathfrak { M } }$ 则 $E + x \in \mathfrak { M } \quad ( \forall x \in \mathbb { R } ^ { n } )$

Proof. $( E + x ) ^ { c } = E ^ { c } + x$ ，and for any $T \subset \mathbb { R } ^ { n }$

we see that $T \cap ( E + x ) = ( ( T - x ) \cap E ) + x .$

Therefore,

$$
\begin{array}{l} m ^ {*} (T \cap (E + x)) + m ^ {*} (T \cap (E + x) ^ {c}) \\ = m ^ {*} \left(\left((T - x) \cap E\right) + x\right) + m ^ {*} \left(\left((T - x) \cap E\right) + x\right) \\ = m ^ {*} ((T - x) \cap E) + m ^ {*} ((T - x) \cap E) \\ = m ^ {*} (T - x) = m ^ {*} (T) \\ \end{array}
$$

Hence, $E + x \in { \mathfrak { M } }$
