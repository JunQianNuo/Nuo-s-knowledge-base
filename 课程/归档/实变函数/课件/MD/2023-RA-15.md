## 黎曼积分

$f(x):[a,b]\to\mathbb{R}$，有界

对于任意的划分：$a=\xi_0<\xi_1<\cdots<\xi_n=b$，定义

用区间划分  
• 按顺序求和

因为是有限项的和

$$
S = \sum_ {i = 1} ^ {n} (\xi_ {i} - \xi_ {i - 1}) M _ {i}, \quad M _ {i} := \sup _ {\xi_ {i - 1} <   x \leq \xi_ {i}} f (x); \quad s = \sum_ {i = 1} ^ {m} (\xi_ {i} - \xi_ {i - 1}) m _ {i}, \quad m _ {i} := \inf _ {\xi_ {i - 1} <   x \leq \xi_ {i}} f (x).
$$

定义黎曼上积分为 $R\overline{\int_a^b f(x)dx} = \inf S$（对所有可能的划分取下确界），定义黎曼下积分为 $R\underline{\int_a^b} f(x) dx = \sup s$（对所有可能的划分取上确界）。

若 $R\overline{\int_a^b} f(x) dx = R\underline{\int_a^b} f(x) dx$，则称 $f(x)$ 是黎曼可积。

## Ex. Dirichlet函数

$$
D (x) = \left\{ \begin{array}{l l} 0, & x \in \mathbb {Q} \cap [ 0, 1 ], \\ 1, & x \in \mathbb {Q} \backslash [ 0, 1 ]. \end{array} \right. \qquad R \overline {{\int_ {a} ^ {b}}} D (x) d x 1, \quad R \underline {{\int_ {a} ^ {b}}} D (x) d x = 0.
$$

不是黎曼可积函数。

结合定理2.2.5（非负可测函数列可由上升的非负简单函数列逼近），非负可测函数的积分的性质可由简单函数的积分性质通过取极限的形式得到。

定理3.1.4（积分的线性性质） 设 是可测集 上的非负可测函数，对于任给的非负常数 有

$$
\int_ {E} (\alpha f (x) + \beta g (x)) d x = \alpha \int_ {E} f (x) d x + \beta \int_ {E} f (x) d x.
$$

证明 设 $\{ \phi _ { k } ( x ) \} _ { k \geq 1 } , \{ \psi _ { k } ( x ) \} _ { k \geq 1 }$ 是非负上升可测简单函数列，且

$$
\lim _ {k \to \infty} \phi_ {k} (x) = f (x), \quad \lim _ {k \to \infty} \psi_ {k} (x) = g (x) \quad (\forall x \in E).
$$

注意到 $\{ \alpha \phi _ { k } + \beta \psi _ { k } \} _ { k \ge 1 }$ 仍是非负上升可测简单函数列，且有

$$
\lim _ {k \to \infty} (\alpha \phi_ {k} (x) + \beta \psi_ {k} (x)) = \alpha f (x) + \beta g (x) \quad (\forall x \in E).
$$

由简单函数的积分的线性性质和Levi定理

$$
\begin{array}{l} \int_ {E} (\alpha f (x) + \beta g (x)) d x = \lim _ {k \to \infty} \int_ {E} (\alpha \phi_ {k} (x) + \beta \psi_ {k} (x)) d x \\ = \alpha \lim _ {k \to \infty} \int_ {E} \phi_ {k} (x) d x + \beta \lim _ {k \to \infty} \int_ {E} \psi_ {k} (x) d x = \alpha \int_ {E} f (x) d x + \beta \int_ {E} g (x) d x \\ \end{array}
$$

推论3.1.5 设 $f ( x ) , g ( x )$ 是 上的非负可测函数，

（1）若 $f = g , \ \mathrm { a . e . } \ [ E ]$ 则 $\int _ { E } f ( x ) d x = \int _ { E } g ( x ) d x ;$ JE  
（2）若 $\int _ { E } f ( x ) \ d x < \infty ,$ 则 $f ( x ) < \infty , { \mathrm { ~ a . e . ~ } } [ E ]$

$$
\therefore \int_ {E} f (x) d x = \int_ {E} f (\chi_ {E _ {1}} + \chi_ {E _ {2}}) d x = \int_ {E _ {1}} f (x) d x + \boxed {\int_ {E _ {2}} f (x) d x} = 0
$$

$$
= \int_ {E _ {1}} g (x) d x + \boxed {\int_ {E _ {2}} g (x) d x} = \int_ {E} g (x) d x

（2）记 $E _ { k } = E ( f > k )$ 则 $E _ { \infty } = E ( f = \infty ) = \bigcap E _ { k }$
