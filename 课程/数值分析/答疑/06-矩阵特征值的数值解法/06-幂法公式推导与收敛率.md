# 幂法公式推导与收敛率

> 问题：$x_k = A^k x_0 = \lambda_1^k\left(c_1 v_1 + \left(\frac{\lambda_2}{\lambda_1}\right)^k c_2 v_2 + \cdots\right)$ 怎么来的？收敛率为什么是 $|\lambda_2/\lambda_1|$？$\lambda_3,\lambda_4$ 不管了吗？

> 来源：[[课程/数值分析/知识点解析梳理/06-矩阵特征值的数值解法-知识梳理]] 第 65-69 行

---

## 前提

$A$ 可对角化，特征值**按模从大到小排列**：

$$|\lambda_1| > |\lambda_2| \ge |\lambda_3| \ge \cdots \ge |\lambda_n|$$

$\lambda_1$ 称为**主特征值**，必须严格大于 $\lambda_2$ 才能收敛。

## 推导

初始向量 $x_0$ 用特征向量的基底展开：

$$x_0 = c_1 v_1 + c_2 v_2 + \cdots + c_n v_n$$

幂法：$x_{k+1}=Ax_k$，所以 $x_k=A^k x_0$。

利用 $A^k v_i = \lambda_i^k v_i$：

$$x_k = c_1 \lambda_1^k v_1 + c_2 \lambda_2^k v_2 + \cdots + c_n \lambda_n^k v_n$$

提取 $\lambda_1^k$：

$$
x_k = \lambda_1^k\left(
c_1 v_1 +
\boxed{\left(\frac{\lambda_2}{\lambda_1}\right)^k c_2 v_2} +
\left(\frac{\lambda_3}{\lambda_1}\right)^k c_3 v_3 +
\cdots
\right)
$$

## 收敛率为什么是 $|\lambda_2/\lambda_1|$

**因为 $|\lambda_2/\lambda_1|$ 是括号里最大的那个比例，衰减最慢。**

| 项 | 比例 | 相对大小 |
|:---|:---:|:---:|
| $(\lambda_2/\lambda_1)^k$ | $<1$ | **最大**（衰减最慢） |
| $(\lambda_3/\lambda_1)^k$ | $<|\lambda_2/\lambda_1|$ | 更小（衰减更快） |
| $(\lambda_n/\lambda_1)^k$ | 最小 | 衰减最快 |

**$k$ 很大时**：$\lambda_3$ 及更小的方向**早就衰减到可以忽略了**，但 $\lambda_2$ 方向还残留着——所以整体收敛速度由 $\lambda_2/\lambda_1$ 决定。

类比：三个人同时减肥，A 每周瘦 50%，B 每周瘦 80%，C 每周瘦 90%。三个人都瘦到看不见需要多久？答案由 **A（最慢的那个）** 决定——B 和 C 早就瘦没了。

**结论**：不是"不在乎"更小的特征值，而是它们早就衰减干净了，不等它们拖后腿就已经不可见了。收敛率的上界就是 $S \le |\lambda_2/\lambda_1|$。
