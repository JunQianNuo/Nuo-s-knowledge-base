# 第七章 插值法 — 知识点汇集

## 一、本章核心脉络

核心问题：给定离散数据点 $(x_i, f(x_i))$，找一条曲线 $g(x)$ 经过所有这些点（$g(x_i) = f(x_i)$）。多项式插值是最基本的方法，但高阶等距插值会出现Runge现象，Chebyshev插值和样条插值是改进方案。

```mermaid
flowchart TD
    A[插值问题: g(x_i)=f(x_i)] --> B{选择基函数}
    B --> C[基本多项式: 1,x,x^2,...]
    B --> D[Lagrange: l_i(x)]
    B --> E[Newton: N_i(x)]
    C --> F[Vandermonde矩阵: 满阵, 条件数大]
    D --> G[系数M=I, 直接得a_i=f(x_i)]
    E --> H[下三角阵, 新增点无需重算]
    A --> I{高阶等距插值?}
    I -->|是| J[Runge现象]
    J --> K[Chebyshev插值: 非等距节点]
    I -->|否| L[分段/样条插值]
    L --> M[三次样条: 对角占优方程组]
```

## 二、基础定义

| 术语 | 符号/表述 | 含义 |
|:--|:--|:--|
| 插值 | $g(x_i) = f(x_i),\; i=0,\ldots,m$ | 函数经过所有给定数据点 |
| 基函数 | $\varphi_0, \ldots, \varphi_n$ | 张成函数空间 $\Phi$ |
| Vandermonde矩阵 | $M_{ij} = x_i^j$ | 基本多项式插值的系数矩阵 |
| Lagrange基函数 | $l_i(x_j) = \delta_{ij}$ | 在$x_i$为1、其他节点为0的多项式 |
| Newton基函数 | $N_i(x) = \prod_{j=0}^{i-1}(x - x_j)$ | 递推构造，新增节点无需重算 |
| 差商 | $f[x_0,\ldots,x_n]$ | Newton插值的系数 |
| Runge现象 | — | 高阶等距插值在区间两端剧烈震荡 |
| Chebyshev多项式 | $T_n(x) = \cos(n \cos^{-1} x)$ | 最小化插值误差上界的最优节点 |
| 样条函数 | $S(x)$ | 分段多项式，在结点处满足连续性条件 |

## 三、核心方法/定理

### 3.1 插值基本概念

$f(x)$ 定义在 $[a,b]$ 上，$\{x_i\}_{i=0}^m$ 为互不相同的点，$\Phi = \text{span}\{\varphi_0, \ldots, \varphi_n\}$。求 $g \in \Phi$ 满足 $g(x_i) = f(x_i)$。

设 $g(x) = a_0 \varphi_0(x) + \cdots + a_n \varphi_n(x)$，得线性方程组 $M a = f$，其中 $M_{(m+1) \times (n+1)}$。

$M a = f$ 存在唯一解的条件：$m = n$ 且系数矩阵 $M$ 可逆。

### 3.2 多项式插值定理

若 $x_0, \ldots, x_n$ 是不同的实数，则对任意数值 $y_0, \ldots, y_n$，存在唯一的次数至多是 $n$ 的多项式 $P_n(x)$ 使得 $P_n(x_i) = y_i\;(0 \le i \le n)$。

### 3.3 基本多项式插值

$\Phi = P_n(x) = \text{span}\{1, x, x^2, \ldots, x^n\}$，系数矩阵为Vandermonde矩阵：

$$M = \begin{bmatrix} 1 & x_0 & x_0^2 & \cdots & x_0^n \\ 1 & x_1 & x_1^2 & \cdots & x_1^n \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ 1 & x_n & x_n^2 & \cdots & x_n^n \end{bmatrix}$$

行列式 $\det(M) = \prod_{0 \le j < i \le n} (x_i - x_j) \neq 0$（节点互异时可逆）。

### 3.4 Lagrange插值

优化基函数使得系数矩阵为单位阵：设 $l_i(x_j) = \delta_{ij}$。

$$l_i(x) = \frac{(x-x_0)\cdots(x-x_{i-1})(x-x_{i+1})\cdots(x-x_n)}{(x_i-x_0)\cdots(x_i-x_{i-1})(x_i-x_{i+1})\cdots(x_i-x_n)}$$

最终插值函数：$g(x) = \sum_{i=0}^n f(x_i) l_i(x)$。

### 3.5 Newton插值

已知经过 $\{x_i\}_{i=0}^n$ 的插值多项式 $P_n(x)$，求新增 $x_{n+1}$ 后的 $P_{n+1}(x)$：

$P_{n+1}(x) = P_n(x) + Q_{n+1}(x)$，由 $Q_{n+1}(x_i) = 0$ 得 $Q_{n+1}(x) = a_{n+1} \prod_{i=0}^n (x - x_i)$。

**递推形式**：

$$P_n(x) = a_0 + a_1(x - x_0) + \cdots + a_n(x - x_0)\cdots(x - x_{n-1})$$

基函数：$N_0(x) = 1,\; N_1(x) = x - x_0,\; \ldots,\; N_n(x) = \prod_{i=0}^{n-1} (x - x_i)$

系数矩阵为**下三角阵**（当 $i < j$ 时 $N_j(x_i) = 0$）。

**差商定义**：Newton插值的系数 $a_n := f[x_0, x_1, \ldots, x_n]$ 称为 $n$ 阶Newton差商。

- $f[x_0] = f(x_0)$
- $f[x_0, x_1] = \frac{f(x_1) - f(x_0)}{x_1 - x_0}$
- $f[x_0, x_1, x_2] = \frac{f[x_0, x_2] - f[x_0, x_1]}{x_2 - x_1}$

**差商性质**：

1. **对称性**：$f[x_{i_0}, \ldots, x_{i_n}] = f[x_0, \ldots, x_n]$，对任意排列成立。
2. **递推性**：$f[x_0, \ldots, x_{n-1}, x_n] = \dfrac{f[x_1, \ldots, x_n] - f[x_0, \ldots, x_{n-1}]}{x_n - x_0}$

### 3.6 不同插值方法对比

| 方法 | 优点 | 缺点 |
|:--|:--|:--|
| 基本多项式插值 | 基函数简单、直观 | 系数矩阵满阵、条件数大 |
| Lagrange插值 | 插值函数构造简单、直接 | 基函数相对复杂 |
| Newton插值 | 新增插值点可避免重复计算 | 计算差商需要递推 |

### 3.7 多项式插值误差定理

设 $f \in C^{n+1}[a,b]$，$P_n(x)$ 是 $f$ 在区间 $[a,b]$ 的 $n+1$ 个不同点 $x_0, \ldots, x_n$ 上的次数不超过 $n$ 的插值多项式，则对任意 $x \in [a,b]$：

$$f(x) - P_n(x) = f[x_0, \ldots, x_n, x] \prod_{i=0}^n (x - x_i) = \frac{1}{(n+1)!} f^{(n+1)}(c) \prod_{i=0}^n (x - x_i)$$

其中 $c \in (a,b)$。

### 3.8 Runge现象

等距插值Runge函数（1901年）：$f(x) = \frac{1}{1 + 25x^2},\; x \in [-1,1]$。高阶等距插值在区间两端出现剧烈震荡。

### 3.9 Chebyshev多项式

**定义**：第一类 $n$ 阶 Chebyshev多项式：$T_n(x) = \cos(n \cos^{-1} x)$

**性质**：
- 递推关系：$T_{n+1} = 2x T_n - T_{n-1}$
- $T_n(x)$ 是 $n$ 次多项式，$n$ 次项系数是 $2^{n-1}\;(n \ge 1)$
- $T_n(1) = 1,\; T_n(-1) = (-1)^n$
- $T_n(x)$ 在 $x \in [-1,1]$ 上的最大绝对值是1
- $T_n(x)$ 的零点：$x = \cos\frac{(2k+1)\pi}{2n},\; k = 0,1,\ldots,n-1$
- $T_n(\cos\frac{k\pi}{n}) = (-1)^k,\; k = 0,1,\ldots,n$（达到极值点 -1 和 1 共 $n+1$ 次）

**首一多项式定理**：若 $p(x)$ 是 $n$ 次首一多项式，则 $\max_{-1 \le x \le 1} |p(x)| \ge 2^{1-n} = \max_{-1 \le x \le 1} |2^{1-n} T_n(x)|$。

### 3.10 Chebyshev插值

**标准区间 $[-1,1]$ 的Chebyshev插值误差定理**：

取插值节点为 $T_{n+1}(x)$ 的根：$x_i = \cos\frac{(2i+1)\pi}{2(n+1)},\; i = 0,1,\ldots,n$，则：

$$|f(x) - P_n(x)| \le \frac{1}{2^n (n+1)!} \max_{c \in [-1,1]} |f^{(n+1)}(c)|$$

**区间变换**：映射 $x = L(t) = \frac{2(t - \frac{b+a}{2})}{b-a}$ 将 $[a,b] \to [-1,1]$。

逆变换：$t = L^{-1}(x) = \frac{b-a}{2} x + \frac{b+a}{2}$。

在任意区间 $[a,b]$ 上的Chebyshev插值节点：

$$x_i = \frac{b-a}{2} \cos\frac{(2i+1)\pi}{2(n+1)} + \frac{b+a}{2},\; i = 0,1,\ldots,n$$

**任意区间 $[a,b]$ 的误差定理**：

$$|f(x) - P_n(x)| \le \frac{(\frac{b-a}{2})^{n+1}}{2^n (n+1)!} \max_{c \in (a,b)} |f^{(n+1)}(c)|$$

### 3.11 样条插值

样条函数是由具有某些连续条件的子区间上的分段多项式构成。结点 $x_0, \ldots, x_n$ 上的 $k$ 次样条函数 $S(x)$ 满足：
1. 每个子区间 $[x_{i-1}, x_i]$ 上，$S(x)$ 是次数 $\le k$ 的多项式
2. $S(x)$ 在 $[x_0, x_n]$ 上 $k-1$ 阶连续

**三次样条**：

$$S_i(x) = f(x_i) + b_i(x - x_i) + c_i(x - x_i)^2 + d_i(x - x_i)^3,\; i = 0, \ldots, n-1$$

共有 $3n$ 个未知数：
- 性质1（$n$个方程）：$S_i(x_{i+1}) = f(x_{i+1})$
- 性质2（$n-1$个方程）：$S_i'(x_{i+1}) = S_{i+1}'(x_{i+1})$
- 性质3（$n-1$个方程）：$S_i''(x_{i+1}) = S_{i+1}''(x_{i+1})$
- 自然边界条件（2个方程）：$S''(x_0) = 0,\; S''(x_n) = 0$

导出的线性方程组 $M c = \beta$ 为**对角占优**矩阵：

$$\delta_i c_i + 2(\delta_i + \delta_{i+1}) c_{i+1} + \delta_{i+1} c_{i+2} = 3\left(\frac{\Delta_{i+1}}{\delta_{i+1}} - \frac{\Delta_i}{\delta_i}\right)$$

其中 $\delta_i = x_{i+1} - x_i$，$\Delta_i = f(x_{i+1}) - f(x_i)$。

```mermaid
flowchart TD

    B -->|是| C[Newton插值: 差商递推]
```

| Lagrange基函数 | $l_i(x) = \prod_{j \neq i} \frac{x - x_j}{x_i - x_j}$ |

| 差商递推 | $f[x_0,\ldots,x_n] = \frac{f[x_1,\ldots,x_n] - f[x_0,\ldots,x_{n-1}]}{x_n - x_0}$ |
| 插值误差 | $f(x) - P_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!} \prod_{i=0}^n (x - x_i)$ |
| Chebyshev递推 | $T_{n+1}(x) = 2x T_n(x) - T_{n-1}(x)$ |
| Chebyshev节点 | $x_i = \cos\frac{(2i+1)\pi}{2(n+1)}$ |
| 区间变换 | $L(t) = \frac{2(t - \frac{b+a}{2})}{b-a}$ |

| 三次样条方程 | $\delta_i c_i + 2(\delta_i + \delta_{i+1}) c_{i+1} + \delta_{i+1} c_{i+2} = 3(\frac{\Delta_{i+1}}{\delta_{i+1}} - \frac{\Delta_i}{\delta_i})$ |

## 七、易错点与注意事项

> [!warning]
> - Vandermonde矩阵条件数随 $n$ 增长迅速增大，数值上不稳定，不推荐直接求解。
> - 等距节点的高阶多项式插值会产生Runge现象，阶数越高震荡越剧烈。
> - Newton差商的对称性意味着插值多项式与节点顺序无关。
> - Chebyshev插值需要做区间变换 $[a,b] \to [-1,1]$，节点分布不均匀（两端密集、中间稀疏）。
> - 三次样条的自然边界条件 $S''(x_0) = S''(x_n) = 0$ 是最常用但不是唯一的边界条件。
> - Lagrange插值和Newton插值是同一插值多项式的不同表达形式——多项式插值的唯一性保证。
> - 差商计算中分母可能很小（节点密集时），需注意舍入误差。
