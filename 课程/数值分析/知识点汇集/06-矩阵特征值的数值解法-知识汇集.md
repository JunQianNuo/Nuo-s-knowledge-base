# 第六章 矩阵特征值的数值解法 — 知识点汇集

## 一、本章核心脉络

核心问题：如何用迭代法求解矩阵的特征值和特征向量。幂法求"最大"特征值，逆幂法求"最小"，位移法求"靠近/远离某点"的；QR算法同时求出全部特征值。

```mermaid
flowchart TD
    A[特征值问题] --> B{求几个特征值?}
    B -->|单个| C[幂法族]
    B -->|全部| D[QR算法]
    C --> C1[幂法: 最大特征值]
    C --> C2[逆幂法: 最小特征值]
    C --> C3[位移幂法: 离μ最远]
    C --> C4[位移逆幂法: 离μ最近]
    D --> D1[QR分解]
    D1 --> D1a[Gram-Schmidt正交化]
    D1 --> D1b[Householder变换]
    D --> D2[归一化同时迭代]
    D --> D3[A_j → Q_j R_j → A_{j+1}=R_j Q_j]
```

## 二、基础定义

| 术语 | 符号/表述 | 含义 |
|:--|:--|:--|
| 幂迭代 | $x_k = A^k x_0$ | 反复左乘矩阵A，提取主特征向量 |
| 特征值 | $\lambda_i$ | $A v_i = \lambda_i v_i$ |
| 特征向量 | $v_i$ | $n$阶方阵$A$存在$n$个线性无关的特征向量 |
| Rayleigh商 | $\lambda = \frac{x^T A x}{x^T x}$ | 由近似特征向量估计特征值 |
| 线性收敛率 | $S \leq \|\lambda_2/\lambda_1\|$ | 幂法收敛速度的上界 |
| QR分解 | $A = QR$ | A分解为正交阵Q与上三角阵R |
| Householder反射子 | $H = I - 2\frac{v v^T}{v^T v}$ | 对称正交矩阵，$H^2=I$ |
| 投影矩阵 | $P = \frac{v v^T}{v^T v}$ | $P^T=P, P^2=P$ |

## 三、核心方法/定理

### 3.1 幂法

$A$为$n$阶方阵，存在$n$个线性无关的特征向量$v_1, \ldots, v_n$，$\lambda_i$是对应特征值。

**幂迭代**：

$$x_k = A^k x_0 = A^k(c_1 v_1 + c_2 v_2 + \cdots + c_n v_n) = \lambda_1^k\left[c_1 v_1 + \left(\frac{\lambda_2}{\lambda_1}\right)^k c_2 v_2 + \cdots + \left(\frac{\lambda_n}{\lambda_1}\right)^k c_n v_n\right]$$

**情形1**：$|\lambda_1| > |\lambda_2| \ge \cdots \ge |\lambda_n|$，$c_1 \neq 0$

$$\lim_{k \to \infty} x_k = \lambda_1^k\left[c_1 v_1 + \left(\frac{\lambda_2}{\lambda_1}\right)^k c_2 v_2\right]$$

- 特征向量：$v_1 \approx x_k$
- 特征值：$\lambda_1 \approx r_k = \frac{x_k^{(i)}}{x_{k-1}^{(i)}},\; x_{k-1}^{(i)} \neq 0,\; 1 \le i \le n$
- 线性收敛率：$S \leq |\lambda_2 / \lambda_1|$

**情形2**：$\lambda_1 = \lambda_2 > \cdots \ge \lambda_n$，$\lambda_1 = -\lambda_2$

$$\lim_{k \to \infty} x_k = \lambda_1^k\left[c_1 v_1 + (-1)^k c_2 v_2\right]$$

- 特征值：$\lambda_1^2 \approx \frac{x_k^{(i)}}{x_{k-2}^{(i)}}$
- 特征向量：$v_1 \approx x_k + \lambda_1 x_{k-1},\quad v_2 \approx x_k - \lambda_1 x_{k-1}$
- 线性收敛率：$S \leq |\lambda_3 / \lambda_1|$

### 3.2 幂法族

| 方法 | 公式 | 求什么 |
|:--|:--|:--|
| 逆幂法 | $x_{k+1} = A^{-1} x_k$（即 $A x_{k+1} = x_k$） | 模最小特征值及特征向量 |
| 位移幂法 | $x_{k+1} = (A - \mu I) x_k$ | 离 $\mu$ 最远的特征值及特征向量 |
| 位移逆幂法 | $(A - \mu I) x_{k+1} = x_k$ | 离 $\mu$ 最近的特征值及特征向量 |

### 3.3 Rayleigh商迭代

已知 $x$ 是 $A$ 的近似特征向量，求对应特征值的近似：$Ax \approx \lambda x$（超定方程）。最小化残差得Rayleigh商：

$$\lambda = \frac{x^T A x}{x^T x}$$

**Rayleigh商迭代算法**：

```
x ← x₀
for k = 0 to k_max do
    u ← x / ‖x‖₂
    x ← A u
    λ ← u^T x
end for
```

### 3.4 Gram-Schmidt正交化与QR分解

若 $m \times n$ 矩阵 $A$ 的列向量 $A_1, \ldots, A_n \in \mathbb{R}^m$ 线性无关（$m \ge n$）：

1. $y_1 = A_1,\; q_1 = y_1 / \|y_1\|_2$
2. $y_j = A_j - q_1^T A_j q_1 - \cdots - q_{j-1}^T A_j q_{j-1},\; q_j = y_j / \|y_j\|_2$

定义 $r_{jj} = \|y_j\|_2$，$r_{ij} = q_i^T A_j$，则有：

$$A_j = r_{1j} q_1 + \cdots + r_{j-1,j} q_{j-1} + r_{jj} q_j$$

- **消减QR分解**（$m \ge n$）：$A_{m \times n} = Q_{m \times n} R_{n \times n}$
- **完全QR分解**（$m > n$）：任意增加 $m-n$ 个向量构成线性无关组，继续正交化

### 3.5 Householder变换

**引理**：$x, w \in \mathbb{R}^n$，若 $\|x\|_2 = \|w\|_2$，则 $\langle w-x, w+x \rangle = 0$。

投影矩阵 $P$ 满足 $P^T = P$（对称），$P^2 = P$（幂等）。$P = \frac{v v^T}{v^T v}$ 是投影矩阵，$Pu$ 是 $u$ 在 $v$ 上的投影。

**定理**：对 $x, w \in \mathbb{R}^n$ 且 $\|x\|_2 = \|w\|_2$，定义 $v = w - x$，$H = I - 2\frac{v v^T}{v^T v}$，则 $H$ 为对称正交矩阵，且 $H x = w$。

$H$ 是Householder反射子，$H x$ 是 $x$ 关于超平面 $v^\perp$ 的镜像。

**Householder QR分解算法**：逐列约化。

第1步：若 $\|A^{(1)}\|_2 = 0$，$H_1 = I$，跳到第2步。否则：

$$r_{11} = \|A^{(1)}\|_2,\; w = r_{11} e_1$$

为避免相近数相减，取 $r_{11} = \begin{cases} -\|A^{(1)}\|_2, & a_{11} > 0 \\ \|A^{(1)}\|_2, & a_{11} < 0 \end{cases}$

$$v = w - A^{(1)},\; H_1 = I - 2\frac{v v^T}{v^T v}$$

$n$ 步后：$H_n \cdots H_1 A = R \Rightarrow A = \underbrace{H_1 \cdots H_n}_{Q} R$

### 3.6 QR算法

**思路**：$n$阶实对称阵 $A$ 的特征向量构成正交基 $v_1, \ldots, v_n$。选取一组正交向量同时迭代，每次迭代后正交化，最终得到所有特征向量及特征值。

**归一化同时迭代算法**：

$$Q_0 = I$$
$$\text{for } j = 0 \text{ to } N_{iter}:$$
$$\quad A Q_j = Q_{j+1} R_{j+1}$$

**QR算法**：

$$A_0 \leftarrow A$$
$$\text{for } j = 0 \text{ to } N_{iter}:$$
$$\quad A_j = Q_j R_j$$
$$\quad A_{j+1} = R_j Q_j$$

性质：$A_{j+1} = R_j Q_j = Q_j^T A_j Q_j$，$R$ 的对角收敛到特征值。

## 四、计算/应用

### 4.1 幂法例题
用幂法和逆幂法求 $A$ 的最大模和最小模特征值，$A$ 的特征值为 $\lambda = 6, 3, 2$（来源 slide 91）。

### 4.2 Gram-Schmidt QR分解例题
对 $A$ 进行消减QR分解（来源 slide 94）：
- $y_1 = A_1 = [1,2,2]^T$，$r_{11} = \|y_1\|_2 = 3$，$q_1 = [\frac{1}{3},\frac{2}{3},\frac{2}{3}]^T$
- $r_{12} = q_1^T A_2 = 2$，$y_2 = A_2 - r_{12} q_1$，$r_{22} = \|y_2\|_2 = 5$，$q_2$ 为归一化结果

### 4.3 Householder QR分解例题
利用Householder反射子对矩阵 $A$ 做QR分解（来源 slides 103-104）：
1. 约化第一列：计算 $v$，得 $H_1$，$H_1 A$
2. 约化第二列：类似处理得 $H_2$
3. $Q = H_1 H_2$，$A = QR$

## 七、易错点与注意事项

> [!warning]
> - 幂法的收敛速度取决于 $|\lambda_2 / \lambda_1|$——比值越接近1，收敛越慢。
> - 幂法初始向量必须包含 $v_1$ 分量（$c_1 \neq 0$），否则会收敛到其他特征向量。
> - $\lambda_1 = -\lambda_2$ 时幂迭代震荡，需用 $x_k$ 和 $x_{k-1}$ 组合解出两个特征向量。
> - Gram-Schmidt正交化在数值上可能不稳定（舍入误差导致正交性丢失）；Householder变换更稳定。
> - Householder约化时要注意符号选取，避免相近数相减损失精度。
> - QR算法每次迭代需要做QR分解，但随迭代进行矩阵趋向对角形。
> - Rayleigh商迭代可利用平方收敛性质加速。
