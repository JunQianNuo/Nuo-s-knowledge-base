## 《深度学习》课程作业03

Exercise 1 (50pts)

用 Python + numpy/torch 等命令库编程, 实现用全连接神经网络对一个未知的 10 维函数 f : K →R 进行回归, 其中 $K = [ - 1 , 1 ] ^ { 1 0 } \subset \mathbb { R } ^ { 1 0 }$

(1) 用 pickle 库读取数据集文件 hw03 1.data. 其中 x train 和 y train 分别为训练数据集的全体特征向量和对应标签 (矩阵 x train 的每一行表示一个特征向量); x test 和 y test 分别为测试数据集的全体特征向量和对应标签 (矩阵 x test 的每一行表示一个特征向量).

(2) 用一个全连接神经网络通过训练数据集学习 f, 并将训练后的神经网络在测试集上进行测试. 最终, 输出训练损失、训练误差、测试误差和泛化差距. 其中, 网络的深度设置为 3 (即2个隐藏层), 隐藏层的宽度均设置为 100, 隐藏层激活函数选用 ReLU, 输出层不使用激活函数, 损失函数选用 ℓ<sup>2</sup>-损失, 优化算法选用最速下降法或随机梯度下降法, epoch 总数和学习率可以自行设置. 训练数据集中的 y 是 f 在对应 x 下的真值, 即 $y = f ( x )$ . 训练数据集中共有 10<sup>6</sup> 个数据点, 可以根据所用的设备算力选取部分数据进行学习, 不要求必须使用全部数据点进行训练.

(3) 在(2)的基础上, 将网络的深度调整为 2,4,5, 并将不同深度的神经网络的结果进行比较.

(4) 在(2)的基础上, 将网络的宽度调整为 50,150,200, 并将不同宽度的神经网络的结果进行比较.

(5) 在(2)的基础上, 将隐藏层的激活函数调整为 logistic sigmoid 函数和 softplus 函数, 并将不同激活函数的神经网络的结果进行比较.

(6) 在(2)的基础上, 将优化算法调整为 AdaGrad 算法和 RMSProp 算法和 Adam 算法, 但学习率保持一致. 将不同优化算法的结果进行比较.

Exercise 2 (50pts)

用 Python + numpy/torch 等命令库编程, 实现用全连接神经网络对 1D 的 MNIST 手写数字数据集进行分类. 全体类别用整数 {0,1,2,...,9} 表示. 关于数据集的具体信息可参考

https://github.com/greydanus/mnist1d.

(1) 用 pickle 库读取数据集文件 hw03 2.data. 其中 x train 和 y train 分别为训练数据集的全体特征向量和对应标签 (矩阵 x train 的每一行表示一个特征向量); x test 和 y test 分别为测试数据集的全体特征向量和对应标签 (矩阵 x test 的每一行表示一个特征向量). 训练数据集和测试数据集分别有 4000 和 1000 个数据点.

(2) 用一个全连接神经网络通过训练数据集对潜在的分类函数进行学习, 并将训练后的神经网络在测试集上进行测试. 最终, 输出训练损失和测试准确率. 其中, 网络的深度设置为 3 (即2个隐藏层),隐藏层的宽度均设置为 100, 隐藏层激活函数选用 ReLU, 输出层激活函数选用 softmax 函数, 损失函数选用交叉熵损失, 优化算法选用最速下降法或随机梯度下降法, epoch 总数和学习率可以自行设置. 训练数据集中的 y 是对应 x 所属的真实类别.

(3) 在(2)的基础上, 将网络的深度调整为 2,4,5, 并将不同深度的神经网络的结果进行比较.

(4) 在(2)的基础上, 将网络的宽度调整为 50,150,200, 并将不同宽度的神经网络的结果进行比较.

(5) 在(2)的基础上, 将隐藏层的激活函数调整为 logistic sigmoid 函数和 softplus 函数, 并将不同激活函数的神经网络的结果进行比较.

(6) 在(2)的基础上, 将优化算法调整为 AdaGrad 算法和 RMSProp 算法和 Adam 算法, 但学习率保持一致. 将不同优化算法的结果进行比较.
