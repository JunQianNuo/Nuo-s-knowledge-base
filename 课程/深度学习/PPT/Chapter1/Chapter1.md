## 机器学习实例: 线性回归线性模型 $f : \mathbb { R } ^ { d } $ R

$$
\begin{array}{c} {{f (x _ {1}, \ldots , x _ {d}) = w _ {1} x _ {1} + \dots + w _ {d} x _ {d} + b}} \\ {{\text {或} f (\pmb {x}) = \pmb {w} ^ {\top} \pmb {x} + b,}} \end{array}
$$

其中 $\pmb { x } = [ x _ { 1 } \dots x _ { d } ] ^ { \top } \in \mathbb { R } ^ { d }$ 是函数的变量; $b \in \mathbb { R } , \pmb { w } = [ \pmb { w } _ { 1 } \dots \pmb { w } _ { d } ] ^ { \top } \in \mathbb { R } ^ { d }$ 称为该线性模型的参数. f(x) 有时也可记作 $f ( \pmb { x } ; \pmb { w } , b )$

## 机器学习实例: 线性回归线性模型 f : R<sup>d</sup> → R

$$
\begin{array}{c} {{f (x _ {1}, \ldots , x _ {d}) = w _ {1} x _ {1} + \dots + w _ {d} x _ {d} + b}} \\ {{\text {或} f (\pmb {x}) = \pmb {w} ^ {\top} \pmb {x} + b,}} \end{array}
$$

其中 $\pmb { x } = [ x _ { 1 } \dots x _ { d } ] ^ { \top } \in \mathbb { R } ^ { d }$ 是函数的变量; $b \in \mathbb { R }$ $\pmb { w } = [ w _ { 1 } \mathopen { . . } \mathclose \bgroup \mathopen { . . } w _ { d } ] ^ { \top } \in \mathbb { R } ^ { d }$ 称为该线性模型的参数. f(x) 有时也可记作 $f ( \pmb { x } ; \pmb { w } , b )$

考虑用上述模型 f(x) 拟合一个数据集. 给定数据集 $\{ ( x _ { n } , y _ { n } ) \} _ { n = 1 } ^ { N }$ , 我们希望模型在 ${ \pmb x } _ { n }$ 上的取值尽可能接近真实数据值 $y _ { n }$ , 即 $f ( { \pmb x } _ { n } ) \approx { \pmb y } _ { n }$

## 机器学习实例: 线性回归线性模型 f : R<sup>d</sup> → R

$$
\begin{array}{c} {{f (x _ {1}, \ldots , x _ {d}) = w _ {1} x _ {1} + \dots + w _ {d} x _ {d} + b}} \\ {{\text {或} f (\pmb {x}) = \pmb {w} ^ {\top} \pmb {x} + b,}} \end{array}
$$

其中 $\pmb { x } = [ x _ { 1 } \dots x _ { d } ] ^ { \top } \in \mathbb { R } ^ { d }$ 是函数的变量; $b \in \mathbb { R }$ $\pmb { w } = [ w _ { 1 } \mathopen { . . } \mathclose \bgroup \mathopen { . . } w _ { d } ] ^ { \top } \in \mathbb { R } ^ { d }$ 称为该线性模型的参数. f(x) 有时也可记作 $f ( \pmb { x } ; \pmb { w } , b )$

考虑用上述模型 f(x) 拟合一个数据集. 给定数据集 $\{ ( x _ { n } , y _ { n } ) \} _ { n = 1 } ^ { N }$ , 我们希望模型在 ${ \pmb x } _ { n }$ 上的取值尽可能接近真实数据值 $y _ { n }$ , 即 $f ( { \pmb x } _ { n } ) \approx { \pmb y } _ { n }$

最小化上述模型逼近的均方误差(Mean Square Error), 即

$$
\min _ {f} \frac {1}{N} \sum_ {n = 1} ^ {N} | f (\pmb {x} _ {n}) - y _ {n} | ^ {2}
$$

$$
\text {或} \min _ {\pmb {w}, b} \frac {1}{N} \sum_ {n = 1} ^ {N} | \pmb {w} ^ {\top} \pmb {x} _ {n} + b - y _ {n} | ^ {2}
$$

求解

$$
\min _ {\boldsymbol {w}, b} \frac {1}{N} \sum_ {n = 1} ^ {N} | \boldsymbol {w} ^ {\top} \boldsymbol {x} _ {n} + b - y _ {n} | ^ {2}
$$

求解

$$
\min _ {\boldsymbol {w}, b} \frac {1}{N} \sum_ {n = 1} ^ {N} | \boldsymbol {w} ^ {\top} \boldsymbol {x} _ {n} + b - y _ {n} | ^ {2}
$$

即求解下述线性方程组的最小二乘解

$$
\left[ \begin{array}{c c} \boldsymbol {x} _ {1} ^ {\top} & 1 \\ \boldsymbol {x} _ {2} ^ {\top} & 1 \\ \dots & \dots \\ \boldsymbol {x} _ {n} ^ {\top} & 1 \end{array} \right] \left[ \begin{array}{c} \boldsymbol {w} \\ b \end{array} \right] \approx \left[ \begin{array}{c} y _ {1} \\ y _ {2} \\ \dots \\ y _ {N} \end{array} \right].
$$

求解

$$
\min _ {\boldsymbol {w}, b} \frac {1}{N} \sum_ {n = 1} ^ {N} | \boldsymbol {w} ^ {\top} \boldsymbol {x} _ {n} + b - y _ {n} | ^ {2}
$$

即求解下述线性方程组的最小二乘解

$$
\left[ \begin{array}{c c} \boldsymbol {x} _ {1} ^ {\top} & 1 \\ \boldsymbol {x} _ {2} ^ {\top} & 1 \\ \dots & \dots \\ \boldsymbol {x} _ {n} ^ {\top} & 1 \end{array} \right] \left[ \begin{array}{c} \boldsymbol {w} \\ b \end{array} \right] \approx \left[ \begin{array}{c} y _ {1} \\ y _ {2} \\ \dots \\ y _ {N} \end{array} \right].
$$

它可以通过QR分解或求解正规方程等算法求解. 记最小二乘解为 $( w ^ { * } , b ^ { * } )$ ), 则相应的模型 $f ( \pmb { x } ; \pmb { w } ^ { * } , b ^ { * } ) = \pmb { w } ^ { * } { } ^ { \top } \pmb { x } + b ^ { * }$ 就是该数据集的最小二乘逼近/拟合.

## 多项式回归若数据集较复杂线性模型未必能较精确地拟合数据集此时可采用更复杂的模型如多项式模型

$$
p (x _ {1}, \ldots , x _ {d}) = \sum_ {0 \leq i _ {1} + i _ {2} + \dots + i _ {d} \leq P} w _ {i _ {1} \ldots i _ {d}} x _ {1} ^ {i _ {1}} \ldots x _ {d} ^ {i _ {d}},
$$

其中, $i _ { 1 } , \dots , i _ { d }$ 为非负整数; 正整数P为多项式的最高次数.

## 多项式回归若数据集较复杂线性模型未必能较精确地拟合数据集此时可采用更复杂的模型如多项式模型

$$
p (x _ {1}, \ldots , x _ {d}) = \sum_ {0 \leq i _ {1} + i _ {2} + \dots + i _ {d} \leq P} w _ {i _ {1} \ldots i _ {d}} x _ {1} ^ {i _ {1}} \ldots x _ {d} ^ {i _ {d}},
$$

其中, $i _ { 1 } , \dots , i _ { d }$ 为非负整数; 正整数P为多项式的最高次数.

例如, 当 $d = 2 , P = 2$ 时,

$$
p (x _ {1}, x _ {2}) = w _ {0 0} + w _ {1 0} x _ {1} + w _ {0 1} x _ {2} + w _ {2 0} x _ {1} ^ {2} + w _ {1 1} x _ {1} x _ {2} + w _ {0 2} x _ {2} ^ {2}.
$$

与线性回归类似, 用于拟合数据集 $\{ ( x _ { n } , y _ { n } ) \} _ { n = 1 } ^ { N }$ 的多项式回归如下

$$
\min _ {p} \frac {1}{N} \sum_ {n = 1} ^ {N} | p (\boldsymbol {x} _ {n}) - y _ {n} | ^ {2}.
$$

## PyTorch使用入门及CPU/GPU设置

PyTorch官方文档: https://pytorch.org/docs/stable/index.html

PyTorch的核心数据结构是 , 可用于统一表示标量、向量、矩阵及高阶数组. 每个Tensor有两个彼此独立的重要属性:

▶ 数据类型<sub>dtype</sub>: 如<sub>torch.float32</sub>、<sub>torch.float64</sub>;

▶ 计算设备<sub>device</sub>: 如<sub>cpu</sub>、<sub>cuda:0</sub>.

推荐在程序中显式选择计算设备

```python
use_cuda = torch.cuda.is_available()
device = torch.device('cuda' if use_cuda else 'cpu')
x = torch.tensor(data, dtype=torch.float32, device=device)
```

已有Tensor或模型可以用以下方式迁移到目标设备:

```txt
x = x.to(device) model = model.to(device)
```

注意: 参与同一次运算的Tensor和模型参数必须位于同一设备; PyTorch通常不会自动在CPU与GPU之间移动数据.

## Tensor的创建与基本属性

torch.tensor(data, ...) 由Python数据创建Tensor; 可指定<sub>dtype</sub>和<sub>device</sub>

torch.from\_numpy(array) 将NumPy数组转化为Tensor, 二者共享内存

tensor1.shape 返回Tensor的形状, 类型为<sub>torch.Size</sub>

tensor1.dtype 返回具体数据类型, 如<sub>torch.float32</sub>、torch.int64

tensor1.device 返回Tensor所在的计算设备, 如<sub>cpu</sub>、<sub>cuda:0</sub>

tensor1.requires\_grad 返回是否记录相关运算, 以便计算相对于该Tensor的梯度
