## 二、容量、数据量与泛化

提高多项式次数可以扩大假设空间，使训练误差下降，但模型可能变得不稳定。数据量增加后，模型需要同时解释更多样本，固定优化预算下训练可能更困难；另一方面，更丰富的数据通常能约束模型，降低测试误差并改善泛化。

> [!note] 关于“训练误差随数据量增加”
> 课堂结论依赖于固定模型、优化器和训练预算。若比较的是平均训练误差并允许充分优化，它并不必然单调增加；理解时要明确误差定义与实验条件。

### 正则化

为限制系数过大，可在经验损失后加入惩罚项：

$$
L_{\lambda}(w)=\frac{1}{N}\sum_{n=1}^{N}\left(\hat f(x_n)-y_n\right)^2+\lambda\Vert w\Vert_2^2.
$$

$\lambda$ 控制拟合数据与约束复杂度之间的权衡。$\lambda$ 太小可能仍过拟合，太大则可能把模型压得过于简单。

## 三、NumPy 常用操作

### 1. 数组创建与形状

```python
import numpy as np

z = np.zeros((3, 4))
x = np.linspace(-1.0, 1.0, 100)
k = np.arange(0, 10, 2)
A = np.array([[1.0, 2.0], [3.0, 4.0]])
```

`shape` 决定运算含义。`reshape` 只改变视图或排列方式，不应改变元素总数：

```python
column = x.reshape(-1, 1)
```

### 2. 切片与矩阵运算

```python
row = A[0, :]
col = A[:, 1]
block = A[:2, :2]

elementwise = A * A   # 对应元素相乘
matrix_product = A @ A
```

> [!warning] `*` 与 `@`
> NumPy 中 `*` 是逐元素乘法，`@` 才是矩阵乘法。向量是一维还是列向量会影响广播和结果形状，运算前应检查 `shape`。

### 3. 随机数与可复现性

固定随机种子可以让数据划分、初始化和噪声样本可复现：

```python
rng = np.random.default_rng(42)
noise = rng.uniform(-0.1, 0.1, size=100)
```

## 四、多项式回归实现

设目标函数为 $f(x)=\sin(2\pi x)$，多项式次数为 $P$。设计矩阵可写成范德蒙德形式：

$$
A_{nk}=x_n^k,\qquad n=1,\ldots,N,\quad k=0,\ldots,P.
$$

目标是求解最小二乘问题

$$
\min_w\Vert Aw-y\Vert_2^2.
$$

NumPy 实现：

```python
x_train = np.linspace(-1.0, 1.0, 100)
y_train = np.sin(2 * np.pi * x_train)

degree = 7
A = np.vander(x_train, N=degree + 1, increasing=True)
w, *_ = np.linalg.lstsq(A, y_train, rcond=None)

x_test = np.linspace(-1.0, 1.0, 200)
A_test = np.vander(x_test, N=degree + 1, increasing=True)
y_pred = A_test @ w
```

训练点和测试点可以数量不同，但应来自同一目标分布；绘图用的密集网格也不能误当成独立测试集。

## 五、神经元的数学模型

单个神经元把输入向量先作仿射变换，再经过非线性激活：

$$
z=w^{\mathsf T}x+b,\qquad y=\sigma(z).
$$

![[课程/深度学习/PPT/Chapter3/images/9ac5cc8a34039e27f5df72fdcf81e50883258af04a2f85021c89637caa2bf411.jpg|560]]

*图：人工神经元由加权求和、偏置与激活函数组成。*

若没有非线性激活，多层线性变换复合后仍是线性变换，增加层数也无法表达更复杂的非线性关系。因此，激活函数是深层网络获得非线性表示能力的关键。

## 六、常见激活函数

### 1. 阶跃函数

$$
H(x)=\begin{cases}0,&x<0,\\1,&x\ge 0.\end{cases}
$$

适合解释二值决策，但在跳点不可导，通常不用于现代网络的梯度训练。

### 2. ReLU 与变体

$$
\operatorname{ReLU}(x)=\max(0,x).
$$

![[课程/深度学习/PPT/Chapter3/images/815e1f7e7b94b8978449412429ff4f0c8f90694e99159071d16a9c24b818cdcf.jpg|380]]

ReLU 计算简单、正半轴梯度稳定，是隐藏层常用选择；负半轴梯度为零可能造成“死亡 ReLU”。Leaky ReLU 在负半轴保留小斜率，ELU 则使用平滑的负值分支。

### 3. Sigmoid 与 Softplus

$$
\sigma(x)=\frac{1}{1+e^{-x}},\qquad
\operatorname{softplus}(x)=\log(1+e^x).
$$

Sigmoid 输出在 $(0,1)$ 内，常用于二分类输出概率，但输入绝对值大时梯度趋近于零。Softplus 是 ReLU 的平滑近似，处处可导。

## 七、易错点与课后任务

> [!warning] 易错点
> - 正则化惩罚的是参数规模，不等于直接限制多项式次数。
> - 训练集、验证集、测试集承担不同职责，不应混用。
> - `reshape`、广播和矩阵乘法错误常不会立即报错，却会改变数学含义。
> - 激活函数应结合网络层位置与任务选择，不存在对所有问题都最优的函数。
