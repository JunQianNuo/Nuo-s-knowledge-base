## 世界观总纲

| 观念 | 马克思主义立场 | 对立面 |
|:---|:---|:---|
| 世界本原 | **物质**（唯物主义一元论） | 唯心主义、二元论 |
| 世界状态 | **联系、发展、有矛盾**（辩证法） | 形而上学（孤立、静止、片面、无矛盾） |
| 世界可知性 | **可知论**（思维与存在有同一性） | 不可知论 |
| 世界统一性 | 统一于**物质性**，是**多样性的统一** | — |

## 一、物质观

### 列宁物质定义
> 物质是标志**客观实在**的哲学范畴，不依赖于感觉而存在，为感觉所复写、摄影、反映。

- 唯一特性：**客观实在性**
- 根本属性：**运动**

### 存在方式
- **运动**：物质的根本属性和存在方式。运动是**绝对的**，静止是**相对的**。
- **时空**：运动着的物质的基本存在形式。物质运动与时空不可分割。

### 世界二重化
```
自然界 ←→ 人类社会
客观世界 ←→ 主观世界
```
人的**实践**是分化与统一的关键。

### 物质与意识的关系
- 物质**决定**意识（表现在意识的起源和本质上）
- 意识**反作用**于物质（目的性/创造性/指导实践/调控行为）

> **基本立场**：唯物主义 + 辩证法 = 既承认物质决定意识，又承认意识能动反作用。

---

## 二、意识观 / 精神观

### 意识的本质
> 意识是**人脑的机能和属性**，是**物质世界的主观映像**。

- 起源：自然界长期发展的产物 + 社会实践的产物
- 本质：人脑机能 + 客观世界的主观映像

### 主观能动性与客观规律性
- 尊重客观规律是发挥主观能动性的**前提**
- 充分发挥主观能动性是认识和利用规律的**必要条件**
- 正确发挥的条件：**从实际出发**（前提）→ **实践**（根本途径）→ **一定物质条件**

### 对人工智能的立场
- AI 只模拟**理性智能**，不具备情感、信念、意志
- AI 不具备真正的**社会属性**
- 人脑有**不可化约**的内容
- 结论：**AI 不能取代人类智能**

## 三、辩证法观念（怎么看世界的变化）

### 两大总观点
| 观念 | 核心 |
|:---|:---|
| **普遍联系** | 事物内部/事物之间/整个世界相互联系（客观/普遍/多样/有条件） |
| **永恒发展** | 新事物战胜旧事物（扬弃） |

### 矛盾观（对立统一规律）
> 矛盾 = 对立统一。同一性和斗争性是两种基本属性。

| | 同一性 | 斗争性 |
|:---|:---|:---|
| 本质 | 相互依存、相互贯通 | 相互排斥、相互分离 |
| 条件性 | 有条件、相对 | 无条件、绝对 |
| 作用 | 存在发展前提 / 吸收有利因素 / 规定转化趋势 | 促进力量变化 / 决定过渡 |

**矛盾精髓**：普遍性（共性/无条件）寓于特殊性（个性/有条件）之中。

**不平衡性**：事物的性质由**主要矛盾的主要方面**决定。方法论：**两点论 + 重点论**。

### 发展观（质量互变 + 否定之否定）

| 规律 | 揭示 | 关键概念 |
|:---|:---|:---|
| 质量互变 | 发展的**状态**（渐进与飞跃统一） | 质/量/度，关节点，适度原则 |
| 否定之否定 | 发展的**趋势**（前进与曲折统一） | 扬弃，两次否定三个阶段 |

### 辩证否定观
> 否定 = 自我否定 + 发展环节 + 联系环节 + **扬弃**（既批判又继承）

## 四、实践观

### 实践的本质
> 人类**能动地改造世界**的**社会性的物质活动**。

### 三大特征
客观实在性 / 自觉能动性 / 社会历史性

### 三大形式
物质生产实践（最基本）→ 社会政治实践 → 科学文化实践

### 实践的核心地位
- 实践是**马克思主义的基本观点**
- **实践性**是马克思主义区别于其他理论的根本特征
- 实践是认识的来源、动力、目的、检验标准
- 实践是世界二重化（自然界↔人类社会、客观↔主观）的**关键**

---

## 五、认识观

### 认识的本质
> 主体在**实践基础**上对客体的**能动反映**。

- 既不是先验论（唯心主义），也不是直观反映论（旧唯物主义）

### 认识过程
```
实践 → 感性认识 → 理性认识 → 实践 → ...
      第一次飞跃    第二次飞跃（更重要）
```

### 感性 vs 理性
| | 感性 | 理性 |
|:---|:---|:---|
| 阶段 | 初级 | 高级 |
| 对象 | 现象、外部联系 | 本质、内部联系、规律 |
| 特点 | 直接性、具体性 | 间接性、抽象性 |
| 形式 | 感觉→知觉→表象 | 概念→判断→推理 |

> 二者**辩证统一**：理性依赖感性，感性需深化为理性，相互渗透包含。
> 偏差：片面夸大感性 → 经验主义；片面夸大理性 → 教条主义。

## 六、真理观

### 真理的定义
> 真理是标志**主观与客观相符合**的哲学范畴，是对客观事物及其规律的**正确反映**。

### 真理三性
| 属性 | 核心 |
|:---|:---|
| **客观性**（本质属性） | 内容客观（不以人的意志为转移），形式主观 |
| **绝对性** | 主客观统一的确定性 + 发展的无限性 |
| **相对性** | 一定条件下认识的有限性和不完善性 |

> 绝对主义 → 教条主义/思想僵化。相对主义 → "过时论"/否定马克思主义原理。

### 真理检验标准
实践是**唯一**标准（因为实践具有**直接现实性**，能连接主客观）。
逻辑证明只能**补充**，不能取代。

### 真理与谬误
- 相互对立 ↔ 在一定条件下**相互转化**
- 真理**同谬误相比较而存在、相斗争而发展**

### 真理一元论
> 认识形式可以多元，但**真理内容是一元的**（同一条件下对同一对象的真理性认识只有一个）。

---

## 七、价值观

### 价值的定义
> 价值是反映**主体和客体之间意义关系**的哲学范畴。

### 四个特性
主体性（以主体为中心）/ 客观性（不依赖主观意识）/ 多维性 / 社会历史性

### 真理尺度与价值尺度
| | 真理尺度 | 价值尺度 |
|:---|:---|:---|
| 含义 | 按**规律**办事（该怎么做） | 按**需要**办事（想怎么做） |
| 性质 | 外在尺度 | 内在尺度 |

> 成功实践 = **真理尺度 + 价值尺度的统一** = 合规律性 + 合目的性。

---

## 八、历史观（怎么看社会）

### 基本立场：唯物史观
> **社会存在决定社会意识**（不是相反）。

| 观念 | 马克思主义立场 |
|:---|:---|
| 社会历史的决定力量 | **物质生产方式** |
| 社会发展的根本动力 | **社会基本矛盾** |
| 历史的创造者 | **人民群众** |
| 社会形态更替 | **必然性与选择性统一** |

### 社会结构观
```
生产力（人与自然）
    ↕ 决定+反作用
生产关系（人与人的经济关系）= 经济基础
    ↕ 决定+反作用
上层建筑 = 政治上层建筑（国家政权为核心）+ 观念上层建筑（意识形态）
```

### 阶级观
- 阶级的存在同**生产发展的一定历史阶段**相联系
- 阶级斗争是阶级社会发展的**直接动力**
- 一切阶级斗争归根结底围绕**经济利益**展开

### 群众观
> 人民群众是历史的创造者。

四层含义：物质财富创造者 / 精神财富创造者 / 社会变革的决定力量 / 先进生产力和文化的创造主体

群众路线：一切为了群众，一切依靠群众。从群众中来，到群众中去。

### 国家观
- 国家是**阶级矛盾不可调和**的产物
- 本质是**阶级统治的工具**
- 国家政权是政治上层建筑的**核心**

## 九、经济观（怎么看资本主义）

### 劳动价值论
- **价值**：凝结在商品中的无差别人类劳动
- **价值量**：由社会必要劳动时间决定
- **劳动二重性**：具体劳动形成使用价值，抽象劳动形成价值
- **基本矛盾**：私人劳动 vs 社会劳动

### 剩余价值论
- **资本**：能带来剩余价值的价值。本质不是物，是**生产关系**。
- **剩余价值**：雇佣工人创造、被资本家无偿占有的超过劳动力价值的价值
- **剥削率**：m' = m/v
- **不变资本 c**（转移不增殖）vs **可变资本 v**（再生产且增殖）

### 资本积累观
- 本质：剩余价值资本化，扩大对工人的剥削和统治
- 趋势：财富两极分化 + 相对过剩人口（失业）
- 历史趋势：**资本主义必然灭亡，社会主义必然胜利**（两个必然）

### 危机观
- 基本矛盾：**生产社会化 vs 生产资料资本主义私人占有**
- 危机本质：**生产过剩**
- 周期：危机 → 萧条 → 复苏 → 高涨

### 对资本主义上层建筑的立场
- 国家：资产阶级进行**阶级统治的工具**
- 民主：**金钱操纵**下的资产阶级精英统治
- 平等：法律名义平等掩盖**事实不平等**
- 意识形态：资产阶级**阶级意识的集中体现**

## 十、关键立场对立表

| 问题 | 马克思立场 | 对立立场 |
|:---|:---|:---|
| 世界本原 | 唯物主义一元论 | 唯心主义/二元论 |
| 世界可知否 | 可知论 | 不可知论 |
| 世界怎样存在 | 辩证法（联系/发展/矛盾） | 形而上学（孤立/静止/片面） |
| 认识来源 | 实践 → 能动反映 | 先验论 / 直观反映论 |
| 真理标准 | **实践**唯一标准 | 逻辑/权威/多数 |
| 历史决定力量 | **生产方式** | 地理环境 / 人口 / 英雄 |
| 历史创造者 | **人民群众** | 英雄/少数精英 |
| 资本本质 | 社会生产关系 | 物（机器/货币本身） |
| 价值来源 | **抽象劳动** | 供求 / 效用 / 机器 |
| 工资本质 | 劳动力的价值/价格 | 劳动的全部报酬 |
