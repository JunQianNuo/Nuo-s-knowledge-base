## 使用建议

1. **先过一遍复习纲要**：[[../复习纲要|复习纲要]] 列出了全部 63 个核心问题
2. **按板块逐个复习**：每个子文件按"定义速查→核心原理→典型问答→易错点"组织
3. **重点关注概念辨析**：[[复习/常考查的概念辨析|常考查的概念辨析]] 汇总了 10 组易混淆概念对
4. **掌握材料分析模板**：[[复习/材料分析题模板|材料分析题模板]] 覆盖唯物论/辩证法/认识论/唯物史观/守正创新五大类
5. **需要深入理解时回看知识梳理**：[[知识点解析梳理/01-导论-知识梳理|知识梳理]] 有"一句话来说"直观理解和 Mermaid 概念演进图
6. **政治经济学部分重计算**：剩余价值率 $m' = M/V$、商品价值 $W = C+V+M$、预付总资本周转次数需动手练习
