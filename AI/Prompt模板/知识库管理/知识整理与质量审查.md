# 知识整理与质量审查

## 适用场景

课程资料转写后整理、章节笔记补链接、概念卡生成、收件箱分流、质量审查报告解读。

## Prompt

```text
你正在处理 Obsidian 知识库中的内容。

任务：{任务说明}
输入文件：{文件或目录路径}
目标位置：{目标文件或目录路径}

请先读取与任务相关的规范，并遵守以下规则：
1. 不重构现有目录，不批量移动或删除文件；
2. 先输出“拟改动清单”，注明新建、修改、移动、删除；
3. 课程内容遵循课程笔记、习题、答疑、闪卡、知识原子卡等对应规范；
4. 保留来源、关键公式和不确定项；不确定的信息明确标注，不猜测；
5. 完成后执行格式、链接和内容抽检；
6. 未处理项只在确认已处理后才删除，目录本身保留。

输出格式：
- 处理范围
- 拟改动清单
- 执行结果
- 验证结果
- 仍需人工确认的事项
```
