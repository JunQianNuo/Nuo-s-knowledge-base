# 课堂录音润色梳理

## 适用场景

对 `scripts/pull_tmeet_recordings.py` 自动归档的课堂录音（`课程/<课程>/课堂笔记/raw/` 下的
逐字稿与智能纪要）进行润色，生成 `YYYY-MM-DD-第N节-主题.md` 课堂内容梳理笔记。

## 前置检查

1. 逐字稿为语音转写原文，含大量口语词与错别字（典型如「仕」=「是」、「就仕」=「就是」、「密 IP」=「MIP」），
   须结合智能纪要上下文修正；
2. 会议纪要由腾讯会议 AI 生成，结构完整但可能遗漏课堂口头补充内容，须与逐字稿互补；
3. 若课程已有课件/知识点梳理（`课程/<课程>/知识点解析梳理/`），新笔记应与其衔接，不重复造轮子。

## Prompt

```text
你正在处理 Obsidian 知识库中的课堂录音笔记。

任务：润色课堂录音，生成课堂内容梳理
输入素材：
- 逐字稿：{raw/...逐字稿.md 路径}
- 智能纪要：{raw/...纪要.md 路径}
- 待润色笔记：{YYYY-MM-DD-第N节-*.md 路径}

请遵守以下规则：
1. 先读取 [[规范/课程笔记生成规范|课程笔记生成规范]] 与 [[规范/Obsidian写作规范|Obsidian写作规范]]；
2. 笔记结构：课程信息（frontmatter）→ 本课主题与目标 → 知识梳理（有因果、有轻重，按讲解逻辑组织）
   → 例题/板书还原 → 重点结论 → 疑问与待查项；
3. 修正转写错别字与口语，保留数学公式的 LaTeX 标记，术语用规范写法；
4. 说话人标注保留在关键论证处（如「老师强调：…」），不必逐句标注；
5. 不确定或听不清的内容标注「（待确认）」，不猜测补全；
6. 完成后：将占位笔记 frontmatter 的 status 改为「已完成」并补充 topics，
   更新 `课堂笔记/README.md` 中该行状态列；
7. 按课程笔记生成规范的“CLT 建构主义与本地学习适配”要求呈现：
   先说明本课问题、必要先修和阅读路线；围绕最小例子、直觉、严格表述、关键推理及边界组织短小学习单元，
   适量使用图表；核心假设与关键逻辑默认可见，较长推导及自测提示、解析可折叠；
8. 保留课堂原内容，新增先修解释、例子和自测分别注明“补充解释”或“自测（新编）”；
   不改写 raw 原文，不把补充推导写成老师原话，不为简短删减本次课必要内容；
9. 静态笔记不使用“【STOP】等待回答”中断生成；自测题在前，提示和解析分别折叠。
   status 为“已完成”只表示笔记处理完成，不表示用户掌握；没有实际作答不得编造掌握度；
10. 输出「改动清单 + 验证结果 + 仍需确认事项」。
```
