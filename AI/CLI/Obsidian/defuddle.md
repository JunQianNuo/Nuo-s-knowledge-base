# defuddle CLI

网页内容净化 CLI，提取可读 Markdown，去除杂讯节省 token。

## 安装

```bash
npm install -g defuddle
```

## 核心用法

```bash
defuddle parse <url> --md
defuddle parse <url> --md -o content.md
defuddle parse <url> -p title
```
