# Kimi Skills

文档生成三件套：PDF、Word、Excel。

## 子 Skills 一览

### kimi-pdf — 专业 PDF

**创建 PDF**：HTML + Paged.js 生成学术论文、报告、文档。支持 KaTeX 数学公式、Mermaid 图表、三线表、引用等学术元素。

**处理 PDF**：Python 读取、提取、合并、拆分、填写表单。

**触发**："生成 PDF"、"导出 PDF"、"LaTeX 编译"

### kimi-docx — Word 文档

创建和修改 `.docx` 文件，支持封面、图表、修订模式（track changes）编辑。适合生成格式规范的 Word 文档。

### kimi-xlsx — 电子表格

XLSX/XLSM/CSV 高级操作：公式部署（非硬编码值）、复杂格式化（含金融场景自动货币格式）、数据可视化、后处理重算验证。
