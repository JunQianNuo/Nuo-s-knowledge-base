# learning-plan

学习节奏与计划 skill。用于制定课程学习计划、安排复习节奏、设计主动回忆和进度跟踪方式。

## 完整功能

### 1. 适用场景

- 制定课程学习计划
- 安排每日 / 每周复习节奏
- 设计主动回忆与间隔重复
- 跟踪学习进度
- 拆分大章节为可执行学习单元
- 为考试前复习提供节奏安排

### 2. 标准流程

```text
确认目标与期限 → 拆分学习单元 → 安排学习节奏 → 设置复习节点 → 加入检测方式 → 输出可执行计划
```

### 3. 输出模板

```markdown
## 学习目标

...

## 阶段安排

| 阶段 | 时间 | 任务 | 验收标准 |
|------|------|------|----------|
| ...  | ...  | ...  | ...      |

## 复习节奏

- 首次学习后：...
- 第 2 天：...
- 第 7 天：...
```

### 4. 质量检查清单

- 是否有明确学习目标
- 是否有阶段安排
- 是否有验收标准
- 是否包含复习节奏或反馈机制
- 是否避免计划过大、过虚、不可执行
- 是否把“学习计划”和“知识梳理”区分开

## 不处理范围

- 不处理资料 OCR
- 不直接梳理知识点
- 不生成闪卡
- 不做考试策略
- 不替代 `knowledge-structuring` 做知识组织
