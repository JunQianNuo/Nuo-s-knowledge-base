# flashcard-creator

间隔重复闪卡制作，兼容 Anki 导入。

## 完整功能

### 卡片设计原则（20条规则精简）

1. 先理解再记忆——不理解的内容不做卡片
2. 最小信息量——每张卡片只测试一个知识点
3. 优先完形填空——对多数概念比问答更有效
4. 避免集合/列表——拆成单张卡片或用助记法
5. 利用图像——视觉记忆更强
6. 运用助记技巧——首字母缩写、故事、记忆宫殿

### 卡片类型

| 类型 | 格式 | 适用 |
|------|------|------|
| Basic | `Front → Back` | 术语、定义、公式 |
| Reversed | 双向问答 | 需双向记忆的内容 |
| Cloze Deletion | `{{c1::答案}}` | 填空式，适合步骤、列表 |

### 模板（按学科）

- **词汇/术语**：术语 → 定义 + 例句 + 关联词
- **公式**：公式名？→ 公式 + 变量含义
- **流程/序列**：步骤？→ 1.2.3. + 助记法
- **日期/事件**：年份→事件 | 事件→年份

### 助记技巧

- **首字母缩写**：PEMDAS、PMAT
- **视觉联想**：Fe → "Fe"rris wheel
- **故事法**：编故事串联序列

### 导出格式

- Tab 分隔 `.txt`（Anki 直接导入）：`Front\tBack\ttags`
- Cloze 格式：`{{c1::隐藏答案}}`
- 支持 Deck 名层级：`Subject::Topic`

### 质量检查清单

- 每张卡片只测一个信息
- 10 秒内可作答
- 无歧义问题
- 难记项有助记法
- 卡片上下文独立
