# exam-prep

备考综合方案：学习计划、复习表、模拟测试、薄弱点识别。

## 完整功能

### 工作流

评估 → 制定计划 → 构建复习材料 → 练习测试 → 回顾薄弱环节（循环）

### 评估阶段

- **时间评估**：距考试天数 × 每日可用小时 = 总学时
- **内容评估**：列出所有主题，评分信心（1-5），低信心 = 高优先级

### 学习计划模板

| 时长 | 策略 |
|------|------|
| **1 周** | Day1-2 弱项→Day3-4 中项→Day5 速查→Day6 模考→Day7 终复 |
| **2 周** | Week1 内容学习→Week2 练习巩固 |
| **1 个月** | Week1 新/难→Week2 巩固→Week3 模考找漏洞→Week4 复习+休息 |

### 复习单模板

每主题一页：关键概念(3-5条)→核心公式→快速流程→常见错误(❌/✅)→助记法

### 模拟测试策略

1. 从教材/真题/习题集出题
2. 匹配真实考试格式（选择/简答/论述）
3. 限时模拟
4. 诚实评分
5. 错误分类：内容不会 / 粗心 / 时间不够

### 考试日清单

**前夜**：复习速查表（不突击）→准备物品→设闹钟→睡7-8小时
**当天**：吃早餐→早到→快速扫笔记→考前上厕所
**考中**：读全卷指令→速扫整卷→先做简单题→合理分配时间→有时间就检查

### 学习技巧

- **Active Recall**：自测而非重读（闪卡、练习题、口头解释）
- **Spaced Repetition**：Day1 学→Day2 复→Day4 复→Day7 复
- **Pomodoro**：25分钟专注→5分钟休息→4轮后15-30分钟休息
