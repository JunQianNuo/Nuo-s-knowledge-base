# knowledge-structuring

课程知识组织 skill。用于把课程资料整理成可理解、可复习、可回链的知识结构。

## 完整功能

### 1. 适用场景

- 章节知识梳理
- 知识点清单
- 知识图谱 / MOC
- 初学版“解析梳理”
- 复习版“知识点汇集”
- 重难点、因果链、易错点标注
- 课程笔记回链建议

### 2. 两类输出

| 输出类型 | 用途 | 适合阶段 |
|----------|------|----------|
| 知识点解析梳理 | 解释概念、建立因果、降低初学难度 | 初学 / 补基础 |
| 知识点汇集 | 清单式复习，覆盖定义、公式、结论、题型 | 期末复习 / 快速检索 |

详见：

- [[规范/课程笔记生成规范]]
- [[规范/课程笔记生成规范]]

### 3. 标准流程

```text
确认资料范围 → 提取章节主线 → 拆分核心知识点 → 标注重难点与易错点 → 建立回链 → 输出复习或初学版本
```

### 4. 输出模板

```markdown
## 章节主线

...

## 核心知识点

1. ...
2. ...
3. ...

## 重难点与易错点

- 重难点：...
- 易错点：...

## 回链建议

- [[...]]
```

### 5. 质量检查清单

- 是否有章节主线
- 是否区分重难点和易错点
- 是否有回链建议
- 是否避免堆砌资料原文
- 是否区分“初学理解”和“复习检索”
- 是否保留公式、定义、结论的准确表达

## 不处理范围

- 不处理 OCR 和图片清洗
- 不制定每日学习计划
- 不生成闪卡
- 不做完整备考计划
- 不替代 `courseware-processing` 做资料转换
