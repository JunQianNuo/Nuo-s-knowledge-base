# knowledge-structuring

课程知识组织 skill。用于把课程资料整理成可理解、可复习、可回链的知识结构。

## 完整功能

### 1. 适用场景

- 章节知识梳理
- 知识点清单
- 知识图谱 / MOC
- 初学版“解析梳理”
- 按当前目标组织复习资料
- 共享个人概念、知识点与方法条目的复用
- 重难点、因果链、易错点标注
- 课程笔记回链建议

### 2. 输出职责

| 输出类型 | 用途 | 组织方式 |
|----------|------|----------|
| 知识点解析梳理 | 解释概念、建立因果、支撑独立应用 | 按知识依赖完整组织章节 |
| 按目标复习资料 | 查缺补漏、考点与题型训练 | 围绕目标选取重点，回链完整知识梳理 |
| 共享个人原子条目 | 跨章节、跨课程复用 | 概念负责定义与边界，知识点负责条件与结论，方法负责操作流程 |

共享条目直接放在根目录 `概念/`、`知识点/`、`方法/`，不设课程子目录，不填写课程归属 `subject`。课程只作 `source` 溯源或实际应用链接；例题与习题按需添加，不要求每个条目都配习题。

详见：

- [[规范/课程笔记生成规范]]
- [[规范/知识原子卡规范]]

### 3. 标准流程

```text
确认资料范围 → 提取章节主线 → 检索已有共享条目 → 梳理核心知识与推理 → 标注重难点与易错点 → 建立真实回链 → 按目标组织复习资料
```

### 4. 输出模板

```markdown
## 章节主线

...

## 核心知识点

1. ...
2. ...
3. ...

## 重难点与易错点

- 重难点：...
- 易错点：...

## 回链建议

- [[...]]
```

### 5. 质量检查清单

- 是否有章节主线
- 是否区分重难点和易错点
- 是否有回链建议
- 是否避免堆砌资料原文
- 是否区分章节完整理解、按目标复习和共享条目复用
- 共享条目是否职责清楚、根目录扁平存放，且未强制配习题
- 是否保留公式、定义、结论的准确表达

## 不处理范围

- 不处理 OCR 和图片清洗
- 不制定每日学习计划
- 不生成闪卡
- 不做完整备考计划
- 不替代 `courseware-processing` 做资料转换
