# math-modeling

数学建模竞赛三阶段工作流。

## 完整功能

### 三阶段流程

| 阶段 | 产出 | 角色文档 |
|------|------|----------|
| **建模分析** | `题目分析报告.md` + `术语表格.md` | `references/roles/建模手说明.md` |
| **代码实现** | `问题X_求解.py` + `结果表格.csv` + 可视化图表 | `references/roles/编程手说明.md` |
| **论文撰写** | `论文.docx`（标准 .docx 格式） | `references/roles/论文手说明.md` |

每阶段必须先读对应角色文档再执行。

### 算法资源库（7大类）

| 类别 | 覆盖算法 |
|------|----------|
| **优化** | 线性规划、整数规划、动态规划、遗传算法、PSO、模拟退火、蚁群、差分进化、禁忌搜索、灰狼优化、免疫算法、鲸鱼优化、麻雀搜索、多目标优化、鲁棒优化 |
| **预测** | 灰色预测、插值拟合、线性回归、神经网络、SVM、ARIMA、指数平滑、Prophet、LSTM、XGBoost/LightGBM、时空预测 |
| **评价** | AHP、Fuzzy-AHP、熵权法、TOPSIS、灰色关联分析、秩和比法、变异系数法、DEA、区间数评价 |
| **图论与网络** | 最短路径、最小生成树、网络流、关键路径、欧拉/哈密顿路径、匹配问题 |
| **统计分析** | 数据预处理、聚类(K-Means/层次/DBSCAN)、假设检验、PCA、因子分析、典型相关分析 |
| **综合类** | 蒙特卡洛、排队论、博弈论、元胞自动机、马尔科夫链、微分方程建模 |
| **机器学习** | 随机森林、AdaBoost、孤立森林 |

### 集成子 Skill

- `tools/docx` — Word 文档处理
- `tools/pdf` — PDF 处理
- `tools/xlsx` — Excel 表格处理
- `tools/paper_search` — OpenAlex 论文搜索

### 优秀论文库

- **CUMCM**（国赛）：9 篇获奖论文（优化调度/数据分析/仿真/工程设计）
- **MCM/ICM**（美赛）：27 篇获奖论文（A-F 题各 4-5 篇）

### 创新指南

- 可组合多种算法（如灰色预测+神经网络）
- 题目特殊时灵活调整方法
- 在分析文档和论文中记录创新理由

### 适用竞赛

全国大学生数学建模竞赛（CUMCM）、美国大学生数学建模竞赛（MCM/ICM）
