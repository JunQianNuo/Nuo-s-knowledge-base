# 归档区

> [!info]
> 归档保留历史，不等于删除。只有已完成、已被替代或长期暂缓且确认不再活跃的内容才进入这里。

## 进入归档前

- [ ] 确认内容不再是当前课程、项目或复习的主要入口；
- [ ] 在源笔记或项目页保留归档后的入口链接；
- [ ] 检查 Wiki-link 与附件引用；
- [ ] 检查 Git 状态，并先创建可回退版本；
- [ ] 在 [[总览/归档-MOC|归档总览]] 记录迁移批次。

## 不归档

- 活跃课程的课件与复习资料；
- `未处理/`、`未处理项/` 中尚未处理的文件；
- 闪卡目录中的卡片；
- 独立 Git 仓库，除非在其自身仓库中完成迁移。
