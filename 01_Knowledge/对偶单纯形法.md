# 对偶单纯形法

对标准形 min，在当前基的所有判别数 $r_j=c_j-c_B^TB^{-1}a_j\ge0$、但某些 $\bar b=B^{-1}b$ 负时，保持对偶可行而修复原可行。

1. 选一个负 RHS 行（常取最负）出基。
2. 仅在该行 $\bar a_{ij}<0$ 的非基列中，取最小 $r_j/(-\bar a_{ij})$ 入基，枢轴后重算/核查判别数。
3. 若负 RHS 行无负系数，当前等式与非负变量不可能相容，原问题不可行。
4. 直到所有 RHS 非负，此时双侧可行即最优；退化应使用防循环规则。

不能把所有问题通过乘-1就自动变成对偶可行，仍需验判别数。目标行 RHS 必须采用一致符号。来源例最终 $x=(11/5,2/5,0)$、原min目标28/5；若使用上文 [[01_Knowledge/单纯形法]] 的负目标行，RHS应为-28/5，来源的正数表与其“负目标”说明不一致。公式/结果可用原约束和目标独立核查，避免靠表角符号猜。
