# 每进程单值的奇偶交换排序

输入为 $P\ge1$ 个rank各持一个可比较的数，输出要求按rank排列为非降序，且全部原始数据保持。排序基于交替的相邻比较交换，适用粒度是每rank一个值。

## 伙伴与更新规则

阶段phase从0起。偶阶段配 $(0,1),(2,3),\ldots$，奇阶段配 $(1,2),(3,4),\ldots$。rank $r$ 的候选伙伴为

$$
\mathrm{peer}=\begin{cases}
r+1,&r\bmod2=\mathrm{phase}\bmod2,\\
r-1,&\text{其他}.
\end{cases}
$$

越界表示本阶段无伙伴，不得向不存在的rank发消息。双方先互换值，再让低rank保留min、高rank保留max；两边都必须更新。可用以下已初始化MPI后的核心循环：

```c
for (int phase=0; phase<P; ++phase) {
    int peer=(rank%2==phase%2) ? rank+1:rank-1;
    if (peer>=0 && peer<P) {
        int other;
        MPI_Sendrecv(&local,1,MPI_INT,peer,0,
                     &other,1,MPI_INT,peer,0,comm,MPI_STATUS_IGNORE);
        if (rank<peer) local=(local<other ? local:other);
        else           local=(local>other ? local:other);
    }
}
```

这是算法解释代码，不冒充缺失的教师原工程。Sendrecv使用分离的发送、接收变量；越界rank只略过当阶段的比较，后续仍按协议参加汇集和收尾。

## 为什么固定做P个阶段

两类相邻比较交替构成奇偶交换排序网络，小值逐阶段向低rank移动，大值向高rank移动。标准的单值奇偶交换排序在 $P$ 阶段后保证全局有序；某一阶段不变不代表下一类配对也无需更新，不能仅凭一次无变化提前退出。要提前终止须另设计并验证全局终止判据。

四rank输入 $(9,3,7,1)$ 的完整轨迹为

$$
(9,3,7,1)\to(3,9,1,7)\to(3,1,9,7)
\to(1,3,7,9)\to(1,3,7,9).
$$

倒序 $(4,3,2,1)$ 则依次为 $(3,4,1,2)$、$(3,1,4,2)$、$(1,3,2,4)$、$(1,2,3,4)$。八个倒序数可用八阶段固定循环；单进程不发生交换。

## 验证必须同时检查两件事

Gather按rank收集结果后，检查非降序，也检查输入输出多重集合相同，即每个数出现次数保持。所有值错写成0也可能通过非降序；两伙伴都取min会复制小值、丢掉大值，破坏数据守恒。可以用独立串行排序后的完整数组作为对照，不能只看总和。

覆盖单rank、重复值、负数、倒序、边界无伙伴，以及输入数量和格式错误；root验证结果须使各rank以一致状态结束。故意破坏一个rank分支的更新，应能被测试检出。课堂隐藏中间输出的具体开关名未可靠保存，须由实际程序help确认。

每rank持有任意大小数据块时，需要块比较合并算法；不能把本卡的单值更新和阶段数结论原样套用。正确性不等于已证明实测加速。
