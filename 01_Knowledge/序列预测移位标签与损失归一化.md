# 序列预测移位标签与损失归一化

## 严格定义与核心内容

下一token预测以(x₁,…,x_T)为输入、(x₂,…,x_{T+1})为标签；训练常用真实前文，生成时反馈预测。

可按样本平均、样本内时间求和L=N⁻¹∑ₙ∑ₜℓ_nt，此时长序列权重更多；按总有效token平均是另一目标。

变长batch需明确有效位置和归一化，不能默换。

分类步输出logits配交叉熵，且核对真实类编码和接口。

## 从完整二维点列截取下一位置样本

给定`points.shape==(nt,N,2)`，第$n$条曲线记为$p_0^{(n)},\ldots,p_{nt-1}^{(n)}$。取$1\le S<nt$、起点$j$，构造

$$X^{(n)}=(p_j^{(n)},\ldots,p_{j+S-1}^{(n)}),\qquad
Y^{(n)}=(p_{j+1}^{(n)},\ldots,p_{j+S}^{(n)}).$$

每条曲线抽一个片段时，输入和标签均为`(S,N,2)`；同形状表示不同时间。标签末索引$j+S\le nt-1$，故$0\le j\le nt-S-1$。

```python
x_train = torch.zeros((S, N, 2), dtype=torch.float32)
y_train = torch.zeros((S, N, 2), dtype=torch.float32)
for n in range(N):
    j = np.random.randint(0, nt-S)  # 上界不含
    x_train[:,n,:] = torch.tensor(points[j:j+S,n,:], dtype=torch.float32)
    y_train[:,n,:] = torch.tensor(points[j+1:j+S+1,n,:], dtype=torch.float32)
```

示意假设已生成`points`、已导入NumPy/PyTorch；dtype、device还须与模型一致。$nt=120,S=10$时最大起点109，输入109至118、标签110至119；取110将使标签缺一点，切片可能不直接报越界，而在赋值时暴露形状错误。若每条抽更多片段，应相应增加样本轴长度。

画前若干输入片段检查索引；截取的小段不必封闭。需要时先`x_train.detach().cpu().numpy()`再绘图。训练时提供真实点列，生成时反馈预测而不再直接调用原曲线公式；长120步点列截成10步片段是数据与展开长度选择，不是改变循环层数。完整二维预测还须接输出层，见[[01_Knowledge/PyTorch单层RNN的张量接口核对]]。本课只确认数据构建及绘图，未演示完整训练、生成或保存加载实现。
