# 线性定常迭代法的收敛性判别

## 适用场景
面对大型稀疏线性方程组 $Ax=b$，选择迭代法前先判断 Jacobi / Gauss-Seidel 哪种方法收敛。

## 核心公式/步骤

1. 拆分矩阵 $\boxed{A=D+L+U}$（$D$ 对角，$L$ 严格下三角，$U$ 严格上三角）
2. 构造迭代矩阵：
   - Jacobi：$\boxed{G_J=-D^{-1}(L+U)}$
   - G-S：$\boxed{G_{GS}=-(D+L)^{-1}U}$
3. 对任意初值收敛的充要条件：$\boxed{\rho(G)<1}$（谱半径 < 1）
4. 充分条件（更易检查）：
   - 严格对角占优→Jacobi 和 G-S 均收敛
   - $A$ 对称正定→G-S 收敛
   - 弱行对角占优、不可约且至少一行严格占优→Jacobi 和 G-S 均收敛

```mermaid
flowchart TD
    A["输入 A，拆分 A=D+L+U"] --> B["构造 G_J = -D^{-1}(L+U)"]
    B --> C["构造 G_{GS} = -(D+L)^{-1}U"]
    C --> D["计算/估计 ρ(G)"]
    D --> E{"ρ(G) &lt; 1 ?"}
    E -->|"是"| F["迭代收敛"]
    E -->|"否"| G["不保证任意初值收敛，换方法"]
    F --> H{"对角占优 ?"}
    H -->|"严格对角占优"| I["Jacobi 和 G-S 均收敛"]
    H -->|"SPD"| J["G-S 收敛，Jacobi 需判断"]
    I --> K["选迭代法求解"]
    J --> K
```

## 典型例题

> **题目**：判断 $A=\begin{bmatrix}4&-1&0\\-1&4&-1\\0&-1&4\end{bmatrix}$ 的 Jacobi 和 G-S 收敛性。

> [!example]- 解答
> $A$ 严格对角占优→Jacobi 和 G-S 均收敛。
> 直接计算 $\rho(G_J)=\frac{\sqrt{2}}{4}\approx0.353553<1$，$\rho(G_{GS})=1/8=0.125<1$。
> G-S 收敛速度快于 Jacobi（$\rho$ 更小）。点评：先用充分条件快速判断，不必每次都算谱半径。

## 2026-11-08 来源复核补充

源例把方程依次重排为第3、第1、第2式，使对角元为3、-8、5且严格行对角占优。Jacobi为$u^+=(-2+v-w)/3$、$v^+=(1-u+2w)/(-8)$、$w^+=(4-u-v)/5$；Gauss-Seidel只将v式的u、w式的u与v替换为本步新值。重排行方程时必须同步重排右端b，并保持未知量顺序一致。对角占优在新矩阵上成立才可据此判敛。
