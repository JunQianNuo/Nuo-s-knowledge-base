# 谱半径

## 一句话

$\rho(G)=\max|\lambda_i(G)|$——线性迭代法收敛的充要条件是谱半径小于 1，幂法收敛率也由次大特征值比决定。

## 严格定义

矩阵 $G \in \mathbb{R}^{n \times n}$ 的**谱半径**定义为：

$$\rho(G) = \max\{|\lambda| : \lambda \text{ 是 } G \text{ 的特征值}\}$$

核心性质：

- $\rho(G^k) = [\rho(G)]^k$
- $G^k \to \mathbf{0}$（零矩阵）当且仅当 $\rho(G) < 1$
- 对任意算子范数 $\|\cdot\|$，有 $\rho(G) \leq \|G\|$
- 对任意 $\epsilon > 0$，存在范数使得 $\|G\| \leq \rho(G) + \epsilon$

> [!important] 范数小于 1 是迭代收敛的**充分**条件，谱半径小于 1 是**充要**条件。实际中验证范数更方便（$\|G\|_\infty < 1$ 可快速判断），但若 $\|G\| \geq 1$ 而 $\rho(G) < 1$，迭代仍然收敛。

## 由来与作用

- 谱（spectrum）的概念来自 Hilbert 空间算子理论，谱半径将特征值提炼为单一标量
- **线性迭代法的核心判据**：Jacobi、Gauss-Seidel、SOR 是否收敛完全取决于迭代矩阵 $G$ 的 $\rho(G)$
- **幂法收敛率**：$\rho(G)$ 本身决定了 $G^k$ 趋向零的渐近速度；次大特征值 $|\lambda_2/\lambda_1|$ 决定幂法的收敛速度
- 关键性质：$\rho(G) \leq \min(\|G\|_1, \|G\|_\infty)$；对角占优矩阵的迭代矩阵满足 $\rho(G) < 1$
