# 卷积积分方程的频域求解

求 $y=a+y*r$，其中 $a,r$ 为已知全线函数、$y$ 为未知函数。这里 $a(x)$ 是给定函数而不是波速。固定 $\hat f=\int f e^{-i\omega x}dx$；先选能使卷积和变换成立的函数类，例如 $a,r,y\in L^1$。

1. 写为 $(1-\hat r)\hat y=\hat a$，其中卷积定理见 [[01_Knowledge/卷积]]。
2. 逐频率检查 $1-\hat r$。不为零处候选为 $\hat y=\hat a/(1-\hat r)$；零点处必须检查兼容性及延拓，不能无条件除法。
3. 检查所得候选确为目标函数类中某函数的变换，并按允许的反演意义还原；仅分母非零不自动证明所有函数类中的存在性和稳定性。
4. 回代 $y-a-y*r=0$，再检查唯一性与正则性。频域的形式解本身不代替这些检查。

例如在 $L^1$ 中若 $\|r\|_1<1$，则卷积算子 $T_ry=y*r$ 的范数小于1，Neumann级数 $y=a+T_ra+T_r^2a+\cdots$ 在 $L^1$ 收敛且唯一，给一个易核验的充分条件。11月11日来源列出一般题面及除法警告，未给某一具体 $a,r$ 的数值题。
