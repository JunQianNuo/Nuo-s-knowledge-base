# 理想气体

## 一句话
理想气体是忽略分子体积和分子间作用力的"弹性小球"简化模型，其宏观行为由状态方程 $pV = \nu RT$ 统一描述——气体越稀薄、温度越高，实际气体越逼近此模型。

## 严格定义

**微观模型假设**：
1. 分子本身线度远小于分子间平均距离，体积可忽略
2. 除碰撞瞬间外，分子之间无相互作用力
3. 分子之间、分子与器壁之间的碰撞均为**完全弹性碰撞**
4. 统计假设（各向同性）：$\overline{v_x^2} = \overline{v_y^2} = \overline{v_z^2} = \frac{1}{3}\overline{v^2}$

**状态方程（宏观描述）**：
$$pV = \frac{M}{M_{mol}} RT = \nu RT$$

引入 $k = R/N_A$：
$$pV = NkT, \quad p = nkT$$

其中 $n = N/V$ 为分子数密度，$k = 1.38 \times 10^{-23} \text{ J/K}$。

> [!important] 状态方程的适用条件
> $pV = \nu RT$ 仅适用于**平衡态**。在非平衡态（如温度不均匀分布），不能将整个系统的 $p, V, T$ 直接代入状态方程。

## 由来与作用
- 理想气体模型是17-19世纪波义耳-马略特定律（$pV = C$）、查理定律、盖-吕萨克定律的实验综合，最终由克拉珀龙整合为统一的状态方程
- 这个模型解决了"如何从微观粒子的无规则运动推导出宏观气体行为"的问题：从三条微观假设出发，可导出压强的统计表达式 $p = \frac{2}{3}n\bar{E}_t$，再结合热力学第零定律得出 $p = nkT$，使微观模型与宏观实验规律自洽
- 关键性质：理想气体的**内能仅与温度有关** $E = \frac{i}{2}\nu RT$；其摩尔热容 $C_V = \frac{i}{2}R$、$C_p = C_V + R$（迈耶公式）、比热容比 $\gamma = \frac{i+2}{i}$ 均由自由度决定
- 实际气体在高温低密度条件下趋近理想气体行为
