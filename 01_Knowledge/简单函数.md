# 简单函数

## 一句话

简单函数是只取有限个值的可测函数——它是 Lebesgue 积分理论的"砖块"：任何非负可测函数都可以用一列单调递增的简单函数从下方逼近，进而定义其积分。

## 严格定义

设 $E_1, E_2, \ldots, E_m$ 是 $E$ 的互不相交的可测子集，且 $\bigcup_{j=1}^{m} E_j = E$，$\alpha_1, \alpha_2, \ldots, \alpha_m \in \mathbb{R}$。称

$$\phi(x) = \sum_{i=1}^{m} \alpha_i \chi_{E_i}(x)$$

为 **$E$ 上的简单函数**。若每个 $E_j$ 是矩体，则 $\phi$ 是**阶梯函数**（简单函数的特殊情形）。

**简单函数必可测**：由特征函数可测的充要条件（$E_j$ 可测）及可测函数对线性组合封闭即得。

**非负可测函数的简单函数逼近定理**（本章最重要的构造性定理）：

> 设 $f \geq 0$ 在 $E$ 上可测，则存在非负简单函数列 $\{\varphi_k\}$ 满足
> $$0 \leq \varphi_1(x) \leq \varphi_2(x) \leq \cdots \leq \varphi_k(x) \leq \cdots, \quad \lim_{k\to\infty} \varphi_k(x) = f(x) \; (\forall x \in E)$$

构造：对每个 $k$，将值域 $[0,k)$ 等分为 $k\cdot 2^k$ 份（每份长度 $1/2^k$），令 $E_{k,j} = E(j/2^k \leq f < (j+1)/2^k)$，再令 $E_{k,k2^k} = E(f \geq k)$，构造 $\varphi_k(x) = \sum_{j=0}^{k2^k} \frac{j}{2^k} \chi_{E_{k,j}}(x)$。

> [!important] 核心要点
> - **简单函数对积分定义的核心角色**：非负简单函数的积分 $\int_E \phi = \sum a_j \cdot m(E_j)$ 是 Lebesgue 积分的出发点。
> - **逼近定理的双向等价性**：$f$ 可测 $\iff$ 存在简单函数列逐点收敛于 $f$。反过来，被简单函数逼近的函数也是可测的。
> - **简单函数 → 积分 → 极限定理**：从简单函数出发定义积分，再通过 Levi 单调收敛定理将积分性质推广到所有非负可测函数，这是 Lebesgue 积分的标准构建路径。

## 由来与作用

- **历史起源**：Lebesgue（1902）在构建其积分理论时，先用简单函数（当时称为"阶梯函数的可测推广"）定义积分，再逐步推广。这一策略直接借鉴了 Cauchy-Riemann 积分中用阶梯函数逼近的思想，但将底集从区间推广为任意可测集。
- **解决的问题**：简单函数在 Lebesgue 积分中扮演与阶梯函数在 Riemann 积分中相同的角色——作为积分定义的"原子"。但简单函数的底集可以是任意可测集，而不仅仅是区间，这是 Lebesgue 积分比 Riemann 积分更强大的根本原因。
- **在实变函数中的角色**：
  - 是可测函数理论中最基础的逼近工具。
  - 是 Lusin 定理、Egorov 定理等证明中的关键技术（先对简单函数证明，再取极限）。
  - 从简单函数逼近出发可以推导出 $L^p$ 空间中分段常数函数（进而连续函数）的稠密性。
- **关键性质**：简单函数对线性组合封闭；简单函数的绝对值仍是简单函数；存在非负简单函数上升列逼近任意非负可测函数。

## 本轮习题补充与边界核对

有限可测分块上取有限个常数的函数，水平集是所有超过阈值分块的有限并，故可测。对非负可测 $f$，可直接写
$$\varphi_k=2^{-k}\lfloor 2^kf\rfloor\ \text{在 }\{f<k\},\qquad \varphi_k=k\ \text{在 }\{f\ge k\}.$$
它们为有限值简单函数，$0\le\varphi_k\le\varphi_{k+1}\le f$。有限值点最终误差小于 $2^{-k}$，无穷值点的逼近值为 $k\to\infty$。反向若简单函数升列趋 $f$，则 $\{f>t\}=\bigcup_k\{\varphi_k>t\}$ 可测。这不是一般无界函数的全域一致逼近定理。
