# 等式约束的Lagrange乘子与切空间二阶检验

## 适用场景与操作步骤

求 $\min f(x),h(x)=0$。

先核查可行与约束 Jacobian $J_h$ 满行秩；正则局部极小点存在自由乘子使 $\nabla f+J_h^T\lambda=0$。

令 $L=f+\lambda^Th$，切空间 $T=\ker J_h$，取基矩阵 $Z$。

在 $C^2$ 及正则条件下，局部极小点需 $Z^T\nabla_{xx}^2LZ\succeq0$；驻点处该约化 Hessian 正定则严格局部极小。

极大点对 $-f$ 或反号条件处理。

全空间 Hessian 不定不妨碍它在切空间正定；半正定只是必要条件，不能直接推出极小。

线性等式+严格凸目标时驻点是唯一全局极小。

计算步骤：固定 $h$ 的符号 → 解驻点与可行方程 → 逐候选核正则性与乘子 → 解切方向 → 检验约化二次型 → 另查全局性及非正则点。

若改 $h$ 为 $-h$，乘子反号；相同 Lagrange 表达式仅换名字则乘子不变。

来源范数平方+两线性等式例得 $x=(15,6,29)/19,\lambda=(-14,-16)/19,f=1102/361$，切基 $(5/2,1,-3/2)$，二次型19。

双曲线 $x_1x_2=6$ 的约束 Hessian 是 $\begin{pmatrix}0&1\\1&0\end{pmatrix}$，并非0；其驻点 $(3,2)$ 局部极小、$(-3,-2)$ 局部极大，而目标在整个双支可行域无上下界。
