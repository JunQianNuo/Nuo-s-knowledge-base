# 压强和温度的统计意义

## 一句话

压强是大量分子碰撞器壁的统计平均效果，温度是分子平均平动动能的量度——二者从微观角度解释了 $p = nkT$ 的物理根源。

## 严格定义

**理想气体压强公式**（微观形式）：

$$
\boxed{p = \frac{1}{3} n m \overline{v^2} = \frac{2}{3} n \bar{E}_t}
$$

其中 $\bar{E}_t = \frac{1}{2}m\overline{v^2}$ 为分子的**平均平动动能**。

**温度的统计意义**（联立 $p = nkT$ 和压强公式）：

$$
\boxed{\bar{E}_t = \frac{3}{2} kT}
$$

> [!important] 关键解读
> 1. 温度是**大量分子**平均平动动能的统计量度——**单个分子没有温度**
> 2. 温度正比于 $\overline{v^2}$（方均速率），而非 $\bar{v}$（平均速率）
> 3. 压强 $p = \frac{2}{3}n\bar{E}_t$ 揭示了宏观压强与微观动能的关系

## 推导：压强公式的统计推导

> [!proof]- 推导
> **核心思路**：压强 = 单位时间内单位面积器壁受到的总冲量。
>
> 1. 取速度 $\vec{v}_i$ 的一类分子，$x$ 方向速率 $v_{ix}$
> 2. 单位时间内碰撞单位面积器壁的分子数：$n_i v_{ix}$（以器壁为顶面的柱体内分子）
> 3. 每次完全弹性碰撞的冲量（垂直器壁方向）：$2m v_{ix}$
> 4. 该类分子贡献压强：$n_i v_{ix} \cdot 2m v_{ix} = 2n_i m v_{ix}^2$
> 5. 对所有速度求和，只有 $v_{ix} > 0$（向器壁飞）的分子碰撞器壁：
>    $$p = \sum_{v_{ix}>0} 2n_i m v_{ix}^2 = n m \overline{v_x^2}$$
> 6. 由统计假设 $\overline{v_x^2} = \overline{v_y^2} = \overline{v_z^2} = \frac{1}{3}\overline{v^2}$，得 $p = \frac{1}{3}nm\overline{v^2}$
>
> 7. 代入 $\bar{E}_t = \frac{1}{2}m\overline{v^2}$，得 $p = \frac{2}{3}n\bar{E}_t$。
>
> 联立 $p = nkT$ 得 $\bar{E}_t = \frac{3}{2}kT$。
>
> 核心洞察：压强公式只依赖 $\overline{v_x^2} = \frac{1}{3}\overline{v^2}$（各向同性假设）和完全弹性碰撞。

## 关键性质

| 关系       | 公式                                | 物理意义                          |
| -------- | --------------------------------- | ----------------------------- |
| 压强-密度-动能 | $p = \frac{2}{3}n\bar{E}_t$       | 压强由分子数密度和平均平动动能决定             |
| 温度-动能    | $\bar{E}_t = \frac{3}{2}kT$       | 温度是平均平动动能的线性量度                |
| 绝对零度     | $T = 0 \Rightarrow \bar{E}_t = 0$ | 绝对零度时分子平动停止（经典物理，量子力学中仍有零点振动） |
|          |                                   |                               |

## 典型例题

> **题目**（习题7-4）：$2.0 \times 10^{-2}\text{ kg}$ 氢气（$M_{mol} = 2.0 \times 10^{-3}\text{ kg/mol}$）和 $4.0 \times 10^{-2}\text{ kg}$ 氦气（$M_{mol} = 4.0 \times 10^{-3}\text{ kg/mol}$）混合，温度 $300\text{ K}$。求：（1）各气体平均平动动能和方均根速率；（2）混合气体温度若变为 $400\text{ K}$，平均平动动能如何变化。

> [!example]- 解答
> （1）平衡态时混合气体各部分温度相同 $= 300\text{ K}$。
>
> 平均平动动能只取决于温度：$\bar{E}_t = \frac{3}{2}kT = \frac{3}{2} \times 1.38 \times 10^{-23} \times 300 \approx 6.21 \times 10^{-21}\text{ J}$（两种气体相同）
>
> 方均根速率 $v_{rms} = \sqrt{3RT/M_{mol}}$：
> - $\text{H}_2$：$v_{rms} = \sqrt{3 \times 8.31 \times 300 / (2.0 \times 10^{-3})} \approx 1934 \text{ m/s}$
> - $\text{He}$：$v_{rms} = \sqrt{3 \times 8.31 \times 300 / (4.0 \times 10^{-3})} \approx 1367 \text{ m/s}$
>
> （2）$\bar{E}_t \propto T$，$T$ 升至 $400\text{ K}$，$\bar{E}_t$ 变为原来的 $\frac{4}{3}$ 倍。
>
> 点评：平衡态下混合气体温度相同 → 平均平动动能相同 → 但分子质量不同 → 方均根速率不同。

> **题目**（习题7-5）：两瓶不同种类的气体，温度和压强相同，但体积不同。比较：（1）单位体积分子数；（2）单位体积气体质量（密度）；（3）单位体积内能。

> [!example]- 解答
> （1）$p = nkT$，$p$ 和 $T$ 相同 $\Rightarrow$ $n$ 相同。
> （2）$\rho = n \cdot m$，$n$ 相同但分子质量 $m$ 不同 $\Rightarrow$ 密度不同。
> （3）$\varepsilon/V = n \cdot \frac{i}{2}kT$，$n, T$ 相同但 $i$ 可能不同 $\Rightarrow$ 单位体积内能不一定相同。
>
> 点评：抓住 $p = nkT$，温压相同意味着分子数密度相同——其他量再分别讨论。

## 易错点

> [!warning] 易错点
> 1. **温度是统计量**：单个分子没有温度概念，"分子的温度"是无意义的说法
> 2. **压强公式和状态方程等价**：$p = \frac{2}{3}n\bar{E}_t$ 与 $p = nkT$ 联立就是 $\bar{E}_t = \frac{3}{2}kT$，不要割裂理解
> 3. **$\overline{v^2}$ 不是 $\bar{v}^2$**：方均根速率 $\sqrt{\overline{v^2}}$ 和平均速率 $\bar{v}$ 数值不同，计算动能一律用 $v_{rms}$

习题7-4用总数密度$n=(N_1+N_2)/V$，得$\bar E_t=3pV/(2N)=8.28\times10^{-21}$ J、$T=400$ K。同温同压时$n$相同，$\rho=mn$通常不同，而单位体积**平动**动能恒为$3p/2$。这与上文例题讨论的总内能不同；总内能还取决于转动、振动贡献。
