# 分布函数与密度互转

## 适用场景

在概率密度 $f(x)$ 与分布函数 $F(x)$ 之间互相转换——给密度求分布，或给分布求密度。

## 核心步骤

### 连续型：正转（$f \to F$）

$$\boxed{F(x) = \int_{-\infty}^x f(t) \, dt}$$

**关键**：必须分段讨论积分限——积分下限是 $-\infty$ 但实际从 $f(t)$ 的非零区域左侧开始。

### 连续型：逆转（$F \to f$）

$$\boxed{f(x) = F'(x) \quad (\text{在 } F \text{ 的可导点})}$$

- 在分段点处 $F$ 可能不可导，此时 $f$ 可取任意非负值（不影响概率）。
- 分段求导后需逐段写出 $f(x)$ 的定义域。

### 离散型：分布律 $\leftrightarrow$ 分布函数

$$F(x) = \sum_{x_k \leq x} p_k \quad (\text{右连续阶梯函数})$$

$$\boxed{p_k = F(x_k) - F(x_k - 0)} \quad (\text{阶跃高度 = 概率})$$

> [!warning] 关键点
> - 连续型下单点概率为 $0$：$P\{\xi = x_0\} = 0$，开区间和闭区间概率相同。
> - 离散型的 $F(x)$ 是阶梯函数——跳跃点高度即分布律。
> - 分布函数 $F(x)$ 必须满足：$\lim_{x\to-\infty}F(x)=0$，$\lim_{x\to+\infty}F(x)=1$，单调不减，右连续。
> - 验证 $F(x)$ 的正确性：检查边界值 $F(\text{左边界})=0$，$F(\text{右边界})=1$，且 $F$ 连续。

## 典型例题

> **题目 1**：$f(x) = \begin{cases} Axe^{-x^2}, & 0 < x < 3 \\ 0, & \text{其他} \end{cases}$，求 (1) $A$；(2) $F(x)$。

> [!example]- 解答
> **(1)** 由规范性 $\int_0^3 Axe^{-x^2}dx = 1$，换元 $u=x^2$：
> $$\frac{A}{2}\int_0^9 e^{-u}du = \frac{A}{2}(1-e^{-9}) = 1 \;\Rightarrow\; A = \frac{2}{1-e^{-9}}$$
>
> **(2)** 分段积分：
> - $x < 0$：$F(x) = 0$
> - $0 \leq x < 3$：$F(x) = \frac{A}{2}(1-e^{-x^2})$
> - $x \geq 3$：$F(x) = 1$
>
> 验证：$F(0)=0$，$F(3)=1$，$F$ 连续且单调不减。

---

> **题目 2**（离散型 $F\to$ 分布律）：$F(x) = \begin{cases} 0, & x < 0 \\ 0.3, & 0 \leq x < 1 \\ 0.7, & 1 \leq x < 2 \\ 1, & x \geq 2 \end{cases}$，求分布律。

> [!example]- 解答
> 阶跃高度：
> - $P(\xi=0) = F(0) - F(0-0) = 0.3 - 0 = 0.3$
> - $P(\xi=1) = F(1) - F(1-0) = 0.7 - 0.3 = 0.4$
> - $P(\xi=2) = F(2) - F(2-0) = 1 - 0.7 = 0.3$
>
> 分布律：$\xi \sim (0:0.3,\; 1:0.4,\; 2:0.3)$。
