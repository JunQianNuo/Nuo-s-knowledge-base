# 半直线波动方程的奇偶延拓法

任务：$x>0$ 上的波动方程零边界初值问题。

1. 零 Dirichlet 边界 $u(0,t)=0$：将初位移、初速度均作奇延拓；零 Neumann 边界 $u_x(0,t)=0$：均作偶延拓。源项也按同一空间对称性延拓。
2. 在整线上用 [[01_Knowledge/达朗贝尔公式]]，有源项时加 [[01_Knowledge/波动方程的Duhamel时间叠加]]。
3. 限制回 $x>0$。按 $x-at$ 是否越过0分区；积分穿过0时分段计算，不能把原函数天然奇偶性代替边界要求。
4. 回代方程、初值、边界，检查角点及传播前沿的相容与光滑性。

例：$\varphi=\sin x,\psi=\cos x,u(0,t)=0$，$\psi$ 的延拓应为 $\operatorname{sgn}(s)\cos s$，不是原来的偶函数。$x\ge at$ 时速度项为 $\cos x\sin(at)/a$，$0<x<at$ 时为 $\sin x\cos(at)/a$。
