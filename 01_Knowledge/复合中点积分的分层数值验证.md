# 复合中点积分的分层数值验证

本方法验证积分的离散公式、代码实现和并行分工是否描述同一个问题。以

$$\pi=\int_0^1 f(x)\,dx,\qquad f(x)=\frac4{1+x^2}$$

为例，等式依据是原函数 $4\arctan x$。取正整数 $N$，步长 $h=1/N$，小区间编号 $0\le i<N$，中点 $x_i=(i+1/2)/N$。面积近似是

$$Q_N=\frac1N\sum_{i=0}^{N-1}\frac4{1+x_i^2}.$$

这里 $N$ 是小区间总数，不是MPI进程数；中点公式不能悄悄改成右端点公式。

## 第一层：独立手算小例

$$Q_1=\frac4{1+(1/2)^2}=3.2,$$
$$Q_2=\frac12\left(\frac{64}{17}+\frac{64}{25}\right)=\frac{1344}{425}.$$

代码参考值须写成 `1344.0/425.0`，不能用整数除法先截断为3。$Q_1$ 与π的差约0.058407，拿N=1的结果去断言与π相差小于 $10^{-4}$，预期本就错误；这并非通信失败。

```cpp
TEST(PiSerial, OnePanel) {
    EXPECT_NEAR(pi_serial(1), 3.2, 1e-4);
}
TEST(PiSerial, TwoPanels) {
    EXPECT_NEAR(pi_serial(2), 1344.0/425.0, 1e-14);
}
```

假定已声明并链接pi_serial、包含GoogleTest头文件；容差是各示例选择，不能当所有浮点测试的通用常数。EXPECT_NEAR检查绝对差不超过容差，ASSERT_NEAR改变失败后的执行控制，不会修正数值。

## 第二层：检查计算结构

局部函数输入 $N,\mathrm{begin},\mathrm{end}$，须满足 $N\ge1$、$0\le\mathrm{begin}\le\mathrm{end}\le N$；使用 `i<end` 遍历指标半开区间。局部仅累加函数值、全局最后除N；不能漏除、重复除或除进程数。

核对分块覆盖、不重叠、合法端点和空块贡献0，方法见 [[01_Knowledge/MPI连续均衡分块与局部和汇总]]。串行和并行应使用同一个N、相同采样点；它们的浮点累加顺序可以不同。

## 第三层：理论误差与误差预算

若 $f\in C^2[0,1]$、$M=\max|f''|$，精确算术的中点公式满足

$$\left|\int_0^1f(x)\,dx-Q_N\right|\le\frac{M}{24N^2}.$$

依据是每个中点处Taylor展开：常数项给矩形面积，线性项在对称小区间积分为0，余项的积分绝对值至多 $Mh^3/24$；N段相加即得上界。本题

$$f''(x)=\frac{8(3x^2-1)}{(1+x^2)^3},\qquad M=8,$$

因在 $y=x^2\in[0,1]$ 上 $|3y-1|\le(1+y)^3$，且x=0取等。于是

$$|\pi-Q_N|\le\frac1{3N^2}.$$

忽略舍入，使上界不超过 $10^{-6}$ 需要 $N\ge\lceil\sqrt{10^6/3}\rceil=578$。这只能约束正确中点公式的离散误差，不能证明程序没有漏算。

实现时先将N转换为浮点再相乘，例如 `1.0/(3.0*(double)N*(double)N)`，防止整数除法和整数平方溢出。可用 `acos(-1.0)` 作浮点π参考，检查理论界时另给有依据的舍入余量；参考值本身也有表示误差。N翻倍通常呈二阶收敛趋势，但上界不是每次实际误差必须恰缩四倍的断言。大N下舍入可能主导。

## 将失败定位到对应层

小例失败先查采样、索引、整数除法和归一化；只在并行失败先查分块、通信和root贡献；结构正确后再审查舍入预算。不能只看输出前几位像π，也不能把任意偏差都归咎于舍入。故意扰动局部和应被合理误差检查检出，不能靠扩大容差掩盖。详见 [[01_Knowledge/并行浮点归约的误差核验]]。
