# 多维随机变量函数的分布

## 一句话

求多维随机变量函数的分布，核心武器是**卷积公式**（独立和）和**变量变换法**（一般变换）——前者把和分布化为单积分，后者通过雅可比行列式处理一般向量变换。

## 严格定义

**分布函数法**（通用）：$\zeta = g(\xi, \eta)$ 的分布函数 $F_\zeta(z) = P\{g(\xi, \eta) \leq z\}$，在联合分布上积分，再对 $z$ 求导得密度。

**离散型卷积**（独立和）：若 $\xi, \eta$ 相互独立取非负整数值，
$$\boxed{P\{\xi + \eta = m\} = \sum_{k=0}^{m} P\{\xi = k\} \cdot P\{\eta = m-k\}}$$

**连续型卷积**（独立和）：若 $\xi, \eta$ 相互独立，密度分别为 $f_\xi, f_\eta$，
$$\boxed{f_{\xi+\eta}(z) = \int_{-\infty}^{+\infty} f_\xi(x) \, f_\eta(z-x) \, dx}$$

**正态分布可加性**：$\xi \sim N(\mu_1, \sigma_1^2), \eta \sim N(\mu_2, \sigma_2^2)$ 独立 $\Rightarrow \xi+\eta \sim N(\mu_1+\mu_2, \sigma_1^2+\sigma_2^2)$。

> [!important] 关键点
> - 分布函数法是最根本的通用方法——对于任意 $g(\xi_1, \ldots, \xi_n)$，先写 $F(y) = P\{g \leq y\}$，化为联合分布的积分。
> - 卷积公式只适用于**独立**且**同类型**（同离散/同连续）随机变量的**和**——非独立或非和的情形必须用分布函数法。
> - **离散+连续混合和**不能套卷积，必须用全概率公式：按离散变量取值拆分，每项平移连续变量的分布函数，叠加后求导。
> - 分布可加性：二项（同 $p$）、泊松、正态、Gamma（同尺度）具有可加性。

## 推导：连续型卷积公式

> [!proof]- 推导
> $$F_\zeta(z) = P\{\xi + \eta \leq z\} = \iint_{x+y \leq z} f_\xi(x) f_\eta(y) \,dx\,dy$$
> 先对 $y$ 积分（固定 $x$，$y \leq z-x$）：$F_\zeta(z) = \int_{-\infty}^{+\infty} f_\xi(x) \left[\int_{-\infty}^{z-x} f_\eta(y) dy\right] dx$。
> 对 $z$ 求导：$f_\zeta(z) = \int_{-\infty}^{+\infty} f_\xi(x) f_\eta(z-x) dx$。关键一步是累次积分后对含参积分上限求导。

## 算法/关键性质

**具有可加性的分布**：

| 分布 | 可加性 | 条件 |
|:--|:--|:--|
| 二项 | $\sum B(n_i, p) \sim B(\sum n_i, p)$ | 同 $p$ |
| 泊松 | $\sum P(\lambda_i) \sim P(\sum \lambda_i)$ | 独立 |
| 正态 | $\sum N(\mu_i, \sigma_i^2) \sim N(\sum \mu_i, \sum \sigma_i^2)$ | 独立 |
| Gamma | $\sum \Gamma(\alpha_i, \beta) \sim \Gamma(\sum \alpha_i, \beta)$ | 同尺度 $\beta$ |

## 典型例题

> **题目**：$\xi, \eta$ 相互独立，$\xi \sim N(0,1)$，$\eta \sim N(0,1)$，求 $\xi + \eta$ 的分布。

> [!example]- 解答
> $$f_{\xi+\eta}(z) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} e^{-x^2/2} e^{-(z-x)^2/2} dx$$
> 配方：$-\frac{x^2}{2} - \frac{(z-x)^2}{2} = -\frac{1}{2}[2x^2 - 2zx + z^2] = -(x - \frac{z}{2})^2 - \frac{z^2}{4}$
> $$f_{\xi+\eta}(z) = \frac{1}{2\pi} e^{-z^2/4} \int_{-\infty}^{+\infty} e^{-(x-z/2)^2} dx = \frac{1}{2\sqrt{\pi}} e^{-z^2/4}$$
> 故 $\xi + \eta \sim N(0, 2)$。
>
> **点评**：卷积公式 + 配方 → 正态可加性。两个独立标准正态之和的方差是 2（方差相加）。

---

> **题目**（$\max$ / $\min$ 分布）：设 $\xi_1, \xi_2, \xi_3$ 相互独立，均服从 $\text{Exp}(\lambda)$。求 $M = \max(\xi_1, \xi_2, \xi_3)$ 和 $N = \min(\xi_1, \xi_2, \xi_3)$ 的分布。

> [!example]- 解答
> 指数分布函数 $F(x) = 1 - e^{-\lambda x}$（$x \geq 0$）。
>
> **$\max$**：$F_M(z) = [F(z)]^3 = (1 - e^{-\lambda z})^3$，$z \geq 0$。
> 密度：$f_M(z) = 3(1 - e^{-\lambda z})^2 \cdot \lambda e^{-\lambda z}$。
>
> **$\min$**：$F_N(z) = 1 - [1 - F(z)]^3 = 1 - (e^{-\lambda z})^3 = 1 - e^{-3\lambda z}$，$z \geq 0$。
> 故 $N \sim \text{Exp}(3\lambda)$！
>
> **点评**：独立指数分布的 $\min$ 仍是指数分布，参数为各参数之和——这正是串联系统寿命模型。$\max$ 不再是单一指数分布。两种极端次序统计量在可靠性工程中有直接对应：串联寿命 = $\min$，并联寿命 = $\max$。

---

> **题目**（离散+连续混合和——全概率公式）：设 $X, Y$ 相互独立，$X$ 的概率分布为 $P\{X = i\} = \frac{1}{3}\; (i = -1, 0, 1)$，$Y \sim U(0,1)$，$Z = X + Y$。求 $Z$ 的概率密度。

> [!example]- 解答
> $X$ 是离散型，$Y$ 是连续型——**不能直接套卷积公式**。用分布函数法 + 全概率公式，按 $X$ 的三个取值拆：
>
> $$F_Z(z) = P\{X+Y \leq z\} = \frac{1}{3}\big[P\{Y \leq z+1\} + P\{Y \leq z\} + P\{Y \leq z-1\}\big]$$
>
> $Y \sim U(0,1)$，$F_Y(y) = y\; (0<y<1)$。求导得密度：
>
> $$f_Z(z) = \frac{1}{3}\big[f_Y(z+1) + f_Y(z) + f_Y(z-1)\big]$$
>
> $f_Y(t) = 1$ 仅当 $t \in (0,1)$：
> - $f_Y(z+1) \neq 0 \iff -1 < z < 0$
> - $f_Y(z) \neq 0 \iff 0 < z < 1$
> - $f_Y(z-1) \neq 0 \iff 1 < z < 2$
>
> 三段各贡献 $1/3$，在 $(-1,2)$ 上叠加为常数：
>
> $$\boxed{f_Z(z) = \frac{1}{3},\quad -1 < z < 2}$$
>
> 故 $Z \sim U(-1, 2)$。
>
> **点评**：离散+连续混合和的核心方法——全概率公式按离散取值拆分，每项是连续变量平移后的分布函数，叠加后求导。结果 $U(-1,2)$ 的直观：三个等权"副本"均匀铺在长度为 3 的区间上，密度恰好是 $1/3$。

## 商的分布

若 $\xi, \eta$ 相互独立，密度分别为 $f_\xi, f_\eta$（且 $f_\eta(y) = 0, \forall y \leq 0$），则 $\zeta = \xi / \eta$ 的密度为：

$$\boxed{f_{\xi/\eta}(z) = \int_{-\infty}^{+\infty} |y| \, f_\xi(yz) \, f_\eta(y) \, dy}$$

**推导思路**：用分布函数法 $F_\zeta(z) = P\{\xi/\eta \leq z\} = \iint_{x/y \leq z} f_\xi(x) f_\eta(y) dxdy$，分区积分后对 $z$ 求导。绝对值 $|y|$ 来自换元 $x = yz$ 时的雅可比行列式。

**积的分布**：$f_{\xi \cdot \eta}(z) = \int_{-\infty}^{+\infty} \frac{1}{|y|} f_\xi(\frac{z}{y}) f_\eta(y) dy$。

## $\max$ 与 $\min$ 的分布

若 $\xi_1, \ldots, \xi_n$ 相互独立，分布函数分别为 $F_1, \ldots, F_n$，则：

$$\boxed{F_{\max}(z) = P\{\max(\xi_1,\ldots,\xi_n) \leq z\} = \prod_{i=1}^n F_i(z)}$$

$$\boxed{F_{\min}(z) = P\{\min(\xi_1,\ldots,\xi_n) \leq z\} = 1 - \prod_{i=1}^n [1 - F_i(z)]}$$

**直观理解**：$\max \leq z \iff$ 所有分量都 $\leq z$（交事件）；$\min \leq z \iff$ 至少有一个分量 $\leq z$（并事件的对立 = 所有分量都 $> z$ 的补）。独立时直接乘分布函数。

**密度**：对 $F_{\max}, F_{\min}$ 求导即得。若同分布 $F_i = F$：$f_{\max}(z) = n[F(z)]^{n-1} f(z)$，$f_{\min}(z) = n[1-F(z)]^{n-1} f(z)$。

**典型应用**：串联系统寿命 = $\min$（最先失效的元件决定），并联系统寿命 = $\max$（最后失效的元件决定）。

## 易错点

> [!warning] 易错点
> 1. **卷积公式与分布可加性均要求独立性**：卷积公式仅适用于独立随机变量之和；分布可加性同样依赖独立——不独立时不能直接卷积，也未必保持原分布族，须退回分布函数法。
> 2. **离散型卷积和连续型卷积形式不同**：离散型是求和 $\sum_k p(k)q(m-k)$，连续型是积分 $\int f(x)g(z-x)dx$。
> 3. **变量变换法的雅可比行列式要取绝对值**：与一维公式法中的 $|h'(y)|$ 对应。
> 4. **商的分布中 $|y|$ 不能丢**：来自换元的雅可比行列式，丢失会导致密度错误。
> 5. **$\max/\min$ 公式依赖独立性**：$F_{\max} = \prod F_i$ 仅在独立时成立，不独立时需联合分布函数。
