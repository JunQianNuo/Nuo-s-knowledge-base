# 周期平面曲线的等角度点列采样

任务：在已知、可求值的周期径向函数$\rho_n(\theta)$下，把$N$条平面曲线变成模型可读取的点列。输入为径向函数、曲线参数及每条采样数$nt$；输出`points`形状`(nt,N,2)`，三轴依次是角度/时间、曲线样本、横纵坐标。

$$p^{(n)}(\theta)=(\rho_n(\theta)\cos\theta,\rho_n(\theta)\sin\theta),\quad
\theta_i=2\pi i/nt,\quad i=0,\ldots,nt-1.$$

```python
theta = np.linspace(0, 2*np.pi, nt+1)[:nt]
# 等价：np.linspace(0, 2*np.pi, nt, endpoint=False)
# rho须由真实径向公式计算，shape为(nt,N)
points = np.zeros((nt, N, 2))
points[:, :, 0] = rho * np.cos(theta)[:, None]
points[:, :, 1] = rho * np.sin(theta)[:, None]
```

丢弃$2\pi$处与起点重复的采样，周期函数决定封闭性；等角度通常不等于等弧长。有限点列视觉上平滑，不构成连续曲线光滑性的证明。

每条曲线随机选择尺度、频率、角度/相位等参数可形成多样样本；课堂以$N=10000,nt=120$为例。先画少量曲线（如前10条），第$n$条用`points[:,n,0]`和`points[:,n,1]`，检查形状变化、横纵坐标对应及时间顺序。再以[[01_Knowledge/序列预测移位标签与损失归一化]]截取短片段。
