# 势

## 一句话

势（基数）是衡量集合"元素个数"的抽象尺度——两个集合"对等"（存在双射）当且仅当它们有相同的势，这使得无穷集之间也能比较"大小"。

## 严格定义

**对等**：若存在双射 $f: A \to B$，则称 $A$ 与 $B$ **对等**，记为 $A \sim B$。对等关系是等价关系（自反、对称、传递）。

**势（基数）**：若 $A \sim B$，称 $A$ 与 $B$ 有相同的**势（基数）**，记为 $|A| = |B|$。

**势的比较**：
- $|A| \leq |B|$ $\iff$ 存在单射 $f: A \to B$（或等价地，存在满射 $g: B \to A$）。
- $|A| < |B|$ $\iff$ $|A| \leq |B|$ 且 $|A| \neq |B|$。

> **Cantor-Bernstein 定理**：若 $|A| \leq |B|$ 且 $|B| \leq |A|$，则 $|A| = |B|$。这是势理论的基石——它保证了"势的比较"是良定义的偏序关系。

**势的运算**：设 $|A| = \alpha, |B| = \beta$，
- $|A \cup B| = \alpha + \beta$（若 $A \cap B = \varnothing$）
- $|A \times B| = \alpha \cdot \beta$
- $|B^A| = \beta^\alpha$（$B^A$ 是全体 $A \to B$ 的映射）

> [!important] 核心要点
> - **无穷集的标志性特征**：$A$ 是无穷集 $\iff$ $A$ 与其某个真子集对等。例如 $\mathbb{N} \sim \{2,4,6,\ldots\}$。
> - **可列集的势为 $\aleph_0$**，实数集的势为 $c = 2^{\aleph_0}$。$\aleph_{k+1} = 2^{\aleph_k}$。
> - **连续统假设（CH）**：不存在 $\alpha$ 满足 $\aleph_0 < \alpha < c$。在 ZFC 中不可判定。

## 由来与作用

- **历史起源**：Cantor 在 1874-1897 年间建立了超限基数理论。他发现并非所有无穷集都"一样大"——$\mathbb{N}$ 与 $\mathbb{R}$ 不等势，且对于任意集合，其幂集总比原集合大。这彻底改变了数学家对"无穷"的理解。
- **解决的问题**：势理论给出了比较任意两个集合"大小"的统一框架，不依赖于集合上是否有测度、拓扑等额外结构。
- **在实变函数中的角色**：
  - $\sigma$-代数和测度通过可数运算定义——但集合本身可以不可数，这种对比贯穿整个理论。
  - 区间与正方形等势（$c$）的结论帮助理解 $\mathbb{R}^n$ 中坐标变换和 Fubini 定理的可测性条件。
  - Cantor-Bernstein 定理在证明各种集合等势时反复使用（如 $|2^{\mathbb{N}}| = |\mathbb{R}|$）。
- **关键性质**：势的比较构成全序（依赖选择公理）；无最大基数；$2^{\aleph_0} = c$。
