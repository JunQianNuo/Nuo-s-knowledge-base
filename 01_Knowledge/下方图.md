# 下方图

## 一句话

下方图將 Lebesgue 积分转化为几何测度：非负函数的积分等于其下方图的 $(n+1)$ 维 Lebesgue 测度，为抽象的积分理论提供了直观的"体积"解释。

## 严格定义

设 $f \geq 0$ 是 $\mathbb{R}^n$ 上的非负可测函数。$f$ 的**下方图**（subgraph）定义为

$$G_f = \left\{ (x, y) \in \mathbb{R}^n \times \mathbb{R} \;\middle|\; 0 \leq y < f(x) \right\}$$

**核心定理**（积分 = 下方图的测度）：

$$\int_{\mathbb{R}^n} f(x)\,dx = m_{n+1}(G_f)$$

其中 $m_{n+1}$ 表示 $\mathbb{R}^{n+1}$ 上的 Lebesgue 测度。

**证明链**（自底向上逐层推广）：

1. **特征函数**：若 $f = \chi_E$（$E$ 可测），则 $G_f = E \times [0, 1)$，由测度的乘积公式 $m_{n+1}(G_f) = m_n(E) \cdot 1 = \int \chi_E$
2. **简单函数**：若 $f = \sum a_j \chi_{E_j}$（$E_j$ 互不相交），则 $G_f = \bigcup_j (E_j \times [0, a_j))$ 为不交并，于是 $m_{n+1}(G_f) = \sum a_j \cdot m_n(E_j) = \int f$
3. **非负可测函数**：取简单函数列 $0 \leq \varphi_k \nearrow f$（单调逼近），则 $G_{\varphi_k} \nearrow G_f$，由测度的下连续性 $m_{n+1}(G_f) = \lim_k m_{n+1}(G_{\varphi_k}) = \lim_k \int \varphi_k = \int f$
4. **一般可测函数**：$f = f^+ - f^-$，分别对正负部应用第 3 步再相减

> [!important] 核心要点
> - **积分即体积**：$\int f = m_{n+1}(G_f)$ 是 Lebesgue 积分最直观的几何解释——函数图像下方区域的 $(n+1)$ 维"体积"就是积分值。
> - **单调性由包含关系直接推出**：$f \leq g \;\Rightarrow\; G_f \subset G_g \;\Rightarrow\; \int f \leq \int g$，无需返回积分定义逐项验证。
> - **积分线性有几何对应**：$\int (f+g) = \int f + \int g$ 对应下方图在 $y$ 方向的不交并分解——$G_{f+g}$ 可通过纵向平移 $G_f$ 与 $G_g$ 后取不交并获得（Fubini 视角下的切片论证）。
> - **可测性等价刻画**：$f$ 可测 $\iff$ $G_f$ 是 $\mathbb{R}^{n+1}$ 中的可测集，下方图可测性是函数可测性的另一等价定义。

## 由来与作用

- **历史起源**：下方图视角可追溯到 Lebesgue（1902）博士论文《积分、长度与面积》中对积分的原始构想——先用测度定义长度、面积、体积，再用体积定义积分。这一几何直觉是 Lebesgue 测度论的自然产物：测度论统一了"大小"的概念，而积分就是被积函数曲线/曲面下方的"大小"。
- **解决的问题**：将抽象的积分定义（简单函数逼近再取上确界）化为具体的几何对象（集合的测度），使得许多积分的性质——单调性、线性、极限定理——可以从集合的包含、不交并、单调列等基本测度性质直接读出，大大简化论证。
- **在实变函数中的角色**：
  - 为 Lebesgue 积分提供了**等价定义**：有些教材（如 Stein & Shakarchi）直接从下方图测度出发定义积分，再反推简单函数逼近。
  - 将积分性质转化为测度性质，简化了 Fubini 定理的 Tonelli 情形（下方图的"切片"就是 $x$ 处截面长度 $f(x)$）。
  - 是连接一维积分理论与高维测度论的桥梁——乘积测度与累次积分的关系在下方图视角下变得自然。
- **关键性质**：
  - $f \leq g \;\Rightarrow\; G_f \subset G_g$（保序性，直接蕴含积分单调性）。
  - $f$ 可测 $\iff$ $G_f$ 可测（可测性的几何等价刻画）。
  - $G_f$ 与 $f$ 之间一一对应：已知 $G_f$ 可通过 $f(x) = m_1(\{y \mid (x,y) \in G_f\})$ 恢复 $f$。

## 本轮习题补充与边界核对

来源使用包含上边界的版本 $H=\{(x,y):x\in E,0\le y\le f(x)\}$。对有限实值非负可测f，图像Γ为零测：先限制有限测度E，用高度δ分层 $E_k=\{kδ\le f<(k+1)δ\}$，各图像片含于 $E_k\times[kδ,(k+1)δ]$，外测度总和≤δm(E)；令δ↓0。一般E先用有界盒分块，再取可数并。

因此H与严格下方图只差零测图像；两者可测且测度均为 $\int_Ef$。反向若H可测，由截口定理 $x\mapsto m(H_x)$ a.e.有可测版本，而E上截口为[0,f(x)]、长度f(x)，故f与可测函数a.e.相同；Lebesgue完备性补回异常点即得可测。该论证依赖E可测和完备测度。
