# 条件方差

## 一句话

条件方差 $D(\xi|\eta)$ 衡量在已知 $\eta$ 的情况下 $\xi$ 的剩余不确定性；方差分解公式 $D(\xi) = E[D(\xi|\eta)] + D[E(\xi|\eta)]$ 将总方差拆为"组内平均方差"+"组间方差"。

## 严格定义

**条件方差**：在 $\eta = y$ 条件下，
$$D(\xi|\eta=y) = E\{[\xi - E(\xi|\eta=y)]^2 \mid \eta=y\}$$

作为随机变量：$D(\xi|\eta)$ 是 $\eta$ 的函数。

**方差分解公式**（全方差公式）：

$$
\boxed{D(\xi) = E[D(\xi|\eta)] + D[E(\xi|\eta)]}
$$

- 第一项 $E[D(\xi|\eta)]$：**组内方差**的期望——已知 $\eta$ 后 $\xi$ 仍残留的平均不确定性
- 第二项 $D[E(\xi|\eta)]$：**组间方差**——$\eta$ 的不同取值导致 $\xi$ 的期望的系统性差异

> [!important] 关键点
> - 方差分解是全期望公式的变体：$D(\xi) = E(\xi^2) - [E(\xi)]^2$，分别对 $E(\xi^2)$ 和 $E(\xi)$ 应用全期望公式，整理即得。
> - 当 $E(\xi|\eta)$ 是常数（如 $\xi$ 与 $\eta$ 独立）时，$D[E(\xi|\eta)] = 0$，组间方差消失，$D(\xi) = E[D(\xi|\eta)]$。
> - 二维正态中：$D(\eta|\xi=x) = \sigma_2^2(1-r^2)$（条件方差与 $x$ 无关），$D[E(\eta|\xi)] = r^2\sigma_2^2$。

## 推导：方差分解公式

> [!proof]- 推导
> $$
> \begin{aligned}
> D(\xi) &= E[(\xi - E\xi)^2] = E\{E[(\xi - E\xi)^2 \mid \eta]\} \quad \text{(全期望公式)}\\
> &= E\{E[\xi^2 - 2\xi E\xi + (E\xi)^2 \mid \eta]\} \\
> &= E[E(\xi^2|\eta)] - 2E\xi \cdot E[E(\xi|\eta)] + (E\xi)^2 \\
> &= E[E(\xi^2|\eta)] - (E\xi)^2
> \end{aligned}
> $$
> 另一方面，$E[D(\xi|\eta)] + D[E(\xi|\eta)] = E[E(\xi^2|\eta) - (E(\xi|\eta))^2] + E[(E(\xi|\eta))^2] - (E[E(\xi|\eta)])^2 = E[E(\xi^2|\eta)] - (E\xi)^2$。两者相等。

## 关键性质 

| 情景                    | $E[D(\xi\|\eta)]$ | $D[E(\xi\|\eta)]$ |
| :-------------------- | :---------------- | :---------------- |
| $\xi$ 与 $\eta$ 独立     | $D(\xi)$          | $0$               |
| $\xi = g(\eta)$（完全确定） | $0$               | $D(\xi)$          |
| 一般情况                  | 组内不确定性的期望         | 组间期望的散布           |

## 典型例题

> **题目**：已知 $\xi \sim U[0,a]$，$\eta|\xi \sim U[\xi,a]$。求 $D(\eta)$。

> [!example]- 解答
> 先求 $E(\eta|\xi=x) = \frac{a+x}{2}$（均匀分布的中点），$D(\eta|\xi=x) = \frac{(a-x)^2}{12}$（均匀分布的方差）。
>
> 组间方差：$D[E(\eta|\xi)] = D(\frac{a+\xi}{2}) = \frac{1}{4} D(\xi) = \frac{a^2}{48}$。
> 组内方差期望：$E[D(\eta|\xi)] = E[\frac{(a-\xi)^2}{12}] = \frac{1}{12} \cdot \frac{a^2}{3} = \frac{a^2}{36}$。
>
> 方差分解：$D(\eta) = \frac{a^2}{36} + \frac{a^2}{48} = \frac{7a^2}{144}$。
>
> **点评**：组内方差来源于"给定 $\xi$ 后 $\eta$ 仍是随机的"，组间方差来源于"$\xi$ 不同导致 $\eta$ 的期望不同"。方差分解清晰分离了这两种不确定性来源。

## 易错点

> [!warning] 易错点
> 1. **方差分解不是 $D(\xi) = D(\xi|\eta) + D[E(\xi|\eta)]$**：第一项是 $E[D(\xi|\eta)]$（条件方差的期望），不是条件方差本身。
> 2. **条件方差 $D(\xi|\eta=y)$ 是 $y$ 的函数**，不是常数——它随条件值的不同而变化（如二维正态中条件方差是常数是个特例）。
> 3. **$E(\xi|\eta)$ 是 $\xi$ 基于 $\eta$ 的最优预测**（均方误差最小），方差分解中 $E[D(\xi|\eta)]$ 就是最优预测的均方误差。
