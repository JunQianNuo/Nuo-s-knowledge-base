# 范数

## 一句话

范数量化了向量和矩阵的"大小"——向量范数度量误差，矩阵范数通过算子范数定义，是条件数和迭代收敛分析的语言基础。

## 严格定义

### 向量范数

映射 $\|\cdot\|: \mathbb{R}^n \to \mathbb{R}$ 满足：正定性、齐次性、三角不等式。常见 $p$-范数：

- **1-范数**：$\|x\|_1 = \sum_{i=1}^{n}|x_i|$
- **2-范数**（Euclid）：$\|x\|_2 = \sqrt{\sum_{i=1}^{n}x_i^2}$
- **$\infty$-范数**：$\|x\|_\infty = \max_{1 \leq i \leq n}|x_i|$

### 矩阵算子范数

$$\|A\| = \max_{x \neq 0}\frac{\|Ax\|}{\|x\|} = \max_{\|x\|=1}\|Ax\|$$

对应的三个常见矩阵范数：

- $\|A\|_1 = \max_{1 \leq j \leq n}\sum_{i=1}^{n}|a_{ij}|$（最大绝对列和）
- $\|A\|_\infty = \max_{1 \leq i \leq n}\sum_{j=1}^{n}|a_{ij}|$（最大绝对行和）
- $\|A\|_2 = \sqrt{\rho(A^T A)} = \sigma_{\max}(A)$（最大奇异值）

> [!important] 矩阵范数的一致性（相容性）：$\|Ax\| \leq \|A\| \cdot \|x\|$ 和 $\|AB\| \leq \|A\| \cdot \|B\|$。算子范数自动满足一致性，但 Frobenius 范数 $\|A\|_F=\sqrt{\sum a_{ij}^2}$ 虽不是算子范数，也满足一致性。

## 由来与作用

- 由 Banach 空间理论形式化，范数是度量向量空间元素的统一语言
- 在数值分析中：向量范数量化误差大小（收敛判据）；矩阵范数定义条件数和迭代收敛条件
- $\|A\|_1$ 和 $\|A\|_\infty$ 计算简单（O($n^2$)），常用于迭代法收敛的快速判断
- 关键性质：有限维空间上所有范数等价（存在常数 $c,C$ 使 $c\|x\|_\alpha \leq \|x\|_\beta \leq C\|x\|_\alpha$）

## 2026-11-08 来源复核补充

诱导无穷范数的等式可由可达上界证明。任意$x$有$\|Ax\|_\infty\le(\max_i\sum_j|a_{ij}|)\|x\|_\infty$。取最大行$i_*$，令$x_j=\mathrm{sgn}(a_{i_*j})$（零项任取±1），则$\|x\|_\infty=1$且该行内积正好为绝对行和。零矩阵单独显然成立，从而上界可达。


## 本次来源核对与适用范围

一般实或复线性空间X上的范数须满足$\|x\|=0\iff x=0$、$\|\alpha x\|=|\alpha|\|x\|$、三角不等式。其距离d(x,y)=‖x−y‖与线性运算相容，反三角不等式$|\|x\|-\|y\||\le\|x-y\|$说明范数连续。给定度量未必来自范数；赋范不要求完备，完备者为Banach空间。
