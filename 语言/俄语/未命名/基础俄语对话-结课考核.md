## Произноше́ние / 发音指南

### IPA 符号速查（音标列所用符号）

| 符号 | 类似汉语 | 示例 |
|:--|:--|:--|
| `ʲ` | —（腭化标记） | [prʲɪˈvʲet] 中 р 和 в 都带 ʲ，舌头抬向硬腭 |
| `ˈ` | —（重音） | 后面的音节读重：`Приве́т` → [prʲɪ**ˈvʲ**et] |
| `ɐ` | a（弱 а） | 非重音 о/а，如 `хорошо́` [xə**rɐ**ˈʂo] |
| `ə` | e（轻 e） | 更弱的非重音元音，如 `хорошо́` [**xə**rɐˈʂo] |
| `ɪ` | i（短 i） | 非重音 е/я，如 `тебя́` [tʲ**ɪ**ˈbʲa] |
| `ɨ` | ei 靠后 | `ы` 的音，舌头后缩 |
| `ʂ` | sh（卷舌） | `ш`，比汉语 sh 更卷 |
| `ʐ` | r（卷舌浊） | `ж`，声带振动版 ʂ |
| `ɕː` | 西（长软） | `щ`，如 `ещё` [(j)ɪ**ˈɕː**ɵ] |
| `tɕ` | j（类似"基"） | `ч`，如 `у́чишься` [ˈu**tɕ**ɪʂsʲə] |
| `ts` | c（类似"次"） | `ц`，如 `ле́кцию` [ˈlʲek**ts**ɨjʊ] |
| `ʉ` | u（撮口） | 介于 у 和 ю 之间 |
| `‖` | —（句边界） | 句子分隔 |

> 💡 **怎么用**：音标列提供了标准俄语发音，配合中文谐音列和音频一起用效果最好。先看音标了解精确发音，再用谐音辅助记忆，最后跟音频练。

### 俄语特殊字母发音

| 俄语字母 | 近似音 | 发音要点 |
|:--|:--|:--|
| **р**（颤音） | l / r 之间 | 舌尖抵上齿龈，气流使舌尖颤动。练不会可用"l"暂代，考试不扣大分 |
| **ы** | ei（诶） | 比"ei"更靠后、更闷。嘴形像发"一"但舌头后缩 |
| **х** | h（喝） | 类似汉语拼音 h，但摩擦更强 |
| **ж** | r（日） | 类似"日"但声带振动更强，舌头更卷 |
| **ш** | sh（湿） | 类似"湿"但舌头更往后卷，永远读硬音 |
| **щ** | 西（软 sh） | 类似"西"但舌头位置更低，永远读软音 |
| **ч** | ch（吃） | 类似"吃"，永远读软音 |
| **ц** | ts（次） | 类似"次"，永远读硬音 |
| **й** | y（衣短） | 类似"衣"但极短，类似 yes 里的 y |
| **ь**（软音符号） | — | 不发音，使前面辅音"软化"（舌头抬高一点） |
| **ъ**（硬音符号） | — | 不发音，隔开辅音和元音 |

### 重音规则

- **重音音节**：读得长一点、响一点。本对话中用 `´` 标出（如 `Приве́т`）
- **非重音 `о`**：读成短而弱的"а"（如 `хорошо́` → "哈拉烁"，第一个 о 弱化为 а）
- **非重音 `е`**：趋向 `и` 的音（如 `тебя́` → "几比亚"）

## Грамма́тика / 语法要点

| 语法点 | 例句 | 说明 |
|:--|:--|:--|
| **名词性别** | студе́нт（阳）/ студе́нтка（阴） | 俄语名词分阳、阴、中三性 |
| **动词变位（现在时）** | я учу́сь, ты у́чишься… | `учи́ться` 带 -ся 反身 |
| **前置词 + 格** | из Кита́я（二格）, в университе́те（六格）, на ле́кцию（四格） | 前置词决定后面名词的格 |
| **否定结构** | Но я ещё то́лько учу́сь. | 用 `ещё` + `то́лько` 表达"还只是" |
| **运动动词** | игра́ть в + 四格 | 从事某种运动的固定搭配 |

## Сове́ты для экза́мена / 考核小贴士

1. **语速适中**：不要图快，每个词说清楚。入门考核考官更看重发音准确度而非速度。
2. **重音读准**：俄语重音非常重要，读错重音可能让人听不懂（如 `звони́т` 不能读成 `зво́нит`）。
3. **自然停顿**：对话时可以在句号、逗号处自然停顿，不必一口气读完。
4. **替换练习**：考试时考官可能会替换角色名或问题，建议把对话中的核心句型（如问姓名、问爱好、告别）单独练熟。
5. **表情自然**：俄语对话时眼神交流和微笑会让整个对话更生动自然。
