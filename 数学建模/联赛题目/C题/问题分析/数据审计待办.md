# C题数据审计待办

## 1. 工作簿结构

- 核对15个输入工作表和6个模板是否齐全；
- 核对字段大小写、顺序和模板空值规则；
- 记录每表行列数、主键、重复、缺失、类型、单位和取值范围；
- 计算文件哈希，保留原始附件只读副本。

## 2. 主外键

- `historicalmatches.matchid`唯一；
- `teams.teamid/teamname`一一对应；
- `groupsmatches`应为72场、12组×6场、每队3场且每轮1场；
- `basepredictions`、`securityrequirements`与72个 `matchid`一一匹配；
- `livegroupresults`应只含前两轮48场；
- 场馆、时段、距离矩阵和日期限制覆盖所有需要连接的ID。

## 3. Q1专项

- train/test行数、日期范围和标签缺失模式；
- test的 `tvviewers`是否全为空且其他字段可用；
- `tvviewers`单位和分布、零值、极端值；
- 当前场赛后字段与目标相关性仅用于泄漏审计；
- 球队冷启动、赛事类别漂移和测试中新球队/类别；
- 同一比赛/重复对阵及时间泄漏。

## 4. Q2专项

- 16场馆、80时段及所有容量上下界；
- 场馆最小总场次之和≤72≤最大总场次之和；
- 时段UTC无歧义、时区转换和当地日期；
- 安保资格候选比例及是否存在无合格场馆比赛；
- 60小时休息的潜在时段可行率；
- 全球黄金时段和大场馆的25%阈值并列处理；
- 各项归一化上下界和零极差项。

## 5. Q3专项

- 每队前两轮恰有2场，积分/xG/红牌/伤病聚合可复算；
- 实际与赛前预计观众比值的分母非零；
- 资源等级、成本、需求/风险乘子完整；
- 每日资源限制覆盖全部第三轮参考日期；
- 票价弹性符号及上下界；
- PDF中的动态安保公式和模板实际字段名回源核准。

## 6. Q4专项

- 真实赛程来源URL、获取日期和UTC转换；
- 真实赛事规模及可比指标分母；
- 无法从公开数据识别的模拟指标单独标记；
- 实际与优化赛程的指标定义、方向和标准化边界一致。
