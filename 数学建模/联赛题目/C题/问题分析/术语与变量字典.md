# C题术语与变量字典

## 核心概念

| 编号 | 概念 | 定义 | 相关问题 |
|---|---|---|---|
| C01 | 赛前可用信息 | 在比赛开球前已知、可合法用于预测观看人数的信息 | Q1 |
| C02 | 日期外推 | 用较早比赛训练并预测较晚比赛，匹配固定日期切分 | Q1 |
| C03 | 全球黄金时段 | `globalprimescore`排名前25%的候选时段 | Q2 |
| C04 | 大容量场馆 | 场馆容量排名前25%的场馆 | Q2 |
| C05 | 公平性惩罚 | 黄金时段次数极差和大场馆次数极差的加权量 | Q2 |
| C06 | 同一信息截面 | 24场第三轮比赛均只使用全部第三轮开始前的信息 | Q3 |
| C07 | 晋级重要性 | 双方晋级事件不确定性的标准化平均 | Q3 |
| C08 | 无激励风险 | 球队晋级或淘汰基本确定而降低竞争动机的风险 | Q3 |
| C09 | 默契风险 | 某些赛果同时有利双方而可能削弱争胜动机的风险 | Q3 |
| C10 | 静态方案 | 赛前信息下优化、前两轮结束后冻结资源决策的方案 | Q3 |
| C11 | 动态方案 | 利用前两轮更新信息重新配置第三轮资源的方案 | Q3 |
| C12 | 同口径比较 | 实际与优化赛程使用相同指标、方向、权重和标准化 | Q4 |

## 单位与接口

| 数据/字段 | 单位 | 注意事项 |
|---|---|---|
| `result1testprediction.predictedtesttvviewers` | 百万人 | 官方MSE尺度 |
| `result1matchprediction.predictedtvviewers` | 人 | 进入Q2/Q3前须乘$10^6$ |
| 场馆容量、现场观众 | 人 | 上座率不得混用百分数/比例 |
| `marketvaluemusd`、场馆成本字段 | 百万美元 | 与美元价值相加前需统一单位 |
| UTC时间 | UTC datetime | 轮次顺序、60小时和并发容量 |
| 场馆当地日期 | local date | `maxmatchesperday` |
| 参考日期 | reference date | Q2/Q3每日资源容量 |
