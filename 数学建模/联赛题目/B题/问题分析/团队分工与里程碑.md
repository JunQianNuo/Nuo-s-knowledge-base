# B题团队分工与里程碑

> [!note]
> 用户尚未提供成员数量与专长，下表只定义角色职责，不虚构具体成员。

## 角色模板

| 角色 | 当前职责 | 交付物 |
|---|---|---|
| 建模 | 冻结目标层级、路径/装载/燃油/时间窗口径 | 问题分析、变量字典、约束清单 |
| 编程 | 附件到位后做数据审计与独立可行性检查器 | 审计报告、验证脚本、可复现运行入口 |
| 论文 | 同步整理三问递进关系、指标定义和假设边界 | 问题重述、问题分析、符号说明 |
| 全队 | 审核主目标口径、Q3两阶段基准及输出格式 | 决策记录与交接检查 |

## 里程碑

| 里程碑 | 完成条件 | 当前状态 |
|---|---|---|
| 题面解析 | 三问类型、共同规则、文件接口明确 | 已完成 |
| 附件审计 | 4个输入CSV和结果模板结构/质量核验 | 等待附件 |
| 基准模型 | 每问形成可运行、可校验的完整基准 | 未开始 |
| 完整结果 | 结果CSV通过独立硬约束检查器 | 未开始 |
| 稳健性 | 主目标容差、次级指标与关键规则敏感性完成 | 未开始 |
| 论文初稿 | 三问方法—结果—检验闭环 | 未开始 |
| 最终检查 | 文件命名、表头、指标、引用和匿名要求一致 | 未开始 |

## 交接必须说明

- 输入文件名、哈希和版本；
- 当前目标层级及容差；
- 方案是否通过容量、燃油、时间和文件外键检查；
- 尚未满足的任务或未通过的验证；
- 字典、假设登记表和论文是否已同步。
