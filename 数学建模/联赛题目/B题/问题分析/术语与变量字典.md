# B题术语与变量字典

## 1. 核心概念

| 编号 | 中文概念 | 英文名称 | 定义/本题口径 | 来源 |
|---|---|---|---|---|
| C01 | 架次 | flight / sortie | 一架直升机从所属机场起飞、连续停靠至多5次海上设施并返回同一机场的完整过程 | 题面 |
| C02 | 出海 | outbound transportation | 从陆地机场前往海上设施 | 题面 |
| C03 | 海返 | inbound transportation | 从海上设施返回陆地机场 | 题面 |
| C04 | 穿梭 | inter-facility shuttle | 从一座海上设施前往另一座海上设施 | 题面 |
| C05 | `LAND` | flexible land airport | 任一陆地机场；实际机场由所乘架次决定 | 题面 |
| C06 | 海上着陆次数 | offshore landings | 中间海上设施实际停靠次数；重复访问同一设施也再次计数 | 题面 |
| C07 | 可加油设施 | refueling facility | F006、F011、F018、F024、F031、F038、F044、F050 | 题面 |
| C08 | 安全余油 | minimum safety reserve | 飞机到达每个地点后不得低于的剩余燃油 | 题面 |
| C09 | 飞机使用时间 | aircraft usage time | 架次从机场起飞至返回同一机场的时长，含飞行、停靠和等待 | 题面 |
| C10 | 人员在途时间 | passenger travel time | 飞机离开该人员起点至首次抵达其终点的时长，含绕行、停靠与等待 | 题面 |
| C11 | 客座公里 | passenger-kilometres | 每航段机上人数与航段距离之积 | 题面 |
| C12 | 可用座公里 | available seat-kilometres | 每航段机型座位数与航段距离之积 | 题面 |
| C13 | 座位利用率 | seat utilization rate / load factor | 全部客座公里除以全部可用座公里 | 题面 |
| C14 | 时间窗 | time window | 人员离开起点不得早于最早时间，抵达终点不得晚于最晚时间 | 题面 |
| C15 | 机场周转 | airport turnaround | 同一飞机前一架次返场至下一架次起飞至少30分钟 | 题面 |
| C16 | 词典序目标 | lexicographic objective | 先不恶化主目标，再优化较低优先级目标 | 对题面“在……基础上”的工作解释，待论文明确 |
| C17 | 取送先后 | pickup-delivery precedence | 同一人员先在起点上机，再在终点下机；不得换乘 | 题面 |

## 2. 集合与索引

| 符号 | 含义 | 取值/备注 |
|---|---|---|
| $A$ | 陆地机场集合 | `{A01,A02,A03}` |
| $F$ | 海上设施集合 | `{F001,…,F052}` |
| $F^{ref}$ | 可加油设施集合 | 8座题定设施 |
| $V=A\cup F$ | 全部地点集合 | 共55个地点 |
| $K$ | 机型集合 | `{T1,T2,T3}` |
| $P$ | 人员需求集合 | 按Q1/Q2/Q3分别读取 |
| $R$ | 架次集合 | 由方案产生 |
| $H$ | 问题三具体飞机集合 | 共24架 |
| $\alpha$ | 问题三具体飞机索引 | $\alpha\in H$ |
| $p$ | 人员索引 | $p\in P$ |
| $r$ | 架次索引 | $r\in R$ |
| $h$ | 架次内停靠/航段位置索引 | 从0起 |
| $a,b$ | 地点索引 | $a,b\in V$ |
| $k$ | 机型索引 | $k\in K$ |

## 3. 题给参数

| 符号/字段 | 含义 | 单位 | 来源/取值 |
|---|---|---|---|
| $d_{ab}$ | 地点$a$至$b$的飞行距离 | km | `distances.csv`实测55×55对称矩阵，非零值14—579 |
| $Q_k$ | 机型座位数 | 人 | T1=12，T2=16，T3=19 |
| $s_k$ | 飞行速度 | km/h | T1=250，T2=220，T3=190 |
| $c_k$ | 单位距离油耗 | kg/km | T1=3.4，T2=2.5，T3=2.9 |
| $C_k$ | 油箱容量 | kg | T1=1000，T2=1150，T3=1600 |
| $R_k$ | 最低安全余油量 | kg | T1=150，T2=150，T3=200 |
| $L_{max}$ | 每架次最大海上着陆次数 | 次 | 5 |
| $t^{stop}_0$ | 不加油最低停靠时间 | min | 10 |
| $t^{stop}_1$ | 加油最低停靠时间 | min | 20 |
| $e_p$ | 人员$p$最早可离开起点时刻 | 北京时间 | Q3字段 |
| $l_p$ | 人员$p$最晚需抵达终点时刻 | 北京时间 | Q3字段 |
| $g_p$ | 人员$p$任务类型 | 类别 | emergency/production/shift/temporary |
| $T_0$ | Q3非临时任务最优总飞机使用时间 | min | 第一阶段求得，不能任意指定 |

## 4. 方案变量与派生量

| 符号 | 类型 | 含义 | 单位 |
|---|---|---|---|
| $k_r$ | 决策 | 架次$r$所用机型 | — |
| $b_r$ | 决策 | 架次$r$所属/起降机场 | — |
| $v_{r,h}$ | 决策 | 架次$r$第$h$个停靠地点 | — |
| $z_{r,h}$ | 决策 | 在停靠$h$是否加油 | 0/1 |
| $x_{pr}$ | 决策 | 人员$p$是否分配给架次$r$ | 0/1 |
| $y_p$ | 决策 | Q3人员$p$是否被服务；非临时固定为1，临时可选 | 0/1 |
| $g_{r\alpha}$ | 决策 | Q3架次$r$是否由具体飞机$\alpha$执行 | 0/1 |
| $o_{rr'\alpha}$ | 关系变量 | Q3中架次$r$是否在飞机$\alpha$上紧邻架次$r'$之前；或由等价序位变量替代 | 0/1 |
| $u_{p},w_{p}$ | 决策/索引 | 人员$p$的上、下机停靠序号 | — |
| $a_{r,h}$ | 时刻 | 到达停靠$h$的时刻 | min/日期时刻 |
| $d_{r,h}^{dep}$ | 时刻 | 离开停靠$h$的时刻 | min/日期时刻 |
| $f_{r,h}^{arr}$ | 状态 | 到达停靠$h$后的剩余燃油 | kg |
| $n_{r,h}$ | 状态 | 架次$r$第$h$条航段机上人数 | 人 |
| $\tau_{ab}^{(k)}$ | 派生 | 机型$k$飞行$a\to b$的向上取整分钟数 | min |
| $T_r$ | 派生 | 架次$r$的飞机使用时间 | min |
| $T^{air}$ | 指标 | 全部架次飞机使用时间之和 | min |
| $T^{pax}$ | 指标 | 全部人员在途时间之和 | min |
| $N^{flight}$ | 指标 | 总架次数 | 次 |
| $F^{fuel}$ | 指标 | 总燃油消耗 | kg |
| $U$ | 指标 | 座位利用率 | 0—1 |
| $N_{temp}$ | 指标 | Q3已满足临时任务人数 | 人 |
