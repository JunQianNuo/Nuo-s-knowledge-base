### 一、论文概况

题目《面向海上油田人员运输的分层路径与多日排班优化》，完整覆盖第一、二、三问。三问均以"完整可行架次列（Route-and-Load / Route-and-Interval Service / 时间化 Configuration）"为核心，采用列生成 + 精确定价 + 对偶证书求下界、有限邻域/大邻域精确重构求上界、ε-约束 + Dinkelbach 做次级 Pareto 优化的统一框架；求解工具提及 SCIP、HiGHS、自研 C++ 定价器与两套独立 Python validator。关键结果：Q1 为 87 架次、T∈[14104, 14699] min（gap 4.05%）；Q2 为 90 架次、T∈[15380, 16584] min（gap 7.26%）、座位利用率 95.24%；Q3.1 为 133 架次、T∈[15276, 23424] min（gap 34.78%），Q3.2 固定预算下临时任务 136≤S*≤160，最终取 ND_005 折中方案（P=258088 person-min，U=72.82%）。

### 三、主要优点

1. **诚实且可验证的界声明贯穿全文**：Q1 明确写"14699 是当前最好可行方案而非证明的全局最优"（式 12），Q2 明示 MID_U"未证"切片最优，Q3 反复声明 136 只是 286-configuration 邻域内最优；三处 boxed 结论均以严格上下界区间给出，杜绝了"把启发式当最优"的通病。
2. **独立校验体系设计完整**：5.5.1、6.5、8.1 节均要求从原始 distances.csv/people*.csv 重算路线闭合、逐段容量、燃油递推、first-delivery 与 30min 周转，三份最终方案 PASS、0 errors，且上界与下界使用相互独立的计算链。
3. **问题二/三的动态座位建模有真实创新**：用半开区间 [u,v) 统一表达先下后上、座位即时复用与首次到达下机（式 24-28），用区间图最大团约束替代逐飞机标签以避免编号对称（式 58-59），并能通过区间染色无损恢复个体方案。
4. **多目标处理忠于题设优先级**：以"一级目标严格优先 + 二级 Pareto"替代主观加权（5.6 节），U 约束线性化与 Dinkelbach 处理分式目标方法得当，且明确不声称完整全局 Pareto 前沿。
5. **支撑材料与可复现性远超常规**：附录 A 给出 17 类文件清单与一键复现命令（verify_support.py），附录 B 列出六个统一入口，含输入哈希、证书 JSON 与自动测试，且附 AI 工具使用声明。

### 四、主要问题与风险

1. **问题三 gap 高达 34.78%，最复杂一问的"答案"实质未认证**：Q3.1 下界 15276 来自仅含容量割的连续松弛（表 11），论文自认"未完整表达多日时间同步和整数服务模式"，意味着题设最看重的 Q3 首要目标质量主要依赖单个可行上界，评审无法判断 23424 距最优多远。
2. **下界证书存在未展示的关键引理**：Q1 下界依赖"至少 29 个架次必须加油"的独立证明补入 290min（5.3 节），但论文正文未给出该证明或校验方式，使 14104 这个安全下界的可信度打折扣。
3. **最终提交方案全部来自显式有限邻域而非全局**：ND_050（等时间邻域）、MID_U（397 路线变体邻域）、ND_005（286-configuration 邻域）都是局部最优折中，摘要中的总时间、利用率等头部数字易被误读为全局意义下的答案，论文虽反复声明但表达上仍具误导风险。
4. **方法论严重过载、篇幅失控**：约 2760 行、158KB，含大量过程考古式内容（历史 checkpoint、迭代诊断表、6 个附录入口代码），中英术语混杂（如"Configuration 后端""incumbent"），普通评审与读者难以在有限时间抓住主线，也可能引起对"是否过度包装"的怀疑。
5. **缺乏基准对照与多维度敏感性**：全篇没有与简单启发式（如贪心逐 OD 拼架、最近邻合并）或可复现解析界的系统对比（仅内部轨迹比较），敏感性只测油耗一项且固定路线，未验证时间窗、机队数量、容量变化对结论稳健性的影响，使复杂求解器的增值难以量化。
