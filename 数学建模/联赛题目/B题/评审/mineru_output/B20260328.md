# 基于启发式算法应用求解器的海上油田直升机人员运输调度优化

摘要：本文针对海上油田人员直升机运输计划编排问题，研究在多机场、多设施、多机型的条件，考虑海上停靠次数、燃油补给、动态载客和人员不可换乘等约束下的路径规划与排班优化方法。综合考虑总飞机使用时间、人员总在途时间、燃油消耗量和座位利用率等评价指标，本文建立了由启发式构造、候选路线生成、集合划分整数规划和分阶段排班共同组成的混合优化框架。首先在路线层面保证起降闭合、停靠次数、燃油安全和载客容量可行，再根据不同问题的新增约束逐步引入全局选线、差异化候选注入和时间窗排班校正。

对于问题一，运输需求均为陆地机场至海上设施的出海需求，且不考虑时间窗和有限机队约束。本文将人员需求按海上设施和归属机场组织为闭合架次，采用贪心合并、局部邻域搜索和参数敏感性检验优化总飞机使用时间，并进一步建立集合划分模型与求解器结果进行交叉验证。最终方案覆盖 1600 名人员，总飞机使用时间为 259.4 h，人员总在途时间为 2369.2h，共 89 架次，总燃油消耗量为 124944 kg，全程座位利用率为 47.8%，这说明所构造的混合启发式方案在效率和可行性方面均具有较好表现。

对于问题二，需求类型扩展为出海、海返和海上穿梭，人员在同一架次不同航段上的占座状态随上下机顺序动态变化。本文先比较设施编号分区与最近机场分区，再将各区域子问题建模为候选路线集合划分整数规划，并通过逐段动态载重约束刻画出海、海返和穿梭需求的混合承运过程。为兼顾启发式候选的结构多样性和整数规划的全局选择能力，最终采用差异化混合候选方案：在 A02 和 A03 区域注入 Clarke-Wright 候选路线，在 A01 区域保持规则候选。最终方案实现 4000 人全覆盖，总飞机使用时间为 18040 min，即 300.7 h，共 91 架次，总燃油消耗量为 137785.4 kg，座位利用率为 44.67%。

对于问题三，在问题二基础上进一步加入时间窗、业务优先级、24 架固定机队和多日运行等约束条件。本文采用编号区域分解与分阶段调度框架，第一阶段优先安排应急处置、增储上产和常规倒班等非临时任务，通过贪心构造、可行性修复和 MILP 整体重排得到基准方案；第二阶段在不增加总飞机使用时间的前提下，将临时任务拼入已有航线。最终方案总飞机使用时间为 56429 min，即 940.5 h，共 307 个唯一架次，总燃油消耗量为 426361 kg，安排 3933名人员，其中临时任务 160/160 全部满足。对未安排的 67 名非临时人员进一步分析表明，其主要瓶颈不是单独运输不可达或座位总量不足，而是时间窗与已有路线组合之间存在冲突。

关键词：直升机调度；路径规划；贪心构造；混合启发式；时间窗；求解器

## 1 问题重述

海上油田由多个油气田及配套设施构成，各设施协同承担开采、处理、输送和维修任务。由于海上生产连续性强，人员需在设施间长期驻守并定期换班，主要依靠直升机运输。运输方向包括出海、海返和穿梭三类，任务按业务性质分为应急处置、增储上产、常规倒班和临时任务，优先级依次递减。

本题涉及 3 座陆地机场、52 座海上设施，其中 8 座具备加油能力。可用机型为 T1、T2、T3，座位数分别为 12、16、19，速度分别为 250、220、190 km/h，油耗、油箱容量和最低安全余油量随机型不同。飞行速度和单位距离油耗不随载客量变化。

一个架次指直升机从机场起飞，连续停靠一座或多座海上设施后返回原机场的过程。每架次最多 5 次海上着陆，人员必须同架次送达且不得换乘。飞机从机场满油起飞，停靠加油设施可选择加油；不加油需停靠至少 10 分钟，加油需至少 20 分钟。

优化的主要目标为最小化总飞机使用时间（各架次从起飞到返回的时间之和）；次要目标包括最小化人员总在途时间、最小化总燃油消耗量以及最大化座位利用率，其定义为：

$$
U = \frac {\sum (\text {机上人数} \times \text {航段距离})}{\sum (\text {机型座位数} \times \text {航段距离})}
$$

问题一：对于给出的 1600 条出海需求，要求为其编排运载计划。不考虑时间窗口和业务优先级约束，假设飞机数量充足，在最小化总飞机使用时间的基础上尽可能优化座位利用率、油耗等因素，并给出总飞机使用时间、人员总在途时间、总架次数、总燃油消耗量和座位利用率。

问题二：对于给出的 4000 条包含出海、海返和穿梭的需求，要求为其编排运载计划。约束条件与问题一相同，在最小化总飞机使用时间的基础上尽可能优化其他因素，并给出相应指标。

问题三：本问在问题二基础上增加了最早可登机时间、最晚需到达时间和业务性质，需求时间分布在 2026-08-03 至 2026-08-10 之间。本问使用 24 架飞机（A01、A02、A03 各 8 架），飞机可在 06:00 至 18:00 之间起飞，不晚于 20:00 返回，不得在海上过夜，架次间至少 30 分钟周转。临时任务可被取消。要求先在不考虑临时任务时编排计划得到基准总飞机使用时间，再在不超过该时间的条件下尽可能多地满足临时人员运输需求，并给出临时人员满足情况及各项指标。

## 2 问题分析

本题属于多机场、多机型、多停靠点条件下的直升机人员运输路径规划与排班优化问题。除每个架次的起降机场、机型、停靠点和人员分配外，还需满足海上着陆次数、燃油安全、人员换乘限制和载客量等约束。随着需求从 1600 人扩大到 4000 人，并加入时间窗和有限机队约束，直接枚举可行组合会造成规模迅速膨胀。因此，本文采用“分解降维、候选生成、可行性检查、全局选择与排班校正”的建模思路。

问题一仅包含出海需求，人员均由陆地机场前往海上设施，不涉及海返、穿梭、时间窗和有限机队约束。关键是在每架次最多 5 次海上着陆、载客容量和燃油安全约束下合并同向人员，并在总飞机使用时间最小的基础上提高座位利用率。因此，可将问题转化为若干“机场-海上设施组-机场”的闭合架次构造与选择问题，并通过局部搜索和集合划分模型优化路线选择。

问题二在问题一基础上增加海返和海上穿梭需求，同一架次中可能出现先下后上或多 OD混合承运，架次可行性取决于停靠顺序和各航段动态载客人数。本文通过区域分解降低问题规模，并在候选路线中显式模拟每段载客量约束、起降机场约束和接送顺序约束，同时用启发式候选补充规则提高候选池覆盖能力。

问题三进一步引入最早可登机、最晚到达、业务优先级、24 架固定机队和多日运行规则，使问题从静态路线选择转为带时间窗的排班问题。路线层面的最短路径未必能对应到可行排班，同一时间窗内人员合并过细也会导致架次数增加。因此，本文先构造可行路线，再通过可行性修复与 MILP 整体重排压缩排班冲突，最后在不超过总飞机使用时间基准的条件下纳入临时任务。

综上，三问呈现由简单出海合并到多方向动态载重、再到带时间窗多日排班的递进关系。本文在统一路线可行性检查框架下，逐层增强模型表达能力。

## 3 模型假设

1. 直升机按距离矩阵中的最短航线飞行，不另考虑天气、空域管制、临时禁飞等外部扰动。

2. 除问题三规定的多日排班外，不考虑机组休息、维修计划和机场地面保障资源差异。

3. 飞行速度和单位距离油耗仅由机型决定，不随载客人数、风向、飞行高度和起降次数变化；停靠期间不计燃油消耗。

4. 对出海、海返和穿梭需求，人员的上机停靠序号必须小于下机停靠序号；每一航段机上人数按此前已上机且尚未下机的人员动态计算。

5. 问题三中应急处置、增储上产和常规倒班视为非临时刚性需求，临时任务允许不安排；第二阶段拼入临时任务时不破坏第一阶段已确定的非临时任务安排。

## 5 问题一的模型建立与求解

## 5.1 模型建立

我们采用贪心算法或粒子群算法，查阅文献发现可以在 VRP 问题中对算法改进优化，因此我们将两种算法进行结合，同时使用 AI 辅助，得出了贪心算法加破坏-重建加小规模粒子群算法，用于完成问题一的求解<sup>[1]</sup>。

## 5.1.1 优化目标

主目标：最小化总飞机使用时间

$$
T _ {\text { total }} = \sum_ {s} \left(\sum_ {i = 0} ^ {k} \left\lceil \frac {d (P _ {i} , P _ {i + 1})}{v _ {a c (s)}} \times 6 0 \right\rceil + \sum_ {i = 1} ^ {k} w _ {i}\right)\tag{1}
$$

其中 $\pi _ { s } = ( P _ { 1 } , \ldots , P _ { k } )$ 为架次 s 的海上停靠序列 $( k \le 5 ) , P _ { 0 } = P _ { k + 1 } = O _ { s } \in \{ A 0 1 , A 0 2 , A 0 3 \}$ 为起降机场； $d ( P _ { i } , P _ { i + 1 } )$ 为两点飞行距离（由 distances.csv 给出）， $v _ { a c ( s ) }$ 为机型 $a c ( s ) \in$ {T1,T2,T3} 的巡航速度； $w _ { i }$ 为第 i 站停靠时间（加油 20 min，不加油 10 min）；时间向上取整到整数分钟。

次目标：在主目标基础上尽可能优化人员总在途时间、总燃油消耗量与座位利用率。座位利用率采用题目口径（全航段）：

$$
\mathrm{Util} _ {\text {全航段}} = \frac {\sum_ {\text {全部航段}} (\text {在机人数} \times \text {航段距离})}{\sum_ {\text {全部航段}} (\text {座位数} \times \text {航段距离})} \times 100 \%\tag{2}
$$

返程航段在分母中完整计入” 座位数 × 距离”，分子贡献为 0（机上人数 = 0）。同时报告去程口径（仅” 机上有人” 航段求和），用于量化空载返程的座公里损失：

$$
\mathrm{Util} _ {\text {去程}} = \frac {\sum_ {\text {机上有人航段}} \text {在机人数} \times \text {航段距离}}{\sum_ {\text {机上有人航段}} \text {座位数} \times \text {航段距离}} \times 100 \%\tag{3}
$$

## 5.1.2 约束条件

每个架次 s 须同时满足：

1. 起降闭合： $O _ { s }$ 为起降机场，途中不得在其它机场中转。

2. 海上着陆上限： $| \pi _ { s } | \le 5$ ，且飞机离开后再次返回同一设施按实际着陆次数累计。

3. 燃油可行：满油起飞，到达任一地点（含最终返机场）剩余燃油 $\geq \mathrm { m i n o i l } _ { a c }$ ；在 R 内的设施停靠时加油则加满；停靠期间不另计燃油消耗。

4. 座位不超载：任意航段，机上人数 $\leq \mathrm { s e a t } _ { a c ( s ) }$

5. 人员不可换乘：从起点上机到终点下机，同一人员只能由一架次运送。

## （二）TSP 停靠顺序与加油扩展

方案可行的关键点为加油点必须是航线停靠点之一，不能凭空插入不在航线上的点，因此采用” 中转扩展” 让路径经过加油点；以设施名标记加油位（而不是位置索引）以避免加油点识别错误。

## 6.1.2 集合划分模型

对任一区域 z，设 $\mathcal { R } _ { z }$ 为该区域的候选路线集合。每条候选路线 $r \in \mathcal { R } _ { z }$ 由起飞机场、海上停靠序列、返场机场和机型共同确定，且已在生成阶段满足停靠数、燃油和路线结构约束。定义整数变量 $x _ { r }$ 表示路线 r 执行的趟数，整数变量 $y _ { r , o d }$ 表示路线 r 承运 OD 对 od 的人数。以总飞机使用时间最小为目标，区域子问题可写为

$$
\min \sum_ {r \in \mathcal {R} _ {z}} t _ {r} x _ {r},\tag{4}
$$

其中 $t _ { r }$ 为路线 r 执行一次所需的飞机使用时间，包含各航段飞行时间及海上停靠时间。

每个 OD 对的需求必须被完全覆盖，故有

$$
\sum_ {r \in \mathcal {R} _ {z}} y _ {r, o d} = D _ {o d}, \quad \forall o d,\tag{5}
$$

其中 $D _ { o d }$ 表示 OD 对 od 的需求人数。若路线 r 不经过该 OD 的起点和终点，或穿梭需求在该路线中的方向不满足先上后下，则不生成相应的 $y _ { r , o d }$ 变量。

## 6.2.1 思路二：启发式可行解

思路二采用“区域分解–Clarke-Wright 节约合并–LNS 模拟退火–PSO 验证”的启发式流程。在基础航线构造阶段，出海和海返需求分别形成“机场–设施–机场”路线，穿梭需求形成“机场–起点设施–终点设施–机场”路线；随后按节约值降序尝试合并：

$$
s a v i n g = d (O, a _ {\mathrm{end}}) + d (b _ {\mathrm{start}}, O) - d (a _ {\mathrm{end}}, b _ {\mathrm{start}}),\tag{7}

## 6.2.2 思路三：集合划分整数规划求解

## 6.2.3 思路四：差异化混合候选

本文最终采用的思路四的基本思想是：思路三具有全局选线能力，但 1/2/3 站固定候选可能遗漏部分优质合并；思路二的 CW 合并虽整体不及求解器结果，但能够补充一部分候选池外的有效路线。因此，将 CW 路线注入集合划分模型，使 CBC 在“规则候选 + 启发式候选”的混合候选集中重新进行全局选择。

## 7 问题三的模型建立与求解

## 7.1 模型建立

问题三在问题二的基础上引入运输时间窗、业务优先级以及有限机队约束，实质上形成带时间窗的取送货路径问题，并叠加多车场、多车型、燃油补给和多日排班要求。本文将每一架次表示为由归属机场出发、依次停靠若干海上设施并返回同一机场的闭合路线，同时在路线层面记录到达时刻、离开时刻、是否加油以及承运人员上下机序号。人员运输需求分为应急处置、增储上产、常规倒班和临时任务，其中前三类为刚性需求，临时任务允许未安排。

## 7.1.1 区域分解模型

问题三沿用问题二的设施编号分区，将全局需求分解为 A01、A02 和 A03 三个单机场子问题。具体分组规则保持与问题二一致：若需求起点或终点为固定机场，则锁定该机场；若需求一端为 LAND，另一端为海上设施，则按海上设施编号归入对应机场；若需求为海上设施间穿梭，则按起终点所在编号区域归入对应机场。区域划分为

## 7.1.2 架次路径与排班变量

设机场集合为 $\mathcal { A } = \{ A 0 1 , A 0 2 , A 0 3 \}$ ，海上设施集合为 ${ \mathcal F } ,$ ，飞机集合为 H。每架飞机 $h \in \mathcal H$ 具有固定归属机场 $a ( h )$ 和机型 $c ( h ) \in \{ T 1 , T 2 , T 3 \}$ 。对架次 r，其停靠序列记为

$$
\pi_ {r} = (v _ {r 0}, v _ {r 1}, \ldots , v _ {r m _ {r}}, v _ {r, m _ {r} + 1}),
$$

其中 $v _ { r 0 } = v _ { r , m _ { r } + 1 } = a ( h )$ ，中间节点为海上设施，且 $m _ { r } \le 5 _ { \mathfrak { c } }$ 。定义 $A _ { r i }$ 、 $D _ { r i }$ 分别为架次 r 到达和离开第 i 个停靠节点的时刻， $z _ { r i } \in \{ 0 , 1 \}$ 表示是否在该节点加油。人员 p 的上机和下机停靠序号分别为 $u _ { p }$ 和 $d _ { p }$ ，其所属架次为 $r ( p )$ o

模型的主目标为最小化总飞机使用时间，即

$$
\min T = \sum_ {r \in \mathcal {R}} \left(A _ {r, m _ {r} + 1} - D _ {r 0}\right),\tag{8}
$$

其中 为所有实际执行架次集合。总架次数、燃油消耗、座位利用率和人员总在途时间作为结果评价指标，用于比较不同求解方案。

## 7.1.3 时间窗与排班约束

问题三的路线层面约束沿用问题二，本问新增的核心约束来自人员时间窗、固定机队和多日运行规则。对人员 $p ,$ ，其上机时刻不得早于最早可登机时刻，抵达终点时刻不得晚于最晚到达时刻，即

$$
D _ {r (p), u _ {p}} \geq e _ {p}, \qquad A _ {r (p), d _ {p}} \leq l _ {p},\tag{9}
$$

其中 $e _ { p }$ 和 $l _ { p }$ 分别为人员 p 的最早可登机时刻和最晚抵达时刻。

在排班层面，每架飞机只能执行其归属机场的架次，且同一实体飞机相邻架次之间需保留不少于 30 min 的地面周转时间。每日运行规则要求起飞时刻位于 06:00 至 18:00 之间，返场时刻不晚于 20:00，且直升机不得在海上过夜。上述约束使问题三由问题二的静态候选路线选择扩展为带时间窗和固定机队的多日排班问题。

## 7.1.4 两阶段层级模型

按照题意，问题三采用两阶段求解。第一阶段仅处理应急处置、增储上产和常规倒班三类非临时需求，得到基准总飞机使用时间 $T _ { 0 }$ ；第二阶段以 $T _ { 0 }$ 为预算，将临时任务作为可选请求加入，在不破坏非临时任务安排且总时长不超过 $T _ { 0 }$ 的前提下，最大化临时任务满足人数。实际结果中，第一阶段送达 3773 名非临时人员，仍有 67 名未能安排；第二阶段将 160 名临时人员拼入现有航线，总时长保持 56429 min。

## 7.2.3 第一阶段：非临时任务构造与调度

第一阶段按时间窗构造紧迫性架次。应急处置共 40 人，按最早可登机时刻排序，优先使用速度较快的 T1，远距离采用 T2 或 T3；增补上产共 360 人，按同设施、同日期合并专机；常规倒班共 3440 人，按最晚到达时刻排序，并采用设施-日期聚类满足时间窗。调度时维护各架飞机的连续可用区间，若当前日期无法排入则顺延安排，以减少架次膨胀和资源闲置。

## 7.2.4 MILP 整体重排

贪心构造和顺延调度后，将候选架次输入 MILP 进行整体重排。模型在固定候选架次下，为每个机场的 8 架飞机分配执行时间和飞机，避免时间重叠，并满足日运行、周转和人员时间窗约束。实验显示，MILP 在保证可行性的同时进一步压缩架次数量，将总体结果降至 42人，并将 T0 由 974.5 h 降至 940.5 h。

## 7.2.5 思路探索与最终选择

## 7.2.6 第二阶段：临时任务拼入

第二阶段将临时任务集合 $\mathcal { P } _ { 2 }$ 并入第一阶段已确定的架次集合 R，其中 $| \mathcal { P } _ { 2 } | = 1 6 0$ 。设$x _ { p , r } \in \{ 0 , 1 \}$ 表示人员 $p$ 是否并入架次 $r , \ u _ { p , r } . \ d _ { p , r }$ 分别表示并入后的上机和下机停靠序号。模型以最大化临时任务满足人数为目标：

$$
\max \sum_ {p \in \mathcal {P} _ {2}} \sum_ {r \in \mathcal {R}} x _ {p, r},\tag{10}
$$

并满足如下约束：

$$
\sum_ {r \in \mathcal {R}} x _ {p, r} \leq 1, \quad \forall p \in \mathcal {P} _ {2},\tag{11}
$$

$$
x _ {p, r} \leq \mathbf {1} \{o _ {p} \in \pi_ {r}, d _ {p} \in \pi_ {r} \}, \quad \forall p \in \mathcal {P} _ {2}, \forall r \in \mathcal {R},\tag{12}
$$

$$
D _ {r, u _ {p, r}} \geq e _ {p}, \quad A _ {r, d _ {p, r}} \leq l _ {p}, \quad \forall p \in \mathcal {P} _ {2}, \forall r \in \mathcal {R},\tag{13}
$$

$$
L _ {r, i} + \sum_ {p \in \mathcal {P} _ {2}} x _ {p, r} \mathbf {1} \{u _ {p, r} <   i \leq d _ {p, r} \} \leq Q _ {c (r)}, \quad \forall r \in \mathcal {R},   \forall i.\tag{14}
$$

上述约束分别对应至多覆盖一次、起终点在停靠序列内、满足人员时间窗以及逐航段载客不超过座位数。由于拼入不改变既有停靠序列和起降时刻，除座位余量外不存在跨架次耦合，因此可逐人扫描首个满足三项判据的架次，复杂度为 $O ( | \mathcal { P } _ { 2 } | | \mathcal { R } | )$ 。

拼入不新增停靠点、不改变停靠顺序，故总飞机使用时间自动保持为第一阶段基准值：

$$
\tilde {T} = \sum_ {r \in \mathcal {R}} \left(A _ {r, m _ {r} + 1} - D _ {r, 0}\right) = T _ {0} = 5 6 4 2 9 \min.\tag{15}
$$

最终 160 名临时任务人员全部并入，满足率为 160/160；总飞机使用时间保持 56429 min，不超过 $T _ { 0 }$ ，且不新增架次与燃油消耗。

## 7.3.3 剩余 67 人的原因分析

## 8 模型的评价与推广

## 8.1 模型优点

本文模型层次清晰、可扩展性较好：问题一从单向出海需求出发，重点处理设施合并和机型选择；问题二引入海返与穿梭需求，并用集合划分提升路线选择能力；问题三进一步加入时间窗、有限机队和多目标排班约束，形成分阶段调度框架。

模型兼顾启发式算法效率和整数规划的全局优化能力。先用 Wright 节约法、时间窗三中心分组等方法生成候选路线，再通过集合划分和 MILP 整体重排优化结果，在较短时间内获得可行且质量较高的方案。

工程实现上，模型约束表达较完整，逐段检查燃油、时间窗、停靠、载客和机型连续编号等要求，提高了输出可信度。同时，通过多种思路对比和对剩余人员原因分析，增强了结论的透明度。

## 8.2 模型不足

模型仍有一定局限。候选路线主要由启发式生成，难以保证覆盖所有潜在最优路线；问题三中路线生成与时间排班尚未完全耦合，可能遗漏部分可行组合，剩余 67 人也体现了时间窗与路线组合的冲突。

此外，模型未考虑天气、机场保障能力、机组执勤、维护窗口和临时故障等因素，实际运行中还需加入鲁棒性与应急调整机制。目标函数也主要关注总飞机使用时间，对等待时间、业务优先级和碳排放等考虑不足。

## 8.3 模型推广

本文框架可推广到海上平台、岛屿交通、应急救援和多基地航空运输等场景。替换节点、距离、机型和需求数据后，可沿用“候选路线生成、可行性检查、集合划分或排班优化、输出校验”的流程。

对于更大规模或复杂时间窗问题，可引入列生成、时间索引集合划分或滚动优化，根据人员需求、天气和飞机状态动态调整方案，并结合仿真评估机队规模、加油设施配置和优先级规则的影响。

def best_multi_route(airport, dests, ac_type):
    """对目的地集合求最优停靠顺序（暴枚 TSP）并做燃油检查，返回可行方案。"""
    if len(dests) == 1:

    else:
    order = None

    route = [airport] + list(perm) + [airport]
    dd = sum(dist(route[i], route[i + 1]) for i in range(len(route) - 1))

    40% 最优，271h vs 20% 时的 289h，见 test_destroy_ratio*.py）。

remaining = [(p, d) for p, d in remaining if p not in assigned]

for f in flights:
    if f.empty_seats <= 0:
    continue
    dests = sorted(f.destinations, key=lambda d: -sum(1 for _, dd in remaining if dd == d))
    for dest in dests:

    if cnt == 0:

    n = min(cnt, f.empty_seats)

    f.passengers += got
    remaining = [(pid, dd) for pid, dd in remaining if not (dd == dest and pid in {x[0] for
    → x in got})]

return flights, remaining

def calculate_metrics(flights):
    """5 项指标。

    - 总飞机使用时间：各架次（飞行时间 + 停靠时间）
    - 人员总在途时间：每人从登机到下机（含中途停靠、不含最后目的站停靠，口径见论文）
    - 总架次数，总燃油量
    - 座位利用率：同时给 "题目全航段口径"与 "去程口径"两种
    """
    total_time = sum(f flight_time for f in flights)
    total_fuel = sum(f.fuel for f in flights)
    total_trips = len(flights)

    # 在途时间（口径：飞行时间 + 途经各海上停靠时间，含目的地自己那一站）
    # 依据题目原文："如果目的地是第1站，则只有1个航段飞行时间 + 该站停靠时间"
    total_in_transit = 0
    for f in flights:
    ac = AIRCRAFT[f.ac_type]
    route = [f.airport] + f.stops + [f.airport]
    refuel_fac = f.refuel_stops or set()
    for pid, dest in f.passengers:
    if dest not in f.stops:
    continue
    didx = f.stops.index(dest) + 1
    it = 0
    # 到目的站前的所有航段飞行时间
    for i in range(didx):
    it += math.ceil(dist(route[i], route[i + 1]) / ac["speed"] * 60)
    # 途经各站（含目的地自己）的停靠时间
    for i in range(1, didx + 1):
    stop_fac = route[i]
    it += 20 if stop_fac in refuel_fac else 10
    total_in_transit += it

    # 座位利用率：两种口径（见seat_util的公式说明）
    return _seat_util_metrics(flights, total_time, total_fuel, total_trips, total_in_transit)

def _nominal_duration(data, airport, atype, stops, refuel):
    """估算架次时长（分钟，无等待）。”"""
    route = [airport] + stops + [airport]
    dur = 0
    for i in range(len(route) - 1):
    dur += data.seg_time(atype, route[i], route[i + 1])
    dur += sum(C.DWELL_REFUEL if r else C.DWELL_NO_REFUEL for r in refuel)
