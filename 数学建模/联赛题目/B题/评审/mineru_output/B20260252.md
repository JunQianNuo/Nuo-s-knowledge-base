# 海上直升机人员接驳的分层候选池优化与多日排班

## 摘要

海上油气设施人员接驳同时受到多机场、异构机型、海上停靠次数、逐航段燃油安全、人员起终点与时间窗等约束，固定机队条件下还需满足多日连续排班与同机周转要求。针对三问逐级增加的约束，本文建立“候选运输单元生成–内部可行性评价–有限候选池整数重组–结果反向复算”的统一框架：决策单元由问题一的路线模板，升级为问题二包含人员批次的可执行列，再升级为问题三绑定具体飞机与日期的排班块。该分层设计将架次内部的载荷、燃油与时间传播约束前置到评价器中，使主模型只组合已验证的可执行单元。

问题一将 1600 条单向出海需求聚合为 104 个需求类，经基础架次、改进节约法与 ALNS 扩池后求解路线池整数规划；再固定 90 个乘客分组，在不增删中间停靠设施的前提下逐架次枚举机场、机型、既有中间设施的访问排列与加油方案。最终得到$T _ { a c } = 1 4 9 5 1 \mathrm { m i n } .$ $T _ { p a x } = 1 1 9 5 6 1 \mathrm { \ m i n } .$ $N _ { f } = 9 0$ 、Fuel= 120103.2 kg、U = 48.84%。该值是固定90个乘客分组空间内的精确最优（逐架次完全枚举380个可行变体），不宣称全路线-分配空间的全局最优。

问题二将 4000 条出海、海返与穿梭需求聚合为 264 个 OD 类，以可执行列固化路线、机型、加油方案及人员上下机批次，并在动态容量与燃油校验后进行有限列池分层重组。将固定 128 个乘客分组后枚举 621 个变体、按签名去重得到 373 条新列，并入79228 列候选池后形成 79601 列增广池，COPT 在该增广池内证明 $Z _ { 1 } = 2 3 1 1 2 \mathrm { m i n }$ 为整数最优（Gap=0）。最终方案取该 $Z _ { 1 }$ 最优解集内的一个可行解，报告 $T _ { p a x } = 2 6 0 7 8 8 \mathrm { { m i n } }$ $N _ { f } = 1 2 8$ 、Fuel= 184953.2 kg、U = 69.53%，后者为该可行解的指标值，不对增广池做次级目标最优声明。

问题三首先仅安排 名核心人员，在当前排班块池内得到基准 $T _ { 0 } = 3 9 7 7 7 \mathrm { { m i n } } ;$ 继而严格执行题目“加入临时任务后总飞机使用时间不超过核心基准”的业务要求，即保持 $T _ { a c } \leq T _ { 0 }$ 并最大化临时人员覆盖。候选排班块阶段覆盖 114 人；随后固定 221 架次、全部飞行时刻和3840名核心人员分配，对临时人员实施0–1精确重装，固定网络模型三层目标均为 Gap=0，覆盖提升至 155/160。最终五项指标为 $T _ { a c } = T _ { 0 } = 3 9 7 7 7 \mathrm { m i n }$ $T _ { p a x } = 2 6 7 0 2 5 \mathrm { ~ m i n }$ $N _ { f } = 2 2 1$ 、Fuel= 335503.9 kg、 $U = 4 5 . 4 8 \%$ 。这里的Gap=0仅适用于该固定网络重装空间。

三问最终方案均由独立程序反向重建路线、载荷、燃油和人员分配，校验错误数均为 0。本文据此区分固定分组精确最优、增广候选池内整数最优与固定网络精确最优，不对未枚举的全部潜在路线或排班空间作全局最优声明。

关键字： 海上直升机调度 取送货问题 自适应大邻域搜索 列池整数规划 字典序优化 多日排班

## 一、问题重述

## 1 . 1 问题背景

海上油气设施分布离散且需连续运行，生产、安全、检维修及后勤人员需在陆地机场与海上设施之间持续接驳。题目给出 A01、A02、A03 三座陆地机场、F001–F052 共52座海上设施及T1、T2、T3三种机型，其中8座海上设施允许途中加油；每个架次从某机场满油起飞，可连续停靠若干海上设施完成送达、接回或穿梭任务，最终返回原机场，单架次海上着陆不超过5次，且到达任一地点和最终返场时均须满足最低安全余油要求。题目以总飞机使用时间为首要评价指标，并同时统计人员总在途时间、总架次数、总燃油消耗量与座位利用率；人员陆地端记为 LAND 时可选择任一机场，给出具体机场编号时则必须由该机场完成相应任务，座位利用率按全部航段客座公里与可用座公里之比计算。

## 1.2 问题提出

问题一给出 1600 条单向出海需求，不考虑最早可登机时间、最晚需到达时间和业务性质优先级，且假设可用飞机数量充足。需要在机场选择、机型容量、停靠次数、燃油安全和人员一次直达等约束下编排架次，以最小化总飞机使用时间为首要目标，并进一步改善其他运行指标。

问题二将需求扩展为 条出海、海返和海上设施间穿梭任务，仍不考虑时间窗、业务性质和飞机数量限制。同一架次中人员可以在海上设施中途上、下机，因此需要同时协调动态载荷、人员批次、停靠次序、机型和加油方案，在完成全部需求的前提下继续优化五项运行指标。

问题三在问题二的人员起终点基础上增加最早离开起点时刻、最晚送达时刻和业务性质，并限定24架具体飞机在7个运营日内执行任务。飞机每日仅能在06:00–18:00起飞，必须在 20:00 前返回所属机场，同一飞机相邻架次之间至少保留 30 min 周转时间。题目要求先在不考虑临时任务时得到核心排班的总飞机使用时间，再在不超过该基准的条件下尽可能多地安排临时人员。

## 二、 问题分析

本题三个问题具有明显的递进结构。其共同难点不在于单一约束，而在于“人员需求–物理路线–机型与燃油–全局组合”之间的耦合；问题三又进一步叠加时间窗、具体飞机和多日连续执行关系。相关研究通常将此类任务置于 pickup-and-delivery、异构车队、多行程与同步车辆路径问题的交叉框架中 [1, 2, 3, 4]，海上直升机人员运输的实际调度问题也具有类似的多约束组合特征[5, 6, 7]。

为避免在一个超大模型中同时暴露全部路径排列、人员分配、燃油状态和时间传播变量，本文采用“先定义可直接执行的候选运输单元，再在候选池上做整数重组”的统一框架。三问的决策单元依次由 Route Template 升级为 Executable Column，再升级为Schedule Block；在每一级内部，均先通过独立 Evaluator 固化结构、容量、燃油及时间等硬约束，再利用候选池扩张与整数规划完成全局组合。本文将这一框架概括为：先验证可执行单元，再组合；每一层的最优性只在明确的搜索空间内声明。总体流程如图 2所示。

## 2.1 问题一的分析

问题一中的人员均为单向出海，所有人员在陆地机场一次性登机，并在架次首次到达其目的设施时下机，海上设施不存在再次上客。因此，同一起点类别与目的设施的人员在可选架次、容量占用和目标贡献上完全一致，可先按“起点类别–目的设施”聚合需求。此时单架次起飞载荷就是全过程最大载荷，人员容量约束可从逐停靠动态递推简化为起飞时总人数不超过机型座位数。

据此，问题一以“起降机场–海上停靠序列–机型–加油方案”构造 Route Template。候选模板先通过结构和逐航段燃油评价，再由基础架次、改进节约法 [8] 和 ALNS 扩充路线池[9,10]；随后以模板执行次数和需求类分配人数为变量建立整数规划，在总飞机使用时间优先的前提下继续优化人员在途时间与座位利用率，最后对固定乘客分组进行逐架次路线级清理，从而进一步压缩绕行和多余停靠时间。

## 2.2 问题二的分析

问题二同时存在出海、海返和设施间穿梭需求，人员可在中间海上设施上下机，问题一“起飞载荷即最大载荷”的简化不再成立。若仍仅把物理路线作为候选对象，主模型必须重新决定人员批次及其上、下机位置，动态容量与人员指派将再次高度耦合。

因此，将候选对象升级为ExecutableColumn：一个Column同时固定起降机场、机型、停靠序列、加油标记和人员批次，且在入池前完成“先下后上”的动态载荷递推和逐航段燃油校验。这样，主模型不再处理架次内部的细粒度可行性，只需在已验证的 ColumnPool 上完成各OD 类的精确覆盖与列组合。候选空间则通过 ALNS、SavingsMerge、LAND 机场重选和机型重配等机制逐步扩张，并以消融结果判断各类结构扩展对主目标的边际贡献。

## 2.3 问题三的分析

问题三新增人员时间窗、固定机队、每日运营边界和同机多架次周转约束，单个架次可行并不能保证“同一架具体飞机在同一日连续执行若干架次”可行。由此，决策单元进一步升级：先以FlightColumn表示未绑定具体飞机和绝对时刻的物理可行架次，再把若干 Flight Column 按机型、基地、日期和执行顺序组合为 Schedule Block，并在 Block内完整传播起降、等待、停靠和返场时刻。多行程、时间窗与同步关系是该阶段的核心结构 [11, 12, 13, 2]。

题面还要求先确定不含临时任务的核心基准，再在不增加总飞机使用时间的条件下尽可能安排临时人员。因此，问题三采用两阶段字典序结构：Phase1对3840名核心人员建立 exact-one 覆盖并得到 $T _ { 0 }$ ；Phase 2 保持 $T _ { a c } \leq T _ { 0 }$ ，优先扩大临时覆盖。最终又在固定 221 架次物理网络、全部飞行时刻和 3840 名核心人员分配的条件下，对临时人员进行精确重装填，将候选排班阶段的114人提升至155人。题面给出的应急处置、增储上产、常规倒班、临时任务保障次序，在三问口径下体现为：前三类为核心任务必须恰好覆盖一次、临时任务允许取消并置于最后补充；由于最终方案中 3840 名核心人员全部精确覆盖、不存在相互挤占的资源冲突，该次序未触发额外取舍，仅在需要时作为等待与分配优先规则。

## 三、 模型假设

为使三个问题在同一计算口径下衔接，并严格遵循题面给出的运行规则，作如下统一约定：

(1) 任意相邻停靠点之间的航程均直接采用题目给出的距离矩阵，不进行欧氏距离替换或最短路闭包处理。

(2) 三种机型的飞行速度和单位距离油耗均按题目给定常数计算，且不随载客量变化；各航段飞行时间按题意向上取整到整数分钟。

(3) 每个架次均从所属机场满油起飞，仅 8 座指定海上设施允许补充燃油；到达任一海上设施及最终返场时，剩余燃油均不得低于对应机型的最低安全余油量。

(4) 问题一和问题二不考虑人员时间窗、业务性质优先级和飞机数量限制，海上停靠采用最短服务时间：不加油 10 min、加油 20 min；问题三则保留人员时间窗，必要等待通过绝对时刻传播计入排班。

(5) 问题三中每架飞机始终以所属机场为基地，不允许在其他陆地机场中转或结束任务；飞机不得在海上设施过夜，相邻两架次之间至少保留30min机场周转时间，该周转只作为可行性约束，不计入单架次 $T _ { a c }$

(6) 题面未考虑机场、海上设施和加油站的并发容量限制，本文不额外引入相关资源约束。

## 五、模型的建立与求解

## 5.1 问题一的模型建立与求解

## 5.1.1 模型的建立

1. 数据校验与需求聚合 距离矩阵覆盖 3 座机场和 52 座海上设施共 55 个地点，经检查对称、主对角线为0且无缺失值和负距离。peopleQ1.csv含1600条单向出海需求，其中 1353 人起点为 LAND，固定由 A01、A02、A03 起飞者分别为 79、82、86 人，所有终点均为海上设施。本问不考虑时间窗与优先级，起点类别g 与目的设施f 相同的人员可选架次、容量占用与目标贡献一致，故按需求类 (g,f) 聚合、人数记为 $D _ { g f }$ ，共形成104 个需求类；求解后再按保留的人员编号还原逐人分配，聚合不改变任何原始需求。

可行架次模板与路线指标 以“起降机场 海上停靠序列 机型 加油方案”定义候选架次模板 $p { : }$ ：首末均为机场 $a _ { p }$ ，中间至多 $m _ { p } \le 5$ 个海上设施，同一设施若重复访问则每次均计为一次海上着陆。相邻停靠点的飞行时间逐航段向上取整 $t _ { p , t } ^ { \mathrm { f l y } } = \lceil 6 0 d _ { s _ { p , t - 1 } , s _ { p , t } } / v _ { k _ { p } } \rceil$ 海上停靠时间 $t _ { p , t } ^ { \mathrm { s t o p } } = 1 0 + 1 0 z _ { p , t }$ （不加油10min、加油20min）。模板飞机使用时间

$$
\tau_ {p} = \sum_ {t = 1} ^ {m _ {p} + 1} t _ {p, t} ^ {\mathrm{fly}} + \sum_ {t = 1} ^ {m _ {p}} t _ {p, t} ^ {\mathrm{stop}}.\tag{1}
$$

式 (1) 先对每个航段分别取整再累加，停靠时间仅计中间海上设施，与最终独立复算口径一致。

燃油可行性与路线指标按下述递推确定：

• 架次满油起飞 $G _ { p , 0 } ^ { + } = Q _ { k _ { p } }$ ；每完成一航段扣减 $\rho _ { k _ { p } } d _ { : }$ ，并在每次海上到达与最终返场处要求剩余燃油 $G _ { p , t } ^ { - } \geq R _ { k _ { p } }$ ；

• 仅在题给 8 座可加油设施允许恢复满油，即 $G _ { p , t } ^ { + } = z _ { p , t } Q _ { k _ { p } } + ( 1 - z _ { p , t } ) G _ { p , t } ^ { - }$ ，其余设施 $z _ { p , t } = 0$ ；单架次最多 5 次停靠，至多枚举 $2 ^ { 5 } = 3 2$ 种加油标记，燃油判断容差为$1 0 ^ { - 8 }$ ；

• 对同一序列的多个燃油可行方案，按总停靠时间与前缀累计停靠时间做Pareto去重，保留非支配加油方案。

模板总航程 $\begin{array} { r } { L _ { p } = \sum _ { t = 1 } ^ { m _ { p } + 1 } d _ { s _ { p , t - 1 } , s _ { p , t } } } \end{array}$ ，因单位距离油耗与载客量无关，总燃油 $\phi _ { p } = \rho _ { k _ { p } } L _ { p }$ 5设设施f 首次出现在模板第 $\ell _ { p f }$ 个停靠位，则对应人员

$$
h _ {p f} = \sum_ {t = 1} ^ {\ell_ {p f}} t _ {p, t} ^ {\mathrm{fly}} + \sum_ {t = 1} ^ {\ell_ {p f} - 1} t _ {p, t} ^ {\mathrm{stop}},\tag{2}
$$

$$
b _ {p f} = \sum_ {t = 1} ^ {\ell_ {p f}} d _ {s _ {p, t - 1}, s _ {p, t}}.\tag{3}
$$

$h _ { p f }$ 用于人员总在途时间， $b _ { p f }$ 用于客座公里计算。

3. 路线池构造与模板兼容性 路线池分三层构造：第一层对每个“机场–目的设施–机型”组合生成基础模板，同时考察直接往返与在目标设施前后插入可加油设施的序列，保留飞机使用时间最小的可行序列及其非支配加油方案；第二层用改进节约法合并同机场路线，在停靠数不超过5时枚举保持两条原路线相对顺序的交错序列并重评机型，仅保留飞机使用时间严格小于两路线之和的正节约候选；第三层用ALNS继续扩池，采用“随机架次移除–贪心修复–模拟退火接受”流程，被释放需求按人数从大到小修复，优先利用现有路线剩余容量，否则枚举最优插入位置或从池中新建覆盖模板。模拟退火以总飞机使用时间变化量 $\Delta T$ 为能量差（ $. \Delta T \le 0$ 直接接受，否则以 $\exp ( - \Delta T / \theta )$ 接受，θ从 120 按 0.995 衰减）。正式配置取随机种子 2026、destroy\_size=12、ALNS 迭代 800次与800次节约合并上限，最终形成1185个唯一模板（以机场、停靠序列、机型、加油标记为唯一键去重）。

定义兼容参数 $\delta _ { p g f }$ ：模板 $p$ 经过目的设施 f 且起点类别 $g$ 与起飞机场相容时为 1，否则为 $0 ~ ( _ { g } = \mathrm { L A N D }$ 时三机场均可，指定机场时必须 $a _ { p } = g )$ ）。仅对 $\delta _ { p g f } = 1$ 的模板–需求类组合建立整数变量，严格执行LAND 与固定机场两类起点规则。

4. 人员分配与分层目标 令 $n _ { p } \in \mathbb { Z } _ { \geq 0 }$ 表示模板p 的执行架次数， $q _ { p g f } \in \mathbb { Z } _ { \geq 0 }$ 表示需求类 $( g , f )$ 分配给模板 $p$ 的人数。约束为

$$
\sum_ {p \in \mathcal {P}} q _ {p g f} = D _ {g f}, \quad \forall (g, f).\tag{4}
$$

$$
\sum_ {(g, f)} q _ {p g f} \leq C _ {k _ {p}} n _ {p}, \quad \forall p \in \mathcal {P}.\tag{5}
$$

$$
q _ {p g f} \leq D _ {g f} \delta_ {p g f}, \quad \forall p, (g, f).\tag{6}
$$

$$
n _ {p} \leq \sum_ {(g, f)} q _ {p g f}, \quad \forall p \in \mathcal {P}.\tag{7}
$$

式 (4) 覆盖全部需求；式 (5) 保证起飞载荷不超过机型座位（问题一起飞载荷即全程最大载荷）；式(6) 限定模板–需求类匹配；式 (7) 排除空架次。

目标按字典序分层。第一层最小化总飞机使用时间

$$
Z _ {1} = \min \sum_ {p \in \mathcal {P}} \tau_ {p} n _ {p}.\tag{8}
$$

固定第一层得到的模板执行向量 $n _ { p } ^ { * }$ （即保持已选架次数与路线模板不变）后，第二层最小化人员总在途时间

$$
Z _ {2} = \min \sum_ {p \in \mathcal {P}} \sum_ {(g, f)} h _ {p f} q _ {p g f}.\tag{9}
$$

座位利用率 $U = \left( \sum b _ { p f } q _ { p g f } \right) / \left( \sum C _ { k _ { p } } L _ { p } n _ { p } \right)$ 。在 $n _ { p } = n _ { p } ^ { * }$ 后分母为常数，故第三层最大化 U 等价于最大化客座公里 $\sum b _ { p f } q _ { p g f }$ 。实际求解先确定 $Z _ { 1 }$ 的当前最好可行模板执行向量，再固定 $n _ { p } ^ { * }$ 求 $Z _ { 2 }$ ，继而加入 $\sum h _ { p f } q _ { p g f } \leq Z _ { 2 } + 0 . 5$ 最大化客座公里；由于 $h _ { p f } , \ q _ { p g f }$ 均为整数，该半分钟容差不会放宽 1 min。固定 $n _ { p } ^ { * }$ 后，燃油 $\sum \phi _ { p } n _ { p } ^ { * }$ 与架次数 $\sum n _ { p } ^ { * }$ 均为常数，故二者是同层方案的报告指标而非仍可改变解的独立优化层。这个区分避免把无自由度的指标误写为已继续优化。

## 5.1.2 模型的求解

求解与校验 求解先读取并校验数据，聚合 1600 名人员为 104 个需求类，再依次生成基础架次、节约法合并与 ALNS 扩池；基于式 (4)–(7) 以 COPT 8.0.6 的 coptpy 接口建立整数规划，并按式 (8) 为首要目标分层求解（Threads = 8，三阶段时限 900/300/300 s）。

第一阶段最小化 $Z _ { 1 }$ 并保存最好可行的 $n _ { p } \backsim \ q _ { p g f } \large ;$ 第二阶段固定 $n _ { p } = n _ { p } ^ { * }$ 、最小化 $Z _ { 2 }$ ；第三阶段继续固定 $n _ { p }$ ，加入 $\sum h _ { p f } q _ { p g f } \leq Z _ { 2 } + 0 . 5$ 后最大化客座公里，再由最终指派计算座位利用率，燃油与架次数由固定 $n _ { p }$ 直接得到。

主目标在 900 s 时限内得到 incumbent=15022 min，因达到时间上限而终止，bestbound=14544.2676 min、Gap 约 3.18%、搜索 246652 个节点；该结果仅作当前路线池与求解时限下的最好可行解。总飞机使用时间由初始方案 20939 min 降至 ALNS 阶段17110 min，再经 COPT 主模型降至 15022 min；随后固定 90 组乘客重新枚举起降机场、机型、停靠顺序与加油方案逐架次清理，最终降至14951min。因问题一无跨架次耦合，固定分组后各架次相互独立，且本次逐架次枚举覆盖全部 380 个可行变体，故 90 架次独立字典序最优之和14951min是该固定分组空间内的精确最优值。为量化原路线池主模型与连续松弛的距离，另对 1185 模板池做 LP 松弛，得到下界 13934.8 min；该值连同 900 s 分支定界界 14544.3 min 均只针对 15022 所在的池模型，不与 14951 直接比较，且LP松弛偏松，故本文以固定分组精确最优作为问题一的主要证书。

为精确说明后处理的搜索边界，记主模型物化后的90个架次集合为 $\mathcal { R } _ { 1 }$ ，架次 $r$ 的固定乘客集合为 $G _ { r }$ ，其主模型中间停靠设施集合为 $F _ { r }$ 。对每个 $r$ 构造允许变体集 $\mathcal { V } _ { r }$ ：变体只能重新选择与 $G _ { r }$ 端点相容的起降机场、容量足够的机型、 $F _ { r }$ 的访问排列及可行加油标记，不得增加或删除中间设施，也不得在不同架次之间转移人员。对 $v \in \mathcal { V } _ { r }$ 重新计算飞机时间 $\tau _ { r v }$ 、固定乘客在途时间 $H _ { r v }$ 、客座公里 $P _ { r v }$ 、可用座公里 $W _ { r v }$ 和燃油 $\phi _ { r v }$ ，并按

$$
v _ {r} ^ {*} = \underset {v \in \mathcal {V} _ {r}} {\operatorname{argmin}} \left(\tau_ {r v}, H _ {r v}, - P _ {r v} / W _ {r v}, \phi_ {r v}\right)\tag{10}
$$

逐架次选择。问题一没有机队数量、跨架次时间窗或同机衔接约束，固定 $G _ { r }$ 后各架次相互独立，故该枚举保持整体可行并可加总降低前两项指标；但第三项是单架次比值的局部排序，最终全局 $\begin{array} { r } { U = \sum _ { r } P _ { r v _ { r } ^ { * } } / \sum _ { r } W _ { r v _ { r } ^ { * } } } \end{array}$ 仅作复算评价，不据此声称固定分组下的全局分式目标最优。

聚合结果按保留的人员编号还原逐人分配，并检查无空架次、无超载、人数一致，物化架次数与总人数分别等于 $\textstyle \sum _ { p } n _ { p }$ 与 1600。最终结果在 COPT 之外独立复验航班与停靠连续性、首末机场、着陆次数、加油位置、逐航段与返场余油、人员无重复无遗漏、机场匹配、首次到达下机及容量，并按 $\lceil 6 0 d / v \rceil$ 与10/20min停靠规则重算全部指标，校验错误数为 0，复算值 14951 min、119561 min、120103.2 kg、0.488420 与最终文件一致。

$$

Column 入池前已通过全部内部可行性检查，主模型只需通过式 (15) 与变量整数性完成候选列组合。目标按字典序依次为总飞机使用时间 $Z _ { 1 } = \mathrm { m i n } \sum \tau _ { c } x _ { c } \mathrm { . }$ 人员总在途时间$Z _ { 2 } = \operatorname* { m i n } \sum H _ { c } x _ { c }$ 、座位利用率 $Z _ { 3 } = \operatorname* { m a x } ( \sum P _ { c } x _ { c } ) / ( \sum W _ { c } x _ { c } )$ 、总燃油 $Z _ { 4 } = \operatorname* { m i n } \sum \phi _ { c } x _ { c } ,$ 总架次数

$$
Z _ {5} = \min \sum_ {c \in \mathcal {C}} x _ {c},\tag{16}
$$

每完成一层即固定已取得的高优先级目标值再优化下一层。 $Z _ { 3 }$ 为分式目标，采用Dinkel-bach 变换 [14]：给定 $\lambda ^ { ( t ) }$ 求解 $\begin{array} { r } { \operatorname* { m a x } \sum _ { c } ( P _ { c } - \lambda ^ { ( t ) } W _ { c } ) x _ { c } } \end{array}$ ，再以当前解更新 $\lambda ^ { ( t + 1 ) } = P ( x ^ { ( t ) } ) / W ( x ^ { ( t ) } )$ 直至残差 $| P - \lambda W |$ 不超过 $1 0 ^ { - 6 }$ 。浮点 $\lambda ^ { * }$ 下的等式不能作为数学上的“精确冻结”；因此，理论表述记录收敛解的整数总量 $P ^ { * } , W ^ { * }$ ，并用交叉乘关系

$$
W ^ {*} \sum_ {c \in \mathcal {C}} P _ {c} x _ {c} - P ^ {*} \sum_ {c \in \mathcal {C}} W _ {c} x _ {c} = 0\tag{17}
$$

刻画与最优比值 $P ^ { * } / W ^ { * }$ 相同的解集。计算实现仍按求解器可行性容差判断 Dinkelbach残差，并在最终方案中重新汇总整数 P,W 验证比值；故后续层的数值结论不依赖把浮点数当作精确有理系数。

T \leq T _ {0}\tag{22}
$$

在式 (22) 的约束下，临时满足人数 $\begin{array} { r } { Y = \sum _ { i \in \mathcal { P } ^ { T } } \sum _ { b \in \mathcal { B } } a _ { i b } \xi _ { b } } \end{array}$ ，并按 $\operatorname* { m a x } Y \gg \operatorname* { m i n } H \gg$ $\operatorname* { m a x } U \gg \operatorname* { m i n } \Phi \gg \operatorname* { m i n } N$ 继续优化。

## 5.3.2 模型的求解

完整 Block 无法直接穷举，求解采用“Flight Column 生成–Schedule Block 评价–候选池扩张–COPT 精确重组”的分层结构。Flight Column 从物理可行性出发保留不同加油组合并重算动态载荷、燃油与时间包络；初始单人列保证核心人员基本可达，必要时针对相容人员构造多人员 Column。Schedule Block 以可执行 Column 为种子、在机型/基地/日期相容候选中逐次追加架次，每次扩展均重新调用 Schedule Evaluator，任何硬约束失效即拒绝，故BlockPool中每个元素都是可直接执行的飞机–日完整排班。

单个核心人员可行不代表3840人能在168个飞机–日资源中同时安排；在投入大量算力做精确重组之前，先用最大覆盖诊断确认当前 BlockPool 是否存在 exact-one 组合。正式优化前建立最大覆盖诊断模型：对当前BlockPool定义 $y _ { b } \in \{ 0 , 1 \}$ ，求解

$$
\max \sum_ {b \in \mathcal {B}} | \mathcal {P} _ {b} \cap \mathcal {P} ^ {0} | y _ {b} \quad \text {s.t.} \quad \sum_ {b \in \mathcal {B}} a _ {i b} y _ {b} \leq 1 (\forall i \in \mathcal {P} ^ {0}), \quad \sum_ {b \in \mathcal {B} _ {v d}} y _ {b} \leq 1 (\forall v, d).\tag{23}
$$

当式 (23) 的最优覆盖达 3840 时存在核心 exact-one 组合；否则依据未覆盖人员的候选Block数、可用飞机–日与时间窗特征定向扩张。经多人员Column扩展、难点人员定向补充与 Block 重组，最大核心覆盖沿 $3 4 8 9 \to 3 4 9 3 \to 3 5 3 8 \to 3 6 9 0 \to 3 6 9 8 \to 3 8 3 6 \to$ 3839 → 3840 逐步提高至 3840（图 12）；核心 Block Pool 随后重建为 23949 个纯核心候选，临时人员泄漏为 $0 ;$ ；其必要性在于核心基准 $T _ { 0 }$ 只能由核心人员的排班构成，否则临时人员混入会污染 $T _ { 0 }$ ，使第二阶段 $T \leq T _ { 0 }$ 的预算失去含义。

该覆盖链的提升来自四类受控扩展：先构造可执行多人员架次列提升单架次运输密度；再以飞机–日为单位把架次打包为排班块；随后建立最大覆盖诊断模型定位未覆盖人员的候选块数与可用飞机–日缺口，针对稀缺人员与稀缺飞机–日定向补充候选；最后对个别单点缺口做相邻飞机–日间的架次腾挪。每轮扩展都以完整ScheduleEvaluator复核，覆盖链的每个数值均来自候选池上的精确最大覆盖求解。

$$
y _ {i r} = \left\{ \begin{array}{l l} 1, & \text {临时人员} i \text {采用乘坐选项} r, \\ 0, & \text {否则}. \end{array} \right.\tag{24}
$$

在可行选项已完成个体约束筛选的基础上，模型只需控制唯一指派和剩余容量：

$$
\sum_ {r \in \mathcal {R} _ {i}} y _ {i r} \leq 1, \quad \forall i \in \mathcal {P} ^ {T}; \qquad \sum_ {i \in \mathcal {P} ^ {T}} \sum_ {r \in \mathcal {R} _ {i}} a _ {e i r} y _ {i r} \leq C _ {e} - q _ {e} ^ {0}, \quad \forall e \in \mathcal {E} ^ {*}.\tag{25}
$$

定义临时人员服务量、总乘坐时长和乘客公里为

$$
Y ^ {T} = \sum_ {i} \sum_ {r \in \mathcal {R} _ {i}} y _ {i r}, \qquad H ^ {T} = \sum_ {i} \sum_ {r \in \mathcal {R} _ {i}} h _ {i r} y _ {i r}, \qquad P ^ {T} = \sum_ {i} \sum_ {r \in \mathcal {R} _ {i}} p _ {i r} y _ {i r},\tag{26}
$$

并按 $\operatorname* { m a x } Y ^ { T } \gg \operatorname* { m i n } H ^ { T } \gg \operatorname* { m a x } P ^ { T }$ 词典序求解。固定网络后， $T _ { a c } .$ 、总可用座公里 $W$ 、架次数 $N _ { f }$ 与燃油均为常数；人员总在途时间由固定核心部分与 $H ^ { T }$ 相加，座位利用率由 $( P ^ { 0 } + P ^ { T } ) / W$ 复算。因此，重装模型可以改变 $T _ { p a x }$ 与 $U$ ，但不会改变 $T _ { a c }$ 、 $N _ { f }$ 或Fuel。该模型共有 579 个 0–1 变量，最大服务量、最小临时时长和最大临时乘客公里三个子问题均求得 $\mathrm { G a p } { = } 0$ ，最终覆盖由114人提升至155 人。

## 六、模型的评价与推广

## 6.1 模型的优点

本文最主要的特点是沿题目约束的递进关系逐级升级决策单元：问题一以 RouteTemplate 固化机场、机型、停靠与加油，问题二把人员上下机批次封装进 ExecutableColumn，问题三再升级为具体飞机–日ScheduleBlock，既保留三问继承关系，又把新增约束限制在真正发生作用的层级。第二，物理可行性评价与全局组合优化相分离：路线、Column 或 Block 在入池前即完成结构、动态载荷、燃油与时间传播检查，主整数规划只在“可直接执行”的候选单元上组合，每个被选变量都具有明确业务含义与可物化结果。第三，求解兼顾候选空间扩张与目标优先级：ALNS[9, 10]、Savings Merge、LAND机场重选与定向 Block扩展补充候选，COPT 在同一有限候选池内逐层冻结高优先级目标，路线级清理，以及固定航班网络和核心分配后的精确重装进一步利用局部结构获得改进。第四，全文采用独立校验闭环，最终CSV由独立程序反向重建，三问errors=0，并明确区分固定分组精确最优、增广候选池内整数最优与固定网络精确最优等证明层次。

## 6.2 模型的不足

问题一在固定 90 个乘客分组的搜索空间内达到精确最优，问题二的 $T _ { a c }$ 在 79601列增广池内达到整数最优，但两者的最优性都不外推到未枚举的全路线-分配空间；问题三核心阶段的整数最优性依赖当前冻结BlockPool、155/160依赖固定221架次、全部飞行时刻和 3840 名核心人员分配，故三问证书均只在其各自的搜索空间内成立。候选池扩张规模与求解难度存在权衡，候选数量增加不保证固定时限下incumbent单调改善，候选池的全空间完备性也缺少统一理论界。另一方面，模型把速度、单位距离油耗、停靠服务时长与天气条件视为确定量，未考虑机场和海上设施并发容量、天气、维护、空域拥堵及扰动后的恢复调度；这些简化保证了模型对应竞赛题面，却限制了方案直接用于实际运营时的稳健性。

## 6.3 模型的改进与推广

后续可沿“候选单元生成—资源评价—整数重组”层次继续扩展：增加针对难覆盖需求与高边际收益结构的定向候选生成，并把后处理发现的优质局部结构反馈给主候选池，缩小候选空间与清理后可行空间的差距。对于实际海上运输场景，还可在ScheduleEvaluator层增加机场与设施并发容量、维修窗口、天气可飞性与机组值勤等约束，新增约束优先放入最接近其业务作用层级的 Evaluator 中，从而保持模型结构的可解释性与可维护性。

## 附录B COPT 求解器使用说明

本文三个问题的整数规划与组合优化阶段均使用杉数科技 COPT 求解器进行数值求解，采用COPT8.0.6及其Python接口coptpy。本文并非将所有潜在运输路线、人员指派和多日排班一次性直接交由求解器枚举，而是先通过需求聚合、候选路线或候选列生成、ALNS、Savings Merge、机场重选以及 Schedule Block 构造等方法形成已经通过物理可行性评价的有限候选空间，再由COPT对相应整数规划模型进行组合重组与分层优化。因此，全文形成“候选结构生成–COPT整数优化–结果独立校验”的混合求解框架。

## 2.1 问题一中的 COPT 使用

问题一首先通过基础架次、改进节约法与ALNS扩充RouteTemplate路线池，随后使用 COPT 建立路线模板整数规划主模型。模型以模板执行次数 n 和人员分配量 $n _ { p }$ $q _ { p g f }$ 为整数决策变量，并加入需求完全覆盖、机型容量、起飞机场兼容性和非空架次等约束。求解时首先最小化总飞机使用时间 $Z _ { 1 }$ ，再固定第一阶段得到的路线结构优化人员总在途时间 $Z _ { 2 }$ ，并在锁定 $Z _ { 2 }$ 后继续优化座位利用相关目标 $Z _ { 3 }$ 。正式COPT路线池模型在既定路线池和求解时限内得到 $T _ { a c } = 1 5 0 2 2 \mathrm { { m i n } }$ 的最好可行解；其后固定90个乘客分组进行逐架次路线级清理，完全枚举 380 个可行变体，得到论文最终采用的 14951 min；因问题一无跨架次耦合、逐架次枚举完备，14951 min 是固定分组空间内的精确最优。对1185 模板池主模型另做 LP 松弛得到下界 13934.8 min，与 900 s 分支定界界 14544.3 min均只针对15022所在池模型，不与14951直接比较。相关COPT建模与求解代码主要见

Q1/code/master.py 和 Q1/code/solve\_q1.py；最终 14951 的路线级清理由独立后处理脚本完成（见附录源码清单）。

## 2.2 问题二中的 COPT 使用

问题二将起降机场、机型、停靠序列、加油方案及人员上下机批次封装为ExecutableColumn，并在候选 Column Pool 上使用 COPT 建立整数重组模型。模型以各 Column 的执行次数 $x _ { c }$ 为非负整数变量，通过 OD 需求覆盖约束保证全部运输需求得到满足，并按照总飞机使用时间、人员总在途时间、座位利用率、总燃油消耗量和总架次数的优先顺序进行分层求解。对于座位利用率对应的分式目标，采用 Dinkelbach 迭代转化为一系列可由COPT求解的整数优化子问题。LAND机场重选阶段在79228个候选Column上得到 $Z _ { 1 } ~ = ~ 2 3 1 7 7 ~ \mathrm { { m i n } }$ ，且该有限 Column Pool 内 Gap 为 $0 _ { \circ }$ 。随后固定 128 个乘客分组进行路线级清理，得到 373 条原池没有的新列，并入后形成 79601 列增广池；以COPT 零容差（RelGap=AbsGap=0）重解 $Z _ { 1 }$ ，得 UB=23112、LB=23112、Gap=0、2524节点、约 42 s，即 23112 为增广池内 $Z _ { 1 }$ 整数最优。相关分层 COPT 求解代码主要见Q2/code/p7\_land\_hier.py 等文件。

## 2.3 问题三中的 COPT 使用

问题三在问题二物理可行运输单元的基础上进一步加入人员时间窗、24 架具体飞机、每日运营边界及同一飞机相邻架次至少30min周转等约束，并以ScheduleBlock表示“具体飞机–日期–有序架次–绝对时刻”的完整日排班。候选 Block 在进入主模型前已完成时间传播、人员时间窗、动态载荷、燃油安全、返场边界及周转约束检查，随后使用 COPT 对 Block Pool 进行整数精确重组。第一阶段仅服务 3840 名核心人员，通过exact-one覆盖约束保证每名核心人员恰好被安排一次，并按照既定字典序目标逐层冻结优化，得到当前纯核心BlockPool内的基准 $T _ { 0 } = 3 9 7 7 7 \mathrm { { m i n } }$ 。第二阶段保持 $T _ { a c } \leq T _ { 0 }$ ，在扩充后的候选BlockPool上优先最大化临时任务覆盖。候选排班阶段首先得到临时覆盖114人的方案；随后固定最终221架次、全部飞行时刻和3840名核心人员分配，对160名临时人员实施579变量0–1精确重装。该重装模型由独立脚本以scipy/HiGHS精确求解（579变量，三层Gap=0），最终覆盖提升至155/160，相关代码见附录源码清单；COPT用于 Block Pool 的两阶段重组。相关 COPT 求解程序主要见 Q3/code/p4\_solver.py、各阶段 run\_p\* 求解脚本及 solve\_coverage.py 等文件。

综上，COPT 在三个问题中分别承担 Route Template 路线池整数重组、Executable分层优化以及 多日排班组合优化等关键求解任务；启发式搜索与候选生成机制负责构造和扩充高质量可行结构，COPT 负责在候选空间上实施整数规划求解与目标冻结，最终结果再由独立校验程序反向复算。完整可运行的COPT 相关程序随支撑材料一并提交，具体文件见下节源码清单。
