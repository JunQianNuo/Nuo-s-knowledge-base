# 面向海上油田人员运输的分层路径与多日排班优化

## 摘要

针对海上油田人员直升机运输中路径、配载、燃油和排班高度耦合的特点，本文构建以总飞机使用时间为严格首要目标的分层优化框架。对问题一，将1600名人员无损聚合为104个OD需求组，以“机场–机型–有界停靠序列–加油方案–整数载客模式”定义完整架次列，建立 Route-and-Load 整数主模型；采用列生成、稳定化定价、局部精确重构和缩放有理对偶证书求解。当前折中方案共 87 架次，总飞机使用时间 14699 min、人员总在途时间124199 person-min、总燃油 118422.2 kg、座位利用率 50.0638%；严格下界为 14104 min，即$1 4 1 0 4 \leq T _ { 1 } ^ { * } \leq 1 4 6 9 9$ C

对问题二，以合法上下机半开区间刻画先下后上与座位即时复用，构建路线–服务区间整数主模型，再以完整Configuration作为精确求解后端。通过物理路线Dantzig–Wolfe松弛、对偶修复与 9 个完整定价子问题得严格下界 15380 min；经精确大邻域重构和限时 Route–Interval邻域优化，得到90架次折中可行方案：总时间16584min、人员总在途时间259171person-min、总燃油 128718.3 kg、座位利用率 95.2417%，故 $1 5 3 8 0 \leq T _ { 2 } ^ { * } \leq 1 6 5 8 4$ 。该时间在显式有限邻域内已证最优，折中切片本身仅为经独立验证的限时incumbent。

对问题三，在上述物理与服务层上加入时间窗、有限异构机队和30min周转，以时间化Configuration与区间团约束建立多日排班模型，并按“必须任务时间优化–临时任务最大满足–次级 Pareto 优化”递进。当前第一层方案以 133 架次完成 3840 名必须运输人员，总时间 23424 min、人员总在途时间 252043 person-min、总燃油 $1 8 4 4 4 8 . 2 \mathrm { k g }$ ，严格下界 15276min，即 $1 5 2 7 6 \leq T _ { 3 , 1 } ^ { * } \leq 2 3 4 2 4$ 。固定该时间预算后，显式有限邻域内最多服务 136 名临时人员，完整问题满足 $1 3 6 \leq S ^ { * } ( 2 3 4 2 4 ) \leq 1 6 0 ;$ ；12 个代表性非支配点中，ND\_005 折中方案为 $P = 2 5 8 0 8 8 { \mathrm { p e r s o n – m i n } }$ $U = 7 2 . 8 1 9 4 \%$ 。所有上界均由原始数据驱动的独立校验程序复核；未闭合的区间仅表述为严格上下界，不作全局最优声明。

关键字：直升机运输；取送路径；列生成；分层多目标；区间排班

## 一、 问题重述

## 1 . 1 问题背景

海上油田由多座油气生产设施及配套平台共同构成，换班、检维修和生产运行均依赖人员在陆地与海上之间及时流动。直升机承担出海、海返和设施间穿梭任务；其座位、航程、燃油和安全余量均受机型限制。因此，在保证人员覆盖和飞行安全的前提下编排架次，是一个具有复杂工程约束的组合优化问题，类似优化已在实际海上油田人员运输中得到应用 [6]。

题目给出三座陆地机场 A01,A02,A03、52 座海上设施 F001–F052 及任意两点间的飞行距离。其中 F006, F011, F018, F024, F031, F038, F044, F050 设有加油站。可选直升机包括T1、T2、T3三种机型，其座位数、速度、单位距离油耗、油箱容量和最低安全余油量不同。

每个架次均由一座机场满油起飞，连续停靠不超过五次海上设施，最终返回同一机场，途中不得在其他机场中转或结束。飞机抵达任一地点时的剩余燃油不得低于该机型安全余油；仅在指定设施可以加满油。普通海上停靠至少需要10min，加油停靠至少需要20min；全部时间均向上取整到整数分钟。人员必须由同一架次完整运送，不能换乘。

## 1.2 问题提出

问题一：单向出海运输。给定1600条由陆地机场（或任意陆地机场LAND）前往海上设施的需求，不考虑时间窗、业务优先级和飞机数量限制。在满足架次、容量、燃油及加油规则的前提下，优先最小化总飞机使用时间，并尽可能改善座位利用率、总油耗、人员总在途时间和总架次数。

问题二：出海、海返与穿梭联合运输。给定4000条人员需求，人员起点和终点均可为机场或海上设施；在不考虑时间窗和优先级的条件下，需处理同一架次中的上下机、穿梭与动态座位变化。

问题三：带时间要求的多日排班。在问题二的基础上增加人员时间窗、业务性质和三座机场共 24 架飞机的限制。飞机只可在 06:00–18:00 起飞并于 20:00 前返场，同一架飞机相邻架次之间至少周转 30 min。需先编排非临时任务，再在不超过其总飞机使用时间的条件下尽可能安排临时任务。

## 二、问题分析

## 2.1 总体分析

将机场和海上设施作为节点、附件给出的有向距离作为边权，可构成有向赋权网络G =(V,E)。一条架次同时包含起降机场、机型、海上停靠序列、加油决策和人员服务决策，且必须回到原机场；因而全局方案不仅要决定访问顺序，还要协调异构座位容量、燃油状态、逐段取整时间和人员分配。本质上，这是多机场、异构机型、带补给资源约束的车辆路径问题扩展 [3, 4]。

本题的难点来自三层耦合。第一，飞行时间按每个航段向上取整，不能用总距离除以速度代替；普通停靠和加油停靠还分别引入10min与20min的时间。第二，燃油可行性具有路径依赖性：飞机从机场满油起飞，每次到达都须保留安全余油，且仅可在指定设施加满油。第三，人员服务与路径相互制约：路线必须经过人员实际起点和终点，座位容量决定同一架次可合并的需求，而问题二中座位还会随着上下机动态变化。

题目明确要求“首先最小化总飞机使用时间”，故该指标具有不可让步的第一优先级。本文先以整数模型求得可行上界并以覆盖完整架次空间的定价或松弛构造安全下界；仅当一级最优值被认证后，才在一级最优域内比较人员在途时间、燃油消耗和座位利用率，避免由任意权重掩盖题设优先级。

## 2.2 问题一分析

问题一的所有人员均在机场上机、在目的设施下机，途中不再上机，故单架次载客量沿路径单调不增，座位约束只需在起飞时检查。无时间窗使同一OD的人员完全可交换，故可将1600 人精确聚合为104个 OD 需求组；聚合后仍能按组内名单无损恢复到具体人员。

由于一个架次最多停靠五座设施，但每个停靠序列还要同时选择机型、加油位置和对多个OD组的载客数量，直接以弧变量展开会产生大量燃油与载重状态变量。本文将完整可行架次作为一列，把固定机场/LAND兼容、逐航段取整、容量、燃油安全余量、加油后满油和返场可达性全部封装在列内；主问题只选择列的次数并精确覆盖需求。该Route-and-Load结构与原问题的可行方案一一对应，且适合列生成避免预枚举全部架次[3, 5]。

## 2.3 问题二分析

问题二允许人员在平台上下机，同一停靠按“先下后上”进行，载客量不再单调变化；一架飞机在不同航段服务的人数可以超过座位数。因此不能沿用问题一的起飞总载客约束，必须显式记录每名人员在路线上的上机位置、上机后首次抵达目的地的位置，以及其占用座位的航段区间。对每条路线的每个航段施加区间重叠容量约束，既可实现座位即时复用，也能保证无换乘运输。

物理飞行层并未改变：同机场往返、至多五次海上着陆、允许重复访问、燃油递推和加油规则仍与问题一完全一致。故问题二应继承问题一已验证的物理层，仅以 Route-and-Interval Service 替换静态装载层，并在精确定价时把“物理路线 + 整数服务模式”合并成Configuration 列。

## 2.4 问题三分析

问题三进一步引入时间窗、有限机队、机场运营时段和同机多架次衔接，属于带时间窗的多趟次取送货调度问题 [10, 11, 12]。可在问题二模型中增加节点到离时刻、具体飞机分配与机场周转约束，并采用“mandatory 时间优化 → 时间预算下 temporary 最大满足 →次级Pareto优化”的三层递进结构。

## 三、 模型假设

1. 附件distances.csv中的有向距离准确代表实际飞行距离，在规划期内不随天气、空域等因素变化。

2. 各机型的速度和单位距离油耗严格按题给参数取值，且不随载客人数改变；停靠期间不额外消耗燃油。

3. 每个架次从机场满油起飞，只能在题设八座加油设施补给；一旦选择加油，油箱立即加满。

4. 问题一和问题二没有时间窗及节点并发限制，主动等待不会改善可行性且会增加目标值，故普通停靠取10min、加油停靠取20min。

5. 题设未禁止同一设施被同一架次重复访问，故模型不额外增加设施唯一访问约束；每次实际抵达均计入海上着陆次数。

## 四、 符号说明

6. 问题三中，除临时任务外的人员均须被运输，且飞机初始停放机场与可用数量严格采用题给配置。

## 五、问题一模型建立与求解

## 5 . 1 数据预处理

按 (origin\_id, destination\_id) 将人员聚合为 OD 组 $g \in G$ ，其需求为 $n _ { g }$ 。由于问题一不含人员层面的时间窗和优先级，组内人员完全同质；求解后只需把该组人数按任意顺序映射回具体person\_id，故聚合不改变任何目标值或可行性。

预先计算每条机型航段的飞行时间和燃油消耗：

$$
t _ {i j} ^ {k} = \left\lceil \frac {6 0 d _ {i j}}{v _ {k}} \right\rceil , \qquad e _ {i j} ^ {k} = c _ {k} d _ {i j}.\tag{1}
$$

若某航段从满油出发仍无法保留安全余油到达，则直接判为不可用。为避免浮点误差，燃油消耗在程序中以0.1 kg的整数倍保存。

## 5 . 2 完整模型：Route-and-Load 整数规划

## 5.2.1 完整架次列与整数主问题

定义一条完整架次列为

$$
c = (a _ {c}, k _ {c}, s _ {c 0}, s _ {c 1}, \ldots , s _ {c m _ {c}}, s _ {c, m _ {c} + 1}, \rho_ {c}, \pmb {a} _ {c}), \quad 1 \leq m _ {c} \leq 5,\tag{2}
$$

其中 $s _ { c 0 } = s _ { c , m _ { c } + 1 } = a _ { c } \in A$ ，中间节点均为设施；ρ 为各停靠点的加油决策， $\rho _ { c }$ $\pmb { a } _ { c } = ( a _ { g c } ) _ { g \in G }$ 为载客向量。列c 必须同时满足：固定机场与LAND 兼容、各目的设施被实际访问、总人数不超过 $Q _ { k _ { c } }$ 、每次到达保留 $S _ { k _ { c } }$ 以上燃油、仅在 R 中加油且加油后满油、至多五次海上着陆，以及至少承运一名人员。

若第h 次停靠后离场燃油为 $B _ { c h }$ ，到达下一节点的燃油为 $D _ { c , h + 1 }$ ，则列内燃油递推为

$$
B _ {c 0} = C _ {k _ {c}},\tag{3}
$$

$$
D _ {c, h + 1} = B _ {c h} - e _ {s _ {c h}, s _ {c, h + 1}} ^ {k _ {c}}, \qquad D _ {c, h + 1} \ge S _ {k _ {c}},\tag{4}
$$

$$
B _ {c h} = \left\{ \begin{array}{l l} C _ {k _ {c}}, & \rho_ {c h} = 1, \\ D _ {c h}, & \rho_ {c h} = 0. \end{array} \right.\tag{5}
$$

其中 $\rho _ { c h } = 1$ 时还必须有 $s _ { c h } \in R$ 。列c 的飞机使用时间为

$$
T _ {c} = \sum_ {h = 0} ^ {m _ {c}} t _ {s _ {c h}, s _ {c, h + 1}} ^ {k _ {c}} + \sum_ {h = 1} ^ {m _ {c}} (1 0 + 1 0 \rho_ {c h}),\tag{6}
$$

燃油消耗为 $\begin{array} { r } { F _ { c } = \sum _ { h = 0 } ^ { m _ { c } } e _ { s _ { c h } , s _ { c , h + 1 } } ^ { k _ { c } } } \end{array}$ 。人员在途时间 $\tau _ { g c }$ 从飞机离开机场起算，到首次抵达 $d _ { g }$ 时止，不计到达终点后的停靠时间。

令 $\lambda _ { c } \in \mathbb { Z } _ { + }$ 表示完整可行列 c 的执行次数。对全部完整列集合 C，问题一第一目标的精确整数规划为

$$
\begin{array}{l l} \min & T (\lambda) = \sum_ {c \in \mathcal {C}} T _ {c} \lambda_ {c} \\ \text {s.t.} & \sum_ {c \in \mathcal {C}} a _ {g c} \lambda_ {c} = n _ {g}, \qquad \forall g \in G, \\ & \lambda_ {c} \in \mathbb {Z} _ {+}, \qquad \forall c \in \mathcal {C}. \end{array}\tag{7}
$$

第一组约束保证每一 OD 组人数恰好得到运输；列定义保证每次被选中的架次均物理可执行。反过来，任一真实可行运输方案均可按其架次的路径、机型、加油和载客向量映射为C 中的列。因此，在不对C 作不安全截断的前提下，式(7) 与原问题一的第一目标等价。

## 5.2.2 完整严格求解的困难

完整列集合C 的规模极大：架次列由机场、机型、至多五次海上停靠的完整walk、逐点加油决策与整数 OD 载客向量共同构成，walk组合随停靠次数快速增长，载客向量又在每个可服务 OD 子集上取整数值，直接显式枚举并精确求解式 (7) 在当前算力下无法完成。因此式 (7) 是判定原问题可行性与最优性的数学基准，实际求解必须在保持题设物理约束不变的前提下，依据求解诊断逐步调整预处理、列表示、候选路线池和下界松弛。每次调整均遵循以下原则：

1. 不改变同机场往返、至多五次海上着陆、燃油安全余量、合法加油、容量和人员唯一运输等原始约束；

2. 用于生成可行方案的有限路线池只改善上界，所有方案必须恢复到 1600 名具体人员并经独立校验器通过；

3. 用于报告全局下界的松弛、割平面和定价必须覆盖完整合法空间，不能将受限主问题的求解器界误作原问题下界。

因此，后续工作是以原MILP为核心的“求解驱动模型强化”，而非根据结果任意修改模型。

## 5.3 近似求解：受限列池列生成与松弛

求解中只维护受限列集 ${ \mathcal { C } } ^ { \prime } \subset { \mathcal { C } }$ ，先求线性松弛；若需求覆盖约束的对偶变量为 $\pi _ { g }$ ，则 候选列的约化成本为

$$
\bar {c} _ {c} = T _ {c} - \sum_ {g \in G} \pi_ {g} a _ {g c}.\tag{8}
$$

按 3 个机场和 3 种机型分解为 9 个定价子问题，搜索“至多五次海上停靠、带燃油和加油资源的可行walk”及其最优载客向量，发现 $\bar { c } _ { c } < 0$ 的列即加入主问题，直至无负约化成本列或达到预设计算时限；必要时以整数主问题求可行解（进一步的上界改进见5.4.1 节）。

上界方向还需缓解“路径–载客绑定”造成的低效：已有列池中常出现“路径本身可行且较短，但原列的 OD 载客组合不合适”的情形，直接在该池上求整数主问题难以通过重新配载继续降低上界。为此，将已验证物理路径与载客决策暂时解耦，构造用于可行方案重组的 flexible-load restricted master。记 $\mathcal { R } ^ { \prime }$ 为去重后的候选物理路径集合， $y _ { r }$ 为路径 r 的执行次数， $x _ { g r }$ 为OD 组g 分配给路径 r 的人数，则求解

$$
\begin{array}{r l r l} {\min} & { \sum_ {r \in \mathcal {R} ^ {\prime}} T _ {r} y _ {r}} \\ {\mathrm{s.t.}} & { \sum_ {r \in \mathcal {R} ^ {\prime}} x _ {g r} = n _ {g},} & & {\forall g \in G,} \\ & { \sum_ {g \in G} x _ {g r} \leq Q _ {k _ {r}} y _ {r},} & & {\forall r \in \mathcal {R} ^ {\prime},} \\ & {x _ {g r} = 0,} & & {\text {若路径} r} \\ & {x _ {g r} \in \mathbb {Z} _ {+}, \quad y _ {r} \in \mathbb {Z} _ {+}.} \end{array}\tag{9}
$$

式(9)中，一条路径被执行 $y _ { r }$ 次即提供 $Q _ { k _ { r } } y _ { r }$ 个起飞座位；其可行整数解可通过OD–路线整数最大流恢复为具体架次分配。该模型只在 $\mathcal { R } ^ { \prime }$ 上优化，消除了无谓的“路径–载客向量”绑定，是构造更好可行上界的有效primal heuristic。

下界方向另建多机场异构passenger-flow弧流松弛。对任意设施集合 $S \subseteq F$ ，设 $D ( S ) =$ $\textstyle \sum _ { j \in S } n _ { j }$ 为该集合的总需求，则任一真实方案均满足rounded-capacity不等式

$$
\sum_ {a \in A} \sum_ {k \in K} \sum_ {i \notin S} \sum_ {j \in S} x _ {i j} ^ {a k} \geq \left\lceil \frac {D (S)}{1 9} \right\rceil .\tag{10}
$$

式 (10) 的左侧为进入 S 的累计架次次数；每次进入至多向 S 运送 19 人。对被违反的子集动态加入该不等式，并将LP对偶有理化、校正残差，得到飞行与基础停靠的安全下界；再利用至少29个架次必须加油的独立证明，补入额外290min加油时间，获得严格整数下界。由此，上界与下界均获得初步的近似界，进一步收紧见下节。

## 5 . 4 . 1 上界压缩

逐架次检查表明，部分已选路线虽然服务对象正确，却不是给定机场、机型和目的设施集合下的最短可行路径。于是对每一已选架次固定起降机场、机型和必须访问的目的设施，重新枚举不超过五个海上停靠，结合动态规划搜索加油决策与返场可达性，执行单架次exactpolishing。该步骤允许在非度量有向距离网络中经过必要的中转设施，不使用未经证明的三角不等式shortcut；其输出仍须满足全部燃油和加油约束。

其次，对最大流重分配暴露出的局部供给不足，使用最小割识别难以共同覆盖的 OD集合，并针对该集合补充二目的可行路径；相应的Hall型容量条件用于筛除明显无法覆盖需求的路径组合。随后在 root 列池、当前 incumbent 路线、精确单目的路线和这些定向生成路线之间进行有限池重组、1-for-1 替换与再次 polishing，每次只接受总飞机使用时间下降且独立校验通过的方案。

进一步的上界压缩采用阈值判定的联合重构：对当前若干架次形成的局部簇，直接加入阈值约束 $T _ { \mathrm { c l u s t e r } } \leq T _ { \mathrm { c l u s t e r } } ^ { \mathrm { o l d } } - 1$ 并求解整数可行性，不再要求先完整最小化再比较。若可行，则所得局部解必然严格改善当前全局 ，随后将其嵌回全部人员方案并运行独立validator。需要强调的是，某个局部簇在该阈值下不可行只证明该邻域内不存在改善，并不提高原问题的全局下界；只有当分离覆盖完整列空间/完整原问题时，阈值不可行才能转化为全局下界。在此机制下，上界轨迹为

## 5.6 基于当前最优结果的次级目标优化

题目要求在完成全部运输任务的前提下，首先最小化总飞机使用时间，并在此基础上兼顾总架次数、人员在途时间、燃油消耗和座位利用率等次级指标。总飞机使用时间具有明确的最高优先级，其余指标之间未给出进一步的严格偏好顺序：若采用简单加权和，需人为设定不同量纲指标的权重；若设置完整字典序，又引入题目未给出的次级偏好。基于多目标规划中的优先级思想和 Pareto 有效性理论，本文采用“一级目标严格优先 + 二级目标 Pareto 优化”的分层结构 [1, 2, 7, 8]。

## 5.6.1 分层结构与一级最优域

设前文Route-and-Load模型的可行域为Ω，一级最优值定义为

$$
T ^ {*} = \min _ {\lambda \in \Omega} T (\lambda), \qquad T (\lambda) = \sum_ {c \in \mathcal {C}} T _ {c} \lambda_ {c}.\tag{14}
$$

在确认 $T ^ { * }$ 为全局最优值后，一级最优解集合为

$$
\Omega^ {*} = \left\{\lambda \in \Omega : \sum_ {c \in \mathcal {C}} T _ {c} \lambda_ {c} = T ^ {*} \right\}.\tag{15}
$$

但由于式 (12) 尚未闭合， $T ^ { * }$ 的认证尚未完成，目前无法在已证明的全局最优域 $\Omega ^ { * }$ 上开展扫描。本文据此以当前独立校验通过的已知最好可行方案的一级目标值 $\bar { T } = 1 4 6 9 9 \mathrm { { m i n } }$ 界定一级域

$$
\hat {\Omega} = \{\lambda \in \Omega : T (\lambda) \leq \bar {T} \},\tag{16}
$$

将后续全部次级优化限制在 $\hat { \Omega }$ 上；若能够证明 $T ^ { * } = \bar { T }$ ，则 $\hat { \Omega }$ 恰为一级最优域、本节结论保持不变。

## 5.6.2 次级目标函数

题目要求报告的总指标中，除作为一级目标的总飞机使用时间外，总架次数 R、人员总在途时间 P、总燃油消耗 F 与座位利用率 U 共四个次级指标。在式 (16) 的一级域 $\hat { \Omega }$ 上定义

$$
R (\lambda) = \sum_ {c \in \mathcal {C}} \lambda_ {c}, \qquad P (\lambda) = \sum_ {c \in \mathcal {C}} \sum_ {g \in G} \tau_ {g c} a _ {g c} \lambda_ {c}, \qquad F (\lambda) = \sum_ {c \in \mathcal {C}} F _ {c} \lambda_ {c},\tag{17}
$$

$$
U (\lambda) = \frac {P K M (\lambda)}{S K M (\lambda)} = \frac {\sum_ {c \in \mathcal {C}} P K M _ {c} \lambda_ {c}}{\sum_ {c \in \mathcal {C}} S K M _ {c} \lambda_ {c}}.\tag{18}
$$

其中R为总架次数；P 为人员总在途时间， $\tau _ { g c }$ 同式(6)后定义； $F _ { c }$ 为列c的燃油消耗；$P K M _ { c }$ 和 $S K M _ { c }$ 分别为列c 的客座公里和可用座公里。由此，二级多目标模型为

$$
\boxed {\min R (\lambda), \quad \min P (\lambda), \quad \min F (\lambda), \quad \max U (\lambda), \qquad \lambda \in \hat {\Omega}.}\tag{19}
$$

## 5 . 6 . 3 ε-约束 Pareto 模型

四个次级指标间存在潜在冲突，通常不存在同时达到各单目标最优值的方案。本文采用 ε-约束法生成非支配方案 [2, 8]：以人员总在途时间 P 为计算主目标，给定架次上限 R¯、燃油上限F¯ 和座位利用率下限U¯，求解

$$
\begin{array}{l l} \underset {\lambda} {\min} & P (\lambda) \\ \text {s.t.} & \lambda \in \hat {\Omega}, \\ & R (\lambda) \leq \bar {R}, \\ & F (\lambda) \leq \bar {F}, \\ & U (\lambda) \geq \bar {U}. \end{array}\tag{20}
$$

式 (20) 中选择 P 作为主目标仅用于构造 ε-约束子问题，并不表示人为规定 $P \succ R \succ$ $F \succ U$ 。由于 $S K M ( \lambda ) > 0$ ，座位利用率约束可等价改写为 $P K M ( \lambda ) - \bar { U } S K M ( \lambda ) \ge 0 ;$ 若 $\bar { U } = p / q$ 为既约分数，进一步得整数形式 $q P K M ( \lambda ) - p S K M ( \lambda ) \geq 0$ ，从而使每个ε-约束子问题保持线性整数优化结构。ε-约束与列生成结合求解多目标车辆路径问题已有成熟研究基础[8]。

## 5 . 6 . 4 Pareto 解集与最终方案确定

首先在 $\hat { \Omega }$ 与受限列池的交集上求取四个极端方案（受限列池的构建见下文）

$$
R ^ {\min} = \min _ {\lambda \in \hat {\Omega}} R (\lambda), \qquad P ^ {\min} = \min _ {\lambda \in \hat {\Omega}} P (\lambda), \qquad F ^ {\min} = \min _ {\lambda \in \hat {\Omega}} F (\lambda), \qquad U ^ {\max} = \max _ {\lambda \in \hat {\Omega}} U (\lambda),\tag{21}
$$

并将各极端方案对应的 $( R , P , F , U )$ 汇总为 payoff table。对于分式目标 $U ^ { \mathrm { m a x } }$ ，采用Dinkelbach参数化方法[9]，将其转化为一系列 $\mathrm { m a x } _ { \lambda \in \hat { \Omega } } \{ P K M ( \lambda ) - \theta S K M ( \lambda ) \}$ 的整数优化问题。生成候选解时，为避免同一ε切片返回弱非支配解，在达到最优 $P ^ { * }$ 后仅在该切片内部依次以R、F、U 并列优化；该步骤只是消除并列，不代表全局字典序偏好。

最终需从非支配解集中选取提交方案。当前等时间邻域内 $R = 8 7$ 恒定，故对其余三个次级指标定义标准化偏差 $z _ { P } , z _ { F } , z _ { U }$ ，采用最小最大偏差准则

$$

$$

其中P 为代表性Pareto非支配解集；若存在并列，则比较三项标准化偏差之和，再以总架次数和编号稳定破除并列。

## 6.2 合法上机–下机区间与动态容量

对OD组g 在路线r上的一次服务，记其实际登机和下机位置为 $( u , v )$ 。若 $o _ { g } = \mathrm { L A N D }$ 则 $u = 0 ;$ ；若 $o _ { g }$ 为指定机场，则须有 $a _ { r } = o _ { g }$ 且 $u = 0$ ；若 $o _ { g }$ 为海上设施，则必须存在$1 \leq u \leq m _ { r }$ 使 $s _ { r u } = o _ { g }$ 。相应地，若 $d _ { g } = \mathrm { L A N D }$ ，则 $v = m _ { r } + 1$ ；若 $d _ { g }$ 为指定机场，则须有 $a _ { r } = d _ { g }$ 且 $v = m _ { r } + 1$ ；若 $d _ { g }$ 为海上设施，则

$$
v = \min \{h > u: s _ {r h} = d _ {g} \}.\tag{24}

$$
\mathcal {I} _ {g r} = \{(u, v): u <   v, (u, v) \text {满足上述起点、终点与首次到达规则} \}.\tag{25}
$$

## 6 . 3 Route-and-Interval Service 整数主模型

$x _ { r } \in \mathbb { Z } _ { + }$ 表示物理路线 $r \in \mathcal { R } _ { 2 }$ 的执行次数；令 $y _ { g r I } \in \mathbb { Z } _ { + }$ 表示采用路线 r、服务区间 $I \in \mathcal { T } _ { g r }$ 运输OD 组g 的人数。问题二首要目标为

$$
\min T _ {2} = \sum_ {r \in \mathcal {R} _ {2}} T _ {r} x _ {r}.\tag{26}
$$

每一OD 组必须恰好完成全部需求：

$$
\sum_ {r \in \mathcal {R} _ {2}} \sum_ {I \in \mathcal {I} _ {g r}} y _ {g r I} = N _ {g}, \quad \forall g \in G _ {2}.\tag{27}
$$

对路线r 的每个航段 $\ell = 0 , \ldots , m _ { r }$ ，逐段容量为

$$
\sum_{g\in G_{2}}\sum_{\substack{I = (u,v)\in \mathcal{I}_{gr}\\ u\leq \ell <  v}}y_{grI}\leq Q_{k_{r}}x_{r}.\tag{28}
$$

综上，Route-and-Interval Service 模型为

$$
\begin{array}{ll}\min_{x,y} & \sum_{r\in \mathcal{R}_{2}}T_{r}x_{r}\\ \text{s.t.} & \sum_{r\in \mathcal{R}_{2}}\sum_{I\in \mathcal{I}_{gr}}y_{grI} = N_{g},\qquad \forall g\in G_{2},\\ & \sum_{g\in G_{2}}\sum_{\substack{I = (u,v)\in \mathcal{I}_{gr}\\ u\leq \ell <  v}}y_{grI}\leq Q_{k_{r}}x_{r}, \forall r\in \mathcal{R}_{2}, \ell = 0,\ldots ,m_{r},\\ & x_{r}\in \mathbb{Z}_{+},\quad y_{grI}\in \mathbb{Z}_{+}. \end{array}\tag{29}
$$

式 (28) 只限制同一航段内重叠的服务区间数，因而允许累计服务人数超过座位数。固定路线后，这些半开服务区间构成区间图；只要每条航段的重叠人数不超过总座位数，就可通过区间染色将服务分配到座位轨道，再按每架 $Q _ { k _ { r } }$ 个轨道恢复为真实架次。因此，式 (29)在整数解层面与原问题二等价；但对含重复访问的路线，其连续松弛不必天然整数，不能直接把连续服务解作为人员方案。

## 6 . 4 完整 Configuration 后端与分层评价

Route-and-Interval Service 适合表达业务规则和构造受限路线池。为完成精确定价、约化成本枚举和Branch-and-Price，将“一次真实物理架次+一次整数服务模式”整体定义为完整配置列

$$
c = \left(r (c), \{q _ {g I} ^ {c} \}\right), \qquad c \in \mathcal {C} _ {2},\tag{30}
$$

其中 $q _ { g I } ^ { c }$ 表示列c 中采用区间I 运输的组 $g$ 人数。列内必须满足

$$
\sum_{g\in G_{2}}\sum_{\substack{I = (u,v)\in \mathcal{I}_{g,r(c)}\\ u\leq \ell <  v}}q_{gI}^{c}\leq Q_{k_{c}},\qquad \ell = 0,\ldots ,m_{c},\tag{31}
$$

并至少承运一人。令 $\begin{array} { r } { a _ { g c } = \sum _ { I \in \mathcal { T } _ { g , r ( c ) } } q _ { g I } ^ { c } } \end{array}$ ，以 $\lambda _ { c } \in \mathbb { Z } _ { + }$ 表示列的执行次数，则等价的配置主问题为

$$
\begin{array}{l l} \min _ {\lambda} & \sum_ {c \in \mathcal {C} _ {2}} T _ {c} \lambda_ {c} \\ \text {s.t.} & \sum_ {c \in \mathcal {C} _ {2}} a _ {g c} \lambda_ {c} = N _ {g}, \qquad \forall g \in G _ {2}, \\ & \lambda_ {c} \in \mathbb {Z} _ {+}, \qquad \forall c \in \mathcal {C} _ {2}. \end{array}\tag{32}
$$

二者描述同一整数原问题：前者保留服务区间变量，后者将一次架次的服务模式封装成一列；实现中采用“Route-and-Interval 主骨架 + Configuration 精确后端”。

对区间 $\boldsymbol { I } = \left( u , v \right)$ ，人员在途时间、客座公里分别为

$$
\tau_ {g r I} = \sum_ {\ell = u} ^ {v - 1} t _ {s _ {r \ell}, s _ {r, \ell + 1}} ^ {k _ {r}} + \sum_ {\ell = u + 1} ^ {v - 1} \delta_ {r \ell},\tag{33}
$$

$$
\mathrm{PKM} _ {g r I} = \sum_ {\ell = u} ^ {v - 1} d _ {s _ {r \ell}, s _ {r, \ell + 1}}.\tag{34}
$$

由此可计算人员总在途时间 $P _ { 2 }$ 、总燃油 $F _ { 2 }$ 、客座公里 $P K M _ { 2 }$ 、可用座公里 $S K M _ { 2 }$ 和座位利用率 $U _ { 2 } = { P K M _ { 2 } } / { S K M _ { 2 } }$ ；总架次数为 $\begin{array} { r } { N _ { 2 } ^ { \mathrm { f l t } } = \sum _ { r } x _ { r } . } \end{array}$ 。在首要目标 $T _ { 2 } ^ { * }$ 得到全局认证后，才在

$$
\Omega_ {2} ^ {*} = \left\{\lambda : \sum_ {c \in \mathcal {C} _ {2}} T _ {c} \lambda_ {c} = T _ {2} ^ {*} \right\}\tag{35}
$$

内求解 min $P _ { 2 }$ , min $F _ { 2 }$ , max $U _ { 2 }$ 的 Pareto 优化。与问题一相同，可用 ε-约束法在给定 ${ \overline { { F } } } _ { 2 } , { \overline { { U } } } _ { 2 }$ 时最小化 $P _ { 2 }$ ；当 $\overline { { U } } _ { 2 } = \alpha / \beta$ 时，利用率约束可线性化为 $\beta P K M _ { 2 } - \alpha S K M _ { 2 } \geq 0$

## 6.5 求解、方案恢复与独立校验

受限主问题初始路线池可复用问题一的物理路线作为 seed，但绝不能将问题二搜索空间限制为问题一路线池。定价阶段可复用问题一的物理转移、燃油状态、返场可达性与安全删弧；人员服务 oracle 则必须重新处理 pickup-before-delivery、上机后 first-delivery、重复设施访问、逐段座位占用及整数服务奖励。启发式DFS、beam或meet-in-the-middle仅用于快速发现候选路线；若需声明下界或最优性，最终必须以覆盖完整合法空间的精确定价MILP 或等价算法闭合。

配置主问题LP中，若OD需求等式的对偶变量为 $\pi _ { g }$ ，且不存在其他活动cut/branch行，配置列c 的约化成本为

$$
\bar {c} _ {c} = T _ {c} - \sum_ {g \in G _ {2}} \pi_ {g} a _ {g c}.\tag{36}
$$

只有完整合法列空间不存在负约化成本列时，当前 值才是安全下界。设独立校验通过的整数方案为 UB、安全下界为 $L B$ ；总飞机使用时间为整数分钟，若 $\lceil L B \rceil = U B$ ，即可认证 $T _ { 2 } ^ { * } = U B$ 。若尚未闭合，则依次进行约化成本枚举、有限候选池的精确整数主问题和Branch-and-Price(-and-Cut)，不得将受限路线池的 LP 值误作全局下界。

最终输出 q2-routes.csv 和 q2-assignments.csv。恢复时，将 $y _ { g r I }$ 展开为乘客区间副本，按区间图染色分配至座位轨道，并把轨道分为每架 $Q _ { k _ { r } }$ 个座位的一组，再从 OD 组名单逐一写入具体person\_id。独立校验器必须重新读取原始数据，逐项核验4000名人员的唯一覆盖、起终点与 LAND 兼容、无换乘、pickup\_stop\_order<delivery\_stop\_order、first-delivery、路线闭合、海上着陆与重复访问计数、燃油加油规则、逐段容量及全部评价指标的一致性。

## 6.6 严格下界的构造

完整 Configuration 的服务模式数量巨大，故先构造 Physical-Route Dantzig–Wolfe 松弛：保留所有物理合法路线、燃油与逐段容量，但放松一次架次内整数服务模式的耦合。任一原问题可行解都可投影至该松弛，因而其最优值不超过 $T _ { 2 } ^ { * }$

计算中保留 7873 条已验证物理路线，对两组 RMP 对偶进行 157 维 route-only dual repair，并对 3 个机场与 3 种机型的 9 个组合重新执行无截断物理路线定价。最小遗漏路线约化成本为 $1 . 0 \times 1 0 ^ { - 5 } > 0$ ，经对偶残差的保守修正后得到

$$
L B _ {2, \mathrm{cont}} = 1 5 3 7 9. 0 8 6 5 5 0 8 \mathrm{min}.\tag{37}
$$

由于原问题总时间必为整数分钟，得严格整数下界

$$
\boxed {L B _ {2} = \lceil L B _ {2, \text {cont}} \rceil = 1 5 3 8 0 \min.}\tag{38}
$$

此下界来自完整物理路线空间的合法松弛，与用于寻找可行解的有限邻域相互独立。

## 6.7 可行上界的逐步压缩

上界搜索在 Route-and-Interval 表达上进行精确大邻域重优化：每次选取 2–5 个乘客和设施相关架次，固定外部方案，对局部路线执行次数与人员服务区间求解整数规划。只有局部 primal 与 dual bound 一致、嵌回全局后总时间严格下降，且两套独立 validator均通过时，才更新 incumbent。

从已归档的 16683 min 方案出发，多轮 2/3-架次精确邻域将上界降至 16629 min。对16629与后续端点间发生变化的19个架次，按乘客关联分解为5个互不耦合的replacementcomponents，分别精确求解后累计节省 39 min，先得到 16590 min。随后固定 90 个航班槽的机场、机型和停靠设施多重集，完整枚举停靠排列与合法加油掩码，并允许4000名人员在所有候选路线间按服务区间重新分配。该有限Route–Interval邻域内求解严格字典序目标

$$
\min \left(T _ {2} + \frac {P _ {2}}{P _ {2} ^ {\max} + 1}\right),\tag{39}
$$

其中 $P _ { \mathrm { 2 } } ^ { \mathrm { m a x } }$ 为邻域内人员时间有效上界。因 $T _ { 2 }$ , $P _ { 2 }$ 均为整数且分式项严格小于1，式(39)等价于先最小化 $T _ { 2 }$ 、再最小化 $P _ { 2 }$ 。模型在 21.68 s 内达到 MILP 最优并由独立 validator 复核，最终得到

$$
\boxed {U B _ {2} = 1 6 5 8 4 \min.}\tag{40}
$$

该解是原问题的合法可行解，故可严格更新全局上界；其最优性证书只覆盖上述 397 个路线变体的有限邻域，不用于提高全局下界。

## 7.3 分层多目标优化模型

## 7.3.1 第一层：mandatory 飞机时间优化模型

Q3.1 中 temporary 完全不参与，所有 mandatory 需求必须恰好覆盖。令 $\lambda _ { c } \in \mathbb { Z } _ { + }$ 为配置执行次数，则第一层首要目标为

$$
\boxed {T _ {1} ^ {*} = \min _ {\lambda} \sum_ {c \in \mathcal {C}} T _ {c} \lambda_ {c}}\tag{60}
$$

$$
\begin{array}{l l} \text {s.t.} & \sum_ {c \in \mathcal {C}} a _ {g c} \lambda_ {c} = n _ {g}, \forall g \in G ^ {M}, \\ & \text {式 (59)}, \end{array}\tag{61}
$$

$$
\lambda_ {c} \in \mathbb {Z} _ {+}, \quad \forall c \in \mathcal {C}.
$$

该模型与题目“先不考虑临时任务编排计划并得到总飞机使用时间”的第一阶段完全对应，temporary不应以惩罚项、零收益列或其他形式进入Q3.1。

## 7.3.2 第二层：时间预算下 temporary最大满足模型

记第一阶段得到的飞机使用时间基准为 $\hat { T } _ { 0 }$ ：若第一阶段已精确闭合则 $\hat { T } _ { 0 } = T _ { 1 } ^ { * }$ ，否则$\bar { T } _ { 0 }$ 为当前第一阶段可行方案的时间。第二阶段可重新安排整个运输计划，只要求mandatory全部满足、所有物理与时间规则继续成立，且

$$
\sum_ {c \in \mathcal {C}} T _ {c} \lambda_ {c} \leq \bar {T} _ {0}.\tag{62}
$$

对每个 temporary 需求组 $g \in G ^ { T }$ 定义实际服务人数

$$
s _ {g} \in \mathbb {Z} _ {+}, \qquad 0 \leq s _ {g} \leq n _ {g},\tag{63}
$$

mandatory 仍完整覆盖，temporary 的服务量满足 $\textstyle \sum _ { c \in { \mathcal { C } } } a _ { g c } \lambda _ { c } = s _ { g }$ 。定义 temporary 总满足人数

$$
S (\lambda) = \sum_ {g \in G ^ {T}} s _ {g},\tag{64}
$$

则第二层第一优先目标为

$$
\boxed {S ^ {*} (\bar {T} _ {0}) = \max _ {\lambda , s} S (\lambda)}\tag{65}
$$

subject to 式 (59)、(62) 及上述覆盖约束。由于数据中 temporary 总人数为 160，显然 $S ^ { * } ( \bar { T } _ { 0 } ) \leq$ 160；一旦在当前预算下构造出 160/160 的合法方案，即可立即证明 $S ^ { * } ( \bar { T } _ { 0 } ) = 1 6 0$ ，无需再为该目标做精确定价。

## 7.3.3 第三层：次级 Pareto 多目标优化

设在最终时间预算 $\hat { T } _ { 0 }$ 下已求得 temporary 最优满足数 $S ^ { * } = S ^ { * } ( \bar { T } _ { 0 } )$ ，定义 primary-optimal 可行域

$$
\Omega_ {S ^ {*}} = \left\{(\lambda , s): \text {满足式} (5 9) 、 (6 2) \text {与覆盖约束}, S (\lambda) = S ^ {*} \right\}.\tag{66}
$$

题目只要求“尽可能多地优化其他因素”，未规定人员在途时间、燃油、架次数与座位利用率之间的绝对优先级，故不人为声明完整字典序，而在 $\Omega _ { S }$ 上研究

$$
\boxed {\min P (\lambda), \qquad \min F (\lambda), \qquad \min R (\lambda), \qquad \max U (\lambda)}\tag{67}
$$

的 Pareto 非支配解，其中 $\begin{array} { r } { P ( \lambda ) = \sum _ { c } P _ { c } \lambda _ { c } , F ( \lambda ) = \sum _ { c } F _ { c } \lambda _ { c } , R ( \lambda ) = \sum _ { c } \lambda _ { c } , U ( \lambda ) = } \end{array}$ $P K M ( \lambda ) / S K M ( \lambda )$ 沿用式(18)。总飞机使用时间继续满足硬预算 $T ( \lambda ) \leq \bar { T } _ { 0 }$

$$
\begin{array}{l l} \underset {\lambda , s} {\min} & P (\lambda) \\ \text {s.t.} & (\lambda , s) \in \Omega_ {S ^ {*}}, \\ & F (\lambda) \leq \bar {F}, \quad R (\lambda) \leq \bar {R}, \quad U (\lambda) \geq \bar {U}. \end{array}\tag{68}
$$

当阈值 $\bar { U } \ = \ p / q$ 为正有理数时，利用率约束可等价改写为线性整数约束 $q P K M ( \lambda ) -$ $p S K M ( \lambda ) \ge 0 $ ；若直接求 $U _ { \mathrm { m a x } }$ ，可采用 Dinkelbach 参数化迭代 [9]。

## 7.4 求解与结果分析

## 7.4.1 总体求解框架

问题三同时包含多日时间窗、异构有限机队、多架次排班、30 min 周转、取送先后与逐航段容量，若一次展开为分钟级时空MILP，将产生大量飞机编号对称与无效弧。实际计算分为三条相互独立的线路：

1. 对完整可行排班进行 Route/Service/Schedule 破坏与重构，不断压低整数上界；

2. 从原问题可行方案的合法连续投影出发，加入容量割得到可独立重建的全局下界；

3. 保留时间化 Configuration 的完整列生成与精确定价，作为后续闭合整数 GAP 的严格路线。

受限列池、有限邻域和未完成精确定价的RMP 值均不用作全局下界。

## 7.4.3 独立严格下界

为避免下界依赖上界搜索的候选池，建立稀疏 Origin-Commodity / Aircraft-Flow 连续松弛。对基地 $a \mathbf { \hat { \theta } } _ { \mathbf { \tilde { \theta } } }$ 、机型k 与有向弧(i,j)保留飞机流 $x _ { a k i j }$ ，对人员起点类别保留commodity流$y _ { o i j }$ ，并以

$$
\sum_ {o} y _ {o i j} \leq \sum_ {a, k} Q _ {k} x _ {a k i j}\tag{71}
$$

联结人员与飞机容量。目标按弧计入向上取整的飞行时间，每次海上到达计入10min普通停靠，并以连续加油计数补入额外10min。任一真实排班均可投影为此模型的可行解。

对任意海上设施子集 S，设边界外起点、 $S$ 内终点的 mandatory 人数为 $D ^ { i n } ( S )$ ，由单航段最多携带 19 人得 rounded-capacity entry cut

$$
\sum_ {a, k} \sum_ {i \notin S, j \in S} x _ {a k i j} \geq \left\lceil \frac {D ^ {i n} (S)}{1 9} \right\rceil ,\tag{72}

## 8.2 燃油参数的结构敏感性

题设将单位距离油耗视为常数，实际运行中它会受风场、载重和飞行状态影响。为判断方案对这一误差的局部脆弱性，保持路线、机型和加油位置不变，将各机型单位距离油耗同比扩大为题设值的 $\beta$ 倍。对架次 c 中从满油起点或加油点到任一后续到达点 h 的累计基准油耗 $E _ { c h }$ ，不变路线仍安全的充要条件为

$$
C _ {k _ {c}} - \beta E _ {c h} \geq S _ {k _ {c}}, \quad \forall h,\tag{79}
$$

因而该架次可承受的最大油耗倍数为

$$
\beta_ {c} ^ {\mathrm{max}} = \min _ {h} \frac {C _ {k _ {c}} - S _ {k _ {c}}}{E _ {c h}}.\tag{80}
$$

## 8.3 模型优点与局限

模型的主要优点有四点。第一，以完整架次封装路径、燃油、加油和人员服务，可在不依赖三角不等式、不禁止重复访问的前提下严格对应题设。第二，问题二用半开服务区间统一表达先下后上、first-delivery和座位即时复用，问题三用区间团约束消除具体飞机编号对称，两者都可无损恢复为个体方案。第三，将启发式上界搜索与严格下界证书分离，使求解质量可量化。第四，第一优先级与 Pareto 次级优化分层处理，避免了任意权重对总飞机时间的补偿。

模型的限制也很明确。题设速度和油耗被视为常数，尚未显式考虑天气、备降、机组值勤、停机坪并发与维修可用率；若用于真实运营，应将这些因素作为情景或鲁棒约束纳入。计算上，Q1 与 Q2 仍存在 4.05% 和 7.26% 的整数 GAP，Q3.1 仍存在 34.78% 的整数 GAP；Q3的临时任务与Pareto结论也必须限定在已声明的当前时间预算、配置邻域与列池内。因此，本文仅报告经校验的可行方案及其上下界，不宣称获得全局最优解。

def dominates(a: dict, b: dict) -> bool:
    """Exact dominance for (T, P, F min, U max), using integer cross-products."""
    t_ok = int(a.get("T", 0)) <= int(b.get("T", 0))
    p_ok = int(a["P"]) <= int(b["P"])
    f_ok = int(a["F10"]) <= int(b["F10"])
    u_left = int(a["PKM"]) * int(b["SKM"])
    u_right = int(b["PKM"]) * int(a["SKM"])
    u_ok = u_left >= u_right
    strict = (
    int(a.get("T", 0)) < int(b.get("T", 0))
    or int(a["P"]) < int(b["P"])
    or int(a["F10"]) < int(b["F10"])
    or u_left > u_right
)
return t_ok and p_ok and f_ok and u_ok and strict

def nondominated(points: Iterable[SolvedPoint]) -> list[SolvedPoint]:
    unique: dict[tuple[int, int, int, int], SolvedPoint] = {}
    for point in points:
    m = point.metrics
    key = (int(m["P"]), int(m["F10"]), int(m["PKM"]), int(m["SKM"]))
    unique.setdefault(key, point)
    values = list(unique.values())
    keep: list[SolvedPoint] = []
    for i, point in enumerate(values):
    if not any(i != j and dominates(other.metrics, point.metrics) for j, other in enumerate(values)):

def seed_tasks(schedule: pd.DataFrame, initial_per_fuel: int) -> list[tuple[int, int]]):
    tasks: list[tuple[int, int]] = []
    for fuel10, frame in schedule.groupby("fuel10", sort=True):
    thresholds = sorted(set(int(x) for x in frame["pkm_lower"]))
    if not thresholds:
    continue
    count = min(max(1, initial_per_fuel), len(thresholds))
    indexes = sorted(set(int(round(i)) for i in np.linspace(0, len(thresholds) - 1, count)))
    tasks.extend((int(fuel10), thresholds[i]) for i in indexes)
    return tasks

def adaptive_tasks(
    solved: dict[int, set[int]],
    schedule: pd.DataFrame,
    blocked: set[tuple[int, int]],
) -> tuple[int, int] | None:
    """Choose the midpoint of the largest unresolved threshold interval.

Intervals are normalized by their fuel-class range, preventing one fuel class from consuming the entire wall-clock budget.
"""
best: tuple[float, int, int] | None = None
for fuel10, frame in schedule.groupby("fuel10", sort=True):
    all_thresholds = sorted(set(int(x) for x in frame["pkm_lower"])
    seen = sorted(solved.get(int(fuel10), set()))
    if len(seen) < 1:
    continue
    endpoints = sorted(set([all_thresholds[0], all_thresholds[-1], *seen]))
    scale = max(1, all_thresholds[-1] - all_thresholds[0])
    for left, right in zip(endpoints, endpoints[1 Multi]):
    if right - left < 2:
    continue
    midpoint = (left + right) // 2
    candidate = (int(fuel10), int(midpoint))
    if candidate in blocked or midpoint in seen:
    continue
    score = (right - left) / scale
    if best is None or score > best[0]:
    best = (score, int(fuel10), int(midpoint))
    return None if best is None else (best[1], best[2])

@staticmethod
def one_row(vector: np.ndarray, lower=-np.inf, upper=np.inf) -> LinearConstraint:
    return LinearConstraint(vector.reshape(1, -1), [lower], [upper])

@staticmethod
def _constraint_satisfied(constraint: LinearConstraint, x: np.ndarray) -> bool:
    values = np.asarray(constraint.A @ x).reshape(-1)
    lower = np.broadcast_to(np.asarray(constraint.lb, dtype=float), values.shape)
    upper = np.broadcast_to(np.asarray(constraint.ub, dtype=float), values.shape)
    return bool(np.all(values >= lower - 1e-6) and np.all(values <= upper + 1e-6))

def verify_vector(self, x: np.ndarray, extras=None) -> None:
    if np.any(x < np.asarray(self.bounds.lb) - 1e-6) or np.any(x > np.asarray(self.bounds.ub) + 1e-6):
    raise AssertionError("solution violates variable bounds")
    for constraint in [self.base_constraint] + list(extras or []):
    if not self._constraint_satisfied(constraint, x):
    raise AssertionError("rounded solution violates a model constraint")

def solve(self, objective: np.ndarray, extras=None, time_limit=30.0, presolve=False):
    constraints = [self.base_constraint] + list(extras or [])
    result = milp(
    objective,
    integrality=self.integrity,
    bounds=self.bounds,
    constraints=constraints,
    options={"time_limit": float(time_limit), "mip_rel_gap": 0.0, "presolve": bool(presolve)},
    )
    if result.x is None:
    raise RuntimeError(result.message)
    x = nprint(result.x).astype(int)
    if np.max(np.abs(np.asarray(result.x) - x)) > 1e-5:
    raise AssertionError("solver incumbent is not integral")
    self.verify_vector(x, extras)
    return x, result

def local_branching_row(self, max_changed_routes: int | None) -> LinearConstraint | None:
    if max_changed_routes is None:
