# Cooperative multiple task assignment problem with stochastic velocities and time windows for heterogeneous unmanned aerial vehicles using a genetic algorithm

Keywords: Stochastic programming Task assignment problem Heterogeneous unmanned aerial vehicles Genetic algorithm Path coordination

## a b s t r a c t

In this paper, a combinatorial optimization problem, formulated as a cooperative multiple task assignment problem with stochastic velocities and time windows for heterogeneous unmanned aerial vehicles, is studied in the form of a two-stage stochastic programming model. To create a more realistic mission scenario, we involve several types of constraints in this problem, such as kinematic constraints, resource constraints (both boarded weapons and fuels), and time constraints (both task sequences and time windows). Due to the prohibitive computational complexity of the problem, a novel meta-heuristic based on a modified genetic algorithm is proposed to improve the solution of this stochastic task assignment problem. After a feasible solution is obtained, a set of actual flight paths will be created by a path coordination process according to the requirements of the task precedence. In the simulation part, the effect of the proposed algorithm, both on searching capability and convergence speed, is demonstrated by comparison with the random search algorithm. Moreover, the stochastic nature of this problem caused by the stochastic flight velocities is also illustrated by comparison with a deterministic model. Additionally, actual flight trajectories meeting all time constraints are displayed for this stochastic task assignment problem.

## 1. Introduction

A task assignment problem is a combinatorial optimization problem that minimizes a predefined objective function by allocating one agent (or several agents) to multiple tasks, such as the traveling salesman problem (TSP) [1], generalized assignment problem (GAP) [2], and vehicle routing problem (VRP) [3]. In recent decades, the cooperative task assignment problem for unmanned aerial vehicles (UAVs) has been an emerging issue with application to sophisticated military missions, such as Wide Area Search Munitions (WASM) [4,5], Suppression of Enemy Air Defense (SEAD) [6,7] and combat Intelligence, Surveillance, and Reconnaissance (ISR) [8]. Among these military applications, the cooperative multiple task assignment problem (CMTAP) [9] has been studied as a typical situation in which multiple unmanned vehicles perform multiple consecutive tasks, such as classification, attack, and verification on stationary targets known a priori.

Compared with the TSP and VRP, CMTAP for UAVs involves two main characteristics: the cooperation and kinematics of UAVs.

CMTAP is concerned with the selection of conflict-free matchings of tasks to vehicles. In other words, a higher-level component of a mission planner provides a list of tasks to the task assignment component, deciding which of the available UAVs should perform each task based on information about the tasks and the capabilities of the UAVs. In this paper, by means of introducing heterogeneous UAVs with special capabilities and resource limitations, the characteristics of cooperation are considered in this stochastic task assignment problem. Additionally, the constraint of the kinematics of UAVs must be taken into account in the process of path generation. Thus, the Dubins Car model is adopted to generate a set of elementary flight paths for UAVs. Furthermore, due to the constraint of the task sequence described below, we propose two extra maneuvering flights to coordinate the flight paths of UAVs and to finally create the actual flight paths for each UAV.

In the scenarios of some special military missions, time constraints such as time windows and task sequences are always involved in the task assignment problem. In this paper, we assume that the time windows are soft constraints which mean that the assignment is penalized if the task performance time exceeds the predefined time intervals. In contrast, a solution of the task assignment is infeasible if the task precedence constraints are broken on any target. Moreover, an unacceptable phenomenon called deadlock may also be involved in the task allocation due to the task precedence constraints. Thus, an approach based on graph theory [10] is adopted to solve this problem.

The aforementioned constraints of the task assignment problem are comprehensive, but the common disadvantage is that all problem elements are deterministic. In real-life applications, the quality of task execution may become quite poor if uncertainties are disregarded. In [11,12], the authors discussed a chance constrained path planning problem. For robust execution, uncertain factors, such as uncertain localization, modeling errors and disturbances, are considered. Different from the studies mentioned above, this paper takes into account the stochastic elements in the process of task assignment at the mission level. The described problem extends the classical task assignment problem by introducing negative stochastic flight velocities based on a known probability distribution for each UAV in each flight segment, leading to a stochastic task performance time. Thus, a two-stage stochastic programming model is adopted to solve this stochastic task assignment problem in a more reliable and effective manner.

From a mathematical perspective, the task assignment problem is one of the fundamental combinatorial optimization problems in the branch of operations research. Hence, the cooperative multiple task assignment problem with stochastic velocities and time windows (CMTAPSVTW) proposed in this paper belongs to the class of NP-hard (non-deterministic polynomial hard) [13] combinatorial optimization problems as well. Complexity is one of the main challenges of CMTAP involving the size of the problem and the types of constraints. Because the deterministic search methods are not suitable for dealing with problems with prohibitive computational complexity, it is practical and reasonable to design heuristic and meta-heuristic algorithms to obtain a good feasible solution in an expected runtime. In this paper, a novel meta-heuristics modified genetic algorithm (GA) is proposed to obtain a more eficient solution in a reasonable number of generations.

The main contribution of this paper is the incorporation of these constraints together with the uncertainties to create a more realistic mission scenario and the proposal of a novel modified GA combined with a path elongation algorithm to make the results more convincing and practical. The remainder of this paper is organized as follows. Section 2 provides a literature review on both the classical task assignment problem and the stochastic task assignment problem. In section 3, a theoretical model of CMTAPSVTW is established and cast within the framework of a two-stage stochastic programming model. In section 4, a novel GA with modified encoding and genetic operators is described; additionally, a type of infeasible state called deadlock is introduced and solved in this section. In section 5, a set of elementary flight paths for each UAV are generated according to the Dubins Car model, and two types of extra maneuvering flights are introduced to coordinate the flight paths and create the actual flight paths for each UAV. In section 6, numerical simulations are carried out to demonstrate the superiority of our algorithm and to evaluate the performance of the two-stage stochastic programming model for this stochastic task assignment problem. Sample trajectories of selected UAVs are also shown in this section. Various major conclusions are drawn in section 7.

## 2. Literature review

## 2.1. Classical task assignment problem

Generally, classical task assignment problem solutions can be classified into the following two categories according to the search algorithms:

• Deterministic algorithms: methods that attempt to obtain the optimal solution for a given objective.

• Heuristic algorithms: methods that aim to provide an effective means of obtaining sub-optimal solutions.

The deterministic algorithms including the family of branch and X algorithms (such as the branch and bound algorithm, branch and cut algorithm, and branch and price algorithm), linear programming and dynamic programming, have been introduced in many published papers. As far as we know, a mixed integer linear programming (MILP) formulation for UAV task assignment problem was first presented in [14]. Three tasks were required to be completed for each target in the MILP model. Due to the complexity of the resulting MILP, only small-sized problems could be solved quickly. Therefore, the authors proposed another work [5] in which classification and attack were grouped into a single task allowing real-time solutions to be obtained for problems of practical size. However, there existed the following limitations: 1) the vehicles in the mission were homogeneous; and 2) the existence of a solution was guaranteed only when the air vehicles had suficient endurance. Although both previous literatures referred to the continuous time variable, [8] presented a task assignment problem in a combat ISR mission by modifying the vehicle routing problem with time windows (VRPTW) to further discuss the time constraints. The common disadvantages in the MILP formulation are that the kinematics of UAVs are not considered and that computational complexity cannot be avoided as the dimension of the problem increases. In recent studies, a search tree model combined with a branch and bound search algorithm was developed [15,16]. In the proposed branch and bound search algorithm, an upper bound on the cost of the cooperative assignment was initialized by a candidate optimal solution obtained from the BFS algorithm. In contrast, a lower bound on the cost of the same target being serviced by a different UAV was obtained using Euclidean distances. The optimal solution to the assignment problem was found by applying these upper and lower bounding procedures iteratively. The search was terminated when all nodes had either been evaluated or pruned. [17] proposed a dynamic programming framework to solve the UAV task assignment problem and introduced two approximation algorithms that significantly reduced the computational complexity for larger problems.

Regarding the second category, heuristics and meta-heuristics approaches, such as Tabu Search (TS) [18], Simulated Annealing (SA) [19], Particle Swarm Optimization (PSO) [20] and Genetic Algorithms (GA) [7,9,21–23] have been studied more extensively than exact methods. These algorithms have been considered to avoid the computational complexity of the combinatorial optimization problems and have been demonstrated to provide an effective basis upon which sub-optimal solutions can be achieved. As a population-based meta-heuristics approach, GA is one of the most useful methods when the search space is not extremely rugged [24] in the presence of many types of constraints. In [21], the authors preliminarily proposed a genetic algorithm for the combinatorial optimization problem, taking the special requirements into account, such as task precedence and flyable trajectories. Subsequently, by introducing a finite set of approach angle, the CMTAP coupled with path planning was posed in the form of a digraph and a more comprehensive encoding with genetic operators was presented for both homogeneous and heterogeneous flight vehicles in [22]. Additionally, limited onboard resources (e.g., weapons), time-sensitive targets (e.g., simultaneous attacks) and deadlock situations were considered in [23]. Analogously, the applications of GA to classical combinatorial optimization problems such as TSP, GAP, and VRP have been widely studied in [25–28].

Furthermore, there have been various excellent works that discuss the dynamic environment. [4] addressed the problem of task allocation for WASM and established a time-phased network flow optimization model. This model was run simultaneously on all munitions at discrete points in time, and assigned each vehicle one or more tasks. The model was solved each time when new information was brought into the system, typically because a new target had been discovered or an already-known target’s status had been changed. [6] extended previous works using MILP to eficiently assign vehicles in a SEAD mission and involved various important constraints, such as dynamic target discovery and heterogeneous teams due to the limited weapons onboard. In the presented work, a dynamic constraint builder was constructed to deal with the discovery of each new target.

## 2.2. Stochastic task assignment problem

A stochastic task assignment problem arises when at least one of the problem’s variables is random. A comprehensive survey on both the stochastic traveling salesman problem (STSP) and the stochastic vehicle routing problem (SVRP) can be found in [29]. The authors argued that uncertainty can be categorized into the following classes: (1) task assignment with stochastic demands, (2) task assignment with stochastic customers, and (3) task assignment with stochastic travel times. The stochastic task assignment is different from the classical task assignment in many fundamental aspects. Many fundamental properties of the classical task assignment, such as the optimality conditions, no longer hold in the stochastic cases. For this reason, two main stochastic programming models are proposed: the chance constrained programming (CCP) model and the two-stage stochastic programming model, which is also called stochastic programming with recourse (SPR) [29–32]. In CCP, we pursue a solution in which the probability of failure is constrained below a certain threshold rather than taking into account the cost of corrective actions in the case of failure. Conversely, it is more meaningful that the aim in SPR is to determine a first-stage solution that minimizes the expected cost of the second-stage solution.

To our knowledge, research related to the stochastic cooperative task assignment for UAVs is limited compared with STSP and SVRP. In early research, VRP with stochastic travel times, in which vehicles incurred a penalty proportional to the duration of their route, was presented in [30]. Three mathematical programming models were also presented in this paper: a CCP model and two recourse models. In [33], VRP with random travel times and two stochastic programming models were presented. The first model minimizes the expected completion time, whereas the second model maximizes the probability of completing the project by a pre-specified deadline. For different sizes of the problem, two solution methods, both centered on a branch-and-cut approach, were proposed in this paper. In [34], VRP with stochastic demands was addressed. The customers’ demands were stochastic variables, and only the probability distribution for each customer was assumed to be known out of all of the variables. A recourse action was implemented if a failure occurred, since the total actual demand on a route exceeded the vehicle capacity. Other relevant studies on SVRP can be found in [35–37].

In more recent research, a related problem also frequently seen in practice is SVRP with time windows (SVRPTW), especially with soft time windows. In [32], the authors considered SVRPTW with stochastic travel and service times. This problem was originally formulated as a CCP model and a SPR model. In the CCP model, the problem was solved by imposing two types of chance constraints (driver duration and time windows), ensuring that the probability of failure was bounded by a certain threshold. In the SPR model, the problem was modeled in two stages. In the first stage, the priori set of vehicle routes was determined. After random variables of travel and service times were realized, the expected costs of route failure due to the excess route duration and violation of time windows were then considered in the second stage. Then, a TS-based heuristic algorithm was proposed for SVRPTW. Similar to SVRPTW with stochastic travel times, SVRPTW with stochastic demands, in which the demands were stochastic and a time window was imposed on each customer, was discussed in [31]. This problem was modeled as an SPR version, and an adaptive large neighborhood search heuristic was proposed for its solution. Several other excellent studies on SVRPTW can be found in [38,39].

## 3. Problem statement and model formulation

In this section, a scenario incorporating a team of heterogeneous fixed-wing UAVs that execute different types of predefined missions on known targets is presented. Then, a mathematical formulation of CMTAPSVTW is established. Different from the traditionally determined task assignment problem, we concentrate on the cooperative multiple task assignment coupled with the stochastic velocities caused by the unknown uncertainties on the flight trajectories.

## 3.1. Mission scenario

The environment of CMTAPSVTW can be a complex and broad concept, including local weather, warning radar, terrain barriers, etc. In addition, unknown uncertainties may occur on the flight paths while the UAVs are en route to perform the allocated tasks. Thus, the environment may have an apparent influence on the task assignment of the entire multi-UAV system, and quality of task accomplishment may become quite low if uncertainties are disregarded at the mission level. Given the aforementioned effectiveness, it is significant to incorporate the stochastic velocities to accurately evaluate the performance of the task assignment. Meanwhile, we suppose that the UAVs fly at separate altitudes so that they have collision free paths.

## 3.2. Targets and tasks

Suppose that

$$
\mathbf {T} = \{T _ {1}, T _ {2}, \dots , T _ {N _ {T}} \}\tag{1}
$$

is the set of $N _ { T }$ stationary ground targets with known positions. Additionally, $T _ { 0 }$ represents the airport.

In actual battlefield conditions, enemy targets may be assigned a set of tasks to achieve some expected goals. In other words, it is essential to distinguish the different types of targets and to allocate suitable missions on them. In this paper, there are two types of targets: ones with lower importance that require a single attack and others with higher importance that require double attacks simultaneously. Consecutive tasks are predefined on each target, which means a set of tasks ${ \mathbf { M } } _ { T _ { i } }$ is assigned on each target:

where C, A, and V are classification, attack, and verification tasks and are denoted as 1, 2, and 3, respectively, in which C and V are surveillance tasks and A is attack tasks. The number of mission types is defined as $N _ { m } = \left\| \mathbf { M } \right\|$ . Notice that attack tasks A can be divided into two types, i.e., single attack $A _ { S }$ and double simul taneous attacks $A _ { D }$ performed by two distinct UAVs, with respect to the two types of targets described above. To address the double attack tasks $A _ { D }$ for target $T _ { i }$ more reasonably, a mirror operation is introduced as follows:

$$
\mathbf {M} _ {T _ {i}} = \{C, A, A, V \}\tag{3}

## 3.3. Vehicles

The heterogeneity of the UAVs discussed in this paper is defined according to their different capabilities. There are two types of capabilities: surveillance and attack. An UAV with surveillance capabilities could perform the surveillance tasks defined above, i.e., classification and verification tasks. UAVs with attack capabilities could be assigned the attack tasks, i.e., single attack $A _ { S }$ and double simultaneous attacks $A _ { D } .$ . UAVs with both capabilities can perform all types of tasks. In terms of the types of capabilities that an UAV possesses, we can introduce three types of UAVs: combat UAVs, surveillance UAVs and munition UAVs. We assume that combat UAVs with both types of capabilities can be allocated all tasks from the set M; surveillance UAVs can perform the surveillance tasks; and munition UAVs can only accomplish the attack tasks. The capabilities of the UAVs and the tasks that can be assigned to them are shown in Table 1.

Suppose that

$$
\mathbf {U} = \left\{U _ {1} ^ {t}, U _ {2} ^ {t}, \ldots , U _ {N _ {U}} ^ {t} \right\}\tag{6}
$$

is the set of $N _ { U }$ cooperating heterogeneous fixed-wing UAVs and that t denotes the different types of UAVs according to their capabilities. As discussed above, t is C, S, and M, respectively, for combat UAVs, surveillance UAVs, and munition UAVs. Therefore, a set of tasks $\mathbf { M } _ { U _ { u } }$ is obtained after a task allocation is determined for μ-th UAV, and $\| \mathbf { M } _ { U _ { u } } \| = N _ { U _ { u } }$ , where $N _ { U _ { u } }$ is the number of tasks that need to be performed for u-th UAV, thus:

$$
N _ {\mathrm{all}} = \sum_ {u = 1} ^ {N _ {U}} N _ {U _ {u}}\tag{7}
$$

It should be noted that UAVs assigned in one allocation are randomly selected from the set U, which means that the equality $N _ { U _ { u } } = 0$ may hold for some unused UAVs.

To simplify the task assignment model and to focus on the main problem in this paper, we adopt the following assumptions:

(1) UAVs have collision-free paths by flying at a given altitude layering; (2) UAVs are survivable and cannot be destroyed when performing the assigned tasks; (3) each type of UAV has a constant but different ideal flying speed and a stochastic speed given the uncertain disturbances on the flight paths; (4) the constraint of fuel consumption is approximately regarded as the nominal total flight time of each UAV; (5) the simultaneous attack tasks cannot be performed by the same UAV. Additionally, we suppose that UAVs with attack capabilities have limited weapons onboard. If a combat UAV has run out of its weapons, it can only be assigned surveillance tasks; if a munition UAV has run out of its weapons, it cannot perform any task and must return to the airport as if it is executing a verification task as described above.

In this paper, the Dubins Car model is introduced to establish the kinematics of UAVs and to generate the elementary flight path. This part will be described in detail in section 5. Given that the scenario discussed above is a 2-D plane, the configuration of UAVs can be expressed by the following three states:

$$
q = \left[ q _ {p} ^ {\mathrm{T}}, q _ {h} \right] ^ {\mathrm{T}} = [ x, y, \psi ] ^ {\mathrm{T}}\tag{8}
$$

where $q _ { p } = [ x , y ] ^ { \mathrm { T } }$ is the horizontal position of the UAV in the Cartesian inertial coordinate frame and $q _ { h } = \psi$ is the UAV’s heading angle, i.e., azimuth angle, under the definition that $0 ^ { \circ }$ is East and the angle increases in the counterclockwise direction.

Then, the kinematics equations of u-th UAV (u ∈ U) are written as follows:

$$
\left\{ \begin{array}{l} \dot {x} = v _ {u} \cos \psi \\ \dot {y} = v _ {u} \sin \psi \\ \dot {\psi} = c v _ {u} / \rho_ {\min} ^ {u} \end{array} \right.\tag{9}
$$

where $\rho _ { \mathrm { m i n } } ^ { u }$ is the minimum turning radius of the u-th UAV and c is the steering command such that $| c | \leq 1 . ~ \nu _ { u }$ is the actual flight speed of the u-th UAV, which is composed of two components, $\mathrm { i } . \mathsf { e } .$ , the ideal flight speed and the stochastic flight speed caused by the uncertainties on the flight paths. Thus, the actual flight speed of the u-th UAV can be rewritten as $\nu _ { u } = \nu _ { u c } + \nu _ { u s }$ , in which the ideal flight speed $\nu _ { u c }$ is a constant value throughout the entire flight process and the stochastic flight speed $\nu _ { u s }$ is assumed to be a negative value corresponding to a predefined probability distribution function determined by each actual flight segment length.

## 3.4. Stochastic programming with recourse model ofCMTAPSVTW

Similar to traditional deterministic CMTAP, the CMTAPSVTW discussed in this paper can also be described as a combinatorial optimization problem. Each feasible solution must meet the constraints of targets and vehicles and allocate vehicles to perform multiple tasks on multiple targets.

To demonstrate the CMTAPSVTW model more clearly, we introduce a simplified approach by representing it as a connected digraph. Given different heading angles of UAVs when flying over different targets, it is essential to discretize these continuous angles to establish this digraph. The set of UAV heading angle discretizations is denoted as

$$
\mathbf {H} = \{\psi_ {i}: \psi_ {i} = 2 \pi i / N _ {\psi}, i = 0, 1, \ldots , N _ {\psi} - 1 \}\tag{10}
$$

where $N _ { \psi }$ is a positive integer representing the number of heading angle discretizations, i.e., $\| \mathbf H \| = N _ { \psi }$ . For more details, refer to the excellent work in Ref. [22].

After completing the preparation work as described above, a connected digraph is introduced as follows. The connected digraph $\mathbf { G } = ( \mathbf { V } , \mathbf { E } )$ denotes the network in which ${ \pmb V } = \{ { \pmb V } _ { 0 } , { \pmb V } _ { T } \}$ is the set of vertices and $\mathbf { E } = \{ e = ( \nu _ { i } , \nu _ { j } ) | \nu _ { i } , \nu _ { j } \in \mathbf { V } , i \neq j \}$ is the set of edges.

The airport is represented by vertices $\mathbf { v } _ { 0 } ,$ , and each vertex in ${ \bf v } _ { T }$ corresponds to a distinct target with discrete heading angles. Then, the set of vertices $\mathbf { v } _ { 0 }$ and ${ \bf v } _ { T }$ in digraph G can be rewritten as

$$

$$

$$

$$
i = 1, \ldots , N _ {T}, j = 0, \ldots , N _ {\psi} - 1\tag{12}
$$

Thus, $\| \mathbf V \| = N _ { V } = ( N _ { T } + 1 ) N _ { \psi }$ in this digraph.

Each target has a predefined task set ${ \mathbf { M } } _ { T _ { i } }$ according to its properties, a deterministic task duration $( s _ { i } > 0 )$ and two types of soft time windows for both classification and attack tasks and simultaneous attack tasks. Unlike a hard time window, a soft time window means that, if the constraint of the time intervals is not satisfied, the assignment is still feasible, but a punishment will be introduced with different weights for the two types of time intervals. It should be noted that the robustness of the stochastic task assignment problem is improved by introducing soft time windows. Additionally, each UAV has its own nominal maximum flight time which means that punishment will be involved if the practical flight time exceeds the nominal flight time. The punishments can be expressed as

$$
P _ {1} = \sum_ {i = 1} ^ {N _ {T}} \lambda_ {1} ^ {T _ {i}} \max \left(t _ {a} ^ {T _ {i}} - t _ {c} ^ {T _ {i}} - \Delta t _ {c a} ^ {T _ {i}}, 0\right)\tag{13}
$$

$$
P _ {2} = \sum_ {i = 1} ^ {N _ {T}} \lambda_ {2} ^ {T _ {i}} \max \big (t _ {a 2} ^ {T _ {i}} - t _ {a 1} ^ {T _ {i}} - \Delta t _ {a a} ^ {T _ {i}}, 0 \big)\tag{14}
$$

$$
P _ {3} = \sum_ {u = 1} ^ {N _ {U}} \lambda_ {3} ^ {u} \max (t _ {u} - B _ {u}, 0)\tag{15}
$$

where $P _ { 1 }$ and $P _ { 2 }$ are the respective punishments for the two types of time windows and $P _ { 3 }$ is the punishment for the total flight time. $\Delta t _ { c a } ^ { T _ { i } }$ and $\Delta t _ { a a } ^ { T _ { i } }$ are the two types of predefined time intervals, and $\boldsymbol { \lambda } _ { 1 } ^ { T _ { i } }$ and $\boldsymbol { \lambda } _ { 2 } ^ { T _ { i } }$ are the weights for these two time interval punishments for target $T _ { i \cdot } ~ t _ { c } ^ { T _ { i } } , t _ { a } ^ { T _ { i } } , t _ { a 1 } ^ { T _ { i } } , t _ { a 2 } ^ { T _ { i } }$ are the corresponding task execution times. $\lambda _ { 3 } ^ { u }$ is the weight for the total flight time punishment for the u-th UAV, and $B _ { u }$ and $t _ { u }$ are the nominal available flight time and the actual flight time, respectively.

Due to the stochastic flight speeds described above, the task execution times and actual total flight times are uncertain, and the three types of punishments will be random values. To address the stochastic factors more reliably and eficiently, we cast CM-TAPSVTW within a framework of stochastic programming model. In general, stochastic programming can usually be formulated as either a chance constrained programming (CCP) model or a twostage stochastic programming model called stochastic programming with recourse (SPR). Given that the CCP model does not incorporate the possibility of failure of task allocation, SPR is adopted to solve the stochastic task assignment problem in this paper. In the presence of an SPR model, the objective of CMTAPSVTW is altered to search for the first-stage solution that minimizes the expected punishment costs of the second-stage.

In this SPR model, the sum-up of the longest total flight times of all UAVs and the expected values of three punishments is chosen as the objective function, and the CMTAPSVTW instance can be stated as follows:

## 4. A modified GA for CMTAPSVTW

As a global search stochastic method, GA is used to obtain a better solution in the search space, though not always the optimal one, with the advantages of dealing with the discontinuous, nondifferentiable problem. In this section, a modified GA is adopted to solve the combinatorial optimization problem formulated as CMTAPSVTW.

## 4.1. Methodology

A classical GA evolves iteratively by operating a population composed of individuals, i.e., the solutions of the problem, and selects the fittest one in the last population as the best solution of the problem. The encoding and genetic operators that determine the performance and convergence of the algorithm are the key technologies in the processing. The procedure of the algorithm can be summarized as follows.

At the beginning, feasible solutions of a predefined population size $N _ { s }$ which are encoded into chromosomes are randomly generated to form the initial population. Next, evaluation of the fitness of each chromosome in the population is performed. After that, two genetic operators simulating the evolutionary process are introduced to obtain a next generation with better fitness. During the first genetic operator, i.e., crossover, individual chromosomes are selected from the population according to their fitness. If an individual has a higher fitness, it will be selected with a larger probability. Each pair of selected chromosomes, denoted as parents, are crossed at a randomly specified position to generate two children chromosomes in the next generation. For the second operator, mutation is achieved by changing one or several parts of a randomly selected chromosome. The above two operators can help to maintain the advantages of the last generation while still introducing diversity into the population. Meanwhile, the two genetic operators can also ensure that the chromosomes are still feasible for this problem. Additionally, elitism is used to save the best chromosomes of the generation. The process discussed above is repeated until a termination condition is reached. A simple process of GA is presented in Fig. 1.

## 4.2. Encoding

Solution chromosome encoding is the most significant part of the modified GA proposed in this paper. Each feasible solution representing an allocation of the tasks is encoded as a chromosome, and each chromosome can be divided into several subchromosomes corresponding to the assigned UAVs. It should be noted that the sub-chromosomes are encoded in a Quasi-matrix formed with $N _ { U _ { i } }$ columns and an extra two rows to simplify the genetic operators, such as crossover and mutation. For the sequence of these columns, i.e., the genes, they correspond to the target performance order for each UAV. For the sake of describing suficient assignment information with respect to the target and UAV, the target number, task type (denoted as 1, 2 and 3 as discussed above), UAV number, UAV capability for performing the corresponding task, and target approach angle are incorporated in one gene. Meanwhile, the UAV initial heading angle and UAV fina heading angle are taken into account in the sub-chromosome. As discussed above, both the heading angle and approach angle are represented by the discretization index.

## 4.3. Initialization

The initialization operator is used to obtain the initial population of the evolutionary process. After the task set on each target and the resource constraint set on each UAV are defined, the initialization process can be started at once. First, according to the type of each task on each target, we randomly select one UAV with the corresponding capability to perform it. Meanwhile, the resource constraint set of this UAV is updated. Then, we randomly select an approach angle for the current task on the target to generate the Dubins path for the UAV. After all tasks are assigned, we sort the allocations according to the used UAV number, and permutate the allocations randomly for each UAV. Finally, we choose an initial and final heading angle randomly for each UAV. Thus, we obtain a task assignment that can be presented as a chromosome, as shown in Fig. 4 and as discussed above. Obviously, the task assignment is totally determined when the initialization is completed. To form the population, the initialization process is repeated until the number of assignments meets the predefined population size $N _ { s } .$ . ## 4.4. Modified GA operators

## 4.4.1. Crossover

According to the law of natural evolution, the motivation behind the crossover genetic operator is that the offspring will have better fitness with advantages taken from both their parents. In this process, parent chromosomes are chosen from the current generation via the roulette wheel method according to their fitness. Afterwards, the method of single-point crossover is adopted to generate a couple of children.

A simple crossover example of an attack gene is illustrated in Fig. 6. In this mission scenario, there are two targets and three combat UAVs and the task sets on each target are $\mathbf { M } _ { T _ { 1 } } = \{ C , A , V \}$ and $\mathbf { M } _ { T _ { 2 } } = \{ C , A , A , V \}$ . Moreover, the attack capabilities of each UAV are 3, 2 and 1, respectively. In step 1, two parents are randomly chosen with different possibilities determined by their fitness. It can be seen that $U _ { 2 }$ is at the randomly selected crossover point in Parent 1. In step 2, the attack complement set of Parent 1 and the set of attack genes of Parent 2 are subsequently determined. Given that different UAVs rather than $U _ { 2 }$ should be allocated to perform the attack task after the crossover process, the capability of $U _ { 2 }$ should be deleted from the attack complement set. Then, the intersection of these two sets can be obtained. In step 3, one attack gene is randomly selected from the intersection and it replaces the original gene. Analogously, the rest of the genes of these two parents will be crossed by repeating the above steps. In step 4, the crossover operator is utilized for the initial and final heading angles of these two parents. With the method discussed above, offspring satisfying the limited resources can be generated.

## 4.4.2. Mutation

The mutation genetic operator is used to alter the assignment represented by the chromosome. It is an essential part of the GA search process to ensure population diversity and search for an optimal solution rather than sinking into a local minimum.

In this paper, the mutation operator is carried out at a randomly selected position of a chromosome and four mutation methods are applied in this process: (1) mutating the UAV for a randomly chosen task; (2) changing the task sequence for a randomly chosen UAV; (3) mutating the target approach angle; and (4) mutating the initial and final heading angle for a randomly chosen UAV. Moreover, the methods mentioned above can be performed concurrently for one chromosome.

To express the mutation procedure more clearly, we illustrate an example of the first mutation method involving double attack genes in Fig. 7. The mission scenario used in this section is similar to the crossover part. In step 1, parent is randomly chosen from the current generation, as is the mutation site. It is obvious that the double attack task of $T _ { 2 }$ performed by $U _ { 2 }$ is selected. In step 2, because the double attack task should be executed by different UAVs, another double attack gene performed by $U _ { 1 }$ is selected. Thus, we can obtain the alternative UAV set on the basis of the forbidden set and the attack complement set. In step 3, one UAV from the alternative set is randomly selected, and it replaces the former one.

Similar to the process described above, the other three mutation methods can also be completed. It should be declared that all resource limitations are satisfied by means of the above operations in the mutation procedure.

## 4.5. Generations

$N _ { g }$ generations of the population are evolved iteratively with constant population size $N _ { s } .$ To avoid the possibility of missing the best solutions in each generation, we employ the elitism genetic technique, and thus the best $N _ { e }$ chromosomes are propagated to the next generation directly. The offspring chromosomes $N _ { c r } < ( N _ { s } - N _ { e } )$ are obtained by the modified crossover genetic operators, and the rest of the new $N _ { m } = N _ { s } - N _ { e } - N _ { c r }$ offspring chromosomes are created by the modified mutation genetic operator. Therefore, the process of producing new generations can be repeated until some stopping criterion is met $( N _ { g }$ generations in this paper).

## 4.6. Deadlock

In this cooperative task assignment problem, it is crucial to take into account the task precedence constraints on each target. Because the performance sequence for each UAV is randomly ordered during the solution generation process, as discussed above, a phenomenon called deadlock may be involved in a chromosome. Deadlock is a type of state in which one or more UAVs fall into an endless waiting process and it will lead to an infeasible solution.

There are two basic deadlock statuses in this assignment problem: self-lock and interlock. In the first deadlock status, two tasks with different priorities on one target are allocated to one UAV, while the performance order of this UAV is opposite the task precedence constraints. Thus, the UAV is involved in an infinite loop in which the latter task is always waiting for the former task to be completed. In the second deadlock status, more than one UAV and target fall into a circuit at the same time. Additionally,

The mission scenario is the same as the crossover part. Two types of deadlock, self-lock and interlock, are represented by the blue line and red line, respectively. In self-lock with the fourth and fifth segments, $U _ { 2 }$ performing the former task C on $T _ { 2 }$ is always waiting for itself to finish performing the latter task $A$ on the same target. It is an obvious endless waiting loop. As with the selflock, $U _ { 1 }$ corresponding to the second and third segments and $U _ { 3 }$ corresponding to the sixth and seventh segments are involved in the interlock. To address this unacceptable deadlock situation, we adopt a transposition operation introduced in Ref. [10]. This transposition operation is achieved by reordering the task execution for each UAV involved in the deadlock. ## 5. Path coordination

The work in this section is significant because the kinematics of UAVs based on the Dubins Car model are taken into account in the process of elementary path generation. Furthermore, to meet the constraints of task precedence, we coordinate the flight paths of UAVs and create the actual flight paths for each UAV by proposing two types of extra maneuvering flights. Therefore, the efforts for path generation and coordination make the stochastic cooperative multiple task assignment more practical.

According to Ref. [22], the minimum length for a flyable path from any initial configuration $[ x _ { i n i } , y _ { i n i } , \psi _ { i n i } ] ^ { \mathrm { T } }$ to any final configuration $[ x _ { f i n a l } , y _ { f i n a l } , \psi _ { f i n a l } ] ^ { \mathrm { T } }$ consists of three flight segments which are either arcs of circles with a minimal radius or straight lines segments. To express the Dubins path precisely, we denote three primary motions: turning left $( L ) ,$ turning right (R) and straight line (S). Then, the Dubins set D can be obtained as follows:

$$
\mathbf {D} = \{R S R, L S L, R S L, L S R, R L R, L R L \}\tag{27}
$$

which means that the minimum feasible flight paths can be chosen in set D. For example, the notation RSR represents a Dubins trajectory composed of R, S, and R segments.

After obtaining an unlocked allocation, i.e., a feasible solution, a set of elementary flight paths, shown in Fig. 9, are generated according to the Dubins Car model for all used UAVs in the allocation. The time information of the task execution on each target can be obtained at the same time. However, due to the different ideal flight velocities for each UAV, the task precedence constraints in Eq. (20) may be broken for some targets, which means that one UAV performing the latter task arrives earlier than the other UAV performing the former task. Thus, the goal of path coordination is to meet the task precedence constraints on all targets by adjusting task performance times, i.e., the arrival times of the corresponding UAVs, according to the topological order of the assignment. The process of path coordination is presented in Fig. 10.

The approach of the adjustment is now detailed. For those targets whose tasks do not satisfy the task precedence constraints, the latter task will be delayed by adding a suitable extra maneuvering flight to the UAV, which will be performed immediately after the former task is completed. To adjust the waiting time, we adopt two types of extra maneuvering flights: waiting circles and attached paths. If the delayed time is exactly equal to or longer than the time spent on the minimum radius circle flight, the extra maneuvering flight will be one or more waiting circles with appropriate radius; if the delayed time is shorter than the minimum circle flight time, the elementary flight path will be added with a suitable attached path to achieve the expected waiting time. To be more flexible and practical, we choose two types of attached paths according to the different conditions. If the turn angle of the first circle (or last circle) in the Dubins path is larger than 180<sup>◦</sup>, the first attached path shown in Fig. 11a) will be selected; otherwise, the second attached path in Fig. 11b) will be adopted.

## 7. Conclusions

In this paper, we focus on a cooperative multiple task assignment problem with stochastic velocities and soft time windows. To construct a reliable and eficient evaluation criterion, we model the problem within a framework of stochastic programming with recourse. The objective is to determine the first-stage task assignment that minimizes the expected costs in the second-stage problem. Considering the prohibitive computational complexity and favorable searching ability, we propose a novel modified GA to improve the solution of CMTAPSVTW. Additionally, to create the actual flight paths for each UAV that meet all time constraints, we propose two maneuver appending methods according to the elementary flight paths.

The Monte Carlo results on mission instances confirm the effectiveness and superiority of our modified GA. Both reliable and eficient task assignments can be obtained by the SPR model compared with the deterministic model, which indicates that optimization in a stochastic manner is significant and essential. For a more realistic application, sample trajectories are illustrated while meeting all constraints in CMTAPSVTW.

Future research includes proposing a distributed task assignment model with more stochastic characteristics, e.g., stochastic task execution effectiveness and stochastic communication with each other. By these means, the resulting problem can cover more practical mission scenarios. Additionally, a further comparison study will be performed between the centralized and distributed models for the stochastic task assignment problem.
