# 多仓库带容量约束弧路径问题的近似算法和多项式算法

## 摘要

随着现代物流行业的崛起，企业为了降低运输成本，越来越重视对车辆路径问题（Vehicle Routing Problem, 简称 VRP）的研究。弧路径问题（Arc Routing Problem, 简称 ARP）与 VRP 问题一样，同样有着重要的现实意义和研究价值。二者的不同之处在于，VRP 以点为服务对象，而 ARP 以边为服务对象。经典的弧路径问题只有一个仓库点，但实际应用中的很多问题需要利用多个仓库点的弧路径问题建立数学模型。因此，本文研究了多仓库带容量约束弧路径问题 (Multi-depot Capacitated Arc Routing Problem, 简称 MCARP)，将经典的弧路径问题推广到更为实际的多仓库情形。针对 MCARP 的不同变形问题，我们提出了近似算法和多项式算法。本文主要分为以下七个章节。

第一章介绍了研究背景并对组合最优化问题进行了简单描述，还阐述了本文相关问题的最新研究进展。

第二章描述了本文所涉及的符号和概念。

第三章介绍了非固定终点 MCARP 问题，给定一仓库点集 D，每辆车可从任一仓库出发，最终可返回至任意仓库，目的是找到服务了所有需求边的若干条路径，使得总路径长度最短。将非固定终点多仓库带容量约束的车辆路径问题（Multi-depot Capacitated Vehicle Routing Problem, 简称 MCVRP）的算法进行推广，得到了非固定终点 MCARP 问题的近似算法。

第四章研究了固定终点 MCARP 问题。给定一仓库点集 D，每辆车从任一仓库出发，最终返回到该仓库，目标是找到服务了所有需求边的若干条回路使得总回路长度最短。我们推广了固定终点 MCVRP 的算法，得到固定终点 MCARP 问题的近似算法。

第五章讨论了多仓库乡村邮递员问题（Multi-depot Rural Postman Problem, 简称MRPP），它是MCARP问题容量无限的特例。有一仓库点集 $D \subseteq V$ ，其中 $|D| = k$ 。目标是找到 $k$ 条覆盖了所有需求边的回路，使得总回路长度最短。每条回路都对应一位邮递员的路径，他们必须从不同的仓库出发且最终返回至该仓库。此外，我们还研究了以极小化最长回路为目标的MRPP的一个变形问题，称为极小-极大乡村邮递员覆盖问题，并给出了改进的近似算法。

第六章介绍了定义在线图上的 MCARP 问题，当需求一致时，证明该问题是多项式可解的；同时，我们还讨论了线图上的 MCVRP 问题，并给出了近似算法。

第七章对本文进行了总结，给出今后可以进一步研究和改进的方向。

关键词：近似算法；多仓库；车辆路径问题；弧路径问题；乡村邮递员问题

## Abstract

With the rise of modern logistics industry, enterprises pay more and more attention to the study of vehicle routing problem (VRP) in order to reduce transportation costs. The arc routing problem (ARP), like the VRP, has important practical significance and research value. The difference between the two is that VRP takes point as the service object while ARP takes edge as the service object. The classical arc routing problem has only one depot, but many problems in practical applications need to use the arc routing problem with multiple depots to establish a mathematical model. Therefore, in this thesis, we study the capacitated arc routing problem with multiple depots (MCARP), and extend the CARP to the more realistic multi-depot case. For different variants of the MCARP, we propose approximation and polynomial algorithms. This thesis is divided into the following seven chapters.

In chapter 1, we show the research background, briefly describe the combinatorial optimization problem, and introduce the latest research progress of related problems.

In chapter 2, we describe some symbols and concepts used in this paper.

In chapter 3, we introduce the nonfixed destination multi-depot capacitated arc routing problem (NMCARP). Given a depot set D, each vehicle can start from any depot and finally return to any depot. The objective is to find several walks that serves the required edge set R and minimize the total length of the walks. The nonfixed destination multi-depot capacitated vehicle routing problem (NMCVRP) is extended to obtain the approximation algorithm of NMCARP.

In chapter 4, we discuss the fixed destination MCARP. Given a depot set D, each vehicle starts from any depot and finally returns to the depot. The target is to find several closed walks that serve the demand edge set R and make the total length of the closed walks minimized. We generalize the fixed destination MCVRP and obtain the approximation algorithm of the fixed destination MCARP.

In chapter 5, we deal with the multi-depot rural postman problem (MRPP), which is a restricted case of the MCARP with infinite capacity. There is a depot set $D \subseteq V$ with $|D| = k$ . The goal is to determine $k$ closed walks covering all required edges of $R$ such that the total length of the closed walks is minimized. In addition, we also study a variant of MRPP aiming at minimizing the longest closed walk, which is called min-max rural postmen cover problem, and give an improved approximation algorithm.

In chapter 6, we treat the MCARP defined on a line graph. When the demands are uniform, we prove the problem is polynomial solvable. What's more, we also discuss the MCVRP defined on a line graph, and give an approximation algorithm.

Keywords: Approximation Algorithms; Multi-Depot; Vehicle Routing Problem; Arc Routing Problem; Rural Postman Problem

## 第1章 引言

## 1.1 研究背景及意义

组合最优化是通过对数学方法的研究，去寻找离散事件的最优编排、分组、次序或筛选等，是运筹学中一个经典且重要的分支，所研究的问题涉及信息技术、经济管理、工业工程、交通运输、通讯网络等诸多领域。该问题可用数学模型描述为： $\min f(x)$ ， $s.t. g(x)\geq0,\quad x\in D$ 。组合最优化问题就是在给定有限集合的所有具有某些特性的子集簇中，寻找使某种指标达到最优的子集的问题。依据问题的性质，包括排序问题、匹配问题和网络流问题等。组合优化的特点是：变量都是离散的；多数问题属于NP难问题，即对该类问题目前还不能在多项式时间内求出它们的最优解。由于这类问题在生产实际中经常出现，于是出现了两类解决问题的途径：一类是精确算法，另一类是近似算法。常用的精确算法有分支定界、整数规划和枚举等。当求解小规模的组合优化问题时，精确算法能够在较短时间内得到最优解；当问题的规模比较大时，即使得到最优解，但是计算时间也会过长。近似算法是指在合理的计算时间内找到一个误差大小能够为人们所接受的可行解。虽然不能求出问题的最优解，但却能较快得到相对合理的解。组合最优化问题在计算机科学领域中占据着重要地位，而拟阵理论在最优化理论中十分流行。因此，随着组合最优化研究的进展，一些数学分支，如组合数学、拟阵以及图论等，也相应地得到新的发展。

路径问题的研究可以分为两个方向：以点为服务对象的车辆路径问题（Vehicle Routing Problem，简称 VRP）和以边为服务对象的弧路径问题（Arc Routing Problem，简称 ARP）。不同于 VRP，ARP 的基本特征是车队从一个仓库出发，对所有需要服务的边进行作业，而不是在顶点进行服务。弧路径问题是著名的中国邮递员问题和乡村邮递员问题的推广。

带容量约束的弧路径问题（Capacitated Arc Routing Problem, 简称 CARP）最早是由 Golden 和 Wong 于 1981 年提出的。CARP 问题普遍应用在日常生活中，特别是市政服务方面，如道路洒水车路径规划、垃圾回收车路径规划、道路除冰车路径规划、校车接送路径问题等。给定一无向图 $G = (V, E)$ ，它的顶点集为 $V$ ，边集为 $E$ 。在 $E$ 上定义了一个非负费用函数 $c(\cdot)$ ，任意边 $e \in E$ 都关联一个非负整数需求 $d(e)$ 。在指定顶点 $O \in V$ （该点也称为仓库）处有一支车队，每辆车完全相同，容量为 $Q$ 。有容量限制的弧路径问题，其目标是寻找一系列起始并终止于仓库的路径（或者闭路），这些车辆能够服务所有需求大于 0 的边，每辆车所服务的顾客总需求不超过容量 $Q$ ，使得路径的总长度最小。在问题中，若需求是在顶点上而不是边上，那么我们就得到了带容量约束的车辆路径问题（Capacitated Vehicle Routing Problem，简称 CVRP）。根据问题有无固定起点和终点的要求，本文研究了以下三种 CARP 问题的变形问题，另外还考虑了线图上的 CARP 和

CVRP 问题。

(1) 非固定终点多仓库带容量约束弧路径问题（Multi-depot Capacitated Arc Routing Problem, 简称 MCARP）。给定一仓库点集 D，每辆车可从任一仓库出发，最终可返回至任意仓库，目的是找到服务了所有需求边的若干条路径，使得总路径长度最短。我们将非固定终点多仓库带容量约束的车辆路径问题（Multi-depot Capacitated Vehicle Routing Problem，简称 MCVRP）的算法进行推广，得到非固定终点 MCARP 问题的近似算法。

（2）固定终点 MCARP 问题。给定一仓库点集 D，每辆车从任一仓库出发，最终返回到该仓库，目标是找到服务了所有需求边的若干条回路使得总回路长度最短。我们推广了固定终点 MCVRP 问题的算法，得到固定终点 MCARP 问题的近似算法。

（3）多仓库乡村邮递员问题（Multi-depot Rural Postman Problem，简称MRPP），它是MCARP问题容量无限的特例。有一仓库点集 $D\subseteq V$ ，其中 $|D|=k$ 。目标是找到k条覆盖了所有需求边的回路，使得总回路长度最短。每条回路都对应一位邮递员的路径，他们必须从不同的仓库出发且最终返回该仓库。此外，我们还研究了以极小化最长回路为目标的MRPP的一个变形问题，称为极小-极大乡村邮递员覆盖问题（Min-Max Rural Postmen Cover Problem，简称MMRPCP），并给出了改进的近似算法。

（4）线图上的路径问题。我们证明了定义在线图上一致需求的 MCARP 问题是多项式可解的；对于线图上的 MCVRP 问题, 我们给出了近似算法。

正如 Golden 和 Wong 所提到的 $^{[1]}$ ，CVRP 是 CARP 问题的特例。因为我们可以将 CVRP 问题的顶点拆分成两个顶点，用费用为 0 的边连接这两个顶点，该边需求恰为初始顶点的需求。CARP 问题在实际生活中有着广泛应用，包括电力线路检查 $^{[2]}$ ，配送服务 $^{[3]}$ ，垃圾收集 $^{[4]}$ ，校车路径问题 $^{[5]}$ 等。

CARP/CVRP问题的一个自然延伸问题是多仓库有容量限制的弧路径或者车辆路径问题（MCARP/MCVRP），其中仓库有多个而不是一个，要求路径从某一仓库出发并且最终回到该仓库（但不同的路径所在仓库可能不同）。研究MCARP/MCVRP的动机不仅在于对它们理论方面的兴趣，还在于它们广泛的应用。对于CARP/CVRP问题，当服务区域较大时，通常会设置多个仓库以满足服务需求[6]。这些仓库可以对应为车站、仓库、倾倒地点、供应点或继电器箱。例如，在网购业务中通常会设置多个运营站点，来满足城市客户体验和满意度[7]。MCARP/MCVRP的其他应用包括邮件派发[8]、爆炸物回收[9]、警察巡逻[10]等。

著名的乡村邮递员问题（Rural Postman Problem，简称 RPP）是 NP 难的，作为 RPP 的推广 CARP 自然也是 NP 难问题。同理，CVRP 是满足度量条件的旅行商问题(Traveling Salesman Problem, 简称 TSP)的推广，因此也是 NP 难的。关于解决 MCARP/MCVRP 的现有文献中，主要运用的方法是分支定界 $^{[11,12]}$ 和启发式算法 $^{[7,8,13]}$ 。然而，我们从近似算法的角度讨论了 MCARP 问题。据我们所知，关于 CARP/CVRP 的多仓库变形问题，近似算法的结果非常有限。尤其是，我们还不知道 MCARP 的任何近似算法。因此，本文主要关注多仓库带容量约束的弧路径问题的近似算法，下面给出近似算法的定义。

定义 1.1 对于一个极小化目标函数的组合优化问题 P（如：MCARP 问题），若对于问题 P 的任意实例 I，算法 ALG 能够在多项式时间内找到一个目标值至多是实例 I 最优值 $\alpha$ 倍的可行解，称 ALG 为问题 P 的 $\alpha$ 近似算法， $\alpha$ 称为近似比。

## 1.2 国内外研究现状

CARP/CVRP 近似算法的研究是由 Haimovich 和 Rinnooy $^{[14]}$ 发起的，他们研究了一致需求的 CVRP, 这是 CVRP 的一个特例，每个顶点的需求 $d(v)=1$ 。他们给出了著名的迭代环游划分算法，记作 $ITP(\alpha)$ ，其中 $\alpha$ 表示求解度量 TSP 问题的近似比 ( $\alpha\leq\frac{3}{2}$ ，参见结果 $^{[15,16]}$ )，并且证明了当顶点个数 $n=|V|$ 是 Q 的倍数时， $ITP(\alpha)$ 的近似比为 $1+(1-\frac{1}{Q})\alpha$ 。后来 Haimovich 等 $^{[17]}$ 和 Altinkemer 及 Gavish $^{[18]}$ 在去掉 n 是 Q 的倍数这一条件时，也得到了相同结果。事实上，文献 $^{[17,18]}$ 中所描述的 $ITP(\alpha)$ 与文献 $^{[14]}$ 稍有不同，但我们仍然将其称为 $ITP(\alpha)$ 。对于一般的 CVRP, Altinkemer 和 Gavish $^{[18]}$ 获得了 $(2+(1-\frac{2}{Q})\alpha)$ -近似算法，称作 $UITP(\alpha)$ ，它是 $ITP(\alpha)$ 在需求不一致情况下的推广。在文献 $^{[17]}$ 中可以找到这一结果的简化证明。最近，Blauth 等 $^{[19]}$ 成功将 CVRP 的近似比改进到 $2+\alpha-2\varepsilon$ ，对于一致需求的情形，他们也得到了一个改进的 $(1+\alpha-\varepsilon')$ -近似算法，这里的 $\varepsilon,\varepsilon'>1/3000$ 。

除了定义在一般图上的 CVRP 的结果外，还有定义在特殊图上的 CVRP 的结果。Labbe 等 $^{[20]}$ 设计出了定义在树图上的 CVRP 问题的 2-近似算法。对于线图上的 CVRP, Wu 和 Lu $^{[21]}$ 进一步将近似比改进到 5/3。

对于CARP问题，Jansen[22]证明了如何将上述一致需求的 $ITP(\alpha)$ 和一般需求的 $UITP(\alpha)$ 近似算法，推广到满足三角不等式的CARP，这两个算法的近似比分别为 $1 + (1 - \frac{1}{Q})\alpha_0$ 和 $2 + (1 - \frac{2}{Q})\alpha_0$ ，其中 $\alpha_0$ 是求解乡村邮递员问题的近似比（根据文献[23,24]中的结果， $\alpha_0\leq \frac{3}{2}$ )。Wohlk[25]提出了满足三角不等式的CARP的另一个 $(2 + (1 - \frac{2}{Q})\alpha_0)$ -近似算法。有趣的是,Van Bevern[23]证明了，对于有三角不等式的CARP,任何 $\beta$ -近似算法都可以转化为一般（无三角不等式）CARP的 $\beta$ -近似算法。因此，一致需求的CARP存在一个 $(1 + (1 - \frac{1}{Q})\alpha_0)$ -近似算法。

对于多仓库的CVRP, Li和Simchi-Levi[26]得到了近似比为 $1 + (2 - \frac{1}{\varrho})\alpha$ 和 $2 + (2 - \frac{2}{\varrho})\alpha$ 的近似算法，它们分别适用于一致需求情况和一般需求情形。此外，他们还考虑了非固定终点MCVRP,即MCVRP的一种变形，允许车辆从一个仓库出发但最终返回至另一个仓库，并给出了一致需求情形的 $1 + (1 - \frac{1}{Q})\alpha$ -近似算法和一般需求情况的 $(2 + (1 - \frac{2}{Q})\alpha)$ 近似算法。

需求可分的车辆路径问题（Split Delivery Vehicle Routing Problem，简称 SDVRP），即每个有需求的顶点可由多辆车服务，是 VRP 的一种变形。Archetti 等 $^{[27]}$ 研究了 SDVRP 在特殊图，如线图、星图和树图等图上的复杂性，还考了车辆数有限和无限情形的 SDVRP 问题。针对线图，他们证明了车辆数有限或无限的 SDVRP 能够在 $O(n)$ 时间内求解，而对于车辆数有限或无限的 VRP 都是 NP 难的。

以上是关于最基本的有容量约束的弧路径和车辆路径问题的研究情况，但 MCARP 和 MCVRP 还能进一步推广，应用到其它方面。我们知道，在实际用中不仅是多仓库情形，还有一些特殊的约束。例如，在城市主干道中，只有在特定时间段才能对它们进行服务；在故障车辆救援中，服务的客户一部是点客户一部分是弧客户……下面我们将具体介绍。

在某些城市的主干道中只有在特定的时间段内才能对它们进行服务。因此，徐凯[28]考虑了在CARP问题的基础上对一些相对重要的路径加以时间限制这一情况，即有时间约束的CARP。它是CARP的一种变形，在实际生活中有着重要应用。带时间约束的CARP,需要在完成全部路径规划的同时,优先保证这些路径的服务时间，如果不能在路径的约束时间内对其进行服务，则优先选择具有最小时间延误代价的路径规划方案来施行，而延误惩罚代价可以根据路径重要程度来确定。徐凯利用遗传算法并借助进化算子来解决该问题。

在故障车辆救援(Rescue of breakdown vehicles)的场景中,有两种客户类型,一类是弧客户(Arc customer),另一类是点客户(Node customer)。其中弧客户需要救援车辆将故障车辆从故障现场拖至相应维修点的服务,并且每位客户拥有各自的响应时间要求;而点客户仅需要送油,送电等却不需要移动故障车辆的服务。在这样的背景下,张毅[29]提出了一种故障车辆救援中的多场站点混合弧路径问题。在该问题中,车辆需要从多个仓库点出发,在车辆最大工作时间的约束下,按照每个客户不同的响应时间需求,为两类客户提供不同的服务,最终完成后回到出发时的场站,目标是找出运行费用最小的路径安排。

随着 “低碳” 理念日渐深入人心，共享单车成为当下生活潮流。为了提高用户体验，共享单车公司需及时对故障单车进行回收，因此，优化故障共享单车回收路径具有重要的意义。故障共享单车大多存在于相应的停放站点或是分散在城市道路边上，回收量不固定且可能大于单个货车的最大装载量，于是单次回收难以满足需求。针对这种现象，徐阳等[30]研究了需求不确定的故障共享单车回收PVRP(周期性车辆路径问题)，目标是使车辆行驶总距离最小。作者提出了基于最大搬运距离限制的 $K - \text{means}$ 算法，对路网上分散的故障共享单车进行聚类，并采用鲁棒优化的方法对不固定的回收量进行处理，设计了近似算法。

车辆的优化配置与调度是机场接送问题的研究核心, 主要内容是优化接送服务中的交通活动, 包括车辆接送路径, 出发时间等。目的是用最低成本完成接送, 同时满足顾客、机票代售企业等各方对接送活动的要求。对于这种基于弧选择的路径优化问题, 王霖青[31]主要运用 Pareto 弧选择问题和分支定界的枚举策略来解决该问题。

城市生活垃圾收集车辆路径优化问题是一个典型的带容量约束的弧路径问题。随着人们环保意识的增强，降低油耗成为优化城市垃圾运输车辆路径的新突破。张卫星[32]从节能减排的角度，以降低油耗为目标，通过考虑运输环节影响油耗的主要因素，构建了该问题的模型，给出了一种结合贪婪算法的混合遗传算法来求解该问题。

本文讨论了 MCARP 问题的若干变形问题。与经典的弧路径问题不同，本文所研究的弧路径问题具有多个仓库点，我们既考虑了车辆路径必须终止于起始仓库点的模型，也研究了车辆路径可以终止于不同于起点的仓库点的情况。此外，我们还考虑了线图上的 MCARP 问题和 MCVRP 问题。文章结构如下：

第二章，我们描述了本文所研究的若干弧路径问题：非固定终点 MCARP、固定终点 MCARP、MRPP、MMRPCP、线图上的 MCARP 和 MCVRP, 还给出了图论相关概念以及本文使用的符号。

第三章，我们讨论了非固定终点 MCARP 问题。通过将仓库点集收缩为一点，再调用 CARP 的 $\beta-$ 近似算法，得到了该问题的 $\beta-$ 近似算法，此处的 $\beta$ 取值为 $2+(1-\frac{2}{Q})\alpha_{0}$ 。

第四章，研究了固定终点 MCARP 问题。通过修改上一章节非固定终点 MCARP 问题的近似算法，得到该问题的 $(2 + (2 - \frac{2}{Q})\alpha_{0})$ - 近似算法，其中 $\alpha_{0}$ 表示求解 RPP 问题的近似比。

第五章，我们讨论了多仓库乡村邮递员问题，这是MCARP问题车辆容量无限的特殊情形。利用最小权完美匹配和约束生成森林的想法，给出该问题的两种近似算法，结合算法构造可行解的互补性，得到 $(2 - \frac{1}{2k + 1})$ -近似算法。此外，我们还研究了以极小化最长回路为目标的MRPP的一个变形问题，称为极小-极大乡村邮递员覆盖问题，针对该问题，我们利用二分搜索和图分解的方法，得到8-近似算法。

第六章研究了定义在线图上一致需求的 MCARP 问题，我们通过将它分解为半直线图上的 CARP 和线图上的 2-仓库 CARP 这两个子问题，证明了该问题能够在 $O(n^{2})$ 时间内求解。对于定义在线图上一般需求的MCVRP问题，我们通过研究该问题的松弛问题一需求可分情形，获得了该问题的2-近似算法。

第七章，对本文的结果进行了总结，并提供了今后可以进一步改进和研究的方向。

## 第 2 章 预备知识

## 2.1 图论相关概念

给定无向图 $G = (V, E)$ ，其中 $V$ 为顶点集，也用 $V(G)$ 表示， $E$ 表示边集，也用 $E(G)$ 表示。任意边 $e \in E$ ，可以表示为 $e = [u, v]$ ，其中 $u, v$ 是边 $e$ 的两个端点。若一条边的两个端点为同一顶点，则此边称作自环（loop）。路径（walk）是指图 $G$ 中一个点边交替出现的序列，可以表示为 $P = v_0 e_1 v_1 e_2 v_2 \ldots e_k v_k$ ，其中 $e_i$ 的端点为 $v_{i-1}$ 和 $v_i$ ， $k$ 称作路径的长度。当它的起点与终点重合时（即 $v_0 = v_k$ ），该路径称为“闭”的，我们称之为回路（closed walk），如果该回路经过每条边恰好一次，则称该回路为欧拉回路（Euler circuit）。若 $G$ 中任意两点间都存在一条路径，就说 $G$ 是连通图（connected graph）。

若 $H = (V', E')$ 满足 $V' \subseteq V$ ， $E' \subseteq E$ ，则称 H 为 G 的子图（subgraph），我们用 $V(H)$ ， $E(H)$ 分别表示其顶点集和边集。子图 H 如果满足 $V(H) = V$ ，则称 H 为 G 的生成子图（spanning subgraph）。如果 C 是 G 的一个极大连通子图，即在 C 中任意添加一条不在 C 中的边，所得的子图都不是连通的，则称 C 为 G 的连通分支（connected component）。匹配（matching）M 是 G 的一个边子集，其中任意两条边都没有公共端点，若 $v \in V$ 与 M 中的边关联，称 v 是匹配的。当 V 中所有点都是匹配的，此时 M 称作完美匹配（perfect matching）。度（degree）是指 G 中与顶点 v 关联的边的条数。

本文研究的 MCARP 是定义在一个无向图 $G = (V, E)$ 上，有一个特殊的点集一仓库点集 D，每个仓库点都有一个由充分多的车辆组成的车队，它们的容量均为 Q。每辆车都必须从仓库点出发，最终返回到仓库点。每条边都关联一个长度和需求，用 $c(e) \geq 0$ 表示边 e 的长度（也称费用）， $d(e) \geq 0$ 表示边 e 的需求， $d(e) > 0$ 的边称为需求边，所有需求边所构成的集合称为 R。给定一条路径 P，路径 P 服务边 e 是指经过 e 并且满足 e 的需求 $d(e)$ 。 $R(P)$ 表示由路径 P 服务的需求边所构成的集合。同一条需求边可能被多条路径经过，但只能被一条路径服务。对于 MCVRP，需求函数 $d(\cdot)$ 定义在顶点集 V 而不是边集 E 上，这时，路径 P 服务顶点 v 是指 P 经过 v 并且满足 v 的需求 $d(v)$ 。 $\overline{R}(P)$ 表示由路径 P 服务的需求点所构成的集合。对任意 $u, v \in V$ ， $c_s(u, v)$ 代表 u 到 v 最短路的长度。对于 G 的子图 H，它的费用定义为 $c(H) = \sum_{e \in E(H)} c(e)$ 。

## 2.2 问题描述

本文研究了经典的带容量约束弧路径问题（CARP）的不同变形问题。下面我们分别给出不同问题的数学语言描述。

非固定终点多仓库带容量约束弧路径问题（非固定终点 MCARP）

输入: 无向图 $G = (V, E)$ , $c: E \to N^{*}$ 是定义在 $E$ 上的非负费用(或长度)函数, $d: E \to N^{*}$ 是定义在 $E$ 上的非负需求函数, 仓库点集 $D \subseteq V$ , 容量 $Q \in N^{*}$ 。

输出：l 条路径 $P_{1}, P_{2}, \cdots, P_{l}$ ，使得 $R \subseteq \bigcup_{i=1}^{l} R(P_{i})$ ，每条路径 $P_{i}$ 从任一仓库出发，最终可返回至任意仓库，且 $\sum_{e \in R(P_{i})} d(e) \leq Q, i = 1, \ldots, l$ 。

目标：最小化 l 条路径的总长度，即最小化 $\sum_{i=1}^{l} c(P_{i})$ 。

数学语言描述为：

$$
\begin{array}{c} \min \sum_ {i = 1} ^ {l} c (P _ {i}) \\ s. t. R \subseteq \bigcup_ {i = 1} ^ {l} R (P _ {i}) \\ \sum_ {e \in R (P _ {i})} d (e) \leq Q, i = 1, \dots , l \end{array}\tag{2-1}
$$

固定终点多仓库带容量约束弧路径问题（固定终点 MCARP）

输入：无向图 $G = (V, E)$ ， $c: E \to N^*$ 是定义在 $E$ 上的非负费用（或长度）函数， $d: E \to N^*$ 是定义在 $E$ 上的非负需求函数，仓库点集 $D \subseteq V$ ，容量 $Q \in N^*$ 。

输出： $l$ 条回路 $C_1, C_2, \ldots, C_l$ ，使得 $R \subseteq \bigcup_{i=1}^{l} R(C_i)$ ，每条回路 $P_i$ 从任一仓库出发，最终返回至该仓库，且 $\sum_{e \in R(P_i)} d(e) \leq Q$ ， $i = 1, \ldots, l$ 。

目标：最小化 $l$ 条回路的总长度，即最小化 $\sum_{i=1}^{l} c(C_i)$ 。

数学语言描述为:

$$
\begin{array}{c} \min \sum_ {i = 1} ^ {l} c (C _ {i}) \\ s. t. R \subseteq \bigcup_ {i = 1} ^ {l} R (C _ {i}) \\ \sum_ {e \in R (C _ {i})} d (e) \leq Q, i = 1, \dots , l \end{array}\tag{2-2}
$$

多仓库乡村邮递员问题（MRPP）

输入：无向图 $G = (V, E)$ ， $c: E \to N^*$ 是定义在 $E$ 上的非负费用（或长度）函数，包含 $k$ 个顶点的仓库点集 $D \subseteq V$ 。

输出：k 条回路 $C_{1}, C_{2}, \cdots, C_{k}$ ，使得 $R \subseteq \bigcup_{i=1}^{k} R(C_{i})$ ，每条回路 $C_{i}$ 从一个不同的仓库出发，最终返回至该仓库。

目标：最小化 k 条回路的总长度，即最小化 $\sum_{i=1}^{k} c(C_{i})$ 。

数学语言描述为:

$$
\min \sum_ {i = 1} ^ {k} c (C _ {i})\tag{2-3}
$$

$$
s. t. R \subseteq \bigcup_ {i = 1} ^ {k} R (C _ {i})
$$

$$
f: \{C _ {1}, C _ {2}, \dots , C _ {k} \} \rightarrow D
$$

其中映射 $f(\cdot)$ 表示从路径集合 $\left\{C_{1}, C_{2}, \cdots, C_{k}\right\}$ 到仓库集合 D 的一一映射。值得注意的是，一条路径 $C_{i}$ 可能包含多个仓库点，但只有一个仓库点是这条路径对应的起点。

极小-极大乡村邮递员覆盖问题（MMRPCP）

输入：无向图 $G=(V,E)$ ， $c:E\to N^{*}$ 是定义在E上的非负费用（或长度）函数，正整数k。
输出：至多k条回路 $C_{1},C_{2},\cdots,C_{l}(l\leq k)$ ，使得 $R\subseteq\bigcup_{i=1}^{l}R(C_{i})$ 。

目标：极小化最长回路的长度，即最小化 $\max_{1\leq i\leq l}c(C_i)$ 。

数学语言描述为:

$$
\begin{array}{c} \min \max _ {1 \leq i \leq l} c (C _ {i}) \\ s. t. R \subseteq \bigcup_ {i = 1} ^ {l} R (C _ {i}) (l \leq k) \end{array}\tag{2-4}
$$

## 线图上的多仓库带容量约束弧路径问题

输入：线图 $L = (V, E)$ ， $c: E \to N^{*}$ 是定义在 $E$ 上的非负费用（或长度）函数， $d: E \to N^{*}$ 是定义在 $E$ 上的非负需求函数，仓库点集 $D \subseteq V$ ，容量 $Q \in N^{*}$ 。

输出：l 条回路 $C_{1}, C_{2}, \cdots, C_{l}$ ，使得 $R \subseteq \bigcup_{i=1}^{l} R(C_{i})$ ，每条回路 $C_{i}$ 从任一仓库出发，最终返回至该仓库，且 $\sum_{e \in R(C_{i})} d(e) \leq Q, i = 1, \ldots, l$ 。

数学语言描述为:

$$
\begin{array}{c} \min \sum_ {i = 1} ^ {l} c (C _ {i}) \\ s. t. R \subseteq \bigcup_ {i = 1} ^ {l} R (C _ {i}) \end{array}\tag{2-5}
$$

$$
\sum_ {e \in R (C _ {i})} d (e) \leq Q, i = 1, \dots , l
$$

## 线图上的多仓库带容量约束车辆路径问题

输入：线图 $L = (V, E)$ ， $c: E \to N^{*}$ 是定义在 $E$ 上的非负费用（或长度）函数， $d: V \to N^{*}$ 是定义在 $V$ 上的非负需求函数，仓库点集 $D \subseteq V$ ，容量 $Q \in N^{*}$ 。

输出：l 条回路 $C_{1}, C_{2}, \cdots, C_{l}$ ，使得 $V \subseteq \bigcup_{i=1}^{l} \overline{R}(C_{i})$ ，每条回路 $C_{i}$ 从任一仓库出发，最终返回至该仓库，且 $\sum_{v \in \overline{R}(C_{i})} d(v) \leq Q, i = 1, \ldots, l$ 。

目标：最小化 $l$ 条回路的总长度，即最小化 $\sum_{i=1}^{l} c(C_i)$ 。

数学语言描述为:

$$
\begin{array}{c} \min \sum_ {i = 1} ^ {l} c (C _ {i}) \\ s. t. V \subseteq \bigcup_ {i = 1} ^ {l} \overline {{R}} (C _ {i}) \\ \sum_ {v \in \overline {{R}} (C _ {i})} d (v) \leq Q, i = 1, \dots , l \end{array}\tag{2-6}
$$

## 第 3 章 非固定终点多仓库带容量约束弧路径问题

在本章中，我们将求解非固定终点MCVRP[26]的算法进行了推广，以此来解决非固定终点MCARP。我们的算法称为NMCARP $(\beta)$ 。通过利用CARP(无三角不等式的情形)的结果[23],给出了比较简单的描述。此处的 $\beta$ 表示求解CARP问题的近似比。设 $G = (V,E)$ 是非固定终点MCARP的初始图， $D\subseteq V$ 为仓库集。NMCARP $(\beta)$ 利用求解CARP的 $\beta$ -近似算法作为子程序，并且可以分成两个阶段。第一阶段是将图 $G$ 的仓库集 $D$ 收缩成单个仓库点 $d$ ，从而产生新图 $G^{\prime}$ 。利用CARP的 $\beta$ -近似算法获得一个由若干条起始于 $d$ 并且终止于 $d$ 的路径的解。算法的第二阶段是将收缩形成的仓库点 $d$ 展开成为初始仓库集 $D$ ，从而构造出非固定终点MCARP的一个可行解。以下是该算法的具体描述。

## 算法 $NMCARP(\beta)$

输入：无向图 $G = (V, E)$ ， $c: E \to N^{*}$ 是定义在 $E$ 上的非负费用（或长度）函数， $d: E \to N^{*}$ 是定义在 $E$ 上的非负需求函数，仓库点集 $D \subseteq V$ ，容量 $Q \in N^{*}$ 。

输出：l 条路径 $P_{1}, P_{2}, \cdots, P_{l}$ ，使得 $R \subseteq \bigcup_{i=1}^{l} R(P_{i})$ ，每条路径 $P_{i}$ 从任一仓库出发，最终可返回至任意仓库，且 $\sum_{e \in R(P_{i})} d(e) \leq Q, i = 1, \ldots, l$ 。

步骤1 由图 $G = (V, E)$ 得到另一个图 $G' = (V', E')$ ，其中 $V' = \{d\} \cup (V \setminus D)$ ，任意边 $[u, v] \in E$ 都对应到边 $[u', v'] \in E'$ ，它们有同样的费用和需求，使得

$$
\left\{ \begin{array}{l l} u ^ {\prime} = u, v ^ {\prime} = v, \text {当} u, v \in V \setminus D \\ u ^ {\prime} = u, v ^ {\prime} = d, \text {当} u \in V \setminus D, v \in D \\ u ^ {\prime} = d, v ^ {\prime} = v, \text {当} u \in D, v \in V \setminus D \\ u ^ {\prime} = v ^ {\prime} = d, \text {当} u, v \in D \end{array} \right.
$$

注意到，当我们将仓库点集 $D$ 收缩为单个仓库点 $d$ 时，可能会将两个端点都是仓库点的边也进行了收缩（上面最后一种情况），此时，边 $[u', v']$ 是 $G'$ 中的自环。

步骤2 运用定义在 $G'$ 上CARP的 $\beta-$ 近似算法，得到一个可行解，该可行解由 $l$ 条起始于仓库点 $d$ 并且终止于仓库点 $d$ 的回路 $C_1', C_2', ..., C_l'$ 组成。此外，不失一般性，我们可以假设 $C_i'$ 恰好经过 $d$ 两次（否则，我们可以将 $C_i'$ 拆分成若干条经过 $d$ 两次的回路）。

步骤3 对每条 $C_i'$ 的边 $[u', v']$ ，用其在 $G$ 中的对应边 $[u, v]$ 去替换它，从而获得 $G$ 中的路径 $P_i$ ，该路径的两个端点均在 $D$ 中（可能不是同一点）。

步骤 4 返回路径 $P_{1}, P_{2}, \cdots, P_{l}$ 。

引理3.1 $Z^{NMCARP(\beta)} \leq \beta Z_n^*$ 。

证明：设 $Z^{*}(G^{\prime})$ 是定义在 $G^{\prime}$ 上的CARP的最优值。可以看出，在将仓库点集 $D$ 收缩为一个仓库点 $d$ 后，对于非固定终点MCARP的可行解，可以在不增加费用的情况下，构造出定义在 $G^{\prime}$ 上的CARP的可行解。这意味着 $Z^{*}(G^{\prime}) \leq Z_{n}^{*}$ 。由定义可知，回路 $C_1', C_2', \cdots, C_l'$ 总长度至多为 $\beta Z^{*}(G^{\prime})$ 。可以观察到在步骤3中， $P_{1}, P_{2}, \cdots, P_{l}$ 的路径总长度和回路 $C_1', C_2', \ldots, C_l'$ 的总长度相等。因此， $Z^{NMCARP(\beta)} \leq \beta Z^{*}(G^{\prime}) \leq \beta Z_{n}^{*}$ 。于是该引理得证。

由文献 $^{[22,23,25]}$ 中的结果，存在CARP一个近似比为 $2+(1-\frac{2}{Q})\alpha_{0}$ 的算法 $UITP(\alpha_{0})$ ，以及一致需求情形一个近似比为 $1+(1-\frac{1}{Q})\alpha_{0}$ 的算法 $ITP(\alpha_{0})$ ，其中 $\alpha_{0}$ 是求解乡村邮递问题的近似比。结合引理3.1，得到以下结果。

定理3.1 对于非固定终点MCARP问题，存在一个 $(2 + (1 - \frac{2}{Q})\alpha_0) -$ 近似算法。如果需求是一致的，存在近似比为 $1 + (1 - \frac{1}{Q})\alpha_0$ 的算法。

注3.1 可以看到，我们的算法有一个非常简单的描述，这归功于无三角不等式的CARP的 $\beta$ -近似算法。尤其在构造 $G'$ 时，除了收缩仓库点集 $D$ ，我们无需改变边的需求和费用。相比之下，Li和Simchi-Levi[26]给出的非固定终点CVRP问题的迭代环游划分算法 $UITP_{n}(\alpha)$ ，必须通过计算 $G'$ 中所有顶点对之间的最短路并添加一些虚拟边来进一步修正边费用。因为他们的算法调用了CVRP问题的 $UITP(\alpha)$ 算法，该算法需满足三角不等式，而图 $G'$ 可能不满足三角不等式。

## 第 4 章 固定终点多仓库带容量约束弧路径问题

我们现在讨论固定终点 MCARP 问题，其中所有路径都需要从某一仓库出发，并最终回到该仓库。我们按照以下方式修改算法 $NMCARP(\beta)$ ，得到一个新的算法，称之为 $MUITP(\alpha_{0})$ 。

算法 $MUITP(\alpha_{0})$

输入: 无向图 $G = (V, E)$ , $c: E \to N^{*}$ 是定义在 $E$ 上的非负费用（或长度）函数, $d: E \to N^{*}$ 是定义在 $E$ 上的非负需求函数, 仓库点集 $D \subseteq V$ , 容量 $Q \in N^{*}$ 。

输出: $l$ 条回路 $C_{1}, C_{2}, \ldots, C_{l}$ , 使得 $R \subseteq \bigcup_{i=1}^{l} R(C_{i})$ , 每条回路 $P_{i}$ 从任一仓库出发, 最终返回至该仓库, 且 $\sum_{e \in R(P_{i})} d(e) \leq Q$ , $i = 1, \ldots, l$ 。

首先，我们用上文所提到的算法 $UITP(\alpha_{0})$ 替换步骤2中的 $\beta$ -近似算法。然后，我们修改步骤4中生成的可行解，为固定终点MCARP推导出可行解。设 $P_{i}=d_{1}^{(i)},v_{1}^{(i)},...,v_{r_{i}}^{(i)},d_{2}^{(i)}$ 为第i条路径，

$$
c \left(P _ {i}\right) = c _ {s} \left(d _ {1} ^ {(i)}, v _ {1} ^ {(i)}\right) + \sum_ {h = 1} ^ {r _ {i} - 1} c _ {s} \left(v _ {h} ^ {(i)}, v _ {h + 1} ^ {(i)}\right) + c _ {s} \left(v _ {r _ {i}} ^ {(i)}, d _ {2} ^ {(i)}\right),
$$

其中 $d_{1}^{(i)}, d_{2}^{(i)} \in D$ 为仓库点， $v_{h}^{(i)} \in V \setminus D (h = 1, \cdots, r_{i})$ 。将 $P_{i}$ 修改为 $C_{i}$ ，其定义如下：如果 $d_{i}^{(i)} = d_{2}^{(i)}$ ，那么 $P_{i}$ 是可行的，我们令 $C_{i} = P_{i}$ ，否则， $P_{i}$ 将由以下回路替换

$$
C _ {i} = \left\{ \begin{array}{l l} d _ {1} ^ {(i)}, v _ {1} ^ {(i)},..., v _ {r _ {i}} ^ {(i)}, d _ {1} ^ {(i)}, \text {当} c _ {s} (d _ {1} ^ {(i)}, v _ {1} ^ {(i)}) + c _ {s} (d _ {1} ^ {(i)}, v _ {r _ {i}} ^ {(i)}) \leq c _ {s} (d _ {2} ^ {(i)}, v _ {1} ^ {(i)}) + c _ {s} (d _ {2} ^ {(i)}, v _ {r _ {i}} ^ {(i)}); \\ d _ {2} ^ {(i)}, v _ {1} ^ {(i)},..., v _ {r _ {i}} ^ {(i)}, d _ {2} ^ {(i)}, \text {当} c _ {s} (d _ {1} ^ {(i)}, v _ {1} ^ {(i)}) + c _ {s} (d _ {1} ^ {(i)}, v _ {r _ {i}} ^ {(i)}) > c _ {s} (d _ {2} ^ {(i)}, v _ {1} ^ {(i)}) + c _ {s} (d _ {2} ^ {(i)}, v _ {r _ {i}} ^ {(i)}). \end{array} \right.
$$

为了分析算法 $MUITP(\alpha_0)$ 的性能，我们定义 $L^*$ 为步骤2中关于 $G'$ 的最优乡村邮递员环游的费用。换句话说， $L^*$ 是 $G'$ 中遍历仓库点 $d$ 和所有需求边的最短回路的长度。 $L(\alpha_0)$ 是算法 $UITP(\alpha_0)$ 使用的 $\alpha_0$ -近似乡村邮递员环游的费用。显然， $L(\alpha_0) \leq \alpha_0 L^*$ 。此外，根据算法 $UITP(\alpha_0)$ 的运行过程可得， $\sum_{i=1}^{l} \sum_{h=1}^{r_i-1} c_s(v_h^{(i)}, v_{h+1}^{(i)}) \leq L(\alpha_0)$ 成立。

引理4.1 $Z^{MUTP(\alpha_0)}\leq (2 + (2 - \frac{2}{Q})\alpha_0)Z^*$ 。

证明：类似于MCVRP的 $ITP_{f}(\alpha)$ 算法的分析，我们能够证明 $c(C_i)\leq c(P_i) + \sum_{h = 1}^{r_i - 1}c_s(v_h^{(i)},v_{h + 1}^{(i)})$ ，因此

$$
Z ^ {M U I T P (\alpha_ {0})} \leq (2 + (1 - \frac {2}{Q}) \alpha_ {0}) Z _ {n} ^ {*} + L (\alpha_ {0}) 。
$$

(4-1)

其中 $L(\alpha_0)$ 是算法 $UITP(\alpha_0)$ 使用的乡村邮递员环游的长度。由于 $Z_{n}^{*}\leq Z^{*}$ ，从而 $L(\alpha_0)\leq \alpha_0L^*\leq \alpha_0Z^*$ ，到此引理的证明完成。

通过上述算法 $MUITP(\alpha_{0})$ 中用 $ITP(\alpha_{0})$ 替换 $UITP(\alpha_{0})$ ，我们还可以得到一致需求情形下固定终点 MCARP 的近似比为 $1+(2-\frac{1}{Q})\alpha_{0}$ 。因此，我们得到以下关于固定终点 MCARP 问题的结果。

定理 4.1 对于固定终点 MCARP 问题，存在一个 $(2+(2-\frac{2}{Q})\alpha_{0})$ -近似算法。如果需求是一致的，存在 $(1+(2-\frac{1}{Q})\alpha_{0})$ -近似算法。

## 第 5 章 多仓库乡村邮递员问题（MRPP）

## 5.1 MRPP 问题的近似算法

在本节中，我们考虑了多仓库乡村邮递员问题，这是MCARP问题车辆负载无限的情形，即 $Q=+\infty$ 。假设有 $k=|D|$ 个仓库点，然后，MRPP基本上可以找到k条回路，每条回路都起始并终止于不同的仓库点，这些回路覆盖了所有的需求边并且总费用最小。

在本节的其它部分，我们假设输入图 $G = (V, E)$ 满足 $V = V(R) \cup D$ 和 $V(R) \cap D = \varnothing$ ，即每个顶点要么是仓库点，要么是某条需求边的一个端点。否则，我们可以把一般问题归约到这种情形[24,33,34]。此外，我们还假设了 $k \geq 2$ 。因为当 $k = 1$ 时，MRPP问题是乡村邮递员问题，正如引言中所描述的，该问题存在3/2-近似算法。

接下来我们将给出两个 MRPP 算法。最后，我们选择这两个算法中较好的解，第一个算法的描述如下。

## 5.1.1 算法 MRPP1

现在我们给出 MRPP 的第一个算法，算法的步骤由图 5.1 中的一个例子来说明。

输入：无向图 $G = (V, E)$ ， $c: E \to N^*$ 是定义在 $E$ 上的非负费用（或长度）函数，包含 $k$ 个顶点的仓库点集 $D \subseteq V$ 。

输出：k 条回路 $C_{1}, C_{2}, \cdots, C_{k}$ ，使得 $R \subseteq \bigcup_{i=1}^{k} R(C_{i})$ ，每条回路 $C_{i}$ 从一个不同的仓库出发，最终返回至该仓库。

步骤1 通过将 $G$ 中需求边 $[u_i, v_i] \in R$ 收缩成一点 $n_i$ ，得到图 $G_1$ ，顶点集为 $N \cup D$ ，其中 $N = \{n_i | i = 1, \dots, |R|\}$ 。然后，我们通过将边 $[u, v]$ 的费用设置为 $G_1$ 中 $u, v$ 间最短路长度 $\overline{c}(u, v)$ ，得到关于顶点集 $N \cup D$ 上的完全图 $\overline{G}$ 。

步骤2 对于图 $\overline{G}$ ，寻找一个最小权约束生成森林 $F$ ，即最小权生成森林中的每棵树都包含一个不同的仓库点。

步骤3 对 $F$ 中的奇度点，计算其最小费用完美匹配 $M$ 。将 $M$ 添加到 $F$ 中得到一个至多有 $k$ 个连通分支的偶图 $F_{1}$ ，将 $F_{1}$ 中边费用替换为 $G_{1}$ 中相应最短路，得到另一偶图 $F_{2}$ 。

步骤4 在 $F_{2}$ 中，我们将 $N$ 中的顶点 $n_i$ 展开为 $G$ 中相应的需求边 $[u_i, v_i]$ ，得到图 $F_{3}$ 。任意边 $[u_i, v_i] \in R$ 对应点 $n_i \in N$ ，若 $u_i$ ， $v_i$ 都是 $F_{3}$ 中的奇度点，我们称 $[u_i, v_i]$ 为奇度边，将该边复制一次。这将产生偶图 $\widehat{F}$ ，它包含 $p (p \leq k)$ 个连通分支。

![](04-廖玉婕_images/38aafdb92a9db2b6caba94fd5ebd18bd5514ef3825a65d9d53c614845fd18c27.jpg)  
图5.1 算法MRPP1的一个例子  
Fig. 5.1 An example for Algorithm MRPP1

说明：图（d）中的虚线表示 $M$ 中的匹配边；图(f)中的点虚线是边 $[u_5, v_5]$ 的复制边，目的是为了得到偶图。

步骤5 对于 $j = 1,\dots,p$ ，计算 $\widehat{F}$ 中第 $j$ 个连通分支的欧拉圈 $C_j$ ，输出路径 $C_1,\dots,C_p$ 。

下面将证明以上算法在多项式时间内运行，并输出了 MRPP 的可行解。

引理5.1 算法MRPP1能够在 $O(|V|^3)$ 时间内输出问题的可行解。

证明：可以发现,通过以上算法构造，最终输出的回路 $C_{1},\cdots,C_{p}$ 覆盖了R中的所有边并且每条回路都包含一个不同的仓库点。在步骤3中，由于图 $F_{2}$ 为偶图，于是任意需求边 $[u_{i},v_{i}]\in R$ ，顶点 $u_{i},v_{i}$ 在图 $F_{3}$ 中的度有相同的奇偶性，如果是奇度边，我们就将它复制一次。因此， $\widehat{F}$ 为欧拉图。故算法MRPP2能够输出可行解。

接下来考虑算法 MRPP1 的复杂度。在步骤 1 和 3 中，计算两点间的最短路和 F 上奇度点的最小费用完美匹配所用时间为 $O(|V|^{3})^{[35]}$ ; 步骤 2 中，计算最小费用约束生成森林是对 Kruskal 算法的调整，所需时间为 $O(|V|^{2} \log |V|)$ ；步骤 5 中，找到欧拉环游所需时间为 $O(|V|^{2})^{[24,36]}$ 。因此，算法 MRPP1 的复杂度为 $O(|V|^{3})$ 。

设 $C^*$ 是MRPP的最优值，接下来我们分析算法的性能。我们需要用到 $\mathbf{Xu}$ 等[37]的结果。

引理 5.2 $^{[37]}$ 给定完全图 $\widetilde{G}$ ，其边权满足三角不等式，仓库个数 $k \geq 2$ 。如果 $\widetilde{F}$ 是 $\widetilde{G}$ 的最小权约束生成森林， $\widetilde{M}$ 是 $\widetilde{F}$ 上奇度点的最小权完美匹配，那么 $\widetilde{F}$ 和 $\widetilde{M}$ 的总费用为任意 $\widetilde{p} \leq k$ 个圈的总费用的 $2 - \frac{1}{k}$ 倍，这 $\widetilde{p}$ 个圈覆盖所有顶点并且都包含一个不同的仓库点。

现在我们能够给出路径 $C_{1},\ldots,C_{p}$ 总费用的上界。

引理5.3 如果 $k \geq 2$ ，那么 $\sum_{j=1}^{p} c(C_j) \leq (2 - \frac{1}{k})c(C^*) + \frac{1}{k}c_R(C^*)$ 。

证明：可以看出， $C^*$ 中的非需求边对应于 $\overline{G}$ 的约束生成森林，这意味着 $c(F)\leq c(C^{*}) - c_{R}(C^{*})$ 。此外， $C^*$ 中的非需求边也包含至多 $k$ 个覆盖 $\overline{G}$ 中所有顶点的圈，每个圈都包含一个不同的仓库点。由引理5.2可得，

$$
c (F _ {2}) = c (F _ {1}) = c (F) + c (M) \leq (2 - \frac {1}{k}) (c (C ^ {*}) - c _ {R} (C ^ {*})).\tag{5-1}
$$

我们将继续推导第4步所添加奇度边的总费用的上界。由于 $F_{3}$ 是通过将 $F_{2}$ 中 $R$ 的边弹开所得，因此 $c(F_{3}) \leq c(F_{2}) + c(R)$ 。为了生成 $\widehat{F}$ ，将 $R$ 中奇度边复制一次，也就意味着

$$
c (\widehat {F}) \leq c (F _ {3}) + c (R) \leq c (F _ {2}) + 2 c (R) 。\tag{5-2}
$$

因此，

$$
\begin{array}{r l} \sum_ {j = 1} ^ {p} c (C _ {j}) & \leq c (\widehat {F}) \\ & \leq (2 - \frac {1}{k}) (c (C ^ {*}) - c _ {R} (R ^ {*})) + 2 c (R) \\ & \leq (2 - \frac {1}{k}) c (C ^ {*}) + \frac {1}{k} c _ {R} (C ^ {*}), \end{array}\tag{5-3}
$$

其中第一个不等式可由（5-1）和（5-2）得，第二个不等式是因为 $c(R) \leq c_{R}(C^{*})$ 。

注1 由于 $F_{2}$ 是偶图，所以我们将 $n_i$ 展开得到边 $[u_i, v_i]$ 时，端点 $u_i$ ， $v_i$ 具有相同的度。

## 5.1.2 算法 MRPP2

现在我们给出 MRPP 的第二种算法，算法的步骤由图 5.2 中的一个例子来说明。

输入：无向图 $G = (V, E)$ ， $c: E \to N^*$ 是定义在 $E$ 上的非负费用（或长度）函数，包含 $k$ 个顶点的仓库点集 $D \subseteq V$ 。

输出：k 条回路 $C_{1}, C_{2}, \cdots, C_{k}$ ，使得 $R \subseteq \bigcup_{i=1}^{k} R(C_{i})$ ，每条回路 $C_{i}$ 从一个不同的仓库出发，最终返回至该仓库。

步骤 1 由图 G 构造一个加权图 $G_{0}=(V\cup D',E_{0})$ ，其中 $D'=\{d_{1}',\cdots,d_{k}'\}$ 是通过复制 $D=\{d_{1},\cdots,d_{k}\}$ 所得， $d_{i}'$ 对应 $d_{i}$ ， $E_{1}=\left\{[u,v]\mid \text{至少有一个不在}D\cup D'\text{中}\right\}$ ， $E_{2}=\left\{[d_{i},d_{i}^{\prime}]\mid i=1,\cdots,k\right\}$ 。任意边 $[u,v]$ 的权重等于 G 中 u，v 间最短路长度， $E_{2}$ 中的边费用定义为 0。

![](04-廖玉婕_images/4fac90cd66fc4a0487b0a281e692235853d8085beaf1af626aacd95604b519db.jpg)  
图5.2 算法MRPP2的一个例子  
Fig. 5.2 An example for Algorithm MRPP2

说明：在图(c)中， $\forall d_i' \in D$ 与 $d_i \in D$ 合并为一点。在图(e)中，点状边表示 $E'$ 中的边。

步骤2 寻找 $G_{0}$ 的一个最小费用完美匹配 $M$ 。设 $M_{0} = M \cap E_{2}$ ， $M_{1} = M \setminus M_{0}$ 。任意边 $(u, v) \in M_{1}$ 对应 $G$ 中 $u$ 到 $v$ 的最短路 $P_{u,v}$ 。将所有点对 $u$ ， $v$ 对应的最短路 $P_{u,v}$ 添加至图 $H_{0} = (V, R)$ ，得到 $G$ 的生成子图 $H$ 。假设 $H$ 包含 $q$ 个连通分支 $F_{1}, \cdots, F_{q}$ ，每个连通分支都是欧拉图，前 $l \leq q$ 个连通分支至少包含一个仓库点。

步骤3 找到一个最小费用非需求边子集 $E'$ ，使得任意 $\nu \in V \setminus D$ 都有一条 $\nu$ 到一些仓库点的路，这可以通过以下类似于 Kruskal 的算法流程来实现。从 $F_1, \cdots, F_q$ 开始，在两个不同的连通分支间添加一条最小费用边，该最小费用边需满足所连接的两个不同连通分支中至少有一个不包含仓库点。当形成一个含有 $l$ 个连通分支的生成子图 $H_1$ 时，程序终止。通过复制 $H_1$ 的边子集 $E'$ ，我们得到一个含有 $l$ 个连通分支 $F_1', \cdots, F_l'$ 的生成子图 $H_2$ 。每个连通分支都包含一个仓库点，并且均为欧拉图。令 $C_j'(j=1, \cdots, l)$ 为 $F_j'$ 的欧拉圈。

步骤 4 输出路径 $C_{1},\cdots,C_{l}^{\prime}$ 。

下面将证明以上算法在多项式时间内运行，并输出了 MRPP 的可行解。

引理5.4 算法MRPP2能够在 $O(|V|^3)$ 时间内输出问题的可行解。

证明：可以发现,通过以上算法构造，最终输出的回路 $C_{1}^{\prime},\cdots,C_{l}^{\prime}$ 覆盖了R中的所有边并且每条回路都包含一个不同的仓库点。在图 $H_{1}$ 中， $M_{1}$ 中的匹配边被替换为它在图G中相应点之间的最短路，得到图H。于是，H的每个连通分支都含有欧拉环游。步骤3中，我们将 $E^{\prime}$ 复制一次，确保了 $H_{2}$ 的欧拉性。因此，算法MRPP2能够输出可行解。

下证该算法的复杂度。算法 MRPP2 的运行时间主要产生于步骤 1 中求图 $G_0$ 所有点对间的最短路，需要时间 $O(|V|^3)^{[35]}$ ，以及步骤 2 中寻找 $G_0$ 的最小费用完美匹配，需要 $O(|V|^3)^{[35]}$ 。步骤 3 所需时间为 $O(|E|\log |E|)$ 。综上所述，算法 MRPP2 的复杂度为 $O(|V|^3)$ 。

该算法得到的路径总费用将在以下引理中给出界定。

引理5.5 $\sum_{j = 1}^{l}c(C_j^{\prime})\leq 3c(C^*) - 2c_R(C^*)$ 。

证明：注意到 $C^*$ 的 $R$ 中需求边可能经过多次复制，我们确定其中的而一组复制边。那么 $C^*$ 中所固定的复制需求边端点间的所有路径都对应步骤1图 $G_0$ 的完美匹配。这个完美匹配的费用至多为 $c(C^*) - c(R)$ 。由于 $M$ 是最优的，这意味着 $c(M) \leq c(C^*) - c(R)$ 。根据定义知， $c(H) = c(M) + c(R) \leq c(C^*)$ 。可以验证， $C^*$ 中的非需求边可以连接至多 $l$ 个连通分支 $F_1, \dots, F_q$ ，使得任意非仓库点和仓库点间都存在一条路，这意味着 $c(E') \leq c(C^*) - c_R(C^*)$ 。根据步骤3和步骤4的构造，可以看出

$$
\begin{array}{r l} \sum_ {j = 1} ^ {l} c (C _ {j} ^ {\prime}) & \leq c (H _ {2}) = c (H) + 2 c (E ^ {\prime}) \\ & \leq c (C ^ {*}) + 2 (c (C ^ {*}) - c _ {_ R} (C ^ {*})) \\ & = 3 c (C ^ {*}) - 2 c _ {_ R} (C ^ {*}) . \end{array}\tag{5-4}
$$

由引理 5.3 和引理 5.5，算法 MRPP1 和算法 MRPP2 中较好解决方案的费用至多为

$$
\begin{array}{l} \min \left\{(2 - \frac {1}{k}) c (C ^ {*}) + \frac {1}{k} c _ {R} (C ^ {*}), 3 c (C ^ {*}) - 2 c _ {R} (C ^ {*}) \right\} \\ \leq (2 - \frac {1}{2 k + 1}) c (C ^ {*}), \end{array}\tag{5-5}
$$

当 $c_{R}(C^{*}) = \frac{k + 1}{2k + 1} c(C^{*})$ 时，等号成立。

通过以上讨论证明，我们得到以下结果。

定理 5.1 对于 MRPP 问题，存在一个 $(2-\frac{1}{2k+1})$ -近似算法。

## 5.2 极小-极大乡村邮递员覆盖问题的近似算法

本节中，我们研究的是极小-极大乡村邮递员覆盖问题（MMRPCP），它是MRPP问题的一个变形，没有仓库点，且目标为极小化至多 $k$ 条回路中最长的回路长度。此前，关于极小-极大乡村邮递员覆盖问题最好的结果为10-近似算法[40]，本节给出了改进的8-近似算法。给定MMRPCP的一个定义在 $G = (V, E)$ 上、需求边集为 $R$ 的实例 $I$ ，我们能够得到一个具有相同输入的实例 $I'$ ，只不过此处 $G$ 由 $G' = (V', E' \cup R)$ 替换，且 $G'$ 满足：

(1) $V' = V(R)$ ，即任意 $\pmb{v} \in V'$ 都是 $R$ 中某条边的端点；

（2）对任意 $u, v \in V'$ ，都有一条边 $[u, v] \in E'$ ，其费用为 $u, v$ 在 $G$ 中的最短路长度；

（3）对任意 $e = [u, v] \in R$ ， $u, v$ 间都有一条平行边，其费用与它在 $G$ 中的费用相等。此时，我们称 $G'$ 为 $G$ 的归约图。可以证明实例 $I$ 等价于实例 $I'$ ，具体过程可参见[24]，因此本节其余部分的讨论都是定义在归约图上。

现给出 $\alpha$ -子程序的定义。

定义 5.1 极小-极大乡村邮递员覆盖问题的一个多项式时间算法，若对 MMRPCP 的任一输入为 $G = (V, E)$ ， $R \subseteq E$ ，正整数 k 的实例，以及任意正整数 $\lambda \leq 2c(E)$ ，该算法要么输出失败，要么输出覆盖边集 R 且目标值至多为 $\alpha\lambda$ 的可行解，并且只要最优值 $\lambda^{*} \leq \lambda$ 时，就能输出问题的可行解，则称该算法为 $\alpha$ -子程序。

给定MMRPCP的 $\alpha$ -子程序，文献[40]证明了利用二分搜索可以得到该问题的 $\alpha$ 近似算法。

引理 5.7 $^{[40]}$ MMRPCP 任一运行时间为 $T(n)$ 的 $\alpha-$ 子程序，总能产生该问题的 $\alpha-$ 近似算法，运行时间为 $O(T(n)\log c(E))$ 。

为了得到MMRPCP的8-子程序，从而得到8-近似算法，需要借助以下文献[38]中图分解相关结论。

引理 5.8 $^{[38]}$ 给定一连通图 G 和正整数 B > 0，可以在 $O(|E|)$ 时间内将 G 分解为 k 个边不交的连通子图 $G_{1}, G_{2}, \cdots, G_{k}$ ，其中， $k \leq \max\left\{\left\lceil \frac{c(G)}{B} \right\rceil, 1\right\}$ ， $c(G_{i}) \leq 2B$ ， $i = 1, 2, \cdots, k$ 。

## 算法 MMRPCP( $\lambda$ )

输入：归约图 $G = (V, E)$ ，需求边集 $R$ ， $c: E \to N^*$ 是定义在 $E$ 上的非负费用（或长度）函数，正整数 $k$ ， $\lambda \in [0, 2c(E)]$ 。

输出：至多 $k$ 条回路 $C_1, C_2, \cdots, C_l (l \leq k)$ ，使得 $R \subseteq \bigcup_{i=1}^{l} R(C_i)$ 。

步骤 1 删去 $E \backslash R$ 中长度大于 $\lambda$ 的边，得到包含 p 个连通分支 $F_{1}, F_{2}, \cdots, F_{p}$ 的图 $G[\lambda]$ 。

步骤2 寻找每个连通分支 $F_{i}$ 的最小费用生成子图 $H_{i}$ ，使得 $R_{i} \subseteq E(H_{i})$ ，其中 $R_{i} = R \cap E(F_{i})$ ， $V(F_{i}) = V(R_{i})$ ， $i = 1, \ldots, p$ 。

步骤3 令 $B = 2\lambda$ ，对每个最小费用生成子图 $H_{i}$ 进行图分解，由引理5.8，得到 $k_{i}\leq \max \left\{\left\lceil \frac{c(G)}{2\lambda}\right\rceil ,1\right\}$ 个连通子图 $\left\{S_j^i\right\}_{j}$ ，且满足 $c(S_j^i)\leq 4\lambda$ 。将子图 $S_{j}^{i}$ 的所有边进行复制，得到欧拉图，它的欧拉回路记作 $C_j^i$ 。

步骤 4 如果 $\sum_{i} k_{i} \leq k$ ，则输出步骤 3 得到的覆盖 R 的可行解；否则，输出失败。

算法MMRPCP $(\lambda)$ 的内容如上文所述。步骤1中，删去长度大于 $\lambda$ 的边，得到 $p$ 个连通分支 $F_{1}, F_{2}, \ldots, F_{p}$ 。对于 $H_{i}$ ，利用图分解得到至多 $k_{i}$ 个子图，每个子图的费用不超过 $4\lambda$ 。如前文所述，用 $\lambda^{*}$ 表示MMRPCP问题的最优值，最优解 $\mathcal{C}^{*} = \{C_{1}^{*}, \ldots, C_{k}^{*}\}$ ，其中每个 $C_{j}^{*}$ 为最优回路。当 $\lambda^{*} \leq \lambda$ 时， $\mathcal{C}^{*}$ 中每条边的长度不超过 $\lambda$ ，且每个 $C_{j}^{*}$ 的所有顶点都包含在某个 $F_{i}$ 中。 $k_{i}^{*}$ 表示 $\mathcal{C}^{*}$ 中覆盖了 $F_{i}$ 中需求边的回路条数。

下面将证明以上算法能够在多项式时间内运行。

引理5.9 算法MMRPCP $(\lambda)$ 能够在 $O(|V|^2\log c(E))$ 时间内运行。

证明：步骤1中删去 $E \setminus R$ 中长度超过 $\lambda$ 的边，所需时间为 $O(|V|^2)$ 。步骤2中，寻找 $F_{i}$ 包含需求边集 $R_{i}$ 的最小费用生成子图 $H_{i}$ 所需时间为 $O(|V|^2)$ 。步骤3中，图分解所需时间为 $O(|E|)$ 。结合引理5.8，算法MMRPCP $(\lambda)$ 的运行时间为 $O(|V|^2 \log c(E))$ 。

接下来我们证明，当 $\lambda^{*} \leq \lambda$ 时，该算法输出问题的可行解。

引理 5.10 如果 $\lambda^{*} \leq \lambda$ ，那么对任意的 i，都有 $k_{i} \leq k_{i}^{*}$ 。

证明：为简单起见，设 $C_1^*, \cdots, C_{k_i^*}$ 为覆盖了 $F_i$ 的最优回路，其条数为 $k_i^*$ 。通过添加 $k_i^* - 1$ 条边，将 $k_i^*$ 条回路连到一起，并将所添加的边复制一次得到一个大回路。由于所加边得费用至多为 $\lambda$ ，因此， $\sum_{j=1}^{k_i^*} c(C_i^*) + (k_i^* - 1)\lambda \geq c(H_i)$ 。因为 $c(C_i^*) \leq \lambda$ ，又由引理5.8， $k_i \leq \max \left\{\left\lceil \frac{c(H_i)}{2\lambda} \right\rceil, 1\right\}$ ，从而 $k_i^* \geq k_i - \frac{1}{2}$ ，由于 $k_i^*$ 为正整数，于是引理得证。

引理5.11 当 $\lambda^{*} \leq \lambda$ ，算法MMRPCP(λ)输出至多 $k$ 条长度不超过 $8\lambda$ 的回路。

证明：步骤2中所得最小费用生成子图 $H_{i}, i = 1, \ldots, p$ 包含了需求边集 $R_{i}$ 。由引理5.10知， $\sum_{i=1}^{p} k_{i} \leq \sum_{i=1}^{p} k_{i}^{*} = k$ ，这意味着算法输出了包含 $R = \bigcup_{i=1}^{p} R_{i}$ 的极小-极大邮递员覆盖。由引理5.8，通过设置 $B = 2\lambda$ ，利用图分解所得子图 $S_{j}^{i}$ 的费用不超过 $4\lambda$ ，复制 $S_{j}^{i}$ 中的每条边得到回路 $C_{j}^{i}$ ，因此 $C_{j}^{i}$ 的费用不超过 $8\lambda$ 。于是该引理得证。

定理 5.2 对于 MMRPCP 问题，存在一个 8-近似算法。

## 第 6 章 线图上的多仓库带容量约束弧路径问题

## 6.1 线图上一致需求的多仓库带容量约束弧路径问题

本节中，我们将解决定义在线图上的 MCARP 问题。当需求一致时，我们证明了 MCARP 问题能够在 $O(n^{2})$ 时间内解决。

给定一线图 $L=(V,E)$ ，其中顶点集为 $V=\left\{v_{1},\cdots,v_{n}\right\}$ ，边集为 $E=\left\{(v_{i},v_{i+1})|i=1,\cdots,n-1\right\}$ 。假设仓库点集为 $d_{1}=v_{i_{1}},\cdots,d_{k}=v_{i_{k}}$ ， $i_{i}<i_{2}<\cdots<i_{k}$ 。可以发现，存在一个最优解决方案，其中以 $d_{j-1}$ 与 $d_{j}$ 为端点的边的需求始终由位于 $d_{j-1}$ 或 $d_{j}$ 的车辆服务， $j=1,\cdots,k+1$ （为了方便起见，我们定义 $d_{0}=v_{1}$ ， $d_{k+1}=v_{n}$ 为两个虚拟仓库点）。这是可行的，因为我们可以在仓库点处中断车辆路径，将新路径重新分配给车辆，以满足上述要求并且不增加总费用。因此，线图上的 MCARP 问题可以归约为同一问题的两种特殊情况。第一种称为半直线图上的 CARP 问题，其中，仓库点位于线图的某个端点处。第二种称为线图上的 2-仓库 CARP 问题，它的两个仓库点分别位于线图的两个端点处。

半直线图上的 CVRP 问题（即一个仓库点位于线图的某个端点处）已被证明是 NP 难的 $^{[3]}$ 。更糟糕的是，除非 P=NP $^{[28]}$ ，否则半直线图上 CVRP 问题的近似比不可能达到 3/2。

接下来，我们将考虑一致需求的情况。Archetti等[39]给出了半直线图上的CVRP问题可以用“最远距离原则”在 $O(n)$ 时间内求解。也就是说，第一辆车服务最远的 $Q$ 个顶点。紧接着第二辆车服务最远的 $Q$ 个未被服务过的顶点，依此类推，最后一辆车服务的顶点数可能少于 $Q$ 个。显然，同样的规则也适用于解决半直线图上一致需求的CARP问题，其需求是位于边上而不是顶点上。

对于线图上的一致需求的 2-仓库 CARP 问题，可以发现存在一个最优解，并且对应于仓库点 $d_{1}$ 的车辆路径和对应于仓库点 $d_{2}$ 的车辆路径不相交（但可能至多有一个公共顶点），这一点可以通过简单相邻交换来证明。因此，该问题可以简化为将该线图最优划分为两条不相交的半直线图，然后分别求解这两个半直线图上定义的两个子问题。因为存在至多 $n$ 个这样的划分，并且半直线图上的问题在 $O(n)$ 时间内是可解的。因此，线图上一致需求的 2-仓库 CARP 问题能够在 $O(n^{2})$ 时间内解决。

如前文所述，线图上一致需求的 MCARP 问题能够归约为半直线图上一致需求的 CARP 问题和线图上一致需求的 2-仓库 CARP 问题。于是我们得到以下结果。

定理 6.1 线图上一致需求的 MCARP 问题，能够在 $O(n^{2})$ 时间内求解。

## 6.2 线图上多仓库带容量约束车辆路径问题

本节中，我们研究了定义在线图上的MCVRP问题。我们首次给出了该问题的2-近似算法。以下是该算法的具体描述。

假设任意 $v \in V$ ，都有 $d(v) \leq Q$ ，否则就不存在可行解。在此之前，我们只需要关注半直线图上的 CVRP 问题和线图上的 2-仓库 CVRP 问题。对于半直线图上的 CVRP 问题，Wu 和 Lu 给出了 5/3-近似算法。

为了得到线图上2-仓库CVRP问题的近似算法，我们首先证明如何最优地解决一个松弛问题，该松弛问题称为线图上需求可分的2-仓库CVRP问题，其中顶点的需求可以被拆分，并由不同路径的车辆来服务。用一条由 $d(v) - 1$ 条零费用边连接 $d(v)$ 个单位需求的顶点所构成的路来替换每个顶点 $v$ 。我们可以推导出一个等价的线图上一致需求CVRP问题，并用上文提到的算法求解（这样得到的是线图上需求可分的2-仓库CVRP问题的一个拟多项式算法，因此需要考虑 $\sum_{v\in V}d(v)$ 个划分，但由以下引理6.1，我们实际上只需要考虑 $O(n^{2})$ 个划分，从而得到一个多项式时间算法）。然后，我们合并由零费用边所连接的顶点，得到需求可分问题的 $m$ 条回路 $C_1,\dots ,C_m$ ，其中 $C_1,\ldots ,C_p(C_{p + 1},\ldots ,C_m)$ 是包含 $d_{1}(d_{2})$ 的回路且 $C_p(C_m)$ 服务 $\nu_{1}(\nu_{n})$ ，并且当 $i < j$ 时，路径 $i$ 服务的顶点在路径 $j$ 所服务顶点的左侧。由于需求可分问题是原问题的松弛，于是有 $\sum_{j = 1}^{m}c(C_j)\leq Z^*$ 。对任意回路 $C_j$ ，由于我们使用的是“最远距离规则”，且满足 $d(v)\leq Q$ 故只有第一个和最后一个顶点可能有需求的拆分，且每个顶点的需求至多被拆分一次。因此，对于 $j$ 不等于1和 $p$ ，我们可以添加一条回路 $C_j^{\prime}$ 来单独服务 $C_j$ 的第一个顶点，删除 $C_j$ 中第一个和最后一个顶点的需求，生成另一条路径 $C_j^{\prime}$ 。对于 $j = 1$ 或 $p$ ， $C_j^{\prime}$ 的定义与此类似，但 $C_j^{\prime \prime}$ 是通过删去第一个顶点的需求得到的。显然，

$\max\left\{c(C_{j}^{'}),c(C_{j}^{n})\right\}\leq c(C_{j})$ ， $j=1,\cdots,m$ 。2m条新的回路 $C_{1}^{'},C_{1}^{n},\cdots,C_{m}^{'},C_{m}^{n}$ 构成了初始问题的一个可行解，其费用为

$$
\sum_ {j = 1} ^ {m} \left(c (C _ {j} ^ {\prime}) + c (C _ {j} ^ {\prime \prime})\right) \leq 2 \sum_ {j = 1} ^ {m} c (C _ {j}) \leq 2 Z ^ {*} \text { 。 }\tag{6-1}
$$

综上所述，我们得到以下结果。

定理 6.2 线图上的 MCVRP 问题存在一个 2-近似算法。

引理6.1 线图上需求可分的2-仓库MCVRP问题能够在 $O(n^{2})$ 时间内找到其最优划分。

证明：在线图的两个端点处均有一个仓库点，用 $d_{1}, d_{2}$ 表示，需求点用 $\nu_{i}$ 表示。给定该问题的一个可行解，设它的路线为 $C_{1}, \ldots, C_{p}, C_{p+1}, \ldots, C_{m}$ ，它们在 $\nu_{t}$ 处被分割，其中 $\nu_{t}$ 的需求一部分在 $C_p$ 中，另一部分在 $C_{p+1}$ 中。将可行解向右平移若干个单位，设平移后的路线为 $C_1', \ldots, C_p', C_{p+1}', \ldots, C_m'$ ，且能够满足以下三个条件之一：

(1) $\overline{R}(C_1') = Q$ ;

(2) $\exists i,1\leq i\leq p$ ， $C_{i}^{\prime}$ 服务的第一个顶点（设为 $v_{k}$ ）的需求没有被拆分；

(3) $\exists j, p + 1 \leq j \leq m'$ , $C_{j}^{\prime}$ 服务的第一个顶点（设为 $v_{l}$ ）的需求没有被拆分。

## 第7章 总结与展望

本文中，我们研究了多仓库带容量约束弧路径问题(MCARP)的近似算法和多项式算法。与经典的弧路径问题不同,本文所研究的弧路径问题具有多个仓库点，我们既考虑了车辆路径必须终止于起始仓库点的模型，也研究了车辆路径可以终止于不同于起点的仓库点的情况。然后，我们讨论了弧路径问题车辆容量无限的情形，即多仓库乡村邮递员问题(MRPP)。最后，我们证明了定义在线图上等需求的MCARP问题是多项式可解的，还给出了定义在线图上的MCVRP问题的2-近似算法。本文的工作主要分为以下几个方面：

1. 对于非固定终点的 MCARP 问题，我们首先将多个仓库点收缩为一点，然后调用了 CARP 问题的 $\beta$ -近似算法，最后将收缩的仓库点展开，得到 MCARP 问题的可行解。从而得到该问题的近似比为 $2 + (1 - \frac{2}{Q})\alpha_0$ 的算法，如果需求是一致的，得到 $(1 + (1 - \frac{1}{Q})\alpha_0) -$ 近似算法。

2. 针对固定终点的 MCARP 问题，我们通过将上一节步骤 2 中 $\beta$ -近似算法替换为算法 $UITP(\alpha_{0})$ ，修正了 $NMCARP(\beta)$ ，得到固定终点 MCARP 问题的 $(2 + (2 - \frac{2}{Q})\alpha_{0})$ -近似算法，如果一致需求，存在 $(1 + (2 - \frac{1}{Q})\alpha_{0})$ -近似算法。

3. 针对 MRPP 问题，我们给出了两种近似算法。对于算法 MRPP1，我们利用约束生成森林和最小权完美匹的想法，得到 3-近似算法；对于算法 MRPP2，采用最小权完美匹配的思想，得到 2-近似算法。利用算法构造可行解的互补性，最终我们得到 $(2-\frac{1}{2k+1})$ -近似算法。对于极小-极大乡村邮递员覆盖问题，我们给出了 8-近似算法。

4. 对于定义在线图上等需求的 MCARP 问题，我们通过将该问题分解为半直线图上的 CARP 和线图上的 2-仓库 CARP 问题两个子问题，证明了该问题能够在 $O(n^{2})$ 时间内求解。对于定义在线图上一般需求的 MCVRP 问题，我们通过研究该问题的松弛问题-需求可分情形，获得了该问题的 2-近似算法。

今后，我们还可以考虑 MCARP 问题在树、圈、星图这类图上的近似算法，以及它们的整数规划模型。
