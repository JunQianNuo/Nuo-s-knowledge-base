# 异构车队多中心交付的低碳车辆路径问题与算法

梁永宏，葛显龙，王 博，程梦丹，张洛彬

（重庆交通大学 经济与管理学院，重庆 400074）

摘要:针对前置仓配送模式面临的“一地多仓、末端交叉、高成本、高排放”难题,提出异构车队多中心横向协同配送模型。通过引入考虑速度、时间、距离、载重和发动机等因素的异构车队综合碳排放函数,将碳排放成本、司机成本和派车成本通过线性加权方式转换为目标函数 设计含特殊头部结构和染色体编码机制的改进遗传算法 引入交叉算子和动态权重调整机制以实现解空间的高效搜索 研究结果表明 相比传统前置仓横向转移补货调度 异构车队多中心横向协同补货调度在总成本方面减少 ％, 排放量减少 ％,车辆使用数节约 ％;随着协同客户占总客户的比例增加 总成本进一步减少 相较碳排放成本 派车成本 司机成本在总成本中占较大比例 需引起物流企业重视。

关 键 词:交通工程;低碳车辆路径问题;多中心配送;异构车队;综合模态排放模型;改进遗传算法

# Low-CarbonVehicleRoutingandAlgorithmfor HeterogeneousFleetMulti-DepotDelivery

LIANG Yonghong, GE Xianlong, WANG Bo, CHENG Mengdan, ZHANG Luobin

(SchoolofEconomicsandManaement,Chon in Jiaoton Universit,Chon in 400074,China)

Abstract: Aiming at the problem of "multiple warehouses in one location, terminal chiasmas, high cost and high emissions" faced by the front distribution center delivery mode, a multi-depot lateral collaborative distribution model for heterogeneous fleets was proposed. By introducing the heterogeneous fleet comprehensive carbon emission function which considered factors such as speed, time, distance, load and engine, the carbon emission cost, driver cost and dispatch cost were converted into an objective function by linear weighting. An improved genetic algorithm with special head structure and chromosome coding mechanism was designed, and a crossover operator and dynamid weight adjustment mechanism were introduced to achieve efficient search in solution space. The research results show that compared with the traditional front warehouse lateral replenishment scheduling, the heterogeneous fleet multi-depot lateral collaboralive replenishment scheduling reduces the total cost by 39. 1% , reduces the CO, emission by 12. 5% and saves the number of vehicles by 27. 2%. As the proportion of collaborative customers to total customers increases. the total cost further decreases. Compared to carbon emission costs and dispatch costs. driver costs account for a larger proportion of the total cost, which needs to be paid attention to by logistics companies

Kev words: traffic engineering; low-carbon vehicle routing problem; multi-depot distribution; heterogeneous fleet: comprehensive modal emission model; improved genetic algorithm

## 0 引 言

前置仓（front distribution center， FDC）配送模式凭借客户与商品之间较短的距离 较快的响应时间在电商物流末端配送中得到广泛应用。 以往关于前置仓调度的优化研究大多围绕订单拆分、需求转移、两级配送展开，无法很好地解决“一地多仓、末端交叉、高成本、高排放”等难题。 基于此，笔者提出传统的低 碳 车 辆 路 径 问 题 （ low carbon vehicle routingproblem， LCVRP）探讨将排放指标引入到目标函数或<sub>者作为独立目标进行优化建模</sub>［1］ <sub>综合模态排放模</sub>型（comprehensive modal emission model，CMEM） 是一种考虑速度、时间、旅行距离、载重和发动机等因素的新型燃油卡车排放评估模型。 自从 CMEM 被提出以来 基于 的低碳车辆路径问题的研究大量涌<sub>现 例如 等</sub>［2］ <sub>等</sub>［3］<sub>设计自适应</sub>大邻域搜索算法（ adaptive large neighborhood search，ALNS）；E． DEMIR 等<sup>［4］</sup>、R． KRAMER 等<sup>［5］</sup>提出用速度优 化 算 法 （ speed optimization algorithm， SOA ）； A．FRANCESCHETTI 等<sup>［6］</sup>提出了出发时间和旅行速度优化算法；Y．SUZUKI<sup>［7］</sup>提出了双目标优化问题；张如云等<sup>［8］</sup>提出了时间依赖性 LCVRP 问题等。

随着城市规模的不断扩大 单中心配送模式已无法满足城市大规模客户配送服务的请求 更多学者关注多中心配送问题 （ multi⁃depot vehicle routingproblems， MDVRP）。 例如，WANG Xingyin 等<sup>［9］</sup>提出了需求可拆分的多车场车辆路径问题等<sup>［10］</sup>构建了多车场多车仓车辆路径问题；范厚明<sub>等</sub>［11］<sub>提出的生鲜末端半开放式多配送中心联合配</sub>送模式；陈沿伊等<sup>［12］</sup>建立了考虑综合模糊时间窗和速度时空系数的多车场多车型生鲜配送路径优化模型；LI Yongbo 等<sup>［13］</sup> 建立了多车场绿色车辆路径问题模型；A． SOEANU 等<sup>［14］</sup> 以最小化路径总成本和交付失败潜在风险成本为目标函数建立多车场车辆路径问题模型；王勇等<sup>［15］</sup>针对多中心共同配送与收集网络联盟优化问题 建立了网络运营总成本最小和配送与收集车辆使用数量最少的双目标优化模型在 异 构 车 队 配 送 （ vehicle routing problems withheterogeneous fleet， VRPHF） 研究方面，葛显龙等<sup>［16］</sup>采用量子遗传算法对考虑固定费用和油耗费用最小化的多车型车辆路径问题进行求解；徐东洋等<sup>［17］</sup> 提出了同时考虑多车场、多车型、多货品、客户间供需未匹配和需求可拆分的取送货车辆路径问题模型，并设计基于大规模邻域搜索的迭代局部搜索求解算法。

上述研究在 LCVRP、MDVRP 和 VRPHE 方面的建模与求解算法设计等方面做出了巨大贡献，为异构车队多中心交付的低碳车辆路径问题研究奠定了基础。 但鲜有研究建立同时考虑多车型、多车场、带协同、带时间窗和 CMEM 的综合模型，且对碳排放模型中载重和距离的非线性关系线性化考虑较少 因此 笔者构建了考虑经济因素和碳排放的异构车队多中心交付的低碳车辆路径（multi⁃depot lowcarbon vehicle routing problems with heterogeneousfleet delivery and time windows， MDLCVRPHFTW）混合整数规划模型，设计包含特殊头部结构的改进遗传算法求解 并基于重庆某企业配送实例 验证了该方法的有效性。

## 1． 4 HF⁃CMEM 模型

根据文献［2］，对异构车队配送车辆的环境影响进行评估，提出基于异构车队综合排放模型（ heterogeneous fleet comprehensive modal emissionmodel， HF⁃CMEM）如下。

车辆燃料消耗率 $F _ { \mathrm { { R } } }$ 函数如式（1）：

$$
F _ {\mathrm{R}} = \xi (\kappa N V + p / \eta)\tag{1}
$$

P 的计算如式（2）：

$$

$$

式中： ${ \mathrm { : } } P _ { \mathrm { a } }$ 与发动机运行损失和车辆配件如空调和电气负载操作相关。

$$

PUPO 交叉时，Chr 头部区编码基因顺序可改变，主干区编码顺序不可改变。 首先，随机选择一对同源染色体作为亲代，分别对头部和主干区执行 PU和 PO 操作。 头部区部分通过结构比对进行均匀交叉，主干区部分保持 Chr 两端出发点 0 位置不变，在中段的0 点位置选择交叉起始点 s 和终点 t，作为优秀子串保留，然后通过部分删除和部分顺序插入操作产生下一代个体 同样的原理 的变异操作采用部分均匀和部分交换（ partial uniform and partialswap，PUPS）变异方式，分别在头部和主干区实行突变和 变异

## 2． 3． 2 头部结构修复

大量的交叉和变异操作后 子代 头部区的结构往往变成无效。 例如，一个 Chr 主干区配送客户为10，如果头部区编码之和为12，显然需要减少2个。 基于此，笔者提出一种循环修复操作算子，对头部区进行操作 具体如图 $4 _ { \circ }$

Step1 该算子在子代染色体头部区反复随机选择一个基因操作位点。

Step2 判断子代染色体头部区基因编码值是变大还是变小。

Step3 如变大，在随机选择的位点上，减去 $1 _ { \circ }$

Step4 再次判断变化后的子代 头部区基因编码值总和是否等于主干区客户总数，如相等，操作终止，如不相等，继续减去1，直到相等为止。

Step5 子代 Chr 头部区基因编码值小于主干区客户总数，则返回 Step2，加 1，继续判断，直到相等为止。

## 2．4 动态权重调整机制设计

由于目标函数中 载重和距离之间存在非线性关系，在 GA 的迭代程序中，引入动态权重调整机制进行线性化处理 假设碳排放最小化时目标函数最优解为 Solution A，运营成本最小化时的目标函数最优解为 Solution B，根据动态权重调整机制和式（6）的权重系数 当 $w _ { 1 } = 1$ $w _ { 2 } = 0$ 时 目标函数解的径向接近最优解 Solution A；当 $w _ { 1 } = 0$ $w _ { 2 } = 1$ 时，目标函数解的横向接近最优解 求解步骤具体为：

Step1 设置 $w _ { 1 } = w _ { 2 } = 1$ 并观察目标函数的收敛情况 如果重复迭代 次种群没有变化

Step2 设置 $w _ { 1 }$ 和 $w _ { 2 }$ 使得满足：随机确定 $w _ { 1 } \in$ ［0． 8，1． 2］， $w _ { 2 } = 2 - w _ { 1 }$ ，然后再迭代15 次。

Step3 恢复 $w _ { \mathrm { f } } = w _ { \mathrm { o } } = 1$ 设置，运行 500 次，终止算法迭代。

## 4 结 语

构建了考虑碳排放成本和车辆运营成本的异构车队多中心交付低碳车辆路径问题模型 设计了含特殊头部结构的编码 解码机制和带部分均匀与部分偏序交叉算子的改进遗传算法 在求解时加入权重调整策略 实现算法更好的寻优 笔者提出的异构车队前置仓多中心交付模式能有效降低企业配送总成本 且能实现环境友好的重要目标 研究发现客户规模与运输的碳排放成本 司机成本 总成本CO 排放量呈正相关，与协同客户占比负相关。 司机成本占总成本较大的比例 可通过适当减少车辆数而达到降本目标

由于笔者自建算例规模较大 大部分算例无法采用 等精确求解器获得最优解 不能验证改进遗传算法的求解精度 未来研究中应探索更高效精准的算法进行求解
