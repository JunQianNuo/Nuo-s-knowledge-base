# 2026年度“策联杯”选题分析

> [!success] 正式选题已锁定

> [!summary] 结论
> 在尚不了解团队特长、且以“按时形成可复现的完整论文”为首要目标时，推荐顺序为 **A > C > B**。
> - **默认推荐 A 题**：规模适中、四问闭环清晰、最容易完成统计—预测—优化的完整证据链。
> - **强 ML + 运筹团队可选 C 题**：上限较高，但数据表多、链路长，隐藏测试集和单位/归一化问题会增加风险。
> - **强组合优化团队才建议 B 题**：区分度最高，但本质是大规模、多约束、多阶段航班路径与排班问题，工程失败风险最大。

## 4. A题：锂离子电池寿命预测与快充策略优化

### 数学任务链

1. 49 块电池的纵向循环数据整理、寿命分布和典型策略识别；
2. 在策略参数相关、实验策略有限的条件下做效应分析和显著性检验；
3. 由前 150 次循环预测第 151—200 次 SOH，并外推 80% SOH 寿命；
4. 联合充电时间与寿命构建受数据邻域约束的多目标策略优化。

### 优势

- 只有两个核心数据表，变量与四问之间的数据流明确。
- “描述统计 → 影响分析 → 寿命预测 → Pareto 优化”形成天然论文主线。
- 基准模型容易建立，复杂模型可按验证结果逐级升级，不需要一开始就押注深度学习。
- 图表表达友好：SOH 曲线、寿命箱线图、参数效应图、预测区间、Pareto 前沿均能直接支撑结论。
- 即使高级模型提升有限，也能用可解释统计模型、分组/留一电池验证和不确定性分析形成完整成果。

### 主要风险

- 真正独立的实验单位只有约 49 块电池，不能把每个循环行误当成独立大样本；普通随机划分会造成电池级数据泄漏。
- $C_1,Q_1,C_2$ 并非独立变化，直接多元回归容易出现共线性和“相关当因果”。
- 9 块测试电池仅公开到第 150 次循环，EOL 外推的不确定性可能很大；应给区间而非只给点预测。
- 题目成熟、相关研究多，常规 XGBoost/LSTM 容易同质化；创新更适合放在层次建模、形状约束、概率寿命预测或稳健 Pareto 决策上。

### 适合团队

- 擅长 Python、统计分析、回归/时间序列；
- 希望用较低工程风险做出完整、可解释、可验证的论文；
- 截止时间较紧或团队人数较少。

### 初步可行路线（非最终模型选择）

电池级数据审计 → 策略分组与寿命估计 → 电池/策略层级统计基线 → 严格按电池划分的预测验证 → 单调/形状约束 SOH 外推 → 充电时间—寿命双目标与稳健性分析。

## 5. B题：海上油田直升机运载计划编排

### 数学任务链

1. 1600 条单向出海需求的分组、路径与机型选择；
2. 4000 条出海、海返、穿梭需求的联合装载与路径设计；
3. 将 24 架具体飞机、时间窗、优先级、机场周转、可选临时任务加入一周多日排班。

其本质接近：**多机场异构机队 + 取送一体车辆路径 + 容量/燃油/加油约束 + 最多五次海上着陆 + 时间窗 + 可选服务 + 多目标调度**。

### 优势

- 现实意义强，算法创新和队伍区分空间最大。
- 目标与硬约束明确，可自行编写严格的可行性校验器。
- 能形成很强的优化论文：下界、构造启发式、局部搜索/大邻域搜索、消融实验和多目标权衡。
- 若能在 4000 条需求和问题三的完整约束下稳定生成高质量可行解，成果辨识度很高。

### 主要风险

- 规模与约束组合非常重，不能简单把标准 VRP 模板套上去；直接建立全量精确 MILP 很可能超时或内存爆炸。
- 最难的不是“写出目标函数”，而是持续生成满足所有装载、停靠、燃油、时间窗、机场归属和人员不换乘条件的结果 CSV。
- 问题二到问题三不是小修补，而是从静态路径构造升级为多日机尾级排班。
- 需要先写独立 validator；否则路线看似优秀但一个索引、时间取整或余油错误即可使整套输出失效。
- 算法调参、性能优化和故障排查会显著挤压论文时间。

### 适合团队

- 至少一人熟悉 OR-Tools/Gurobi、VRP/PDP、列生成或 ALNS；
- 有较强工程实现能力，能维护路线状态、增量代价和可行性检查；
- 时间充足，愿意选择高风险高上限路线。

### 初步可行路线（非最终模型选择）

严格可行性校验器 → 需求聚类与机场分配 → 路线候选生成/装载匹配 → ALNS 或列生成式优化 → 问题三滚动时域机尾排班 → 下界、消融、多次随机运行和约束违例零容忍检查。

## 6. C题：世界杯预测、赛程与动态资源优化

### 数学任务链

1. 历史比赛的转播观看人数预测，测试集标签隐藏；
2. 对 72 场比赛、16 个场馆和 80 个候选时段进行多指标约束优化；
3. 用前两轮结果进行 20,000 次第三轮模拟，并优化转播、安保、交通和票价资源；
4. 采集一届已结束世界杯的实际赛程，与优化赛程做统一评价。

### 优势

- 数据分析、机器学习、整数优化、Monte Carlo 和综合评价兼具，展示面最丰富。
- 问题二、三给出了大量指标定义与公式，建模边界相对清楚，便于形成稳定实现。
- 任务链叙事完整：“预测需求 → 优化赛程 → 动态更新资源 → 现实赛程对照”。
- 各模块可由不同队员并行开发，适合三人团队。

### 主要风险

- 至少 13 个输入工作表，字段关联、单位、时区、标准化方向和缺失处理容易出错。
- 问题一真实测试标签不公开，模型选择失误无法通过官方标签即时纠正；必须严防时间泄漏和测试统计泄漏。
- 问题二的决策空间大，且黄金时段公平、休息间隔、场馆容量、安保和转播容量相互耦合。
- 问题三依赖前两问，任何单位或定义错误都会沿整条链路传播；“百万人”和“人”的输出单位尤其需要单独校验。
- 问题四还需可靠外部赛程及来源说明，增加数据采集与口径统一工作。
- 当前 OCR Markdown 中部分公式有识别错误，正式实现必须回看 PDF 与官方模板，不能直接复制 OCR 公式。

### 适合团队

- 一人擅长特征工程/预测，一人擅长 MILP/CP-SAT，一人擅长数据处理与论文；
- 希望兼顾完成度与技术丰富度，并能承担较长的联调链路；
- 有充足时间做端到端数据契约和一致性测试。

### 初步可行路线（非最终模型选择）

按日期的无泄漏预测基线 → 稳健特征与集成回归 → 预计算候选比赛—场馆—时段收益 → CP-SAT/MILP 赛程优化 → 固定随机种子的泊松晋级模拟 → 逐日资源分配优化 → 历史赛程标准化对照。

## 7. 情景化建议

| 团队/目标 | 建议题目 | 理由 |
|---|---|---|
| 不清楚团队优势，优先完成与稳健 | **A** | 数据链最短、验证路径最清楚 |
| 一人或两人，时间较紧 | **A** | 可用可解释基准形成完整闭环 |
| 强 ML + 强运筹，三人分工清晰 | **C** | 模块化好、展示丰富、上限较高 |
| 强 VRP/ALNS/列生成与工程实现 | **B** | 区分度最高，但必须先保证可行性 |
| 想避免预测隐藏标签风险 | **A 或 B** | C 的官方测试 MSE不可见 |
| 想避免超大规模组合优化 | **A** | B 的求解和 C 的赛程优化都更重 |
| 追求高风险高上限 | **B** | 算法质量能直接拉开差距 |

## 8. 最终建议

### 默认选择：A题

推荐理由不是“A题最简单”，而是它最容易同时满足以下四点：

1. 每问都有明确、可复现的数值产出；
2. 前一问的结果自然进入后一问，论文结构不会割裂；
3. 可以设置严格的电池级验证、时间外推检验和不确定性分析；
4. 即使复杂模型失败，仍有可靠的统计/曲线基准可回退。

### 备选：C题

若团队确有预测与整数优化双重能力，且能为数据字段、单位和跨问题接口写自动检查，C题的综合展示和创新空间优于A题。

### 谨慎选择：B题

只有在团队已有大规模路径规划经验，并能在正式优化前完成“结果文件可行性校验器”时，才建议选B题。否则最可能出现的情况是算法思路很漂亮，但最终 CSV 不完全可行。

## 9. 正式锁题前的附件门禁

取得附件后，先做 30—60 分钟快速审计：

- **A题**：核对 49 个电池 ID、9 个测试电池、策略重复数、寿命字段及 150/200 循环截断方式；
- **B题**：核对四个 CSV 和全部结果模板，先验证距离矩阵对称性、需求类型分布、时间窗可行率；
- **C题**：核对 13 个输入表、全部模板、训练/测试规模、日期划分、单位和主外键完整性。

附件不全时不得进入正式求解，也不应仅凭公开同名数据替代竞赛指定子集。
