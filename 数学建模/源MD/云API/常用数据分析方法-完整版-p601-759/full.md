## Cox 模型— 风险比解释与实例

## 风险比（Hazard Ratio, HR）的解释

模型： $h ( t | \mathbf { x } ) = h _ { 0 } ( t ) \exp ( \beta _ { 1 } x _ { 1 } + \cdot \cdot \cdot + \beta _ { p } x _ { p } )$

比较两个个体 A 和 B 的风险比：

$$
\mathrm{HR} = \frac {h (t | \mathbf {x} _ {A})}{h (t | \mathbf {x} _ {B})} = \exp \left[ \sum_ {j = 1} ^ {p} \beta_ {j} (x _ {A j} - x _ {B j}) \right]
$$

对单个变量 $X _ { j }$ （其他变量不变）：

• $X _ { j }$ 增加 1 个单位，风险变为原来的 $\exp ( \beta _ { j } )$ 倍

• $\exp ( \beta _ { j } ) > 1 \colon X _ { j }$ 越大风险越高（危险因素）

• $\exp ( \beta _ { j } ) < 1 : \ X _ { j }$ 越大风险越低（保护因素）

• $\exp ( \beta _ { j } ) = 1 \colon X _ { j }$ 对风险无影响

信息准则法（更客观）

AIC（Akaike Information Criterion）：

$$
\mathrm{AIC} = - 2 \ln L + 2 k
$$

其中 L 是似然函数值，k 是参数个数。选择AIC最小的模型。BIC（Bayesian Information Criterion）：

$$
\mathrm{BIC} = - 2 \ln L + k \ln n
$$

BIC对复杂度惩罚更重，倾向选择更简单的模型，大样本下更一致。

做法：在一定范围内（如 $p = 0 , 1 , \ldots , P , q = 0 , 1 , \ldots , Q )$ 穷举，选信息准则最小的。

• 特异度 $/ \mathbf { T N R } \colon \ \mathrm { T N R } = { \frac { \mathit { T N } } { \mathit { F P } + \mathit { T N } } }$

• 假阳性率/FPR：

$$
\mathrm{FPR} = \frac {F P}{F P + T N} = 1 - \mathrm{TNR}
$$

• 假阴性率 $/ \mathbf { F N R }$ ：

$$
\mathrm{FNR} = \frac {F N}{T P + F N} = 1 - \mathrm{TPR}
$$

• 准确率 $/ \mathbf { A c c u r a c y : }$ $\mathrm { A c c } = { \frac { T P + T N } { T P + F P + F N + T N } }$

• 阈值越高，TPR 越低、FPR越低；阈值越低，TPR 越高、FPR越高

## AUC的计算方法

方法一：梯形法（Trapezoidal Rule）

将ROC曲线上的点按 FPR从小到大排序： $( f _ { 0 } , t _ { 0 } ) , ( f _ { 1 } , t _ { 1 } ) , \dots , ( f _ { m } , t _ { m } )$ 用梯形面积求和近似曲线下面积：

$$
\mathrm{AUC} = \sum_ {i = 1} ^ {m} \frac {t _ {i - 1} + t _ {i}}{2} \cdot (f _ {i} - f _ {i - 1})
$$

这是最常用的数值计算方法。

## AUC的计算方法

方法一：梯形法（Trapezoidal Rule）

将ROC曲线上的点按 FPR从小到大排序： $( f _ { 0 } , t _ { 0 } ) , ( f _ { 1 } , t _ { 1 } ) , \dots , ( f _ { m } , t _ { m } )$ 用梯形面积求和近似曲线下面积：

$$
\mathrm{AUC} = \sum_ {i = 1} ^ {m} \frac {t _ {i - 1} + t _ {i}}{2} \cdot (f _ {i} - f _ {i - 1})
$$

这是最常用的数值计算方法。

方法二：Wilcoxon 秩和检验联系

设正样本有 $n _ { + }$ 个，负样本有 $n _ { - }$ 个。

将所有样本按评分从高到低排序，正样本的秩次为 $R _ { 1 } , R _ { 2 } , \ldots , R _ { n _ { + } }$ 。

Mann-Whitney U 统计量：

$$
U = \sum_ {i = 1} ^ {n _ {+}} R _ {i} - \frac {n _ {+} (n _ {+} + 1)}{2}
$$

AUC与 U统计量的关系：

$$
\mathrm{AUC} = \frac {U}{n _ {+} \cdot n _ {-}}
$$

此方法体现了AUC 的概率意义：正样本排在负样本前面的比例。
