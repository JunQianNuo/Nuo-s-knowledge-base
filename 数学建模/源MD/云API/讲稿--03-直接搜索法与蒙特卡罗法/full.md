## 1.2. 非线性规划模型的一般形式

在工程、经济、管理等各类实际问题中，我们抽象出的数学模型往往不是完美的线性关系。非线性规划模型的标准数学形式如下：

$$
\begin{array}{c} \min f (\mathbf {x}) \\ \text {s.t.} g _ {i} (\mathbf {x}) \leq 0, i = 1, 2, \dots , m \\ h _ {j} (\mathbf {x}) = 0, j = 1, 2, \dots , p \\ \mathbf {x} \in \mathbb {R} ^ {n} \end{array}\tag{1}
$$

其中：

$\mathbf { x } = [ x _ { 1 } , x _ { 2 } , . . . , x _ { n } ] ^ { T }$ ：称为决策向量，是我们需要求解的未知数集合（即系统的参数或方案）。

 ：称为目标函数，是我们希望优化的指标（如成本最低、收益最大、误差最小）。只要 中包含变量的二次方、三角函数、指数、对数或变量间的乘积，它就是非线性的。

$g _ { i } ( \mathbf { x } ) \leq 0$ ：称为不等式约束，代表了系统运行的安全边界、资源的限量或物理空间的限制（如反应温度不能超过熔点、资金预算有限）。

$\textbf { \textit { k } } _ { j } ( \mathbf { x } ) = 0$ ：称为等式约束，代表了系统必须严格遵循的物理定律或平衡条件（如质量守恒、能量守恒）。

 所有满足约束条件的 的集合，称为可行域（Feasible Region），记为 。我们的任务就是在 中找到使 最小的那个点。

## 1.3. 最优化模型实例

$$
\min _ {x _ {1}, x _ {2}} (x _ {1} - 3) ^ {2} + (x _ {2} - 2) ^ {2}
$$

s.t. $x _ { 1 } + 2 x _ { 2 } = 8 ,$

$$
x _ {1} + x _ {2} \leq 6,\tag{1}
$$

$$
2 x _ {1} - x _ {2} \geq 1,
$$

$$
x _ {1} ^ {2} + x _ {2} ^ {2} \leq 2 5,
$$

$$
x _ {1}, x _ {2} \geq 0.
$$

目标函数： 最小化 $f ( x _ { 1 } , x _ { 2 } ) = ( x _ { 1 } - 3 ) ^ { 2 } + ( x _ { 2 } - 2 ) ^ { 2 }$

约束条件：

1. 等式约束： $x _ { 1 } + 2 x _ { 2 } = 8$

2. 线性不等式约束 1： $x _ { 1 } + x _ { 2 } \leq 6$

3. 线性不等式约束 2： $2 x _ { 1 } - x _ { 2 } \geq 1$

4. 非线性约束： $x _ { 1 } ^ { 2 } + x _ { 2 } ^ { 2 } \leq 2 5$

5. 非负约束： $x _ { 1 } \geq 0 , x _ { 2 } \geq 0$

这个最优化模型具有以下特点：

1. 等式约束 $x _ { 1 } + 2 x _ { 2 } = 8$ ：将可行域限制在一条直线上

2. 线性不等式约束：两个线性约束进一步限制可行域

（直观展示哪些区域满足所有约束条件）

3. 非线性约束 $x _ { 1 } ^ { 2 } + x _ { 2 } ^ { 2 } \leq 2 5$ ：圆形约束，增加问题复杂度

4. 非负约束：符合实际应用场景

5. 目标函数：二次函数，表示到点 (3,2) 的距离平方

可行域是等式约束直线被其他约束条件截取的一段或几段线段，这使得问题既有实际意义又具有一定的求解难度。

## 1.4. 应用直接搜索法与蒙特卡罗法的必要性

分析与思考：既然是求极值，我们微积分里学过，求导令其等于零不就行了吗？为什么还要大费周章搞这些数值算法？

这就涉及到了传统解析法在非线性规划中面临的三大致命困境，这也是引入直接搜索法与蒙特卡罗法的根本必要性：

## 1.4.1. 困境一：黑盒函数与不可导性（引出直接搜索法）

在实际工程中， 往往不是一个写出解析式的数学公式，而是一个“黑盒”。比如，输入一组结构参数 ，返回的是有限元软件（如 ANSYS）跑出来的应力值；或者输入一组超参数，返回的是深度学习模型的准确率。

这种情况下，函数没有解析表达式，根本无法求导。传统的梯度下降法、牛顿法全部失效。此时，我们只能依靠直接搜索法——它不需要知道函数的导数信息，仅仅通过比较目标函数值的大小来决定下一步的搜索方向，是解决“黑盒优化”的唯一出路。

## 1.4.2. 困境二：多极值与局部最优陷阱（引出蒙特卡罗法）

非线性函数的曲面往往极其崎岖，布满了“坑坑洼洼”。传统的局部搜索算法（包括直接搜索法和梯度法）就像是一个“只看脚下”的盲人，很容易走入一个浅坑（局部极小值）就以为到了谷底，从而错失真正的深渊（全局极小值）。

对于多极值问题，搜索的起点极大地决定了最终的结果。如果只从某一个初始点出发，几乎必然陷入局部最优。蒙特卡罗法利用大数定律，通过在可行域内进行随机的大规模撒点，能够以极大概率逼近全局最优解，是打破局部最优陷阱的利器。

## 1.4.3. 困境三：复杂约束导致的可行域畸形

当非线性等式约束 $\textbf { \textit { k } } _ { j } ( \mathbf { x } ) = 0$ 和不等式约束 $g _ { i } ( \mathbf { x } ) \leq 0$ 同时存在时，可行域往往不再是规整的矩形，而可能是一个极其狭长、弯曲甚至不连通的非凸区域。

 梯度法在遇到约束边界时，需要复杂的投影操作，极易计算发散或停滞；

 直接搜索法在越界时，可以通过简单的步长回退或收缩来强制拉回可行域，鲁棒性极强；

 蒙特卡罗法则更简单粗暴：生成随机点后，直接检验约束条件，不满足就丢弃，满足才计算目标函数，天然适应任何形状的可行域。

## 小结：

非线性规划的复杂性，使得“求导解析”走不通，“单点起步”易迷失，“边界约束”难处理。

因此，直接搜索法成为了处理不可导黑盒函数的稳健之选，而蒙特卡罗法则是破解多极值全局寻优的破局之法。

## 1.6. 蒙特卡罗法

求解优化模型：n 元函数有约束最值问题

s.t. $\left\{ \begin{array} { l l } { g ( x ) \leq 0 } \\ { l _ { i } \leq x _ { i } \leq u _ { i } ( i = 1 , 2 , \cdots , n ) } \end{array} \right.$

输入：

f (x) 目标函数

l n 维数组，其中 $l = ( l _ { 1 } , l _ { 2 } , \cdots , l _ { n } )$

u n 维数组，其中 $\boldsymbol { u } = ( u _ { 1 } , u _ { 2 } , \cdots , u _ { n } )$

m 随机产生可行解个数

输出：

tmp\_min 存储随机跳跃法求得的近似最优目标函数值

tmp\_x 存储随机跳跃法求得的近似最优决策，n 维数组

临时变量：

n维数组 $x = \left( x _ { 1 } , x _ { 2 } , \cdots , x _ { n } \right) ^ { T }$ 存储随机点

n维数组 $\boldsymbol { r } = \left( r _ { 1 } , r _ { 2 } , \cdots , r _ { n } \right) ^ { T }$ 存储伪随机数

## 1.6.1. 简单约束的情形

min ( )f x

$$
\text { s.t. } \quad l _ {i} \leq x _ {i} \leq u _ {i} (i = 1, 2, \dots , n)
$$

## 【算法步骤】

1. $\scriptstyle { \dot { 1 } } = 0$

2. $\mathrm { { t m p \_ m i n = 9 9 9 9 9 9 9 9 9 } }$ ; //赋值为一个很大的数

3. 随机产生n个在区间(0,1)上均匀分布的随机数 $r _ { j } ( j = 1 , 2 , \cdots , n )$

4. 令 $x _ { j } = l _ { j } + r _ { j } ( u _ { j } - l _ { j } ) , j = 1 , 2 , \cdots , n \ ; / /$ 产生在区间 $[ l _ { j } , u _ { j } ]$ 上均匀分布随机数

5. $x = [ x _ { 1 } , x _ { 2 } , \cdots , x _ { n } ]$

6. 如果 $f ( x ) < { \mathrm { ~ t m p \underline { { { \ m i n } } } } }$ ,则 $\mathrm { t m p \_ m i n } { = } f ( x ) , \mathrm { t m p \_ x } = \ x$

7. $\mathbf { i } { = } \mathbf { i } + 1$ ;

8. 如果i=m，则结束；否则跳到第 3步;

tmp_min = 99999999
for i=1:m,
    for j=1:n,
    r(j)=rand; //  $r_{j}$  在区间[0,1]上均匀分
    x(j)=1(j)+r(j)*(u(j)-1(j)); //  $x_{j}$  在区间 $[l_{j},u_{j}]$ 上均匀分布
    end for

    end if
end for
