# 2024 年国赛 B 题：优秀论文方案对照与当前建模审查

## 结论先行

本次评价状态为 **WARN**，不是因为当前模型选错，而是因为“理论严谨性”和“竞赛可交付完整度”不均衡。

- **问题一：模型方向正确，但数值方案尚未闭环。** 精确二项检验与截断序贯概率比检验（SPRT）比展示论文中的正态近似、经验样本量更可审计；不过题目没有给出劣质率设计点 `p1` 与最大抽样量 `Nmax`，当前方案如果不明确补充业务假设，就不能产生唯一的可执行抽检方案。
- **问题二：当前吸收马尔可夫奖励模型在精确性上优于蒙特卡洛方案。** 它能显式处理拆解回流、保留质量信息和非吸收策略。但优秀论文普遍在拆解后强制检测未检零配件，以避免循环；这与当前“原策略物理保留”解释不同。两种解释都应保留为并列情景，不能悄悄混用。
- **问题三：当前算法选择优于多数展示论文。** 决策只有 16 位，完整空间为 `2^16=65536`，精确枚举可给出全局最优证书，不需要用遗传、蚁群或退火替代。官方展示论文 B196 用遗传算法得到的策略结构与当前精确解一致，构成了有价值的外部交叉验证。
- **问题四：当前不确定性设计最严谨，但实现最不完整。** 同时置信域、策略稳定域和最大遗憾比逐变量扰动、边界点代入或“三倍标准差”更有解释力；然而严格区间分支定界尚未实现，而且原始抽样量与次品数 `(N,K)` 缺失，因此现在只能给协议，不能声称完成了稳健最优求解。

总体判断：**当前方案的建模骨架强于检索到的多数竞赛论文，尤其是问题二、三；但当前论文如果现在提交，会输在问题一、四缺少明确假设和完整数值结果，而不是输在算法不够复杂。**

## 分题评价

### 问题一：经典模型已经完全覆盖，不应为“论文感”升级算法

题目本质是伯努利次品率的接收/拒收抽样。固定样本二项检验和 SPRT 都是直接对应数据生成机制的经典模型；检索到更复杂的做法并不自动更优。

B159 的优点是把抽样成本与检验能力放在一个目标函数中，竞赛叙述完整；缺点是权重和备择域先验主观，而且正态近似不是必要的。B195、B196给出了可执行样本量，但设计差异和误差控制并不完全清晰。开源方案选择 SPRT 是方向最接近当前方案的，但其 `0.09/0.11` 是人为设定的无差异区，不能从“标称次品率 10%”唯一推出。

因此当前方案应保持：

1. 以**精确固定样本二项方案**作为最容易解释的基线；
2. 以**截断 SPRT**作为节省平均样本量的主挑战者；
3. 明示 `p1` 为“企业认为有实际差异的劣质率”，至少报告 `0.11/0.12/0.15` 等情景，不把其中某个值伪装为题目给定；
4. 明示 `Nmax` 反映时间/成本上限，并报告截断后真实的两类错误概率，而不是只抄 Wald 近似阈值。

**评分：模型选择 A；可执行完整度 C+；补齐 `p1/Nmax` 后可到 A-。**

### 问题二：吸收马尔可夫模型正确，但回流语义必须做双模型

B159 的解析期望法是检索结果中最值得吸收的设计：它没有在只有 16 个策略时使用元启发式算法，而且能直接计算收益。但该文为避免死循环，规定拆解后对原来未检的零配件强制检测。这是一个合理的业务补充，却不完全等于题目所说的“重复之前的决策”。

当前模型保留零件潜在质量和已获得的信息，并把拆解回流建成吸收马尔可夫奖励过程，理论上更一般；同时它会诚实暴露某些策略的非吸收或无限循环风险。当前问题二结果与 B159 的利润/策略不同，不能简单说谁算错，首要原因是**回流语义不同**。

应正式增加两个命名清楚的情景：

- `fixed_policy_physical_retention`：拆解后保留原质量与检测信息，继续执行同一固定策略；这是当前主模型。
- `forced_inspection_on_recovery`：拆解后，所有此前未检测的回收零件必须检测；这是竞赛论文常用的防循环业务规则。

再用 B159 的解析公式校验第二个情景。如果两个情景给出的最优策略不同，就把“回流业务规则”列为一级敏感因素，而不是把差异藏在程序细节中。

**评分：模型选择 A；算法 A；题意歧义处理 B，目前整体 A-。**

### 问题三：精确枚举优于遗传、蚁群和退火

B195 用模拟退火，B196和开源方案用遗传算法，B196还在问题二的 16 策略上使用蚁群算法。这些方法可以展示算法，但不能给出全局最优保证，并且对如此小的离散空间没有必要。

当前方案枚举全部 `65536` 个固定策略，再用精确状态转移求期望利润，是更合适的算法设计。当前最优结构为：8 个零配件全检、3 个半成品全检、成品不检、3 个半成品和成品均拆解；B196 的遗传算法独立得到相同的开关结构，说明当前结果不是明显的编码偶然。

B159 得到“成品也检测”的策略，并报告较低利润；其动态规划设定了最大递归深度，可能有截断偏差，同时它允许的状态动作也可能与当前“固定 16 位策略”不同。该差异应通过统一状态、统一成本口径复算，而不能直接凭论文奖项决定采用哪一个。

需要保留一个边界：如果题意允许企业在每次回流后根据已知状态重新决策，那么真正的问题是状态自适应 MDP；固定 16 位策略的精确枚举是一个较窄但清楚的策略类。论文中必须声明当前优化的是哪一类策略。

**评分：固定策略模型 A；算法 A；外部一致性 A-。**

### 问题四：不确定性方法最好，但必须落地到数据

B159 的 Beta 后验积分是一种完整的贝叶斯解法，值得作为挑战者；它的前提是明确先验并保留共同参数导致的重复生产依赖。B195 的边界代入与 B196 的“三倍标准差”都是易实现的敏感性方法，但逐个参数变化不代表多参数同时覆盖，因而不能直接声称“95% 稳健”。开源方案使用 Wilson 区间和随机扰动，也没有解决同时覆盖和最坏情景漏检。

当前方案的正确主线是：

1. 从每个抽检对象的原始 `(N,K)` 构造置信区间；
2. 用 Bonferroni/Holm 或适合序贯抽样的置信序列形成**同时置信集**；
3. 对全部候选策略传播参数不确定性，报告名义最优、最坏收益、最大遗憾和策略翻转边界；
4. 把 Beta 后验期望利润作为“接受先验时”的挑战者，而非无条件主结论。

现在的硬缺口是题目只给标称次品率，没有给抽检原始 `(N,K)`，且严格区间全局优化尚未实现。因此问题四当前状态必须写成 **BLOCKED/PROTOCOL ONLY**，不能写“已证明稳健”。为了竞赛完整度，可先实现可审计的全角点/情景网格筛查，再把区间分支定界作为严格证书层。

**评分：设计 A-；实现 C；当前不能宣称完成。**

## 当前方案最值得保留的部分

1. **模型复杂度服从问题规模。** 16 和 65536 策略直接枚举，避免用元启发式制造虚假的复杂度。
2. **把反馈闭环当作模型主体。** 拆解、回流、重复加工不是一次成本公式的修补项，而是状态转移。
3. **区分潜在质量、观测信息和物理库存。** 这比许多仿真论文把“检测”直接等同于“质量改变”更严谨。
4. **有非吸收、物料守恒、蒙特卡洛对照和回归测试。** 这些是结果可信度的重要来源。
5. **不把论文中的复杂模型自动替换经典模型。** 当经典二项/SPRT、吸收马尔可夫链和完整枚举已完全覆盖问题时，论文主要用于校核机制、变量和业务假设，而不是强迫升级算法。

## 必须补强的缺口与优先级

### P0：不补就不能形成完整答案

1. **问题一补参数治理：** 把 `p1`、`Nmax`、抽样成本写成业务输入；输出多情景 OC/ASN，而不是给一个无来源的唯一数字。
2. **问题二补回流双语义：** 同时实现固定策略物理保留与拆解后强制检测，统一成本口径比较；用 B159 解析结果作独立 oracle。
3. **问题四补可运行版本：** 要求输入真实 `(N,K)`；先实现同时区间 + 全角点/自适应情景筛查 + 策略稳定性，再实现严格区间分支定界。
4. **把策略类写清楚：** 区分“预先固定的检测/拆解开关”与“回流后依据状态改变动作的 MDP”，不要交叉比较利润。

### P1：提升论文说服力

1. 把 B196 得到的同结构策略登记为问题三外部基准，但不把遗传算法当主求解器。
2. 增加 Beta-Binomial 后验期望利润挑战者，明确先验、后验和频率学派结论的差别。
3. 增加一页竞赛友好的结论表：主假设、最优策略、期望利润、次优差距、假设翻转点、证据状态。
4. 对论文报告的策略差异做“同口径复算”，优先排查回流规则、成本计入时点、利润单位和截断深度，而不是以奖项作投票。

## 最终评价

当前建模没有因检索优秀论文而需要改成更复杂的遗传/蚁群/退火组合。相反，检索强化了三个判断：

- **问题一应坚持经典统计检验，但要补齐业务设计点。**
- **问题二的核心不是搜索算法，而是拆解回流的状态和规则。**
- **问题三应坚持精确枚举；论文中的遗传算法只适合作外部交叉验证。**

真正需要从优秀论文吸收的是：把假设落成可运行数值、提供竞赛可读的完整闭环、加入“拆解后强制检测”这一业务解释，以及把贝叶斯后验作为问题四的竞争模型。当前版本是**严谨度高、完成度不均衡的强方案**；按上述 P0 补齐后，才可评价为完整的竞赛级解答。
