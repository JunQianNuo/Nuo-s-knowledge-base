# 数学建模项目总览

## 新建项目

1. 在本目录复制 [[模板/项目模板|项目模板]]；
2. 填写 `due_date`、`next_action`、目标与完成条件；
3. 项目资料继续保留在现有题目、训练或独立仓库目录，不强制搬迁；
4. 每周更新下一步，完成后填写复盘并标记 `已完成` 或 `已归档`。
