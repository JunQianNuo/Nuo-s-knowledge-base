# 文献精读：四维提取与适用条件审查

## 概述

文献检索（阶段1.5a）只是找到论文，精读（阶段1.5b）才是提取可用于建模的技术细节。

本文档定义：
1. 四维提取模板（背景/模型/算法/结论）
2. 适用条件审查清单
3. 文献结果报告格式

---

## 一、四维提取模板

### 对每篇论文，按以下模板提取

```markdown
## [论文完整标题]

**文献信息**
- 作者：First Author et al.
- 年份/期刊：YYYY, Journal Name (SCI Qx / 中文核心 / EI)
- DOI/链接：

### 1. 研究背景
- 解决什么问题：[用一句话概括该论文的核心问题]
- 场景是什么：[应用领域、物理/工程场景]
- 与本题的关联：[该论文的问题与我们的赛题在哪些方面相似]

### 2. 核心模型
- 模型名称：[如 Walker Constellation / NSGA-II / ARIMA / SIR]
- 数学形式：[关键公式的 LaTeX 形式，至少包含核心方程]
  ```
  $$公式$$
  ```
- 关键变量定义：[列出公式中每个符号的含义和单位]
- 适用条件：[模型成立的假设——这是最关键的！]
  - 假设1：
  - 假设2：
  - ...
- 输入/输出：[模型需要什么输入，产出什么输出]

### 3. 关键算法
- 求解方法：[用什么算法求解该模型]
- 算法步骤摘要：[3-5 步概括]
- 收敛条件：[如为迭代算法]
- 计算复杂度：[如文献有报告]
- 实现要点：[调参经验、技巧、易错点]

### 4. 主要结论
- 量化结果：[数值结果，带单位]
- 适用范围：[该结论在什么条件下成立]
- 与同类方法的比较：[如有，说明比谁好/差多少]
- 可复用到本题的部分：[这是最重要的字段]
  - 公式：[具体的公式编号，如 Eq.(7)，可直接改写适配]
  - 参数取值：[文献使用的参数值及取值依据]
  - 推导：[可以直接引用的推导过程]
  - 数据：[可直接引用的表格/曲线数据]
- 局限性：[论文自己声明的 + 你判断的]
  - 声明局限：
  - 判断局限：
```

### 提取要求

1. **公式必须完整**：不止是名字（如 "Lüders公式"），必须有 LaTeX 形式（如 `θ = arcsin(R·sin(α)/(R+h)) − α`）
2. **适用条件必须逐条列出**：这是阶段3审查的基础
3. **可复用的部分必须精确到公式编号**：阶段6代码中的注释必须引用文献公式编号
4. **局限性必须诚实标注**：不影响建模决策的局限也要写

## 二、适用条件审查清单

### 对每篇文献的核心模型，逐条审查

```markdown
## 适用条件审查：[模型名称] ← [论文标题]

| # | 文献声明的适用条件 | 本题情况 | 是否满足 | 不满足时的处理 |
|---|------------------|---------|:------:|--------------|
| 1 | 圆轨道（e=0） | 题给近圆轨道，e≈0 | ✅ | — |
| 2 | 球形地球（无扁率） | 本题可使用球面近似 | ✅ | — |
| 3 | 天线波束为锥形 | 题给圆锥形波束 | ✅ | — |
| 4 | 单重覆盖（无冗余叠加） | 本题需多重覆盖 | ❌ | 需扩展公式：引入重叠因子 β |
| 5 | 同构Walker星座 | 问题二可能考虑异构 | ⚠️ | 先按同构建模，异构作为扩展讨论 |

### 审查结论

- 完全满足：X/总数
- 不满足：Y/总数
- 需扩展：Z/总数

**总体判断**：
- 如核心条件（影响模型数学形式）不满足 → ❌ 不推荐使用，或需重要修改
- 如次要条件（影响参数取值）不满足 → ⚠️ 可以使用，但论文中需声明局限
- 如全部满足 → ✅ 直接可用
```

### 常见不满足场景与处理

| 场景 | 处理方式 |
|------|---------|
| 模型假设条件不满足核心前提 | ❌ 放弃该模型，寻找替代文献 |
| 模型假设可放松但需扩展公式 | ⚠️ 标注"需扩展"，在阶段3提出扩展方案 |
| 模型假设在当前精度下可近似满足 | ⚠️ 标注"近似满足"，在论文中讨论近似误差 |
| 模型假设不满足但可做敏感性分析 | ⚠️ 在阶段5增加对应假设验证检验 |

### 编写规则

1. **量化结论优先**：能用数字就不要用"较好""显著"等定性词
2. **标注论文间的一致性/矛盾**：如两篇论文对同一问题给出不同结论，标注并分析可能原因
3. **区分"文献声明"和"你的判断"**：用不同的标记（如 `[文献]` vs `[判断]`）区分
4. **可直接引用的结论单独汇总**：方便阶段8直接嵌入论文
