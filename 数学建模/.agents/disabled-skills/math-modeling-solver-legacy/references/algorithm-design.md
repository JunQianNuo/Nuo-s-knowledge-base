# 算法设计报告模板

## 概述

算法设计（阶段4）在模型确定（阶段3）之后、代码实现（阶段6）之前进行。目标是产出完整的算法设计报告，确保"先想清楚再写代码"。

算法设计报告包含 8 个标准模块。

## 算法设计报告编写规则

1. **输入/输出必须明确类型**：`float` / `int` / `np.ndarray` / `list[tuple]` —— 这直接决定代码的数据结构
2. **流程图可以用 mermaid**：Obsidian 原生支持，节点标签含数学符号时用 `"..."` 包裹
3. **复杂度必须具体到本题**：不只是 O(n²)，还要带入本题的 n 估算实际耗时
4. **局限性不能空**：任何算法都有局限——收敛到局部最优、参数敏感、假设不满足等
5. **预期范围是阶段7的对比基准**：如果没有预期范围，阶段7跑出结果也无法判断合理性
6. **模板优先**：先查到已有模板再设计算法——避免从零造轮子

---

## 与阶段3（模型设计）的关系

- 阶段3回答"用什么模型" → 阶段4回答"怎么实现这个模型"
- 阶段3的一个模型可能有多种算法实现方式 → 阶段4选择最合适的算法
- 阶段3的适用条件审查结论，在阶段4中体现为局限性声明的依据

## 与阶段5（检验方案设计）的关系

- 阶段4的预期输出范围 → 阶段5中"预期结果"列的输入
- 阶段4的局限性 → 阶段5中对应检验项的来源
- 阶段4的瓶颈环节 → 阶段5中需特别检验的环节
