# 进退法

## 一句话

进退法沿下降方向大步前进，直到函数值开始回升，从而确定包含极小点的初始搜索区间。

## 严格定义

一维搜索方法（黄金分割法、二分法等）都需要极小点被"框"在一个区间内。进退法解决"如何找到这个初始区间"的问题。

**目标**：找到三点 $a<c<b$ 满足 $f(c)<f(a)$ 且 $f(c)<f(b)$——极小点被框在 $(a,b)$ 内。

## 算法步骤

```
S0: 任选三点 x₀<x₁<x₂
S1: 若 f(x₁)<f(x₀) 且 f(x₁)<f(x₂):
      → 框住成功，[a,b]=[x₀,x₂]
    否则若 f(x₀)>f(x₁)>f(x₂)（持续下降）:
      → 取 x₃>x₂（步长加倍）
      → 若 f(x₂)<f(x₃): [a,b]=[x₁,x₃]（已框住）
      → 否则: 继续向右扩展（步长加倍）
```

## 直观理解

沿着下降方向大步前进，步长逐次加倍。一旦函数值开始回升（$f(x_{i+1})>f(x_i)$），说明已经越过了极小点，区间就被框住了。

## 实际应用

习题 7.12 的典型流程：先调用**进退法**（确定搜索区间），再调用黄金分割法或斐波那契法（在区间内精确搜索）——这正是实际优化中常用的两步策略。
