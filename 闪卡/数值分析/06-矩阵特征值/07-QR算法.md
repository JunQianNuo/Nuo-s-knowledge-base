QR 算法的基本迭代过程？与归一化同时迭代的关系？

---

**QR 算法**（求全部特征值，对称阵）：
```
A₀ ← A
for j = 0, 1, 2, ...:
    Aⱼ = Qⱼ Rⱼ           (QR分解)
    Aⱼ₊₁ = Rⱼ Qⱼ         (逆序相乘)
```

**关键性质**：
$$A_{j+1} = R_j Q_j = Q_j^T A_j Q_j$$
即每步**相似变换**，特征值不变。

**收敛性**：$A_j$ 收敛于（块）对角阵，对角块为特征值。

**与归一化同时迭代的关系**：
- 归一化同时迭代：$A Q_j = Q_{j+1} R_{j+1}$
- QR 算法：$A_j = Q_j R_j$，$A_{j+1} = R_j Q_j$
- 两者等价：$Q_0 Q_1 \cdots Q_j$ 正好是同时迭代的正交基！

**加速技巧**：
- 先用 Householder 约化为上 Hessenberg 型
- 位移 QR：$(A_j - \mu I) = Q_j R_j$，$A_{j+1} = R_j Q_j + \mu I$
