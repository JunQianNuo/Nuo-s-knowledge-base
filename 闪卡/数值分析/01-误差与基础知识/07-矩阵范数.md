矩阵范数的三大公理？三种算子范数的公式？

---

**三大公理**（与向量范数类同）：正定性、齐次性、三角不等式

**算子（从属矩阵）范数**：$\|A\| = \max_{x \neq 0} \frac{\|Ax\|}{\|x\|}$

| 算子范数           | 公式                   | 含义      |     |        |
| -------------- | -------------------- | ------- | --- | ------ |
| $\|A\|_1$      | $\max_j \sum_i       | a_{ij}  | $   | 最大绝对列和 |
| $\|A\|_2$      | $\sqrt{\rho(A^T A)}$ | 谱半径的平方根 |     |        |
| $\|A\|_\infty$ | $\max_i \sum_j       | a_{ij}  | $   | 最大绝对行和 |

**算子范数性质**：$\|I\| = 1$，$\|Ax\| \leq \|A\| \cdot \|x\|$，$\|AB\| \leq \|A\| \cdot \|B\|$
