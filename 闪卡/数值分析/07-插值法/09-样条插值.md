三次自然样条插值的定义与方程系统？

---

**$k$ 次样条函数定义**：
1. 在每个子区间上是次数 $\leq k$ 的多项式
2. 在整个区间上 $k-1$ 阶连续

**三次样条**：每个子区间 $[x_i, x_{i+1}]$ 上（$i=0,\dots,n-1$）：
$$S_i(x) = f(x_i) + b_i(x-x_i) + c_i(x-x_i)^2 + d_i(x-x_i)^3$$
共 $4n$ 个未知数。

**条件**：
- 插值条件（$2n$ 个）：$S_i$ 过两端节点
- 一阶连续（$n-1$ 个）：$S_i'(x_{i+1}) = S_{i+1}'(x_{i+1})$
- 二阶连续（$n-1$ 个）：$S_i''(x_{i+1}) = S_{i+1}''(x_{i+1})$
- 自然边界（2 个）：$S_0''(x_0) = S_{n-1}''(x_n) = 0$（即 $c_0 = c_n = 0$）

**最终三对角方程**（$n-1$ 个未知 $c_i$）：
$$\delta_i c_i + 2(\delta_i+\delta_{i+1})c_{i+1} + \delta_{i+1}c_{i+2} = 3\left(\frac{\Delta_{i+1}}{\delta_{i+1}} - \frac{\Delta_i}{\delta_i}\right) \quad (i=0,\dots,n-2)$$
其中 $\delta_i = x_{i+1} - x_i$，$\Delta_i = f(x_{i+1}) - f(x_i)$。

**回代求 $b_i, d_i$**（解出 $c_i$ 后）：

$$a_i = f(x_i)$$

$$d_i = \frac{c_{i+1} - c_i}{3\delta_i}$$

$$b_i = \frac{\Delta_i}{\delta_i} - \frac{\delta_i}{3}(2c_i + c_{i+1})$$
