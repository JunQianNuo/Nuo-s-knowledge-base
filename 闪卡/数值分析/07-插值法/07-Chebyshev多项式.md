Chebyshev 多项式的定义与核心性质？首一多项式定理？

---

**定义**（第一类 $n$ 阶 Chebyshev 多项式）：
$$T_n(x) = \cos(n \arccos x), \quad x \in [-1,1]$$

**性质**：
| 性质 | 内容 |
|------|------|
| 递推 | $T_{n+1}(x) = 2x T_n(x) - T_{n-1}(x)$ |
| 次数 | $n$ 次多项式，首项系数 $2^{n-1}$（$n \geq 1$） |
| 端点 | $T_n(1) = 1$，$T_n(-1) = (-1)^n$ |
| 最大值 | $\max_{[-1,1]} |T_n(x)| = 1$ |
| 零点 | $x_k = \cos\frac{(2k+1)\pi}{2n}$，$k=0,\ldots,n-1$ |
| 极点 | $T_n(\cos\frac{k\pi}{n}) = (-1)^k$，共 $n+1$ 个 ±1 极值点 |

**首一多项式定理**：
任意 $n$ 次首一多项式 $p(x)$ 满足：
$$\max_{-1 \leq x \leq 1} |p(x)| \geq 2^{1-n} = \max_{-1 \leq x \leq 1} |2^{1-n} T_n(x)|$$
即 $q(x) = 2^{1-n} T_n(x)$ 在首一多项式中具有**最小最大范数**。
