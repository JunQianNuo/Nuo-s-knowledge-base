龙贝格（Romberg）求积的核心思想与外推公式？

---

**核心思想**：用 Richardsen 外推加速收敛慢的复化梯形序列。

**复化梯形余项展开**（Euler-Maclaurin）：
$$I - T_n = c_1 h^2 + c_2 h^4 + c_3 h^6 + \cdots$$

**① $T_n \to S_n$ 外推**（消去 $h^2$ 项）：
假定 $f''(\xi) \approx f''(\eta)$，则 $(I - T_n)/(I - T_{2n}) \approx 4$
$$S_n = \frac{4T_{2n} - T_n}{4-1}$$

**② $S_n \to C_n$ 外推**（消去 $h^4$ 项）：
$$C_n = \frac{16S_{2n} - S_n}{16-1}$$

**③ $C_n \to R_n$ 外推**（消去 $h^6$ 项）：
$$R_n = \frac{64C_{2n} - C_n}{64-1}$$

**龙贝格数表**（外推递推）：

| $T_1$ | | | |
|-------|---|---|---|
| $T_2$ | $S_1$ | | |
| $T_4$ | $S_2$ | $C_1$ | |
| $T_8$ | $S_4$ | $C_2$ | $R_1$ |
| $\vdots$ | $\vdots$ | $\vdots$ | $\vdots$ |

**外推通式**：$X_n^{(k)} = \frac{4^k X_{2n}^{(k-1)} - X_n^{(k-1)}}{4^k - 1}$
