# 资本有机构成

## 定义

**资本有机构成**是由资本的技术构成决定并**反映技术构成变化**的资本价值构成。简单说：$c:v$（不变资本 : 可变资本）。

## 核心要点

1. **技术构成**：由生产技术水平决定的生产资料与劳动力的比例（自然形式）
2. **价值构成**：不变资本与可变资本的比例 $c:v$（价值形式）
3. **有机构成**：由技术构成改变**引起的**价值构成改变。如果价值构成改变只是因为价格变化（非技术原因），则不叫有机构成改变。
4. **趋势**：资本有机构成不断提高 → 可变资本相对减少 → 劳动力需求减少 → **相对过剩人口**（失业）。

> 举例：原来 4 斤面 : 1 工人 → 技术构成改变为 2 斤面 : 2 工人 → 价值构成改变反映了技术构成 → 此时价值构成 = 有机构成。

## 常见考法

- **选择/判断**：区分技术构成、价值构成、有机构成的概念；判断"面粉涨价导致的 c:v 变化是有机构成变化"（错，不是技术原因）
- **计算**：给定 c 和 v，求有机构成比例
