# 常用常数与符号

## 基本物理常数

| 符号 | 名称 | 数值 | 备注 |
|------|------|------|------|
| $h$ | 普朗克常量 | $6.63 \times 10^{-34} \text{ J·s}$ | $h = 2\pi\hbar$ |
| $\hbar$ | 约化普朗克常量 | $1.055 \times 10^{-34} \text{ J·s}$ | $\hbar = h/2\pi$ |
| $k$ | 玻尔兹曼常量 | $1.38 \times 10^{-23} \text{ J/K}$ | $k = R/N_A$ |
| $R$ | 普适气体常量 | $8.31 \text{ J/(mol·K)}$ | |
| $N_A$ | 阿伏伽德罗常数 | $6.02 \times 10^{23} \text{ mol}^{-1}$ | |
| $e$ | 元电荷 | $1.60 \times 10^{-19} \text{ C}$ | |
| $m_e$ / $m_0$ | 电子静质量 | $9.11 \times 10^{-31} \text{ kg}$ | |
| $c$ | 真空中光速 | $3.0 \times 10^8 \text{ m/s}$ | |
| $\varepsilon_0$ | 真空介电常数 | $8.85 \times 10^{-12} \text{ F/m}$ | |

## 导出常数

| 符号 | 名称 | 数值 | 来源 |
|------|------|------|------|
| $m_0 c^2$ | 电子静能 | $0.511 \text{ MeV}$ | $m_e c^2$ |
| $a_0$ | 玻尔半径 | $5.29 \times 10^{-11} \text{ m} = 0.529 \text{ Å}$ | $\varepsilon_0 h^2/(\pi m e^2)$ |
| $E_1$ | 氢原子基态能量 | $-13.6 \text{ eV}$ | $-me^4/(8\varepsilon_0^2 h^2)$ |
| $\lambda_c$ | 康普顿波长 | $0.024 \text{ Å}$ | $h/(m_0 c)$ |
| $R$ | 里德伯常量 | $1.097 \times 10^7 \text{ m}^{-1}$ | |

## 标准状态

| 量 | 值 |
|------|------|
| 温度 $T_0$ | $273 \text{ K}$（$0^\circ\text{C}$） |
| 压强 $p_0$ | $1 \text{ atm} = 1.013 \times 10^5 \text{ Pa}$ |
| 摩尔体积 $V_0$ | $22.4 \text{ L} = 22.4 \times 10^{-3} \text{ m}^3$（1 mol 理想气体） |

## 热学常用符号

| 符号 | 含义 |
|------|------|
| $p$ | 压强（Pa） |
| $V$ | 体积（m³） |
| $T$ | 热力学温度（K） |
| $\nu$ | 摩尔数（mol） |
| $n$ | 分子数密度（m⁻³） |
| $N$ | 总分子数 |
| $M$ | 气体质量（kg） |
| $M_{mol}$ | 摩尔质量（kg/mol） |
| $i$ | 自由度（单原子 3 / 刚性双原子 5 / 刚性多原子 6） |
| $t, r, s$ | 平动/转动/振动自由度 |
| $C_V$ | 定体摩尔热容 = $\frac{i}{2}R$ |
| $C_p$ | 定压摩尔热容 = $C_V + R$ |
| $\gamma$ | 比热容比 = $C_p/C_V = (i+2)/i$ |
| $E$ | 内能（J） |
| $A$ | 功（J），对外做功为正 |
| $Q$ | 热量（J），吸热为正 |
| $\eta$ | 热机效率 |
| $\omega$ / $\varepsilon$ | 制冷系数 |
| $S$ | 熵（J/K） |
| $\Omega$ | 热力学概率（微观状态数） |
| $\tau$ | 弛豫时间 |
| $v_p$ | 最概然速率 |
| $\bar{v}$ | 平均速率 |
| $v_{rms}$ | 方均根速率 |

## 量子常用符号

| 符号 | 含义 |
|------|------|
| $\nu$ | 频率（Hz） |
| $\lambda$ | 波长（m） |
| $\varphi$ | 散射角 |
| $A$ | 逸出功（eV） |
| $\nu_0$ | 红限频率 |
| $\Psi$ | 波函数 |
| $n$ | 主量子数 $= 1, 2, 3, \ldots$ |
| $l$ | 角量子数 $= 0, 1, \ldots, n-1$ |
| $m_l$ | 磁量子数 $= 0, \pm 1, \ldots, \pm l$ |
| $m_s$ | 自旋磁量子数 $= \pm 1/2$ |
| $\text{Å}$ | 埃 $= 10^{-10} \text{ m}$ |

## 比热容比 $\gamma$ 参考值

| 分子类型 | $i$ | $C_V$ | $\gamma$ |
|------|:---:|:---:|:---:|
| 单原子 | 3 | $\frac{3}{2}R$ | $5/3 \approx 1.67$ |
| 刚性双原子 | 5 | $\frac{5}{2}R$ | $7/5 = 1.40$ |
| 刚性多原子 | 6 | $3R$ | $8/6 \approx 1.33$ |
