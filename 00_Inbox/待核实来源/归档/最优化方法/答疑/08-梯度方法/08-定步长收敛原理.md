# 第8章 答疑 — 定步长梯度法的收敛原理

> 问题：**习题 8.16 中 $|1-2\alpha| < 1$ 这个收敛条件是什么原理？**

> 来源：`习题库/08-梯度方法/习题8.16.md` 第 123 行

---

## 一句话兜底

> 定步长梯度法对二次函数退化成一个**线性定常迭代系统** $x^{(k+1)} = M x^{(k)} + d$，收敛的充要条件是迭代矩阵 $M = I - \alpha Q$ 的**谱半径** < 1。

---

## 推导

### Step 1：迭代退化为线性系统

对 $f(x) = \frac{1}{2}x^T Q x - c^T x$，梯度 $\nabla f = Qx - c$。定步长迭代：

$$x^{(k+1)} = x^{(k)} - \alpha (Q x^{(k)} - c) = \underbrace{(I - \alpha Q)}_{M} x^{(k)} + \alpha c$$

这是标准的 $x^{(k+1)} = M x^{(k)} + d$ 形式，其中 $M = I - \alpha Q$。

### Step 2：线性迭代的收敛充要条件

对 $x^{(k+1)} = M x^{(k)} + d$，设不动点 $x^* = M x^* + d$。误差 $e^{(k)} = x^{(k)} - x^*$ 满足：

$$e^{(k+1)} = M e^{(k)} = M^{k+1} e^{(0)}$$

$e^{(k)} \to 0$ 的充要条件：

$$\boxed{\rho(M) = \max_i |\lambda_i(M)| < 1}$$

其中 $\rho(M)$ 是**谱半径**。

### Step 3：谱半径 → 步长范围

$Q$ 特征值为 $\lambda_i$，则 $M = I - \alpha Q$ 特征值为 $1 - \alpha \lambda_i$：

$$|1 - \alpha \lambda_i| < 1 \quad \forall i$$

$$\Downarrow$$

$$-1 < 1 - \alpha \lambda_i < 1 \;\Longrightarrow\; 0 < \alpha \lambda_i < 2 \;\Longrightarrow\; \alpha < \frac{2}{\lambda_i}$$

最紧约束来自最大特征值：

$$\boxed{0 < \alpha < \frac{2}{\lambda_{\max}(Q)}}$$

### Step 4：本题数值验证

$A = \begin{bmatrix} 1 \\ 0 \end{bmatrix}$，$Q = 2A^T A = [2]$，$\lambda_{\max} = 2$：

- 特征值法：$\alpha < 2/2 = 1$ → $\alpha \in (0,1)$
- 谱半径法：$M = [1-2\alpha]$，$|1-2\alpha| < 1$ → $\alpha \in (0,1)$

两者完全等价——谱半径条件 $|1-\alpha\lambda| < 1$ 就是特征值条件的逐特征值写法。

---

## 直观理解

$|1 - \alpha \lambda|$ 是每一步误差的**衰减因子**：

| $\alpha$ 大小 | $1 - \alpha\lambda$ | 效果 |
|:--|:--|:--|
| 太小 | $\approx 1$ | 几乎不衰减（爬行） |
| 恰好 | 在 $(0,1)$ 内 | 逐步收敛 |
| 太大 | $< -1$ | **发散**（过冲振荡） |

最优固定步长：$\alpha^* = \dfrac{2}{\lambda_{\min} + \lambda_{\max}}$，衰减因子最小。
