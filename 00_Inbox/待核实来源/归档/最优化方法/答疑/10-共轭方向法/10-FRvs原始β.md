# 第10章 答疑 — 为什么用 FR 而不用原始 $\beta$ 公式

> 问题：**习题 10.10 中为什么用 Fletcher-Reeves 公式 $\beta_k = \|g^{(k+1)}\|^2 / \|g^{(k)}\|^2$，而不用原始 $\beta$ 公式 $\beta_{k-1} = g_k^T Q p_{k-1} / (p_{k-1}^T Q p_{k-1})$？**

> 来源：`习题库/10-共轭方向法/习题10.10.md` 提示第 4 条；`复习/IV-无约束优化.md` L274

---

## 一句话兜底

> 对二次函数 + 精确线搜索，两者**完全等价**。但 FR 不需要 Hessian $Q$——只用梯度内积即可，既省 $O(n^2)$ 计算，又能直接推广到非二次函数。

---

## 等价性推导

原始公式从 $Q$-共轭约束直接解出：

$$\beta_{k-1} = \frac{g_k^T Q p_{k-1}}{p_{k-1}^T Q p_{k-1}}$$

**推导 FR 等价形式**（对 $f = \frac{1}{2}x^T Q x - b^T x$，精确线搜索）：

### 关键事实

1. 由 $g_{k} = g_{k-1} + \alpha_{k-1} Q p_{k-1}$ → $Q p_{k-1} = \dfrac{g_k - g_{k-1}}{\alpha_{k-1}}$
2. 精确线搜索：$g_k^T p_{k-1} = 0$，且对二次函数梯度互相正交 $g_k^T g_{k-1} = 0$

### 代入化简

分子：$g_k^T Q p_{k-1} = g_k^T \cdot \dfrac{g_k - g_{k-1}}{\alpha_{k-1}} = \dfrac{\|g_k\|^2 - g_k^T g_{k-1}}{\alpha_{k-1}} = \dfrac{\|g_k\|^2}{\alpha_{k-1}}$

分母：$p_{k-1}^T Q p_{k-1} = p_{k-1}^T \cdot \dfrac{g_k - g_{k-1}}{\alpha_{k-1}} = \dfrac{\cancel{p_{k-1}^T g_k} - p_{k-1}^T g_{k-1}}{\alpha_{k-1}}$

而 $p_{k-1} = -g_{k-1} + \beta_{k-2}p_{k-2}$，且 $g_{k-1} \perp p_{k-2}$：

$$p_{k-1}^T g_{k-1} = -\|g_{k-1}\|^2$$

所以：

$$\beta_{k-1} = \frac{\|g_k\|^2 / \alpha_{k-1}}{\|g_{k-1}\|^2 / \alpha_{k-1}} = \boxed{\frac{\|g_k\|^2}{\|g_{k-1}\|^2}}$$

> $\alpha_{k-1}$ 刚好在分子分母相消——这是巧合，不是设计。

---

## 为什么 FR 更好

| | 原始 $\beta$ | Fletcher-Reeves |
|:--|:--|:--|
| 需要 $Q$ | ✅ 需要 | ❌ 不需要 |
| 计算量 | $O(n^2)$（$Q p_{k-1}$ 矩阵-向量乘） | $O(n)$（两个内积） |
| 非线性推广 | 不行（$Q$ 不是常数） | **可以**（只用梯度） |
| 等价性 | — | 二次 + 精确线搜索下等价 |

> 原始公式是"**推导用的**"——从 $Q$-共轭约束直接解出，直观但不实用。FR 是"**计算用的**"——消掉 $Q$，只留梯度，既高效又通用。

---

## $\beta$ 的四种等价形式总览

对二次函数精确线搜索，以下全部等价：

| 名称 | 公式 | 特点 |
|:--|:--|:--|
| 原始（DHS） | $\dfrac{g_k^T Q p_{k-1}}{p_{k-1}^T Q p_{k-1}}$ | 直接导出，需 $Q$ |
| Hestenes-Stiefel | $\dfrac{g_k^T (g_k - g_{k-1})}{p_{k-1}^T (g_k - g_{k-1})}$ | 用梯度差替换 $Q p_{k-1}$ |
| Polak-Ribière | $\dfrac{g_k^T (g_k - g_{k-1})}{\|g_{k-1}\|^2}$ | 分母简化 |
| **Fletcher-Reeves** | $\dfrac{\|g_k\|^2}{\|g_{k-1}\|^2}$ | **最简，数值最稳定** |

非线性情形下四种公式**不再等价**，FR 通常最稳健（虽然可能更慢），PR 在有重启时更快。
