# 第10章 答疑 — 共轭梯度方向 $\beta$ 公式推导

> 问题：**共轭梯度法的方向更新公式 $p_k = -g_k + \beta_{k-1} p_{k-1}$ 是怎么导出来的？$\beta_{k-1}$ 为什么是这个形式？**

> 来源：`IV-无约束优化.md` 第 274 行

---

## 一句话兜底

> $p_k = -g_k + \beta_{k-1} p_{k-1}$ 不是猜的——先假设「新方向 = 负梯度 + 旧方向的修正」，再强制 $Q$-共轭条件 $p_k^\top Q p_{k-1} = 0$，解出唯一的 $\beta_{k-1}$。

---

## 推导三步

### Step 1：Ansatz

新方向用负梯度加旧方向某比例的修正：

$$p_k = -g_k + \beta_{k-1} p_{k-1}$$

纯 $-g_k$ 不满足 $Q$-共轭性——需要 $p_{k-1}$ 的分量来"修补"。$\beta_{k-1}$ 待定。

### Step 2：强制 $Q$-共轭

要求 $p_k$ 与 $p_{k-1}$ 是 $Q$-共轭的：

$$p_k^\top Q p_{k-1} = 0$$

代入 $p_k$：

$$(-g_k + \beta_{k-1} p_{k-1})^\top Q p_{k-1} = 0$$

$$-g_k^\top Q p_{k-1} + \beta_{k-1} p_{k-1}^\top Q p_{k-1} = 0$$

$$\boxed{\beta_{k-1} = \frac{g_k^\top Q p_{k-1}}{p_{k-1}^\top Q p_{k-1}}}$$

### Step 3：为什么只保 $p_{k-1}$ 就够了？

精确线搜索保证 $g_k$ 与所有历史方向正交：$g_k \perp p_0, \ldots, p_{k-1}$。

利用 $g_{i+1} - g_i = \alpha_i Q p_i$（由 $x_{i+1} = x_i + \alpha_i p_i$ 和 $g = Qx - b$ 推出），$Q p_i$ 是 $g_i$ 和 $g_{i+1}$ 的线性组合。所以对 $i < k-1$：

$$g_k^\top Q p_i = 0 \quad \Rightarrow \quad p_k^\top Q p_i = (-g_k + \beta_{k-1}p_{k-1})^\top Q p_i = 0$$

与更早方向的 $Q$-共轭**自然成立**——induction 一步到位，不需要手动逐对强制。

---

## $\beta$ 的四种等价形式

对二次函数，$\beta_{k-1}$ 的原始形式等价于以下四种（对非线性函数不等价）：

| 名称 | 公式 | 特点 |
|------|------|------|
| 原始（DHS） | $\frac{g_k^\top Q p_{k-1}}{p_{k-1}^\top Q p_{k-1}}$ | 直接导出，需知 $Q$ |
| Hestenes-Stiefel | $\frac{g_k^\top (g_k - g_{k-1})}{p_{k-1}^\top (g_k - g_{k-1})}$ | 用梯度差替换 $Q p_{k-1}$ |
| Polak-Ribière | $\frac{g_k^\top (g_k - g_{k-1})}{g_{k-1}^\top g_{k-1}}$ | 分母简化 |
| **Fletcher-Reeves** | $\frac{g_k^\top g_k}{g_{k-1}^\top g_{k-1}}$ | **数值最稳定** |
