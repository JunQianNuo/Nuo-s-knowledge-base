# 第22b章 答疑 — 为什么对偶可行性要求 $\mu \geq 0$

> 问题：**为什么不等式约束的乘子必须有 $\mu \geq 0$？**

---

## 从一阶条件推导

$\min f(x)$ s.t. $g(x) \leq 0$。在 $x^*$ 处，$\nabla g$ 指向禁区外，$\nabla f$ 必须指向可行域内——两力平衡，方向相反：

$$\nabla f(x^*) = -\mu \nabla g(x^*), \quad \mu \geq 0$$

```
        ∇g ↑（指向禁区外 g>0）
    ═══════╪════
    ▓▓▓▓▓▓▓│▓▓▓  g>0 禁区
    ▓▓▓▓▓▓▓●▓▓▓  x*
    ▓▓▓▓▓▓▓↓▓▓▓  ∇f（指向可行域内）
```

---

## 从 Lagrangian 下界推导

$$\mathcal{L} = f + \mu g$$

若 $\mu < 0$，对 $g < 0$（可行点）有 $\mu g > 0$ → $\mathcal{L} > f$ → Lagrangian **不是** $f$ 的下界 → 对偶函数 $q(\mu) = \inf \mathcal{L}$ 失效。

$\mu \geq 0$ 保证惩罚方向正确：违规（$g > 0$）被罚，守规（$g < 0$）被奖励。
