# 第21章 答疑 — 怎么理解积极约束集

> 问题：**积极约束集 $J(x^*) = \{j \mid g_j(x^*) = 0\}$ 是什么意思？**

---

## 一句话

积极约束 = 在 $x^*$ 处已经碰到边界的约束。没碰到的（$g_j < 0$）暂时不碍事，KKT 不关心。

---

## 图解

```
         g₁ ≤ 0
          ╲
    可行域  ╲   ● x*
    ▓▓▓▓▓▓▓▓╲ ╱
    ▓▓▓▓▓▓▓▓▓╳──── g₂ ≤ 0（积极！贴上了）
    ▓▓▓▓▓▓▓▓╱
           ╱
         ╱  g₃ ≤ 0（不积极，还在里面）
```

- $g_1$、$g_2$ 正好踩在边界上 → $J(x^*) = \{1, 2\}$
- $g_3$ 在内部，$g_3 < 0$ → 不在 $J$ 里

---

## 为什么重要

KKT 驻点条件：$\nabla f + \sum_{j \in J} \mu_j \nabla g_j = 0$

没碰到的约束乘子 $\mu_j = 0$（互补松弛），不参与梯度平衡。

> 类比：你靠着两堵墙，只关心这两堵墙的推力。远处第三堵墙虽然也是约束，但没挨上。
