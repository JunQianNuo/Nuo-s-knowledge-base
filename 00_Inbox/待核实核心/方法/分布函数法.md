# 分布函数法

## 适用场景
求 $\eta = g(\xi)$ 的分布，当 $g$ 非单调（如 $g(x)=|x|$）或反函数难求（如 $g(x)=\tan x$）时，分布函数法是唯一可靠的方法。也适用于 $g$ 单调但不想套公式的情况。

## 核心公式/步骤

**三步走**：

1. 写出分布函数表达式：$\boxed{F_\eta(y) = P\{g(\xi) \le y\}}$
2. 解不等式 $g(x) \le y$，确定 $x$ 的范围（需分段讨论）
3. 利用 $\xi$ 的已知分布计算概率，求导得密度：$f_\eta(y) = F_\eta'(y)$

对于多维情况，$\zeta = g(\xi_1, \ldots, \xi_n)$ 同样适用：
$$\boxed{F_\zeta(z) = P\{g(\xi_1, \ldots, \xi_n) \le z\} = \iint_{\{(x_1,\ldots,x_n): g \le z\}} f(x_1,\ldots,x_n) \,dx_1\cdots dx_n}$$

```mermaid
flowchart TD
    A["f_ξ(x)"] --> B["写出 F_η(y) = P{g(ξ) ≤ y}"]
    B --> C["解不等式 g(x) ≤ y<br>确定 x 的范围"]
    C --> D{"g 是否单调?"}
    D -->|"单调"| E["直接求 F_η(y)<br>或转公式法"]
    D -->|"非单调/反函数复杂"| F["分段讨论<br>每段分别处理"]
    F --> G["对 y 求导<br>得 f_η(y)"]
    E --> G
```

## 典型例题

> **题目**（$\eta = |\xi|$ 的非单调情形）：设 $\xi$ 的密度函数为 $p(x)$，求 $\eta = |\xi|$ 的分布密度。

> [!example]- 解答
> $g(x) = |x|$ 非单调——用分布函数法。
>
> 当 $y < 0$：$F_\eta(y) = P\{|\xi| \le y\} = 0$。
>
> 当 $y \ge 0$：
> $$F_\eta(y) = P\{|\xi| \le y\} = P\{-y \le \xi \le y\} = F_\xi(y) - F_\xi(-y)$$
>
> 求导：
> $$p_\eta(y) = \frac{d}{dy}[F_\xi(y) - F_\xi(-y)] = p(y) + p(-y), \quad y \ge 0$$
>
> 当 $y < 0$ 时 $p_\eta(y) = 0$。
>
> 综上：
> $$p_\eta(y) = \begin{cases} p(y) + p(-y), & y \ge 0 \\ 0, & y < 0 \end{cases}$$
>
> **特别地**：若 $\xi$ 的密度关于 $0$ 对称（即 $p(x)=p(-x)$），则 $p_\eta(y)=2p(y)$（$y\ge0$）。
>
> **点评**：$g$ 不单调时分布函数法是唯一可靠方法——解不等式 $g(x) \le y$ 确定 $x$ 范围，分段讨论边界。关键一步是将 $|\xi| \le y$ 等价转化为 $-y \le \xi \le y$。
