# 随机变量序列的收敛性

## 一句话

随机变量序列有四种收敛——几乎处处最强，依概率居中，依分布最弱；但**收敛到常数时，依概率和依分布等价**。Slutsky 定理则是依分布收敛的运算工具。

## 严格定义

**依分布收敛（最弱）**

设 $\xi_n$ 与 $\xi$ 的分布函数分别为 $F_n(x)$ 与 $F(x)$。若 $F_n \xrightarrow{W} F$（在 $F$ 的每个连续点收敛），则称 $\xi_n$ **依分布收敛**于 $\xi$，记作

$$\xi_n \xrightarrow{d} \xi$$

> 直观：分布函数的"形状"趋于一致，不要求变量在同一概率空间上有任何逐点关系。

**依概率收敛（居中）**

若对任意 $\varepsilon > 0$，

$$\lim_{n\to\infty} P\{|\xi_n - \xi| \geq \varepsilon\} = 0$$

则称 $\xi_n$ **依概率收敛**于 $\xi$，记作 $\xi_n \xrightarrow{P} \xi$。

> 直观：大偏差的概率趋于零——"大概率很接近"。

**$r$ 阶矩收敛**

设 $r > 0$，$E|\xi_n|^r < \infty$，$E|\xi|^r < \infty$。若

$$\lim_{n\to\infty} E|\xi_n - \xi|^r = 0$$

则称 $\xi_n$ **$r$ 阶矩收敛**于 $\xi$，记作 $\xi_n \xrightarrow{r} \xi$。$r=2$ 时特称**均方收敛**。

> 直观：偏差的 $r$ 次幂的平均趋于零。

**几乎处处收敛（最强）**

若

$$P\left\{\lim_{n\to\infty} \xi_n(\omega) = \xi(\omega)\right\} = 1$$

则称 $\xi_n$ **几乎处处收敛**（或以概率 1 收敛）于 $\xi$，记作 $\xi_n \xrightarrow{a.s.} \xi$。

> 直观：除了一个零测集外，每个样本点 $\omega$ 都逐点收敛。

## 关键性质

### 四种收敛的关系

```
几乎处处 ──→ 依概率 ──→ 依分布
   ↑                      ↑
 r阶矩  ──→ 依概率 ──→ 依分布
```

**不能推出的方向**（常见反例）：

| 不成立的关系                     | 反例                                                                                              |
| :------------------------- | :---------------------------------------------------------------------------------------------- |
| 依概率 $\nRightarrow$ 几乎处处    | $[0,1]$ 上"滑动区间"序列：每个 $\omega$ 被无数个 $\xi_n$ 覆盖，但区间宽度 → 0                                         |
| $r$ 阶矩 $\nRightarrow$ 几乎处处 | 同上                                                                                              |
| 几乎处处 $\nRightarrow$ $r$ 阶矩 | $\xi_n = n \cdot \mathbf{1}_{[0,1/n]}$，$E\xi_n = 1 \nrightarrow 0$                              |
| 依概率 $\nRightarrow$ $r$ 阶矩  | $\xi_n = n \cdot \mathbf{1}_{[0,1/n]}$，$P(\xi_n > \varepsilon) \to 0$ 但 $E\xi_n \nrightarrow 0$ |
| **依分布 $\nRightarrow$ 依概率** | 取 $\xi \sim B(1, 1/2)$，令 $\xi_n \equiv \xi$，$\eta = 1 - \xi$。分布相同 → $\xi_n \xrightarrow{d} \eta$，但 $\xi_n$ 与 $\eta$ 取值完全相反 → $P(\vert\xi_n - \eta\vert > 1/2) = 1 \nrightarrow 0$ |

### 核心等价：收敛到常数

若极限是常数 $C$，则：

$$\boxed{\xi_n \xrightarrow{P} C \;\Longleftrightarrow\; \xi_n \xrightarrow{d} C}$$

这是唯一两种收敛等价的情形。原因：退化在 $C$ 的分布函数只有一个不连续点 $x = C$，依分布收敛变严格。

## 推导：几乎处处 ⇒ 依概率

> [!proof]- 推导
> 设 $\xi_n \xrightarrow{a.s.} \xi$，即 $P\{\lim \xi_n = \xi\} = 1$。对任意 $\varepsilon > 0$，定义 $A_n = \{|\xi_n - \xi| \ge \varepsilon\}$。
> 由几乎处处收敛，$P(\limsup A_n) = 0$（因为除了零测集外，$|\xi_n-\xi|$ 最终小于 $\varepsilon$）。
> 由 Fatou 引理：$\limsup P(A_n) \le P(\limsup A_n) = 0$，故 $\lim P(A_n) = 0$，即 $\xi_n \xrightarrow{P} \xi$。

## 收敛到常数的运算性质

若 $X_n \xrightarrow{P} a$，$Y_n \xrightarrow{P} b$（$a,b$ 为常数），则：

- $X_n + Y_n \xrightarrow{P} a + b$
- $X_n \cdot Y_n \xrightarrow{P} ab$
- $X_n / Y_n \xrightarrow{P} a / b$（$b \neq 0$）

证明只用依概率收敛定义 + 三角不等式 + 有界性技巧，不超出课件范围。

## 典型例题

> **题目**（依概率 vs 几乎处处——滑动区间反例）：在 $[0,1]$ 上构造 $\xi_n$：逐轮将 $[0,1]$ 切成 $k=1,2,3,\ldots$ 等份，每份依次作为 $\xi_n$ 的取 1 区间。即第 $k$ 轮有 $k$ 个 $n$，对应区间宽 $1/k$。求证：$\xi_n \xrightarrow{P} 0$，但 $\xi_n$ 不几乎处处收敛。

> [!example]- 解答
> **依概率**：对任意 $\varepsilon \in (0,1)$，$P(|\xi_n - 0| \geq \varepsilon) = P(\xi_n = 1)$ = 当前区间宽度。第 $k$ 轮区间宽 $1/k$，随 $n\to\infty$（$k\to\infty$），$P(\xi_n=1) \to 0$。$\square$
>
> **不几乎处处**：对任意固定 $\omega \in [0,1]$，在第 $k$ 轮中 $\omega$ 必然落在某一个子区间内——该轮内 $\xi_n(\omega)$ 有一次为 1。因此 $\xi_n(\omega)$ 在 0 和 1 之间无限振荡，$\lim \xi_n(\omega)$ 不存在。$\square$
>
> **核心启示**：比例→0 ≠ 每个个体稳定。依概率看整体比例，几乎处处看每个点的轨迹。

---

> **题目**（习题5.12）：证明 $X_n \xrightarrow{P} X,\; Y_n \xrightarrow{P} Y \;\Rightarrow\; X_n + Y_n \xrightarrow{P} X + Y$。

> [!example]- 解答
> 三角不等式：$|(X_n+Y_n)-(X+Y)| \leq |X_n-X| + |Y_n-Y|$。由并集上界：
> $$P\{|X_n-X|+|Y_n-Y| \geq \varepsilon\} \leq P\{|X_n-X| \geq \varepsilon/2\} + P\{|Y_n-Y| \geq \varepsilon/2\} \to 0$$
> 故 $X_n + Y_n \xrightarrow{P} X + Y$。证明只用了依概率收敛的定义和三角不等式，不涉及分布。

## 易错点

> [!warning] 易错点
> 1. **四种强度不要搞反**：几乎处处 > 依概率 > 依分布；$r$ 阶矩 > 依概率 > 依分布。
> 2. **几乎处处和矩收敛互不蕴含**：几乎处处收敛不一定保证矩收敛（偏差可能大但概率极小），反之亦然。
> 3. **收敛到常数的等价只对依概率/依分布有效**：几乎处处和矩收敛都不会因此变等价。
> 4. **Slutsky 定理要求 $Y_n \xrightarrow{P} c$ 是常数**：若 $Y_n$ 收敛到随机变量，结论不成立。
> 5. **依分布收敛本身没有线性运算性质**：$X_n \xrightarrow{d} X$，$Y_n \xrightarrow{d} Y$ 不能推出 $X_n + Y_n \xrightarrow{d} X + Y$（除非独立或借助 Slutsky）。
