4. 未经允许，不得修改 `docs/` 中的文档。
5. `docs/` 文档应简洁、易读，不堆砌混乱术语。
6. 遵守 `99_System/` 中各功能的详细运行规则、维护程序及内部数据约定。
7. 若工作与 `docs/` 或 `99_System/` 的约定冲突，立即中止并询问如何处理。
8. 若架构在获批准情况下改动，需要及时更新`docs/ARCHITECTURE`
