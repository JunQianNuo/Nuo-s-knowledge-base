# 个人知识体系迁移实施计划

> 执行方式：按用户“实现第一点与第二点”的授权在当前知识库完成；三个课程的汇集差异独立审查，文件迁移与整合由主执行者统一进行。

**目标**：概念、知识点、方法取消课程子目录，成为跨课程复用的个人知识条目；停用并移除知识点汇集，保留其中独有的有效内容。

**范围**：三个原子知识目录、24 份汇集及对应知识梳理、相关模板/规范/导航和受影响的链接。不改第三点已完成的来源图谱方案，不改数学建模独立项目的内容。

## 验收步骤

- [x] 记录现有未提交改动，保存 Markdown、Bases、Canvas 和汇集附属文件的 ZIP 备份；保存 Obsidian 实时链接快照。
- [x] 比较同名条目，区分内容合并与语义分支；将算法归到方法，定理和性质归到知识点，课程图谱回到课程目录。
- [x] 通过 Obsidian 文件管理接口迁移并更新链接；合并重复概念短卡和单一算法操作卡，保留推导、例题、有效块 ID 与来源。
- [x] 去掉个人条目的课程归属字段；补全语义关联、方法入口和课程中的引用，建立不按课程分组的静态索引。
- [x] 逐份审查24份汇集，将独有的有效内容并入知识梳理；改链后移入系统回收站，清除空目录和已备份的提取临时文件。
- [x] 更新原子卡、课程笔记、复习、质量审查规范、模板和 Agent 指令，取消固定九板块汇集流程。
- [x] 核验新目录、迁移覆盖、内容保留、元数据与链接；抽查同名方法、方法与习题关系、来源属性和移除汇集后的锚点。

## 重点检查

1. 现有用户改动不得回退或覆盖；备份保存本轮起点的实际文件。
2. 同名牛顿法、割线法、二分法须保留求根与求驻点/极值的不同条件。
3. 不把概念、规律与操作流程强制拆成三份重复笔记；复合方法和选择流程可独立保留。
4. 汇集中的错算、缺条件和无效引用不得作为补充内容扩散；已存在的内容问题记录于报告。
5. 旧课程前缀、普通元数据路径、Wiki-link 标题锚点与短文件名都要核验；不把历史上已有的失效链接误报为本轮新增。

完整迁移清单、差异审查和原始备份保存在本次会话的 `knowledge-restructure` 产物目录。
