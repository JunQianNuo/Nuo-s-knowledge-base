## 报告结构

### 1. 引言
- 历史背景：Joseph Fourier 与热传导方程
- 核心思想：从时域到频域的视角转换
- 报告中使用的符号约定

### 2. 傅立叶级数
- **三角函数形式**：$f(t) = a_0 + \sum_{n=1}^{\infty}(a_n\cos n\omega t + b_n\sin n\omega t)$
- **Dirichlet 条件**：周期函数可展开的充分条件（分段连续、有限个极值、有限个间断点）
- **复指数形式**：$f(t) = \sum_{n=-\infty}^{\infty} c_n e^{in\omega t}$
- **例子 2.1 — 方波展开**：完整计算过程，含频谱图（Mermaid）
- **例子 2.2 — 三角波展开**：完整计算过程，对比方波（衰减更快）
- **Gibbs 现象**：简述 + 图示

### 3. 傅立叶变换
- **从级数到变换的过渡**：周期 $T \to \infty$，离散和 → 连续积分，离散谱 → 连续谱
- **定义**：$F(\omega) = \int_{-\infty}^{\infty} f(t) e^{-i\omega t} dt$
- **逆变换**：$f(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} F(\omega) e^{i\omega t} d\omega$
- **核心性质**：线性、时移、频移、尺度变换、卷积定理、Parseval 定理
- **例子 3.1 — 矩形脉冲**：$\text{rect}(t/T)$ 的变换 → sinc 函数
- **例子 3.2 — 单边指数衰减**：$e^{-at}u(t)$ 的变换

### 4. 级数与变换的关系
- **对照表**：级数（离散谱）vs 变换（连续谱）
- **视觉对比**：周期方波频谱（离散线）→ 非周期矩形脉冲频谱（连续 sinc）
- **统一视角**：正交基展开 → $L^2$ 上 Fourier 级数 → $L^2(\mathbb{R})$ 上 Fourier 变换

### 5. 应用举例
- **信号滤波**：低通滤波的频域解释
- **微分方程**：用 Fourier 变换解热传导方程（简述）
- **图像处理**：JPEG 压缩与 DCT 的关系（一句话提一下）

### 6. 总结：关键公式速查表
- 傅立叶级数（三角函数 / 复指数）
- 傅立叶变换对
- 常用性质一览
